# period-outlook 占类方法

来源方法：`shiyun-zonghe`；依总入口加载，完整条件见下文。

## I — 方法论骨架 (Interpretation)

时运课是"泛占一段时间运气"的综合课，问题没有单一类神。作者把判断拆成一组合的逐维检查清单，核心逻辑是"课传中显示出什么，就断什么"——哪一维有明确象就细断哪一维，无象的维度不强断。

1. 先验课体定大势（吉凶先验）：吉课（龙德、铸印、互生俱生）整体偏吉；凶课（天网、解离、芜淫、鬼临三四）整体偏凶。
2. 安全维优先（凶煞优先法）：吉象=长生、父母爻旺相；凶象=太岁/岁破/勾蛇虎空玄作日鬼或克行年→死丧、官司、病伤、盗贼。安全不过，其余各维全部打折。
3. 收入维：看父母爻、日禄的虚实旺衰；空陷或乘凶将→减薪减收。
4. 婚姻维：六合、太常旺相生合干支为吉；怕解离格、芜淫课。
5. 官运维（有官职者）：贵人、青龙、太常作父母爻/长生爻→有升迁之象；怕勾虎克干克行年。
6. 家运维：以支上为主，喜生气，怕支上作鬼。
7. 看课重点：干上（我之所遇）、支上（他人他物）、三传（初中末三阶段）；重神、夹、空、墓、拱、并聚等"纠结之处即显明之事"。
8. 年命锚点（g13）：年命入课传看本身、不入课传看年命上神；行年上神代表占者当前状态。
9. 产出：逐维结论 + 综合吉凶定性 + 特别事件提示。有官职者"官比财更重要、发用比末传紧迫"。

## E — 可执行步骤 (Execution)

1. **定义时段与现实身份**：确认是阶段综合运势，而非一个具体事件；记录题干已知职业/关系与年命，缺项不推造。用户已给核心问时优先回答，不能用五维泛论覆盖。
2. **背景与分维并读**：沿用安全、收入、关系、官运/工作、家宅五维；各维有明确象才论，标对象、位置、作用时段。背景只作暂定框架，不因一个安全凶象自动压低全部维度或直接定死丧。
3. **跨维核对**：同一象可能表示职责、压力、收入等不同层面，须说明选择理由，不把一种不顺扩成处处不顺。取最强反证检查，发现救应时重新确认作用范围；一维变动不等于其他维度同向。
4. **输出**：各维结果及边界、共同主线和有依据的转折；工作内部事务可路由应聘/升职，财务路由财禄。无象写不足，不按固定数量编特别事件。

保留上文 c15–c17 的逐维论证，参照 M06 的分年分问组织；不是整体命中验证。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- ce05（白虎）：见虎即断死丧大凶，忽略"壬占最重位"——白虎作阴神只显象不主吉凶、发用才主吉凶；长生带白虎=先吉后祸（先得死丧之财、后有横祸）。时运安全维必须查虎的位、受制、克谁。
- ce06（勾陈）：只断官司打斗，忽略"迟滞"义——勾陈临干或作大运主题=运势极度低迷、像时间停止、麻烦不断，恰如被捆住手脚。
- ce11（凶课体）：只按类神断而漏课体凶格（天网难逃、解离婚姻先好后坏、芜淫私情、干支乘墓为"止"）；吉课体（轩盖课）遇空亡变质转凶（乘轩落马→丢官罢职）。且同一课体吉凶随占类而变（解离问婚姻凶、问牢狱反可逃脱）。
- ce12-ce15（公共边界）：全书案例全部"果应"=幸存者偏差，不可当统计证据；同一课可多解、结论对侧重选择敏感；象意系统模糊、无预注册检验，命中率未必高于随机；干支五行映射人事是未论证的信仰前提。

### 作者的盲点 / 时代局限

- 案例集中于 2004–2009（股市、房改、金融危机），经济语境过时；方法论本身不依赖时代。
- 五维"课传中显示出什么，就断什么"的对应关系被默认为稳定唯一，实际同一课不同侧重可得相反结论（ce13）。
- 反馈多为占者事后自述、时间跨度短（多为数月），缺乏长周期检验；"果应"=判断正确未被证明。
