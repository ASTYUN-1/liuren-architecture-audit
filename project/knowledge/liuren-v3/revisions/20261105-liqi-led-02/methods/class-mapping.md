# 分类与九系统共同取用

本机采用“理气为骨、象法为肉”。分类取用确定理气所分析的对象；关键类神既看自身旺衰气地，又看其与四课三传及其他关键类神的实际作用。专法中的吉凶象辞保留来源和条件，不能越过共同理气直接裁决成败；具体形象依已判走势表达。

先明确背景、对象、事件阶段和结果标准，按子问选类：朋友借款先查财务，公司同事态度先查人际；录用、薪资到账、升职分别判断。类别及模块见入口，不用关系称谓代替目标。九系统按职责参与，不凑九格或 108 格。

1. 干支先依分类专法确定阴阳、动静、尊卑、内外等对待轴，再展开干阳干阴、支阳支阴。日干不由谁提问机械决定，也不永久等于事件主体；四课不按人数分配，多象可共指一人。G01。
2. 支神取物类、形质、功能；天将取人、物、事或职能；复合象必须实际具备所需节点。神煞可直接为类或限定性质，先核起法、位置、乘将条件。六亲注明相对谁，分人物义与作用义。G04—G08。
3. 长生运区分胎库等直接取类与对象状态，核参照五行/十干和起例；土胎差异见 D02，不能双取凑答案。课体核完整构成和占类，不由课名定结果；年命核归属、年界及起法，分本身/上神/所临；遁干先辨旬遁/五子遁，再察暗六亲与旬煞。G09—G12。
4. 同目标候选按专项择主，不同职责兼看。九系统提供取用依据，关键类神须与四课三传一起进入理气裁决；不按类神或课名标签直接定结果。类不现按成败、属性、方向及所查位置分支：北海财孕成败重类现，动物属性、盗贼方所等可到天地盘寻类；壬归仍凭类及类神三传另列。不一概删去或无边界遍找，“一般不计第二、第四课”也不等于删除已定位对象的阴神作用。财通专及不现内部异说见 D01；未入课传的并举及未解例保留待辨。互换查得本家不算原将已经入课传。G02—G03。
5. 取类与察象同时执行：四课三传、已核年命中的其他相关显象仍须检查其如何作用于本问，不能只看常用类神，也不由朱勾空等名称凭空增加官司、第三者。课体不固定为背景，显象不预设只作细节；默认不越问，专门例外须满足原法。金针1444“不作为类象”与其课体章总论仍有文字张力，保留待辨，不改原文制造一致。D03。

比较争议先分通法、专法、阶段与所答维度；同条件仍互斥，再按北海（含毕法讲解）→壬归→指南→毕法原文取用。北海内部异说及文本张力保留待辨，不拼成无例外法。需核 D01—D04 原段时读 mapping-provenance 所列卡及原文。
