# 事件定位、人物取用与主线选择

适用：每次单事判断的明占类与定侧重。北海三步法提供选线方法；本文件补足事件主体与代问关系的区分。此事件定位约束是本项目修订，不冒称整段出自《壬归》。

## 先固定事件，再决定符号

保存原问并编号Q1、Q2。记录主体、事件、阶段、期限、判断维度与成功标准。区分成败、存现、趋势；数量、程度、属性、身份、方位、时间另列，不强吞入三分类。例如“会否进任何水”不同于“会否成灾”，“考试通过”不同于“发挥顺利”，“录用”不同于“收到通知”或“入职”。题干未确认的背景不得由盘象补造。

一个事件盘围绕所问事情建立主体关系；同一患者、同一病程问题，换家属来问，不能仅因亲属身份把全盘主体改成家属。**日干常为人，但先说明这个“人”在本题是谁；日干并非永远是提问者。** 不把六爻式“按亲属六亲直接替换一切主体”的做法无条件搬入六壬。

每问先给定位表：

| 角色 | 必须填写 |
|---|---|
| 事件主体 | 谁正在经历哪件事，来自题干哪句话 |
| 提问/代问者 | 与事件主体的关系；是否确实进入本问关系 |
| 日干、日支 | 本问含义、取法出处、适用范围；不适用也说明 |
| 主类神 | 代表人、病、事、物、阻碍还是治疗；不能混名 |
| 辅助象、六亲 | 相对于哪个参照；身份佐证或作用节点，不能自动顶替主体 |
| 本命/行年 | 属于谁、出生年界与起法是否核定；未知保留 |

定位未成立时，暂停依赖该定位的生克吉凶和应期；可继续核盘和查方法。确有多个有据取法时，先说明各自回答的子问及成立条件，选定后再判断，不因哪个取法更吉或更凶而更换。定位变更须重算所有受影响关系及结论，不能沿用另一参照的“生我”“脱我”。

## 常用角色的适用边界

- **疾病进展、治疗、恢复**：指定患者为事件主体，默认日干定位该患者；祖孙、父子、朋友代问均不自动改变。日支须依实际方法明确为病、病所/环境或其他所指，不能在一条论证里自由切换“医院—病症—身体”。父母爻、子孙爻等先是相对于日干的关系与作用节点，不能只按亲属称谓替代患者。患者、病象、医药、救应分列。特殊代占取年命等须说明来源与条件，见疾病专项。
- **传统异性感情法**：保留专项常法“干男、支女”；女问男也不自动改为干女支男。谁问、谁主动、谁是谁的对象分别记录。变法、本命行年按专项条件；同性关系尚无完整统一专法，不能按提问顺序或主被动臆造男女映射。
- **家宅/车库**：按人宅法干为人、支为宅时，支及其上下关系必须直接进入宅的判断；不能只论三传水势而遗漏水与宅的实际位置和作用。支上火、水不入传、辰为水库等单项，都不自动保证干燥、无水或必进水。
- **考试**：先定考试阶段和成功标准，区分学校、驾驶资格、职业资格；从专项核考生、考试场域、考官/文书/资格，不能见“考试”就只取文昌或父母。某符号是资格还是患者/考生，应有明确角色。
- **司法行政**：先区分报警求助、调查、处罚、诉讼、羁押、取证、办证等事件。机关名称不能单独决定勾陈、官鬼或白虎；法院、警察、监狱、市场监管、城管不能无条件共用一个定式。未有专项时检索该事件方法，不编一张万能机构取用表。
- **出行/行人**：出行问主体将往某地及路程；行人问已经在外或所候之人，先固定其与提问者、目的地/家宅的关系。人、路途、归宿不能互相代替。有据的干陆支水、支城干外等是各自方法的条件读法，不叠成一套永久映射；见动态模块。

这些边界仅确立定位前提，不预判吉凶。没有成熟细则时列检索依据与待定项，不用常识补出术理。

## 类神、日辰关系、课体的主次

先实际检索本问的方法、完整条件和反例，再选主线：具体对象先检查对应类神；人物/事物的相互作用检查日辰角色关系；方向大势或取不到明确对象时检查课传结构。课体也是固定类象组合，三者在同一流程中核对。

类神选取须能定位到干支神将组合：例如原论中的房产亥楼/午厅堂/卯房宿/丑勾田产、孕胎神、证件戌印绶乘六合、病白虎官鬼、职位禄/父母/长生，都是待核对象与条件的候选，不能看到就判成事，也不能把“病象”偷换成“病人”。

“入课传为重、象清晰”是选线条件，不能由不入传删除相关对象。以直接性、位置、状态与完整适用条件说明主次；无永久“课体最大”“类神最大”“三传定一切”排名。同一问给一条可解释的主线和最强相反依据；不同子问可不同主线。冲突不足裁决时保留分歧，不拼接互相矛盾的答案。

## 占类词与来意

检索使用统一十类：事业占、财运占、感情占、学业占、健康占、出行占、失物占、官讼占、家宅占、天时占。标签仅帮助路由；实际取用以具体子问与专项条件为准。传统候选索引分别有官星/青龙/贵人/驿马，财/青龙/太阴，天后/六合，朱雀/太冲/文昌/魁星，患者/病象/白虎，传送/驿马，玄武/太阴，勾陈/朱雀/白虎，日支/功曹，青龙雨/白虎风/朱雀晴/太阴阴；辅助象不得越过事件定位。

只有用户未明说事项时才用来意法：正时与所临类神、天将相参，泛占由课传紧事、干支乘神和实际落点推测；干上主思、支上主行是该来意法参考。说明“推测占类”，不能用盘象改写用户已明确的问题。默认不越占；原论课象明显可提示紧事的例外须保留来源与条件，不能据此无限扩写。

完成标准：原问与成功标准、定位表、实际选法来源、主线为何回答本问、最强反证候选、定位缺口。角色只在表格出现而没有参与任何结论依赖，视为未完成取用。
