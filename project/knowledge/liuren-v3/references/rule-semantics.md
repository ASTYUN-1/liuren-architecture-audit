# 判断规则的适用范围与否定含义

用于解释、提取、压缩和应用六壬判断规则。这里规定怎样忠实表达规则，不新增任何占断结果通则；原书论法、经验假说和当前执行约束仍须分清身份。

## 先确定一句话究竟在限制什么

“仅凭A不足以断定B”只说明A不能单独决定B。B仍是候选，也可能不发生；要判断B或非B，均须另有对应证据。不能改读成“有A就没有B”，也不能自动改成双方概率相等。

例如“在胎产占中，仅见白虎不足以确定剖腹产”，限制的是**从单一白虎象直接认定分娩方式**这一步推断，没有排除剖腹产。否定一种推断方法与否定一种现实结果，须分别表述。

| 表述性质 | 在对应范围内允许表达什么 | 不能偷换成什么 |
|---|---|---|
| 单项不足 | 仅凭A不能确定B，需补证；B仍待判 | A成立所以B不会发生，或A对B毫无参考作用 |
| 条件排除 | 有明确方法和排除证据，且条件齐备时，在指定对象/阶段排除B | 未核条件便永久排除B，或外推到其他占类 |
| 有限支持 | A在所列条件下支持B；支持力度须依来源及实际作用判断 | 必然B、只有B，或相反结果已被排除 |
| 反例 | 有A而没有B的实例可否定“A必B” | A通常不B、A必然非B，或该例证明所有原推导均错 |
| 未知/未发现 | 当前资料未给、未检查或所选方法未检出 | 已证实不存在、一定不会发生 |
| 不适用 | 本方法缺前提，不能在此问使用 | 现实事件不可能发生，或其他方法也不能判断 |

若原规则确有明确的排除或充分条件，应完整保留该强度与依据；本规范不能把所有“禁止”“不成立”都软化为可能。排盘计算定义、禁止编造事实及用户授权边界等执行约束，按各自规定执行。

## 一条可迁移规则要把话说完整

解释或新整理一条影响判断的规则时，在相邻文字中交代：

- **适用范围与前提**：哪种占类、哪个子问、人物/类神、位置、阶段与时间；已确认哪些条件，哪些仍未知。“仅见”“单凭”“当且仅当”“同时”“至少一种”等限定不能省掉。
- **具体断言及强度**：它是定义、必要条件、充分条件、支持线索、倾向、单项不足、条件排除，还是待验假说？写明限制的是推断步骤、证据效力还是现实结果。
- **保留范围与后续判断**：未排除什么，另有哪些相关可能，需核哪些关键条件才能取舍。只列与本问相关的候选，不为完整性穷举全部象义；没有出处的成立条件写未知，不自行补齐。
- **来源、例外及停止位置**：原文支持到哪里、是否存在条件反例；缺资料时停在何种精度。若原文本就残缺，保留缺口，不能借“补全定义域”冒充作者原论。

不必每条都套固定表格，但离开原案后的摘要也应能独立表达边界。必要条件不自动成为充分条件；“缺A不能用此法证明B”不自动等于“缺A则B不会发生”。列出的例子默认是解释候选，除非来源明确穷尽，不能当封闭清单；不同事件或阶段也不天然互斥。

## 胎产例：白虎与剖腹产

**当前可用的完整表述：**在胎产占中，若只凭白虎出现及其刀刃、见血等象义，尚不足以确定将采取剖腹产，也不足以排除剖腹产或认定顺产。剖腹产仍可列为候选；出产出血、撕裂、侧切或其他相关意外也可按本问和资料另核。这些不是穷尽列表，出血与手术可以同时发生，不能把它们当作非此即彼。

判断分娩方式时，须结合本问的母胎取用、相关位置、月令与坐处、具体结构、实际制救和其他有出处的分娩方式依据。相关信息若只够说明见血/刀刃之象，就停在这一层，分娩方式保持未定；其他证据支持剖腹产时，不能用本条将其否决。以上候选不是对真实患者的诊断或治疗建议。

按本次用户明确纠正的先后顺序：误用发生后，经用户指出，才有后续条目/补注防止再次误用。当前档案中的限制文字不能证明初版就已写完整，更不能据此声称模型在原限制齐备时仍然忽略规则。首次整理就应表达清楚：不能由“不是必剖”读成“一定不剖”。旧补注中的“性偏剖”“判剖看闭不看血”等仍保留原有来源和待验身份，不能升级成所有胎产题的必要/充分条件，更不能从未见墓闭直接推出无需剖腹产。

## 防止压缩、检索和复盘再次丢失边界

经验标题、摘要、检索返回和引用段落都要保留会改变意义的限定。可用标题“胎产：仅凭白虎不足定顺剖，仍须补证”，不单写“白虎不等于剖腹产”。“不是必剖”不能压缩成“不剖”，“可顺产”也不能压缩成“偏顺/必顺”。

首次写入时就做这项检查。后续纠错保留原表述、发生的误读、用户纠正及补注的先后身份；当前合并文本不能当作误用发生前已经存在的版本。若只有现版，初版内容或当时加载情况记未知。

检索只返回短标题或条件残句时，先回原文及相邻限定，再决定是否引用；无法补齐时，仅记录歧义及其来源，不用于确定排除或保证结果。不得将旧摘要的含糊之处用自己偏好的结果补完，也不为了新文案而改写历史初判。

最终检查一遍：读者是否可能把“尚不能确定”读成“确定不会”？列举是否被当作穷尽、互斥？本案观察是否越出了对象、阶段或占类？若可能，改成包含适用范围、保留候选和下一步条件的完整句。
