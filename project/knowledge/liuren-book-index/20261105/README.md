# 三本常用书的结构化检索

检索增强版本：`20261105-three-book-search-01`。与专业方法包07分开登记；原书及冻结方法包不改写。

| 代号 | 原书 | 原始行数 | 目录定位区间 | 检索段 |
|---|---|---:|---:|---:|
| RG | 壬归 | 971 | 58 | 60 |
| LF | 北海闲人《大六壬理法易简》，文件名《理法简易》 | 6931 | 85 | 161 |
| TY | 喜爱六壬的水《献给六壬天一群的六壬笔记-2023年》 | 5423 | 159 | 161 |

“目录定位区间”包括原书章、节及部分书内例证标题，不等于302个独立章节或独立案例。检索段由标题边界及句末段落组织，不按固定行数截断。PDF转文本中的硬换行可以跨行匹配；返回原文仍使用原字节解码后的一基splitlines行号，不改写或重排。长章采用段落组并带邻段；过长输出明确标出未返回范围。原书本来缺失或混在正文中的标题不擅自补造，LF原文由卷之六跳到卷之八的缺口保留。

`catalog.json`保存三本书的路径、别名、原字节SHA256、编码、目录锚点、专题检索词及19个既有已核选段的定位。目录的`end`表示该标题之后到下一个标题之前的连续正文区间，`subtree_end`包括下级标题，二者不能混用。专题检索词仅帮助召回，不表示术理同义、通则成立或分歧解决。

`index.sqlite3`是可重建的SQLite FTS5字符二元索引，索引正文定位区间和章节关键词，不保存可以代替原书的AI摘要。搜索以原查询词完整命中优先，再用章节和文本相关性排序。多词完整命中存在时不拿单词弱命中填满结果；必要的已登记相关口径另列，不能因此忽略本问其他反证。相同来源重叠区间少返，但不同来源观点不合并。查不到时仍可用全书库scan或目录定位，不能宣称全部相关资料都已找到。

普通OpenCode使用已有`liuren_materials`，无需新增独立工具名或开启插件：

```json
{"action":"book_search","query":"死火 旺金"}
{"action":"book_search","queries":["十二长生","鬼禁日"],"limit":4}
{"action":"book_search","query":"财旺 身弱","book":"RG"}
{"action":"book_outline","book":"LF"}
```

默认最多4个结果，原文总预算14000字符，包含相关原文；单次可集中最多4个必要争点。`book`可以是RG/LF/TY，省略则搜索三本；其他书仍走scan/books。`passage_complete`只表示所选检索段是否全部输出，`section_complete`才表示这个目录定位区间是否全部输出；两者均不证明全书、全部论法或所有例外已读。`continuation`显示截断续读位置；`context`提示章内未返回范围。行内字符截断时，char_offset只是截断位置元数据，read补读时读取该原始整行。

Build维护命令（不调用模型）：

```powershell
python -X utf8 tools/liuren_book_search.py check
python -X utf8 tools/liuren_book_search.py search "死火 旺金"
python -X utf8 tools/liuren_book_search.py outline --book RG
python -X utf8 tools/liuren_book_search.py build
```

原书每次搜索均校验字节哈希，并只从当前原书回读文本；索引只读打开，不在普通研判中自动重建。原书或目录变化报错，维护者须先核版本、编码、目录和选段，再修改catalog并build；启用时同时更新活动指针中的检索增强记录。普通工具不接受任意目录或自选数据库路径，也不通过此索引访问案例库、经验库、旧缓存、其他运行包或开发资料。

作者正文、所引古籍、后人注解、书例断语和原载反馈可能在同一节交错。已核选段保留原来源身份；其余按章的身份提示只是辅助，仍须逐段辨别。本次只做定位结构与检索优化，没有把三本书逐条语义精读，也没有新增术理归纳或预测效果验证。
