# 农渔畜养：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C30 农事：农人、田圃、所种与收获分别定位

适用：分清已定种何物，还是问宜种何物；区分人安、作物长势和实利收获。

干农人支田圃，支上可为所植，日上可为所仰天时；禾谷按水木火金土分类，结合所求作物、旺衰、地盘、阴神与干支作用。初中末可分早中晚之宜。

排除与边界：壬归专分“已有所主”和“原无所主”，不一律要求类现才可察类。；古代粳糯大小等释义保留文本身份，不改写为现代农学事实。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：壬归 LF662—696（工作台662—696）；理法 LF2273—2296（工作台4545—4591）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C31 桑蚕：蚕、桑、茧、丝与蚕娘须各有类

适用：明确问养蚕生长、结茧或丝绵收成，核阶段。

壬归以午蚕、未桑、寅茧等分取，并仰看午上神；心镜本歌分午蚕未桑、寅茧、巳筐、卯丝、辰箔、申绵等。再核所求类及蚕娘年命关系，不能用财爻一项统包。

排除与边界：指南864—865与心镜940对卯絮申丝、卯丝申绵文字不同，详D04，不擅自统一。；单见有利蚕之象不保证人的实际收益或安全。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：壬归 LF702—710（工作台702—710）；壬归 LF730—748（工作台730—748）；心镜 LF938—940（工作台938—940）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C32 畜养：按动物本类取用，临地、栏舍与乘将兼察

适用：明确所养品种及问生长、病损、栏舍还是买卖收益。

指南列戌犬寅猫酉鸡午马丑牛未羊亥猪等；心镜注本又察动物类神所临及物命。断案吴四公例逐种察栏舍、宅基与各动物处境，不能把多个品种压成一个总类。

排除与边界：畜安、生长、是否获利是不同问题；不由一个类神强行得出全群动物同命。；断案的伏尸叙事属原载解释，未被本批核实；金针转引戌亥有异文。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF866—868（工作台1731—1735）；心镜 LF970—974（工作台970—974）；断案 LF1844—1852（工作台1844—1852）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C33 渔猎：人网与禽鱼是不同对象，取物不等于通用求财

适用：所问确是捕获禽鱼，已明确方法、对象及子问。

心镜渔猎本歌取支为鱼鸟、干为网，入式及郇注又以干为渔猎人与网罟、支为禽兽鱼鳖，核人和所获物的状态与制约；欲知何物又看支上神。

排除与边界：养殖宜物长旺与捕猎宜制获物属于目标不同，不强行统一吉凶。；心镜1208本歌“干伤支吉”与注文的有气无气、干克支读法须保留各层；本批不擅改歌文。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：心镜 LF1206—1208（工作台1206—1208）；理法 LF641—641（工作台1281—1281）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D04 待辨：蚕桑丝绵异文与转引个案的戌亥差别

适用：需要以丝绵的精确取类或吴四公个案做进一步推断。

指南865作“寅茧卯絮申为丝”，心镜940作“卯是丝、申为绵絮”；断案1851作“戌加亥作白虎”，金针1224的转引另作亥。前者是词义或版本差别待校，后者是盘位转引疑点，均不应静默修正。

排除与边界：指南在作者优先序中可作本批优先检索口径，仍须保留异文身份，不说明孰真。；未核扫描页，不用异文直接新增一种神将关系。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF862—868（工作台1723—1735）；心镜 LF938—940（工作台938—940）；断案 LF1844—1852（工作台1844—1852）；金针 LF1221—1228（工作台1221—1228）。完整连续引文见同 ID 规则卡。
