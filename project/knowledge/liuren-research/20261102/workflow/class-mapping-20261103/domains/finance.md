# 财务经营：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C06 人际：去求人与等待答复阶段可改变干支

适用：所问确为主动求办或已求后等待答复，实际阶段已知。

北海分别取：尚未去而打算求人，我动为干；已去、现待对方消息，我静为支，对方为干。此法不可因结果不利而临时倒换。

排除与边界：不是所有代问或人际都按谁动谁为干；先核具体专法。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF182—186（工作台363—371）；理法 LF636—638（工作台1271—1275）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

排除与边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF705—713（工作台1409—1425）；理法 LF1344—1349（工作台2687—2697）；理法 LF558—561（工作台1115—1121）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C10 财务：得财、财源性质、与财之人和迟速分别看

适用：原问是实际财物或款项得失，明确对象、财源与是否已达成交易。

北海以财爻为首要候选，分开察其得失、所乘天官所示财源、支上所示与财之人及出现位置与旺衰所示迟速。壬归财将察类仍可作有身份的对照，不混抄为同一规则。

排除与边界：求财不等于经营事业，收入、利润、资金周转、债款到账须分目标。；财不现的分支与通专优先有内部差异，见D01，不以单句永久否定其他条文。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1711—1728（工作台3421—3455）；壬归 LF285—301（工作台285—301）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C11 财务：讨债定位随主动追讨与等待变化

适用：实际已确认债权债务关系，分别问能否还、是否有钱或何时到账。

去讨者动，可为干，对方为支；已要求还款而静待答复者为支，对方为干。关系上有无还意或压力，与财爻旺衰所示有无可还之财须分别核。

排除与边界：朋友、亲属、同事只是债款关系的条件，不自动把主问题改成人际。；顺从或口头答应不能替代实际还款。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF636—638（工作台1271—1275）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C12 财务：店业、行商外销与交易的钱物分配

适用：区分开门面、外销行商及具体买卖。

开店干可为客商支为店业，宜店业得生合；外销干为行者支为他乡，重彼地对人的作用。金针交易例又以干为买家支为店家，财可分别取钱与物，须有该题交易背景。

排除与边界：这些是不同子问的关系轴，不可不说明就叠成同一永久分配。；交易个案的钱物读法不能推成所有干财必为钱、支财必为货。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1357—1358（工作台2713—2715）；金针 LF1178—1178（工作台1178—1178）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C13 财务：财的真实性、阴神、地盘和暗鬼须核实际作用

适用：已定位财物与求取者，再看财阴、所临和遁干。

财现不等于能取；财阴与所临的生克、空墓、破碎、闭口、玄夺等可改变可得性或带来后患。遁财与财遁鬼是不同明暗组合，不能只计为多一财。

排除与边界：“因财致祸”须核具体组合与本题财所指，不直接断违法。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：金针 LF1237—1240（工作台1237—1240）；理法 LF1723—1728（工作台3445—3455）；理法 LF1743—1746（工作台3485—3491）；壬归 LF293—301（工作台293—301）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D01 待辨：财通类专类及不入课传的北海内部差异

适用：比较同一财务子问、对象、位置、阶段与断言范围后，才讨论是否真正互斥。

壬归357以青龙通类为主；北海理法698、1357改财爻为通类并说俱现以专类为主，而1742却说财现以财为主不看专类。1719重课传年命，1723又有不入传仍可得财的条件说。当前不能合成一条无例外主次法。

排除与边界：北海优先于壬归能解决作者间选用，不能解决北海内部两说。；未有版本年代与完整适用条件，不自行设“早说晚说”或补出隐含分支。

待辨：本批以北海的财爻主线组织财物子问，但涉及通专俱现或类不入时并列适用路径，未决部分不生成自动决策。

出处：壬归 LF355—359（工作台355—359）；理法 LF697—698（工作台1393—1395）；理法 LF1355—1358（工作台2709—2715）；理法 LF1719—1724（工作台3437—3447）；理法 LF1740—1744（工作台3479—3487）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。
