# 疾病求医：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C16 疾病：患者、病证、虎鬼与六亲代占分别定位

适用：明确患者、病程、所问病势或治疗，另列求问者关系。

北海概法干为病人支为病证；疾病分类又可用六合小儿等人物类。粹言另载子占父、妻占夫按六亲察类。它们的参照与适用层次应分别保留，不能把所有亲属代问强制归一套。

排除与边界：疾病人物取法未完成全面对读，不把某一代占例扩成统一身份替换法。；原文的病象、生死断语不作为已核实的医学事实或临床诊疗依据。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF719—719（工作台1437—1437）；粹言 LF774—775（工作台1547—1549）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C17 疾病：虎鬼取病象，受虎克神另指病处

适用：所问是病源、病处或病势，须分患者与致病之象。

指南以虎鬼寻病症之源；毕法第67法以受虎克之神察病处，北海又保留三合局、重神等其他路径。不是白虎乘哪个五行就直接把该五行当唯一患处。

排除与边界：原法经络与脏器解释存作者身份；本条不形成诊断、用药或治疗方案。；虎鬼出现还须核旺衰、神煞、年命及制救，不能凭一将定生死。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF730—741（工作台1459—1481）；北海毕法 LF3334—3348（工作台3334—3348）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C18 疾病：医药、制鬼救神、天地医须核有无实际救力

适用：课中已有需要制约的病鬼或明确治疗目标。

子孙可以承担制鬼救神，天地医可以取医生；救神要核所临、空陷、被制与实际作用。天医作鬼则是不同组合，不能因天医名号就认定为吉。

排除与边界：无鬼时子孙还可能是耗泄；不能固定“见子孙就病愈”。；古书的药物、方位、针灸等类比不转成现代医疗操作指令。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：金针 LF1356—1356（工作台1356—1356）；理法 LF950—951（工作台1899—1901）；北海毕法 LF3392—3410（工作台3392—3410）；北海毕法 LF4655—4655（工作台4655—4655）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。
