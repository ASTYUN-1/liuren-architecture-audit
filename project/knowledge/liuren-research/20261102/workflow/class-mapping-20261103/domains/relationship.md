# 婚恋伴侣：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C01 婚恋：干支、三传、龙后及年命有不同职责

适用：采用书中传统男女婚配方法，已明确婚配、相处还是个人发展。

干为男支为女，干二课看男方及男家、支二课看女方及女家；北海以干支侧重态度与婚配，龙后侧重各人发展，不能把龙后相克直接顶替干支的成否判断。

排除与边界：此法原适用传统异性婚配；同性伴侣不能按提问先后或主动性硬配男女。；不把原书尊卑、贞淫等评价当成已证实现实人格。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1991—2006（工作台3981—4011）；壬归 LF475—491（工作台475—491）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C02 婚恋：三传初男中媒末女是专门角色读法

适用：所用婚姻专法以三传作双方与中介的对待关系。

初传男、中传媒、末传女，考察彼此生克、旺衰与所乘。不能默认每张婚恋盘的三传都等于过去现在未来；也不能因有中传就认定现实必有一个媒人。

排除与边界：媒的现实承担可未明，不能按表补造中介人数。；专门过程读法若另有来源须单列，不能与本法无说明混用。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF2027—2036（工作台4053—4071）；壬归 LF493—501（工作台493—501）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C03 婚恋：龙后、六合、年命与财官分别查所问

适用：婚配之外另问品貌、媒合、妆奁或偕老等。

龙男后女及各自阴神察其本身处境；六合可为媒，妆奁以财为类；北海以本命看品性、行年看容貌。指南又以夫问妻财、妻问夫官及虚实论配偶、偕老。必须先辨所答子问。

排除与边界：财官与干支不必是互斥取法；成婚与偕老不能混为一个结论。；原文的品貌与性别评价只存方法身份，不作为本案已知事实。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1994—2000（工作台3987—3999）；壬归 LF505—527（工作台505—527）；指南 LF699—706（工作台1397—1411）；理法 LF2250—2253（工作台4499—4505）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C04 婚恋：喜庆、孤寡、谩语等需结合占类和搭配

适用：已确认所问婚恋，所用煞起例、位置、乘将及空实可靠。

北海列天喜、太常、长生等为婚姻欲得之类；孤辰寡宿在婚问与一般人物问取义不同；谩语乘朱雀或天空才取言语不真。财乘暗鬼等是有明示条件的专门组合。

排除与边界：见孤寡不直接断必孤，见朱雀不直接断说谎。；未满足专法组合时，朱雀勾陈天空等仍须察其对本问的作用，不能删除，也不能据名扩写指控。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF567—571（工作台1133—1141）；理法 LF3127—3136（工作台6253—6271）；指南 LF704—708（工作台1407—1415）；北海毕法 LF4796—4798（工作台4796—4798）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。
