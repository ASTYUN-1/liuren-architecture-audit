# 失物盗逃：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C26 失物盗逃：先分物、人、盗与赃，不混同目标

适用：确认是自失、被盗、人员失联、逃亡还是追捕；未确认盗窃时保留未知。

失物按本物专类，如犬戌等；人走失可察玄武并与年命比较。北海明确：走失以玄武为人，受制可能被禁；盗贼以玄武为盗，受制可主易获；赃物失得另看财。

排除与边界：寻人不是捉贼；不能把走失者受克制当成一律利寻。；不由象辞直接认定某现实人物盗窃；多人区分仍须有据。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF717—717（工作台1433—1433）；理法 LF1349—1350（工作台2697—2699）；指南 LF843—854（工作台1685—1707）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C27 失物盗逃：捕者、贼身、赃物与三传角色须核方法

适用：确为盗贼、追捕或赃物问题，并采用相应专项。

指南以鬼、玄武察贼，子孙察追寻，勾陈与玄武关系察捕获；又有初贼中赃末捕者的专门三传分配。不能把该角色读法泛用于所有失物盘。

排除与边界：贼被捕与赃物追回分别判断。；类神三传与本课三传不是同一组；不把两种角色序列混写。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF846—858（工作台1691—1715）；粹言 LF811—829（工作台1621—1657）；北海毕法 LF4804—4814（工作台4804—4814）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。
