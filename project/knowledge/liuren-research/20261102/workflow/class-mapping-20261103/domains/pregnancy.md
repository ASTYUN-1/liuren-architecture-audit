# 胎产生育：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C19 胎产：是否怀孕先取干支胎，不以子孙统代

适用：具体问是否受孕或孕期维持，核干支各自胎神及所用长生法。

金针以干支之胎作有孕类象；北海毕法将胎爻、财爻、月内生气死气区分。胎财生气是复合条件，不能删成只见财或子孙便有孕。

排除与边界：土胎子午存在北海内部起法差异，须列法别，不能双取凑命中。；原例私孕、堕胎等描述不是据盘即可认定的现实事实。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：金针 LF1367—1379（工作台1367—1379）；北海毕法 LF1449—1467（工作台1449—1467）；北海毕法 LF1630—1634（工作台1630—1634）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C20 胎产：孕期宜静与分娩宜动，母子分别取类

适用：先明确在孕期保胎还是临产分娩阶段。

北海将动神、血神等在孕与产的宜忌分开；产时兼看干支、合后。指南以支母干儿，又察天后母、六合子及其受克，胎位与产期另查，不能单凭动象就说母子平安。

排除与边界：同一符号“孕中受损”与“分娩发动”不冲突，前提是阶段确实不同。；生产动象、母子安危和是否怀孕分别回答，不把古法当医学结果。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1344—1345（工作台2687—2689）；北海毕法 LF1449—1461（工作台1449—1461）；指南 LF719—727（工作台1437—1453）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D02 待辨：五行长生、土随水火与胎位的法别

适用：采用长生运、胎神或墓绝类方法前，核所据书、计算对象与起例。

理法447主五行长生水土申；指南庄按2567区分五行与十干并主张土干随火；北海毕法1463—1467保留土胎子或午。这是算例基准差异，不能只汇总象义后隐去。

排除与边界：同属北海的材料仍有不同口径，作者优先序不能抹平。；同一论证不能混用起法而不标，不能双法取有利结果。

待辨：通用讨论可先列北海理法五行法为默认研究口径；实际胎产条文中另起例须明示，待专项校勘后才能固化计算。

出处：理法 LF447—447（工作台893—893）；指南 LF2560—2567（工作台5119—5133）；北海毕法 LF1463—1467（工作台1463—1467）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。
