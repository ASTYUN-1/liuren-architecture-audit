# case-008 — 1994甲戌女HR总监换工作（事业占·元首斩关退茹不备课）

## 原始信息
- **占问时间**：2024年10月14日 10:47 星期一
- **四柱**：甲辰 甲戌 辛亥 癸巳
- **月将**：辰将（寒露后霜降前，中气换将）
- **旬空**：寅卯（甲辰旬）
- **年命**：甲戌 行年：辰 性别：女
- **背景**：HR总监，老板让做很多额外工作，问去留及换工作能否满意
- **课体**：元首，斩关，退茹，不备
- **三传**：初传庚戌(太常)→中传己酉(玄武)→末传戊申(太阴)
- **课式**：玄酉/阴申/常戌/玄酉 / 辛(申)玄酉 · 太阴申 · 常戌亥 · 玄酉戌

## 排盘详细

- 第一课：辛（申）上见 酉（玄武）
- 第二课：酉上见 申（太阴）

**课体：** 元首 · 斩关 · 退茹 · 不备

## 模范答案（来自复盘）
### 问题1：是去是留？
**去。**

理据：
1. **太岁冲命**：太岁辰冲本命戌——今年有动向，身不由己
2. **行年寅为年马**：2024年女命行年寅，寅为驿马——动象
3. **寄宫戌为天马**：九月天马在戌，应短暂时间内就会动
4. **先锋巳腾蛇飞天冲亥白虎溺水**：巳乘腾蛇（午）冲亥（支），官鬼来冲子孙——领导逼着换工作的象
5. **三传退茹**：退茹是从公司退出，不是退守不动
6. **元首课**：事从外来，被动接受，顺势而为
7. **干加支，阳不备**：主动离职

### 问题2：能换到满意的工作吗？
**能。**

理据：
1. **寄宫戌乘太常为征召**：太常主职务、编制，征召之象
2. **戌为天马登天门**：戌为天马，加亥天门——冲破关隘，换到更好的工作
3. **行年寅乘勾陈**：勾陈有两种读法——①勾连旧人/旧公司；②勾陈为官方。要么遇到旧关系牵线，要么去官方公司或做官方业务
4. **三传走完到支**：人随课走，从现职退出后去新环境
5. **行年入未**：她最终去了另一个公司，能接受就是满意
6. **太常禄具备**：有职务有待遇

### 问题3：其他补充
- **主动辞职**，戌月或亥月庚辛日为应期
- **与旧关系/官方公司有关**：行年勾陈主勾连旧人旧事或单位性质偏官方
- **玄武暗财**：中传玄武——可能有暗箱操作或私下介绍

## 经验提炼
- **太岁冲命主动**：太岁辰冲本命戌，必动
- **先锋门定占法**：占时巳乘腾蛇临午，飞天冲亥白虎——领导逼迫之象
- **退茹退出之象非退守**：退茹三传戌酉申，退出而非退缩
- **魁度天门=破关而出**：戌加亥虽为魁度天门，但戌为天马为太常，是冲破关隘
- **行年勾陈双读法**：勾连旧人+官方性质
- **戌天马登天门**：九月天马在戌，加亥天门，动而向上
- **人随课走**：不问主观满意与否，看课象是否走到新位置
