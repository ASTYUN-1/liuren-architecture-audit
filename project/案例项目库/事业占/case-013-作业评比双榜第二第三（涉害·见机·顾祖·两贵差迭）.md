# case-013 — 作业评比能否得冠军（事业占·比赛·涉害见机顾祖·双榜第二第三）

> 断曰：见机之卦，当察机辨色，因时制宜，不当犹豫逡巡也。**初传龙蛇空陷，凶既不成，喜亦不就。**
> 课经：甲戌日干亡子，支上申，谓之危中取财格……**喜旬中申空，亦可无畏**。

## 核心断语

**第一轮（成败）**：难夺冠军。官鬼申空、寅午戌火局克官、两贵受克——"不是第一"；但作品被看见、有非名次性实得（中传辰财六合）。

**第二轮（名数）**：初断**第七名**——错。正确应为 **2 / 3**（两榜）。

## 原始断法（当时的推理与结论）

### 成败层（命中）
1. 官鬼申旬空＋临申月月建，按"空就是空"（《理法简易》）取空，不以月建解空。
2. 三传午辰寅＋日支戌成**寅午戌火局**，子孙旺克官鬼——名次被克。
3. **两贵受克**（毕法49）——两个贵人都不给第一。
4. 顾祖（午辰寅）——回归本位，不进。
5. 结论：不得冠军，置信度约七成。

### 名数层（错断）
1. 取官鬼申 = 7（大衍数：甲己子午九、乙庚丑未八、丙辛寅申七）。
2. 末传寅 = 7（同为大衍数）。
3. 甲申日填实 = 7。
4. 三处同数 → 断第七名。

## 实际结果

- **未得第一**（成败层命中）。
- 实际存在**两个榜单**：一个榜排**第二**，一个榜排**第三**。
- AI 所断"第七名"与实际不符。
- 应期断"9月7日甲申日前后"——用户未反馈公布日，**未验**。

## 反馈

**部分应验**：成败方向（不是第一）正确；名次数（7）错误。

## 反推分析

### 偏差定位
- **类型**：程度/数值偏差（非吉凶反转）。方向对（非第一），数值错（7 vs 2/3）。

### 被忽略的线索

**1. 取数体系选错（根本原因）**
《六壬粹言》原文：

> "数目者，**子午甲己九**之类，此**大衍数**也。**水一火二者，河图数也。少者以河图数取之，多者以先天数取之**，仍以旺相休囚为之增减。"

- 名次属**少数目**（个位数等级）→ 应用**河图数**：水一、火二、木三、金四、土五（《六壬神定经》："火，生数二，成数七。木，生数三，成数八。"）
- 我却用了**大衍数**（子午九、寅申七）——那是断钱粮、人数、里程等"多数目"的体系。
- 旁证：陈公献断数目亦用河图数（《理法简易》："官鬼为木克玄武，木的河图数为三，故主三日获"）；《毕法案录》"巳为四数，名数应在第四"亦合河图／后天之数。

**2. 生数/成数取用规则未用**
《六壬拃河棹》："**阳生阴成**"。甲戌日为**阳日** → 取**生数**。
- 初传午（火）生数 = **2**
- 末传寅（木）生数 = **3**

→ **2 与 3**，与"一个榜第二、一个榜第三"严丝合缝。

**3. "两贵差迭"被当作泛泛背景，未落实为"双榜"**
- 毕法46「**贵人差迭事参差**」：两个贵人（昼贵丑／夜贵未）位置参错 → **两套评审口径、两个榜单，结果不齐**。
- 毕法49「**两贵受克难干贵**」→ 两个榜都压不到第一。
- 当时只写作"大背景凶、凶大吉小"，没有把它翻译成"两榜"这个具体人事。

**4. 「间传」只读成"间阻"，未读成"差一位"**
午辰寅为间传（隔一位递传）。两榜 2 与 3 恰好差一位——当时只标"事多间阻"。

**5. 空亡与受克的语义被外推**
官鬼申空 + 火局克官，只能否定"**第一**"这一项，**不能指定"名次低"**。当时把"空"顺推成"名次压在中段"，再叠加错误的 7，得出"第七"。这是本次最关键的推理硬伤。

### 正确断法（事后重建，标注可信度）

| 层 | 正确路径 | 依据 | 可信度 |
|---|---|---|---|
| 成败 | 官鬼空＋火局克官＋两贵受克 → **非第一** | 裁决阶梯等级2；case-019 同课技法 | 高（已验证） |
| 结构 | 两贵差迭＝**两榜**；两贵受克＝**都不给第一** | 毕法46/49 原文 | 中高（本课命中） |
| 名数 | 少数目用**河图数**、阳日取**生数** → 午2、寅3 | 《粹言》《神定经》《拃河棹》 | 中（单案） |
| 应期 | 末传冲神申＋出空填实 → 甲申日 | yingqi-panduan 末传冲神法 | 未验 |

## 经验提炼

1. **当占名次/等级等小数目，且课中已定"非第一"时**，取数用**河图数**（水一火二木三金四土五），阳日取生数、阴日取成数；**不要用大衍数**（子午九、寅申七）。
2. **当毕法见"贵人差迭"且占评比/评审类时**，应直接断"**存在两套口径／两个榜单，且结果不一致**"，而非泛称背景不利。
3. **当官鬼（名次类神）空亡或受克时**，只可断"**拿不到该项（第一）**"，**不可外推为名次靠后**；具体位次须另取数。
4. **当课体为间传、且占评比时**，两处结果常"**差一位**"，可作 2/3、3/4 这类相邻名次的候选结构。
