# case-009 — 乙亥男面试工作（事业占·元首元胎不备寡宿课）

## 课经判词

> "生被虎攻，往就徒空，舍益就损，终身困穷。"
> "仕宦：财贵虽空，递生不畏，至吉之象。"
> "元胎之卦，干乘支马，支乘干禄，所谓富贵课也。但支乘六合，干乘六害，有己劳人逸之象。"

## 断语解析

### 1. 课体分析
- **元首课**：一上克下发用，事从外起——面试结果由公司方决定
- **元胎课**：三传巳寅亥为元胎，主新事发生、快速进展——面试是新事情，过程快
- **不备课**：一课与四课同，阳不备——气场不均，公司方面有一定优势
- **寡宿课**：寡宿主孤——求职者一人面试，无需多人协作

### 2. 成败判断
课经直指 **"仕宦至吉之象"**，问事业面试大利。

- **初空末实**：初传巳空亡，初试时虚而不实；中传寅(螣蛇)过渡，末传亥为日禄、本命，由虚入实，最终得禄——offer到手
- **本命见禄**：本命乙亥，亥出现在末传为日禄，命中有此禄，命中注定得此职位
- **递生不畏**：虽然初传财贵空亡，但三传递生（寅生巳→？），课经明言"递生不畏"

### 3. 速度判断
- **元胎主速**：元胎课主新事发生迅速，权重高于退间传的迟滞
- **巳亥相冲（初末相冲格）**：初传巳与末传亥相冲，主事体速成、一气呵成
- **速象优先**：退间传本主事缓，但元胎速象和初末相冲格共同覆盖退间传的迟滞

### 4. 注意事项
- **禄乘勾陈**：末传亥禄乘勾陈，主竞争拖延——入职后需注意人际关系，竞争对手可能不服
- **干乘六害**：有己劳人逸之象——工作辛苦，成果可能被他人分走

## 反馈

初试完成后不久即约 **次日（癸卯日，贵人日）未时** 复试，**申时（干上神申金驿马时）** 电话通知通过并发offer。整体过程快速、顺利。

## 技法提炼
- **课经"仕宦至吉之象"直接验**：课经判词明确支持事业类占卜，一击即中
- **元胎课主快速新事**：元胎课权重高于退间传迟滞，速象优先
- **巳亥相冲（初末相冲格）主速成**：初末相冲，事体从头到尾一气呵成
- **初空末实得禄**：初空代表虚的阶段（投递、初试），末实代表实的阶段（offer、入职）
- **本命亥见禄在末传**：本命即日禄，命中注定得此职位
- **应期取法**：次日癸卯日（贵人日，贵登天门）完成复试；申时（干上神申金驿马时，速象之应）接到通知
- **禄乘勾陈提示入职后注意人际关系**：勾陈主竞争、留滞，入职后可能需要处理内部关系
