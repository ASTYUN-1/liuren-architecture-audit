# case-004 — 医院外包人员能否拿到正式编制（事业占·元首斩关间传课）

## 原始信息
- **占问时间**：2023年11月20日 10:44 星期一
- **四柱**：癸卯 癸亥 壬午 乙巳
- **月将**：卯将
- **旬空**：申酉（甲戌旬）
- **年命**：己巳 行年：戊戌 性别：女
- **课体**：元首，斩关，间传
- **三传**：初传寅(太阴)→中传子(青龙)→末传戌(白虎)
- **课式**：未阴 寅辰未酉 / 申玄 辰午酉壬
- **反馈**：此事不成。

## AI解析

### 1. 课体分析
- **元首课**：一上克下发用，事从外起——编制之事由外部关系决定
- **斩关课**：魁罡加日辰，主冲破障碍——但斩关需寅卯龙合加辰戌方能破关
- **间传课**：三传寅→子→戌，退间传，由阳退入阴——不利求谋

### 2. 水的断语解析
- **变体门（巳）**：巳为贵人，正时门巳与日干冲动为财——求贵人办事
- **太常空亡**：编制见于太常，太常在头上见空——编制不得
- **中传子青龙**：子为羊刃乘青龙，主财物争斗——花钱送礼但不成
- **末传戌白虎**：戌为冠带（编制之象），但被初传寅所制——编制被阻

### 3. 退间传——由阳退入阴
三传寅（阳）→子（阳）→戌（阳），虽皆为阳支，但退间传由旺退衰：
- 初传寅为旺气
- 中传子为败气
- 末传戌为墓气
- 最终退入空亡之地（戌在甲戌旬中申酉空，戌为旬空）

### 4. 胜晏理断语
"三传寅子戌为冥阴，由阳退入阴，不利求谋，正时财作贵人，需与贵人行贿，支来墓干，难得编制，中传龙入庙本应大吉，但作兄弟为竞争对手，戌乘白虎为编制，落入子地，断不行。"

## 经验提炼
- **退间传不利求谋**：由阳退入阴，气势衰退
- **太常空亡**：编制之象空亡，不得
- **斩关需破关条件**：寅卯龙合加辰戌方能破关
- **冠带被制**：戌为冠带（编制），被初传所制则不得
- **龙入庙作兄弟**：青龙入庙本吉，但作兄弟则为竞争对手
