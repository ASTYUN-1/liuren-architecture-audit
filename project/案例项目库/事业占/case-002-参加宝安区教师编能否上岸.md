# case-002 — 参加宝安区教师编能否上岸（事业占·遥克蒿矢课·多人断）

## 原始信息
- **占问时间**：2023年10月30日 23:32 星期一
- **四柱**：癸卯 壬戌 壬戌 庚子
- **月将**：卯将
- **旬空**：子丑（甲寅旬）
- **年命**：辛巳 行年：庚戌 性别：女
- **课体**：遥克，蒿矢，稼墙，励德，芜淫
- **三传**：初传辰(腾蛇)→中传未(勾陈)→末传戌(白虎)
- **课式**：辰丑巳寅 / 丑戌寅壬
- **反馈**：第一轮就被刷下来了。

## 水的断语

变体门见巳命上乘朱雀作文书一事遁丁飞扬。正时门为子作羊刃斗争，值事门玄武为贼...课得遥克，主气力弱小，若见考试作官则难以成就，三传见官众鬼...又见亥作日禄下坐申马大动，亥乘太常见于为官事。此编制如何？是教书匠，戌作冠带上见申长生为学校，又子爻在寅其长生在亥，天生为教师。此数若不见巳命，断不可轻言为教师。因为巳命上见申，为帘幕贵人者双马齐齐动用才敢为教师，险过象。

## AI解析

本案为**遥克课+蒿矢课+稼穑课**组合，展示了课体定大象的典型断法——遥克主气力弱小，决定了事情难成的基调，类神再丰富也无法逆转。

**课体层面**：
- **遥克课**：主气力弱小、被动受制。遥克之"遥"意味着力量不足、鞭长莫及，用于考试竞争，先天已落下风。
- **蒿矢课**：蒿矢为草箭，虽能伤人但力量有限，进一步强化"有心无力"之象。
- **稼穑课**：三传辰未戌全土，土重埋金、土多塞水。稼穑主迟滞、耕耘，但三传全为官鬼（壬日，辰未戌皆为七杀），官鬼重重克身，压力极大。
- **励德课**：主君子小人分野，此处暗示竞争中有德者居之，但自身德行或准备不足。
- **芜淫课**：主事情不清、暧昧不明，对应考试结果模糊、难以突围。

**关键类神分析**：
- **变体门（巳命）**：巳命上乘朱雀，朱雀主文书、考试，遁丁（丁火）飞扬，说明命主确实在考试一事上有行动、有努力。
- **正时门（子）**：子为羊刃，主斗争、竞争激烈。子又旬空（甲寅旬子丑空），空则无力。
- **值事门（玄武）**：玄武为贼、为暗昧，对应考试中可能存在的暗箱操作或自身准备不足。
- **亥作日禄下坐申马**：亥为壬日之禄，下坐申为驿马，禄马大动，说明命主确实在积极谋求这个职位。亥乘太常，太常为官事、为印绶，指向编制。
- **戌作冠带**：戌为冠带之位，上见申（长生）为学校，构成"冠带+长生=学校"的类象，对应教师编制考试。

**"险过象"的深层含义**：
水的断语说"险过象"，意思是"险险通过之象"。但实际结果是第一轮就被刷了。这里需要理解：
1. 遥克课+稼穑课的课体组合，力量太弱，官鬼太重，基调已经定了"难成"。
2. "险过象"是基于巳命上见申（帘幕贵人+驿马）的局部判断，但课体的大象压过了局部细节。
3. 三传辰未戌全土，官鬼重重，初传辰（腾蛇）→中传未（勾陈）→末传戌（白虎），一路由蛇化虎，压力递增，最终白虎临戌（戌为壬日之冠带，也是七杀），官非压力达到顶峰。

**为什么第一轮就被刷**：
- 遥克主气力弱小，连第一轮都难以突破。
- 三传官鬼重重，竞争压力极大，且官鬼克身，自身实力被压制。
- 正时子为羊刃旬空，羊刃空则斗志不足、竞争力缺失。
- 值事门玄武，暗昧不明，考试过程或结果不透明。

## 经验提炼

1. **课体定大象**：遥克课决定了"气力弱小"的基调，这是本案最核心的判断依据。课体的大象优先级高于局部类神的吉象。
2. **遥克+稼穑的叠加效应**：遥克主无力，稼穑主迟滞+官鬼重重，两者叠加，考试突围几乎不可能。
3. **"险过象"的局限性**：局部类神（巳命见申帘幕贵人+驿马）可以给出"险过"的判断，但课体大象（遥克+稼穑）决定了这个"险过"也难以实现。类神在框架内做细节调整，不能逆转课体基调。
4. **三传化象**：腾蛇→勾陈→白虎，由虚入实、由轻到重，压力逐层升级。
5. **禄马大动≠成功**：亥为日禄下坐申马，禄马大动只说明命主在积极行动、确实在谋求此事，但不代表能成功。禄马是"动象"而非"成象"。
6. **教师类神的构建**：戌（冠带）+申（长生）=学校，巳命上见申（帘幕贵人+驿马）=教师身份的确认。类神的组合需要多个条件同时满足才能确定。
