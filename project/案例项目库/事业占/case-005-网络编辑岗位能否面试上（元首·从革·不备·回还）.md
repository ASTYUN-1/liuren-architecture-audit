# case-005 — 网络编辑岗位能否面试上（事业占·元首从革不备回还课）

- **三传**：初传巳(贵人)→中传丑(勾陈)→末传酉(太常)
- **课式**：勾贵贵常 / 丑巳巳酉 / 巳酉酉癸
- **反馈**：面试过了。后续是因为和同事领导关系不和而离开公司。

## AI解析

### 1. 课体分析
- **元首课**：一上克下发用，事从外起——面试由公司方决定
- **从革课**：三传巳酉丑金局，主改易、变动——工作变动之象
- **不备课**：干备支不备——公司缺人，求贤若渴
- **回还格**：三传归干——最终回到自身，面试能过但最终离开

### 2. 水的断语解析
- **正时门（未）**：未与丑相冲主外动，未刑丑主侵害——面试后有变动
- **发端门（巳）**：巳为贵人财爻，与日干相合——求财有力，面试能过
- **巳财月破**：巳为月破（亥月巳破）——难长久
- **中传丑勾陈**：丑为官鬼乘勾陈，主斗争——与同事领导关系不和
- **从革改易**：三传金局主改易——最终离开

### 3. 子白断语
"此课干备支不备，公司缺人不完善之象，支加干来生干，上又乘太常，干支又是一气，乃是相谈甚欢，主动提供工作给我之意，本命丑上见酉，也是合该有此份工作，支上巳贵发用，传归干上，兼之又是三传递生，有他人举荐，求我办事之象，末传闭口，最终自己拒绝了，没去。"

### 4. 从革课的"改易"之象
从革课主改易、变动：
- 面试能过（回还格主成事）
- 但最终离开（从革主变动）
- 巳财月破（难长久）
- 丑勾陈斗争（人际关系不和）
