# case-006 — 母亲暴雨失踪联系上（灾厄占·铸印课·空亡解凶）

## 原始信息
- **占问时间**：2023年9月6日 0:30 星期三
- **四柱**：癸卯 庚申 丁卯 庚子 巳将 戌亥空
- **课体**：重审，铸印，乘轩
- **年命**：丙午 行年：乙亥 性别：女
- **三传**：初传巳(太常)→中传戌(腾蛇)→末传卯(天空)
- **课式**：丑申巳子 / 申卯子丁
- **反馈**：反馈是刚起局一个小时就联系上了，就是子时。

## 水的断语

> 铸印课，若占走失不利，主凶已成。可是此课铸印见空，又见三传由外事门转内事门则无凶事。

## AI解析

此课与案例4（脚踝骨痛）课式完全相同（同为丁卯日、同三传巳戌卯），但占事不同，结果亦不同。关键在于"铸印见空"和"三传由外转内"。

**课象分析：**

1. **铸印课占走失不利**：铸印课主"成印"，若占走失，则主走失之势已成，难以找回。但此课戌亥空亡，戌为印模，空则印不成，故凶势不成。

2. **铸印见空，凶不成**：铸印课以戌为印模、巳为炉火、卯为印。戌空则印模虚，印不能成。凶事逢空则凶势消散，故虽铸印课占走失不利，但空则凶不成。

3. **三传由外事门转内事门**：三传巳→戌→卯。巳为外事门（巳为阳、为外），卯为内事门（卯为阴、为内）。三传由外转内，主事由外向内发展——即走失之人由外回归。此乃"由外转内则无凶事"之关键。

4. **子时联系上的应期**：反馈"刚起局一个小时就联系上了，就是子时"。子时为当日庚子时，正是课中庚子时柱。子水为丁火之官鬼，但子水空亡（戌亥空，子不空），且子时为夜半，主事之应期。

**结论**：铸印课占走失本不利，但戌空印不成，凶势自解；三传由外转内，主走失之人回归。故断无凶事。反馈：起局后一小时（子时）即联系上。

## 经验提炼

- **铸印课占走失核心法则**：铸印主成，占走失则主走失之势已成。但若印模（戌）空亡，则印不成，凶势自解。
- **空亡解凶法则**：凶事逢空则凶势消散，吉事逢空则吉事不成。此课戌空，铸印之凶自解。
- **三传内外门判断**：巳为外事门（阳），卯为内事门（阴）。三传由外转内，主事由外向内发展，走失则主回归。
- **同课式不同占事不同结果**：此课与案例4课式完全相同，但案例4占骨病断无碍，此课占走失断联系上。可见课象需结合占事具体分析。
