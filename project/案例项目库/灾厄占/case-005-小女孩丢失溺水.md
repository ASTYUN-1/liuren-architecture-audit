# case-005 — 小女孩丢失溺水（灾厄占·斫轮课·溺水之象）

- **反馈**：小女孩因患有智力障碍，死于河中溺水而亡，于当月27日丙辰寻回。

## 水的断语

> 铸印主气质成熟，若事为凶事，成则大凶，象无吉凶，因事而异。又见行年在午乘天后坐于亥地，又见于死气，当是溺水而亡。

## AI解析

此课为斫轮课占走失寻人，课体主凶事成则大凶，行年见天后坐亥地又逢死气，断溺水而亡。

**关键凶象分析：**

1. **斫轮课体，凶事成则大凶**：课得斫轮（卯加申），斫轮主"成器"之象。若占吉事（如功名、官职），则主成器、成就；若占凶事（如走失、疾病），则主凶事已成、不可挽回。此课占小女孩走失，凶事逢斫轮，则凶象已成。

2. **行年午乘天后坐亥地**：行年在午，午乘天后（天后主水、主妇人、主溺）。午下临亥地，亥为水（登明、江河之水）。天后乘午坐亥，正是"天后入水"之象——主溺水。

3. **死气在年命**：行年午上见死气（正月死气在午）。死气临行年，主年命逢死气，大凶。走失最忌行年见死气，主凶多吉少。

4. **课体与案例10对比**：此课与案例10（己丑年小女孩丢失）几乎完全相同——同为癸巳日、同课体、同三传。区别仅在于年命不同（此课年命丑，案例10年命己丑）。两课结果相同，皆溺水而亡，可见课象之确定性。

**结论**：斫轮课凶事成则大凶，行年天后入水主溺水，死气临年命主生机断绝。全课无救，故断溺水而亡。反馈：当月27日丙辰寻回尸体于河中。

## 经验提炼

- **斫轮课吉凶因事而异**：斫轮主成器，吉事占之则成，凶事占之则凶事已成不可挽回。占走失逢斫轮，主走失之势已成。
- **天后入水主溺水**：天后乘午坐亥地，天后为水神，亥为江河，天后入水即溺水之象。
- **行年死气大凶**：行年上见死气，主年命逢凶，是占走失最凶之组合之一。
- **课象重复验证**：此课与案例10课式完全相同，结果相同，说明课象具有确定性和可重复性。
