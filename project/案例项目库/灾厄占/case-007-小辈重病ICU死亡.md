# case-007 — 小辈重病ICU死亡（灾厄占·斩关课·绝地截杀）

- **四柱**：壬寅 庚戌 丙辰 戊戌 卯将 子丑空

- **课式**：寅青 / 寅酉卯戌 / 酉辰戌丙
- **反馈**：长期喝酒，喝死的。起课后的第二天上午医院放弃治疗了，让拉回家，巳时在家去世。

## 水的断语

> 发端门长生被官鬼所制，又作死气。末传官鬼见子空，空陷日干作为疾病。子疾病绝地在巳，则巳日为一道关，绝地是作截杀，过之则能见活，不过则死。

## AI解析

此课为斩关课占重病生死，发端门长生被制，末传官鬼空陷，绝地截杀，应期在巳日巳时。

**关键凶象分析：**

1. **发端门长生被官鬼所制**：初传寅木，为丙火之长生（丙火长生在寅）。但寅木乘青龙，寅上见酉（中传酉为官鬼），长生被官鬼所制。长生为生机，生机被制则命不久。

2. **长生又作死气**：寅为丙火长生，但寅在戌月（霜降后）为死气（死气：正月起午，顺行十二辰。戌月死气在寅）。长生逢死气，生机之中藏死象，主看似有生机实则已死。

3. **末传官鬼见子空**：末传子水为官鬼（水克丙火），子水空亡（甲寅旬子丑空）。官鬼空陷，则疾病虽重而不致死——但此课之空非吉。水的断语"空陷日干作为疾病"，指官鬼空陷反主疾病深重难治。

4. **绝地截杀，巳日为关**：子水为丙火之官鬼，丙火绝地在巳（丙火长生在寅，帝旺在午，死在酉，墓在戌，绝在亥——此处需注意：丙火绝在亥，但水的断语说"子疾病绝地在巳"，是以子水为疾病，子水绝地在巳）。巳为绝地，又作截杀（截杀：寅午戌在亥，亥卯未在申，申子辰在巳，巳酉丑在寅。子年截杀在巳）。绝地逢截杀，主过此关则死。

5. **应期验证**：断"巳日为一道关"，反馈"巳时在家去世"。巳日巳时，正是绝地截杀之应期。

**结论**：长生被官鬼所制且逢死气，生机已绝；末传官鬼空陷主疾病深重；绝地截杀在巳，巳日巳时为应期。全课无救，故断必死。反馈：次日巳时去世。

## 经验提炼

- **长生被制则生机绝**：发端门长生为生机之始，若被官鬼所制或逢死气，则生机断绝。
- **绝地截杀定应期**：以疾病类神之绝地为关口，截杀加重其凶，过此关则死。此课子水绝地在巳，巳日巳时应。
- **官鬼空陷非吉**：官鬼空亡，看似凶不成凶，但若空陷反主疾病深重、药石无效。需结合具体课象判断。
- **斩关课占病**：斩关主动、主破，占病则主病情急转直下、迅速恶化。
