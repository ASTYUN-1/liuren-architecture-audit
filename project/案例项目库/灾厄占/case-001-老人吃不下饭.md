# case-001 — 老人吃不下饭（灾厄占·铸印课·死象）

## 原始信息
- **占问时间**：2023年12月10日 18:09 星期日
- **四柱**：癸卯 甲子 壬寅 己酉 寅将 辰巳空
- **课体**：知一，斩关
- **年命**：庚子 行年：己巳 性别：男
- **三传**：初传子(六合)→中传未(天空)→末传辰(青龙)
- **课式**：子未酉辰 / 未寅辰壬
- **反馈**：老人走了。

## 水的断语

> 不好，老人可能要走，首先课得铸印，占病不吉，巳虽然得空，但是行年填之。论行年，巳临子作死，巳作绝地。论日干，上见辰水墓，又逢死气，又不见破关神。第四课发用，得子六合，下坐太常作官鬼，是饮食不下，卯日论死地。

## AI解析

此课为铸印课占病，大凶之象。铸印课本为成印之象，占官占事主成，占病则主"印封"——即人被封入棺椁之象，故占病最忌。

**关键凶象分析：**

1. **铸印课体，占病不吉**：课得铸印，巳为炉火，戌为印模，卯为印。占病逢铸印，如入模铸形，主形体被封印，生机断绝。

2. **行年填空，反助其凶**：巳火虽空亡，但行年恰在巳，填空填实。行年巳临子水作死地，巳火本身又处绝地（巳火绝于亥，亥为子之根气），行年填实则凶象落实，再无转圜。

3. **日干壬水上见辰墓**：壬日干上辰为水库，乃日干之墓库。占病逢墓，主神识昏沉、生机入墓。又逢死气（子月死气在辰），墓上加死，凶上加凶。

4. **不见破关神**：铸印课需破关方能解厄——破关神为"未"（破印模）。此课中传虽见未（天空），但未为天空虚诈之神，且未土克子水，反助其克，不能真正破关。

5. **第四课发用，饮食不下**：第四课发用得子水六合，子下坐太常（太常主饮食），六合为关闭之象，故断"饮食不下"。卯日论死地，卯为壬水之死地，应期在卯。

**结论**：此课无救神。行年填空不但不能救，反而将空亡之凶填实；日干入墓逢死气；破关神无力；发用直指饮食断绝。全课无一丝生机，故断老人必走。

## 经验提炼

- **铸印课占病核心法则**：铸印如入棺，占病大忌。需看是否有"破关"之机（破印模）或"救神"（生气、天医、日干空亡等）。
- **行年填空的双刃剑**：空亡本为凶中藏变，若行年填空，则凶象落实。此课行年填巳，反将铸印之凶坐实。
- **墓+死气=绝象**：日干上见墓神，又逢死气，主生机断绝，是占病最凶组合之一。
- **救神的有无决定生死**：此课无救神（无生气、无天医、日干不空、破关无力），故断死。与案例2形成鲜明对比。
