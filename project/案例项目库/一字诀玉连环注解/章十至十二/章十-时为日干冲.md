# 章十：时为日干冲（主外动）

## 徐次宾原文

以日为外，用时与日冲，主外动，此其大略也。

1. 若壬日、戊日、庚日，得时为日冲，并驿马，附财，主外动干求。
2. 若甲日得之，即为甲之鬼，主外动破财吉。
3. 若丙日得之，则亥为丙之贵马，仕人主迁官历任。
4. 其余阴干仿此推之。

## 假令案例

### 假令：戊辰日寅将亥时（十月）

**四值：** 亥月辰日亥时

**课式：**
- 日干：戊（土）
- 月将：寅
- 正时：亥
- 三传：亥（勾陈）→ 寅（白虎）→ 巳（太阴）
- 课体：重审、玄胎

**断语：** 西北上出入干财，有李姓人无发者暗为鬼贼，其事自解，其财不得，主空回。

**徐次宾析：**
- 何知西北上出去干财？先锋与发用皆亥，亥主西北，又为日财日马也。
- 何知李姓无发者为鬼贼？盖中传功曹为木，下临壬水，配合为李字也，白虎主无发鬓人。为日下之鬼，故知此人为害也。
- 言自解者，经云：鬼自受制忧将自救。寅为日之鬼，上得白虎金制之，故曰自解也。
- 其财不得而主空回也者，盖发用登明为空亡，虽为日下之财，而正时自为空亡，岂不是空回也。

**水论：**
- 正时亥作日冲主外事门动，又作日财见旬空则论财物丧失引起外动。
- 中传寅为官鬼，其神见巳得太阴主阴私不正，鬼受制则不为其害，此人心虚不敢再取财。
- 三传由外事门传外事门，加之正时为空，课得遥克无力，终究空回。
- 申者《心镜》"传送刀兵僧及医，冤仇道路税湖池"主僧也，白虎本家在申，据寅头上则见光头。

## 水的注解

Water对该章的注解核心在于：

1. **冲动的双重性**：时为日干冲，主外动，但冲的结果取决于所冲之神的性质。亥为戊之财马，冲则动财；若甲日亥为鬼，冲则破财。同一"冲"字，吉凶全在六亲关系。

2. **空亡定虚实**：发用亥为空亡，正时亥亦为空亡，双重空亡决定了"空回"的结局。空亡在此不是"无财"，而是"看得见摸不着"——财在眼前却拿不到。

3. **鬼受制则自解**：寅为日鬼，上乘白虎金克寅木，鬼被制则不能为害。这是"鬼自受制忧将自救"的经典运用——鬼若被制，反而成为救神。

4. **拆字取姓法**：功曹（寅）为木，下临亥为壬水，木得水为"李"字（木+子）。这是六壬中典型的拆字取象技法，与章一中六合草头得"董"姓一脉相承。

5. **白虎主无发**：白虎为西方金神，金主白色，又白虎为凶神，取其"肃杀""凋零"之象，故主无发鬓之人。白虎本家在申，申临寅头，寅为毛发，金克木故无发。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全·课经》论"冲"多从返吟课、日辰冲等角度入手，而《一字诀》章十的核心创新在于**以正时冲日干为第一切入点**——"时为日干冲"即先锋门定外动基调。

《大全》论返吟课云："十二神各居冲位，主事反复不宁。"但徐次宾在此课中并未因亥冲巳（返吟）而断反复，而是以正时亥冲日干戊论外动干财。这说明**冲的运用有层次之分**：正时冲日干主外动，课体返吟主反复，二者不可混为一谈。

《大全》论空亡："空亡主事虚而不实，求谋不成。"徐次宾在此课中完全继承此说——发用亥为空亡，正时亥亦为空亡，故"其财不得，主空回"。

### 2. 与《心镜》对照

Water引用《心镜》"传送刀兵僧及医，冤仇道路税湖池"来印证申主僧的类象。在徐次宾的断语中虽未直接提及申，但白虎本家在申，白虎临寅头，申为僧则白虎所主之"无发人"亦与僧相关。

《心镜》论白虎："白虎金神主刀兵，丧服疾病及惊恐。"徐次宾以白虎主无发鬓人，是对白虎类象的延伸——白虎为金，金主白色、主肃杀，头发为木（寅为毛发），金克木故无发。

《心镜》论登明："登明聚众主牢狱，猪豕骡驴及细碎。"徐次宾以亥为日财日马，取亥的"财"与"动"之象，而非《心镜》的"牢狱"之象。这说明同一神煞在不同语境下取象不同，关键在于六亲关系。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论冲："冲者动也，凡事主变动不宁。"徐次宾在章十中进一步区分了"外动"与"内动"——时为日干冲主外动，时为日支冲主内动。这是对"冲"理论的精细化发展。

《直指》论空亡多主"虚而不实"，但徐次宾在此课中论"空回"——空亡不是"没有财"，而是"财在眼前却拿不到"。这种"看得见摸不着"的断法，比简单的"无财"更符合实战。

### 4. 与《邵彦和断案》对照

邵彦和断案中大量运用"鬼受制则不为害"的技法。如邵案中有一课：鬼临日上，但鬼下被地盘克，邵断"鬼虽克我，然鬼自受制，不足为忧"。徐次宾在此课中继承此说——寅鬼上得白虎金制之，故"其事自解"。

邵案中拆字取姓的技法在徐次宾这里得到继承和发展。邵案中常以神将的五行属性配合字形拆解，徐次宾在此课中以"功曹为木，下临壬水，配合为李字"，正是邵氏技法的直接运用。

### 5. 核心技法解锁

章十最核心的断课心法是**"冲动分内外，空亡定虚实"**：

1. **先锋门定内外**：正时冲日干为外动，冲日支为内动，这是《一字诀》对"冲"的独特分类
2. **六亲定吉凶**：冲财则动财，冲鬼则破财，冲贵则迁官，吉凶全在六亲
3. **空亡定虚实**：正时与发用俱空，则事虽动而终虚
4. **鬼制则自解**：鬼上得制神，则鬼不能为害，反成救神
5. **拆字取姓法**：以神将的五行属性配合字形拆解，得姓字

## 技法提炼

- **技法1：先锋门冲动法**——正时与日干相冲，主外动。冲财则动财，冲鬼则破财，冲贵则迁官。这是《一字诀》对"冲"的独特分类体系。

- **技法2：空亡定虚实法**——正时与发用俱空亡，则事虽动而终虚。空亡在此不是"无"，而是"看得见摸不着"。

- **技法3：鬼受制则自解法**——鬼上得制神（如鬼为木，上乘金神），则鬼不能为害，反成救神。这是判断凶事能否化解的核心心法。

- **技法4：拆字取姓法**——以神将的五行属性配合字形拆解。如功曹（寅）为木，下临亥为壬水，木得水为"李"字（木+子）。

- **技法5：白虎主无发法**——白虎为金，金克木（寅为毛发），故白虎临寅主无发鬓之人。白虎本家在申，申为僧，故亦主光头。
