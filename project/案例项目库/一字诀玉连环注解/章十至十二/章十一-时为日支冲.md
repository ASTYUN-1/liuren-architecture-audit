# 章十一：时为日支冲（主内动）

## 徐次宾原文

一气所冲如物当风，岂有安息。

1. 日为占人，辰为所居之宅又为卑下，时为辰冲，故主内动。若辰上神更值白虎凶神，主宅不可居、卑幼灾难。
2. 若不内动即主与我相争、他人疾病，盖辰亦为他人也。
3. 若从革返吟，定主移宅；八专日辰同居一处。
4. 若正时冲之名内外俱乱，主男女俱淫乱、逃难奔窜。
5. 其灾祸更于课式中互换取要而言之。

## 假令案例

### 假令：癸卯日丑将酉时（十一月）

**四值：** 子月卯日酉时

**课式：**
- 日干：癸（水）
- 月将：丑
- 正时：酉
- 三传：酉（天空）→ 丑（太阴）→ 巳（朱雀）
- 课体：从革

**断语：** 西南近寺与姓周老阴人争竞，后移东北近庙居住。

**徐次宾析：**
- 盖先锋门与日支冲而又发用，主宅不安。
- 中传大吉为日下之鬼，下临酉为寺，合酉为佛为金仙，又酉为西方，大吉得太阴，主老阴人争竞，因此家宅不安。
- 太阴主口舌事，大吉为土，地盘酉为兑，主口舌，以大吉下见吉配合为周字，故曰西南近寺，与姓周老阴人争也。
- 辰为宅，时既冲克之，不安之象。
- 何以移往东北近庙居住？盖卦得从革，革故鼎新，从革本主西南，而运东北者何也？盖大吉临酉为日鬼，畏其鬼不敢往。
- 末传太乙，得朱雀为日下之财，下临丑，丑主庙，故言往东北近庙居住，丑为天乙本家，故言庙也。

**水论：**
- 正时酉与外事门合冲动内事门，主内动而外合。
- 值事门天空主虚无。
- 发端门为丁马大动，课体从革主改易，知有迁动。
- 中传丑作日鬼，不以日干论，主与人相争。丑在酉上，被酉与太阴锁定是寺庙得象——《心镜》"大吉将军主荐贤，桥梁长者地祇冤"。
- 丑鬼临空门，丑作神佛，酉作西方，也是寺庙。
- 卯为宅门，得酉克不安，又见从革，所以要搬迁。

## 水的注解

Water对该章的注解核心在于：

1. **内外动的区分**：时为日支冲主内动，与章十的时为日干冲主外动形成对照。日干为外、为尊、为占人自身；日支为内、为卑、为宅、为他人。冲支则宅不安、卑幼灾、与人争。

2. **从革主改易**：课体从革，主革故鼎新。从革本主西南（金方），但徐次宾以"畏鬼不敢往"而断移东北，说明课体方向需结合具体神将灵活运用，不可死板。

3. **丑为寺庙的类象**：丑为天乙本家，天乙为贵神，故丑主庙。丑临酉（西方、金仙、佛），故为寺。同一丑字，在寺庙语境下为"庙"，在佛道语境下为"寺"，全看组合。

4. **拆字得姓法**：大吉（丑）为土，下临酉为兑，兑为口，土口相配为"周"字。这是六壬中典型的拆字取姓技法，与章十的"李"字取法一脉相承。

5. **太阴主老阴人**：太阴为阴神，主老妇、阴私、口舌。大吉得太阴，故主老阴人争竞。太阴在酉上，酉为西方、为少女，太阴临之则老阴人。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全·课经》论从革课云："从革者，金局也，主革故鼎新，移易更变。"徐次宾在此课中完全继承此说——"卦得从革，革故鼎新"，并进一步以从革断移宅方向。

《大全》论返吟课云："十二神各居冲位，主事反复不宁。"徐次宾在章十一中虽未直接使用返吟，但"正时冲之名内外俱乱"的论述，与返吟课的精神相通——冲则乱，乱则变。

《大全》论日辰："日为占人，辰为所居之宅。"徐次宾完全继承此说，并进一步以"时为辰冲"论宅不安。这是对日辰理论的实战化运用——正时冲辰，则宅有动变。

### 2. 与《心镜》对照

Water引用《心镜》"大吉将军主荐贤，桥梁长者地祇冤"来印证丑主寺庙的类象。在徐次宾的断语中，丑为天乙本家故言庙，与《心镜》的"地祇"意象相通——地祇即土地神，庙为地祇所居。

《心镜》论从魁："从魁金玉小刀钱，九江阴私近水边。"徐次宾以酉为寺、为佛、为金仙，取酉的"金"象与"西方"象，而非《心镜》的"阴私"之象。这说明同一神煞在不同语境下取象不同——酉在寺庙语境下为西方极乐，在阴私语境下为私通。

《心镜》论太乙："太乙萤火主口舌，灶釜妇女及炉冶。"徐次宾以末传巳（太乙）得朱雀为日下之财，取巳的"财"象，而非《心镜》的"口舌"之象。巳为癸水日干之财（癸水克巳火），故论财不论口舌。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论从革课云："从革主更变，凡事有改作之象。"徐次宾在此课中以从革断移宅，与《直指》的"改作"之论完全一致。

《直指》论日辰冲："辰冲主宅动，或家人有灾。"徐次宾进一步细化为"宅不可居、卑幼灾难"、"与我相争、他人疾病"，这是对日辰冲理论的实战化细化。

《直指》论八专课："八专日辰同居一处，主事暧昧不明。"徐次宾在章十一中论"八专日辰同居一处，若正时冲之，名内外俱乱，主男女俱淫乱"，这是对八专课的独特运用——八专本已暧昧，再加正时冲之，则内外俱乱。

### 4. 与《邵彦和断案》对照

邵彦和断案中大量运用课体断移宅。如邵案中有一课：占宅，得从革课，邵断"宅当改移"。徐次宾在此课中继承此说——"卦得从革，革故鼎新"，以从革断移宅。

邵案中拆字取姓的技法在徐次宾这里得到继承。邵案中常以神将的五行属性配合字形拆解，徐次宾在此课中以"大吉为土，地盘酉为兑，土口相配为周字"，正是邵氏技法的直接运用。

邵案中论"丑为天乙本家"的技法，徐次宾在此课中继承——"丑为天乙本家，故言庙也"。天乙贵人本家在丑，故丑主庙、主神佛。

### 5. 核心技法解锁

章十一最核心的断课心法是**"冲支主内动，从革主改易"**：

1. **先锋门定内外**：正时冲日支为内动，主宅不安、卑幼灾、与人争
2. **课体定性质**：从革主革故鼎新，定移宅；返吟主反复，定不安
3. **神将定方位**：丑为庙在东北，酉为寺在西南，神将的方位属性决定移宅方向
4. **拆字取姓法**：以神将的五行属性配合字形拆解，得姓字
5. **鬼畏不敢往**：大吉临酉为日鬼，畏鬼不敢往西南，故移东北

## 技法提炼

- **技法1：先锋门冲支法**——正时与日支相冲，主内动。宅不安、卑幼灾、与人相争、他人疾病，皆属内动范畴。

- **技法2：从革断移宅法**——课体从革，主革故鼎新，定主移宅。移宅方向需结合神将方位灵活判断，不可死板从革本方。

- **技法3：丑为庙寺法**——丑为天乙本家，故主庙。丑临酉（西方、金仙）则为寺。同一神煞在不同组合下取象不同。

- **技法4：拆字取姓法**——以神将的五行属性配合字形拆解。如大吉（丑）为土，地盘酉为兑，土口相配为"周"字。

- **技法5：太阴主老阴人法**——太阴为阴神，主老妇、阴私、口舌。太阴临大吉，故主老阴人争竞。

- **技法6：鬼畏不敢往法**——某方为日鬼所临，则畏鬼不敢往，需另择他方。这是判断移宅方向的核心心法。
