# 章四：时为日干三合六合（主外和合事）

## 徐次宾原文

1. 六合者，为月宿合神；三合者，为五行本局之神。以日为阳为尊，主外事。
2. 若正时与日干六合三合，定主外事和合。
3. 若合中带财，吉神良将主外财和合事；或妻妾和合事。
4. 若见天后、太阴为日与日为鬼，日辰传重见鬼者，必是因外面阴人和合上致生官事。
5. 若见空亡，或天空，是虽败露，无咎也。
6. 若命中带破，日辰传中复见必凶。

## 假令案例

### 假令一：己未日辰将午时，八专课

**四值：** 酉月未日午时

**课式：**
- 日干：己（土）
- 月将：辰
- 正时：午
- 三传：丑（螣蛇）→ 巳（青龙）→ 巳（青龙）
- 课体：八专

**断语：** 南面上有属马妇人来往事败露，内有一姓孙人恐吓惊恐，坏钱十一贯，至庚申日即无事。

**徐次宾析：**
- 午时为日干六合，卦名八专主淫乱
- 午时属马为南方
- 事败 = 日上太乙得青龙木为日鬼
- 姓孙人惊恐 = 用大吉主姓孙螣蛇主惊恐
- 坏钱十一贯 = 青龙主财帛7数 + 太乙4数 = 11
- 庚申日无事 = 青龙为鬼至庚申日死绝

**水论：**
- 正时门午与日干日支相合主合和事，午上天空主虚无缥缈事
- 八专干支同位阴阳不分主淫乱，大象定下
- 天官青龙克日干则知道钱会失去
- 庚申日无事原理是天官青龙木气在申日作绝地

### 假令二：己卯日申将午时（丁丑人占）

**四值：** 巳月卯日午时

**课式：**
- 日干：己（土）
- 月将：申
- 正时：午
- 三传：亥（螣蛇）→ 丑（天后）→ 卯（玄武）
- 课体：三交

**断语：** 外和合事中虚诈、不实、邪僻之事。财上有惊恐，青衣姓牛人取财，驴亦被取，意欲远行心有所畏紧速而归。

**徐次宾析：**
- 时为日干六合主外和合，直事门天空主虚诈
- 日上从魁三交主隐匿不明
- 发用登明为财上见螣蛇主惊恐
- 中传大吉为牛上见乙字青色
- 命上太冲为驴上见玄武为贼人

**水论：**
- 正时门午与日干相合主外合和事，值事门天空主虚诈不实
- 课体三交主阴私，三传后玄当有人夺他
- 年命法应当有两般：一是定气势如徐次宾一般定下整个局的情况，二是入局如邵彦和先生一般排出行年

## 水的注解

Water对该章的注解核心在于：

1. **八专大象定淫乱**：八专干支同位阴阳不分，主淫乱。大象定下后，具体细节再以神将推演。

2. **天官青龙克日干则知钱会失去**：青龙为财帛之神，但克日干则财反为害。

3. **庚申日无事原理**：天官青龙木气在申日作绝地，故至庚申日即无事。这是以天官五行生死论应期。

4. **年命法两般**：一是定气势（徐次宾法），二是入局（邵彦和法）。定气势是定下整个局的情况，入局是排出行年逐一推演。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论八专课："八专者，干支同位，阴阳不分，主淫乱之事。"徐次宾在假令一中，以八专课断"南面上有属马妇人来往事败露"，正是取八专淫乱之象。

《大全》论三交课："三交者，四仲相加，主隐匿不明，奸私之事。"徐次宾在假令二中，以三交课断"虚诈、不实、邪僻之事"，与《大全》一致。

《大全》论六合："六合者，月宿合神，主和合之事。"徐次宾以正时与日干六合定"外事和合"，这是对《大全》六合论的直接运用。

但《一字诀》的创新在于：**六合不只是吉神，合中带鬼则凶**。假令一中，午与日干六合，但日上太乙得青龙木为日鬼，故"事败"。这是对六合理论的深化——合中有鬼，吉中有凶。

### 2. 与《心镜》对照

《心镜》论螣蛇："螣蛇惊恐是虚惊，火光怪异事相萦。"徐次宾在假令一中，以发用大吉得螣蛇断"姓孙人恐吓惊恐"，在假令二中，以发用登明得螣蛇断"财上有惊恐"，皆取螣蛇惊恐之象。

《心镜》论青龙："青龙财帛喜重重，酒色婚姻信息通。"徐次宾在假令一中，青龙为财帛之神，但克日干则财反为害——坏钱十一贯。这是对《心镜》青龙论的补充：青龙虽主财，但克日则财去。

《心镜》论玄武："玄武盗贼不可当，阴私暗昧主逃亡。"徐次宾在假令二中，末传卯上见玄武，断"驴亦被取"，正是取玄武盗贼之象。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论八专："八专之课，阴阳共位，夫妇不明，主有淫乱之事。"这与徐次宾的断法一致。

《直指》论三交："三交事体勾连，二烦触处荆棘。"徐次宾在假令二中，以三交课断"虚诈、不实、邪僻之事"，与《直指》的"事体勾连"相通。

《直指》论青龙克日："青龙乘克，财帛有损。"徐次宾在假令一中，青龙木克己土，断"坏钱十一贯"，与《直指》一致。

《直指》论应期多从旬空填实、绝处逢生等角度。徐次宾在假令一中，以"庚申日无事"——青龙木绝于申，这是以天官五行绝地论应期，与《直指》的"绝处逢生"相对，是"绝处逢死"的用法。

### 4. 与《邵彦和断案》对照

邵彦和断案中，年命法的运用分为两个层次：
- **定气势**：以年命上神定整个局面的性质
- **入局**：排出行年，逐一推演每个流年的吉凶

Water指出，徐次宾多用"定气势"法，而邵彦和则"定气势"与"入局"兼用。在假令二中，徐次宾以丁丑人占，命上太冲为驴上见玄武为贼人——这是以年命上神直接定气势，而非排出行年逐一推演。

邵彦和断案中有一课：某人占失驴，邵以命上卯木为驴，上见玄武为贼，断驴被偷。徐次宾在假令二中完全继承此说。

### 5. 核心技法解锁

章四最核心的断课心法是**"合中辨鬼，大象定淫"**：

1. **正时与日干六合三合定外事和合**：这是先锋门的第一层判断
2. **合中带财为吉，合中带鬼为凶**：同样是合，带财则吉，带鬼则凶
3. **八专大象定淫乱**：课体大象优先于具体神将
4. **天官五行绝地论应期**：青龙木绝于申，故庚申日无事
5. **年命法分定气势与入局两般**：徐次宾多用定气势，邵彦和兼用入局

## 技法提炼

- **技法1：合中辨鬼法**——正时与日干六合三合，需进一步判断合中是否带鬼。合中带财吉神良将主外财和合；合中带鬼（天后、太阴为日鬼）则因阴人和合致生官事。

- **技法2：八专课淫乱断法**——八专干支同位阴阳不分，主淫乱。结合正时方位（午为南方属马），可断具体人物特征。

- **技法3：天官五行绝地应期法**——以天官的五行绝地论应期。如青龙木绝于申，故庚申日无事。这是以神将五行生死论应期的核心技法。

- **技法4：年命定气势法**——以年命上神直接定整个局面的性质，而非排出行年逐一推演。如命上太冲为驴，上见玄武为贼人。

- **技法5：三传后玄夺财断法**——三传见天后、玄武，主有人夺财。结合课体三交主阴私，可断"虚诈不实、邪僻之事"。
