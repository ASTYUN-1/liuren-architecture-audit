# 章三：时为日贵日禄日德（主动官事）

## 徐次宾原文

1. 贵德禄三神者，异名而同体，谓显有德、享有禄，皆为贵官之象。
2. 若三神带财，多为官场之财，或托有官人干财。
3. 若被刑带杀害，传中有凶将，定入官府争财。
4. 若三传神上带吉将，传中见青龙、六合、太常，为日三合六合，不见刑克，仕人加官；秀士及第；庶人得之，见官得理，或得上人提挈。
5. 若式中见昼夜贵人全者，主两重衙门。
6. 若卦中遥克、反吟，中传见天马，即知他处衙门官动也。

## 假令案例

### 假令一：丙子日申将酉时（癸巳人占）

**四值：** 午月子日酉时

**课式：**
- 日干：丙（火）
- 月将：申
- 正时：酉
- 三传：戌（天魁）→ 酉（从魁）→ 申（传送）
- 课体：知一

**断语：** 家西耕开荒地一段种麦，有带官人刈麦相争到官，劝和，得麦一半。

**徐次宾析：**
- 酉为日下之财，不言金玉而言麦者人事也
- 酉主小麦，《心镜》"从魁金玉小刀钱，九江阴私近水边，奴婢小麦并赏赐"
- 家西 = 酉西方
- 带官人 = 直事门为仲中传见天乙
- 劝和分麦 = 时为合卦得比用，申酉时财落空亡只得一半

**水论：**
- 正时门为酉贵，与日干合又为日财，为外合和事、财事、官事
- 先锋门一见气势就定下
- 人随课走，课又因为人有不同
- 取数兼用旺相休囚死，空亡则半数

### 假令二：丙戌日未将亥时（癸酉人占）

**四值：** 未月戌日亥时

**课式：**
- 日干：丙（火）
- 月将：未
- 正时：亥
- 三传：酉（贵人）→ 巳（太常）→ 丑（勾陈）
- 课体：从革

**断语：** 西北上远行理会自己差遣文字，并无难阻，得差遣必是近任，八月丁酉日还家，当月得俸。太守刚毅正直姓刘。

**徐次宾析：**
- 时为日下驿马与天马并，登明为西北
- 从革课得近任
- 末传大吉为归计门下临酉上丁字故知丁酉日
- 酉为金刀故姓刘

**水论：**
- 此课应是两个人，一为"我"差遣，二为太守
- 正时门得亥冲动日干，是官鬼得帘幕贵人，主外事官事贵人事文书事迁移事
- 从革是改任的象
- 酉与日干三合，此处酉不为我——年命法中日干命行年都是我但处于不同状态
- 酉本命定完气势在课体中必须转换掉以贵人论，这是锚定坐标系的转换

## 水的注解

Water对该章的注解核心在于：

1. **正时门酉贵**：与日干合又为日财，为外合和事、财事、官事。先锋门一见气势就定下。

2. **人随课走，课又因为人有不同**：同一课式因占人不同而断法不同，这是六壬"活法"的精髓。

3. **取数兼用旺相休囚死，空亡则半数**：财落空亡只得一半，这是取数的核心原则。

4. **锚定坐标系转换**：酉本命定完气势在课体中必须转换掉以贵人论。年命法中日干、命、行年都是"我"但处于不同状态——这是六壬中"我"的多重身份问题。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论贵德禄："贵德禄三神，异名而同体。"《大全》将贵、德、禄视为同类，主贵官之象。《一字诀》章三完全继承此说，但进一步细化——三神带财为官场之财，被刑带杀为官府争财。

《大全》论从革课："从革者，金之性也，先天后革，改故鼎新。"徐次宾在假令二中，以从革课断"得差遣必是近任"，正是取从革"改任"之象。

《大全》论帘幕贵人："帘幕贵人，主文书、官事、贵人之事。"徐次宾在假令二中，亥为帘幕贵人冲动日干，断"外事官事贵人事文书事迁移事"。

### 2. 与《心镜》对照

Water引用《心镜》"从魁金玉小刀钱，九江阴私近水边，奴婢小麦并赏赐"来印证酉主小麦的类象。在假令一中，徐次宾以酉为小麦而非金玉，正是取《心镜》的类神体系，结合"人事"（种麦）来定象。

《心镜》论天乙贵人："天乙贵人是福神，出入干求喜气新。"徐次宾在假令一中，中传见天乙（酉为夜贵），断"带官人"，正是取天乙为贵官之象。

《心镜》论登明（亥）："登明天柱廪楼台，狱厕猪圈恶物该。"徐次宾在假令二中，亥为驿马与天马并，主西北远行，这是取亥的"天柱""楼台"之象——天柱为西北，楼台为高处。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论从革："从革之课，革故鼎新，事主冗杂不一，动摇不定。"徐次宾在假令二中，以从革课断"得差遣必是近任"，取"革"为改任之意，但《直指》更强调从革的"动摇不定"，而徐次宾则结合其他因素（末传大吉为归计、酉上丁字）得出具体应期。

《直指》论贵德禄："贵德临身，仕宦占之最吉。"这与徐次宾的"仕人加官，秀士及第"一致。

《直指》论空亡："空亡则事虚，财落空亡只得一半。"徐次宾在假令一中，申酉时财落空亡，断"得麦一半"，与《直指》完全一致。

### 4. 与《邵彦和断案》对照

邵彦和断案中，年命变体门的运用极为精妙。Water在注解中指出：**年命法中日干、命、行年都是"我"但处于不同状态**。

在假令二中，癸酉人占丙戌日：
- 酉为占人本命
- 酉与日干丙三合（丙与酉为三合关系）
- 但徐次宾不以酉为"我"，而是将酉转换为贵人论
- 这就是"锚定坐标系的转换"——本命酉在课体中先定气势，然后必须转换掉

邵彦和断案中常见此类技法：年命神煞在课体中先作为"定调"因素，然后根据课体需要转换为其他角色。这是六壬年命法的最高境界。

### 5. 核心技法解锁

章三最核心的断课心法是**"贵德禄三位一体，先锋门定官事"**：

1. **贵德禄异名同体**：皆为贵官之象，但需结合财、刑、杀等判断具体性质
2. **昼夜贵人全者两重衙门**：这是判断涉及多个官方机构的技法
3. **遥克反吟中见天马主他处衙门官动**：这是判断异地官事的技法
4. **锚定坐标系转换**：年命在课体中先定气势，然后根据课体需要转换角色
5. **从革为改任之象**：课体大象直接决定占事性质

## 技法提炼

- **技法1：贵德禄三位一体法**——贵、德、禄皆为贵官之象，但需结合是否带财、被刑、带杀来判断具体是"官场之财"还是"官府争财"。

- **技法2：昼夜贵人全者两重衙门**——式中昼夜贵人全见，主涉及两个官方机构或两重衙门。这是判断官事复杂程度的核心技法。

- **技法3：锚定坐标系转换法**——年命在课体中先定气势，然后根据课体需要转换角色。如癸酉人占，酉本命先定气势，然后转换为贵人论。这是六壬年命法的最高技法。

- **技法4：从革改任断法**——从革课主改故鼎新，结合驿马、天马，断改任、差遣之事。末传为归计，结合遁干定应期。

- **技法5：空亡半数取财法**——财落空亡，只得半数。这是取数中的核心原则，结合旺相休囚加减使用。
