# 章五：时为日支三合六合（主内和合事）

## 徐次宾原文

1. 辰为阴为宅，主内动。时为日支三合六合，主内和合事。
2. 若式中见子孙爻乘旺相气而带吉神者，添进子孙。
3. 若支神合中带鬼，上见勾陈、朱雀，卦得乱首、绝嗣，定主眷属仇讐，为内事争竞。
4. 若仕人得之，主同僚不睦，公吏等辈相陷。
5. 若支合并贵禄德三神，式中见官鬼，必因内事起官府词讼。
6. 若时与日辰俱合者，为两动，主内外和合事。
7. 若式中八门所主来意为外事，以此故只言外事也。

## 假令案例

### 假令一：壬申日申将辰时

**四值：** 巳月申日辰时

**课式：**
- 日干：壬（水）
- 月将：申
- 正时：辰
- 三传：未（朱雀）→ 亥（天空）→ 卯（太阴）
- 课体：曲直

**断语：** 家内不和，妻姓王刚暴口舌争斗，因此休弃。后因生子而复还合。

**徐次宾析：**
- 时与日支三合带鬼主内不和
- 天后为妻乘天罡下临子故姓王（天罡主欺诈恶人）
- 门户上发用朱雀主口舌
- 卦得曲直属木为子孙爻，时为日支合用传为日干合，内外俱合，因生子还合

**水论：**
- 正时门辰与日支相合是内合和事
- 辰为网罗欺诈恶人
- 发端门未朱雀是争吵事
- 三传课体得曲直为子爻
- 卯遁丁是水日逢丁财动，我为此子而动身见妻子
- 课体与八门气势相同——内事门正时门与日支合，三传与日干合，则能论合和事

### 假令二：丙子日申将丑时

**四值：** 巳月子日丑时

**课式：**
- 日干：丙（火）
- 月将：申
- 正时：丑
- 三传：子（六合）→ 未（太阴）→ 寅（青龙）
- 课体：重审

**断语：** 内外和合，主添妻妾之庆。

**徐次宾析：**
- 日干与时三合，与支六合，故言内外和合
- 太阴主妾媵，六合主婚姻和合，青龙主喜庆，始末俱吉

**水论：**
- 正时门丑时与支六合主内事门和合，又主外事门和合
- 最关键的技法是子乘六合是为官鬼，但巳月作休囚气
- 《壬归》论官鬼"旺相犹可，休囚难当"
- 徐次宾论此官鬼以子临巳地作绝地

## 水的注解

Water对该章的注解核心在于：

1. **正时门辰与日支相合是内合和事**：辰为网罗欺诈恶人，这是辰的类象。

2. **课体与八门气势相同**：内事门正时门与日支合，三传与日干合，则能论合和事。这是课体与八门相互印证的技法。

3. **卯遁丁是水日逢丁财动**：我为此子而动身见妻子。这是遁干与六亲结合的用法。

4. **《壬归》论官鬼"旺相犹可，休囚难当"**：子乘六合为官鬼，但巳月作休囚气，子临巳地作绝地，故不为害。这是判断官鬼吉凶的核心原则。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论日支三合六合："辰为阴为宅，主内事。时为日支三合六合，主内和合事。"《一字诀》章五的核心创新在于**区分了"时为日干合"（章四，主外事）与"时为日支合"（章五，主内事）**。

《大全》论曲直课："曲直者，木之性也，主先曲后直，始难终易。"徐次宾在假令一中，以曲直课为子孙爻，断"因生子而复还合"，正是取曲直"先曲后直"之象——先休妻后还合。

《大全》论乱首课："乱首者，辰临日克日，主卑小凌犯尊长。"徐次宾在规则中提及"卦得乱首、绝嗣，定主眷属仇讐"，与《大全》一致。

《大全》论绝嗣课："绝嗣者，三传皆与日干相克，主无后。"徐次宾以绝嗣为"眷属仇讐，内事争竞"，是对《大全》的补充。

### 2. 与《心镜》对照

《心镜》论朱雀："朱雀文书口舌侵，斗争词讼两相临。"徐次宾在假令一中，发用未朱雀主口舌争斗，正是取朱雀口舌之象。

《心镜》论六合："六合婚姻和合亲，子孙交易喜频频。"徐次宾在假令二中，子乘六合主婚姻和合，与《心镜》一致。

《心镜》论太阴："太阴阴私妇女事，婢妾金银首饰类。"徐次宾在假令二中，中传未乘太阴主妾媵，正是取太阴妇女之象。

《心镜》论青龙："青龙财帛喜重重，酒色婚姻信息通。"徐次宾在假令二中，末传寅乘青龙主喜庆，与《心镜》一致。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论曲直："曲直之局，先屈后伸，始难终易。"徐次宾在假令一中，以曲直课断"因生子而复还合"，正是取"先屈后伸"之象。

《直指》论官鬼："官鬼旺相犹可，休囚难当。"Water引用《壬归》此说，徐次宾在假令二中，子乘六合为官鬼，但巳月休囚，子临巳地作绝地，故不为害。这与《直指》的官鬼论完全一致。

《直指》论六合乘官鬼："六合乘官鬼，主婚姻中有官事。"但徐次宾在假令二中，子乘六合为官鬼，却断"添妻妾之庆"——因为官鬼休囚绝地，不为害反为吉。这是对官鬼论的灵活运用。

《直指》论内外合："时与日辰俱合，为两动，主内外和合事。"徐次宾在假令二中，日干与时三合、与支六合，断"内外和合"，与《直指》一致。

### 4. 与《邵彦和断案》对照

邵彦和断案中，以内事占断最为精妙。邵案中有一课：某人占家宅，得曲直课，邵断"先不和而后和，因子而合"。徐次宾在假令一中完全继承此说。

邵彦和论天后为妻："天后乘天罡，妻性刚暴。"徐次宾在假令一中，天后为妻乘天罡下临子，断"妻姓王刚暴口舌争斗"，正是继承邵说。

邵彦和论天罡得姓法：天罡（辰）为欺诈恶人，下临子水，子为"王"姓（子水为壬水）。这是六壬中"以神煞配姓氏"的独特技法。

Water指出：**课体与八门气势相同**——内事门正时门与日支合，三传与日干合，则能论合和事。这是邵氏断案中"课体与八门相互印证"的核心技法。

### 5. 核心技法解锁

章五最核心的断课心法是**"内外分判，合中辨鬼"**：

1. **时为日支合主内事**：与章四的"时为日干合主外事"相对，这是《一字诀》内外分判的核心框架
2. **时与日辰俱合为两动**：内外俱合，主内外和合事
3. **合中带鬼则凶**：支神合中带鬼，上见勾陈朱雀，主眷属仇讐
4. **官鬼旺相休囚论吉凶**：官鬼旺相犹可，休囚难当；绝地则不为害
5. **课体与八门相互印证**：内事门正时门与日支合，三传与日干合，则能论合和事

## 技法提炼

- **技法1：内外分判法**——时为日干合主外事（章四），时为日支合主内事（章五）。这是《一字诀》以正时与日干/日支的关系来分判内外事的核心框架。

- **技法2：官鬼旺相休囚论**——官鬼旺相犹可，休囚难当。子乘六合为官鬼，但巳月休囚，子临巳地作绝地，故不为害反为吉。这是判断官鬼吉凶的核心原则。

- **技法3：课体与八门相互印证法**——内事门正时门与日支合，三传与日干合，则能论合和事。课体大象与八门气势一致时，断语最为有力。

- **技法4：天罡得姓法**——天罡（辰）为欺诈恶人，下临子水为"王"姓。这是六壬中以神煞配姓氏的独特技法，源自邵彦和断案。

- **技法5：曲直课子孙爻断法**——曲直课属木为子孙爻，结合内外俱合，断因生子而还合。这是以课体五行定六亲的技法。
