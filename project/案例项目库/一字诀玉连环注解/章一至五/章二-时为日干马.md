# 章二：时为日干马（主出入之事）

## 徐次宾原文

1. 驿马者，传送之神也。主道路出入，若不落空亡、天空，定主出入也。
2. 若马为日干之财，主因财出行也。
3. 若马为日鬼见白虎发用，休气所乘，主紧速疾病。
4. 若时为日马带鬼，或式中更见勾陈、朱雀刑克于日者，因出入有官事。
5. 若驿马为贵人，式中见朱雀、太常，与日三合六合，官员差除。见关格则出入有阻。伏吟马动主出入在近或出而便归。反吟见马则反复出入，千里之行。
6. 若得进游子卦，有天涯地角之行。如斩关、三交，更得凶将，主避罪逃亡。

## 假令案例

### 假令一：癸丑日返吟亥时（壬辰老人占）

**四值：** 申月丑日亥时

**课式：**
- 日干：癸（水）
- 月将：午（申月午将）
- 正时：亥
- 三传：未（太常）→ 丑（朱雀）→ 未（太常）
- 课体：返吟、游子

**断语：** 因酒食过多，伤损肝胃，下孟血痢，小肠不通，心腹胀满，用药不效，饮食不进，旦暮而死。

**徐次宾析：**
- 日上小吉（未）主羊酒，太常主筵宴，土主脾胃，各乘休气故酒食伤脾胃
- 三传皆土故癸水不能流行，小肠不通
- 小吉为药、太常为饮食即为日鬼，故药不效食不进
- 旦暮死 = 时日马卦返吟游子，未为旬中六丁，丑时为日马，老病得之当是阳魂乘驿马六丁游于天外

**水论：**
- 未是药师主药，卯为乐师主音，丑是长者主旧，亥有室宿主修筑师傅，申作刀兵主武职——转类象法
- 象不能独论必有所主
- 论人生死神煞只是添头，以课体论大象，老人占病忌讳游子课、铸印、反吟等课

### 假令二：辛酉日午将申时（壬戌人占）

**四值：** 未月酉日申时

**课式：**
- 日干：辛（金）
- 月将：午
- 正时：申
- 三传：午（贵人）→ 辰（朱雀）→ 寅（勾陈）
- 课体：重审

**断语：** 因藏有夫妇人，事败露到官，旬日案成，累罪断徒五年，杖一百，丁丑日决之，发邻州居住。

**徐次宾析：**
- 本命日上见太阴主伏匿阴人不正之事
- 先锋门胜光发用上见天乙为今日鬼，故事败到官
- 徒五年 = 始末俱凶辰午两重自刑，三刑弃世二刑徒递，辰数五
- 丁丑日决 = 丁马为鬼丑为日刑

**水论：**
- 丁马水日为财，金日为官，火日为兄弟，木日为子孙，土日为长辈
- 驿马主快与近，天马主远与慢，丁马常常身不由己

## 水的注解

Water对该章的注解核心在于：

1. **转类象法**：未是药师主药，卯为乐师主音，丑是长者主旧，亥有室宿主修筑师傅，申作刀兵主武职——同一神煞在不同语境下可转类取象，但"象不能独论必有所主"。

2. **课体大象优先于神煞**：论人生死神煞只是添头，以课体论大象。老人占病忌讳游子课、铸印、反吟等课，这是大象决定吉凶走向的典型案例。

3. **丁马分论**：丁马水日为财，金日为官，火日为兄弟，木日为子孙，土日为长辈。驿马主快与近，天马主远与慢，丁马常常身不由己。这是对三种"马"的精细区分。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论驿马："驿马者，乃阴阳倚伏，气化循环，犹今之置驿传命，送往迎来。"《大全》强调驿马的"动"象，而《一字诀》章二则进一步细化了"动"的性质——因财而动、因疾而动、因官事而动。

《大全》论返吟课："返吟者，十二神各易其位，来而复往，去而复来。"徐次宾在假令一中，老人占病得返吟游子，断"旦暮而死"，正是取返吟"反复无常、阴阳离散"的大象。

《大全》论游子课："游子者，五行各归其位，主天涯地角之行。"老人占病得游子，是"阳魂乘驿马六丁游于天外"——魂已离体，故主死。这是课体大象在占病中的极致运用。

### 2. 与《心镜》对照

《心镜》论驿马："驿马原来是传送，道路出入最为先。"徐次宾完全继承此说，以驿马为出入之象。

《心镜》论小吉（未）："小吉姨姑酒食厨，天医门内主和愉。"徐次宾在假令一中，以小吉为羊酒、太常为筵宴，正是取《心镜》的类神体系。但徐次宾更进一步——小吉为药、太常为饮食，二者皆为日鬼（土克水），故药不效、食不进。

《心镜》论胜光（午）："胜光宫女信诚人，太乙蚕姑姨婶亲。"徐次宾在假令二中，以胜光发用上见天乙（贵人）为今日鬼，故事败到官。这是将午的"官"象与天乙的"贵"象结合，得出"官事"的结论。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论返吟："返吟之卦，孤神无依，事多反覆，百凡疑滞。"这与徐次宾在假令一中的断法一致——老人占病得返吟，主"旦暮而死"。

《直指》论游子："游子商贾而未回，斩关逃窜而速疾。"徐次宾进一步指出，游子课在老人占病中尤为忌讳，因为"阳魂乘驿马六丁游于天外"——魂已出游，肉身将死。

《直指》论丁马："金日逢丁凶动。"徐次宾在假令二中，丁丑日决——丁马为鬼，丑为日刑。这与《直指》的"丁主凶动"一致，但徐次宾更精细地指出丁马在不同日干下的不同含义（水日为财，金日为官等）。

### 4. 与《邵彦和断案》对照

邵彦和断案中，老人占病最忌游子、返吟、铸印等课。邵案中有一例：老人占病得返吟，邵断"魂游千里，三日当亡"。徐次宾在假令一中完全继承此说。

邵彦和论年命变体门极为精妙，徐次宾在假令二中运用年命法——"本命日上见太阴主伏匿阴人不正之事"，壬戌人占辛酉日，本命戌上见太阴，故断"藏有夫妇人"。

Water的注解进一步阐发了邵氏年命法的精髓：**年命法应当有两般——一是定气势，如徐次宾一般定下整个局的情况；二是入局，如邵彦和先生一般排出行年。**

### 5. 核心技法解锁

章二最核心的断课心法是**"马分三品，课体定生死"**：

1. **驿马主出入**：传送之神，主道路，不落空亡则定主出入
2. **丁马主身不由己**：丁马常与旬丁结合，主被迫而动、不得不动
3. **天马主远与慢**：与驿马的快近相对
4. **课体大象决定吉凶走向**：老人占病得游子、返吟，不论神煞如何，大象已定生死
5. **马带鬼则凶**：马为日鬼，见白虎发用，休气所乘，主紧速疾病

## 技法提炼

- **技法1：马分三品法**——驿马主快近、天马主远慢、丁马主身不由己。三者需结合使用，不可混淆。丁马在不同日干下含义不同：水日为财、金日为官、火日为兄弟、木日为子孙、土日为长辈。

- **技法2：课体大象优先法**——老人占病，课体大象（游子、返吟、铸印）优先于具体神煞。大象已定生死，神煞只是添头。这是《一字诀》"先定大象，后论细节"的核心原则。

- **技法3：转类象法**——同一神煞在不同语境下可转类取象：未为药师主药、卯为乐师主音、丑为长者主旧、亥为室宿主修筑、申为刀兵主武职。但"象不能独论必有所主"，需结合课体语境。

- **技法4：年命定气势法**——本命上神直接决定占事性质。假令二中本命戌上见太阴，直接断"藏有夫妇人"，这是年命法的最直接运用。

- **技法5：返吟游子病危断法**——老人占病得返吟+游子，是"阳魂乘驿马六丁游于天外"之象，旦暮当死。这是六壬占病中最凶的课体组合之一。
