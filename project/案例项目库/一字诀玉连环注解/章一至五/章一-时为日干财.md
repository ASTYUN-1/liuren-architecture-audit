# 章一：时为日干财（主求财）

## 徐次宾原文

凡时为日干之财，更乘旺气，得吉神良将，上下相生，定主干财之事。

1. 若式中得斩关、游子发用，子午白虎，必是出入干财。
2. 若式中见兄弟爻，上得吉将，便言同人干财。
3. 若日落空亡，或上见天空，便言财为等辈取也。占失财，亦为等辈偷也。
4. 若上得朱雀、勾陈、白虎与日为鬼，便言争财之人。
5. 若见天空、空亡者，必是空手求财也。
6. 若财在日上，乃手内之财，名为出门见财。
7. 若太阴乘财与日三合六合，主得阴人财。
8. 若见玄武临财，防盗；更见鬼贼，定是失财。
9. 凡财乘旺气，是目下之财；相气，是将来之财；休气，是过去之财，或为旧财，或于有疾病人处求财；囚气，系无力之财；死气，是关死人之财。
10. 欲知财数，以神将上下相乘，不用他人之干也。亦量旺相休囚、相生相克加减言之。

## 假令案例

### 假令一：乙亥日申将未时

**四值：** 巳月亥日未时

**课式：**
- 日干：乙（木）
- 月将：申
- 正时：未
- 三传：丑（螣蛇）→ 寅（朱雀）→ 卯（六合）
- 课体：重审

**断语：** 出外取索旧财两重，系丑年交易，共钱三百二十贯，至六月得钱五十六贯，至十二月再索此钱，主口舌相争，却得姓董人和劝，其财尽得。

**徐次宾析：**
- 时为日干财（未为乙木之财），直事门见白虎主道路
- 发用大吉（丑）亦为日干之财，大吉土无气故言出外取索旧财两重
- 三百二十贯 = 大吉8 × 螣蛇4 = 32，取十倍为320贯
- 六月得56贯 = 小吉8 × 白虎7 = 56
- 十二月再索得姓董人劝和——发用大吉应十二月建，中传功曹（寅）为等辈上得朱雀主口舌，末传卯六合草头为"董"，六合主和

**水论：**
- 丑无气难解，申将为巳月应作相气
- 丑作旧事，《邵案》童巡检课中邵论丑为旧事
- 《心镜》"大吉将军主荐贤，桥梁长者地祇冤"中丑主长者
- 六合草头相"重"叠则得董
- 休气在《一字诀》中常见与疾病同论，也可表示退休者

### 假令二：壬申日申将午时

**四值：** 巳月申日午时

**课式：**
- 日干：壬（水）
- 月将：申
- 正时：午
- 三传：子（白虎）→ 寅（玄武）→ 辰（天后）
- 课体：斩关

**断语：** 出外，东南上干财。因姓崔人成合交易，其人内怀欺诈，终不敢发。又有一属狗人姓王，欲相侵害，终而自解。

**徐次宾析：**
- 发用神后将得白虎主道路，天罡临支为斩关
- 东南干财 = 时下财乘螣蛇临辰
- 姓崔 = 末传天罡为山加寅配艮为垒土（辰与戌都作垒土煞）配"人"字
- 内怀欺诈 = 天罡虚诈克日
- 属狗姓王欲害 = 申上天魁（狗）+ 日上大吉（王）
- 自解 = 日落空亡彼不见我

**水论：**
- 《六壬大全》斩关课需辰戌发用，但实际不必如此，只需辰戌被破则可斩关
- 鬼不能为害三种情况：1.鬼得旬空 2.鬼下被地盘克 3.四课三传有子孙为救
- 若见官鬼克日干，日干得空则不为大害但仍然被伤

## 水的注解

Water对该章的注解核心在于：

1. **旺相休囚的灵活运用**：丑在巳月本为死气，但徐次宾以"相气"论之，说明旺相休囚需结合月将和实际占断灵活处理，不可死板。

2. **丑为旧事的类神依据**：引用《邵彦和断案》童巡检课中邵论丑为旧事，以及《心镜》"大吉将军主荐贤，桥梁长者地祇冤"中丑主长者，说明丑的转类象用法。

3. **六合草头得"董"姓**：卯为六合，六合为草头，两"草"相叠为"艹艹"→"董"，这是六壬中拆字取象的典型技法。

4. **斩关课的灵活理解**：传统认为斩关需辰戌发用，但实际只需辰戌被破即可论斩关，这是对课体规则的灵活运用。

5. **鬼不能为害的三种情况**：鬼得旬空、鬼下被地盘克、四课三传有子孙为救，这是断课中判断凶事能否化解的核心心法。

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》课经中论"财"多从三传财局、日财临身等角度入手，而《一字诀》章一的核心创新在于**以正时为第一切入点**——"时为日干之财"即先锋门定基调。

《六壬大全·课经》论斩关课云："魁罡临日辰，传有白虎，为斩关得断。"但徐次宾在假令二中，天罡（辰）临支而非发用，仍论斩关。这与《大全》的严格定义有出入，却更符合实战——**斩关的本质是"冲破关隔"，而非拘泥于辰戌发用**。

《六壬大全》论财数："以神将上下相乘"，徐次宾完全继承此法，且进一步细化——大吉8×螣蛇4=32，取十倍为320贯，这是将神将数乘以10的实战取数法。

### 2. 与《心镜》对照

Water引用《心镜》"大吉将军主荐贤，桥梁长者地祇冤"来印证丑主长者的类象。在假令一中，丑为发用，徐次宾以丑为"旧事"、"长者"，与《心镜》的"将军""荐贤"意象相通——将军为长者，荐贤为旧交。

《心镜》论从魁："从魁金玉小刀钱，九江阴私近水边，奴婢小麦并赏赐。"徐次宾在章三假令一中以酉为小麦，正是直接取用《心镜》的类神体系。

### 3. 与《六壬直指御定》对照

《六壬直指御定》对财的论述多从"传财太旺，反为财害"的角度（如"全财病体难担荷"），而《一字诀》章一则更注重**财的来路与性质**——是旧财还是新财、是空手求财还是带官人干财、是阴人财还是争财。

《直指》论空亡多主"虚而不实，求财不得"，但徐次宾在假令二中论"日落空亡彼不见我"——空亡在此不是"无财"，而是"对方看不见我"，即鬼不能为害。这是对空亡理论的创造性运用。

### 4. 与《邵彦和断案》对照

邵彦和断案中大量运用年命变体门，而徐次宾在章一中虽未直接使用年命，但其"丑为旧事"的论断直接源自邵案。

邵案中有一课：童巡检占，邵论"丑为旧事"，徐次宾在假令一中继承此说，以发用大吉（丑）无气论"出外取索旧财两重"。这说明：
- **丑的类象具有跨时代的稳定性**：从邵彦和到徐次宾，丑主旧事、主长者的象意一脉相承
- **旺相休囚决定新旧**：丑乘旺气为新事，乘休囚为旧事，这是判断新旧的核心技法

### 5. 核心技法解锁

章一最核心的断课心法是**"先锋门定调，八门逐层入"**：

1. **先锋门（正时）定基调**：先看正时是否为日干之财，确定求财的大方向
2. **直事门（正时所乘天盘）定路径**：如白虎主道路、天空主空手
3. **发端门（初传）定细节**：如大吉为旧财、螣蛇主惊恐
4. **课体定性质**：如斩关主出入、游子主远行
5. **旺相休囚定时态**：旺为目下、相为将来、休为过去、囚为无力、死为死人财

这五层逐次展开，构成了《一字诀》完整的断课框架。

## 技法提炼

- **技法1：先锋门直读法**——正时与日干的六亲关系直接定占事大类，时为财则求财，时为马则出入，时为贵则官事。这是《一字诀》区别于其他壬学体系的最核心特征。

- **技法2：神将数乘法取财数**——以发用神将上下相乘得基数，再根据旺相休囚加减（旺相乘10、相气乘5、休囚取本数），这是六壬中少有的定量技法。

- **技法3：丑主旧事转类象法**——丑在《心镜》为"将军""长者"，在邵案中为"旧事"，在《一字诀》中丑无气则论旧财。同一神煞在不同语境下可转类取象，关键在于结合旺相休囚。

- **技法4：斩关课的灵活运用**——不局限于辰戌发用，只要辰戌被破（临支、入传、被冲等）即可论斩关，这是实战中更实用的判断标准。

- **技法5：鬼不能害三条件**——鬼得旬空、鬼下被地盘克、四课三传有子孙为救，三者有一则鬼不为大害。这是判断凶事能否化解的核心心法。
