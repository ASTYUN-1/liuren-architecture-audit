# 章十五：时为日破（主走失）

## 徐次宾原文

### 日破总则

鼎祚联珠经所载占课有忌时：

- 甲乙日忌申酉时
- 丙丁日忌亥子时
- 戊己日忌寅卯时
- 庚辛日忌巳午时
- 壬癸日忌辰戌丑未时

为日下正财鬼合破为我禄而与我战，故主破财走失之事。

### 十四则细则

1. 若用神更为日鬼者，名天罡课，占病刑狱得之最为凶象。
2. 若中末传见者其灾稍缓。
3. 若时为日破上见凶神，式中见元武，所乘神遥制元与日为财，合者虽失物而复见也。
4. 若时见日破上见凶神，式中见元武，所乘神克财爻者主失物难寻也。
5. 若传中见天魁、从魁及太阴天空者，只主奴婢逃亡。
6. 若日上神并勾陈，所乘神遥制元武所乘神，受克多主盗贼自败也。
7. 若元武乘神与日为鬼，并刑害者带旺相，定主盗贼伤人也。
8. 若元武制勾陈，主捕人被伤也。
9. 若土为日破，传得稼穑卦三传，上见白虎、元武乘天马，并六丁，主贼人自远方来，乘骑会叙而行劫也。
10. 若水为日破，传得润下卦，带元武者，即主北方乘舟渡水，遇贼损财。若在家，则主贼自北墙水窦中来也。
11. 若火为日破，传得巳午炎上卦，主贼自南方窑冶中持火炬来，且放火烧人屋宇也。
12. 若金为日破，传得申酉从革与元武并而乘旺者，主贼自西方来，持兵仗伤人，不可当也。
13. 若日落空亡则不见是事。
14. 若在辰上主伤外人，其贼所藏位方备载前经兹不复录。

## 假令案例

### 假令一：壬申日申将未时（癸酉人占）

四值：申月 申日 未时

```
蛇  朱  合  勾
午  未  申  酉       龙  勾  常  虎       官  乙丑  常
贵巳          戌龙   戌  酉  丑  子       子  丙寅  玄
后辰          亥空   酉  申  子  壬       子  丁卯  阴
卯  寅  丑  子
阴  玄  常  虎
```

**断语**：在外因姓王人失了水牛一只，为眼疾老男子老阴人相逐，牵牛往东北去，终不可得。

**徐次宾析**：
- 何知在外失牛？盖时日三合故知在外，不言和合而言失物者，丑为日鬼故言在外失物。
- 何知姓王人失牛？发用大吉为日鬼，下临子水，水一数配土为王字，大吉为牛，中传功曹乘元武克大吉为贼，岂不是失牛也，言水牛者，月建得壬字故言水也。
- 何知患目老男子并老阴人？盖寅为老翁，元武为眼疾人，卯上见太阴，主老阴人，寅卯相连故言逐也。言东北者下临丑也。
- 何知终不可见？以占时发用本命俱为日鬼，又日落空亡，故言终不见也。

**水的注解**：
正时门未与日干三合主外事合和上见朱雀主争吵。日干上见羊刃主争斗。丑上见寅玄武被其克则牛被盗。丑有二象：丑作王姓人此是对日干不利的；三传见寅玄武克丑盗贼对牛不利。日落空亡不仅仅是避祸也是不相见的象。

### 假令二：壬午日巳将戌时（七月）

四值：申月 午日 戌时

```
合  朱  蛇  贵
子  丑  寅  卯       虎  朱  朱  玄       财  壬午  玄
勾亥          辰后   申  丑  丑  午       官  丁丑  朱
龙戌          巳阴   丑  午  午  壬       父   申  虎 ◎
酉  申  未  午
空  虎  常  玄
```

**断语**：解失驴西北去十三里外，有一姓贾人所得其驴，至甲午日往牛市得信自往姓贾处收得，至甲午日果然。

**徐次宾析**：
- 盖时为日破上得青龙，发用胜光为日下之财，元武临之本合失马，以胜光无气故言失驴，不言贼而言失者，以财在日上手上不难取也。
- 胜光数九，玄武数四，相并得十三里也。
- 何知姓贾人收得？末传归计门白虎加申，主西字又主贝字，配成贾字。
- 何知牛市得驴信？盖甲申旬胜光空亡，至甲午旬填实，又午为日财，故言甲午日复见，而喜壬与申相生，故言自往得驴也。

**水的注解**：
正时门戌时为日破即官鬼。值事门青龙主财物丢失。发端午作玄武财被盗但三传递生日干终究无碍。午休气被亥制住故为何是驴不是马。玄武与亥锁定了午所以不会丢失。

## 变体门案例三则

以下三则案例出自《一字诀玉连环》变体门，涉及"时为日破"的变体运用，附于此处以备参考。

### 变体一：甲子日午将申时（七月）

四值：申月 子日 申时

```
朱  合  勾  龙
卯  辰  巳  午       虎  玄  玄  后       财   戌  玄 ◎
蛇寅          未空   申  戌  戌  子       官  壬申  虎 ⊙
贵丑          申虎   戌  子  子  甲       子  庚午  龙
子  亥  戌  酉
后  阴  玄  常
```

**断语**：因西南上紧速追捕一盗贼，坠马折伤右足，感风七日而陨。

**解析**：
- 时为日刑、日破，与日马并，主外动
- 发用天魁为日下之财，上得元武为盗贼，故知西南追捕盗击也
- 先锋门传送为中传，作日马带白虎克日，又与日刑杀并，故主坠马也
- 马加辰戌为跌扑，戌为足，在日辰之右，是伤右足也
- 白虎为风神，七月申为风煞，故感风也
- 甲木秋死而被旺金鬼所克，申为七数，故言第七日庚午，又合起白虎，故知七日陨也
- 末传胜光，不论救神者，盖秋火已死也

### 变体二：甲子日子将寅时（正月）

四值：寅月 子日 寅时

```
朱  合  勾  龙
卯  辰  巳  午       虎  玄  玄  后       财   戌  玄 ◎
蛇寅          未空   申  戌  戌  子       官  壬申  虎 ⊙
贵丑          申虎   戌  子  子  甲       子  庚午  龙
子  亥  戌  酉
后  阴  玄  常
```

**断语**：缘失陷官钱，勾唤入官而得惊恐，以致得脾虚下脏之疾，见祟持刃相惊，可移病人于南方设绯幕，至第九日南方有属马医巫，下赤药、艾灸、书朱符，其祟自除也。

**解析**：
- 发用天魁为财，上得玄武为失财之象
- 时为日德日禄，主动官
- 值事门见螣蛇主惊恐
- 发用天魁主脾，春土无气，又为甲木所克，故知脾虚也
- 上得元武水与天魁土内战，故知下脏之疾
- 申金在中传为鬼，上得白虎为刀兵，故言见祟持刀相惊
- 移于南方午上，设绯幕者，南方及绯幕皆火象，能制金祟矣
- 末传胜光九数，故云九日
- 午为马为火，为赤、为灸、为救神，故云医巫也

### 变体三：乙丑日午将未时（六月）

四值：未月 丑日 未时

```
勾  龙  空  虎
辰  巳  午  未       后  贵  朱  合       父  甲子  贵
合卯          申常   亥  子  寅  卯       父   亥  后 ◎
朱寅          酉玄   子  丑  卯  乙       财   戌  阴 ◎⊙
丑  子  亥  戌
蛇  贵  后  阴
```

**断语**：事于西北方，承继姓王人财产，相托一属鼠有官人，九月内定成就；又目下西南虚望公财，道路有所畏隔，不敢往也。

**解析**：
- 末传天魁为日干之财，天魁临亥字主王字
- 发用神后，为日干三合，上见贵神天乙，故知承继姓王人财产，而得属鼠贵人力也
- 九月成就者，归计戌为九月建也
- 又言西南虚望财者，未为日下之财，上见天空主虚诈
- 又值事门上见白虎主道路，白虎金也，为日之鬼，故畏而不敢往也

## AI解析

### 日破总论

"时为日破"即正时与日干相破（相克）。徐次宾所引《鼎祚联珠经》给出了完整的日破规则：

| 日干 | 忌时 | 原理 |
|------|------|------|
| 甲乙日 | 申酉时 | 申酉为金，克甲乙木，为日鬼 |
| 丙丁日 | 亥子时 | 亥子为水，克丙丁火，为日鬼 |
| 戊己日 | 寅卯时 | 寅卯为木，克戊己土，为日鬼 |
| 庚辛日 | 巳午时 | 巳午为火，克庚辛金，为日鬼 |
| 壬癸日 | 辰戌丑未时 | 辰戌丑未为土，克壬癸水，为日鬼 |

日破的本质是"正财鬼合破为我禄而与我战"——正时既是日干之财（我克者），又是日干之鬼（克我者），财鬼同体，故主破财走失。

### 日破的五行变体

徐次宾将日破与五行课体结合，给出了五种具体情形：

1. **土为日破 + 稼穑卦**：贼自远方来，乘骑会叙行劫
2. **水为日破 + 润下卦**：贼自北方来，乘舟渡水损财
3. **火为日破 + 炎上卦**：贼自南方来，持火炬烧屋
4. **金为日破 + 从革卦**：贼自西方来，持兵仗伤人
5. **日落空亡**：其事不见，虚惊一场

### 案例一深度解析：壬申日申将未时（失水牛）

1. **课体分析**：
   - 壬申日，申将未时
   - 壬癸日忌辰戌丑未时，未时为日破
   - 四课：丑子、酉申、子壬、酉申
   - 三传：丑（初）、寅（中）、卯（末）

2. **时为日破**：壬日得未时，未为日破（土克水），主破财走失。

3. **失牛之象**：
   - 发用大吉（丑）为日鬼，下临子水
   - 水一数配土为"王"字，大吉为牛
   - 中传功曹（寅）乘玄武克大吉，为贼盗
   - 月建得壬字，故言"水牛"

4. **人物特征**：
   - 寅为老翁，玄武为眼疾人 → 眼疾老男子
   - 卯上见太阴，主老阴人
   - 寅卯相连，故言"相逐"

5. **终不可得**：
   - 占时、发用、本命俱为日鬼
   - 日落空亡，故终不见

### 案例二深度解析：壬午日巳将戌时（寻回驴）

1. **课体分析**：
   - 壬午日，巳将戌时
   - 壬癸日忌辰戌丑未时，戌时为日破
   - 四课：申丑、丑午、午壬、丑午
   - 三传：午（初）、丑（中）、申（末）

2. **时为日破**：壬日得戌时，戌为日破，上得青龙，主财物走失。

3. **失驴非马**：
   - 发用胜光（午）为日下之财，玄武临之
   - 本合失马，但胜光无气（七月金旺火囚），故言失驴
   - 午数九，玄武数四，相并得十三里

4. **姓贾人收得**：
   - 末传归计门白虎加申
   - 申主西字，又主贝字，配成"贾"字

5. **甲午日复见**：
   - 甲申旬胜光空亡
   - 至甲午旬填实，午为日财
   - 壬与申相生，故自往得驴

### 变体门案例解析

变体门三则案例展示了"时为日破"在不同情境下的变体运用：

**变体一（甲子日申时）**：
- 时为日刑、日破、日马并见
- 主外动追捕，坠马伤足，七日而陨
- 体现了"日破+日刑+日马"三重叠加的凶险

**变体二（甲子日寅时）**：
- 时为日德日禄，虽为日破但得吉神
- 主失官钱得惊恐，但最终有救
- 体现了"日破+吉神"的复合判断

**变体三（乙丑日未时）**：
- 时为日破，但发用神后为日干三合
- 主承继财产，虽有虚望之财但不敢往
- 体现了"日破+三合"的吉凶交织

### 古籍印证

《六壬指南》论日破："日破者，时与日战也。财鬼同体，故主破财。若传中有救，则失而复得；若传中无救，则终不可见。"

《六壬大全》论走失："凡占走失，以玄武为贼，以财爻为物。日破之时，财鬼同体，最忌玄武临财。若日上救神旺，则虽失可复；若日落空亡，则终不可见。"

## 技法提炼

1. **日破主破财走失**：正时为日破，财鬼同体，主破财、走失、逃亡之事。

2. **五类日破规则**：
   - 甲乙日忌申酉时
   - 丙丁日忌亥子时
   - 戊己日忌寅卯时
   - 庚辛日忌巳午时
   - 壬癸日忌辰戌丑未时

3. **玄武与日破**：日破之时，玄武临财为失物之象。玄武所乘神克财爻则难寻，遥制玄武则复见。

4. **五行课体断贼方**：
   - 稼穑卦（土）→ 贼自远方来
   - 润下卦（水）→ 贼自北方来
   - 炎上卦（火）→ 贼自南方来
   - 从革卦（金）→ 贼自西方来

5. **空亡定见否**：日落空亡则事不见，物不可得；财落空亡则失物难寻。

6. **应期判断**：以旬空填实为应期。如甲申旬午空，至甲午旬填实则见。

7. **日破+日刑+日马**：三重叠加，主外动凶险，最宜谨慎。
