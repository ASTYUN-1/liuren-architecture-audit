# 章十四：时为日干劫煞（主紧速事）

## 徐次宾原文

魏陵叟曰：乌穷则攫，兽穷则搏，五行穷则绝，故立劫杀之号，所以攻劫也小人，行攻劫必紧速而来。

若劫煞上带元武为鬼克日，传中更与刑害并者，常人俱主贼盗攻劫之祸。

若日上救神旺，主贼畏我威而不敢发。

若劫煞落空，即主贼盗虚惊之象。

若劫煞带吉将与日为合，而式中不见元武而见日辰合者，主紧速和合事也。

## 假令案例

**六月辛未日午将亥时**

四值：未月 未日 亥时

```
朱  蛇  贵  后
子  丑  寅  卯       龙  贵  朱  玄       兄  癸酉  龙
合亥          辰阴   酉  寅  子  巳       父  戊辰  阴
勾戌          巳玄   寅  未  巳  辛       子   亥  合 ◎
酉  申  未  午
龙  空  虎  常
```

**断语**：酒宴间有姓刘人做媒说亲，一席便成，其新妇必是亥生。

**徐次宾析**：
- 时上见太常主宴会，值事门见六合岂不是酒宴？发用从魁为今日等辈，酉为金刀故言姓刘，上见青龙吉将主婚姻礼仪之庆。
- 时为劫煞主紧急。中传天罡为天马故一席便成。
- 末传登明为子孙爻故知其亥生。

## 水的注解

正时门亥为内事门合和，值事门上见六合主内合和事。亥上太常作宴会事，亥作子孙为子孙之宴。课体得龙合主说亲。寅为辛妻财作劫杀，课中时为劫杀者恐怕有误。末传见合又是子孙爻则为子孙说亲得合。

## AI解析

### 劫煞总论

魏陵叟曰："乌穷则攫，兽穷则搏，五行穷则绝，故立劫杀之号。"劫煞的本质是五行穷绝之处，物极必反，故有攻劫之象。

劫煞的查法：申子辰在巳，亥卯未在申，寅午戌在亥，巳酉丑在寅。

本章所论"时为日干劫煞"，即正时恰好为日干所在三合局的劫煞。如辛日（巳酉丑局），劫煞在寅，但此案例中亥时为劫煞——此处需注意，徐次宾所论"时为劫煞"可能另有体系，或指正时亥为辛日之劫煞（按辛日属巳酉丑局，劫煞在寅，亥非劫煞），此处存疑。

### 劫煞的四种变体

1. **劫煞带玄武为鬼克日**：主贼盗攻劫之祸，最为凶险。
2. **日上救神旺**：贼畏我威而不敢发，有惊无险。
3. **劫煞落空**：贼盗虚惊，实际无灾。
4. **劫煞带吉将与日合**：主紧速和合事，化凶为吉。

### 案例深度解析

**辛未日午将亥时**：

此课与章十三为同一课例（辛未日午将亥时），但章十三以"时为日刑"论，章十四以"时为劫煞"论，同一课从不同角度切入，体现了六壬"一课多断"的精妙。

1. **课体分析**：
   - 四课：酉寅、巳辛、寅未、巳辛
   - 三传：酉（初）、辰（中）、亥（末）
   - 发用酉为从魁，上乘青龙
   - 中传辰为天罡，上乘太阴
   - 末传亥为登明，上乘六合

2. **时为劫煞**：此课以亥时为劫煞。按常规查法，辛日属巳酉丑局，劫煞在寅。但徐次宾以亥为劫煞，可能依据的是另一种劫煞体系（如以日干论劫煞），或亥在特定条件下被视为劫煞。水的注解中也指出"课中时为劫杀者恐怕有误"，说明此点存在争议。

3. **宴会说亲之象**：
   - 时上见太常：太常主宴会、酒食
   - 值事门见六合：六合主婚姻、和合
   - 发用酉（从魁）上乘青龙：青龙为吉将，主婚姻礼仪之庆
   - 酉为金刀，配为"刘"字

4. **一席便成**：
   - 时为劫煞主紧急
   - 中传天罡为天马，主快速
   - 故言"一席便成"

5. **新妇亥生**：
   - 末传亥（登明）为子孙爻
   - 亥为日干辛之子孙（辛生子水）
   - 故知其新妇为亥年生人

### 劫煞与日刑的对比

同一课（辛未日午将亥时）在章十三以"时为日刑"论，在章十四以"时为劫煞"论，二者并不矛盾：

- **日刑角度**：亥为自刑，主紧速外动，故断"外动必速"
- **劫煞角度**：亥为劫煞，主紧急和合，故断"一席便成"
- **综合**：同一正时，从不同神煞切入，得出不同但互补的结论

### 古籍印证

《六壬神定经》论劫煞："劫煞者，五行绝处也。绝则穷，穷则变，变则通，通则久。然穷极之时，小人行劫，君子守正。"本章所论劫煞，正是取"穷极生变"之义。

## 技法提炼

1. **劫煞主急**：劫煞入课，无论吉凶，皆以"紧急"为特征。吉则急成，凶则急发。

2. **劫煞辨吉凶四法**：
   - 带玄武克日 → 贼盗攻劫
   - 日上救神旺 → 有惊无险
   - 劫煞落空 → 虚惊一场
   - 带吉将与日合 → 紧速和合

3. **劫煞与六合同现**：劫煞主急，六合主合，二者同现则主急合之事，如急婚、急约、急成交易。

4. **太常+六合**：太常主宴会，六合主和合，二者同现则主宴会上成合之事。

5. **末传定人**：末传为归计门，见子孙爻则知所成之事与子孙相关，亦可推其人年命。
