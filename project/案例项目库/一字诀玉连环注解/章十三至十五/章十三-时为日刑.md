# 章十三：时为日刑（主紧速事）

## 徐次宾原文

日刑者，谓寅刑巳，巳刑申，申刑寅名无恩刑，丑戌未名恃势刑，子刑卯，卯刑子，名无礼刑，辰午酉亥名自刑。

若壬日得亥时又以日德论，乙日得辰时又以日干之财论，故亥辰不当自刑，午酉子卯无日干相寄，亦无日刑也。

若甲日得巳时主速动外忧事，盖刑害兼全也。

若丙日得申时，则主外动紧速和合事，为刑中有合也。

若庚日得寅时，寅木乘旺气，主东北上有紧速干财事，盖刑中带马也负财故主财也。

其余诸刑取类言之。

## 假令案例

**辛未日午将亥时（六月）**

四值：未月 未日 亥时

```
勾  合  朱  蛇
寅  卯  辰  巳       合  贵  朱  后       官  戊午  贵
龙丑          午贵   卯  午  辰  未       财  乙卯  合
空子          未后   午  酉  未  辛       子   子  空 ◎
亥  戌  酉  申
虎  常  玄  阴
```

**断语**：本人欲往运司理会旧房钱，其外动必速，其中一姓马人作鬼贼，却得姓陈人力，至丁亥日见事务定作归计。

**徐次宾析**：
- 胜光发用上见天乙为三品衙门，中传太冲主门户下临午四正配房子，卯上六合俱为日下财故言房钱。
- 时为日刑又发用午为道路天乙在酉在门为励德故外动必速。
- 初传胜光为马为日鬼。末传神后水为曲阜下临卯为东字相配为陈字，神后反克胜光日鬼故得姓陈人力。
- 甲申旬午鬼落空，丁合壬与亥水克胜光也。不言戊子日者，缘戊为大杀也。

## 水的注解

正时门亥时主驿马之动，亥上见虎是道路神。课体得午卯子天车主大动。午作官鬼正时又为日刑。贵人立门为励德课——小人进职君子退位，是坚守自盗的象。末传子能克杀午，正时门亥能克杀午。论得亥日归不论子日：一是子日本身空无力，二是正时门在亥克午又作丁马大动，丁壬合木作财主财归来。戊为大杀不解。

## AI解析

### 日刑体系总论

本章所论"日刑"，核心在于正时与日干之间的刑冲关系。徐次宾将六壬刑法分为四类：

1. **无恩刑**（寅刑巳、巳刑申、申刑寅）：寅木生巳火，巳火生申金，申金生寅木，本为相生之道，却反相刑，故曰"无恩"。主恩将仇报、背信弃义之事。
2. **恃势刑**（丑戌未）：丑戌未皆为土，同类相争，恃势相凌。主倚势欺人、同室操戈。
3. **无礼刑**（子刑卯、卯刑子）：子水卯木本为相生，子为母、卯为子，母子相刑，故曰"无礼"。主悖逆伦常、以下犯上。
4. **自刑**（辰午酉亥）：此四者各自为刑，主自寻烦恼、自取其咎。

### 特殊处理规则

徐次宾特别指出两条例外：
- **壬日得亥时**：亥为壬日之德（日德），虽亥为自刑，但以日德论，不按自刑断。
- **乙日得辰时**：辰为乙日之财，虽辰为自刑，但以日财论，不按自刑断。

此二条体现了六壬"吉神优先"的原则——当日刑与日德、日财等吉神重叠时，以吉神为主。

### 三刑变体

- **甲日得巳时（刑害兼全）**：巳刑申，申为甲之鬼，巳又害申，故主外忧事，且行动迅速。
- **丙日得申时（刑中有合）**：申刑寅，寅为丙之生，申又为丙之合（丙辛合），故主外动紧速和合事。
- **庚日得寅时（刑中带马）**：寅刑巳，寅为庚之财，寅又为庚之驿马，故主东北方紧速干财事。

### 案例深度解析

**辛未日午将亥时**：

此课为日刑章的经典案例，涉及"时为日刑"与"励德课"的复合运用。

1. **课体分析**：
   - 四课：卯午、辰未、午酉、未辛
   - 三传：午（初）、卯（中）、子（末）
   - 发用午为胜光，上乘天乙贵人
   - 中传卯为太冲，上乘六合
   - 末传子为神后，上乘天空

2. **时为日刑**：辛日得亥时，亥为辛之死地，亥又为自刑。但此处徐次宾未以自刑论，而是以"时为日刑"统称，重点在于正时亥与日干辛的关系——亥为辛之病地，又为日刑，主紧速外动。

3. **励德课**：贵人立酉（门），酉为从魁，主门户。贵人立于门，为"励德课"——小人进职、君子退位。此象暗示内部有人作祟（姓马人作鬼贼），但最终能得人助。

4. **三传象意**：
   - 初传午（胜光）：为日鬼（辛日午为鬼），为马，为道路，为三品衙门（上见天乙）。午为日刑发用，主外动必速。
   - 中传卯（太冲）：主门户，下临午（四正），配为房子。卯上六合为日下之财，故言房钱。
   - 末传子（神后）：为水，为曲阜，下临卯为东字，相配为"陈"字。神后反克胜光日鬼，故得姓陈人力。

5. **应期判断**：
   - 甲申旬午鬼落空，故初传之鬼无力。
   - 丁亥日：丁合壬（丁壬合），亥水克午火，故丁亥日事务定。
   - 不言戊子日：戊为大杀，故不取。

### 古籍印证

《六壬大全》论刑："凡刑者，主动、主伤、主破、主速。"本章所论"时为日刑"，正是取"刑主动速"之义。徐次宾将刑与日干结合，细分为不同情形，较之泛论刑象更为精微。

## 技法提炼

1. **日刑断速动**：正时为日刑，主事情紧急、行动迅速，无论吉凶皆以"速"为特征。

2. **刑中辨吉凶**：
   - 刑中带害（如甲日巳时）：主外忧事
   - 刑中有合（如丙日申时）：主和合事
   - 刑中带马（如庚日寅时）：主干财事

3. **刑德取舍**：当日刑与日德、日财重叠时，以吉神优先，不以刑论。

4. **励德课的应用**：贵人立门为励德，主内部有人作祟，但最终能得外力相助。

5. **三传救应**：末传能克初传之鬼，则事虽凶而有救；若末传空亡，则救应无力。
