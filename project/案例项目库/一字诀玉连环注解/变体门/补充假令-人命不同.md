## 假令一：七月甲子日午将申时

### 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 七月（申月） |
| 月将 | 午将（七月午将） |
| 正时 | 申时 |
| 日辰 | 甲子日 |
| 三传 | 戌（玄）→ 申（虎）→ 午（龙） |
| 课体 | 重审 |

### 课式

```
    午将  申时
    七月  甲子日

    朱  合  勾  龙
    卯  辰  巳  午
    蛇寅          未空
    贵丑          申虎
    子  亥  戌  酉
    后  阴  玄  常

    四课：
    申  戌  戌  子
    戌  子  子  甲

    三传：戌（玄）→ 申（虎）→ 午（龙）
```

### 断语

> 来意因西南上紧速追捕一盗贼，坠马折伤右足，感风七日而陨。

### 徐次宾原析

> 盖时为日刑、日破，与日马并，主外动，发用天魁为日下之财，上得元武为盗贼，故知西南追捕盗击也。先锋门传送为中传，作日马带白虎克日，又与日刑杀并，故主坠马也。马加辰戌为跌扑，戌为足，在日辰之右，是伤右足也。白虎为风神，七月申为风煞，故感风也。甲木秋死而被旺金鬼所克，申为七数，故言第七日庚午，又合起白虎，故知七日陨也，末传胜光，不论救神者，盖秋火已死也。

### 逐层解析

#### 1. 先锋门——申时

- 申时为甲日之**刑**（甲刑申）、**破**（甲申破）、**马**（申为甲木驿马）
- 刑主动、破主破财、马主道路 → 外动、紧速、破财

#### 2. 发端门——戌（玄武）

- 戌为甲木之**财**（甲木克戌土）
- 上得玄武为**盗贼**
- 戌主西南（戌为西北偏西，但徐次宾以戌为西南，盖戌在西北偏西，与申西南相呼应）

#### 3. 中传——申（白虎）

- 申为甲木之**驿马**，带白虎主道路、紧速
- 申为甲木之**鬼**（申金克甲木），又为**日刑**
- 白虎为**风神**，七月申为**风煞** → 感风
- 申为**七数** → 七日

#### 4. 坠马折足

- 马（午）加辰戌为**跌扑**（午为马，辰戌为坡坎）
- 戌为**足**，在日辰之右 → 伤右足
- 中传申（白虎+日马）克日 → 坠马

#### 5. 七日陨

- 甲木秋死（秋金旺克木），被旺金鬼（申）所克
- 申为七数 → 第七日庚午
- 末传午（胜光）虽为救神（火克金），但秋火已死，不能救

### 水论

- 此课与假令二（正月甲子日子将寅时）**三传完全相同**（戌申午），但月将不同、正时不同、季节不同，断语天壤之别
- 七月申金旺相，甲木死绝，故主死亡
- 申为风煞、白虎为风神，故感风
- 末传午火虽为救神，但秋火死绝，不能救——**旺相休囚决定吉凶程度**

## 假令二：正月甲子日子将寅时

### 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 正月（寅月） |
| 月将 | 子将（正月子将） |
| 正时 | 寅时 |
| 日辰 | 甲子日 |
| 三传 | 戌（玄）→ 申（虎）→ 午（龙） |
| 课体 | 重审 |

### 课式

```
    子将  寅时
    正月  甲子日

    朱  合  勾  龙
    卯  辰  巳  午
    蛇寅          未空
    贵丑          申虎
    子  亥  戌  酉
    后  阴  玄  常

    四课：
    申  戌  戌  子
    戌  子  子  甲

    三传：戌（玄）→ 申（虎）→ 午（龙）
```

### 断语

> 来意缘失陷官钱，勾唤入官而得惊恐，以致得脾虚下脏之疾，见祟持刃相惊，可移病人于南方设绯幕，至第九日南方，有属马医巫，以撒火为姓名，下赤药、艾灸、书朱符，其祟自除也。

### 徐次宾原析

> 何以知失陷官钱而得惊恐？盖发用天魁为财，上得玄武为失财之象，时为日德日禄，主动官，值事门见螣蛇主惊恐。
> 何知脾胃、下脏之病？盖发用天魁主脾，春土无气，又为甲木所克，故知脾虚也；上得元武水与天魁土内战，故知下脏之疾。
> 又言祟者，申金在中传为鬼，经云传见魁病必有祟，上得白虎为刀兵，故言见祟持刀相惊，移于南方午上，设绯幕者，南方及绯幕皆火象，能制金祟矣。
> 末传胜光九数，故云九日。午为马为火，为赤、为灸、为救神，故云医巫也。经云：土丸木散水汤火灸金针，今传送为鬼，若针则加病，灸则病减也，金为日鬼，故宜书朱篆以压之，交春木旺金无气矣，救神乘相气病当瘥也。

### 逐层解析

#### 1. 先锋门——寅时

- 寅时为甲日之**德**（甲德在寅）、**禄**（甲禄在寅）
- 德禄主动官、主动贵人
- 值事门寅乘**螣蛇**主惊恐

#### 2. 发端门——戌（玄武）

- 戌为甲木之财，上得玄武 → **失财**
- 戌主脾（土主脾胃），春土无气 → 脾虚
- 玄武水与天魁土内战 → 下脏之疾

#### 3. 中传——申（白虎）

- 申为甲木之鬼（金克木），上得白虎为刀兵
- "传见魁病必有祟" → 见祟持刃相惊

#### 4. 救治之法

- 移南方（午位）设绯幕 → 火象制金祟
- 末传午为**九数** → 第九日
- 午为马、为火、为赤、为灸、为救神 → 属马医巫
- 书朱符 → 朱为火色，压金鬼

#### 5. 与假令一的对比

| 维度 | 假令一（七月） | 假令二（正月） |
|------|----------------|----------------|
| 季节 | 秋金旺 | 春木旺 |
| 甲木状态 | 死绝 | 旺相 |
| 申金状态 | 旺相 | 休囚 |
| 午火状态 | 死绝 | 相气 |
| 结果 | 死亡（七日陨） | 可救（九日愈） |
| 核心差异 | 旺金克死木，救神无力 | 旺木抗金，救神有力 |

### 水论

- 同一三传（戌申午），因季节不同（七月vs正月），旺相休囚不同，断语天壤之别
- 七月申金旺相克死木 → 死亡
- 正月寅木旺相抗金，午火相气为救 → 可愈
- **旺相休囚是断课的关键变量**，同一课式在不同季节下吉凶截然不同

## 假令三：六月乙丑日午将未时

### 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 六月（未月） |
| 月将 | 午将（六月午将） |
| 正时 | 未时 |
| 日辰 | 乙丑日 |
| 三传 | 子（贵）→ 亥（后）→ 戌（阴） |
| 课体 | 重审 |

### 课式

```
    午将  未时
    六月  乙丑日

    勾  龙  空  虎
    辰  巳  午  未
    合卯          申常
    朱寅          酉玄
    丑  子  亥  戌
    蛇  贵  后  阴

    四课：
    亥  子  寅  卯
    子  丑  卯  乙

    三传：子（贵）→ 亥（后）→ 戌（阴）
```

### 断语

> 来意事于西北方，承继姓王人财产，相托一属鼠有官人，九月内定成就；又目下西南虚望公财，道路有所畏隔，不敢往也。

### 徐次宾原析

> 盖末传天魁为日干之财，天魁临亥字主王字，发用神后，为日干三合，上见贵神天乙，故知承继姓王人财产，而得属鼠贵人力也。九月成就者，归计戌为九月建也。
> 又言西南虚望财者，未为日下之财，上见天空主虚诈，又值事门上见白虎主道路。白虎金也，为日之鬼，故畏而不敢往也。

### 逐层解析

#### 1. 先锋门——未时

- 未时为乙木之**财**（乙木克未土）
- 未乘白虎主道路
- 未为西南

#### 2. 发端门——子（天乙贵人）

- 子为乙木之**三合**（亥卯未三合木局，子为三合之贵人）
- 子上见天乙贵人 → 得贵人力
- 子为**鼠** → 属鼠有官人

#### 3. 归计门——戌（太阴）

- 戌为乙木之**财**
- 戌临亥 → 亥为水，水数一，一土为王 → **王字**
- 戌为九月建 → 九月成就

#### 4. 西南虚望

- 未为日下之财，上见天空 → 虚诈
- 直事门未乘白虎 → 道路有畏
- 白虎金为乙木之鬼 → 不敢往

### 水论

- 此课核心：**末传定姓+发用定人+归计定时**
- 戌临亥得"王"字 → 姓王人
- 子为鼠乘贵人 → 属鼠有官人
- 戌为九月建 → 九月成就
- 未为西南+天空+白虎 → 西南虚望不敢往

## 假令四：六月丙寅日午将未时

### 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 六月（未月） |
| 月将 | 午将（六月午将） |
| 正时 | 未时 |
| 日辰 | 丙寅日 |
| 三传 | 子（蛇）→ 亥（贵）→ 戌（后） |
| 课体 | 比用 |

### 课式

```
    午将  未时
    六月  丙寅日

    龙  空  虎  常
    辰  巳  午  未
    勾卯          申玄
    合寅          酉阴
    丑  子  亥  戌
    朱  蛇  贵  后

    四课：
    子  丑  卯  辰
    丑  寅  辰  丙

    三传：子（蛇）→ 亥（贵）→ 戌（后）
```

### 断语

> 来意主北面，近水酒筵间，与额尖眼小之人相争，又一贵人与彼相助，而欲见官，却得一王姓人劝和无事也。

### 徐次宾原析

> 盖值事门上见太常，主酒饮食，发用亥子为北，又临亥为近水，神后为为日之官鬼，见蛇为眼小额尖之人，中传登明亦为日鬼，见贵人知与彼相助。缘日上天罡，主怒恶，能制亥子水，故知息怒恶而欲到官，卦体比用主和合，末传天魁临亥主王字，故云姓王人劝合。

### 逐层解析

#### 1. 先锋门——未时

- 未时为丙火之**子爻**（丙火生未土）
- 值事门未乘**太常** → 酒食、筵宴

#### 2. 发端门——子（螣蛇）

- 子为丙火之**官鬼**（子水克丙火）
- 子上见螣蛇 → **眼小额尖**之人（蛇为细小、尖形）
- 亥子为**北面**，临亥为**近水**

#### 3. 中传——亥（贵人）

- 亥亦为丙火之官鬼
- 亥乘贵人 → 贵人与彼相助

#### 4. 日上——辰（天罡）

- 辰为天罡，主**怒恶**
- 辰土能制亥子水 → 息怒恶

#### 5. 归计门——戌（天后）

- 戌临亥 → 亥水数一，一土为王 → **王字**
- 戌乘天后主和合
- 卦体**比用**主和合

### 水论

- 此课与假令三（乙丑日）同一月将（午将）、同一正时（未时），但日辰不同（乙丑vs丙寅），三传虽同为子亥戌，但神将不同（贵/后/阴 vs 蛇/贵/后），断语各异
- 假令三主承继财产（财），假令四主酒筵争讼（官鬼）
- 核心差异：乙丑日未时为财，丙寅日未时为子爻
- **同一正时对不同日干的意义不同**，这是"人命不同"的另一种表现形式

## 假令五：六庚日伏吟辨——徐次宾亲身经历

### 背景

> 壬寅秋七月，余以陇西公事匿村落中，父即求课于元公，得庚午日午将午时，三传申寅申，将虎蛇虎。

这是《一字诀》中唯一一则徐次宾以**第一人称**叙述的亲身经历案例，弥足珍贵。

### 基本信息

| 项目 | 内容 |
|------|------|
| 时间 | 壬寅年秋七月 |
| 月将 | 午将（七月午将） |
| 正时 | 午时 |
| 日辰 | 庚午日 |
| 三传 | 申（虎）→ 寅（蛇）→ 申（虎） |
| 课体 | 伏吟 |

### 课式

```
    午将  午时
    壬寅年七月  庚午日

    勾  龙  空  虎
    巳  午  未  申
    合辰          酉常
    朱卯          戌玄
    寅  丑  子  亥
    蛇  贵  后  阴

    四课：
    午  午  申  申
    午  午  申  庚

    三传：申（虎）→ 寅（蛇）→ 申（虎）
```

### 事件时间线

| 日期 | 事件 | 课象对应 |
|------|------|----------|
| 壬申日 | 勾唤妻到官；徐次宾避难赴官出头 | 中传寅为妻爻，被初末申所克；传送白虎为道路 |
| 戊寅日 | 唤至州 | 应中传寅字，寅为庚日驿马 |
| 乙卯日 | 陇西公承服 | 卯为勾陈，主官府承服 |
| 壬午日 | 断讫 | 螣蛇至壬午日制之 |
| 戊申日 | 徐次宾归家 | 末传申为归计，申乃庚之本位 |

### 徐次宾原析

> 盖庚日课中正是谓螣蛇至壬午日制之，又发用申与白虎俱是七数，二七十四数，彼以己巳日入州，壬午日事毕，盖是十四日也。戊申日予始归，盖末传申为归计，申乃庚之本位，故申日至家也。先锋门为日破主破财，又中传寅为财爻被初末二申制之。传送主姓张人，先锋门午亦主姓张人，案吏姓张，住正南胜光也。占亲人请客亦姓张住西南，传送也。破财二十七数，同前数也。予父经两丁月对问应予命上大吉为父母爻，见天乙主动官也，所居村去州七里，连高阜盖中传寅为东北，为七里建得戊字寅配艮为山得戊寅即阜也，村名黄村，戊土黄也，申数亦七，而只言七里者，伏吟主近故也。

### 逐层解析

#### 1. 课体特征——伏吟

- 庚午日伏吟，四课午午申申
- 古法以申寅巳为三传，徐次宾以申寅申为三传
- 徐次宾云："六庚日伏吟者，古法以申寅巳为三传，又书以申寅申为三传，余尝谓刑始于寅终于申。甲戊丙日当尽三刑，庚日先刑而后冲也。"

#### 2. 先锋门——午时

- 午时为庚日之**破**（庚午破）
- 主破财

#### 3. 三传——申寅申（虎蛇虎）

- 初传申（白虎）：道路、紧速、刑伤
- 中传寅（螣蛇）：妻爻、驿马、惊恐
- 末传申（白虎）：归计、本位

#### 4. 妻到官

- 中传寅为庚日之**妻爻**（寅为庚之财）
- 寅被初末二申所克 → 妻被勾唤到官

#### 5. 姓张人

- 传送（申）主姓张人
- 先锋门午（胜光）亦主姓张人
- 案吏姓张，住正南（胜光午为南）
- 占亲人请客亦姓张，住西南（传送申为西南）

#### 6. 破财二十七数

- 发用申与白虎俱是七数，二七十四
- 中传寅为财爻被初末二申制之
- 破财二十七数

#### 7. 村名黄村

- 所居村去州七里，连高阜
- 中传寅为东北，为七里
- 寅配艮为山，得戊寅即阜
- 村名黄村：戊土黄也

### 伏吟辨——徐次宾的课理创新

徐次宾在六庚日伏吟的取用上提出了自己的见解：

> "六庚日伏吟者，古法以申寅巳为三传，又书以申寅申为三传，余尝谓刑始于寅终于申。甲戊丙日当尽三刑，庚日先刑而后冲也。"

**水论：** 徐次宾认为庚日伏吟应以**申寅申**为三传，而非申寅巳。理由是"庚日先刑而后冲"——申刑寅（无恩刑），寅冲申（寅申冲），刑冲交替。这一见解体现了徐次宾不拘泥于古法、以理为据的治学态度。

### 核心心法总结

**一、同一三传，不同季节，吉凶天壤**

假令一与假令二，三传完全相同（戌申午），但：
- 七月（秋）→ 申金旺克死木 → 死亡
- 正月（春）→ 寅木旺抗金 → 可救

**二、同一正时，不同日辰，事类各异**

假令三与假令四，同一月将（午将）、同一正时（未时），但：
- 乙丑日 → 未时为财 → 承继财产
- 丙寅日 → 未时为子爻 → 酒筵争讼

**三、伏吟课中刑冲交替**

假令五（庚日伏吟）：
- 申寅申三传，刑冲交替
- 徐次宾以"先刑后冲"论之，不拘泥于古法

**四、姓字法的广泛运用**

五则假令中大量运用姓字法：
- 戌临亥 → 王字（假令三、四）
- 传送申 → 张字（假令五）
- 胜光午 → 张字（假令五）

## 经验提炼

### 技法1：同课异断——季节决定旺相休囚

同一课式在不同季节下，旺相休囚不同，吉凶程度不同。这是"人命不同"的延伸——**时间不同，人命亦不同**。

### 技法2：正时定事类——同一正时对不同日干意义不同

同一正时（如未时），对乙木为财，对丙火为子爻。正时的六亲关系决定了占事的大类。

### 技法3：伏吟取用——刑冲交替

庚日伏吟，徐次宾以申寅申为三传，取"先刑后冲"之意。这是对伏吟课体的灵活运用。

### 技法4：亲身经历入课

假令五是《一字诀》中唯一一则徐次宾以第一人称叙述的案例。从中可以看到：
- 徐次宾本人也会遭遇官非
- 课象与事件高度吻合
- 姓字法、数法、方位法综合运用
