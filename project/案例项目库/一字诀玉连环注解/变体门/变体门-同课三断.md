## 案例一：五十四岁戊申生男子

### 基本信息

| 项目 | 内容 |
|------|------|
| 年龄 | 五十四岁 |
| 本命 | 戊申（申命） |
| 行年 | 五十四岁，行年至**未**（申年男命，54岁行年未） |
| 占来意 | 因子在外饮酒过多，胃有宿食，冷气得病 |

### 徐次宾原断

> 盖时为日干六合，支上发用，本命上俱得子孙爻，乘休气，故为子孙病，命上小吉太常为饮食，并发用，戌为脾胃，上得天后水为冷饮，又值事门得白虎为道路，故云因子孙在外饮食，伤脾胃得病，来占。

### 逐层解析

#### 1. 先锋门定调

午时为丁火日干之**六合**（午与未合，丁与壬合，午为丁之合神），主外事和合。但午乘白虎，白虎主道路、疾病，故虽为合而带病象。

#### 2. 年命变体——申命

**申命上神：未（小吉）乘太常**

- 未为丁火之子爻（子孙），乘太常主饮食、酒食
- 未为小吉，主饮食、酒食、宴会
- 未乘休气（巳月未为休气），主过去之事、疾病之事

**行年上神：未（小吉）乘太常**

- 行年与命上同见未，双重饮食之象
- 未为胃（土主脾胃），太常主饮食

#### 3. 发端门——戌（天后）

- 戌为丁火之子爻（子孙），发用主事从子孙起
- 戌为脾胃（土主脾胃），上得天后水为**冷饮**
- 戌为休气（巳月戌为死气，徐次宾以休气论），主疾病

#### 4. 直事门——午（白虎）

- 白虎主道路，故知"在外"
- 白虎主疾病，故知"得病"

#### 5. 完整断课链条

```
申命上见未（子爻+饮食）→ 因子在外饮食
发用戌（子爻+脾胃）→ 伤脾胃
戌上天后水 → 冷饮、冷水
直事门白虎 → 道路、疾病
子爻乘休气 → 子孙有病
```

### 水论

- 申命上神未乘太常，未为丁火之子爻，太常为饮食，故因子在外饮食
- 发用戌为脾胃，天后为冷饮，故"冷气得病"
- 戌为休气，巳月土为死气，徐次宾以"休气"论之，取其"无力"之意
- 白虎临午（直事门），午为道路，故"在外"
- 此课核心：**子爻+饮食+脾胃+冷饮+道路** → 因子在外饮酒冷食伤胃

## 案例二：三十五岁丁卯生男子

### 基本信息

| 项目 | 内容 |
|------|------|
| 年龄 | 三十五岁 |
| 本命 | 丁卯（卯命） |
| 行年 | 三十五岁，行年至**巳**（卯年男命，35岁行年巳） |
| 占来意 | 因在外与二卑下妇人来往，得气痞嗽血之病 |

### 徐次宾原断

> 盖命上见六合为私门，天后主厌翳，中传见太阴主伏匿，天魁从魁主奴婢，上得天后、太阴，故曰与二卑下妇人往来，天后克日、末传玄武又克日，戌酉申俱是日干死墓之乡，丁主心血，故得病嗽血也。

### 逐层解析

#### 1. 年命变体——卯命

**卯命上神：寅（功曹）乘六合**

- 寅为六合之本家，六合为**私门**，主私情、隐匿、和合
- 寅为卯命之禄（卯禄在寅），但寅乘六合，禄入私门
- 寅为功曹，主官吏、文书，但乘六合则主私情

**行年上神：巳（太乙）乘天空**

- 巳为丁火之禄（丁禄在巳），但乘天空主虚诈、不实
- 巳为行年，天空临之，主行年不利

#### 2. 三传阴私之象

| 传位 | 神将 | 象意 |
|------|------|------|
| 初传 | 戌（天后） | 天后主妇人、厌翳、私情 |
| 中传 | 酉（太阴） | 太阴主婢妾、伏匿、阴私 |
| 末传 | 申（玄武） | 玄武主盗贼、隐匿、不正 |

- 戌为天魁主**奴**，酉为从魁主**婢**，故"二卑下妇人"
- 戌乘天后、酉乘太阴，皆阴私之神
- 三传戌酉申，皆为丁火之**死墓之乡**：
  - 戌为丁火之**墓**（火墓在戌）
  - 酉为丁火之**死**（火死在酉）
  - 申为丁火之**病**（火病在申）

#### 3. 克日之象

- 天后（戌）克日干丁（戌土克丁火）
- 玄武（申）克日干丁（申金克丁火）
- 日上白虎（午）亦克日干丁
- 重重克日，病势沉重

#### 4. 嗽血之因

- 丁主**心血**（丁火为心、为血）
- 天后水克丁火 → 水克火 → 心血受伤
- 戌酉申为死墓之乡 → 气血衰败
- 故得"气痞嗽血"之病

### 水论

- 卯命上见六合（私门），与案例一的申命上见太常（饮食）形成鲜明对比——**年命不同，所主的天壤之别**
- 三传戌酉申皆为阴私之神（天后、太阴、玄武），且皆为丁火之死墓病地
- 天后克日、玄武克日、日上白虎克日，三重克日
- 此课核心：**私门+阴私+死墓+克日** → 因与卑下妇人往来致病

## 案例三：八十一岁辛巳生

### 基本信息

| 项目 | 内容 |
|------|------|
| 年龄 | 八十一岁 |
| 本命 | 辛巳（巳命） |
| 行年 | 八十一岁，行年至**亥**（巳年男命，81岁行年亥） |
| 占来意 | 因家中走失奴婢两口，得一姓马人往西南追捕捉获 |

### 徐次宾原断

> 盖发用天魁主奴，从魁主婢，末得元武临门，为窥户，又值事门上见白虎主道路，卦得斩关主逃亡，今年老有官者来占，岂不是奴婢逃亡也。先锋门胜光为今日等辈，又主姓马人克玄武，故捉获，言往西南追捕者，盖元武阴神所居也。

### 逐层解析

#### 1. 年命变体——巳命

**巳命上神：辰（天罡）乘天空**

- 天空主虚诈、走失、逃亡
- 辰为天罡，主奴仆、走失
- 巳命上见辰，辰为巳之**天罗**（巳辰为天罗地网），主困厄

**行年上神：亥（登明）乘朱雀**

- 亥为丁火之官鬼（亥水克丁火）
- 朱雀主口舌、文书、信息
- 行年见亥，主行年有官鬼之扰

#### 2. 斩关逃亡之象

- 发用戌（天魁）主**奴**，中传酉（从魁）主**婢**，故"奴婢两口"
- 末传申（玄武）临门（亥为丁火之门户），为**窥户**，主盗贼、逃亡
- 直事门午（白虎）主道路
- **斩关课**：辰（天罡）临巳（命上），巳为门户，辰破门户为斩关

#### 3. 姓马人追捕

- **先锋门午（胜光）为马**，主姓马人
- 午为丁火之等辈（比和），故为"今日等辈"
- 午克申（玄武），故马姓人能制逃亡之奴婢
- 往西南追捕：**玄武阴神所居**——申（玄武）之阴神为未（小吉），未主西南

#### 4. 年老有官者

- 八十一岁辛巳生，巳命
- 巳为丁火之禄（丁禄在巳），故"有官者"
- 年老占奴婢逃亡，非自身之事，故以奴婢为占

### 水论

- 巳命上见辰（天空），天空主走失、逃亡，与案例一的申命上见未（太常饮食）、案例二的卯命上见寅（六合私门）截然不同
- 发用戌（奴）+ 中传酉（婢）= 奴婢两口
- 末传玄武临门 = 逃亡
- 先锋门午（马）= 姓马人
- 此课核心：**奴婢+逃亡+斩关+马姓追捕** → 家中走失奴婢被马姓人追回

## 年命变体核心心法

### 同一课式，三断天壤

| 维度 | 案例一（戊申生） | 案例二（丁卯生） | 案例三（辛巳生） |
|------|------------------|------------------|------------------|
| 本命 | 申 | 卯 | 巳 |
| 命上神 | 未（太常） | 寅（六合） | 辰（天空） |
| 命上象意 | 饮食、酒食 | 私门、私情 | 走失、逃亡 |
| 占事 | 子孙病 | 自身病 | 奴婢逃亡 |
| 病因/事因 | 饮食伤胃 | 阴私伤身 | 奴婢逃亡 |
| 三传作用 | 子爻+饮食 | 阴私+克日 | 奴婢+逃亡 |

### 变体门心法要诀

**一、年命上神定基调**

同一课式，年命不同则命上神不同。命上神是变体门的核心——**命上见什么神将，就主什么事**。

- 申命上见未（太常）→ 饮食之事
- 卯命上见寅（六合）→ 私情之事
- 巳命上见辰（天空）→ 走失之事

**二、年命与三传的呼应**

三传是课体的"公共信息"，但年命决定了这些公共信息如何作用于占人：

- 三传戌酉申（子爻+财+财），申命取其"子爻+饮食"（戌为子爻，未为饮食）
- 三传戌酉申（天后+太阴+玄武），卯命取其"阴私+克日"（天后太阴为阴私，玄武克日）
- 三传戌酉申（奴+婢+逃亡），巳命取其"奴婢+逃亡"（戌为奴、酉为婢、玄武为逃亡）

**三、行年与命上互参**

行年与命上神共同构成年命体系：

- 案例一：命上未（太常）+ 行年未（太常）= 双重饮食
- 案例二：命上寅（六合）+ 行年巳（天空）= 私情败露
- 案例三：命上辰（天空）+ 行年亥（朱雀）= 逃亡有信

**四、先锋门与年命的配合**

先锋门午（白虎/胜光）在不同年命下意义不同：

- 案例一：午为白虎主道路 → 因子在外
- 案例二：午为白虎主疾病 → 自身得病
- 案例三：午为胜光主马 → 姓马人追捕

### 变体门与八门的关系

变体门是八门中的最高层次，它不独立运作，而是**统摄前七门**：

```
先锋门（正时）→ 定大方向
直事门（天盘正时）→ 定路径
外事门（日干）→ 定外事
内事门（日支）→ 定内事
发端门（初传）→ 定事始
移易门（中传）→ 定事中
归计门（末传）→ 定事终
变体门（年命）→ 定人事
```

**前七门是"课体"的公共信息，变体门是"人"的个性化信息。** 同一课体，不同年命，所取用的公共信息不同——这就是"变体"二字的真义。

## 经验提炼

### 技法1：年命上神直读法

年命上神是变体门的第一切入点。命上见什么神将，直接决定占事的性质：
- 命上见太常 → 饮食、酒食、宴会
- 命上见六合 → 私情、和合、婚姻
- 命上见天空 → 走失、虚诈、逃亡
- 命上见白虎 → 疾病、道路、死亡
- 命上见天后 → 妇人、阴私、厌翳

### 技法2：三传取用因年命而异

同一三传，不同年命取用不同：
- 戌：可作子爻（案例一）、可作奴仆（案例三）、可作墓库（案例二）
- 酉：可作财（案例一）、可作婢（案例三）、可作死地（案例二）
- 申：可作财（案例一）、可作玄武贼（案例三）、可作病地（案例二）

**取用的依据是年命上神所指向的占事方向。**

### 技法3：年命与五行生克

年命与日干的五行关系，决定了占事对占人的影响程度：
- 申命（金）生丁火（日干）→ 案例一中申命为子爻，因子得病
- 卯命（木）生丁火（日干）→ 案例二中卯命为印，自身得病
- 巳命（火）与丁火（日干）比和 → 案例三中巳命为等辈，奴婢之事

### 技法4：行年与命上呼应

行年与命上神的关系，决定了事态的发展趋势：
- 命上神与行年上神相同 → 事态集中、力量加倍（案例一）
- 命上神与行年上神相克 → 事态矛盾、内外不一（案例二）
- 命上神与行年上神相生 → 事态顺畅、有始有终（案例三）

## 与古籍对照

### 与《六壬大全》对照

《六壬大全·变体门》云："变体门者，人命之事也。谓四课虽同时而人命不同，以人命所见神将各异，故变其卦体，所主灾福亦不同。"

徐次宾的丁亥日三案例，正是对这段话的完美诠释——同一课式（四课同时），因年命不同（戊申/丁卯/辛巳），命上神各异（未/寅/辰），所主灾福天壤之别。

### 与《邵彦和断案》对照

邵彦和断案中大量运用年命变体。如邵案中"同一课而三断"的案例，与徐次宾的丁亥日三案例如出一辙。邵彦和云："课虽同而人不同，人虽同而命不同，命虽同而年不同，故所主各异。"

徐次宾继承并发展了邵彦和的年命变体思想，将其系统化为"变体门"，成为《一字诀》八门中的最高层次。

### 与《六壬心镜》对照

《心镜》论年命："年命上神为根本，吉凶先向此中寻。"徐次宾的变体门正是以年命上神为根本——命上见太常则饮食、见六合则私情、见天空则走失。

## 水论总结

徐次宾先生为了让我们理解720课结构相似但是人不同必然所主不同。一课方向很多已知要素帮助我们排除不需要的方向是为**年命变体**。

**变体门的本质**：课体是"天"，年命是"人"。天道有常（同一课式），人事无常（年命各异）。变体门就是"天道"与"人事"的交汇点——以天道为体，以人事为用。

**学习变体门的关键**：不要死记课式，而要理解年命如何"变"出不同的占事。同一课式，年命不同则命上神不同，命上神不同则取用的三传信息不同，取用的信息不同则断语天壤之别。

**变体门的最高境界**：见课不见人，非真断课也。见人不见课，亦非真断课也。课人合一，方为真断。
