# 章八：时为日空亡（主望空用事或无用）

## 徐次宾原文

**规则条文：**

1. 空亡者，十干不到之处，为虚气无象也。
2. 若用时神、正时得之，主占无用事，或虚诈之事。
3. 若式中见三合六合、龙常后合，主虚望喜事不成。
4. 惟病讼门以空亡为最吉。
5. 凡占事见空亡，事必过旬而成。
6. 凡占失物，其类落空亡者，不能得其物。占失奴仆，天魁落空亡，其奴仆亦不能捕矣。
7. 如日支干落空带鬼者，主相争之人不足畏。
8. 如今日落空亡，虽三传为鬼，上挟凶神而欲相害我，既在空，彼不得见，将与谁争？
9. 空亡中见太阴，多是虚诈设谋，见玄武是盗贼窥财。

## 假令案例

**案例：甲戌日辰将未时（戊戌人占）**

**四值：** 戌年 酉月 甲戌日 未时（辰将）

**课式：**

```
    辰将  未时
    甲戌日（戊戌人占）
    
    白  勾  蛇
    申  巳  寅
    
    巳  寅  申  巳
    戌  未  戌  未
    
    四课：
    巳  申  戌  巳
    甲  戌  戌  未
    
    三传：申（白）→ 巳（勾）→ 寅（蛇）
```

**断语：** 七月中劝和公事到官，以所得财物检法拟定徒罪。上申至来年正月文字来只得杖罪，以寄作月日相折无事。

**徐次宾析：**
- 时干日干财并日贵
- 发用申为日空，上带白虎又为日刑，始末俱凶主重刑
- 但直事门得天空，发用二传临空亡，不能解散而只言拟定
- 白虎秋正旺，故拟定徒罪
- 至来年正月建丙寅，白虎至寅死绝，又旺火所制共为救神
- 又卦时本是空亡，故正月无事而出

**水的注解：**
- 正时门在未是外事门之墓，主昏迷
- 是外事门之财，主财事
- 是帘幕贵人，主官
- 课得玄胎，三传具刑，发端官来刑我，必主因财得讼
- 申得空，巳勾也空，但申金在八月旺气仍会定罪
- 寅月申金绝地——《玉连环》环环相扣循环不止

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论空亡："空亡者，旬中空亡也。在天曰寡宿，在地曰孤辰。吉凶相反，克我害我刑我劫我泄我皆要空，生我扶我救我者不可空。"

章八的规则与此完全一致：
- "惟病讼门以空亡为最吉"——克我者空则吉
- "日支干落空带鬼者，主相争之人不足畏"——鬼空则无害
- "如今日落空亡，虽三传为鬼……彼不得见，将与谁争"——鬼空则不能为害

《六壬大全·毕法赋》"喜惧空亡乃妙机"——空亡的妙处在于：凶神空则喜，吉神空则惧。章八假令中，白虎（凶神）在申为空，但八月申金旺相，故"拟定徒罪"（凶事仍在），至寅月白虎死绝方无事——这正是"喜惧空亡"的灵活运用：空亡不等于全无，旺相之空仍有其力。

《六壬大全》论"踏脚空亡进用宜"——初传空亡，但中末不空，可进用。章八假令中，初传申空，中传巳空，末传寅不空，正是"脚踏空亡"之格。

### 2. 与《心镜》对照

《心镜》云："空亡发用事无成，忧喜皆空总不真。托人多诈闻事假，出旬方可望为真。"此与章八"主占无用事，或虚诈之事""事必过旬而成"完全对应。

《心镜》又云："病讼逢空最是奇，凶神恶煞尽推移。若还吉神临空位，喜事翻成一场虚。"——病讼逢空最吉，吉神逢空反虚。章八"惟病讼门以空亡为最吉"正源于此。

《心镜》论失物："类神空亡物难寻，纵有踪迹也消沉。"章八"占失物其类落空亡者，不能得其物"与此一致。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论空亡极为详尽：

- "用神空亡，忧喜俱不成，托人多诈，闻事不实"——对应章八"主虚诈之事"
- "三传俱空，则百无一实"——对应章八"望空用事"
- "末空，谓之传入空亡，吉凶到后，皆无实际"——对应章八"事必过旬而成"
- "鬼陷空亡，不能为害"——对应章八"相争之人不足畏"
- "空亡中见太阴，多是虚诈设谋"——章八直接引用

《六壬直指》论甲戌日课（辰将未时）：
- "申为日空，上带白虎，又为日刑"——与徐次宾析一致
- "白虎秋正旺，故拟定徒罪"——旺相之空，仍有其力
- "至来年正月建丙寅，白虎至寅死绝"——寅月申金绝地，凶神无力

《六壬直指》论"虎乘遁鬼殃非浅"——白虎乘遁鬼，凶祸极重。但若虎鬼落空亡，则"目前有灾，后却无畏"。章八假令正是此理：八月白虎旺相故有徒罪之拟，但申为空亡，故最终只杖罪而非实徒。

### 4. 核心技法解锁

**技法一：空亡的虚实转化**

空亡不是简单的"无"，而是"虚气无象"——有象而无形，有声而无实。章八揭示了空亡的四种状态：

1. **旺相之空**：如八月申金，虽空但旺相，仍有其力（拟定徒罪）
2. **休囚之空**：如寅月申金，死绝之地，全无其力（无事而出）
3. **空亡+凶神**：凶神空则吉（鬼不足畏）
4. **空亡+吉神**：吉神空则虚（喜事不成）

**技法二：空亡的应期**

"凡占事见空亡，事必过旬而成"——空亡的应期规律：
- 旬空之事，出旬可成
- 旺相之空，待填实之时
- 休囚之空，待生旺之时

章八假令中，申空至寅月（申之绝地）方了结，正是空亡应期的典型案例。

**技法三：空亡在病讼中的妙用**

"惟病讼门以空亡为最吉"——这是空亡技法中最重要的变通：
- 病占：鬼空则病愈，墓空则不死
- 讼占：官鬼空则罪轻，刑害空则免刑
- 鬼空：彼不得见，将与谁争

**技法四：空亡+太阴/玄武的细化**

"空亡中见太阴，多是虚诈设谋；见玄武是盗贼窥财"——空亡与其他神将的组合判断：
- 空+太阴：虚诈设谋（阴私之谋，空而不实）
- 空+玄武：盗贼窥财（盗贼之象，但空则不得）

## 技法提炼

- **技法1：空亡四态法**——旺相之空仍有其力，休囚之空全无其用，凶神空则吉，吉神空则虚
- **技法2：空亡应期法**——旬空出旬可成，旺空待填实，休空待生旺
- **技法3：病讼空亡吉法**——病讼逢空亡最吉，鬼空则病愈罪轻
- **技法4：空亡+神将组合法**——空+太阴=虚诈设谋，空+玄武=盗贼窥财
- **技法5：脚踏空亡进用法**——初传空但中末不空，可进用；凶事空则宜进，吉事空则宜退
