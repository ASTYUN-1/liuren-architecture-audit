# 章七：时为日支六害（主内忧）

## 徐次宾原文

**规则条文：**

辰为阴主内事，时既害之，定主内忧。

1. 若见玄武、六合临门，防盗贼窥财、婢妾蒙蔽而为内忧。
2. 若螣蛇临门，主家室不宁，更变迁徒而主内忧。
3. 若式中见白虎乘休囚之气，必主家内有人患病。
4. 若临子便是属鼠人病。若六害上见天空或落空亡，虚忧不成。
5. 若阴人占，式中见子孙爻，或嗣部上带螣蛇，主因身孕而有惊忧。
6. 若男子占，必因子孙而致忧也。

## 假令案例

**案例：庚子日卯将未时（甲子阴人占）**

**四值：** 亥月 庚子日 未时（卯将）

**课式：**

```
    卯将  未时
    庚子日（甲子阴人占）
    
    蛇  青  玄
    子  申  辰
    
    辰  申  子
    申  子  辰
    
    四课：
    子  辰  申  子
    庚  子  申  子
    
    三传：子（蛇）→ 申（青）→ 辰（玄）
```

**断语：** 三月胎气不安而有惊恐，至十一月喜见生子，子母俱庆。

**徐次宾析：**
- 发用起神后为今日子孙，上见螣蛇为日下鬼，下临辰墓而为三月，故胎气不安
- 至十一月见喜生男：中传送为嗣，上得青龙吉庆，下临子
- 天罡所系与日比阳，三传日辰俱阳，故生男
- 子母俱庆：三传与日辰三合，虽有螣蛇克日，卦得润下，日上有玄武水乘旺相气为救神

**水的注解：**
- 未时作日支六害，是宅内有忧虑的象
- 发用子水为子爻，年命子也为子爻
- 出生时月：子下临辰又作螣蛇，主三月惊恐
- 十一月生子：申龙为子
- 生男生女：课得不备课，阴不备则生男；润下课为水坎卦则生男；胎爻为卯则生男——多象并临

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论支辰："辰为阴主内事"，章七以时害日支定内忧，正合此理。日支为宅、为家、为内事，时来害支，则家宅不宁、内事有忧。

《六壬大全·毕法赋》"彼此猜忌害相随"同样适用于此，但章七将六害的焦点从"日干"（外事）转向"日支"（内事），体现了《一字诀玉连环》"时与日干/日支"的二分法体系。

《六壬大全》论"支乘墓虎有伏尸"——支上见墓神乘白虎，主宅中有伏尸为祸。章七"白虎乘休囚之气，主家内有人患病"与此相通，但更强调休囚之气（病气）而非旺气。

《六壬大全》论"胎神生气妻怀孕，胎财死气损胎推"——章七假令中，子为子孙爻，下临辰墓（三月），螣蛇为惊，正是胎气不安之象。至十一月申为传送，青龙为吉庆，应生子之喜。

### 2. 与《心镜》对照

《心镜》云："六害加辰宅不宁，阴小灾殃病缠身。玄武临门防盗贼，螣蛇绕宅有虚惊。"此与章七"玄武六合临门防盗贼""螣蛇临门主家室不宁"完全对应。

《心镜》又云："白虎乘休囚死气，家中必有病伤人。"章七"白虎乘休囚之气，主家内有人患病"直接引用此意。

《心镜》论胎产："子孙爻上见螣蛇，胎孕惊忧不是差。"章七"阴人占见子孙爻或嗣部上带螣蛇，主因身孕而有惊忧"与此一致。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论六害加支：
- "支乘六害，宅亦虚危"——支上见六害，家宅不安
- "干支上神六害，人宅不宁"——人宅俱不安
- "子未六害，宅必颓坏"——具体害象

《六壬直指》论润下课（三传子申辰）：
- "润下生干克支，恐子孙不利"——但章七假令中，润下反为吉，因日上有玄武水乘旺相为救神，螣蛇虽克日而有救
- 三传与日辰三合（子申辰合水局），故子母俱庆

《六壬直指》论生男生女之法：
- "三传日辰俱阳，故生男"——与徐次宾析一致
- "阳支包阴，产必生女；阴支包阳，产必生男"——章七假令中，课得不备课，阴不备则生男

### 4. 核心技法解锁

**技法一：时害日支定内忧**

章七的核心技法：**以正时与日支的六害关系，判断家宅内事之忧**。日支为辰、为宅、为内事，时来害之，则内事不宁。

六害加支的细化判断：
- 玄武/六合临门 → 防盗贼、婢妾蒙蔽
- 螣蛇临门 → 家室不宁、迁徒
- 白虎乘休囚 → 家内有人患病
- 天空或空亡 → 虚忧不成

**技法二：胎产占断体系**

章七假令展示了完整的胎产占断体系：

1. **胎气不安的判断**：发用子为子孙爻，上见螣蛇（惊），下临辰墓（三月）
2. **生产时间的判断**：中传申为传送，青龙为吉庆，应十一月
3. **生男生女的判断**：
   - 三传日辰俱阳 → 生男
   - 课得不备课，阴不备 → 生男
   - 润下课为水坎卦 → 生男
   - 胎爻为卯 → 生男
4. **母子平安的判断**：三传与日辰三合，虽有螣蛇克日，但日上有玄武水乘旺相为救神

**技法三：六害+空亡的虚实转化**

"六害上见天空或落空亡，虚忧不成"——这是六害技法中的重要变通：六害虽主忧，但若落空亡或见天空，则虚忧不成，有惊无险。这与《毕法》"喜惧空亡乃妙机"相通。

## 技法提炼

- **技法1：时害日支定内忧法**——正时与日支六害，主家宅内事之忧，结合临门神将细化判断
- **技法2：胎产占断四步法**——①子孙爻+螣蛇=胎惊 ②下临辰墓=月份 ③传送青龙=生产时间 ④三传日辰阴阳=男女
- **技法3：六害+空亡化解法**——六害见天空或落空亡，虚忧不成，凶中有救
- **技法4：润下三合救应法**——三传与日辰三合（水局），虽有凶将克日，但日上得旺相救神，可化险为夷
