# 章九：时为日墓（主干田土或他人茔坟事）

## 徐次宾原文

**规则条文：**

1. 四季者五行所终万物所归，故曰墓也。
2. 若正月时得之，更在用传，定主坟墓之事。
3. 或式中带鬼与凶将并，定是坟墓争讼。
4. 若见财神旺气不落空亡，主得坟墓占窖之财。
5. 用传俱土，虽不见墓神亦可言坟墓事。
6. 有天马六丁者则为游子之卦，若水日占之众土乘旺则是与家人相争。
7. 若木日得之则为动众之财，若墓神临日辰占病见之最为凶象。

## 假令案例

**案例：己丑日巳将辰时**

**四值：** 申月 己丑日 辰时（巳将）

**课式：**

```
    巳将  辰时
    己丑日
    
    朱  六  勾
    寅  卯  辰
    
    卯  辰  寅  卯
    丑  寅  丑  寅
    
    四课：
    卯  寅  丑  寅
    己  丑  丑  寅
    
    三传：寅（朱）→ 卯（六）→ 辰（勾）
```

**断语：** 正月间与一姓杜人争田土。一姓蔺人与姓杜人挟势相助，却得一姓张贵人力。七月间务了毕。

**徐次宾析：**
- 时为日墓，直事门见勾陈，故争田土
- 发用寅木与丑土为杜字
- 中传卯为门，六合为草头，临寅为隹字，为蔺
- 日上得传送为今日贵人，上得太常吉将
- 寅卯二木，传送为弓为道为张字
- 七月建申，故七月毕

**水的注解：**
- 正时辰时为外事门之墓，主外动土事
- 发端门在内事得寅作朱雀，则不论官只论与人相争
- 申贵人不论落空，因为贵人临日，三会木局日得，与空"彼不见我与谁争"
- 申又是子孙救神，所以得力
- 课体得进连茹，主进程迅速顺畅

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论墓："墓者，蒙蔽之煞也。五行潜伏之地，四时死绝衰败之乡，闭塞不通，幽暗不振。凡占得墓不吉，逢墓即止。"

章九论墓，但并非全凶——"若见财神旺气不落空亡，主得坟墓占窖之财"，墓中亦有财。这与《六壬大全》"墓加长生旧事再发""生旺入墓事成中止"的辩证观一致。

《六壬大全》论"干支乘墓各昏迷"——日上得日墓，辰上得辰墓，人宅俱不利。章九"墓神临日辰占病见之最为凶象"正合此理。

《六壬大全》论"墓门开"——"墓乘蛇虎加卯酉与行年并为墓门开也。如日墓加卯为外丧，辰墓加卯为内丧。"章九"正月时得之更在用传，定主坟墓之事"，正是墓神发用的典型判断。

《六壬大全》论"用传俱土，虽不见墓神亦可言坟墓事"——土为五行之墓库，用传俱土则事涉坟墓。此是《一字诀》的独特发挥。

### 2. 与《心镜》对照

《心镜》云："墓神加日事昏迷，病者难痊灾可悲。若在传中为用起，坟茔田土定须知。"此与章九"时为日墓主干田土或他人茔坟事"完全对应。

《心镜》又云："墓神发用事多迟，田土坟茔不可移。若带鬼神来克日，争讼纷纷定不疑。"——墓神发用带鬼，定主坟墓争讼。章九"式中带鬼与凶将并，定是坟墓争讼"正源于此。

《心镜》论"游子卦"："天马六丁游子卦，身动千里不还家。"章九"有天马六丁者则为游子之卦"引用此意。

### 3. 与《六壬直指御定》对照

《六壬直指御定》论墓：
- "日墓临支，宅有伏尸"——墓临支上，宅中有伏尸之患
- "墓神覆日，占身则昏滞，占病则沉困"——墓覆日干，病重难愈
- "传墓入墓，自明投暗，如人下井"——墓在传中，事多暗滞

《六壬直指》论己丑日课：
- "用传俱土，虽不见墓神亦可言坟墓事"——与徐次宾析一致
- 三传寅卯辰为进连茹，主事进程迅速
- 日上申为贵人，虽落空但临日，故不为空

《六壬直指》论"进连茹"："寅卯辰为升阶，亲观光于上国"——进连茹主事顺遂、进展迅速。章九假令中，正月争田土，七月了毕，半年内解决，正是进连茹之速。

### 4. 核心技法解锁

**技法一：墓神定田土坟茔**

章九的核心技法：**以正时为日墓，判断田土、坟墓之事**。墓为五行归宿，时入墓则事涉归宿之地——田土、坟茔。

细化判断：
- 墓+鬼+凶将 → 坟墓争讼
- 墓+财神旺气 → 得坟墓占窖之财
- 用传俱土 → 虽不见墓神亦可言坟墓事
- 墓临日辰占病 → 最为凶象

**技法二：墓神+神将的字象拆解**

章九假令展示了六壬字象拆解的高超技法：
- 寅木 + 丑土 = "杜"字（木+土）
- 卯为门 + 六合为草头 + 寅为隹 = "蔺"字
- 传送（申）为弓为道 + 张字

这是六壬"射覆"技法的延伸——通过神将的象意组合，拆解出具体的人名、地名。

**技法三：墓神与空亡的辩证**

章九假令中，日上申贵人落空亡，但水论指出"申贵人不论落空，因为贵人临日，三会木局日得，与空'彼不见我与谁争'"——这是对章八空亡技法的呼应：贵人空而临日，且三会木局，故不为空。墓神虽主暗滞，但得贵人救应，事终可成。

**技法四：进连茹的应期**

三传寅卯辰为进连茹，主事进程迅速。正月争讼，七月了毕，半年内解决。进连茹的应期规律：
- 顺进连茹：事速成
- 逆退连茹：事迟滞
- 间传连茹：事有间隔

## 技法提炼

- **技法1：墓神定田土坟茔法**——正时为日墓，主干田土、坟墓之事；墓+鬼+凶将=争讼，墓+财神旺气=得财
- **技法2：用传俱土定墓事法**——三传俱土，虽不见墓神亦可言坟墓事
- **技法3：字象拆解法**——通过神将象意组合拆解人名（杜=木+土，蔺=草头+门+隹，张=弓+长）
- **技法4：墓神+贵人救应法**——墓神虽主暗滞，但得贵人临日救应，事终可成
- **技法5：进连茹应期法**——顺进连茹主事速成，应期缩短
