# 章六：时为日干六害（主外忧）

## 徐次宾原文

**规则条文：**

十二辰横为六合，纵为六害，若时与日干六害者，为刑害之象，故主外忧也。

1. 若壬丙二日时为六害者，主因尊亲人挟势相害而有外忧也。（壬日在亥害为申，丙日在巳害为寅，皆长生作父母尊长）
2. 乙辛二日时为六害者，主因兄弟等辈在外相害。（乙日在辰害卯，辛日在戌害酉，皆兄弟）
3. 庚甲二日时为六害，主幼小人相害。（庚在申害亥，甲在寅害巳，皆子孙）
4. 癸己二日时为六害者，主因外财而有忧。（癸在丑害午，己在未害子，皆妻财）
5. 若丁日得之，主北面有破损之忧。戊日得之，惧攻劫战伤之祸。（丁在未害子，戊在巳害寅，皆官鬼）

## 假令案例

**案例：癸丑日巳将午时**

**四值：** 申月 癸丑日 午时（巳将）

**课式：**

```
    巳将  午时
    癸丑日
    
    勾  龙  空
    丑  子  亥
    
    亥  子  丑
    子  丑  寅
    
    四课：
    丑  亥  子  戌
    癸  丑  子  亥
    
    三传：丑（勾）→ 子（龙）→ 亥（空）
```

**断语：** 因丑时三人巡更，与地方中姓马人相争。来日申时到官。因一姓孙司吏为鬼，三人并遭杖责。

**徐次宾析：**
- 发用大吉为今日丑时
- 癸水与子亥等辈为三人
- 直事门胜光（午）为姓马人，又为日下之财与日为六害
- 发用勾陈为鬼
- 大吉为纽系，中传神后与子相配成孙字
- 勾陈为杖棒

**水的注解：**
- 正时门午作道路，又为日干之财，又为丑之害
- 值事门天后主阴私事
- 丑时为夜晚人事，主夜巡
- 勾陈与丑皆是克日干与亥子
- 勾陈主牢狱神，所以会受刑罚
- 末传天空万事皆休，但克日所以不为解散，而是同时受罚

## AI解析

### 1. 与《六壬大全》课经对照

《六壬大全》论六害云："害者，阻也，滞也，妒也。事多阻隔，彼此猜忌。"六害之象，主事有阻隔、猜忌、暗算。章六所论"时为日干六害"，正是以正时与日干的关系定外忧之来源。

《六壬大全·毕法赋》有"彼此猜忌害相随"之句，正对应此章。毕法云："干支上神作六害，主彼此各相猜忌。"章六进一步细化：不同天干遇六害，所害之人不同——壬丙为父母尊长，乙辛为兄弟，庚甲为子孙，癸己为妻财，丁戊为官鬼。这是将六害与六亲体系结合，精准定位外忧的来源对象。

《六壬大全》论"害贵讼直遭屈断"——若贵人被六害所伤，有理也遭屈断。此章虽未直接论贵人，但午时为癸日之财又为六害，财被害则因财致祸，与"害贵"之理相通。

### 2. 与《心镜》对照

《心镜》云："六害相逢事未宁，各怀猜忌不相亲。若还日上逢斯煞，外扰频来不暂停。"此与章六"主外忧"完全吻合。

《心镜》又云："三刑六害同传日，蛇虎疾病朱官方。"章六假令中发用勾陈（官符之神），正应"朱官方"之象。勾陈为官讼、牢狱，与断语"到官""杖责"相应。

### 3. 与《六壬直指御定》对照

《六壬直指御定》多处论六害：

- "干支上神作六害，主彼此各相猜忌"——对应章六"外忧"之本质
- "子未六害，而又空亡，则所主者，孤寒也"——六害加空亡，事更虚而不实
- "交互六害，各怀驵侩"——彼此皆有害心

《六壬直指》中"丑午六害"之例与章六假令直接对应。丑午害，午为日财，故因财致祸。丑为勾陈，主官讼牢狱，与断语"杖责"吻合。

### 4. 核心技法解锁

**技法一：六害定外忧来源**

六害的本质是"纵为害"——纵向的不和谐关系。章六的核心技法在于：**以正时与日干的六害关系，结合六亲体系，定位外忧的来源对象**。

六害配六亲的规则：
| 日干 | 害神 | 六亲关系 | 外忧来源 |
|------|------|----------|----------|
| 壬/丙 | 申/寅 | 父母（长生） | 尊亲长辈 |
| 乙/辛 | 卯/酉 | 兄弟 | 同辈兄弟 |
| 庚/甲 | 亥/巳 | 子孙 | 幼辈小人 |
| 癸/己 | 午/子 | 妻财 | 外财之事 |
| 丁/戊 | 子/寅 | 官鬼 | 官非破损 |

**技法二：发用与正时的配合**

章六假令中，发用丑（正时）与日干癸的六害关系，结合勾陈（官符）与亥子（三人数），构成完整的断课链条：
- 正时午为日财→因财
- 午与丑害→财被害
- 发用丑为勾陈→官讼
- 亥子为三人→三人同案

**技法三：十二辰横合纵害的方位体系**

"十二辰横为六合，纵为六害"——这是理解六害空间关系的钥匙。横为合（子丑合、寅亥合等），纵为害（子未害、丑午害等）。六害是六合的"破坏面"，代表关系中不和谐、互相伤害的一面。

## 技法提炼

- **技法1：六害配六亲定位法**——根据日干与正时的六害关系，结合六亲体系，精准定位外忧来源（尊长/兄弟/子孙/妻财/官鬼）
- **技法2：发用+正时双参断**——正时定事因（六害），发用定事体（神将），二者结合断吉凶细节
- **技法3：横合纵害空间法**——十二辰横为六合（和谐关系），纵为六害（破坏关系），六害是六合的破坏面
- **技法4：六害+凶将加重法**——六害本身已主不吉，若再乘勾陈（官讼）、白虎（灾祸）、螣蛇（惊扰）等凶将，则事态更严重
