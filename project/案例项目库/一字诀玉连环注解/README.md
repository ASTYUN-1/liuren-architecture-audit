# 一字诀玉连环注解

## 概述

《一字诀玉连环》是**宋代徐次宾（庐溪）** 所撰的六壬经典，以 **"正时入手法"** 为核心方法论，通过分析占时与日干的15种关系（财/马/贵/合/害/空/墓/冲/刑/劫/破等），构建了一套完整的断课体系。

**水** 在笔记后半部分（行3912-5101）逐章抄录了《一字诀玉连环》全文，并以"水论"形式加入了大量实战注解——这是全笔记中最精华、最有深度的一部分。

## 《一字诀》核心思想

> **"凡占一课，八门之内须要消息详审，择其精要而断之。"**

徐次宾立的"八门"理论：
| 八门 | 对应 | 含义 |
|------|------|------|
| **先锋门** | 所占正时 | 不待运式而先有所主——**入手法** |
| **直事门** | 正时天官 | 天上正时直事——**基调** |
| **外事门** | 日干 | 日为阳为尊为外事 |
| **内事门** | 日支（辰） | 辰为阴为卑为宅为内事 |
| **发端门** | 初传 | 灾福发用之端——**事之始** |
| **移易门** | 中传 | 凶可移吉，吉可移凶——**事之变** |
| **归计门** | 末传 | 事之结局——**终** |
| **变体门** | 年命 | 人命不同则卦体变——**关键变量** |

## 水的注解亮点

- **转类象法**：未是药师→主药，卯为乐师→主音，丑是长者→主旧——"象不能独论，必有所主"
- **鬼不受害三法**：鬼得旬空 / 鬼下被地盘克 / 四课三传有子孙为救
- **年命定气势法**：年命定完气势在课体中转换掉以他论——锚定坐标系的转换
- **丁马法**：水日为财，金日为官，火日为兄弟，木日为子孙，土日为长辈
- **驿马vs天马vs丁马**：驿马主快近，天马主远慢，丁马身不由己
- **生男生女多象并临法**：不备课阴阳 / 课体卦象 / 胎爻 三者合参
