# 案例元数据规范

本库所有案例文件需在**文件第一行**添加 `<!-- META: -->` 标签行，便于 AI 通过 grep 精确检索和课式指纹匹配。

## 标准格式

每个案例文件的第一行必须是 META 标签行：

```markdown
<!-- META: 占类=考试占 | 编号=case-001 | 课体=反吟,三交,二烦,斫轮 | 发用=卯(天空) | 三传=卯酉卯 | 日干=丁 | 反馈=验 | 技法=魁星格, 格压倒象, 行年朱雀 -->
```

META 标签行之后，紧跟案例正文（标题、四柱、课式、断语、反馈等）。

## 字段说明

| 字段 | 必填 | 格式 | 说明 |
|------|:---:|------|------|
| `占类` | 是 | 考试占 / 事业占 / 感情占 / 疾病占 / 来意占 / 交易占 / 灾厄占 / 失物占 / 胎产占 / 官讼占 / 比赛占 / 宅门占 / 天时占 / 出行占 / 射覆占 / 杂事占 | 分类目录名 |
| `编号` | 是 | case-NNN | 目录内唯一编号 |
| `课体` | 是 | 逗号分隔，如 `反吟,三交,二烦` | 所有课体名称 |
| `发用` | 是 | 地支(天将)，如 `卯(天空)` | 初传地支+天将 |
| `三传` | 是 | 三地支连写，如 `卯酉卯` | 初传中传末传 |
| `日干` | 是 | 甲/乙/丙/丁/戊/己/庚/辛/壬/癸 | 日干五行 |
| `反馈` | 是 | 验 / 部分验 / 不验 | 验证结果 |
| `技法` | 推荐 | 逗号分隔，如 `魁星格, 格压倒象` | 核心技法标签 |

### ⚠️ `编号` 字段的实际归属（2026-09-16 核验修订）

**`编号` 是「索引专有字段」，不是源文件字段。** 实测：

| 对象 | 是否在文件首行 META 里写 `编号=` | 说明 |
|---|:--:|---|
| `case-*.md`（169 个） | ❌ 167/169 未写 | 索引中的 `编号` 由**文件名前缀** `case-NNN` 派生 |
| 古籍注解文件（18 个） | ❌ 15/18 未写 | 索引按 `章一`…`章十五` 顺序号占位；3 个专题文件已补 |

⇒ **检索与同步核对时，案例一律以「目录名 + 文件名 `case-NNN`」作为键**，不得依赖文件内 `编号`；
⇒ 新增案例**无需**在文件里手写 `编号`，只需保证文件名形如 `case-NNN-描述.md`；
⇒ 本节修订前的旧表述（"`编号` 是文件必填字段"）与实测不符，已作废。

## grep 搜索示例

```bash
# 按占类搜索
grep "^<!-- META:.*占类=考试占" 案例项目库/**/*.md

# 按课体搜索
grep "^<!-- META:.*课体=.*反吟" 案例项目库/**/*.md

# 按发用搜索
grep "^<!-- META:.*发用=卯(天空)" 案例项目库/**/*.md

# 按反馈搜索（仅已验证）
grep "^<!-- META:.*反馈=验" 案例项目库/**/*.md

# 组合搜索（占类+课体）
grep "^<!-- META:.*占类=事业占.*课体=涉害" 案例项目库/**/*.md

# 按技法搜索
grep "^<!-- META:.*技法=.*魁星格" 案例项目库/**/*.md
```

## 与 `_metadata_index.md` 的关系

| 文件 | 用途 | 格式 |
|------|------|------|
| `_metadata_index.md` | 集中索引，快速扫描匹配 | 每条一行 `<!-- META: -->` + 表格行 |
| 各案例文件 | 完整案例内容 | 第一行 `<!-- META: -->` + 正文 |

**调用流程**：先 grep `_metadata_index.md` 快速定位匹配案例编号 → 再读取对应案例文件的完整内容。

## 旧版迁移

旧版使用 YAML frontmatter（`---...---`）格式，与 grep 不兼容。如需迁移旧案例，使用 `liuren-extract` 子智能体的"重整模式"自动转换。
