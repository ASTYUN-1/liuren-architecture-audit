# 戌女占戌男今晚是否提分手

## 课式数据
- 公历：2026-05-25 11:45
- 四柱：丙午 癸巳 己亥 庚午
- 月将：申
- 课体：涉害，间传，见机，出产
- 四课：酉(六合) 亥(腾蛇) 丑(天后) 卯(玄武)
- 三传：丑(天后) → 卯(玄武) → 巳(白虎○空亡)
- 旬空：辰巳（甲午旬）
- 贵人：逆行（子/申）

## 核心断语
戌男会提分手，且凌晨确认分手（出户格+官鬼发用+初传月破），但分手不是最终结局——末传白虎空亡，凶不成。后男方求复合，关系恢复。

## 原始断法
### 第一轮判断（正确）
1. 涉害课：风波险恶，过程艰难，已有多日摩擦
2. 出户格（丑卯巳）：有出门之象，暗示他会约出去谈
3. 初传丑（天后/月破）：事已破——吵架已伤感情，第三方（比肩）为引火线
4. 中传卯（玄武/官鬼）：男方态度暗昧不明，心有猜疑但不坦荡
5. 末传巳（白虎○空亡）：最终凶不成，分手不会锁定
6. 干上酉（六合）：关系纽带仍在

### 第二轮补充（部分偏差）
错误地认为"他最终说不出口"，实际上他提了且分了。偏差原因：
- 误将闭口（初传丑之煞）读作"话说不出口"，实为前期"晚上有事讲"的含糊态度
- 空亡应读作"不锁定"而非"不发生"

## 实际结果
次日凌晨2:30确定分手。后男方回头求复合，两人又在一起。

## 反推分析
### 偏差定位
第二轮中误判"他最终说不出口"，否定了第一轮的正确判断。

### 被忽略的线索
出户格本身就是"出门"之象，三传丑→卯→巳是逐步推进的，不是"说不出口"而是"说了但作废"。

### 正确断法
涉害课+出户格占感情，分手动作会执行（课体为环境），末传空亡才决定结局（类神为结局）。课体说"出门"，类神说"最终不锁死"——二者不矛盾。

## 经验提炼
当感情占+涉害课+出户格（丑卯巳）+末传空亡时，应断为"分手会提会执行，但最终不被锁定（有复合可能）"，因为出户格主动荡分离，而末传空亡使凶不成。
