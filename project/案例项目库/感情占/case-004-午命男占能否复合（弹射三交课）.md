# case-004 — 午命男占能否复合（感情占·弹射三交课）

## 原始信息
- **占问时间**：2023年12月20日 22:25 星期三
- **四柱**：癸卯 甲子 壬子 辛亥
- **月将**：寅将（夜占）
- **旬空**：寅卯（甲辰旬）
- **年命**：午 行年：未知 性别：男

- **三传**：初传午(六合)→中传酉(天空)→末传子(玄武)
- **课式**：午卯巳寅 / 卯子寅壬
- **反馈**：女后来和别人好了。

## 飞星断语
"此课弹射，祸从内起，午为妻财上又见六合，做与女和合事，却又与宅冲，法云干男支女，干上天后落空，无有女象，该难以复合，又见三交中有六合者，皆不正之交而已。"

## AI解析

### 1. 弹射课——祸从内起
- **弹射课**（遥克课的一种），主"祸从内起、事出突然"。
- 感情破裂之事，祸起于内部（两人之间的问题），而非外部因素。

### 2. 午为妻财乘六合——与女和合事
- 初传午（六合），午为壬日之妻财（壬水以午为财），六合为婚姻和合之神。
- 妻财乘六合，表面看有和合之象，但午与日支子相冲（子午冲），**与宅冲**——与女方（支为宅、为女）相冲，和合不成。

### 3. 干男支女——干上天后落空
- 法云"干男支女"：干为男（午命男），支为女（子）。
- 干上神卯（六合），但卯为空亡（甲辰旬寅卯空），干上无天后（天后为女性类神），"无有女象"——男方这边没有女方的信息，女方已不在男方这边。
- 天后落空，女象不存，复合无望。

### 4. 三交中有六合——不正之交
- 三交课主"事多交加、不正"，三交中见六合，为**不正之交**。
- 飞星断语："三交中有六合者，皆不正之交而已"——感情已非正当关系，女方已另有新欢。

### 5. 反馈印证——女后来和别人好了
- 反馈：女后来和别人好了，印证"干上天后落空，无有女象"——女方已不在男方这边。

## 经验提炼
1. **弹射课断祸从内起**：弹射课主祸从内起，感情破裂源于内部问题。
2. **妻财与宅冲断和合不成**：妻财（午）与日支（子）相冲，和合之事不成。
3. **干男支女+天后落空**：干为男、支为女，干上天后落空=女方不在男方这边，复合无望。
4. **三交+六合=不正之交**：三交课中见六合，感情已非正当关系。
5. **干支分主客**：干为男、支为女，干上神主男方状态，支上神主女方状态。
