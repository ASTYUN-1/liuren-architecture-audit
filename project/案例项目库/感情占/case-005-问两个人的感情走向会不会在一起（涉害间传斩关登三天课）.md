# case-005 — 问两个人的感情走向，会不会在一起（感情占·涉害间传斩关登三天课）

## 原始信息
- **占问时间**：2024年1月27日 19:50（活时午）
- **四柱**：癸卯 乙丑 庚寅 壬午
- **月将**：子将（夜占）
- **旬空**：午未（甲申旬）
- **年命**：未知 行年：未知 性别：未知
- **课体**：涉害，间传，斩关，登三天
- **三传**：初传寅(天后)→中传申(青龙)→末传寅(天后)
- **课式**：寅申申寅 / 申寅寅庚
- **反馈**：男方出轨。

## 飞星断语
"此课赘婿，干加支来克支，支加干被干克，三传四课不出龙后寅申，寅申始终相冲，后又受龙制，定不成多对女方有害。"

## AI解析

### 1. 赘婿课——干加支克支
- **赘婿课**：干（庚）加支（寅）来克支，支（寅）加干（申）被干克——干支互加互克。
- 赘婿课主"以尊从卑、男就女家"，但此处干支互克，关系不谐。
- 飞星断语："此课赘婿，干加支来克支，支加干被干克"——干支互克，感情难以和谐。

### 2. 三传四课不出龙后寅申——始终相冲
- 三传寅→申→寅，四课寅申申寅，全部围绕寅申展开。
- 寅为天后（女性类神），申为青龙（男性类神），**寅申始终相冲**（寅申为驿马、为对冲）。
- 飞星断语："三传四课不出龙后寅申，寅申始终相冲"——男女双方始终相冲，难以在一起。

### 3. 后又受龙制——对女方有害
- 末传寅（天后）为女方，中传申（青龙）为男方，申克寅（金克木），**青龙克天后**——男方克制女方。
- 飞星断语："后又受龙制，定不成多对女方有害"——男方对女方有害，对应反馈"男方出轨"。

### 4. 涉害课——事有艰难
- 涉害课主"事有艰难、经历磨难"，感情之路坎坷。

### 5. 间传课——事有间隔
- 间传课主"事有间隔、不连续"，感情有隔阂。

### 6. 斩关课——冲破阻碍
- 斩关课主冲破阻碍，但此处斩关对应出轨——冲破感情底线。

### 7. 登三天——事体上升
- 登三天课主"事体上升、渐入佳境"，但此处反用——感情看似上升实则崩塌。

## 经验提炼
1. **赘婿课断干支互克**：干加支克支、支加干被干克，干支互克，感情不谐。
2. **龙后寅申始终相冲**：青龙（男）与天后（女）寅申相冲，男女双方始终对立。
3. **青龙克天后=男克女**：申（青龙）克寅（天后），男方克制女方，对女方有害。
4. **三传不出龙后**：三传四课不出青龙天后，感情之事完全围绕男女双方展开。
5. **涉害+间传=坎坷**：涉害主艰难，间传主间隔，感情之路坎坷有隔阂。
