# 杂事占·案例004 — 忘带门禁卡等开门（知一·高盖·六仪）

## 原始信息

- **占问时间**：2026年7月25日 17:43 星期六
- **四柱**：丙午 乙未 庚子 乙酉
- **月将**：午将（大暑后）
- **旬空**：辰巳（甲午旬）
- **课体**：知一，高盖，六仪
- **三传**：初传午(腾蛇)→中传卯(勾陈)→末传子(白虎)
- **四课**：干上巳(朱雀○)→巳上寅(青龙)→支上酉(太阴)→酉上午(腾蛇)
- **背景**：下班回家走小区侧门，没保安，忘带门禁卡，站门口等有人经过开门。

## 问事

1. 等多久有人开门？（A.2分钟 B.5分钟 C.8分钟 D.12分钟）
2. 打开的人是进去还是出来的？
3. 附加题：这人是男是女？

## AI初断（全错）

**答案：** 8分钟 / 进去 / 男 ❌❌❌

**错误归因：**

| 错在哪 | 错误推理 | 正确的判断 |
|:------|:---------|:-----------|
| 来人取类 | 取初传午（阳支）为来人 | 应取**支上酉**（门/环境之人），酉阴×太阴=女子 |
| 进出方向 | 三传终归于子（支=家）→进去 | 三传**逆行**主出→对方出来；卯酉冲→我要进则对方出 |
| 应期 | 午7+子1=8，取8分钟 | **支乘虎主速**+午数7休囚折半≈2分钟 |
| 性别 | 午阳支→男 | 支上酉阴支+太阴→女（正确信号一直在支上） |

## 正确断法

### 1. 取类——开门人是支上酉（太阴）

**核心心法：支为环境/门，支上神才是出现在门口的人。**

- 支（子）为门、为侧门环境
- 支上神**酉（太阴）** = 门口出现的人
- 酉为阴支 → 女性
- 乘太阴 → 阴将，女性

> 口诀："问谁在门口/谁开门，看支上神。支为环境，支上神为环境中出现的人。"

### 2. 进出方向——三传逆行主出

三传：午（初）→卯（中）→子（末），逆行为**退/出**。

- **对宫法**：我要回小区（进），支上酉的对宫是**卯**。卯酉冲，对方与我反向→**出来**
- **三传逆行**：午巳辰卯寅丑子，逆流而下，主退主出

### 3. 应期——支乘虎主速+午数折半=2分钟

- **支（子）乘白虎**：虎主道路、迅猛、速疾。门外之人动作快，稍等即来
- **发用午数7**：午属火，未月土旺火休囚，**折半≈2分钟**
- **知一主邻近**：比用课事在咫尺
- **干上巳空亡**：等待不会长久

### 4. 性别——阴支+太阴=女

- 酉为**阴支**，乘**太阴**阴将 → 女性确凿
- 巳空亡为**阴宫** → 女性

## 反馈验证

> 约2分钟后，从小区里**出来**一位**女子**，帮忙开了侧门。

- 时间2分钟 ✅
- 方向：出来（逆行+对宫卯酉冲） ✅
- 性别：女（酉阴+太阴） ✅

## 经验提炼

1. **支上神取人法**：问"谁出现在门口"，取支上神而非发用。支为环境，上神为环境之人。
2. **阴支+太阴=女**：阴支乘太阴，女性概率极高。
3. **三传定出入**：顺行主进/入，逆行主退/出。与占人的行动方向对应。
4. **对宫定反向**：我要进，则卯酉冲为出；我要出，则对方进。
5. **白虎为速**：虎在支/门，门外之人来速，时间短。
6. **午火休囚折半**：发用午数7，未月火休囚取半≈2分钟（实际2分钟）。
7. **空亡阴宫＝女**：空巳为阴宫，辅助断女。
