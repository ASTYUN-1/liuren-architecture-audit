## 反推分析

### 偏差1：父母职业——经商屠户误判为体制内

**当时推理：** 父母宫午乘青龙→青龙贵神→体制内。太常在官禄宫酉→官方编制。

**被忽略的关键线索：**

| 线索 | 正确读法 |
|------|---------|
| **田宅宫申乘白虎** | 田宅=家业，白虎=杀伐刀兵，申=金=刀→**屠户之业的铁象** |
| **太常+酉+羊刃** | 酉为金+羊刃=切割刀器，太常=日常常业→贩肉常业 |
| **青龙在午克日** | 青龙≠一定有官职，午为日鬼克身→父有威严/压力但非官贵 |
| **午被申穿破** | 父母宫午受田宅宫申穿破，父母之"贵气"被"屠户家业"所破 |

**正确断法：** 田宅宫为家业之根基，白虎+申=杀伐金刀，当先读家业为屠宰血财之业，父母宫青龙在午受申虎所穿，父母从事与家业相关的营生（屠户卖肉）。太常酉（羊刃）为刀肉常业，非体制内编制。

**经验提炼：** 田宅宫（第10宫）读家业时，神将优先于其他宫位判断家庭出身。田宅宫见白虎+申金=屠宰杀戮之业，强于父母宫青龙的"贵气"解读。

### 偏差2：学历——本科误判为硕士

**当时推理：** 伏吟课"科举必中"+帘幕贵人未+日旺→硕土。

**被忽略的关键线索：**
- 帘幕贵人未乘天空→天空为虚，帘幕虽在但为虚贵，非实助
- 朱雀卯秋季木休囚→文星较弱
- 卯带桃花咸池→读书分心（反馈：沉迷上网、心思散漫）
- 初传申（日德）乘白虎而非青龙→德禄被虎威压制

**正确断法：** 帘幕贵人乘天空为"虚贵"，朱雀休囚+桃花主读书分心。伏吟课"科举必中"可能应验于最终能入门（街道办公务员考试），并非学历层级。

### 偏差3：2023年——恋爱误判为父灾

**当时推理：** 小限卯（妻妾宫+桃花+朱雀）→感情年。

**被忽略的关键线索：**
- **小限卯冲太常酉**（父类神）→卯酉冲，冲为冲击动荡→**父灾第一信号**
- 酉（太常）带闭口+羊刃→闭口为堵、不通；羊刃为切割、手术→**癌症手术之象**
- 朱雀在卯，朱雀为文书→**诊断书/病历**
- 我过度关注了桃花的感情面，忽略了冲太常的灾象

**正确断法：** 小限所在宫位冲类神时，类神灾象优先于小限自身寓意。2023年卯冲酉（太常），酉为父类神+羊刃切割+闭口堵塞=父亲癌症。

### 偏差4：2025年——父逝+辞职误判为普通事业变动

**当时推理：** 巳命宫+太岁+官鬼勾陈→事业变动。

**实际同时发生：** ①父逝 ②辞职考公

**被忽略的线索：**
- 乙巳年，乙为正财，巳为官鬼→正财（父/妻）受损+官鬼事业变动并行
- 巳酉丑三合，引动酉太常，太常受巳刑（巳刑申，申合酉...）
- 巳为末传官鬼+太岁临命宫→命主自身大转折
- 但太常（父类神）在酉，巳年刑合酉（巳中丙克酉中辛）→父逝

## 核心经验提炼

### 经验1：田宅宫白虎=屠宰杀戮家业
**条件：** 伏吟课 + 田宅宫（第10宫）乘白虎 + 申/酉金干支
**断语：** 屠户/屠宰/血财之业，不问父母宫青龙贵官
**依据：** 田宅宫为家业根基，白虎主杀伐，金主刀切割。家业象强于父母宫神将的"贵气"。

### 经验2：小限冲类神=该年类神所主之人有灾
**条件：** 推命/占卜 + 小限所在宫位冲六亲类神
**断语：** 该年类神所代表的人（被冲者）有灾祸
**依据：** 冲为冲击动荡，类神受冲即该六亲受冲击。冲比克更急切。

### 经验3：太常≠仅体制内——须区分"常业"与"编制"
**条件：** 推命断父母职业 + 太常在金属宫位（申酉）+ 羊刃/闭口
**断语：** 太常为日常常业，与金属切割相关则为屠宰/肉食行业，非必为体制内
**依据：** 太常本义为"常"——常业常服，非仅官方编制。

### 经验4：帘幕贵人乘天空=虚贵
**条件：** 推命看学历 + 帘幕贵人在未(天空)
**断语：** 帘幕贵人虽在但天空虚之，为"虚贵"，应降低学历判断等级
**依据：** 天空主虚，帘幕贵人乘天空则助考之力减弱。

## 技法迁移
1. 伏吟课推命时，**田宅宫**优先于父母宫判断家庭出身
2. 太常的象意应包括"常业常服"而非仅限"官方编制"，需结合宫位金属性解读
3. 小限断年事，先看**冲克类神**，再看本宫寓意
4. 三传递刑（申冲寅→寅刑巳）的"三刑"主人生多波折，家业/健康/事业三端皆可能应
