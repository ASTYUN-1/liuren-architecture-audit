# case-022 — 丙寅日中考录取压线（始入·火局·太常临行年）

## 课式指纹
- **占类**：考试占（中考录取）
- **占问时间**：2026-06-21 20:01（夏至后）
- **四柱**：丙午年 甲午月 丙寅日 戊戌时
- **月将**：午
- **占时**：戌
- **旬空**：戌亥（甲子旬）
- **课体**：贼克·始入格
- **年命**：2011辛卯（兔）
- **行年**：男命16 → 巳

## 课式关键特征
- **发用**：寅（白虎·天马）
- **中传**：戌（天后·空亡）
- **末传**：午（六合·帝旺）
- **干上神**：丑（太常）加巳（丙禄/德）
- **支上神**：戌（天后·空亡）加寅
- **主要神煞**：天马（寅）、帝旺（午）、禄神（巳）、德神（巳）
- **主要格局**：三传寅午戌合火局生日干丙火；行年巳上太常临禄德

## 断课结论

### 关键依据
1. **太常临行年禄德** → 录取文书与命主运势高度重合，板上钉钉
2. **三传寅午戌合火局生日干丙火** → 全程得助，终有归属
3. **中传戌空亡** → 名额有空缺／录取过程中间有不确定性
4. **末传午（六合·帝旺）归位** → 压线但圆满落地
5. **朱雀本位未（西南）** → 学校方位在西南

### 方向判断教训
- 原断偏重末传午之正南，忽略朱雀未之西南
- **朱雀即为录取通知书，其本位（未）才是学校方位正解**
- 末传午（六合）与朱雀未（午未合），正南与西南为合应关系

## 验证结果
- **结果**：验
- **验证时间**：后续反馈
- **细节说明**：
  - 学校位于卦主家**西南**方向
  - 区招**3人**，按分数从高到低录取
  - 卦主在报名名单中恰好排**第3名**，压线录取
  - 课象完美对应：三传=3人，中传空=第2名有空缺，末传六合=压线合上

## 核心经验
1. **考试占方位**：朱雀本位（未=西南）比三传末传方向更直接指示学校方位
2. **空亡应事**：中传空亡不一定对应"不顺"，可能对应名额结构上的空缺
3. **六合断压线**：六合非冲锋之将，主"刚好配对成功"，考试占压线录取见之为验
4. **三传数量应**：三传数=3，与现实招生人数/排名数吻合
5. **太常临行年**：考试占见太常临行年禄德之地，录取无疑
