# 考试占·案例030 — 壬寅日学考双B复盘（伏吟元胎+德入天门末传空亡）

## 原始信息
- **占类**：考试占
- **背景**：数学和技术学考能到 A 吗？大概 28 号出成绩。
- **时间**：2026年7月27日 12:00
- **四柱**：丙午 乙未 壬寅 丙午
- **月将**：午（小暑后）
- **占时**：午（夜占，卯昼酉夜规则）
- **旬空**：辰巳（甲午旬）
- **课体**：伏吟，元胎，励德
- **课式数据**（6ren.cn排盘）：
  - 四课：干上亥（天空），支上寅（六合）
  - 三传：亥（初，天空）→ 寅（中，六合）→ 巳（末，贵人◎空亡）

## 断语原文
> 德入天门占试必中 + 伏吟课稳定 = 能过但末传巳空亡意味着成绩（财）落空，可能压线或不到顶A。

## 反馈
> **数学B，技术B，两个都是B。** 没有到A，但是都过了（合格）。

## AI解析

### 1. 课体分析
此课得**伏吟课**，天地如一，主静守。**元胎课**主萌芽。**励德课**主激励。

### 2. 发用——德入天门
初传亥为壬日之**日德**，发用即"**日德加亥为用，名德入天门，占试必中**"（《六壬秘要》）。
- 多部古籍（《六壬大全》《六壬粹言》《六壬银河櫂》）均强调此格"占试必中""主高中"
- 《六壬粹言》特别指出"**惟六壬日伏吟，亥发用为最的**"，本课完全对应

### 3. 末传——成绩等级的决定因素
末传巳为**妻财，空亡**。妻财在考试占中代表分数/成绩等级。
- 末传决定结局 → 财空则高分虚而不实
- 德入天门可以"中"（通过/合格），但财空决定了不能是"优"（A级）

### 4. 复盘——误判原因
**过度强调了德入天门的"高中"二字，低估了末传财空亡对成绩等级的限制。**

核心教训：
- **德入天门主"考中"（通过），不等于"高等第"（A）**
- **类神定结局优先于课体**：末传财空亡（成绩虚）> 发用德入天门（考试大利）
- 考试占中，财为空亡时应保守断，只看能否"过"而非"高分"

## 经验提炼
1. **德入天门主通过而非高分**：发用吉只保底线，等级看末传类神
2. **末传财空亡定上限**：考试占中财代表分数等级，空则等级不高
3. **类神定结局优先于课体**：再好的课体，核心类神空亡也要打折
4. **伏吟课稳定应验**：伏吟主成绩稳定，不会大起大落，双B符合"稳定中等"
