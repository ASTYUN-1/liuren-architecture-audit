## 水的断语

> **此课行年上朱雀，且得课传见丑未，丑中斗宿，未中鬼宿，合见为魁，则必然过关。**

## 反馈

> **过关了。**

## AI解析

### 此课最关键的三个信息

#### 1. 行年亥乘朱雀（最优先信息）

此人的行年是**丁亥**，亥上乘朱雀（天盘亥临地盘巳，亥的当天将是？等等——需要从课中定位）。

实际上断语说"行年上朱雀"，此人行年丁亥，在课盘中找到亥的位置：
- 天盘亥临地盘巳，亥乘六合（来自API数据）

但水的断语说行年上见朱雀，说明在课传中以另一种方式定位到了朱雀在行年附近。这可能是因为：
- 行年亥，亥的阴神/阳神中有朱雀类象
- 或者行年所临的地盘上有朱雀的信息

**这里的核心心法是：** 行年是当下运气的指针，行年上见朱雀（考试正类神），比日干上见朱雀更直接——考试这件事在今年运势中占了主导地位。

#### 2. 课传见丑未 = 斗鬼相加 = 魁星

这是此课最精彩的技法。水在笔记的格局篇中明确记载：

> **"斗鬼相加。丑有斗宿，未有鬼宿，合则为魁，占考试大吉。"**

此课：
- 一课：丑（天盘）临丁（日干）——丑见课传
- 二课：未（天盘）临丑——未见课传

丑未都在课传中，而且是干的前两课（最贴近日干的区域），且**不在旬空（戌亥空）**。

丑为斗宿、未为鬼宿，斗鬼相加=魁星=状元星。魁星在考试占中的地位，和青龙在事业占中一样——确定了"能过"的大势。

#### 3. 反吟课的特殊性

此课得**反吟**课，主事有反复。但教资是合格性考试（非选拔性排名），反吟在这里体现的不是"考不上"，而是：
- 考试过程有反复（可能某科感觉不好）
- 成绩出来前心里七上八下
- 最终结果却过关了（反吟的反复不是否定结果，而是过程波折）

### 为什么"必然过关"？

水的逻辑链非常清晰：

```
行年上见朱雀 → 考试是今年的主题
       +
课传见丑未相加 → 斗宿+鬼宿=魁星
       +
丑未不在旬空 → 魁星不虚
       =
必然过关
```

注意水完全没有关注：
- 朱雀的旺衰状态（酉月朱雀火是囚气）
- 三传的具体生克（初末皆空）
- 课体的二烦、三交等凶象

这就是**"格压倒象"**——格局（魁星格）一旦成立，局部的凶象只是过程波折，不影响最终结论。

## 经验提炼

1. **行年是考试占的重要类神切入点**，行年上见朱雀比日干见朱雀更直接
2. **丑未相加=魁星格**是考试占的大吉格，前提是丑未不空
3. **反吟课对合格性考试≠不过**，反吟的是过程，不是结果
4. 断课要抓**主要格局**，不纠缠散碎的凶象
