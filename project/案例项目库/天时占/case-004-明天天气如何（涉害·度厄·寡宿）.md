# case-004 — 明天天气如何（天时占·涉害度厄寡宿课）

## 原始信息
- **占问时间**：2023年12月12日 17:43 星期二
- **四柱**：癸卯 甲子 甲辰 癸酉
- **月将**：寅将
- **旬空**：寅卯（甲辰旬）
- **课体**：涉害，度厄，寡宿
- **三传**：初传子(青龙)→中传巳(太阴)→末传戌(六合)
- **课式**：虎雀青贵 / 寅酉子未 / 酉辰未甲
- **反馈**：有雪连绵不断，规模比小雪大一些。

## AI解析

### 1. 课体分析
- **涉害课**：事有稽留——天气系统稳定持续
- **度厄课**：四课皆上神克下——天气变化剧烈
- **寡宿课**：主孤独——雪天行人稀少

### 2. 铸印课占天时
水断此课为铸印课（三传子→巳→戌，子水为印模，巳火为炉火，戌土为印）：
- 邵彦和法：铸印占天时必有雨，冬占必雪
- 不拘泥于占雨雪，皆有其气

### 3. 水的断语解析
"课得铸印，不拘泥于占雨雪，皆有其气，又水升其上，火伏其下，发端门见壬子乘青龙为入海之象，入海之龙在天则大雨。又深冬铸印则见雪，明日天气取巳，乙巳日中巳中庚金合乙木化而为金，见于巳日则为风雪，又见巳天官太阴为雪神，知明日有雪。"

### 4. 天干化气法
- 明日为巳日，巳中庚金
- 配干乙（乙巳日）
- 乙庚合化金，金生水则雪
- 巳天官太阴为雪神
