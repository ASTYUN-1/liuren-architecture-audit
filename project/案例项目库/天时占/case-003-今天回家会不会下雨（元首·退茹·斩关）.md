# case-003 — 今天回家会不会下雨（天时占·元首退茹斩关课）

- **四柱**：癸卯 戊午 丁巳 戊申

- **三传**：初传卯(勾陈)→中传辰(青龙)→末传巳(天空)
- **课式**：勾青空虎 / 卯辰巳午 / 辰巳午丁
- **反馈**：下了雷阵雨，跑着回家的。

## AI解析

### 1. 课体分析
- **元首课**：一上克下发用，事从外起——天气由外部系统决定
- **退茹课**：三传卯→辰→巳，退行连茹——天气变化连续
- **斩关课**：魁罡加日辰——天气突变

### 2. 水的断语解析
"青龙飞天，天罡指阴，又贵人临子，皆是行雨之象。三传见卯为雷，青龙在卯，亦催雷之象。"

### 3. 行雨之象
- **青龙飞天**：青龙在卯（震宫），主雷雨
- **天罡指阴**：辰为天罡，指阴则雨
- **贵人临子**：贵人临子（水乡），主雨
- **卯为雷**：三传见卯，青龙在卯，雷象

### 4. 退茹课——天气连续变化
退茹课三传卯→辰→巳，由木退至火：
- 卯为雷（震）
- 辰为雨（天罡指阴）
- 巳为晴（火）
- 先雷后雨再转晴——雷阵雨
