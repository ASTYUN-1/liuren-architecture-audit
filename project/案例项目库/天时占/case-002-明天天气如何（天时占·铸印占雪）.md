# case-002 — 天时占——明天天气如何（天时占·铸印占雪）

## 原始信息
- **占问时间**：2023年12月12日 17:43 星期二
- **四柱**：癸卯 甲子 甲辰 癸酉
- **月将**：寅将
- **旬空**：寅卯（甲辰旬）
- **课体**：涉害，度厄，寡宿
- **三传**：初传子(青龙)→中传酉(朱雀)→末传辰(六合)
- **课式**：寅酉子未 / 酉辰未甲
- **反馈**：有雪连绵不断，规模比小雪大一些。

## 水的断语

"课得铸印，不拘泥于占雨雪，皆有其气，又水升其上，火伏其下，发端门见壬子乘青龙为入海之象，入海之龙在天则大雨。又深冬铸印则见雪，明日天气取巳，乙巳日中巳中庚金合乙木化而为金，见于巳日则为风雪，又见巳天官太阴为雪神，知明日有雪。"

## AI解析

此课占明日天气，断有雪且连绵不断，规模较大，其理据如下：

1. **铸印课气**：课体虽为涉害、度厄、寡宿，但三传子酉辰仍具铸印之象（子水、酉金、辰龙），不拘泥于课名，取其气即可。铸印占天时必有雨雪，深冬则见雪。

2. **龙入海为大雨**：发端门初传壬子乘青龙，青龙入于子水，为"入海之龙"。龙入海则升腾于天，在天则行云布雨，主大雨。此为神将组合断法。

3. **水升火伏**：课中水象上升（子水发用），火象潜伏（朱雀乘酉金，火被金伏），水火交蒸，雨雪之象已成。

4. **天干化气法（乙庚化金）**：明日为巳日，取乙巳日。巳中庚金合乙木化而为金，金生水，见于巳日则为风雪。且巳天官为太阴，太阴为雪神，进一步印证雪象。

5. **反馈印证**：有雪连绵不断，规模比小雪大一些，与"龙入海主大雨""铸印深冬见雪"的判断完全吻合。

## 经验提炼

- **铸印课不拘课名取其气**：即使课体不是铸印，只要三传有铸印之象（子水、酉金、辰龙），即可取铸印课气断天时。此为活法。
- **龙入海断法**：青龙乘水（壬子）为入海之龙，在天则大雨。神将组合的经典应用。
- **天干化气法再证**：乙巳日，巳中庚金合乙木化金，金生水为雪。与案例1同法，形成跨案例验证。
- **太阴为雪神**：巳天官太阴，太阴为雪神，辅助断雪。天官与化气法相互印证。
- **水升火伏为雨雪象**：水火交蒸、水升火伏，是雨雪天气的课象特征。
