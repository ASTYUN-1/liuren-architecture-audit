# case-005 — 今天有雨吗（天时占·重审退茹夜衰三奇课）

## 原始信息
- **占问时间**：2023年11月5日 8:43 星期日
- **四柱**：癸卯 壬戌 丁卯 甲辰
- **月将**：卯将
- **旬空**：戌亥（甲子旬）
- **课体**：重审，退茹，夜衰，三奇
- **三传**：初传丑(玄武)→中传寅(太阴)→末传卯(朱雀)
- **课式**：申玄 丑寅巳午 / 酉阴 寅卯午丁
- **反馈**：第二天子时下雨了。

## AI解析

### 1. 课体分析
- **重审课**：一下克上发用，事由内起
- **退茹课**：三传丑→寅→卯，退行连茹——天气变化延迟
- **夜衰课**：夜占衰气——当日难雨
- **三奇课**：三传丑寅卯为三奇——虽有奇应但需等待

### 2. 水的断语解析
"此课火升于上，水伏于下，卯日作月将上见寅六合，发端又见朱雀，难雨。若要见雨则要寻气，有气则为亥贵临子，亥贵本空降雨于子，则是第二日子时，辰日见青龙神，此时下雨。"

### 3. 当日难雨的原因
- **火升于上**：巳午火在上，阳气盛
- **水伏于下**：亥子水在下，阴气伏
- **卯将见寅六合**：木旺生火
- **发端朱雀**：朱雀为火神

### 4. 应期——第二日子时
- 亥贵临子：亥为贵人，临子（水乡）则雨
- 亥贵本空（甲子旬戌亥空），出空则降雨
- 子时为水旺之时
- 辰日见青龙神：辰日青龙当令

## 经验提炼
- **火升水伏难雨**：阳气盛于上、阴气伏于下则难雨
- **寻气法**：有气则为亥贵临子，降雨之象
- **贵人出空**：贵人空亡则出空方能起作用
- **子时水旺**：子时为水旺之时，降雨应期
- **退茹课主延迟**：天气变化延迟到次日
