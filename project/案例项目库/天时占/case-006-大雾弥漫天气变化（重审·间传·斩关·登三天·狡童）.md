# case-006 — 大雾弥漫，天气变化（天时占·重审间传斩关登三天狡童课）

## 原始信息
- **占问时间**：2023年5月20日 14:43 星期六
- **四柱**：癸卯 丁巳 戊寅 己未
- **月将**：酉将
- **旬空**：申酉（甲戌旬）
- **课体**：重审，间传，斩关，登三天，狡童
- **三传**：初传辰(六合)→中传午(青龙)→末传申(白虎)
- **课式**：青合常空 / 午辰酉未 / 辰寅未戊
- **反馈**：申时下了一些小雨。

## AI解析

### 1. 课体分析——复杂天气
此课集五重课体，天气变化复杂：
- **重审课**：事由内起
- **间传课**：三传辰→午→申，隔位而传——天气变化有间隔
- **斩关课**：魁罡加日辰——天气突变
- **登三天**：三传辰午申，登天而上——天气由地面升至高空
- **狡童课**：主阴私——大雾弥漫

### 2. 水的断语解析
"这一课天罡指阳主晴，贵登天门主雨，火临于上，水伏其下，又见青龙飞天，是复杂情况，则找克处《指南》言无气空亡微雨来。首先是午时是我认为会下雨的时间，因为遁干作壬又逢青龙，见申作水母为象。但是起课已经到未时了，则寻见申时小雨，空亡微雨的缘故。"

### 3. 复杂天气的判断方法
- **天罡指阳主晴**：辰为天罡，指阳方则晴
- **贵登天门主雨**：贵人临亥（天门）则雨
- **火临于上**：午火在上
- **水伏其下**：申水在下
- **青龙飞天**：青龙在午，飞天则雨

### 4. 应期——申时小雨
- 午时本为预期下雨时间（壬午遁干，青龙）
- 但起课已到未时，则寻申时
- 申为水母（水长生在申）
- 申空亡（甲戌旬申酉空），空亡微雨
