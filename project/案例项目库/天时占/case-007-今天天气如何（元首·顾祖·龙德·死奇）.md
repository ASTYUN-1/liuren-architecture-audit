# case-007 — 今天天气如何（天时占·元首顾祖龙德死奇课）

- **旬空**：戌亥（甲子旬）
- **课体**：元首，顾祖，龙德，死奇
- **三传**：初传午(贵人)→中传辰(朱雀)→末传寅(勾陈)
- **课式**：合蛇贵阴 / 卯巳午申 / 巳未申辛
- **反馈**：今天多云晴天。

## AI解析

### 1. 课体分析
- **元首课**：一上克下发用，天气由外部系统决定
- **顾祖课**：三传午→辰→寅，回顾长生之地——天气稳定
- **龙德课**：青龙乘德神——天气平和
- **死奇课**：主异常——但此课死奇不显

### 2. 水的断语解析
"此课青龙居本家则休，发端门有午贵作太阳普照，则气势难雨，时放晴气候。"

### 3. 晴天判断的关键
- **青龙居本家（寅）则休**：青龙在寅为归本家，主休息——无雨
- **午贵作太阳普照**：午为贵人，太阳之象——晴天
- **发端门见午贵**：初传为事之始，一开始就是太阳——全天晴朗

### 4. 顾祖课——天气稳定
顾祖课三传午→辰→寅，回顾长生之地：
- 午为日之长生（辛日长生在子，午为败地，但顾祖回顾寅）
- 寅为青龙本家
- 天气稳定无变化

## 经验提炼
- **青龙归本家则休**：青龙在寅为归本家，主休息、无雨
- **午贵为太阳**：午为贵人，太阳之象，主晴
- **顾祖课主稳定**：三传回顾长生之地，天气稳定
- **发端门定全天**：初传为事之始，初传晴则全天晴
