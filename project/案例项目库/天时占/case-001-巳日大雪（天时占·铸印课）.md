# case-001 — 天时占——巳日大雪（天时占·铸印课）

## 原始信息
- **占问时间**：2023年12月10日 18:09 星期日
- **四柱**：癸卯 甲子 壬寅 己酉 寅将 辰巳空
- **课体**：知一，斩关
- **三传**：初传子(六合)→中传未(天空)→末传辰(青龙)
- **课式**：子未酉辰 / 未寅辰壬
- **反馈**：巳日大雪。

## 水的断语

"明日巳日，巳中庚金，配干乙，乙庚合化金则雪，此陈公献先生法，况且邵彦和先生言说过，铸印占天时必有雨，冬占必雪。"

## AI解析

此课占天时，断明日（巳日）有大雪，其理据有三：

1. **铸印课占天时必有雨雪**：课得铸印（三传子未辰，子为水，未为印，辰为龙，合铸印之象），邵彦和先生明确指出铸印课占天时必有雨，冬占必雪。此为课体层面的核心判断。

2. **天干化气法（乙庚化金）**：明日为巳日，巳中藏庚金，配干为乙。乙庚合化金，金为水之母，金生水则雪。此乃陈公献先生之法，以日干化气推天气变化。

3. **冬占雪象**：时值深冬（甲子月），课传水象已显（初传子水），冬占见水，更兼铸印课体，雪象确凿。

## 经验提炼

- **铸印课占天时**：邵彦和法——铸印课占天时必有雨，冬占必雪。此为课体断法的经典应用。
- **天干化气法实战**：陈公献法——以巳日取巳中庚金，配干乙，乙庚合化金则雪。将纳音化气与天时占断结合。
- **知一、斩关为课体辅断**：知一主事有定数，斩关主动荡变化，合于天气突变之象。
