# 明天中午会不会下雨（遥克弹射元胎·风先雨后零星）

## 核心断语

风多雨少：明天中午以多云到阴、风大为主，最多零星小雨或极短小阵雨，不会大雨、不会持续；二选一偏“不会下成明显降雨”。

## 原始断法（初判冻结）

1. **风象成组**：中传亥乘白虎（虎为风）、初传寅为箕宿、干上未为风伯、日支巳为风门、亥又为驿马；《理法简易》“虎为风，入课传必有之”，《六壬金针》“寅、巳入传必有风”。
2. **雨象多虚**：中传亥水、干上天后、二课辰为水库；但青龙乘丑临辰不入课传，酉为雨师而旬空，丑为雨师而不入传，申为水母入末传却旬空；《六壬金针》“丑、酉入传多有雨”，本课丑酉皆不入传。
3. **月令**：戌月土旺、金相、水死、木囚、火休；亥水失令，申金虽相却空，水源不继。
4. **明日午位**：天盘午乘贵人（午为太阳之位），地盘午上神为卯（六合、雷），判为“中午非主雨段”。
5. **课体**：弹射“势轻，事费力而轻”；元胎三传皆孟，主酝酿未成形；水库辰又逢月破、死气。
6. **应期**：发用寅加地盘巳（日支），“日”级；主看明日午时，降水窗口给 10:00–11:30，申时后转阴或止；结论“偏不会下”。

## 实际结果

- 11:26：刮风，无雨。
- 12:47：开始掉雨点，零星小雨。

## 反馈

**部分应验**。

- 命中：风大；先风后雨（初传寅风 → 中传亥雨）；零星、短时、不成势；未出现大雨或持续雨。
- 未中：二选一“偏不会下”判反；把中午判成“非主雨段”；应期窗口 10:00–11:30 给窄，实际 12:47 仍在午时、且在中传段（巳午未）内。

## 反推分析

### 偏差定位

| 类型 | 表现 |
|---|---|
| 程度/量级 | **命中**：零星、短时、不成势 |
| 过程/次序 | **命中**：先风后雨 |
| 吉凶方向（下不下） | **偏差**：判“偏不会”，实际午时末起雨 |
| 应期 | **偏差**：窗口偏早，未按中传整段给 |

### 被忽略或误读的线索

1. **中传亥水乘白虎、又为驿马**：这是本课最实的“风雨”组合；“三传分时”初传卯辰、中传巳午未、末传申酉，12:47 正落中传段。初判把该法以“行路语境”压成备选，压得过头。
2. **把“雨类空”读成“没有雨”**：正确读法是“量小、短、不成势”。《六壬金针》“虚者事多不成”指一场像样的雨不成，不是一滴不下；末传申空、酉雨师空只减量，不断无。
3. **“明日午天盘乘贵人、午为太阳”被当成强晴证**：贵人临地盘酉，午火克酉金，贵人失位；酉又旬空；戌月火休，太阳力弱。只能算弱晴旁证，不足以否决中传亥水。
4. **应期窗口缩得过窄**：中传段本为巳午未（约 9–15 点），只给 10:00–11:30；实际 12:47 仍在该段内。

### 正确断法（反推）

- 以中传亥水＋白虎＋驿马为主证，断“中午段有零星或短时小雨”；末传申空＋太阴定“不成势、后段转阴或止”。
- 二选一应取“会下一点、下不大”，而不是“偏不会”。
- 应期按中传整段给（巳午未，约 9–15 点），主落点在午时末至未时；申时后转阴或止。
- “明日午天盘乘贵人”保留为弱晴旁证，须先核贵人得位、坐空与月令旺衰，不能单独作否决。

## 经验提炼

当 **天时占** ＋ **中传见亥/子水** ＋ **白虎或驿马引动** ＋ **雨类神（龙/雨师/水母）空** 时，应断 **“有零星或短时降水，量小、不成势”**，不应把“空”读成“完全无雨”；当三传分时可用时，**中传（巳午未）见水应优先于“某位天盘乘贵人/午为太阳”的晴象**。反推自 2026-11-03 本案例。

## 边界

- 本案为单一实测复盘，未做跨案例统计；“雨类空只减量不断无”仍属**未验证从疑**，需更多天时案例核对。
- 若中传水全无生扶、又被月令死气重重压制且无白虎/驿马引动，仍可能“只阴不雨”；本案能落零星，与白虎、驿马引动有关。
- 若末传不空、水有源，量级可上调为小到中雨；本案末传申空，故只到零星。
- 案中“洗澡”按背景处理；若为洗车、晾晒，结论同样以降雨判断为准。
