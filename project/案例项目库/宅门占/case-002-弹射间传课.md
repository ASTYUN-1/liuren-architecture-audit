# case-002 — 搬家了，能不能找到新工作呢？（宅门占·弹射间传课）

## 原始信息
- **占问时间**：2023年11月17日 2:52 星期五
- **四柱**：癸卯 癸亥 己卯 乙丑
- **课体**：遥克，弹射，间传，纯阴，溟蒙
- **三传**：初传亥(玄武)→中传丑(白虎)→末传卯(青龙)
- **课式**：未巳亥酉 / 巳卯酉己
- **年命**：癸酉 行年：壬寅 性别：女
- **反馈**：家住在城中村中心附近的大厦，是新房子，西边有条溪流，附件有油烟味，其中西偏南是本市高档小区，我去做了金属一类的文职，汽修一类的文职属于技能型。

## 水的断语

> 旧房子则见于支，为卯地见于死气。为财而动则见于第二课，亥作房子在酉地为生气，生气则为新地。又亥作水气在西方上，又是月建当是好的房子。至于工作去则能有。

## AI解析

### 1. 支为旧宅——卯地死气

己卯日，支上见未，未中有卯木死气。支为宅，卯为旧宅之象，死气则主旧宅已衰、不宜久居。反馈中"搬家了"正应此象——离开旧宅。

### 2. 亥为新宅——酉上生气

第二课亥水临于酉地，酉为生气（己日生气在酉），亥为月建当令，又为水气在西方。水断"亥作房子在酉地为生气，生气则为新地"——新宅环境好，水气旺盛。反馈中"西边有条溪流"——亥水在酉（西）地，正是西边有水的应象。

### 3. 弹射课——气力虽弱，问工能有

弹射课主遥克，气力不足，事多费力。然亥为月建当令，虽弹射而气不衰。水断"至于工作去则能有"——亥为月建，当令有力，故工作可成。反馈中"我去做了金属一类的文职"——酉金为金属，正应三传中酉金之象（课式中有酉），文职则合弹射课之轻柔。

### 4. 纯阴溟蒙——环境细节

纯阴课、溟蒙课主阴暗、蒙昧、不清。反馈中"附件有油烟味"——溟蒙之象，环境有浊气。西偏南是高档小区——酉（西）→未（西南），正合课式中的酉未之象。

### 5. 间传——事有间隔

间传课主事情有间隔、不连续。搬家后找工作，中间有过渡期，最终得成，正合间传之象。

## 经验提炼

- **支为旧宅**：支上卯木死气，主旧宅已衰。
- **亥为新宅**：亥在酉地为生气，月建当令，新宅环境好。
- **西边有水**：亥水在酉地，应西边溪流之象。
- **弹射问工**：弹射课气力虽弱，然月建当令，工作能有。
- **酉金应职**：课式酉金为金属，应金属类文职。
- **溟蒙应境**：纯阴溟蒙，应环境油烟浊气。
