# case-003 — 欲购买一处住宅（宅门占·涉害间传斩关涉三渊课）

## 原始信息
- **占问时间**：2020年4月7日 16:10 星期二
- **四柱**：庚子 庚辰 庚辰 甲申
- **月将**：戌将
- **旬空**：申酉（甲戌旬）
- **课体**：涉害，间传，斩关，涉三渊
- **三传**：初传申(白虎)→中传戌(玄武)→末传子(天后)
- **课式**：虎青后玄 / 申午子戌 / 午辰戌庚
- **反馈**：白天去看此意向房屋，一切满意，唯独得知为回迁房，需支付额外茶水费，难以接受。后择选该楼盘西南坐落的一栋楼购买，不必多花茶水费。

## AI解析

### 1. 课体分析
- **涉害课**：事有稽留——购房过程有波折
- **间传课**：三传申→戌→子，隔位而传——计划有变
- **斩关课**：魁罡加日辰——无论如何都必须动
- **涉三渊**：三传由申入子，由高入低——从意向到实际

### 2. 水的断语解析
"宅看支上，见午作日干败气，又见青龙在其上，是此宅败财伤财。是否会去呢？我想是会过去的，因为戌在干上遁甲，是斩关课，无论如何都必须动。中传冲宅，又是玄武神，遁甲暗财，恐怕因为欺诈之财事而更改计划，最后见申在午地，仍然在南方通楼盘得一房子，可是仍然不好。"

### 3. 宅看支上——午败气伤财
- 支为宅，支上午为日干败气（庚日败在午）
- 青龙在午，青龙为财——败财伤财
- 反馈中"需支付额外茶水费"正应此象

### 4. 斩关课——无论如何必须动
- 戌在干上遁甲，斩关课
- 斩关课主冲破障碍，必须行动
- 即使知道房子有问题，还是会去看

### 5. 中传戌玄武——欺诈之财
- 中传戌冲宅（辰戌冲）
- 玄武为欺诈、暗昧
- 遁甲暗财——茶水费（额外费用）
- 因欺诈之财事而更改计划

### 6. 末传申在午地——南方得房
- 末传申在午地（南方）
- 最终在南方通楼盘得一房子
- 但"仍然不好"——仍有问题

- **宅占看支**：支为宅，支上神定宅之吉凶
