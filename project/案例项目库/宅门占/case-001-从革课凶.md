# case-001 — 最近家里发生一些事情，占宅（宅门占·从革课·凶）

## 原始信息
- **占问时间**：2023年11月14日 22:48 星期二
- **四柱**：癸卯 癸亥 丙子 己亥
- **课体**：重审，从革，斩关，伏殃
- **三传**：初传酉(贵人)→中传丑(太常)→末传巳(勾陈)
- **课式**：申辰丑酉 / 辰子酉丙
- **反馈**：不太太平，老是有人受伤，基本都是破财，家里面的叔伯姑妈都发生了一些不太好的事情，是有惊无险吧。我之前也觉得是墓的问题，而且我奶奶是属鸡的，今年确实是有引产的一个姐姐。

## 水的断语

> 这一课比较凶，天罡压宅不宁。财爻为岁破则破财，三传吊丧并逢，其次子作胎爻上有玄武作鬼，子上面被辰水墓压着。是胎儿孩子有凶的象。

## AI解析

### 1. 宅占看支——天罡压宅

宅门占以支（辰）为宅。此课支上见申（天罡），天罡为凶神，压于宅上，主宅不安宁。辰为水库，申为天罡，二者叠加，宅中阴气凝重，家宅不靖。

### 2. 财爻岁破——破财之象

初传酉金为财爻，然酉在甲戌旬中旬空，且岁破在卯（太岁卯木冲酉金），财爻既空又逢岁破，主破财无疑。反馈中"基本都是破财"与此吻合。

### 3. 三传吊丧——家人有灾

三传酉→丑→巳，酉为吊客，丑为丧门，巳为劫煞，三传递克，吊丧并逢，主家中人口有灾祸。反馈中"老是有人受伤""叔伯姑妈都发生了一些不太好的事情"正应此象。

### 4. 子作胎爻——胎儿之凶

课中子上见辰水墓，子为胎爻（丙日胎在子），上有玄武作鬼，辰水又为墓库压之，是胎儿有凶险之象。反馈中"今年确实是有引产的一个姐姐"——奶奶属鸡（酉），酉年引产，正应胎爻受克之象。

### 5. 从革课——改易变动

从革课主改易、变动、革除。对于宅占而言，主家中人事变动、格局改变。引产之事、家人接连受伤，皆属家中人事之变动与不安。

## 经验提炼

- **宅占核心**：支为宅，天罡压宅则宅不宁。
- **财爻岁破**：财爻空亡且被太岁冲破，必主破财。
- **吊丧并逢**：三传吊客、丧门、劫煞传递，主家人灾祸。
- **胎爻受克**：子上见墓鬼，主胎儿凶险。
- **从革课性**：改易变动，宅中人事不宁。
