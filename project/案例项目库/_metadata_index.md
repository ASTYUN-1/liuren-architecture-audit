# 案例库元数据索引

> **grep 友好格式**。每条案例以 `<!-- META: 字段=值 | ... -->` 标签行标记，紧随其后为表格行。
> 标签行与表格行一一对应，grep 命中标签行后用 `-A 1` 即可同时获取表格行。

## 快速搜索

```bash
# 按占类+课体搜索
grep "占类=考试占.*课体=反吟" _metadata_index.md

# 按发用搜索
grep "发用=卯(天空)" _metadata_index.md

# 按反馈+占类搜索（仅已验证案例）
grep "反馈=验.*占类=事业占" _metadata_index.md

# 按核心技法搜索
grep "技法=.*魁星格" _metadata_index.md

# 列出所有标签行（统计用）
grep "^<!-- META:" _metadata_index.md | wc -l
```

## 字段速查

| 标签字段 | 含义 | 示例 |
|----------|------|------|
| `占类` | 分类目录 | 考试占 / 事业占 / 感情占 / 疾病占 / ... |
| `编号` | 案例编号 | case-001 |
| `课体` | 课体名称（逗号分隔） | 反吟,三交,二烦,斫轮 |
| `发用` | 初传(天将) | 卯(天空) |
| `三传` | 初传中传末传 | 卯酉卯 |
| `日干` | 日干五行 | 丁 / 甲 / 戊 / ... |
| `反馈` | 验证结果 | 验 / 部分验 / 不验 |
| `技法` | 核心技法标签（逗号分隔） | 魁星格, 格压倒象, 涉害vs比用 |
