# 大六壬案例项目库

## 🔍 整理目的

1. **重新排版**——原文排版混乱（竖排课式错位、空行过多），本库对所有案例进行规范化排版
2. **深度分析**——每个案例结合古籍文献（《六壬大全》《六壬直指御定》《六壬指南》《一字诀玉连环》《心镜》等）进行AI解析
3. **技法提炼**——从水的断语中提取可复用的断课心法，归纳规律
4. **交叉验证**——对比古法论述与现代实战，验证六壬核心理论
