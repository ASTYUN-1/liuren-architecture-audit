# 官讼占·案例001 — 离婚财产官司能打赢吗（反吟课·比用合和）

## 原始信息

- **占问时间**：2023年11月11日 18:21 星期六
- **四柱**：癸卯 癸亥 癸酉 辛酉
- **月将**：卯将
- **旬空**：戌亥（甲子旬）
- **课体**：无依，三交，龙战，励德
- **三传**：初传酉(天空)→中传卯(贵人)→末传未(天后)
- **课式**：酉卯丑未 / 卯酉未癸

## 反馈

> **男方打赢了，但女方还是要分走一部分。**

## AI解析

此课无水明确断语，但反馈信息本身揭示了反吟课在官讼中的重要规律。

### 反吟课的特性

反吟课天地对冲，主事有反复、两方对立。在官司占中：
- 反吟本身 = 双方对抗激烈
- 初传酉（天空） = 虚诈不实，对方的主张有虚假成分
- 中传卯（贵人） = 有贵人介入（法官/律师）
- 末传未（天后） = 最终有和解/安抚性质的结果

### 比用课的和合性

课体得"无依"（反吟的一个变体），但三传酉→卯→未，三传与干支有合：
- 酉与日干癸有生（金生水） → 我方有理
- 卯与日支酉冲 → 对方与家宅对立
- 末传未与酉（日支）合 → 最终宅（财产）被分走一部分

### 反馈解读

"男方打赢了"——日干癸水旺于亥月，干上见酉（金生水），我方有理有力。
"但女方还是要分走一部分"——末传未（天后=女性）乘天后临酉（宅/财产），女得财之象。

## 经验提炼

1. **官讼占先看课体**——反吟主对抗、比用主合和（即使对抗最终也有合的成分）
2. **末传定结果**——末传未天后临酉宅，女得财
3. **日干旺衰**——癸水旺于亥月，自身底气足，打官司能赢但不全赢
