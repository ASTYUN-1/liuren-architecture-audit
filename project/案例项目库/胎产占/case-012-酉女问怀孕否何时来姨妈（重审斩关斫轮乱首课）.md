# case-012 — 酉女问怀孕否+姨妈应期（胎产占·重审斩关斫轮乱首课）

## 原始信息
- **占问时间**：2025年3月13日 12:15 星期四
- **四柱**：乙巳 己卯 辛巳 甲午
- **月将**：亥将（昼占）
- **旬空**：申酉（甲戌旬）
- **年命**：癸酉（1993年，酉女）
- **行年**：戌（虚岁33，女命逆排）
- **占类**：胎产占——问是否怀孕，若否则何时来姨妈
- **课体**：重审，斩关，励德，不备，斫轮，乱首
- **三传**：初传卯(玄武)→中传申(朱雀)○→末传丑(白虎)

## 课式

四课：
      玄武  朱雀  勾陈  玄武
      卯    申    戌    卯
      辛    卯    巳    戌
      干     干阴   支     支阴

三传：己卯(妻财·玄武) → 申(兄弟·朱雀)○空 → 丁丑(父母·白虎)

## 模范作业（优秀答案）

> **答案一**：1.没怀 2.丙戌日、己丑日
>
> **答案二**：1.没怀 2.辛巳日、丙戌日
>
> **老师真实反馈**：戊戌日来

### 模范答案推理过程

**（一）没怀的判断**
1. **四课三传无子孙**：辛金的子孙为壬水（寄亥）、癸水（寄丑），四课（卯、申、戌、卯）三传（卯、申、丑）皆无子爻，胎孕无着落。
2. **午遁子孙遭丑害**：先锋午为时支，午遁壬（甲午旬），壬为辛之子孙，丑午相害，子孙遭害，胎不成。
3. **丑为腹又陷落**：末传丑为腹部，乘白虎凶将，非安胎之象。

**（二）姨妈应期的判断**
1. **血忌遭刑则动**：二月（卯月）血忌在**未**。末传丑与未相刑（丑未相刑），血忌遭刑，血动经来。
2. **戌日冲空换旬**：中传申空亡（甲戌旬申酉空）。甲戌旬至**戌日**结束换旬，过戌日则申不空——"冲空"非地支六冲，而是**旬尾冲开空亡**。
3. 模范答案取丙戌、己丑，实际反馈为**戊戌日**。

## 核心技法

### 技法一：血忌刑动应期法
- 占月经/血事，先查当月血忌：二月血忌在未。
- 课中见刑/冲该地支 → 血动经来。本课末传丑刑未，血忌被刑则破。

### 技法二：换旬冲空法
- 空亡填实不仅限于六冲/三合/六合，**旬尾换旬同样让空亡失效**。
- 本课中传申空（甲戌旬申酉空），甲戌旬尾为戌日。过戌日进入甲申旬，申不再空。
- 模范作业取丙戌日，实际反馈戊戌日，同属戌日范围。

### 技法三：课传无子孙断未孕
- 占孕先查课传是否有子孙爻（日干所生之五行）。
- 辛金子孙为壬（亥）癸（丑）。四课三传中仅末传丑为癸寄，但乘白虎且被午害，子爻受伤无孕。

### 技法四：午遁子孙遭害
- 先锋午为时柱，午遁壬，壬为辛之子孙。
- 午临丑，丑午相害，子孙遭害——未孕确证。
