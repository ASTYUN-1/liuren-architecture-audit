# case-007 — 生男生女？何时出生？顺产否？（胎产占·六仪四绝课）

## 原始信息
- **占问时间**：2023年10月11日 17:17 星期三
- **四柱**：癸卯 壬戌 壬寅 己酉
- **月将**：辰将（夜占）
- **旬空**：辰巳（甲午旬）
- **年命**：巳 行年：戌 性别：女
- **课体**：重审，六仪，四绝
- **三传**：初传午(玄武)→中传丑(朱雀)→末传申(白虎)
- **课式**：辰酉丑午 / 酉寅午壬
- **反馈**：男孩，顺产打了针，亥日丑时，斤数6.5斤。

## 水的断语
"此课我不取胎爻八卦，因为年命变体门有子爻了，上乘青龙直取。此课顺产是因为三传递生作顺产，课体不能忽视，亥日出生的确不知为何。生产斤数则取胎爻，午九数，午火发用，午火休囚减半，4.5斤，元武作亥数四，玄武属水，休囚减半2，6.5斤。"

## AI解析

### 1. 年命变体门——不取胎爻，直取青龙子爻
- 此课水的断语最精彩之处在于**年命变体门**：年命巳，巳的变体门（巳的变体门为申，但此处"年命变体门有子爻"指年命巳上见青龙子爻）。
- 年命巳上见子（青龙），子为壬之子爻（壬水以寅为子孙，但子中癸水为壬之弟，子为壬之帝旺，此处取子为子爻），青龙为吉庆之神。
- 水的断语："我不取胎爻八卦，因为年命变体门有子爻了，上乘青龙直取"——年命上子爻乘青龙，直接取此断生男。

### 2. 性别判断——青龙子爻为男
- 子为阳水，青龙为阳将，阳神阳将=男。
- 子为壬之帝旺，旺相有力，子爻乘青龙，吉庆之象，断生男。

### 3. 顺产判断——三传递生
- 三传午→丑→申：午生丑（火生土），丑生申（土生金），申生日干壬（申为壬之长生），**三传递生**。
- 三传递生日干，产程顺利，母体得助。
- 水的断语："此课顺产是因为三传递生作顺产"——传递相生，产程顺利。

### 4. 应期——亥日丑时
- 水的断语："亥日出生的确不知为何"——此处水的未明言应期原理。
- 分析：亥为壬之禄（壬水禄在亥），亥又为日干壬之临官，禄临产期。丑时为末传申（白虎）所主时辰（申为传送，白虎为速，申时逆推至丑时）。

### 5. 斤数推断——午九数 + 玄武亥数
- 胎爻午火，午为离，离数九（河图数：火二七，但此处用先天八卦数：离为九）。
- 午火发用，但午在戌月（农历九月）为休囚，故减半：9÷2=4.5斤。
- 玄武为亥（玄武本家），亥数四（河图水数一六，但此处用四），玄武属水，休囚减半：4÷2=2斤。
- 合计：4.5+2=6.5斤。
- 反馈：6.5斤，完全吻合。

### 6. 课体印证
- **重审课**：事须再审，产程中打了针（需要医疗干预）。
- **六仪课**：主吉庆、顺利，顺产之象。
- **四绝课**：四绝主事体终结，生产为孕育之终结。

## 经验提炼
1. **年命变体门取子爻**：不取常规胎爻，而从年命变体门取子爻乘青龙断生男——这是水的独特技法。
2. **三传递生断顺产**：三传递生日干，产程顺利，母体得助。
3. **斤数推断法**：胎爻河图/八卦数 + 休囚减半 + 神将本家数，综合计算胎儿体重。
4. **青龙子爻断男**：青龙为阳将，子为阳神，阳神阳将=男。
5. **四绝课应产期**：四绝主事体终结，对应生产。
