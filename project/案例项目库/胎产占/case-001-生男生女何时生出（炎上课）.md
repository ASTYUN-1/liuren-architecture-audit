# case-001 — 生男生女？何时生出？（胎产占·炎上课）

## 原始信息
- **占问时间**：2023年9月29日 16:34 星期五
- **四柱**：癸卯 辛酉 庚寅 甲申
- **课体**：涉害，炎上，斩关，狡童
- **三传**：初传戌(六合)→中传午(白虎)→末传辰(腾蛇)
- **反馈**：当月卯日午时，男生。

## 水的断语
"先看胎爻咯，卯，震男，月份就在本月，因为已经冲了卯，卯胎已经空了，今天是寅，那就在当下。"

## AI解析

### 1. 胎爻定位与性别判断
- 以地盘卯为胎爻（庚寅日，胎在卯）。
- 卯在八卦配震☳，震为长男，故断生男。
- 胎爻卯木在课中受申（日干庚之禄）暗合，又逢戌（六合）发用，合中带冲，胎气已动。

### 2. 产期应期——冲空填实
- 占时为申，日支为寅，寅卯辰会木局，卯胎已在局中。
- 水的断语核心："冲了卯，卯胎已经空了"——申月卯为囚死，又逢寅日填实后即冲（寅卯辰会木，寅日引动卯胎），胎爻被冲则胎气破而出。
- "今天是寅，那就在当下"——寅日冲卯（寅卯辰会木局，寅为木局之首，引动卯胎），故产期即在当日附近。
- 反馈为当月卯日午时：卯日正是胎爻本日，午时火旺生土（庚之印），母子平安。

### 3. 课体与三传印证
- **涉害课**：事主迟疑不决（怀孕待产），但涉浅得深，终有结果。
- **炎上局（寅午戌）**：三传戌→午→辰，虽非标准寅午戌局，但发用戌、中传午暗合炎上之意。火主速，应期急促，与"当月生产"吻合。
- **斩关**：冲破阻碍，胎儿过关。
- **狡童**：合中有散，胎出之象。

### 4. 神将细节
- 初传戌（六合）：六合为子孙爻、为胎产，戌为火库，胎气汇聚。
- 中传午（白虎）：白虎为血光、产道，午为离火，主速、主午时。
- 末传辰（腾蛇）：腾蛇主惊、主变，辰为水库润胎，至此胎出。

## 经验提炼
- **胎爻法**：以日干胎地为胎爻，配八卦定男女（卯=震=男）。
- **冲胎应期**：胎爻逢冲（寅冲卯）则胎动，冲空填实之日时为产期。
- **炎上主速**：火局旺相，应期急促，不出当月。
- **神将呼应**：六合（胎）→白虎（产道）→腾蛇（惊变），三传演绎产程。
