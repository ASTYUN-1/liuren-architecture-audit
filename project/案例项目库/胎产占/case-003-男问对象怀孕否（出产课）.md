# case-003 — 男问对象怀孕否？（胎产占·出产课）

## 原始信息
- **占问时间**：2023年11月11日 2:34 星期六
- **四柱**：癸卯 癸亥 癸酉 癸丑
- **月将**：卯将
- **旬空**：戌亥（甲子旬）
- **年命**：未知 行年：未知 性别：未知
- **课体**：元首，间传，出产
- **三传**：初传丑(太阴)→中传卯(贵人)→末传巳(朱雀)
- **课式**：丑亥巳卯 / 亥酉卯癸
- **反馈**：男生已经花钱给女生吃药了。

## 水的断语
"首先怀孕了，其次家中容不下这个孩子，要打掉。是子爻在日干上，仰首见子。又作女性私户亥作经血，癸酉闭户亥又见空是怀孕了。那么酉是家宅冲卯则家中难容此子，又卯作死气，亥者孩子也为丑太阴所克杀，丑是天医则吃药了。"

## AI解析

### 1. 怀孕判断——子爻仰首见子 + 亥为经血闭户
- 癸日，子爻为金（癸水以金为子孙）。课中卯上见亥（亥为癸之劫财，但亥为女性私户、经血之象），亥临空亡（甲子旬戌亥空），经血闭户——**经血空则停，怀孕之象**。
- 日干癸上见卯（贵人），卯为仰首之象，卯为子爻（癸水长生在卯，卯为癸之子孙位），"仰首见子"——子爻抬头，胎气已显。
- 酉为闭户（癸酉日，酉为日之偏印，闭户之象），亥为经血，亥空则经停，综合断怀孕。

### 2. 家中难容——酉冲卯 + 死气
- 酉为家宅（日支），卯为子爻，**酉卯相冲**——家宅冲克子爻，家中容不下这个孩子。
- 卯乘贵人，但卯为**死气**（正月起卯顺行十二辰，十一月死气在卯），子爻临死气，胎气不吉。
- 综合：家宅冲子爻 + 子爻死气 = 孩子保不住。

### 3. 打胎之象——丑太阴克亥 + 天医
- 初传丑（太阴），丑为**天医**（正月起辰顺行十二辰，十一月天医在丑），天医发用主医药。
- 丑太阴克亥（丑土克亥水），亥为孩子（亥为子孙），太阴克亥 = 暗中用药伤害孩子。
- 水的断语："亥者孩子也为丑太阴所克杀，丑是天医则吃药了"——天医发用克子爻，吃药打胎之象。

### 4. 课体印证
- **元首课**：事有主事之人，男生主导此事。
- **间传课**：事有间隔、曲折，非顺遂之事。
- **出产课**：课名"出产"，但此处非正常生产，而是胎出（打掉）。

## 经验提炼
1. **经血闭户断孕法**：亥为女性私户、经血，亥空则经停，为怀孕之象。酉为闭户，亥空+酉闭=怀孕。
2. **子爻仰首**：日干上见子爻（卯为癸之子孙），仰首见子，胎气已显。
3. **家宅冲子爻**：酉（宅）冲卯（子爻），家中难容此子。
4. **天医克子爻**：天医发用（丑）克亥（孩子），主用药打胎。
5. **死气临子爻**：子爻临死气，胎气不吉。
