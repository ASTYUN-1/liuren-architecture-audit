# case-004 — 试管婴儿能成功吗？（胎产占·退茹三奇课）

- **旬空**：戌亥（甲子旬）

- **三传**：初传丑(太常)→中传子(玄武)→末传亥(太阴)
- **课式**：丑寅巳午 / 寅卯午丁
- **反馈**：没成，子宫壁薄，不好着床。女方以前流过产，很可能是这个导致的。家里倒是催促，男方女方到处求访，还搞了玄学法事。

## 水的断语
"亥子丑作三奇必然是新奇事物，三奇见空则难，空一亥作孩子，是为不能孕。"

## AI解析

### 1. 三奇课——新奇事物（试管婴儿）
- 三传亥子丑为**三奇课**（乙丙丁为天上三奇，亥子丑为地下三奇），主新奇、特殊之事。
- 试管婴儿在当时属于新奇医疗技术，三奇课正应此象。
- 水的断语："亥子丑作三奇必然是新奇事物"——课体直接对应试管婴儿这一新兴技术。

### 2. 三奇见空——事难成
- 末传亥（太阴）为三奇之末，**亥为空亡**（甲子旬戌亥空）。
- 三奇课以全见为吉，末传空则三奇不全，事难成就。
- 水的断语："三奇见空则难"——三奇缺一，奇事不成。

### 3. 亥为孩子——空则不能孕
- 亥为子孙爻（丁火以亥为官鬼，但亥中壬水为丁之官鬼，此处亥取象为孩子，因亥为胞胎、为幼子）。
- 亥空亡，**孩子空则不能孕**。
- 水的断语："空一亥作孩子，是为不能孕"——孩子空亡，无法怀孕。

### 4. 退茹课——退步、后退
- 三传丑→子→亥为**退茹**（退步连茹），主事体后退、不进反退。
- 试管婴儿之事，虽有尝试但最终退步（失败），与退茹课吻合。

### 5. 重审课——事须再审
- 重审课主"事须再审、不可轻举"，暗示此事需要反复斟酌。
- 反馈中"女方以前流过产"、"到处求访"、"搞了玄学法事"——正是反复尝试、多方求访之象。

### 6. 夜衰课——夜占衰气
- 夜占得夜衰课，气运衰微，事难成就。

## 经验提炼
1. **三奇课应新奇事物**：三奇课主新奇、特殊之事，可对应新兴技术（如试管婴儿）。
2. **三奇忌空**：三奇以全见为吉，末传空则三奇不全，事难成。
3. **亥为孩子**：亥为胞胎、幼子，亥空则孩子空，不能怀孕。
4. **退茹主退步**：退茹课主事体后退，不进反退，对应失败结局。
5. **重审主反复**：重审课主事须再审，对应多方求访、反复尝试。
