# case-008 — 此女怀孕否？（胎产占·退茹不备课）

## 原始信息
- **占问时间**：2023年10月14日 9:17 星期六
- **四柱**：癸卯 壬戌 乙巳 辛巳
- **月将**：辰将（昼占）
- **旬空**：寅卯（甲辰旬）
- **年命**：未知 行年：未知 性别：未知
- **课体**：元首，退茹，不备，蓦越
- **三传**：初传辰(勾陈)→中传卯(六合)→末传寅(朱雀)
- **课式**：卯辰寅卯 / 辰巳卯乙
- **反馈**：没有怀孕。

## 水的断语
"此课不备课，则气势已少，又见正时门在巳的天罡所压，卯本身斩关逢空，子难生出。"

## AI解析

### 1. 不备课——气势已少
- **不备课**：四课不全，缺一课（乙巳日，干上卯，支上辰，干阴寅，支阴卯，四课中卯重复出现，实际只有三课）。
- 不备课主事体不全、气势不足，胎孕之事以全备为吉，不备则胎气不足。
- 水的断语："此课不备课，则气势已少"——胎气不足，难以成孕。

### 2. 正时门天罡所压
- 正时为巳（辛巳时），巳为天罡（辰）所压（辰将加巳，天罡辰临巳）。
- 天罡为凶神，压正时门，主事体受阻、被压制。
- 怀孕之事被天罡压制，难以成孕。

### 3. 卯为斩关逢空——子难生出
- 卯为乙日之子孙爻（乙木以午为子孙，但卯为乙之禄，此处卯取象为子爻），卯为空亡（甲辰旬寅卯空）。
- 卯又为**斩关**（斩关课以卯酉为门户），斩关逢空，子爻空亡，孩子无法出生。
- 水的断语："卯本身斩关逢空，子难生出"——子爻空亡，无法怀孕。

### 4. 退茹课——退步
- 三传辰→卯→寅为退茹（退步连茹），主事体后退。
- 怀孕之事不进反退，没有怀上。

### 5. 蓦越课——事出突然
- 蓦越课主事出突然、意外，此处对应突然想知道是否怀孕而占。

## 经验提炼
1. **不备课断胎气不足**：胎孕以全备为吉，不备则胎气不足，难以成孕。
2. **天罡压正时**：天罡凶神压正时门，事体受阻。
3. **子爻空亡断不孕**：子爻（卯）空亡，孩子空，无法怀孕。
4. **斩关逢空**：斩关本主过关，逢空则关过不去，子难生出。
5. **退茹主不进**：退茹课主事体后退，怀孕之事不进。
