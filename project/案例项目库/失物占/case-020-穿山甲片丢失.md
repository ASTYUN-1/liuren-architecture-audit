# case-020 — 穿山甲片丢失（失物占·别责·午午自刑·腾蛇化龙）

## 原始信息
- **占问时间**：2026年4月24日 16:40
- **四柱**：丙午 壬辰 戊辰 庚申
- **月将**：酉将（谷雨后，中气换将）
- **旬空**：戌亥（甲子旬）
- **卦主**：母亲己酉年命
- **占类**：失物占
- **背景**：母亲今天早上从儿子镇上家搭车回农村家，下午打电话说药物不见了。药是镇上买的，不记得是落在儿子家还是已带回老家。儿子在自己家找了两遍没找到。
- **药物描述**：动物制作的中药片
- **反馈**：药物已带回老家，被母亲放进**厨房冰箱保鲜层**了。冰箱在**正南方**。当天晚上找到。药物是**穿山甲片**（非法禁药，托人搞的，治甲状腺结节）。母亲有点健忘。

## 水的断语验证

本案由AI初断→用户反馈→高手修正。关键技法如下：

### 1. 午午自刑→母亲自己忘记
中末传午(青龙)自刑。午为戊土之母（火生土），午午自刑正是**母亲自己疏忽忘记**，非被盗非他因。AI初断时忽略了此条。

### 2. 支上未（天空）下临午→正南方厨房
- 支为母亲家，支上未(天空)→被收起来了
- 未为木库→柜子、储藏空间
- 未下临地盘午→**午为正南**→厨房在正南方
- **反馈**：冰箱在厨房，正南方 ✅

### 3. 玄武在戌（空亡）→非盗，归藏
玄武主失盗，但戌空亡则非被盗，是**被收起来了**。戌为戊土之墓（火库），药物归藏入库之象。

### 4. 腾蛇化龙→穿山甲
发用寅(腾蛇)→中末午(青龙)=**蛇化龙**。穿山甲有鳞片，介乎蛇龙之间，正应此象。

### 5. 别责课→不在常规位
别责"不备"+"事主变更"，药物被移动过（从儿子家带到母亲家），不在常放的位置。AI初断误以为"干上神生日→东西在干方"，实则是母亲从干方带到支方。

## 经验提炼

| 技法 | 应用 |
|:----|:----|
| **午午自刑=母自忘** | 午为母星，自刑主自己忘记放了哪里 |
| **支上天空下临地盘=方位** | 天空所乘神下临地盘即物之处所 |
| **未为木库=柜子** | 未象木库，对应储藏柜、冰箱 |
| **玄武空亡≠被盗** | 玄武空则非失盗，乃自己收起来 |
| **别责课辨位置** | 别责主移动、不在常规位，干支都看 |
| **蛇化龙=鳞甲动物** | 腾蛇→青龙，有鳞片的动物（蛇/龙/穿山甲） |
