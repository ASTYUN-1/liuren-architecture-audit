# 手机丢失——八专帷簿课未丢，巳午车上柜中寻

## 原始信息
- **占类**：失物占
- **背景**：手机丢哪里了
- **提供者**：子白
- **水的断语**：子白断：手机类神为巳，在课上就没丢，你是有两个手机吗？初传卯空，应该是车上没找到，中末传午，是店里，乘六合在柜子里，找了两次。

## AI解析

### 1. 类神定位法
手机为电子通信设备，以巳（巳火、电子）为类神。课中巳乘蛇，巳为电子、为手机，蛇主细长、信号。午乘六合，午为火、为电子，六合主成双、为柜子。

### 2. 方位判断
- **初传卯空**：卯为车（卯为震、为动、为车），空亡→车上没找到
- **中末传午**：午为店（午为离、为市、为店），乘六合→柜子里
- 子白断两个手机：一个在车上（卯），一个在店里（午）

### 3. 能否找回
- **八专课**：干支同位，物未远走
- **帷簿课**：主遮蔽、隐藏
- **课上就没丢**：类神巳在课上，物未失
- 综合判断：没丢，可找到

### 4. 时间应期
未给出具体应期。反馈为"在车上找到的"——初传卯空，但最终在车上找到，空亡主暂时不见而非永失。

### 5. 反馈印证
在车上找到——初传卯为车，虽空亡但终在车上寻得。子白断"两个手机"——中末传午为店里，乘六合在柜子里，找了两次，应六合之数。
