# case-023 — 金手链吵架扔出车外被环卫妇人捡走（失物占·反吟·玄武临亥定西北）

## 原始信息
- **占问时间**：2026年10月14日 20:46（戌时）
- **四柱**：丙午 戊戌 辛酉 戊戌
- **月将**：辰（天罡）　**旬空**：子丑（甲寅旬）
- **课体**：反吟、龙战、斩关、斫轮
- **三传**：初传卯(天后·妻财) → 中传酉(青龙·兄弟) → 末传卯(天后·妻财) = **卯酉卯**
- **四课**：太阴 辰/辛 ｜ 勾陈 戌/辰 ｜ 天后 卯/酉 ｜ 青龙 酉/卯
- **背景**：男子与小三路边车上争吵，一气之下将金手链扔出车外，女子下车一直找到晚上未获。问"掉在哪里"。

## 核心断语
失物占取正类神（玄武、太阴）；玄武乘巳临**地盘亥**、太阴乘辰临**地盘戌**，两神同落**乾宫（戌亥）= 西北方**，正应引擎断语"捕获：赃在西北方喜事人家"。天后乘财爻卯发用 → **经一女人之手**（断语"女人窃去"）。

## 原始断法
1. **明占类**：失物占（问"在哪 / 能否找到"）。官方类神=玄武、太阴（手链为财，金饰亦归酉/太阴）。
2. **看显象**：空亡只在子丑，玄武/太阴/卯/酉四神皆不空 → **物为实体、未毁、可寻**；玄武乘巳带**破碎** → 物有磕碰；玄武临亥（闭口+天罗+驿马）→ 藏于隐蔽、不显眼、且**已被移动**处。
3. **定方位**：玄武临亥、太阴临戌（戌带天喜）→ **西北方（乾宫），戌亥之间**；断语"西北方喜事人家"（喜事=天喜临戌）与此吻合。
4. **性质**：**卯酉为门户道路**，反吟中读作"门户口/一出一入"，**不取东西方位**；断语"女人窃去" → 经女性之手。
5. **地形**：亥=水/低洼/沟渠；太阴乘辰（湿土/水库/草丛/墙根）临戌（土堆/墙根）→ 路边隐蔽、水沟、土堆墙根一带。
6. **应期**：反吟初末相同主速应 → 近日。

## 实际结果
**方位全对**：手链在**车的戌亥方**（西北，乾宫）——与所断"西北·戌亥"完全一致。
**"经女人之手"全对**：被**环卫妇人**捡走（女性，应天后之意）。
**结果**：卦主报警并联系环卫公司，**已寻回**。

## 复盘分析
### ✅ 命中
1. **方位**：玄武临亥 + 太阴临戌 → 乾宫戌亥 → 实际正是车的戌亥方。（失物占"正类神所临地盘定方位"再次验证）
2. **拾者性质**：天后乘财爻发用 → 女性；断语"女人窃去" → 实际=环卫妇人。（天后主中老年女性/劳作者）
3. **物在可寻**：类神不空 → 物未毁、可寻回；结果确已寻回。
4. **反吟速应**：反吟初末相同（卯…卯）主速应 → 近日内报警即寻回。

### ⚠️ 未及/偏差
- 断语"喜事人家"（天喜在戌）本案未特别核实是否对应具体"喜庆人家"，标"未验细节"。
- "被移动"之象（玄武带驿马）与"环卫妇人捡走"高度一致，但原始断法未点明"环卫/清洁工"身份（天后只给到"女性"，未细到职业）——可作下次精化方向。

### 🔑 核心技法提炼
1. **失物占方位 = 正类神（玄武、太阴）所临地盘**，优先于"物件类神下临"——本案若按物件类神酉（金饰）下临卯会误取"东"，正类神玄武/太阴皆指西北，故取西北。
2. **反吟课卯酉冲**：按"门户/道路/进出一开一合"读，**不作东西对立**（与毕业证伏吟复盘、case-010 反吟对冲法一致）。
3. **天后乘财发用 = 拾者为女性**；可进一步细化天将为"妇人/劳作者"。
4. **玄武临亥（水+暗+闭口+驿马）** → 藏于隐蔽处且已被移动。

## 经验提炼
当 失物占见反吟课、玄武与太阴同落乾宫（临亥/临戌）时，应断为"物在西北（戌亥）方、经女性之手"，因为失物占以玄武、太阴为正类神，其**所临地盘即方位**；反吟之卯酉冲只读作门户道路，不取东西。
