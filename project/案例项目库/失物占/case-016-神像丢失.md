# 神像丢失——申鬼乘贵为神祇，午地洗衣机中寻

## 原始信息
- **占类**：失物占
- **背景**：一尊神像在何处？
- **提供者**：水
- **水的断语**：神像就找申，鬼乘天乙乃神祇。下坐午地则是在南方，有靠近水处，明天则可以找到。

## AI解析

### 1. 类神定位法
神像为神祇、宗教物品，以申（申为鬼、为神道）为类神。申乘天乙贵人，贵人主尊贵、神祇，鬼乘天乙乃神祇之象——申为鬼（鬼道），乘贵人（尊贵），合为神像。

### 2. 方位判断
申乘贵人下临地盘午，午为**南方**。午为离、为火，但断语说"有靠近水处"——午虽为火，但课中见水象（亥子），且洗衣机为水器。反馈在洗衣机中找到——洗衣机为水器，靠近阳台（阳台为午之象，午为光明、为外）。

### 3. 能否找回
- **重审课**：事有反复，但终可成
- **间传课**：事有间隔，但可寻
- **涉三渊**：主深入，但可出
- **申乘贵人**：类神乘吉将，物可寻
- 综合判断：可找回

### 4. 时间应期
"**明天**则可以找到"——断语明确给出次日。反馈：第二天在洗衣机中找到。应期精准。

### 5. 反馈印证
- 第二天找到（应期精准）
- 南方家中洗衣机中找到（午为南方）
- 靠近阳台（午为光明、为外，阳台为午之象）

## 经验提炼
- **类神定位**：神像→申（鬼道），申乘贵人（尊贵）→鬼乘天乙乃神祇
- **方位判断**：申下临午→南方
- **水处判断**：午虽为火，但课中水象（亥子）→洗衣机（水器）
- **应期法**：明天（次日）——断语直接给出
- **涉三渊**：物在深处（洗衣机内）
