## 复盘要点

### ✅ 命中
1. **方位精准**: 类神酉下临地盘辰→东南方 ✅
2. **环境精准**: 辰=湿土/水边/田园，六合=草木/围栏，综合=水渠上 ✅
3. **走失性质**: 重审事从内起+玄武空亡→自己走失非被盗 ✅
4. **斩关格**: 鸡越过围栏/关口而去 ✅

### ❌ 失分
**应期偏晚**：断为2月13日未时/2月15日酉时，实际当天（2月11日）未时就找到了。

**失误原因**：丁马加未 → 推"最近未日"而非"占时即未时"。忽略了**占时（未时）与中传丁神（未）同位**这一极速信号，直接跳到了"日"的层级。

### 🔑 核心技法提炼

#### 应期速度：占时与课传同位的优先级

```
丁马加某支 → 该支 = 占时？ → 是 → 当天该时辰（最优先）
           → 该支 = 日支？ → 是 → 当天（次优先）
           → 否则 → 最近的该支日 → 再定时辰
```

**时→日→月，逐级递推，不可跳级。**

#### 迟速信号叠加判断

即使有贵人逆行、类神休囚等偏慢因素，当"占时入传"或"占时=丁马同位"出现时，极速信号压倒一切偏慢因素。应期速度判断须以最高优先级信号为准。
