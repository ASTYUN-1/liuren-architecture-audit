# case-002 — 充电器丢失（失物占·三合局定位）

## 原始信息
- **占问时间**：2023年12月12日 19:17 星期二
- **四柱**：癸卯 甲子 甲辰 甲戌
- **课体**：蒿矢，润下，励德
- **三传**：初传申(腾蛇)→中传子(青龙)→末传辰(玄武)
- **课式**：子申戌午 / 申辰午甲
- **反馈**：在东南方的客服区，正方形垃圾桶里。

## 水的断语
> 申腾蛇作充电器等类，下坐辰地则见于东南方，辰本身为网状物，被东西兜住了，申子辰课体为水润下则是此物在下面可见而非桌上一类。

## AI解析

### 1. 类神定位
- **申**为金属、电器之象，**腾蛇**为细长线缆之形，二者结合正应**充电器**（含线缆）。
- 申乘腾蛇，腾蛇本位在**巳**，巳为东南方——再次运用**神将互换**技法。

### 2. 三合局定位（核心技法）
本案最关键的技法在于**申子辰三合水局**：
- 三传申→子→辰，构成**申子辰润下课**
- 润下者，水势趋下，物在**下方**而非桌面等高处
- 此即"此物在下面可见而非桌上一类"的判断依据

### 3. 方位与环境细节
- **申下临辰**：辰为东南（巽宫），与腾蛇本位巳（东南）呼应
- **辰为网状物**：辰为水库，象渔网、网格、兜状物——"被东西兜住了"
- **反馈中的"正方形垃圾桶"**：辰为土，方形，正应垃圾桶之形

### 4. 反馈验证
- 东南方 ✅（申下临辰 + 腾蛇本位巳）
- 在下面而非桌上 ✅（申子辰润下）
- 被东西兜住 ✅（辰为网状/兜状）
- 正方形容器 ✅（辰为土，方形）
