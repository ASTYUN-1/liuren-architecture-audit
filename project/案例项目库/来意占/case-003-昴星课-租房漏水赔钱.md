# case-003 — 来意占·昴星课——租房漏水赔钱

## 原始信息
- **占问时间**：2024年1月5日 23:48 星期五
- **四柱**：癸卯 甲子 己巳 甲子
- **月将**：丑将（小寒前一日）
- **旬空**：戌亥（甲子旬）
- **年命**：未知 行年：未知 性别：未知
- **课体**：昴星，龙德，天罗，虎视，掩目
- **三传**：初传申(贵人)→中传午(朱雀)→末传辰(青龙)
- **课式**：戌阴 未午酉申 / 亥玄 午巳申己
- **反馈**：租的房子漏水但是不知道，房东发现水费不对让赔钱，最后赔了1000元。

## 水的断语

> 正时先锋门，子与日干本家未穿害，作外忧虑。值事门见太常（一字决玉连环的值事门是正时天官），一作聚会，二作衣食，三作医药。课体冬蛇掩目格事情多主暗中，祸在难见处。发端门，是申作休气，休气一字决中常作疾病。此五处见完，大象已定，主暗中有祸，祸主外来。

## AI解析

### 1. 课体总断——昴星·冬蛇掩目

此课与case-002（被同学传染发烧）为**同一课式、同一时间**，但占问人不同、年命不同，反馈结果截然不同。这是六壬"课同象异"的经典案例——课式相同，但占人不同、所问不同，断法随之调整。

课体为**昴星课**，冬季为**冬蛇掩目格**，主暗中行事、祸在难见处。对应"房子漏水但不知道，房东发现水费不对才知道"——漏水在暗处发生，事主毫不知情。

### 2. 先锋门（正时）——子与日干穿害

正时为**子**，日干己土本家为**未**（己未），子未相穿害。

- 穿害主意外、暗害、不情愿的牵连
- 子为外、未为内，穿害象意为"外事侵内"
- 水断"外忧虑"，对应"房东从外发现水费问题，找事主赔钱"
- 与case-002的"外忧虑"相同，但case-002是外部传染，此案是外部发现漏水

### 3. 值事门（正时天官）——太常

正时子的天官为**太常**。

- 太常三象：聚会、衣食、医药
- 此案中太常取**衣食**之象——水费（生活用水）属于"衣食"范畴
- 太常也主"常事、日常"，漏水是日常生活中的意外事件
- 与case-002取"医药"不同，同一太常在不同案例中取不同象

### 4. 课体——冬蛇掩目

冬蛇掩目格，主暗中行事、祸在难见处。

- 对应"漏水在暗处发生，事主不知情"
- 房东发现水费异常→查表→发现漏水，整个过程是"暗中之事被揭露"
- 课体定调"暗中有祸"，与反馈高度吻合

### 5. 发端门（初传）——申作休气

初传**申**乘贵人，水取**休气**断之。

- 休气主退气、衰病、损耗
- 此案中休气不作"疾病"解，而作"损耗"解——水费异常增加是财物的损耗
- 同一申休气，case-002断疾病，此案断损耗，体现了**同象异断**的灵活性

### 6. 为何同一课式断出不同结果

| 要素 | case-002（发烧） | case-003（漏水赔钱） |
|------|-----------------|---------------------|
| 年命 | 壬午（午朱雀→发烧） | 未知 |
| 太常取象 | 医药 | 衣食（水费） |
| 休气取象 | 疾病 | 损耗 |
| 反馈性质 | 身体疾病 | 财物损失 |

核心差异在于**年命不同**。case-002有年命午作朱雀，直接锁定发烧；此案无年命信息，故休气不作疾病而作损耗，太常不作医药而作衣食。

### 7. 反馈验证

> "租的房子漏水但是不知道，房东发现水费不对让赔钱，最后赔了1000元。"

- 漏水不知→冬蛇掩目（暗中行事）
- 水费异常→太常（日常/衣食）
- 赔钱→休气（损耗）
- 房东发现→子未穿害（外事侵内）
- 1000元→丑作八数（丑为八，1000为八的倍数，但此案未直接出现丑，可作参考）

## 经验提炼

1. **同课异断**：同一课式、同一时间，不同占人、不同年命，断法不同。年命是区分的关键变量。
2. **太常取象的灵活性**：太常三象（聚会、衣食、医药），根据具体场景选择最贴合的象意。
3. **休气不唯疾病**：休气主退气、衰败，可作疾病也可作损耗，需结合其他信息综合判断。
4. **冬蛇掩目的双重性**：既可以是"暗中被传染"，也可以是"暗中漏水"，课体定调的是"暗中"这个性质，而非具体事件。
5. **八门入手法的一致性**：先锋门（穿害）→值事门（太常）→课体（冬蛇掩目）→发端门（休气），四门逐层推进，每门取一象，汇合定大象。
