# case-013 — 寻访·伏吟课——寻访贵人

## 原始信息
- **占问时间**：2023年8月15日 12:23 星期二
- **四柱**：癸卯 庚申 乙巳 壬午
- **月将**：午将（立秋后）
- **旬空**：寅卯（甲辰旬）
- **课体**：伏吟，斩关，六仪
- **三传**：初传辰(勾陈)→中传巳(青龙)→末传申(太常)
- **课式**：青青勾勾 / 酉玄 巳巳辰辰 / 戌阴 巳巳辰乙
- **背景**：寻访贵人并请至家中，来否？为何而来？何时来？
- **反馈**：求财之事，涉及土地问题，对家恶意竞争，正在打官司，期望贵人相助，今日相请后托人言有事婉拒，遂等下次相请。后反馈说贵人主动想来，今起课问是因心里拿不准，但贵人因为特殊原因推脱了。

## AI解析

### 1. 课体总断——伏吟·斩关·六仪

**伏吟课**：天地盘皆同，主静、主迟、主不动。对应"贵人推脱不来"——伏吟主事难动，贵人难以成行。

**斩关课**：斩关主冲破阻碍、出行。伏吟遇斩关，是"静中求动"之象——虽伏吟主静，但斩关有冲破之意，对应"贵人想来但被特殊原因推脱"——有动意但未能动。

**六仪课**：六仪主吉庆、逢凶化吉。对应"求财之事"——虽有阻碍但最终有望。

### 2. 寻访占的核心逻辑

寻访占与来意占、射覆不同：寻访占需要判断**人来不来、为何来、何时来**三个问题。此案中水的断语未直接给出，但可以从课象中还原推理过程。

### 3. 先锋门（正时）——午

正时为**午**。

- 午为日干乙木之**食神**（乙木生午火为食神），食主求财、谋事
- 午乘白虎（正时午的天官为白虎），白虎为道路、为官非
- 对应"求财之事涉及官司"——白虎为官非

### 4. 发端门（初传）——辰乘勾陈

初传**辰**乘**勾陈**。

- 勾陈主田土、争斗、官司
- 辰为天罡，主斗讼、牢狱
- 辰为日干乙木之财（乙克辰土为财），勾陈为田土
- 对应"求财之事，涉及土地问题，对家恶意竞争，正在打官司"
- 发端门即见勾陈+辰，直指"田土官司"

### 5. 移易门（中传）——巳乘青龙

中传**巳**乘**青龙**。

- 青龙为吉神，主贵人、喜事
- 巳为日干乙木之**病地**（乙木病在巳），但巳为贵人（巳为日贵）
- 对应"贵人"——青龙为贵，巳为日贵
- 中传为事之变，对应"期望贵人相助"

### 6. 归计门（末传）——申乘太常

末传**申**乘**太常**。

- 太常主日常、饮食、聚会
- 申为日干乙木之**官鬼**（申金克乙木），官鬼主官非、压力
- 末传为事之终，对应"最终贵人因特殊原因推脱"
- 太常+申：贵人（太常）被官鬼（申）所阻

### 7. 伏吟课——贵人为何不来

伏吟课天地盘皆同，主静、主迟。

- 伏吟主"不动"，对应"贵人推脱不来"
- 但伏吟遇**斩关**，有"静中求动"之意
- 反馈"贵人主动想来"——斩关的动意
- "因特殊原因推脱"——伏吟的静象最终占了上风

### 9. 反馈验证

> "求财之事，涉及土地问题，对家恶意竞争，正在打官司，期望贵人相助，今日相请后托人言有事婉拒，遂等下次相请。后反馈说贵人主动想来，今起课问是因心里拿不准，但贵人因为特殊原因推脱了。"

- 土地问题→初传辰勾陈（田土）
- 打官司→辰为天罡（斗讼）、勾陈（官司）
- 求财→辰为乙木之财
- 贵人相助→中传巳青龙（贵人）
- 贵人推脱→伏吟（不动）、末传申官鬼（被阻）
- 贵人主动想来→斩关（静中求动）
- 特殊原因→申为官鬼（外部压力/原因）

## 经验提炼

1. **伏吟主静、主迟**：寻访占中见伏吟，主被访者难以成行或迟迟不来。
2. **斩关为静中求动**：伏吟遇斩关，有"想动但动不了"之意，对应"贵人想来但来不了"。
3. **勾陈+辰=田土官司**：勾陈为田土，辰为天罡斗讼，二者叠加直指"土地纠纷/官司"。
4. **巳为日贵主贵人**：巳为乙木之日贵，青龙为吉神，中传巳青龙断"贵人相助"。
5. **申为官鬼主阻碍**：末传申为官鬼，主外部压力/原因导致贵人无法成行。
6. **寻访占的三问**：来否（伏吟→不来）、为何来（辰勾陈→土地官司）、何时来（伏吟→迟/未定），三问皆可从课象中找到答案。
