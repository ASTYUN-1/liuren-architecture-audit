# case-005 — 来意占·昴星课——户主卖房父亲生病

## 原始信息
- **占问时间**：2023年11月26日 11:03 星期日
- **四柱**：癸卯 癸亥 戊子 戊午
- **月将**：寅将（大雪前）
- **旬空**：午未（甲申旬）
- **年命**：未知 行年：未知 性别：未知
- **课体**：昴星，龙战
- **三传**：初传巳(太常)→中传申(青龙)→末传丑(贵人)
- **课式**：玄青勾贵 / 巳常 辰申酉丑 / 午虎 申子丑戊
- **背景**：问户主为何卖房。我今天看房，然后都是新的本来要作婚房，突然卖了。
- **反馈**：其父亲生病了。

## 水的断语

> 三传吊丧全逢，天罡压支阴，申作日干长生是为其父，则见其父亲有灾，青龙本家在寅为今年病符，可见其家长辈得病。

## AI解析

### 1. 课体总断——昴星·龙战

此课为**昴星课**，无遥克、无贼射，天地盘皆静中求动。昴星课主"关梁闭塞、出行艰难"，对应"突然卖房"这一反常举动。

**龙战课**：卯酉为门户，龙战于野，主门户不安、家庭变动。对应"婚房突然出售"——婚房为家庭门户之事，龙战主家庭内部有变。

### 2. 三传吊丧全逢——核心断法

水断"三传吊丧全逢"，这是此案最关键的技法。

- **吊丧**：巳为吊（巳作太常，太常为丧事），申为丧（申为白虎本家），丑为墓（丑为金墓）
- 三传巳→申→丑，依次为吊→丧→墓，构成完整的丧葬链条
- 三传吊丧全逢，主家中长辈有灾病之象
- 虽然反馈是"生病"而非"去世"，但吊丧全逢提示病情严重到足以引发卖房筹款或家庭变故

### 3. 天罡压支阴

**天罡**为辰（辰为天罡），**支阴**为支上神。

- 此课支为子（戊子日），支上神为丑（子上见丑）
- 天罡辰压支阴，辰为凶神，主斗讼、死丧
- 支为宅、为家，天罡压支阴，主家庭内部有凶事
- 对应"家中出事导致卖房"

### 4. 申作日干长生——为父

**申**为日干戊土之**长生**（戊土长生在申）。

- 长生为父母、为长辈、为基础
- 申乘青龙，青龙为吉神，但申为丧（吊丧链条中的一环）
- 水断"申作日干长生是为其父"，将长生定位到父亲
- 申在支阴（申在支子之阴神位），说明父亲之事影响家庭（支）

### 5. 青龙本家在寅——病符

**青龙**本家在**寅**。

- 2023年癸卯年，病符在寅（病符为年神煞，寅为当年病符）
- 青龙为吉神，但青龙本家临病符，吉神被病气所侵
- 水断"青龙本家在寅为今年病符，可见其家长辈得病"
- 青龙也主"父亲"（青龙为东方、为震、为长男），与申作长生为父呼应

### 6. 为何卖房而非其他

- 三传吊丧全逢→家庭有重大变故（长辈病重）
- 天罡压支阴→家庭内部有凶事
- 申作长生为父→父亲出事
- 龙战课→门户变动（卖房是门户变动的一种）
- 婚房突然出售→家庭急需用钱（治病）或家庭计划突变

### 7. 反馈验证

> "其父亲生病了。"

- 父亲→申作日干长生
- 生病→青龙本家临病符、三传吊丧全逢
- 卖房→龙战课（门户变动）、天罡压支阴（家庭有凶）
- 突然出售→昴星课（静中求动，事出突然）

## 经验提炼

1. **三传吊丧全逢**：巳为吊、申为丧、丑为墓，三传构成完整的丧葬链条，主长辈灾病。这是来意占中判断"家庭长辈有灾"的核心技法。
2. **长生定位父亲**：日干长生为父（戊土长生在申），申在支阴，说明父亲之事影响家庭。
3. **青龙本家临病符**：青龙本家在寅，寅为当年病符，吉神被病气所侵，主长辈得病。
4. **天罡压支阴**：天罡辰压支上神，主家庭内部有凶事，是来意占中判断"家中有事"的重要信号。
5. **龙战课主门户变动**：龙战于野，主家庭门户不安，对应卖房这一家庭重大决策。
6. **来意占的核心逻辑**：问"为何卖房"，不直接断卖房本身，而是断卖房背后的原因——父亲生病。这是来意占"透过现象看本质"的典型应用。
