"近期运势：虚惊变动、先苦后甘。有耗财之象，注意钱财虚诈。驿马动意浓，必有变动，但难以实际成行。压力虽大但虚而不实，不必过分担忧。"

## 反馈验证分析

### ✅ 正确部分：耗财
- **课象依据**：干上巳一身兼三煞
  - ① **破碎煞**（甲戌日巳为破碎）→ 主破财损耗
  - ② **小耗**（丙午年小耗在巳）→ 主小破费
  - ③ **睨上逢脱**（甲木生巳火，巳火生太常，泄气脱耗）→ 主虚诈耗财
- 三重神煞叠加 → 耗财必然

### ⚠️ 修正部分：驿马空=虚动
- **AI原断**："驿马动意浓，必有变动"
- **老师傅纠正**："驿马空，他没有动"
- **根源分析**：课义"动意尤浓"确实主有动意，但初传申为驿马且逢空亡，空则虚——心动而未行，不是真正成行。这是AI过于相信课义的字面提示，没有仔细看驿马落地的状态。

### 💡 提升方向：多参神煞
老师傅"建议多向神煞方面看看资料"是点睛之笔——本课中很多判断都可以在神煞层面精确化：

| 判断项 | 课体+类神粗粒度 | +神煞精细化 |
|--------|----------------|-------------|
| 耗财 | 睨上逢脱，大致有耗财 | 破碎煞+小耗+睨上逢脱三重叠加 → 耗财必然 |
| 动与不动 | 课义"动意尤浓"→ 有动 | 驿马空亡 → 虚动/心动/不动 |
| 空鬼 | 申鬼空亡，凶减半 | 驿马空+鬼空双空叠 → 既不动也凶不成 |
| 末传吉 | 天后+日禄，吉 | 天后+日禄+月德（月德在寅）→ 三吉叠加 |

## 核心技法提炼

### 技法1：🚩 驿马空亡=虚动心动非实动
**公式：** 驿马现于课传 + 不空 = 真动；驿马空亡 = 虚动/心动/计划动
- 本课驿马申空亡 → "心动测近运"的课象真意就是"心动而未行"
- 如果AI当初读出"你心里想动，有想法有计划，但实际不会行动"，就完全准确了
- **应用场景**：出行占、事业变动占、来意占中的"动向"判断

### 技法2：🚩 破碎煞+小耗+脱上逢脱三重叠加断耗财
**公式：** 破碎煞（日干支定） + 小耗（年支定） + 睨上逢脱（干上生天将）
- 单一神煞可能只是"微耗"，但三重叠加则耗财之意确凿
- 破碎煞速查：子日酉、丑日辰、寅日巳、卯日午、辰日未、巳日申、午日酉、未日辰、申日亥、酉日子、戌日丑、亥日寅
  - 本课甲戌日 → 破碎在巳 ✓
- 小耗速查：太岁前五位（丙午年大耗在午，小耗在巳）
- **应用场景**：交易占、财运占、来意占中的钱财判断

### 技法3：🚩 课义与类神状态需分别看
**公式：** 课义=总纲方向，类神状态=落实程度
- 课义"动意尤浓" → 方向上有动意 ✓
- 驿马申空亡 → 落实到具体上是虚动 ✗
- 两者不矛盾，是"意图vs成果"的关系
- **心法**：先读课义知大势，再审类神知落实。课义提供"想什么"，类神提供"成什么"。

### 技法4：🚩 神煞是精细化调整关键
- 粗粒度：课体+类神 → 知吉凶方向（压力大、有动意、先苦后甘）
- 细粒度：神煞叠加 → 定具体事项（耗财、虚动、月德护佑）
- 老师傅点出神煞，正是六壬断课中从"大概齐"到"精准"的关键一步

### 技法5：年命申即初传=事主正处课象核心
- 申命男，初传申发用，年命即发用 → 课象直接对应事主本人
- 申为日鬼克日干 → 事主感受到被克（对应奇门"死门鬼爻来克"）
- 申空亡 → 克也是虚克，非实质伤害
