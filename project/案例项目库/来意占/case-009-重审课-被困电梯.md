# case-009 — 射覆·重审课——被困电梯

## 原始信息
- **占问时间**：2024年1月29日 19:50 星期一
- **四柱**：癸卯 乙丑 壬辰 庚戌
- **月将**：子将（大寒后）
- **旬空**：午未（甲申旬）
- **年命**：己卯 行年：戊申 性别：女
- **课体**：重审，六仪，涉三渊
- **三传**：初传申(青龙)→中传戌(白虎)→末传子(玄武)
- **课式**：青合贵阴 / 亥常 申午卯丑 / 子玄 午辰丑壬
- **背景**：射覆我刚刚经历了什么
- **反馈**：被困电梯，生死二十分钟

## AI解析

### 1. 课体总断——重审·六仪·涉三渊

**重审课**：事从内起，反复审察。对应"被困电梯"——在封闭空间内反复经历恐惧。

**六仪课**：六仪主吉庆、逢凶化吉。对应"生死二十分钟但最终脱困"——虽险但终得救。

**涉三渊**：涉三渊为课格，主涉险难、进退两难。对应"被困电梯"——卡在楼层之间，进退不得。

### 2. 射覆的核心逻辑

射覆（占测已发生之事）与来意占不同：来意占是"问什么"，射覆是"发生了什么"。射覆需要从课象中还原**已经发生的事件**，更注重课象的"事象"还原。

### 3. 先锋门（正时）——戌

正时为**戌**。

- 戌为火库、为囚禁、为牢狱
- 戌乘天空（正时戌的天官为天空），天空主虚、空、狭小空间
- 戌为闭口（戌为闭口之一），主封闭、无法言语
- 对应"被困在封闭空间（电梯）"

### 4. 发端门（初传）——申乘青龙

初传**申**乘**青龙**。

- 申为日干壬水之**长生**（壬水长生在申），但申为白虎本家，乘青龙为吉神
- 申为传送，主移动、运输
- 青龙为吉神，主生机
- 对应"电梯"——运输工具（传送），但被困（申为白虎本家，有凶性）

### 5. 移易门（中传）——戌乘白虎

中传**戌**乘**白虎**。

- 白虎为凶神，主血光、死丧、惊恐
- 戌为火库、为囚禁
- 白虎+戌=被困中的惊恐
- 对应"生死二十分钟"——白虎主生死之危
- 中传为事之变，对应"被困过程中经历的恐惧"

### 6. 归计门（末传）——子乘玄武

末传**子**乘**玄武**。

- 玄武为暗昧、隐藏
- 子为日干壬水之**帝旺**（壬水帝旺在子），旺则终将脱出
- 玄武主暗，对应"电梯黑暗的封闭空间"
- 末传为事之终，对应"最终脱困"

### 7. 课象还原

| 课象 | 象意 | 对应事件 |
|------|------|---------|
| 正时戌（天空/闭口） | 封闭空间 | 电梯 |
| 初传申（青龙/传送） | 运输工具 | 电梯运行 |
| 中传戌（白虎） | 惊恐、生死 | 被困恐惧 |
| 末传子（玄武/帝旺） | 暗、终旺 | 黑暗后脱困 |
| 涉三渊 | 进退两难 | 卡在楼层间 |
| 六仪 | 逢凶化吉 | 最终得救 |

### 8. 反馈验证

> "被困电梯，生死二十分钟"

- 被困→戌（闭口/囚禁）、涉三渊（进退两难）
- 电梯→申（传送/运输）
- 生死→白虎（凶神）、六仪（逢凶化吉）
- 二十分钟→戌为五数（河图），但二十分钟可作"短暂"解
- 最终脱困→末传子帝旺、六仪课

## 经验提炼

1. **射覆与来意占的区别**：射覆是"还原已发生之事"，更注重课象的具象化还原；来意占是"判断所问之事"，更注重逻辑推理。
2. **申为传送=运输工具**：申为传送，在现代射覆中可直断"电梯、车辆"等运输工具。
3. **戌为闭口=封闭空间**：戌为闭口、为火库，在射覆中可断"封闭的金属空间"（电梯轿厢）。
4. **白虎+涉三渊=险境**：白虎为凶，涉三渊为进退两难，二者叠加断"身处险境、进退不得"。
5. **六仪课主逢凶化吉**：虽课象凶险（白虎、涉三渊），但六仪课体提示最终能脱困。
6. **射覆的"事象"还原法**：从课体（涉三渊→进退两难）→神将（白虎→惊恐）→地支（戌→封闭）→天官（天空→虚/空），逐层还原事件全貌。
