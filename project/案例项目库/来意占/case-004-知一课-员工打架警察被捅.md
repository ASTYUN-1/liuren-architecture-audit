# case-004 — 来意占·知一课——员工打架警察被捅

- **四柱**：癸卯 壬戌 乙巳 丁丑
- **月将**：辰将（寒露后）
- **旬空**：寅卯（甲辰旬）

- **三传**：初传未(腾蛇)→中传戌(太阴)→末传丑(白虎)
- **课式**：玄贵阴蛇 / 子常 亥申戌未 / 丑虎 申巳未乙
- **反馈**：三个员工喝酒之后打架，其中一个被打瘫痪了，警察过来拉架，被捅了一刀，然后警察过来直接查封公司，朋友花了一共80多万又赔钱，又打通关系，才能继续开。（丑作八数）

## 水的断语

> 正时门丑与日干破，主外破事。值事门白虎作官鬼恐见祸事。外事门发用见财而动，但三传全财反生为鬼，中传见戌乘太阴主阴人欲在我取财时害我，故发端腾蛇主惊恐，又末传见财闭口又得白虎杀神，作日破又主血灾破财。最后破财被伤。比用者事有两端，家中有官贵来，官鬼坐长生也被制，上神见玄武则欲取财冲家门，终无恙。

## AI解析

### 1. 课体总断——知一·稼穑·游子

此课三课体叠加，各有指向：

- **知一课**：事有两端，善恶不定，比用者事有两端。对应"员工打架"和"警察介入"两条线索。
- **稼穑课**：三传皆土（未戌丑），土主稼穑、田地、不动之象，但此案中土反主"众人聚集"（三个员工）、"争斗"（土性滞重，冲突难解）。
- **游子课**：三传皆土为游子课，主远行、移动、不安定。对应"警察出动"、"公司被查封"等动荡事件。

### 2. 先锋门（正时）——丑与日干破

正时为**丑**，日干乙木，丑为乙木之**墓库**（乙木墓在戌，丑为金库，但丑与乙有破的关系）。

- 丑与乙的破害关系，水断"主外破事"
- 丑为白虎的本家（白虎本家在丑），正时见丑即见白虎之根
- 丑作八数，反馈中"80多万"应丑八之数

### 3. 值事门（正时天官）——白虎

正时丑的天官为**白虎**（丑为白虎本家）。

- 白虎作官鬼（丑为乙木之鬼，乙木克丑土为财，但丑为金库反克乙木），主祸事、血光、官非
- 水断"恐见祸事"，白虎发用即见凶象
- 白虎为道路之神，对应"警察"（公权力、执法者）

### 4. 发端门（初传）——未乘腾蛇

初传**未**乘**腾蛇**。

- 腾蛇主惊恐、虚惊、缠绕
- 未为乙木之财（乙克未土），但三传全财（未戌丑皆土），财多反生鬼
- 水断"发端腾蛇主惊恐"，对应"打架→瘫痪→警察被捅"的惊恐事件链
- 腾蛇为缠绕之象，对应"三个员工喝酒打架"的纠缠局面

### 5. 移易门（中传）——戌乘太阴

中传**戌**乘**太阴**。

- 太阴主阴人、暗中、私密
- 戌为乙木之墓（乙木墓在戌），又为火库
- 水断"中传见戌乘太阴主阴人欲在我取财时害我"
- 对应"员工酒后打架"——酒为阴物（水），酒后失态为阴私之事
- 太阴也主"暗中谋划"，对应员工酒后失控的暗中因素

### 6. 归计门（末传）——丑乘白虎

末传**丑**乘**白虎**。

- 白虎为杀神，丑为金库，金主血光
- 水断"末传见财闭口又得白虎杀神，作日破又主血灾破财"
- 末传丑为闭口（丑为闭口之一），主事终难言、损失难追
- 对应"警察被捅一刀"（血灾）、"花80多万"（破财）

### 7. 三传全财反生为鬼——核心技法

此案最关键的技法点是**三传全财反生为鬼**：

- 三传未戌丑皆土，为日干乙木之财
- 但财多身弱（乙木在戌月为死地），财反生鬼（土生金，金为乙木之官鬼）
- 水断"三传全财反生为鬼"，即求财反招祸
- 对应"员工因喝酒（酒为财所耗）打架（鬼）→警察介入（官鬼）→被捅（血光）→破财（80多万）"

### 8. 反馈验证

> "三个员工喝酒之后打架，其中一个被打瘫痪了，警察过来拉架，被捅了一刀，然后警察过来直接查封公司，朋友花了一共80多万又赔钱，又打通关系，才能继续开。"

- 员工打架→知一课（事有两端）、腾蛇（惊恐缠绕）
- 瘫痪→白虎（血光凶神）
- 警察被捅→白虎作官鬼（公权力见血光）
- 查封公司→白虎为执法、官鬼为官非
- 花80多万→丑作八数
- 打通关系继续开→"官鬼坐长生也被制，上神见玄武则欲取财冲家门，终无恙"

## 经验提炼

1. **三传全财反生为鬼**：来意占中见三传皆财，不可直断得财，需看日干强弱。身弱财多，财反生鬼，求财招祸。
2. **白虎作官鬼**：白虎为凶神，官鬼为官非，二者叠加主"因官非/执法而见血光"。
3. **腾蛇发用主惊恐**：发端门见腾蛇，事之始即有惊恐，对应突发事件。
4. **丑作八数应验**：丑在河图为八，反馈中80多万应数，说明来意占中神煞之数可断金额。
5. **知一课"事有两端"**：比用课体提示事件有两条线索交织，此案中"员工内斗"与"警察介入"并行。
6. **稼穑课的变通**：稼穑课本主田地农事，但在现代占中可作"众人聚集"、"土性滞重冲突"解。
