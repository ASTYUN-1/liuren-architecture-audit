## 复盘

### 命中
- 「凶亦解散」的定盘话抓对了：全课俱空 + 无鬼 + 无白虎发用 + 本命德禄入中传 ⇒ 人安。
- 通讯断的取象（玄武乘辰·阴位 + 巳亥冲绝）与「泳池信号差」对得很准，是本案最硬的一击。

### 漏读（均有盘面依据）
1. **反吟的「反复」只读了折返，没读「决定反复」**。断语原文「**事带两途**，远近系心，往返无常，有疑莫决」——「两途」正是「说不去／又去了」的两条相反说法。初判把它全部用在「行程折返、门户动摇」。
2. **水象整体未提，三处同向**：①三传亥→巳→亥，亥水两见且临日干；②支上戌之阴神为辰，辰乘**玄武**（水神·暗昧）且**辰为水库**；③**本命巳临地盘亥**，本命正落水地。第三处是硬伤——`shiwu-xunren` 要求空间分层必须标「类神临处」，初判只把「巳临亥」读成绝地，未读成水边。
3. **元胎「事体皆新」未用**：元胎主事体皆新、临时起意，正合「中午说不去、晚上临时又去」。
4. **应期漏掉最近锚点**：占时＝戌，支上神亦＝戌，**时与归处同支**，按《说约》「正时为用，应在当时」应于本时（戌时）。初判未取此锚。

### 内部矛盾（无须外部佐证即可查出）
先判「戌为月建、旺不为空、兄弟爻是实的」，随即又用「天马落空＝想动没动成」。同一支不能既旺实又落空。既判戌实，则天马实而动、兄弟临支上＝人已在归处／归途——这与「今晚不归」自相矛盾。

### 被题干诱导
用户问「是忙还是别的事」，初判把勾陈的「迟滞／羁留」直接落到「工作加班」。勾陈只负责「滞留」，落点须看**阴神**：戌之阴神为辰（玄武·水库）→ 滞在水里，不在工位。属题干导向的过度具体化。

### 应期为何偏了一个量级
初判用「一课占一天内：初传卯辰／中传巳午未／末传申酉」判「当晚应期已走完」，据此推到次日。**该方法是以卯起、酉止的日间分段，戌时以后不在其覆盖范围**。夜间占（戌亥子丑时）应以「正时为用应当时」优先，不得以日间分段判「已过」。

### 过程迟滞的象
晚约 2 小时：**勾陈临干主迟滞**（初判判对「迟滞」但绑错落点），反吟主往来延宕。至于「反吟推一位时辰（酉→戌）」属事后候选，标从疑，不作规则。

## 证据与边界
- 断语原文（引擎 `zhiZhi` / `jiYingQian`）：「吉固消亡，凶亦解散」「事带两途」「行人不得归」「来去俱空岂动移」——「行人不得归」与「戌时归」并存，说明该句只能读「当晚原定归期不成／延后」，不能读「今夜不归」；此为本课边界，不外推。
- 空亡二重鉴别：戌得月建＝旺不为空（`kongwang-bianzhi`「旺不为空」基本原则，与分房课 c02 同法）；亥在戌月休囚又受戊土克＝真空。学派张力：断语按旬空直断「四课三传无一不空」，与旺衰鉴别并存，本课取鉴别。
- 应期量级：《大六壬说约》八级量级链「正时为用，应在当时」；`yingqi-panduan` A2「反吟应期优先取中传、中传值日即兑现」（源自 case-021）——本案证明「中传值日」不是反吟的唯一锚点，最近锚点优先。
- 占类口径：寻人／行人并入 **出行占**（`liuren-cases` 旧名映射：行人占→出行占）。
- 边界：单案；未做人工审核；「泳池」为现实反馈所补，非初判推出，不得回写为初判命中；年命按 2001 辛巳、虚 26 取行年丁未，若虚岁口径不同则行年变动、相关判读需重算。

## 经验提炼
1. 反吟＋元胎占行程／行人：先查「两种相反说法之间反复」（说不去又去、说走又留），再看路上折返——断语「事带两途」是首选读法。
2. 占人不见且涉水季／水事：亥子水重、玄武乘辰（水库）、本命或类神临亥子 → 水域（泳池、河边、浴场）优先级高于「工作场所」。
3. 天马／驿马与旬空并见：先过旺衰鉴别——月建之支不空；不可同支既判旺实又判虚动。
4. 勾陈临干只定「滞留」，落点看阴神。
5. 夜间占（戌亥子丑时）断应期：优先「正时为用应当时」并用「时是否与支上神同支」核对；禁用「初卯辰／中巳午未／末申酉」判「应期已过」。
6. 兄弟／类神旺实临支上：不是「人不在家」的默认依据；旺实临支即「人已在归处／归途」的直接依据。
