# case-002 — 换充电器来回折腾（出行占·伏吟斩关稼穑游子课）

## 原始信息
- **占问时间**：2026年7月20日 14:41（未时）
- **四柱**：丙午 乙未 乙未 癸未
- **月将**：未将
- **旬空**：辰巳（甲午旬）
- **课体**：伏吟，自信，斩关，稼穑，游子
- **三传**：初传辰(勾陈○)→中传未(白虎)→末传丑(腾蛇)
- **课式**：乙未日第一局干上辰
- **反馈**：
  - 没花钱（充电器以旧换新）
  - 30块欠款忘了要
  - 路程安全，16:03到家

## 断语
> "你这趟去大概率不用花大钱，但30块要不回来或要费口舌。路程安全但路上有耽搁。大约申时末到酉时初到家。而且这个事还没完——末传丑蛇主缠绕，换完充电器回来还会有后续问题。"
>
> 实际：没花钱、忘了要钱、16:03到家但发现充电桩也不供电、又折腾到16:25才完事。

## AI解析

### 1. 课体分析
- **伏吟课**：天地盘相同，主静、主迟、主呻吟。万物不动之象，问题藏在原地未动。
- **自信课**：伏吟专名，"自信自守"——一开始就认定是充电器坏了，自信地跑去换。
- **斩关课**：魁罡发用，主动。伏吟遇斩关，为"静中求动"——本来在家不动，为换充电器而出门。
- **稼穑课**：三传纯土，厚重缓慢。土主迟滞，出行如在泥地骑车，速度慢，事情拖沓。
- **游子课**：三传俱季神（辰、未、丑），主行人在外游移——换完充电器回来发现还没完，又跑出去排查。

### 2. 应验复盘

| 问题 | 断语 | 实际反馈 | 课象对应 |
|------|------|---------|---------|
| 要花钱吗？ | 不用花大钱（发用空亡虚而不实） | ✅ 没花钱 | 发用辰空亡，财虽遍地但虚 |
| 30块能要回吗？ | 要不到或费口舌 | ⚠️ 忘了要 | 发用空亡+勾陈，事虚且拖 |
| 路程安全？ | 安全（白虎伏吟不动） | ✅ 安全往返 | 白虎虽临支但伏吟不动 |
| 到家时间？ | 申时范围（16:03） | ✅ 申时初到家 | 发用空亡缩短了时间 |
| 事完了吗？ | 没完（末传丑蛇缠绕） | ✅ 回来一试还充不上电 | 末传丑蛇主缠绕反复 |
| 最终怎么解决的？ | 问题在原处（伏吟） | ✅ 充电桩一直就是坏的 | 伏吟主一切未变 |

### 3. 伏吟课的"假动"本质
此课最精妙之处在于伏吟+斩关的矛盾：
- **斩关**让人以为要出门有大动作（换充电器）
- **伏吟**揭示根子没动（充电桩本来就坏了）
- 骑车去换充电器是"静中求动"的假动作——看似动了，实际上真正的问题（充电桩）纹丝未动
- 这就是为什么换完回来一试还是不行——伏吟告诉你：**问题在原地，你没找对地方**

### 4. 三传财局与求财
- 三传纯土皆是乙木之财（遍地财神）
- 但初传空亡 → 虚而不实，看着有钱实则没有
- 发用勾陈主拖延 → 30块的事拖着拖着就忘了
- 毕法"传财化鬼财休觅" → 财多身弱，强求反招不愉快
- 末传丑腾蛇 → 缠绕到底，最终也没跟商家提那30块

### 5. 末传丑蛇的"缠绕"应法
末传丑乘腾蛇，在本次占中应了多层缠绕：
1. **换完回来还有事** → 以为完了，结果充电桩也不行
2. **反复排查** → 试充电器→试充电桩→再确认→最终定位问题
3. **时间拖长** → 16:03到家发现还有问题，折腾到16:25才彻底完事
4. **腾蛇主发现隐藏问题** → 最终发现根子在充电桩，充电器根本没坏

### 6. 出行时间应期
- 发用辰空亡 → 应期缩短，实际16:03（申时初）到家，早于预期的申时末
- 末传丑蛇 → 缠绕拖延到16:25才彻底完事，正好应了末传的"尾巴"

## 经验提炼
- **伏吟课出行占**：断行而不远、动而不久；问题不在路上而在原地
- **伏吟+斩关辨真假动**：看似要动，实则问题根源未变——在外折腾一圈，最后发现根子在家
- **末传腾蛇的缠绕象**：不仅指第一次没完，还指反复排查折腾
- **发用空亡缩短应期**：虚象快，实际到家时间早于预期
- **"传财化鬼"的现代应用**：遍地财神却拿不到——换充电器不用花钱（财虚），30块也忘了要（财空）
