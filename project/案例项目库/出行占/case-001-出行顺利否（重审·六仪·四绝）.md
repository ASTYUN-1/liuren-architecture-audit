# case-001 — 出行顺利否（出行占·重审六仪四绝课）

## 原始信息

- **四柱**：甲辰 丙寅 己亥 己巳
- **月将**：子将
- **旬空**：辰巳（甲午旬）
- **课体**：重审，六仪，四绝

- **课式**：辰常 丑午酉寅 / 巳虎 午亥寅己
- **反馈**：自己的车手动挡怕熄火，在城市内与朋友换车回去，父亲身体不好刚刚住院出来。同时要和朋友聚一聚。丑日出行。

## 水的断语
> "正时门是巳作父爻，又冲宅门，值事门见白虎则是道路神。巳是旬空则有解散的像。因为正时门已经有出行的类神了，看巳上白虎本家在申作道路，申勾陈主迟滞，勾陈上见辰太常是原因，有个聚会没办完。查看道路的情况，申上神见卯玄武，车在道路上，卯是车玄武作偷盗神本身不吉，所以要查看这个玄武的情况，玄武本家在亥与车卯与日干未三合。说明是我认识的人，玩的不错的人。亥又是见螣蛇，作改变的象。这个亥在支上，见到了午空是天马。午天马与日干合，这里就是换车的象。和一个朋友换了车子。四课有两个马，一个丁马酉乘六合，六合就是卯也是今年的病符，说明这个车有问题。酉下临寅地在月建上，说明我会在省内开这个车移动。但是最终选择了朋友的车，因为它上传了，所以会先开自己的车在省内，然后用朋友的车回家，午在支上也代表家。现在看四课的顺序也能看出来，第一课到第四课逐渐为阴，则是以时间顺序往下走，车在二课与三课，就会先开酉车，再开午车，这是四课的结构问题。最后看看回家的情况，因为正时门见巳是父爻，又白虎作生病，申恰好是长生之地，就是父母的类象，所以依然是取申来看情况，申遁丙是为病此为一象，申上见卯为病符此为二象。至于出行顺利否，三传递生，至子孙爻，虽然长生但是囚气，无阻碍但是累得很。另一法很简单：套用毕法赋：权摄不正禄临支，午作禄又是天马，禄是道路就是车子，跑到了别人的地方受克，别人的财就是别人的车子。午未合和我合住了，发用又是别人的车子所以就会换车。说明古法淳朴好用，但是思路不固定。"

## AI解析

### 1. 课体分析
- **重审课**：一下克上发用，事由内起，反复斟酌之象。出行之事需多次考虑、调整计划。
- **六仪课**：旬首甲午发用，主吉庆，出行虽有波折但终有吉应。
- **四绝课**：四课皆上神克下，主事体已到极致，出行之事即将发生、不可更改。

### 2. 出行类神体系
水在此课中展示了完整的出行占断体系：
- **正时门（巳）**：巳为父爻，冲宅门，白虎为道路神，巳空则解散——出行之意已定
- **道路神（申）**：白虎本家在申，申为道路，申勾陈主迟滞——路上有耽搁
- **车象（卯）**：卯为车，乘玄武为偷盗神——车有问题
- **天马（午）**：午为天马，与日干合——换车之象
- **丁马（酉）**：酉为丁马，乘六合——另一辆车

### 3. 四课时序法
"第一课到第四课逐渐为阴，则是以时间顺序往下走"——这是一个重要的四课读象法：
- 第一课（干上）：酉车——先开自己的车
- 第二课（干阴）：午车——后换朋友的车
- 第三课（支上）：亥——聚会原因
- 第四课（支阴）：午——回家

### 4. 换车逻辑链
1. 正时巳空→出行解散之象
2. 申上卯为车，玄武为偷盗→车有问题
3. 玄武本家在亥，与卯、未三合→朋友的车

### 5. 毕法赋应用
"权摄不正禄临支"——午为日禄临支，禄为道路、车子，跑到别人地方受克，别人的财即别人的车子。古法直接断换车，简洁有力。
