# case-001 — 问工资何时发（交易占·财爻取应期）

- **课体**：重审，元胎
- **三传**：初传申(腾蛇)→中传亥(太阴)→末传寅(白虎)
- **反馈**：于十二月四日，癸亥月丙申日发工资发了13056，扣了2000。

## AI解析

### 1. 课体与事体
- **重审课**：主反复、拖延、需经审核。工资发放延迟，符合重审之象——需经财务复核、领导审批等环节。
- **元胎课**：三传申亥寅为孟神，主初始、萌芽、等待。工资之事尚在"胎动"阶段，尚未落地。

### 2. 三传与财爻关系
- **初传申（腾蛇）**：申为丙火日干之财（丙克申金为财），腾蛇主虚惊、缠绕、拖延。初传发用即见财，但腾蛇缠绕，说明钱已"在路上"但迟迟不到。
- **中传亥（太阴）**：亥为丙火之官杀（水克火），太阴主暗中操作、财务流程。中传见太阴，对应财务审核、银行处理等幕后环节。
- **末传寅（白虎）**：寅为丙火之印（木生火），白虎主迅速、决断。末传白虎，主最终突破、快速解决。

### 3. 应期分析——为何是丙申日？
- **申（初传）**：初传申为财爻发用，申本身即为应期信号。申日（丙申日）见申，是初传兑现。
- **丙（日干）**：丙申日，天干丙与日干丙相同，为"比肩应期"——日干值日，事主本人直接相关。
- **驿马**：申为丙火之驿马（丙申日，申为驿马），主行动、变动、到来。驿马临财爻，主钱财"动"到手中。
- **十二月四日**：癸亥月丙申日。月柱癸亥（水旺之月），丙申日火金相生，财星得用。

### 4. 金额分析
- **13056**：申为金，数7/9；丙为火，数2/3。13056中含13（丙火之数1+3=4，但实际为13），56中含5（土生金）和6（水）。申金财爻得丙火日干之生，财数可观。
- **扣2000**：腾蛇初传缠绕之象，主有损耗。2000为2（火数），腾蛇属火，火克金（财），故有扣款。

## 经验提炼
1. **财爻发用定应期**：初传申为财爻，应期即申日（丙申日）。三传发用之处，即为应期指向。
2. **驿马临财主速至**：申为丙火驿马，驿马临财爻，钱财快速到来。
3. **日干值日**：丙申日天干丙与占人日干相同，事主直接相关之日应事。
4. **腾蛇缠绕主延迟**：初传腾蛇，主流程反复、拖延，对应工资延迟发放。
5. **白虎末传主突破**：末传白虎，主最终快速解决，对应钱款到账。
