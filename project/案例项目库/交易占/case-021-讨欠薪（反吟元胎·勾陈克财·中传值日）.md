# case-021 — 讨欠薪（交易占·反吟元胎·勾陈克财）

## 原始信息

- **占问时间**：2026年10月1日 19:25（星期四）
- **四柱**：丙午年 丁酉月 戊申日 壬戌时
- **卦主**：女，本命癸未（2003年生，虚24）
- **背景**：此前打工，中途辞职，老板一直拖欠工资并反复拖延。问何时要到、全部还是部分、金额多少（1000以内）。
- **占类**：交易占（讨欠薪＝已到期债权）

## 课式

- **月将**：辰（秋分后，中气换将）
- **占时**：戌时（夜占）
- **旬**：甲辰旬，**空寅卯**
- **贵人**：夜贵未加丑，昼贵丑加未（丑未相冲）
- **课体**：反吟、元胎（元胎逢反吟＝**绝胎格**）
- **四课**：干戊←亥（妻财·勾陈）｜亥←巳（太阴）｜支申←寅（官鬼·白虎）｜寅←申（子孙·腾蛇）
- **三传**：寅（官鬼·白虎·空）→ 申（子孙·腾蛇）→ 寅（官鬼·白虎·空）
- **六亲序**：官鬼 → 子孙 → 官鬼

## 解课过程

### 1. 课体与断语（引擎原文）
- 课义：「虎鬼空排，切勿贪财，如贪亥水，生起寅来。」
- 断曰：「反吟之课，来去俱空，吉固不成，凶亦无准。**干支值绝，止宜结绝财物之事**。」
- 分类占：**求财：宜索债。**
- 课经元胎：「财可大兴」；但「元胎课逢反吟，虽开花但不结子」＝**绝胎格**。

### 2. 类神与显象
- **财＝亥**（戊土克水），临干上、日干克之 → 钱本在我名下，主动权在我，**可索**。
- 财乘**勾陈**，勾陈属土**克**亥水 → 天将克类神＝**压着不给**（拖欠），非"流程慢"；勾陈只"压"不"扣"。
- 财亥酉月为**相**（金生水），旺相不被折 → **无克扣，可全要**。
- 禄＝巳临亥（火绝于亥）、乘太阴 → 该得的报酬被压到绝处（解释"要得辛苦"，不解释"要不到"）。
- **初末官鬼寅空** ＝ 老板避而不见、凶而不实（虎鬼空排）。
- **中传申（子孙）为财源**：金生水，且申＝日支 → 事落在"对方本位"，是全程唯一"实"的传。

### 3. 动象
反吟整盘对冲（寅申冲、亥巳冲、子午冲）＋丁马临本命（未），命上见丑（天空＋闭口）→ 反复拖延、对方闭口、我方缺凭据；驿马寅空 → 对方嘴上动、实际不动。

### 4. 应期（两线）
- **迟速**：反吟来去＋丁马 → 速；勾陈得巳火生、寅卯空 → 旬内难落，出旬即应。
- **线一（事情落点）**：三传唯中传实，中传申＝日支 → **申日值日而兑现**。
- **线二（财爻当旺＋合鬼）**：财亥旺于亥时；亥合寅（官鬼），合住则事了 → **亥时**。
- 合断：**申日亥时**。

### 5. 数额
- 取**行年上神**：行年己酉，酉上神卯。
- 卯属**震三宫**（洛书九宫数）→ **3 → 300 元**。

## 断语

> **核心断语：钱能全要回来，应在申日亥时（10月13日 21–23时），约 300 元。**

## 反馈

> **验** — 申日亥时全部要回，约 300 元。

## 经验提炼

1. **天将克类神 = 压/扣之分**：勾陈（土）克财（水）主**拖欠**（压），非**克扣**（扣）。财旺相则全额，囚死才折——一字之差决定"全额/部分"。
2. **反吟应期优先取中传**：初末多空、多相同，中传是唯一"实"的落点；**中传临日支 → 申日值日即兑现**（不宜说"填实"，申本不空）。
3. **应期时辰取财爻旺时，并可兼取"合鬼"**：亥时财临旺地，亥合寅鬼 → 合住则事了。**不可取财之绝宫**（亥加巳若取巳时＝财死之时，方向反）。
4. **反吟"双象"两读**：无德神读"分两次"；有德神（本课寅带**天德**、天医）读"首尾相应、一了百了"。
5. **千元以内数额用宫数**：取行年（或命上）神之洛书宫数×100（震3、巽4、离9…）。本例卯空仍取数得验，属特例待验。
6. **课体不压类神**：反吟"来去俱空"、绝胎"不结子"只解释**过程反复、拖了12天**，不推翻"财临干旺相 → 全额"的结局判断（裁决阶梯第2级：类神定结局，课体定环境）。
