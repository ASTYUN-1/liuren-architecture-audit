# case-018 — 闲鱼卖头盔（交易占·伏吟元胎·空亡出货）

## 原始信息
- **占问时间**：2026年7月23日 11:35
- **四柱**：丙午 乙未 戊戌 戊午
- **课体**：伏吟，元胎，斩关，孤辰
- **三传**：初传巳(勾陈·空亡)→中传申(白虎)→末传寅(腾蛇)
- **旬空**：辰巳（甲午旬）
- **月将**：午
- **问题**：闲鱼挂卖闲置头盔，挂价1520，有人问价。问①能否成交 ②成交价多少/对方出价多少
- **反馈**：待反馈

## 模范答案（原断者提供）
> 初传空亡，代表东西没了。申子孙通道贵人丑也是有人买的像。末传寅蛇通道丁酉太常，说明卖得快。因为寅乘蛇肯定是砍价卖，寅是三数就蒙1350。

## AI解析（复盘）

### 0. 卖货占与买货占的方向差异——本课最大教训
**卖货占和买货占的读课方向完全相反：**
- **卖货占**：空亡读作"货离手"（卖出去了），而非"交易虚"
- **买货占**：空亡读作"财不来"（买不到）
- 同是空亡，立场不同读法不同

### 1. 课体总论
- **伏吟课**：天地不动，各归本位。看似主静，但丁马、驿马动则有变。
- **元胎课**：三传四孟（寅申巳），主事情萌芽、新开端。卖货之始。
- **斩关课**：过关越梁，有人问价即是"过关"之始。
- **孤辰课**：一人卖一人买，孤单交易。

### 2. 三传核心分析

#### 初传巳（勾陈·空亡·○）——货已出手
- 巳为空亡，**卖货占读作"货没了"（卖出）**，而非"交易虚"
- 勾陈主拖延，但空亡则勾陈之力被虚化——拖延不成立
- 初传空亡也主初始阶段货已不在手中（被预定/发出）

#### 中传申（白虎·子孙）——买家出现
- 申为戊土之食神/子孙（戊土生申金）——在交易占中，**子孙为买家、客户**
- 申乘白虎：白虎主急速、道路——买家来得快
- 申中藏庚，庚为传送，有运输/快递之象
- **贵人丑**通行于申（贵人丑在天地盘中为丑加丑，伏吟位），丑为贵人，代表有人要买、有贵人穿针引线

#### 末传寅（腾蛇·官鬼·丁酉太常通道）——砍价+速卖
- 寅为戊土之官鬼（木克土），官鬼主压力——砍价=压力
- **腾蛇**缠身、缠绕——买家缠着你砍价
- 寅通过遁干丁与酉太常连通（寅遁丙丁，丁为丁马，酉为太常）：
  - **丁马**主动——卖得快、成交快
  - **太常**为宴喜——交易有成之喜
- **寅数三** → 成交价1350（1520-170=1350，砍了170块）
  - 寅先天数三，断价用三
  - 三也含"砍三成"之意

### 3. 价格判断逻辑
| 因素 | 读法 | 指向 |
|------|------|------|
| 寅三数 | 末传生数 | 1350 |
| 初传巳空 | 挂价已虚（货要出） | 达不到1520 |
| 寅蛇缠价 | 砍价卖 | 需降价成交 |
| 丁酉太常 | 速卖+宴喜 | 最终能接受 |

### 4. 模范答案技法精要

1. **卖货占读空亡**：空亡不是"空事"，是"货空"（货离手）
2. **子孙为买家**：申为戊土子孙，子孙为买家/客户
3. **通道读法**：寅蛇通过遁干丁与酉太常连通，而非孤立看末传
4. **寅三数断价**：末传生数定成交价
5. **贵人丑在传**：丑为贵人，有人要买的佐证

### 5. 对比：两种解读视角

| 课象 | 模范读法（卖货视角） | 最初读法（买货视角） |
|------|---------------------|---------------------|
| 初传巳空亡 | **货没了（卖出）** ✅核心 | 交易虚 ❌ |
| 申子孙 | **买家出现** ✅ | 过程压力 |
| 寅蛇克干 | **砍价卖出** ✅ | 结果克我不利 |
| 丑贵人 | **有人要买** ✅ | （未注意） |
| 结论 | **能成交，1350速卖** | 难成交 |

## 经验提炼
1. **卖货占：空亡读出货**：发用空亡，卖货占读作"货离手/卖出"，非"事虚"
2. **子孙申为买家**：食神/子孙爻为买家、客户
3. **寅蛇通道丁马**：腾蛇=砍价，丁马=速卖，太常=宴喜有成
4. **寅数断价**：末传寅先天数三，断价1350
5. **贵人丑在课**：丑贵人现于课传，有人要买之确证
