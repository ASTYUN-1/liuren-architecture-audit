# case-020 — 沈阳一环90平卖房高于预期价（交易占·稼穑斩关·高价成交）

## 原始信息
- **占问时间**：2026年6月18日 9:10（巳时）
- **四柱**：丙午 甲午 癸亥 丁巳
- **课体**：元首，稼穑，斩关
- **三传**：初传辰(天后)→中传未(朱雀)→末传戌(青龙)
- **四课**：干阳辰(天后)、干阴未(朱雀)、支阳寅(玄武)、支阴巳(贵人)
- **旬空**：甲寅旬子丑空
- **无年命**
- **背景**：课主在沈阳市区中心有一环路90平房子，想卖150万，中介说没人买。问结果如何。另问：是挂之前问的还是挂了一段时间后问的。
- **反馈**：实卖170万，比预期多20万。含家电家俱价值约5万，相当于家电家俱也高价卖出。

## AI解课回顾

### 初断（错误）
断为"低于150万售出"。错误原因：过度依赖"日禄在子旬空"推断价格低，忽视了财爻巳的核心地位。

### 复盘修正
**正确论断应为"高于150万售出"。核心在：巳贵作财，旺相带德。**

### 课体分析

| 维度 | 内容 | 象意 |
|:--|:--|:--|
| 九宗门 | 元首 | 事从外来，被动等待买家 |
| 课体① | 稼穑 | 三传全土，过程迟缓反复 |
| 课体② | 斩关 | 不安居，利于变动 |
| 卦主 | 稼穑 | 壬癸日稼穑为"脱难杀"，危反解散 |
| 贵人 | 巳加寅 | 贵人塞鬼户，凶中有救 |

### 日干状态
- 癸水在午月囚，干上辰墓克日 → 课主压力大、迷茫
- 支上寅木泄干生财、制三传鬼 → **救神在宅**

### 三传解读
```
初传辰(天后) → 中传未(朱雀) → 末传戌(青龙)
   官鬼            官鬼            官鬼
```

- 三传皆鬼只说明**过程压力大**（中介反复、买家犹豫、谈判拉扯），非指价格低
- 辰墓覆日发用：旧事积累，已挂出一段时间
- 末传戌冲辰（初末相冲）：突破封闭，终出墓库
- **末传青龙**：青龙为吉将，主喜事财富，末传见青龙→终有收获

### 财爻分析（定价核心）

| 财爻巳的状态 | 象意 |
|:--|:--|
| 午月火旺 | 财旺相有根，非虚浮 |
| 乘贵人 | 买家认可价值，出价大方 |
| 带日德（癸日德在巳） | 财有德气，得之有道 |
| 带福星 | 财有福气，超出预期 |
| 驿马+丁马 | 水日逢丁财动之，交易发生 |
| 在四课支阴 | 宅之深层——家电家俱为宅阴物，对应家电也高价卖出 |

### 日禄的局限
- 子为日禄，旬空 → 禄空
- **禄主固定收入/薪资，不管一次性交易价格**
- 禄不在课传，影响权重本就很小
- 初断错误在于将此放大为主因

### 送命题
**挂了一段时间后问的。**
- 发用墓神→发旧事
- 斩关课→已动
- 驿马丁马→财已在动

## 经验提炼

1. **财爻旺相乘贵带德=高价**。巳贵作财在午月旺相，乘贵人、带日德福星，必高于预期。财的状态直接决定卖价。
2. **禄空≠价格低**。日禄管固定薪资，一次性交易价格看财爻而非禄。且禄不在课传，权重应极低。
3. **三传全鬼=过程压力，≠结局凶**。稼穑全鬼克日仅表示谈判反复、过程艰难。末传青龙+辰戌相冲=绝处逢生，终局有收。
4. **支阴财爻对应宅内附物**。巳在四课（支阴）→家电家俱也高价脱手，物象高度对应。
5. **课体正确定位**：课体定环境（稼穑=迟缓反复），类神定结局（财旺=高价）。
6. **贵人塞鬼户**：凶中有救，众鬼不得出而作祟，最终化险。
