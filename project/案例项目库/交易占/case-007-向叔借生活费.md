# case-007 — 向叔借生活费（交易占·曲直寡宿·空财寻贵）

## 水的断语
断语：正时酉为财爻遁闭口，发用空亡，干支又各成三合局，找你叔没借到，可以找干上寅贵试试，又断可有属虎，面相方正，姓氏中带有艹字头或带木之人？为领导长辈，平时多帮助于你的。

## AI解析

### 1. 课体总论
- **知一课**（比用）：事起同类，需抉择。向叔借钱，叔为同类长辈。
- **曲直课**：三传亥卯未合成木局，木主仁、主生长。但曲直局在此课为脱气（辛金日干，木局耗金），主费力、耗神。
- **寡宿课**：主孤独、无助。向叔借钱，叔不借，正应寡宿之象。

### 2. 三传与财爻分析——核心：正时酉为财遁闭口，发用空亡

#### 日干辛金定位
- 辛金日干，生于丑月（土旺之月），金得土生。
- 三传亥→卯→未，合成木局。木为辛金之财（辛克木），三传全财！

#### 初传亥（腾蛇）——空亡发用
- **亥为辛金之财**：辛克亥水，亥为伤官，但亥中藏甲木，甲为辛金之正财。
- **亥为空亡**：甲子旬戌亥空。初传空亡，主事始即虚。
- **亥乘腾蛇**：腾蛇主虚惊、缠绕。财爻空亡乘腾蛇，主借钱之事虚而不实。

#### 中传卯（天后）
- 卯为辛金之财（辛克卯木），天后主恩泽、庇护。中传见财，看似有财可得。
- 但卯为曲直局之中传，木局耗金，财虽多而身弱不胜。

#### 末传未（白虎）
- 未为辛金之印（土生金），白虎主凶伤、迅速。末传白虎，主最终有惊险。

#### 正时酉为财遁闭口
- **酉为辛金之禄**（辛禄在酉），又为辛金之财（辛克酉金为偏财）。
- **酉为闭口**：甲子旬以戌为旬首，酉为旬尾。旬尾加时（酉时），为闭口。闭口主事不可言、不可成。
- **"正时酉为财爻遁闭口"**：财爻闭口，主借钱之事说不出口、对方不开口答应。

### 3. 为何叔叔不借？

1. **初传空亡**：亥为空亡，事始即虚。向叔借钱，一开始就无实质可能。
2. **曲直局脱气**：三传木局耗辛金日干，主费力而无功。借钱之事耗费心力而无结果。
3. **寡宿课**：主孤独无助，求助于人而人不助。
4. **正时闭口**：酉为闭口，主对方不开口、不答应。

### 4. 为何最终找到女老师借到？

- **干上寅（贵人）**：水断"可以找干上寅贵试试"。寅为辛金之财（辛克寅木），又为昼贵（辛日昼贵在寅）。干上见贵人，主可求助于贵人。
- **"属虎，面相方正，姓氏中带有艹字头或带木之人"**：寅为虎，寅木主草木。女老师名字带草木，正应寅木之象。
- **"年命是卯"**：借到钱的人年命为卯。卯为辛金之财（辛克卯木），又为曲直局之中传。中传为移易，主中途转机。
- **"十号给钱也就是酉日"**：酉为辛金之禄，又为正时。酉日给钱，是正时应期。

- 《六壬大全·寡宿课》：主孤独无助，求人不助。

## 经验提炼
1. **正时闭口主事不成**：正时酉为闭口，主借钱之事对方不开口答应。闭口之财，不可得。
2. **初传空亡事始虚**：初传亥为空亡，事从一开始就无实质基础。
3. **曲直局脱气费力**：三传木局耗辛金日干，主费力而无功。财多身弱不胜财。
4. **干上贵人可求助**：干上寅为贵人，主可求助于有地位之人。贵人临干，另寻他路。
5. **年命为财可借到**：借到钱的人年命卯，为辛金之财。年命入财，主此人有钱可借。
