## 核心断语
初传朱雀乘官鬼遥克日干，检查报告显示实质性问题；三传递生归干（未→酉→亥→癸），有医疗介入（支架/药物）可化解；但蒿矢遥克力轻的判断被重估——官鬼发用不论正遥，皆是实病之象。

## 原始断法
详见本课交互记录。主要结论：
1. 当时以"蒿矢力轻"判定心脏问题不严重、堵塞轻微
2. 以"指日可愈"6ren.cn断语为乐观依据
3. 错误地将官鬼发用定性为"虚象"，低估了朱雀官鬼的实病信号

## 反馈
**部分应验** — 课象显示"有心经问题""有官鬼克身""三传递生有医疗出路"均验；但"蒿矢力轻不严重"的判断偏差较大，实际为需要介入治疗的重度狭窄。

## 反推分析

### 偏差定位
**程度偏差** — 断为"轻度/不严重"，实为"重度/需介入"。

### 被忽略的线索
1. **朱雀乘官鬼发用 = 检查报告显示实病**，不应以"蒿矢遥克"为由轻看。官鬼就是官鬼，正克遥克皆官鬼。
2. **钙化积分与官鬼的对应**：未土官鬼在疾病占中对应"壅塞/斑块/硬化"（土主堵塞），与钙化积分461.93高度吻合。
3. **朱雀对应心脏/血液**：朱雀属火，与心/血管/炎症直接对应。发用朱雀落实为"冠脉CT检查报告显示异常"，是真实信号而非虚惊。
4. **蒿矢的真正含义**：蒿矢不是"病不重"，而是"病非急发性、为渐积而成"（钙化斑块正是长年累积的结果）。

### 正确断法
当遥克蒿矢课 + 朱雀官鬼发用 + 疾病占时：
- **蒿矢定性应为"渐积而成，非急发之症"**，而非"力轻不重"
- **官鬼乘朱雀发用 = 检查报告显示实质性病变**，不以遥克减等
- **三传递生归干 = 有医疗手段可以治疗**，末传亥水比劫归干 = 治疗后恢复可期
- **中传酉金（勾陈）** = 介入治疗/支架（金属/器械）

## 经验提炼

### 规则一：蒿矢+官鬼发用占病
当疾病占见 **蒿矢课 + 朱雀/白虎乘官鬼发用** 时，应断为 **"有实质性病变，非虚惊"，因为** 官鬼发用不论正克遥克皆是实病信号，蒿矢仅提示"渐积而成、非急发"。

### 规则二：朱雀乘官鬼 = 检查报告异常
当 **朱雀乘官鬼** 出现于课传时，在疾病占中应断为 **"检查/检验报告将显示异常指标"，因为** 朱雀主报告/信息/火象，官鬼主病。二者组合即为"报告显示有病"。

### 规则三：酉金父母 = 介入治疗/支架
当疾病占见 **酉金（勾陈/太常）在课传中** 且与日干有生助关系时，应断为 **"有介入治疗（如支架/手术）可解决问题"，因为** 酉为金/金属/器械，金生水为治疗与日干（癸水）相匹配。

### 规则四：钙化积分与未土官鬼对应
当疾病占见 **未土官鬼发用** 时，钙化/斑块/堵塞类病变的严重程度**取决于官鬼的旺衰而非遥克与否**。未土在未月旺相，对应钙化积分高。

## 新增/修正技法
1. **蒿矢课的疾病占定性**：此前经验将蒿矢一概定为"力轻"，此次反推揭示——蒿矢不等于"病轻"，而是"过程长、非急发"。官鬼发用才是决定病情程度的最终依据。
2. **朱雀官鬼=检查报告实病**：新增反推规则，朱雀乘官鬼（无论正遥）在疾病占中不可轻看。
3. **酉金=支架/介入治疗**：此案例验证了酉金作为"金属医疗器械"的类象在现代医学中的新应用。
