## 反推分析

### 偏差定位

**吉凶反转。** 根因四条：

1. **暴病/久病未分（总开关）**：把急性误服当久病，套“禄空＝元气绝”。
2. **白虎受制未查**：只取白虎、岁破、羊刃，未取午火克白虎金、虎不敢伤人。
3. **末传冲的方向读反**：把“末传寅冲中传申”读成“申旺克寅、病克救神”，实为“末传冲散病邪”。
4. **课经通用断语压过具体救神**：元胎“老人投胎”、寡宿孤寡、伏吟“屈而不伸”被当成铁口，未取“再生／静中思动”的另一面。

### 被忽略的线索

1. **先锋门午**＝月将＋生气＋天马；白虎乘午，午火克金，虎受制——“虎加午地，不敢伤人”。
2. **初传巳空**＝暴病之“病空”，主吉；空亡“作事无力”，巳火克不动申金，三传递克的凶链从初传即断。
3. **巳天空**＝精神空、不省人事，是当下昏迷之象，不是元气绝。
4. **末传寅**＝本命＋长生＋六合；寅冲申＝末传冲散中传病邪（《说约》“占凶事视末传冲神……主何月日解散”）。
5. **干克支**（丙克申）＝我克病，有克服之能；干空只是当下无力，出旬填实即可克。
6. **行年戌**：除墓、血光外，另有天医起法（作业2作戌；引擎作子，**起法待核**）。
7. **伏吟“静中思动”**：昏而后醒；不是纯静衰竭。
8. **元胎有救取“再生／病难速愈”**：鬼门关走一遭、如再生一次；不取“投胎”。

### 正确断法（复盘，不回写初判）

1. **先锋门午月将生气＋白虎受制** → 危而不死。
2. **初传巳空** → 病空／凶链断；巳天空 → 当下昏迷。
3. **末传寅本命长生＋六合＋冲申** → 终局转危为安。
4. **申为医药＋玄武＋伏吟主多** → 误服多药、不明不白（病因）。
5. **末传遁壬暗鬼＋壬主肾** → 治愈后肾伤（后遗，待核）。

## 经验提炼

> ⚠️ 以下 1–8 均为单案例反推，标“未验证从疑”，不得作硬断依据；须经独立结构案例验证后方可转正。

1. **【暴病/久病·硬闸】** 占病先分暴久：暴病逢空＝病空／吉，空则凶神无力、克不动；久病逢空才主无路。见禄空／德空不可直接断元气绝。
2. **【白虎受制·硬闸】** 白虎先查受制：虎乘火地（午／巳），火克金，虎不敢伤人；再得月将／生气，凶而不死。受制优先于“白虎发用才主吉凶”的一般位次。
3. **【末传冲·方向】** 末传为终局；末传冲中传＝冲散病邪／解散凶事。不可反读为中传克末传、病克救神。
4. **【末传长生＋本命】** 末传长生＋本命＋吉将＝真救神；月破／遁鬼多应“治愈但留后遗”，不主死。
5. **【先锋门】** 正时（先锋门）见月将＋生气，主当下有生机；不可只取其上凶将。
6. **【课经通用断语·主次】** 元胎、寡宿、伏吟等课经通用断语，不压具体救神／先锋门／年命。元胎有救取“再生／病难速愈”，无救才取“投胎”。
7. **【伏吟·静中思动】** 伏吟不是纯静；“占病倦言”是当下，静极可动，昏而后醒。
8. **【空亡·暴病】** 空亡在暴病中可作“当下无力／昏迷”，出旬填实则恢复；不可把“当下空”当“终局绝”。
