# case-003 — 姑夫生什么病？何时住院？（疾病占·元首稼墙斩关课）

## 原始信息
- **占问时间**：2023年1月5日 20:40 星期四
- **四柱**：壬寅 癸丑 癸亥 壬戌
- **月将**：丑将
- **旬空**：子丑（甲寅旬）
- **年命**：甲辰 行年：丙寅 性别：男
- **课体**：元首，稼墙，斩关
- **三传**：初传辰(螣蛇)→中传未(勾陈)→末传戌(白虎)
- **课式**：雀后勾蛇 / 巳寅未辰 / 寅亥辰癸
- **反馈**：天天喝酒喝的，好多次了。喝的头晕，脑子有毛病了，然后不省人事磕到炉子上导致头感染了。身上还有点烧伤，去医院了，膀胱有病应该是尿结石，喝酒喝的肝硬化了，昏迷不醒。当晚还没出院，我姑姑直接管够他了，说了直接不听，因为这个事住了好几次院了。还有癌症，已经扩散。

## AI解析

### 1. 课体分析
- **元首课**：一上克下发用，事从外起。此病由外因（长期饮酒）引发。
- **稼墙课**：三传辰未戌皆土，土主脾胃、消化系统。稼墙课主沉重、积累之病，对应长期饮酒导致的慢性病变。
- **斩关课**：魁罡加日辰发用，主疾病来势凶猛，有"过关"之象——病情已到关键阶段。

### 2. 三传全鬼——病势凶险
三传辰（蛇）、未（勾）、戌（虎）皆为官鬼，且乘凶将：
- **初传辰蛇**：辰为天罡，主争斗、毒物；螣蛇主缠绕、惊疑。对应酒精中毒、神志不清。
- **中传未勾**：未为太常之本家，主饮食；勾陈主争斗、滞留。对应长期饮酒、肝病。
- **末传戌虎**：戌为火库，主烧灼；白虎主疾病、血光。对应烧伤、癌症扩散。

### 3. 年命与病象
- 年命甲辰，行年丙寅
- 辰命上见巳（朱雀）→巳为丙火，主血液、炎症
- 寅行年上见亥（太阴）→亥为肾、膀胱，对应尿结石
- 三传辰未戌皆克日干癸水，水主肾、泌尿系统，故有膀胱病

### 4. 稼墙课与慢性病
稼墙课三传皆土，土重克水（癸日），主：
- 消化系统疾病（脾胃属土）
- 积累性病变（土主积累）
- 病情沉重难愈（稼墙主迟滞）

## 经验提炼
- **稼墙课占病**：三传皆土，主消化系统、积累性慢性病
- **三传全鬼**：官鬼遍传，病势凶险，多重疾病并发
- **斩关课占病**：疾病来势凶猛，已到关键阶段
- **年命与病位**：年命上神结合五行，可定位具体病位
