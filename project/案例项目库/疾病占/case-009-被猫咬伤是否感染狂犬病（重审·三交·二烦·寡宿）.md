# 被猫咬伤十天，问是否感染狂犬病（未病先防·恐病占）

## 课式数据
- 公历：2020-06-08 10:10
- 四柱：庚子 壬午 壬午 乙巳
- 月将：申（中气换将）
- 课体：重审、三交、二烦、寡宿
- 四课：寅(玄武) 巳(贵人) 酉(勾陈) 子(白虎)
- 三传：酉(勾陈)○空 → 子(白虎) → 卯(太阴)
- 旬空：甲戌旬，申酉空（发用酉空亡）
- 贵人：夜贵巳加寅（贵人差迭、罡塞鬼户）

## 核心断语
未感染、虚惊为主。发用空亡"不能成愁"，课传全无官鬼（土神不现）病根不立，救神（天医乘青龙、生气乘天后、解神、天赦临末传）齐全乘吉将——感染之象未成立。白虎乘子（日干旺地比劫）为惊恐之象，非病实之象。

## 原始断法
- 占类：疾病占（未病先防/恐病型），类神取白虎、日鬼、脱气、救神
- 察动：发用酉乘败气（壬之沐浴）逢空亡 → 集应钤"虽谓之愁课，幸发用空亡，不能成愁"
- 观局：课传不见土神 = 日鬼全不现 → 无病根
- 取类：白虎乘子（壬帝旺、比劫非鬼）主惊恐；干上寅脱气乘玄武（脱盗格）主虚耗；末传卯子孙乘太阴 = 医药解厄暗中化解
- 神煞：救神齐全（天医青龙、生气天后、解神随虎、天赦临卯），凶煞虚化（丧吊乘玄武、血光坐空宫），罡塞鬼户病不发作
- 应期：出旬（6月18日前后）或卯日/卯时（卯冲酉填实）见分晓

## 实际结果
一年后反馈：人一直正常，未感染狂犬病，虚惊一场。

## 反推分析（如有）
### 偏差定位
无实质偏差。断"虚惊为主、感染之象未成立"与事实一致。
### 被忽略的线索
- 应期"出旬/卯日"未做实际追踪验证（用户仅一年后反馈整体结果），应期细节待后续同型案例补证。
### 正确断法
发用空亡直断"忧不能成" + 课传无鬼断"病根不立" + 救神齐现乘吉将断"有救无虞"，三层互证，凶课体（二烦/三交）不敌类神之实。
