## 解课过程（正解逻辑回盘核对）

### 1. 明占类
健康占·代占幼儿病，属“存现＋时间”混合类。以类神线为主、课体为辅。

### 2. 定侧重
- 病＝**官鬼未土**（初传发用，遥克日干癸）
- 孩子＝**亥为幼子**（干上神），兼取**子孙卯**（末传）
- 医院／医生＝**贵人巳**（中传，且为日医、太岁）
- 宅／病床＝**支酉**（乘太阴、闭口）

### 3. 看显象（空亡与变质）
- 干上亥：旬空＋天空＋驿马空 → **占者（父）不到场、信息虚**，不可反断病者不住院。
- 支上未：官鬼＋太阴＋**丧门、吊客**同临 → 象在“家中阴人丧”，非泛泛“忧惧”。
- 本命寅：为癸水**病地**，又乘**死气** → 生病、状态差。
- 日柱癸酉：**闭口日** → 病者懒言、不哭闹。
- 初传未：官鬼、**本命寅木之墓** → 命墓发用，主病者受困、留院。
- 辰：**癸水之墓**（干墓），天盘辰与支酉六合 → 墓合宅，困于一处。
- 末传卯：子孙制鬼、本命寅木之帝旺；但坐癸水死地、乘朱雀、丁马 → 能治，过程有反复奔波。

### 4. 有路
末传卯冲支酉（离宅）、末克初（制鬼）、行年巳入中传（本人之事显明、得医）。

### 5. 课体
蒿矢＝非急发、渐积而成（**不等于病轻**，参见 case-008）；回明＝吉事渐成、凶事渐消，宜缓；间传＝波折、阻隔；墓象叠加＝住院。

### 6. 吉凶调制
- 官鬼（凶爻）× 太阴（吉将）＝温柔一刀：病来得平和。
- 妻财（吉爻）× 贵人（吉将）＝吉而又吉：得医得助。
- 子孙（吉爻）× 朱雀（凶将）＝吉中有忧：能愈，伴发热奔波。
- 白虎不入四课三传 → 非危重、无血光急症；但“非危重”≠“不住院”。

### 7. 应期
- **末传遁干**：卯遁丁 → 丁日（丁丑，11/4）
- **末传地支**：卯 → 卯日（己卯，11/6）
- **墓传生**：初传未（本命木墓）→ 末传卯（本命帝旺），出墓即出院。
- 两候选：**丁丑 11/4 / 己卯 11/6**。

## 反推分析

### 偏差定位
**位次错误（主因）＋应期取法用错层。**

### 被忽略的线索
1. **发用未＝本命墓**：命墓发用主受困留院，被读成普通“官鬼＋丧门”。
2. **辰＝干墓**：癸墓在辰，天盘辰与支酉六合，墓合宅＝困于一处。
3. **干上亥空的位次**：干为占者，亥空只断父亲不到场；病者留滞看发用鬼与墓，二者不可互换。
4. **亥为幼子**：空＋天空＋马空＝蔫、不哭闹，非“父亲不归”。
5. **癸酉闭口日＋本命病地＋死气**：三条合看才是“状态差、不哭闹”。
6. **末传本身**：应期应优先取末传遁干／末传地支，而非外围补空、三合缺神。

### 正确断法
1. 病：鬼未发用＝病因；未为饮食、坤土主皮肤肠胃；秋冬换季＋朱雀巳火＝流感。→ 流感或肠胃炎。
2. 住院：间传主波折；辰为干墓、发用未为命墓 → 住院。
3. 出院：墓传生（未墓→卯旺）；末传卯遁丁、地支卯 → 丁日／卯日。

## 经验提炼

> ⚠️ 以下 1–5 为单案例反推，标“未验证从疑”，不得作硬断依据；第 6 条有既有经验支持；第 7 条为流程规则，可立即执行。

1. **【住院判定·墓为床，空为人未到】** 占他人病住院，先看墓：发用为命墓（本命五行之墓）、干墓现于课传，主病者受困留院；干上神空亡只断占者不到场，不可反断病者不住院。
2. **【应期·末传优先】** 出院／病愈应期，先取末传：末传遁干所值日为第一候选、末传地支所值日为第二候选；“初传墓→末传旺／生”为出墓之期。
3. **【幼子类神】** 占孩子病可直接取“亥为幼子”；亥空＋天空＋驿马空＝蔫、不哭闹、无力，不作“父亲不归”解。
4. **【闭口日】** 癸酉等闭口日占病，主病者懒言、不哭闹、精神不振；配本命坐死气则状态差。
5. **【现类力度】** 支上鬼乘太阴临丧门／吊客，太阴为阴人，应直读“家中女性丧事”，不可一律软化为“忧惧”；属“非占现类”边缘，引用须谨慎。
6. **【病因取象·有支持】** 鬼未发用＝饮食、坤土＝皮肤肠胃；秋冬换季＋朱雀巳火＝流感。与经验 B0226《占病五要》一致；本案验，可作有支持的经验。
7. **【流程·必执行】** 案例检索必须带课式特征参数（`--rigan/--fayong/--keti/--sanchuan`），否则问题相关性会淹没结构匹配。
