# case-004 — 父亲病情如何（疾病占·元首间传悖戾马闭口励德课）

## 原始信息
- **占问时间**：2022年10月28日 10:22 星期五
- **四柱**：壬寅 庚戌 甲寅 己巳
- **月将**：卯将
- **旬空**：子丑（甲寅旬）
- **年命**：甲辰 行年：甲子 性别：男
- **课体**：元首，间传，悖戾马，闭口，励德
- **三传**：初传戌(玄武)→中传申(白虎)→末传午(青龙)
- **课式**：玄后玄后 / 戌子戌子 / 子寅子甲
- **反馈**：肝腹水变肝癌了，课主父亲8天后去世，于2022年11月5日凌晨走的。

## AI解析

### 1. 课体分析——多重凶象叠加
此课集元首、间传、悖戾马、闭口、励德五重课体于一身，凶象叠加：
- **元首课**：一上克下发用，事从外起，病势由外因引发
- **间传课**：三传戌→申→午，隔位而传，主迟滞、隔阻——病情拖延难治
- **悖戾马**：驿马被冲，主反常、悖逆——病情发展出人意料
- **闭口课**：旬尾加旬首，主事体封闭、无出路——药石无效
- **励德课**：贵人临辰戌，主反复无常——病情反复

### 2. 三传退间传——阳气渐衰
三传戌→申→午，为退间传（由土退至火），阳气逐渐衰减：
- **初传戌（玄武）**：戌为火库，玄武为水，水火交战。肝属木，木生火，火库被水所克——肝病
- **中传申（白虎）**：申为白虎本家，白虎主疾病、死亡。申金克木（肝）——肝病加重
- **末传午（青龙）**：午为青龙，青龙本吉，但在此为退间传之末，气已衰。午为心、血——肝腹水影响心脏

### 3. 闭口课——药石无效
旬首甲寅加旬尾癸亥（闭口），主：
- 病情无法开口（无法治愈）
- 药石无效（闭口则无生路）
- 信息不通（家人不知病情严重程度）

### 4. 应期——8天后去世
- 三传戌→申→午，退间传，主事体加速衰退
- 末传午为青龙，青龙入墓（午在戌地入墓）——死亡之象
- 11月5日（壬戌日）去世，戌为初传，亦为墓库

## 经验提炼
- **闭口课占病**：旬尾加旬首，药石无效，凶多吉少
- **退间传占病**：三传由旺退衰，阳气渐竭，病势加速
- **悖戾马占病**：驿马反常，病情发展出人意料
- **白虎临申**：白虎归本家，主疾病凶险
- **青龙入墓**：吉神入墓，吉不成吉，反主死亡
