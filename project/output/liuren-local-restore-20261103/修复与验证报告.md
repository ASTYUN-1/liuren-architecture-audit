# 本机 OpenCode 六壬流程修复与验证

修复日期：2026-11-03。范围限于本机专业研判入口、检索工具及可选审计工具。活动版本为 `20261103-local-restore-01`。

## 发现与处理

原专业方法与资料库没有被融合删空。问题主要出在执行方式：统一会话工具成为强制入口，同卦追问重复建立运行；长中文查询未有效拆出争点，候选裁剪又遮住相关经验；检查器对案例引用缺少校验，页码回执也不能证明正文实际呈现、阅读和理解。详见 `../liuren-workflow-audit-20261103/诊断报告.md`。

历史案第一轮确实独立检索过案例，不能说整案从未调查案例；但没有发现独立补检经验的记录，第三轮新争点也没有新增案例/经验原文读取。该案三轮使用相同盘面事实哈希。此次修复不改写原案记录，也不重判其结论。

已实施：

- 本机默认回到专业十一环节：实际读适用方法、分别检索案例与经验、阅读原文条件及反馈、比较迁移限制、完成反证和逐问判断，直接交付完整专业正文。
- 同卦追问保留原盘、前情、有效来源与先前判断；新争点补读补检，前提变化明确修正。普通追问无需重新登记问题集、生成判断 JSON 或重跑完整会话。
- `prepare/read/check` 保留为可选工程审计，不作普通回答或最终正文的门禁。专业核对仍是研判的一部分。
- 本机明确不加载网站公开输出隐藏、客户版改写、格式/字数限制及发布门禁。`wenheng-public-output` 的禁用配置保留。原配置本来就禁用了该技能，不能据此声称历史案实际执行过网站输出技能。
- 检索支持从长问题提取明确争点词、按已声明占类优先排列，区分胎产与感情类别。保留跨占类比较；不强制采用固定条数。可选审计的本机候选包不再因网站式字符预算仅剩少量不对题条目。
- 可选审计检查案例 ID、来源及对应原文输出记录；空经验采用不冒充已经完成调查。读取回执仅表示工具输出，不证明实际显示、精读、理解或采用。

当前说明以 `docs/本机六壬完整研判流程.md` 为准。旧输出目录里的历史“强制统一会话”说明仅作历史证据。

## 检查机制如何分工

| 类型 | 本机是否需要 |
| --- | --- |
| 专业核对：盘源、角色坐标、条件、年命、反证、来源和漏答 | 需要，属于完整专业研判 |
| 工程辅助：健康检查、哈希、结构化引用审计 | 按需使用，不要求每问运行，不批准或改写最终正文 |
| 网站交付：公开内容隐藏、客户版改写、格式字数、发布及权益检查 | 仅网站使用，本机不执行 |

因此“检查”不应一概取消，也不应一概成为本机强制程序。专业核对保留，工程审计可选，网站交付约束留在网站。

## 验证及证据

- 58 项测试通过：会话审计 14、案例检索 20、经验检索 18、方法加载 6。覆盖长句与占类召回、候选保留、胎产分类、伪造/未读案例引用及读取凭证能力边界。
- 活动包健康检查通过：153 个文件、50 个模块，资料根存在，647 条附加知识记录机械校验通过。
- 本机实际 `opencode debug skill` 成功发现四个项目技能，其中 `daliuren` 正文包含本机模式且不含旧强制路由。四个技能的格式校验均通过。校验器最初受到系统 GBK 默认解码影响，指定 Python UTF-8 后通过；未修改全局配置或安装依赖。
- 用历史第三轮问题离线回放经验召回：可见八条感情相关候选，字符预算省略为零。命中仅表示待审候选，不表示其中规则适用于本案。
- 两个原有冻结包逐文件哈希保持不变。47 份专业 Markdown 与上版逐字节相同；本版修改集中在执行入口、证据规程、报告规程和可选会话契约。
- 未调用模型执行新的完整占断，因此尚未验收真实模型整轮行为或预测效果。程序与配置验证通过不等于术理、语义或预测准确性验证通过。

证据文件：`activation.json`、`integrity-verification.json`、`opencode-skill-discovery.json`、`retrieval-smoke.json`、`final-verification.json`。

## 使用与回滚

已打开的旧 OpenCode 对话需要重新加载当前 `daliuren` 与 `docs/本机六壬完整研判流程.md`，避免继续服从旧上下文；新对话按当前项目入口加载。无需重新起课，可继续原盘。

原文件在 `before/`，其基线 SHA256 在 `before-manifest.json`；新旧运行包均保留。需要回滚时先保存当前改动，仅逐项恢复本次文件及活动指针，核对备份 SHA256；不要整体覆盖后续工作或执行仓库级还原。新增运行包和报告保留作追溯。一次性构建脚本会拒绝覆盖重跑。

网站、服务器和 APK 未改动；未新增跨会话记忆。
