## 现在怎样执行

保留原十一环节：

1. 环节 2 先读取短的共同取用模块，明确背景、子问、对象、阶段、成功标准，从十二分类进入；继而读定位、证据和选中专项。九系统按职责参与，不要求逐问填写九格或 108 格。
2. 环节 3 明示现实对象、候选类神、采用依据、实际位置及所答子问。多象可以共指一人，四课不按人数分槽；干支的关系轴依具体占类和阶段确定。
3. 神将同用/互换需要时读 `shenjiang-use`；需核十二神或十二将具体辞义，分别加 `shen-symbols`、`jiang-symbols`，自动带上共同边界。这三项未触发时不整表加载。
4. 环节 4 同时检查主类神与其他相关课传显象。婚问的朱、勾、空等不能因不在龙后合名单里而删除；它们如何影响所问目标仍须具体证明。
5. 后续理气、神煞、动态、课体、制救、应期取数和反证沿原流程。定位有变时重新核受影响关系。

新增 `home`、`travel`、`weather`、`agriculture` 四个有限条件专项，覆盖家宅、出行、天时、农渔畜养。事业仍分求职与在职；阶段运势、长期、古典兵占等原入口继续保留。司法、梦怪等未齐专项仍查原书子段，不能硬套邻类。

疾病定位已修订：北海干病人/支病证概法、分类人物类和《粹言》六亲代占分别保留，不把所有代问强制归为一套。主类神与决定结果的关键依据也不要求相同。

通法、专法、不同子问先分层；同条件仍互斥才按“北海（含其毕法讲解）→壬归→指南→毕法原文”处理。北海内部未决项保留；天一笔记“子午合”、巳章阴阳吉凶相反等可疑文字不成为自动规则。
