# 54版整体分析路线改造

本次按用户授权修复共用层级和整条分析流程，53版冻结保留。不是将本例的20分写入规则，也不是放弃第一次有据基础数及其旬空修正。

## 统一顺序与职责

原问中的实际事件与验收标准 → 专项分支及分析侧重 → 同职责首取、跨职责兼看、按条件递补 → 真实坐标察类 → 施受双方状态、通路、制救、时序 → 最强反证的同标准比较 → 成败/程度/数量/应期分别兑现 → 一次实质复核。

大象用来定侧重；专项决定具体对象和作用含义；旺衰描述能力与限制；生克制化判断实际作用；毕法、课体、神煞融入同一关系，不分系统投票。没有专项明确排序的地方不虚构统一全局序列。正文保持自由表达。

## 实施位置

1. 重写judgment-core的操作主线及入口/裁决/报告说明，合并重复、按事件解释层级；保留U01—U11既定采用口径。
2. 在全部17个活动专项开头设置事件分流，核验manifest、tool_help和工具domain枚举一致；修复已注册litigation未进入工具枚举的缺口。
3. 每问沿现有input_review交接小型route：事件、分析侧重、主候选ID、首取理由和时间职责。程序仅核覆盖与ID/问项关联，模型决定类神；独立裁决可有据纠正，非固定报告表格。
4. 数量保留source原法及其有据后续步骤，不强迫将完整算法换成实验分段。状态计空与数量扣空沿实际运算路径区分；非零进位及免空减例外须绑定具体来源/事实原句与应用说明，而非只改枚举。保留有依据的例外和近似估计，不固定为任何一题的公式。
5. 五项review保留，增加可追踪的核对引用与职责；一次recheck优先处理题意、取用、有效作用与数量依据，不预先保护原结论或数字。程序不裁专业效力。
