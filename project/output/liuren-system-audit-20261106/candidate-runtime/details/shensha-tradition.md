来源方法：`shensha-panduan`；依总入口加载，完整条件见下文。

## I — 方法论骨架 (Interpretation)

面对的问题：课传中神煞数十上百，如何**取用**（选重点）、**断状态**（力大力微）、**判叠加**（组合意义），而不被神煞淹没、说明神煞对本问的有效作用。

完整断课还须执行 [八煞九宝综合核查](<../references/bashajiubao.md>) 与 [用户32项](<../references/shensha-focus.md>)：八煞九宝包括关系和状态，不局限于神煞。主要依据神将气地、生克制救，普通神煞补象；旧R中“神煞更重要”的论断保留来源身份，不作为本次无条件优先级。

当前方法以 [神煞取用](<../references/shensha-use.md>) 为执行入口：《六壬笔记》优先，《壬归》核气地制化；旧《神煞全解》清单保留作专项参考，《六壬思辨-神煞》保留理解假说身份。

神煞先核成立、切题、有效位置与力量，再说明净影响。多标签不是多次独立证实；“三煞无疑”不作为数量门槛。课体背景可以复核，有效作用触及关键前提时重新裁决，不因神煞身份而永久排除。

### 季煞推演法（旧来源思辨，保留理解参照，不作新煞起法）

以春木局为例的推演坐标（理解法，非死记）：

| 地支 | 季煞 | 推演逻辑（五气旺衰 × 十二长生气） |
|:---:|------|------|
| 亥/子 | 返魂煞 | 木之长生沐浴，冬形死而气生，返魂 |
| 寅 | 皇书、吏神 | 木之临官，旺气未掌权，得书任职、小吏传书 |
| 卯 | 转煞、贼神 | 帝旺生变是转折；旺则争斗为羊刃故亦为贼神 |
| 辰 | 天目、浴盆 | 衰为退气、预见之象（目主出去）；浴盆产煞占产吉、占病凶 |
| 巳 | 孤辰 | 酉金亲戚被囚后成社会边缘人 |
| 午 | 火鬼 | 火旺克木之象 |
| 未 | 狱神 | 囚气之象 |
| 申 | 绝神、战雌 | 木局绝地；寅强申弱故申为战雌 |
| 酉 | 丧车煞 | 囚气克旺气，酉必遭囚之凶 |
| 戌 | 天耳、天喜 | 木之养，进气权柄回归，预见之象（耳主进来） |
| 丑 | 寡宿 | 酉金亲戚被囚成边缘人 |

**要点**：①辰戌都主预见，但一耳一目——辰主出去（浴盆）、戌主进来（天耳），合人体耳目进出之象；②季节煞必然有事主，事主者发十二气五气的坐标系；③年煞中病符=去年太岁（权柄丧失）亦主旧事疾病，同"退气"逻辑。

## E — 可执行步骤 (Execution)

1. **先核综合关系和神将状态**：读八煞九宝与理气规则，德合禄、生旺、刑害鬼墓空等不是可有可无的普通神煞。明确对象、神将、坐处、月令、上神/阴神及制救；普通神煞在此基础上辅助。
2. **逐项核到重点**：读32项清单，核起法、成立及相关盘面落点，不只限三传，不以作者没列过而漏查用户项目。按占类深化；待核、未成立、成立但无关分别记录。名称按用户澄清为帘幕贵人、月破、桃花、丧门；丁马成神分项，成神去重。完整遍历12宫 `tiandipan[].shensha`，不以 `keyShensha` 摘要漏项为无；详 [引擎字段](<../references/engine-shensha-output.md>)。
3. **署清基准与分歧**：岁/月/日/旬及年命的基准不混。阳刃、羊刃按 [两刃排法](<../references/blade-methods.md>) 分列；文献混称按实际表核，不以字面合并。小耗、死符、旬奇、文星、天地医等采用哪一表须清楚；引擎冲突不私改盘，缺字段不虚构起法。来源见 [新增出处](<../references/shensha-sources.md>)。
4. **按占类核实际作用**：释义未清时查 [常用释义](<../references/shensha-meanings.md>)，区分原书象义、整理归纳与待核项。刃类重阳刃、羊刃次之，二者象义相近、起法分列，不重复计证。说明对应人物、事件与阶段，比较神将力量、生脱克制、阴神和刑害。天医克日/脱日、德空刑害等不凭吉名保康复，丧吊/死符不凭凶名独断死亡。相同节点多标签归并，不按数量定无疑。
5. **裁决并简洁输出**：解释采用项影响结果、过程、程度或应期的哪一维。神煞辅助不等于排斥有效反证，关键条件变动回主线重判。保留逐项核查简记，报告只写关键采用项及影响结论的待核项；单项不足仍保留该结果，不反向排除。

旧R/A1、季煞思辨继续保留其历史身份；指定项目与新增重点标记见上述清单。不得把推演假说、原文残句或后加补注冒充先前完整规则。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者/来源警告的失败模式

- **名称替代判断**：不相关吉凶名不能推翻有效主线；若神煞揭示关键作用条件，须核力量并返回主线复核，不能无条件限制为只改过程。
- **起法冲突未裁决**：天医优先《六壬笔记》正月辰、地医对冲，仍核月序；旧正月戌等异法保留分歧不静默改盘。疑似OCR/排印错误须核原文上下文，不从推演结果反推为既定公式。
- **异体系混入**：八字等起法、年支/日支基准与本问六壬所选法分开。本轮只大六壬占事，不因旧资料允许“八字义注解”而加载其方法；不能用另一体系同名星补本盘未成立项目。
- **空表格/民俗煞**：《神煞全解》L1044-1057 三张空表与道教十二神煞，弃用不引。
- **单源经验（友人思辨）**：季煞推演法为单源未验证的推演方法论——用于理解"煞从何来"、增强判读，不替代权威起法。
