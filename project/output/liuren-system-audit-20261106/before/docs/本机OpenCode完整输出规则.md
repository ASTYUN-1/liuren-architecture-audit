# 本项目本机 OpenCode：完整技术输出

本规则仅适用于用户在 `六壬八字测算` 项目目录中直接运行的本机 OpenCode，由项目 `opencode.json` 的 `instructions` 加载。自2026-10-29起，默认采用完整技术报告，暂不启用网站最终输出的信息隐藏与改写规则。

## 本机交付要求

- 默认执行[本机完整研判流程](本机六壬完整研判流程.md)。直接交付专业判断原文，当前无两库对照不调用案例库、经验库及旧检索缓存，改为本盘与原书条件复核；同卦追问沿用原盘和前情，只补新增争点。无需每轮 prepare、写判断 JSON 或通过 check 才能回答；这些程序保留为可选工程审计，不是网站输出或发布门禁。

- 本机六壬起课使用[直接排盘操作模块](本机六壬直接排盘.md)：优先 `liuren_chart`；当前会话尚未发现工具时用 `node tools/liuren-direct.mjs`。该操作模块替代旧手册的“强制浏览器/唯一依赖3456/默认不落盘”，不替代原引擎、完整字段读取及专业研判规则。可靠同盘复用，普通正时不反复开网页、选时间或点击导出。

- 不加载或调用 `wenheng-public-output`，不把 `website-skills/wenheng-public-output/SKILL.md` 当作本机最终交付规范；项目 skill 权限对该名称设为 `deny`。为开发网站而读取该文件属于查看源码，不使其成为本机报告指令。
- 不因“客户公开报告”“网站用户输出”而隐藏本机报告中已经取得且与本问相关的技术信息。任何旧包、引用模块中的网站或客户公开报告信息隐藏、格式/字数限制及末步改写，在本机交付中均不适用，不只限于某个旧版本。
- 按现有专业研判规则交付：保留盘面和角色定位、实际采用的方法与规则条件、关键关系、支持与最强反证、救制裁决的可核对说明、逐问结论及依赖、应期依据、未定项和读取缺口。保留足够细节，不再经过网站末步删减或通俗化改写。
- 与本次判断有关且实际读取过的书籍/经验/案例名称、来源ID、文件路径、原文位置、准确短引文、检索词、命中候选、实际评分及其含义、相似与差异、技法适用条件、方法版本、工具操作结果，可以在本机正文或技术附录中展示。不要求照抄整库或无关记录，不编造调用、分数、引用、已完成步骤或未经核验的事实。
- 返回后核事实、引用、问项与争点覆盖及报告一致性；复用裁决者的实体、关系、争点取舍及逐问答案整理完整正文，不另起一轮全盘权衡。格式错误局部修复；具体事实/引用错误或新材料按12版一次补核，纯排版更正可直接处理。最终表达忠实于专业裁决，说明为何取此舍彼；区分结果程度与把握程度，有依据则明确主次，缺少区别依据则说明精度边界，不以稳妥自动折中。
- 主报告、追问及澄清均使用此本机范围。完整展示资料依据与可审查的理由摘要；原有不输出私下思维草稿的约束继续保留。
- 除本次按设计取消两库调用外，完整输出保留原有方法读取、原书查证、盘面核对、反证、证据边界和实际反馈记录要求；工程检查通过不等于术理成立或预测准确率得到验证。

## 与网站的边界

本机 OpenCode 会话与 `web/src/agent` 启动的受限网站任务是不同入口。本机没有网站的报告交付、付费权益或发布校验步骤；本机专业复核只服务于盘面、资料、条件和判断质量。本地配置不关闭网站任务的输出校验或客户信息隔离，不修改网站代码、服务器、APK、既有冻结版本及历史报告。

仅取消术理依据、资料来源和方法信息的展示隐藏；密码、密钥、令牌及与本问无关的他人个人资料仍不应被加入报告。

重新启动 OpenCode 并在本目录开启新会话使用本配置。已有会话可能保留此前已加载的输出指令。用户以后明确要求恢复本机简化交付时，再单独调整此项目配置。

先按当前路由读必查与触发专项；同版同上下文已读可复用。packet保存前核准备阶段必查回执，缺哪项只补哪项。report在交付前读。来源按行段/hash交程序装配，quote可省略；不要反复手抄引文。branch只放干支/纯支组合/戊（寄宫巳），注释放mapping_basis或mapping_review；verification只用method_interpretation/unverified。

packet返回task_prompt原样交新task，不提供task_id，不用background:true，不把上下文塞入task。裁决者逐页读完紧凑文件，使用liuren_adjudication_submit提交结构化结果，末消息仅返回工具回执。格式报错只在原子任务内修对应字段，保持裁决内容不变，最多三次提交；不得重新全盘权衡。含混对象不由程序猜改。程序保留原报告、字段错误、校验产物及hash。
