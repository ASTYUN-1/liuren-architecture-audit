### 第 1 步 · 定格局（月令取格 → 格局成败 → 相神）

> **"八字用神，专求月令。"** — 《子平真诠》沈孝瞻
>
> **"提纲有用提纲重。"** — 格局取法第一原则

格局是八字的"骨架"，决定命局的层次和方向。

#### 1.1 取格方法（来自《子平真诠》）

**核心逻辑：** 月令为提纲，以月支所藏透出天干者为格。

**取格决策树：**
```
月令藏干本气透出于天干？
  ├── 是 → 以本气取格
  └── 否 → 月令藏干中气透出于天干？
              ├── 是 → 以中气取格
              └── 否 → 月令藏干余气透出于天干？
                        ├── 是 → 以余气取格
                        └── 否 → 以本气取格（无透则取本）
```

**特殊情况：** 月令为日主比劫 → 建禄格/月劫格，另看四柱财官煞食透干会支。

#### 1.2 八种正格

| 格局 | 日主关系 | 核心特征 | 成格关键 |
|------|----------|---------|---------|
| **正官格** | 克我、阴阳异 | 正直、规矩、贵气 | 财印相辅，无刑冲破害，无伤官，无杀混 |
| **七杀格** | 克我、阴阳同 | 威权、果决、压力 | 食神制杀或印星化杀 |
| **正财格** | 我克、阴阳异 | 稳定收入、节约 | 财旺生官或食伤生财，身强能担 |
| **偏财格** | 我克、阴阳同 | 横财、慷慨 | 同上，注意比劫夺财 |
| **正印格** | 生我、阴阳异 | 仁慈、学识 | 官印相生或杀印相生 |
| **偏印格** | 生我、阴阳同 | 偏才、特殊技能 | 注意枭神夺食 |
| **食神格** | 我生、阴阳同 | 温和、才艺 | 食神生财或食神制杀 |
| **伤官格** | 我生、阴阳异 | 聪明、傲气 | 伤官生财或伤官配印，忌伤官见官 |

#### 1.3 格局成败判断（来自《子平真诠》）

**成格规则：**
```
正官格成 = 官星透 + 有财或印相辅 + 无刑冲破害 + 无伤官克 + 无七杀混杂
七杀格成 = 杀透 + (食神制杀 OR 印星化杀)
财格成   = 财旺生官 OR 财逢食生身强 OR 财格透印位置妥帖
印格成   = 印逢官杀 OR 身印两旺用食伤泄气
食神格成 = 食神生财 OR 食神带杀无财
伤官格成 = 伤官生财 OR 伤官配印
```

**败格规则：**
```
正官格败 = 逢伤官克 + 刑冲 + 七杀混杂
财格败   = 财轻比劫重 + 财透七杀
印格败   = 印重身强 + 财星破印（位置不佳）
食神格败 = 逢枭神夺食
伤官格败 = 伤官见官（无财通关）
```

#### 1.4 相神辨识（子平真诠核心概念）

> **"伤相神甚于伤用。"** — 《子平真诠》

**相神 = 保护格局用神的那个字。** 用神是格局的核心十神，相神是保护用神不被破坏的十神。

```
正官格 + 伤官 → 印星克伤官 → 印星 = 相神
食神格 + 枭神 → 偏财克枭神 → 偏财 = 相神
七杀格        → 食神制杀    → 食神 = 相神
财格 + 七杀   → 食神制杀护财 → 食神 = 相神（或劫财合杀）
```

**相神不可受伤：** 相神一旦被克/被合/被冲，格局即破。

#### 1.5 特殊格局（外格）速查

| 特殊格局 | 条件 | 核心判断 |
|----------|------|---------|
| **从格**（从强/从杀/从财/从儿） | 日主极弱无根，满盘克泄，不得不从 | 从得真则贵，从得假则夭；大运不可逆从 |
| **化格** | 日干与月干/时干合化成功，化神得月令 | 化得真者大贵 |
| **专旺格**（曲直/炎上/稼穑/从革/润下） | 一行独旺，满盘生扶，不可见克 | 大运顺其旺势则吉，逆势则凶 |
| **两神成象** | 两种五行各占一半 | 相生优于相克 |

> ⚠️ "有官莫寻格局"——月令有官杀为先，不必强寻外格。舍弃月令寻外格是常见错误。

### 第 2 步 · 调候（穷通宝鉴体系）

> **"调候为急"** — 《穷通宝鉴》（《栏江网》）
>
> **"寒虽甚，要暖有气；暖虽至，要寒有根，则生成万物。"** — 《穷通宝鉴》

#### 2.1 调候优先级

**生于夏冬两季，调候优先于格局和旺衰。** 这是《穷通宝鉴》体系的核心论断，也是裁决阶梯的第一层级。

| 出生月份 | 气候 | 调候需要 | 调候五行 |
|----------|------|----------|---------|
| 巳午未月（夏） | 炎热 | 急需水来润燥 | **水** |
| 亥子丑月（冬） | 寒冻 | 急需火来暖局 | **火** |
| 寅卯辰月（春） | 温湿 | 调候需求弱 | 见水木有情即可 |
| 申酉戌月（秋） | 燥凉 | 调候需求弱 | 见火暖局为佳 |

#### 2.2 调候十干十二月纲要

《穷通宝鉴》为每个天干在十二月分别给出了精确的调候用神。核心逻辑：

**十干调候共性规律：**
- 甲乙木生于夏 → 优先用水（既调候又生木）
- 丙丁火生于冬 → 优先用木火（木生火暖局）
- 戊己土生于夏 → 优先用水（润土）+ 辅以金（发水源）
- 庚辛金生于夏 → 优先用水（淬金调候）
- 壬癸水生于冬 → 优先用火（暖水）+ 辅以木（泄水秀气）

**具体查表（必做）：** 十干 × 十二月逐月精确调候用神见 `八字经验库/速查-调候用神表.md`。查法：先 `grep -l "主题=调候.*日主=[^| ]*X" 八字经验库/*.md` 定位小节（X=命盘日主），再在节内表格按"月令"行取值。完整查询协议见第 6 步 6.0。

#### 2.3 调候有效判断

- **调候用神出现** → 命局有调候能力
- **调候用神有根有力** → 调候得力，多有奇遇
- **调候用神虚浮无根** → 有调候之意，无调候之力
- **调候用神不现** → 夏冬生人一生起伏较大，需等调候大运
- **调候用神被克合** → 调候失败，反为灾祸

#### 2.4 大运调候

> "进入调候大运 → 爆发式上升。" — 《穷通宝鉴》大运论

- 原局无调候，大运走调候地 → 运势突然转好
- 原局有调候，大运走调候地 → 锦上添花
- 原局有调候，大运走克调候地 → 好运中断

### 第 3 步 · 辨旺衰（日主强弱判断）

> **"能知旺衰之真机，其于三命之奥，思过半矣。"** — 《滴天髓》

#### 3.1 旺衰四维判断法

| 维度 | 含义 | 判断方法 |
|------|------|---------|
| **得令（月令）** | 日主是否得月令生扶 | 月支为日主长生/临官/帝旺/余气 → 得令 |
| **得地（地支）** | 日主在地支是否有根 | 地支有日主的禄（临官）、旺（帝旺）、长生、余气 |
| **得生（印星）** | 是否有印星生扶日主 | 天干透印且印有根 → 得生 |
| **得助（比劫）** | 是否有比肩劫财帮助 | 天干透比劫且有根 → 得助 |

#### 3.2 旺衰等级

| 等级 | 条件 | 身强/弱 | 含义 |
|------|------|:------:|------|
| **极旺** | 得令+得地+得生/助 | 极强 | 可担大任，但需克泄耗 |
| **偏旺** | 得令+得地，或得令+得生 | 偏强 | 能担财官 |
| **中和** | 得令不得地，或得地不得令 | 适中 | 不弱不强，最吉 |
| **偏弱** | 失令，有一二根气或有生扶 | 偏弱 | 需扶助 |
| **极弱** | 失令无根无生，满盘克泄 | 极弱 | 易从，见根反凶 |

#### 3.3 透干通根分析

从排盘 JSON 的 `transparentStems`（透干）和 `rooting`（通根）字段直接读取。

- 有根透干 → 力量最大，真实不虚
- 无根透干 → 虚浮无力，好看不中用
- 有根不透 → 暗藏力量，待时而发
- 无根不透 → 力量微弱

> **关键判断：** 格局再美，日主无根则难担——格局决定"能有什么"，日主旺衰决定"能不能拿到"。

### 第 4 步 · 取用神（综合格局+旺衰+调候 → 平衡用神）

> 本步取的是 **"平衡用神"（扶抑用神）**，用于平衡日主强弱、调候寒暖、通关对峙，不同于第 1 步沈氏的"格局用神"。

#### 4.1 五大用神体系（徐乐吾整理）

| 用神类型 | 适用场景 | 取用方法 |
|----------|---------|---------|
| **扶抑** | 日主偏强/偏弱 | 身强→克泄耗；身弱→生扶 |
| **调候** | 夏冬出生 | 夏→水；冬→火（详见第2步） |
| **通关** | 两种五行对峙 | 取通关之神（金木交战→水；水火交战→木） |
| **病药** | 命局有明显"病症" | 以去病之药为用神（详见第5步） |
| **专旺** | 从格/专旺格 | 顺势而为，从强而旺 |

#### 4.2 普通格局用神原则

| 日主状态 | 用神选择 | 原则 |
|----------|----------|------|
| **身强** | 克（官杀）、泄（食伤）、耗（财星） | 削弱日主，取平衡 |
| **身弱** | 生（印星）、扶（比劫） | 增强日主 |
| **身强官杀弱** | 财星（生官杀） | 财生官，官制约身 |
| **身弱官杀强** | 印星（化官杀生身） | 官印相生，杀印相生 |
| **身强财弱** | 食伤（生财） | 食伤生财 |
| **身弱财强** | 比劫（制财帮身） | 比劫分财 |
| **食伤过旺** | 印星（制食伤） | 印制食伤护身 |
| **印星过旺** | 财星（破印） | 财破印 |

#### 4.3 用神真假判断

| 用神状态 | 含义 | 命局层次 |
|----------|------|:------:|
| **用神透干通根，不受伤** | 真用神，力量充足 | 高 |
| **用神透而无根，或被克合** | 假用神，力弱 | 中 |
| **原局无用神** | 等大运流年补足 | 起伏大 |
| **用神为忌神所克** | 用神受伤 | 低 |

|------|------|-----------|

| **忌神** | 破坏用神/加重失衡的五行 | 有害 |
| **仇神** | 生忌神的五行 | 间接有害 |
| **闲神** | 不起平衡作用的五行 | 中性 |

### 第 5 步 · 病药（神峰通考体系）

> **"有病方为贵，无伤不是奇。"** — 《神峰通考》张神峰

#### 5.1 病药说核心

**八字如人体，有病需有药。有药则贵，无药则贱。**

| 概念 | 含义 | 判断 |
|------|------|------|
| **病** | 命局中破坏平衡、阻碍流通的因素 | 过旺的忌神、五行偏枯、刑冲破害 |
| **药** | 能化解/克制/合住"病"的五行/十神 | 制忌神的十神、通关的五行 |
| **轻重** | 病重药轻 → 不治；病轻药重 → 过治 | 药力需与病力匹配 |

#### 5.2 常见病药组合

| 病 | 药 | 说明 |
|----|-----|------|
| 七杀攻身无制 | 食神/印星 | 食神制杀、杀印相生 |
| 伤官见官 | 印星/财星 | 印制伤官护官，或财星通关 |
| 枭神夺食 | 偏财 | 财星克枭护食 |
| 财多身弱 | 比劫/印星 | 比劫分财、印星生身 |
| 官杀混杂 | 合/去其一 | 合官留杀或合杀留官 |
| 五行交战（如金木互克） | 通关五行（水） | 金生水→水生木，化克为生 |
| 比劫夺财 | 官杀/食伤 | 官杀制比劫，食伤泄比劫生财 |
| 印重身强 | 财星 | 财破印 |

#### 5.3 病药判断步骤

1. 找出命局最大的"病"（失衡点）
2. 找原局是否有"药"（治病的五行）
3. 药有力且不被克 → 有病有药，贵人命
4. 药无力或被克 → 有病药轻，命运多舛
5. 无药 → 等大运流年补药

### 第 6 步 · 观十神（十神配置 → 组合 → 做功方式）

> **"格局是骨，十神是肉。"** — 命理通则

#### 7.3 五行流通

### 第 9 步 · 推大运（大运+流年+梁湘润流月法则）

从排盘 JSON 的 `dayun` 字段读取完整数据。

**引擎粒度能力（按需使用，禁止自行推算）：**

- **大运表头**：常规排盘已包含（`dayun.pillars[].ganzhi`、`startAge`、`endAge`），无需额外参数
- **流月**：仅在用户问「这个月运势」或需检查梁湘润流月三法则时启用。**推荐 `--liuyue-year <年份>`**，只输出目标年流月；不要用裸 `--liuyue`（输出约 18000 行）
  ```bash
  # 按需排盘（轻量）
  node 排盘工具魔改/bazi-paipan/paipan.js ... --liuyue-year 2026 --out 排盘_流月.json
  ```
- **流日/流时**：加 `--liuri YYYY-MM-DD`（当日干支/十神/旬空）与 `--lishi YYYY-MM-DD`（12 时辰），十神以命盘日主为基准
- **数据提取**：即使生成了流月 JSON，也不要全量 read。用 grep 定位目标年份后只读周边行，或使用 Node 单行脚本提取：
  ```bash
  node -e "const d=require('./排盘_流月.json'); for(const p of d.dayun.pillars) for(const ln of p.liunian) if(ln.year===2026) console.log(JSON.stringify({year:ln.year,ganzhi:ln.ganzhi,liuYue:ln.liuYue},null,2))"
  ```

#### 9.1 大运起运

- `dayun.startAge`：起运年龄（精确到月日）
- `dayun.forward`：阳男阴女顺行 / 阴男阳女逆行
- `dayun.pillars`：每个大运的干支、起止年份、十神、流年

#### 9.2 大运断法

**大运是十年一个大方向，流年是每年具体应事。**

| 大运与原局关系 | 含义 |
|----------------|------|
| 大运为用神地 | 十年好运，发展顺利 |
| 大运为忌神地 | 十年低谷，多有阻碍 |
| 大运干支一气 | 该五行力量极大，影响深远 |
| 大运与原局三合/三会 | 引动原局，应相应事项 |
| 大运冲月柱 | 变动大（搬家、换工作、父母变动） |
| 大运冲日柱 | 自身变动（婚姻、健康危机） |
| 大运冲时柱 | 子女变动 |

> **"大运以干支配八字之喜忌。"** — 《子平真诠》论行运

#### 9.3 流年断法

- 流年天干主事之表象，地支主事之实质
- 流年与命局、大运形成刑冲合害 → 应事的导火索

#### 9.4 应期判断（索引 bazi-yingqi 子 skill）

> **应期技法已拆分至 `bazi-yingqi` 子 skill**（保持主 skill 精简）。涉及婚/育/置业/六亲事件/重大变动的年份判断时，**必须用 skill 工具加载 `bazi-yingqi`**，按五查表逐列核对（红鸾天喜/配偶星透干/食伤透干/印星置业/驿马/六亲流年宫/岁运并临），未命中的表列显式写"无"，禁止凭记忆只挑一两列。

本步基础框架（通用层，子 skill 之外仍需遵守）：

| 应期类型 | 判断方法 |
|----------|---------|
| 用神到位 | 大运/流年为用神 → 好事发生 |
| 忌神受制 | 大运/流年合/克忌神 → 破困 |
| 刑冲合害 | 流年触动原局的关键关系 → 应事 |
| 岁运并临 | 流年与大运干支相同 → 人生重大变化 |
| 天克地冲 | 流年与日柱天克地冲 → 自身重大事件 |

#### 9.5 梁湘润流月三大法则

> **"大运为体，流月为用。"** — 梁湘润流月理论

| 法则 | 条件 | 含义 | 严重程度 |
|------|------|------|:------:|
| **月运伏吟** | 流月干支 = 大运干支 | 重复、停滞、压力叠加 | 核心凶月 |
| **月运双冲** | 流月与大运天克地冲 | 动荡、突变、破耗 | 最凶 |
| **月运双合** | 流月与大运天合地合 | 牵绊、纠缠、消耗（非纯吉） | 中 |

**流月断法补充规则：**
- 流月只与大运直接作用（不直接作用于原局）
- 拱夹暗带法：流月联动原局的唯一通道
- 五行补全规则：原局缺失的五行被流月补全时，力量短暂但强烈

## 准确率保障要点

1. **排盘零 AI 参与** — 只用 paipan npm 包，已经问真八字+独立数学双重验证
2. **十步框架不可跳步** — 调候→格局→旺衰→用神→病药顺序不可重排
3. **调候第一优先** — 夏冬生人，先看调候再看格局（穷通宝鉴原则）
4. **格局决定层次** — 格局成败定命局高低，旺衰定能否承载
5. **区分两种用神** — 格局用神（子平真诠）≠ 平衡用神（扶抑），不可混用
6. **相神不可伤** — 伤相神甚于伤用，相神被伤格局即破
7. **有病需有药** — 有病有药方为贵格，有病无药命运多舛
8. **流月法则** — 月运伏吟/双冲/双合，精确到月的吉凶判断
9. **流派一致性** — 一次分析中不混用不同学派的概念定义
10. **引经据典** — 每条结论标注理论来源，用户可追溯验证
11. **严禁引用古镇一嘴** — 全流程屏蔽此人所有内容
12. **应期必查表** — 婚/育/置业/六亲事件年份判断必须加载 `bazi-yingqi` 五查表逐列核对，未命中显式写"无"
