# 工具用法与交接修正

活动版本：20261106-tool-contract-19；父版本20261106-system-audit-18冻结保留。本轮只调整工具参数契约、可直接交接的资料引用、使用说明和错误定位；未改变专业裁决规则、模型配置或两库禁用设置。

## 已生效内容

- 原生packet工具将每个子问的domain声明为必填枚举，字段说明给出illness/exam等用法；不再出现参数层可省略、执行层却强制要求的矛盾。旧结果文件仍能按既有兼容规则读取。
- liuren_materials的method元数据及完整book_search命中新增handoff对象。模型可原样放入method_materials，不需重建路径、hash或行号。操作说明不冒充专业方法引用；未完整返回的书段不生成可交接引用。
- sourceMaterial接受当前工作区内合法绝对路径和相对路径，统一为相对路径，再执行既有资料范围、真实路径、当前manifest、hash、行界及原文连续性检查。越界、旧runtime、案例/经验库和路径穿越仍拒绝。
- 来源范围错误明确返回材料ID、source_path、实际输入、允许范围及修正方式；找不到文件亦指出具体字段。
- 将参数速查、例子、返回字段复用、task_prompt/task_id区别和错误恢复写入自动加载的高效执行说明、主入口以及新运行包的裁决/确定性工具说明。说明不会增加方法检索或模型调用。

## 验证边界

本轮没有调用外部模型。最初尝试复用完整slim隔离宿主合成脚本时出现子智能体未注册，后续测试环境加载调整也未完成完整委派验证；记录保留在host-chain.json、host-cli.log及first-*文件中。本轮实际通过的真实宿主验证范围是读取至打包，不把它标成完整slim裁决链验收；原生裁决协议与流程回归另有测试覆盖。没有据隔离测试失败修改用户的插件注册机制。

新参数定义需要重启OpenCode并在本目录新开liuren会话后加载；运行中的旧会话可能保留旧schema，不能仅靠提示词确保刷新。
