# 大六壬通用判断与裁决方法设计（文献调查后第二稿）

状态：已按北海、陈公献原载断例、邵彦和原载断例、《壬归》及天一群笔记的有界调查修订；仍为候选执行归纳，尚未接入活动 Skill 或运行包，尚无独立预测效果验证。

本稿已修正首稿的不足：增加真假变质与主客取与，扩明气势的组合、方向及传递意义；区分重复计证与有效类聚；用误断核查象义到结果的推导；隔离异盘、编注与读者补议。调查范围及23个案例单元见[调查结论](../liuren-expert-adjudication-study-20261105/高手断例调查与修订结论.md)，[首稿原字节另存](../liuren-expert-adjudication-study-20261105/通用判断与裁决方法设计-首稿留存.md)。

范围：本机大六壬各类占事。正常年命、行年、应期仍按原法；不引入出生推命、大运、小限、飞限。此设计在既有三宏阶段内补足裁决动作，不新增一套替代六壬原法的评分体系。

## 一、要解决的问题

“依据很多，最后拿不定主次”至少包含四种不同错误：没有选出切题主线；把不同对象或维度的依据当成冲突；把有关系当成有效作用；缺少细分结果的依据却强行选档。结尾温和化可能进一步改变已经形成的判断，但仅凭现有片段，不能确认这是所有模型统一的输出机制。

改进目标是有根据地取舍，允许明确吉、明确凶、吉凶分维度并存或确实不能裁决。不能把“不要折中”改成必须报高档、必须极端、必须单选；也不能把所有反证预先降为过程问题。

现行定位、理气、裁决与报告模块已包含许多相关原则，缺口主要是原则之间的连接和最后的收束。《壬归》LF357引“专视青龙则失之拘，遍推寻而无所主则失之荡”，北海讲义以明占类、定侧重、看显象入手；断例进一步显示真假、取与和组合关系不能被标签清单替代。以下七动作是据这些材料组织的本轮执行归纳，不能冒充诸书一致承认的统一算法。

## 二、七个判断动作

### 1. 定清本问及需要区分的结果

先用一句话写明：谁，问什么，已经处于哪一阶段，在什么期限内，以什么实际事件为结果标准。按实际任务区分成败、程度、过程、持续性、时间与数量，不强迫每案全部展开。

例如“收到录用通知”“实际入职”“入职后能否留任”是不同问题；“有回款”“足额回款”“扣除成本后的利润”也不同。某种支持不能直接在这些问题间转用。

存在会影响作答的候选时，列出需要区分的结果即可，不穷举所有可能，不预设中间选项较安全。现实制度有已知门槛时予以记录；没有资料不编门槛、比例或常见结果。

### 2. 因问与课传定侧重，提出可复核的主线

在初看全局后，说明本问主要依据哪一关键类神、关系或切题结构，为什么它比其他现象更直接回答本问；随后辨其真假、状态与有效作用。主线是待检验的解释，不能提前冻结成败。

先定侧重，不等于先选答案。《指南问答》会试段中“先定必中，再找类神”的文字是未署名读者补议，不能归北海，也不采作规则。北海《理法简易》要求核课体与所问是否亲切；本轮E02返吟应聘取成、E05官龙临干却取不入相，是不同具体作用下的取舍对照，不是课体和类神谁永远更大的证明。

可用一句话形成工作小结：

> 本问重点在于____；目前以____为主线，因为____；需要核实的主要阻碍是____。

这里的“关键”须由题目所问、原法适用范围、实际位置和作用说明，不能以“我觉得它重要”代替。发用、课体、末传、类神、年命均不设跨占类固定百分比，也不预定任何一项永远最大。

若出现同职责多类神，先核其对应同一件事、不同对象还是不同阶段，再择用或分断。不能把候选角色全部纳入主判后相加。

### 3. 把决定性依据落实为作用判断

对实际支撑主判或可能推翻主判的依据，核四件事：

| 检查 | 要回答的问题 |
| --- | --- |
| 方法成立 | 用哪条原法或哪项本轮归纳？占类、位置与其他前提成立吗？存在何种来源分歧？ |
| 对象与状态 | 作用于谁？盘面坐标、六亲参照、旺衰、空墓、阴神和相关制救是否核清？ |
| 实际作用 | 依所用方法，它在本课怎样生效，有什么支持或限制？关系存在是否足以造成所声称的改变？ |
| 所答维度 | 它说明成败、大小、取与、迟速、损耗、持续性，还是只提供属性？能推出到哪一层？ |

只展开相关检查，不机械穷举全盘组合。有成立条件的复合类象或专法可参与结果，不强行把它们改写为单一五行生克；原文的强语保留，但原句存在不等于本课已经满足其全部条件。

气势不只指旺衰，还涉及进退、内外、传递、动静、神将组合和类聚，具体依所用原法。主象可能因空陷、闭口、阴神或其他组合变质；要核它是否仍是原主判所需的东西。《断案》E07的长生空使引鬼为生未能完成，不能仍保吉再扣程度。E01分房则在作者明确的得气得生口径下保留类神可用；两者均不得抽成一见空就永吉或永凶。

按占类核取与：资源旺不等于对方愿给或本人能取；生助所忧之神也不一定有利。《壬归》文书之财分别考察财阴、与财者及本人的受益受伤，不把分夺、后患、不敢给和不敢取统一翻译成财少。

例如，出现“克”的关系，不等于已经制住；出现“救”的名称，不等于障碍已解除；出现“财有损”的依据，也尚未给出损在获评、实发、花费还是净所得的定位。不能为保全主判临时编出损耗的发生位置。

### 4. 先辨是否真冲突，再作正面对决

对相反依据先检查：是否同一对象、同一阶段、同一结果维度。不同维度可以同时成立，不必相互抵消；不同阶段仍须检查后续影响，不能仅分开就当无关。同一事实的重复命名、同案跨本转载不算独立证据；但同一节点的六亲、乘将、煞、旺气等不同职责可以共同形成专门组合。《理法简易》明确有重神、类聚之论，不能为机械去重把组合拆散。须说明各条件如何共同成立及作用，既不按名称数投票，也不把同支信息一概删成一条。

真正冲突时，比较适用前提、切题性、实际位置、状态力量、传递或作用、制救及原法所定范围。它们是核查事项，不能改成跨占类永久优先的权重表。

重点处理最强反证，同时保留其余会独立改变结果的反证，不能只挑一条容易反驳的反证作过场。双方都要接受同样检查，不为保吉断提高凶证门槛，也不为保凶断提高救应门槛。

最后完成这个取舍句：

> 相反依据____在本课成立／不成立／尚未核清；它影响____，因此主线的____仍成立／已经失效／需要保留分支。

不能只写“综合来看”“小煞不改大局”“虽凶有救”。必须补出本课的实际理由。反证不适用，只能撤销这一反证，不能因此新增一条成功依据；反向同理。

资料之间有实质冲突时，先辨占类、阶段、定义及版本，采用口径须明示，不能随预想结论切换。差异尚无法解决且影响主判时，保留方法分支及其不同结果，不装成原书已经一致。

### 5. 根据作用决定保留、改变或暂缓

| 核查后的情况 | 应作的裁决 |
| --- | --- |
| 主线仍成立，反证未改变所问结果 | 保留主判；仅在有依据时说明其造成的具体影响。不能为了照顾反证凭空编波折。 |
| 作用确实改变程度、时间或持续性 | 修改对应维度；变到何处须有依据，不能统一扣一档、打折或顺延。期限本是成功标准时，迟延可能直接改成失败。 |
| 关键定位、依据或作用失效，或有效制救改变局面 | 重新裁决结果，并复核依赖它的程度、数量与应期；允许由吉转凶或由凶转吉。 |
| 关键资料或方法仍无法裁清 | 说明未定点及其对应分支；有充分偏向才给主选，没有偏向依据就明确无法区分。 |

不存在跨占类通用的“出现几项凶象才可翻判”门槛。局部支持不是全局成功，局部受损也不是全局失败。主线能否保留由本课方法条件及有效作用决定。

### 6. 单独判断结论能精细到什么程度

先问依据能否判断事情成败；再问它是否还能够区分原问所需的等级、名次、金额、日期或持续时间。细分专法有新发现时，应回核主线，不能把前面判断当成不可变的前提。

区分候选结果时，特别识别二者共同拥有的支持：它可以说明总体趋势，却未必能排列二者。支持“有录用机会”的依据不当然区分第一志愿与第二志愿；支持“得财且财丰”的依据不当然区分两个具体金额。

先核象义与目标是否等价，再谈精度。天一群笔记E15以铸印有奖直接断辩论胜，反馈却输了但有奖；这是胜负主问错误而获奖子项有对应，不能以“整体吉”消去差别。可问：该依据成立时，是否仍能出现另一个待选结果？若能，它单独就不足以完成这次区分。此为本轮由反例归纳的检查办法，不是新的六壬占断定理。

有切题、成立的区别依据时，明确作出主次选择。没有时保留已经能成立的较粗结论，并写明细分缺口；不能把资料不足自动转成较低档位，也不能为了避免折中强选最高档。

数量、等级、期限等不总能分成粗细两层，仍依具体问题：若用户问的就是足额回款，部分回款不能偷换成成功。精度受限也不能把一个没有回答原问的宽泛判断标为回答正确。

把握程度与结果程度分开。对较高结果仍有疑虑，可以保留这一主判并说明疑虑来源；不能因为不够确定就改成中等结果。对严重结果的判断同样不能为缓和表达而改成轻微结果。没有统计校准，不编概率。

### 7. 按已完成的裁决输出，结束无新增依据的循环

最终报告先直接回答子问，再说明决定性依据、最强反证及其取舍，最后给必要的条件、精度和缺口。全部检查不必变成全盘标签清单。

报告至少能让读者看清：

> 主判是什么；为什么这个依据对本问更有决定性；最强反证改变了什么、没有改变什么；哪些细分目前做不到。

写作阶段不得仅因“稳妥”“公平”“通常如此”改变已裁定的结果。复核发现新事实、漏项、起法或推导错误时仍必须修订，并说明影响的依据。只有同一批理由反复重述、没有新条件或错误修正时，停止循环，不继续折中。

可作一个简短自检：去掉这条依据后，哪个判断还成立、哪个不再有据？若某条凶象在所有候选结果里都被解释成同一种“不顺”，它可能没有提供选择作用。此检查用于暴露推导缺口，不是新的六壬断法，也不是对现实因果的证明。

## 三、跨占类逻辑对照

下表是假设裁决前提已按各占类原法核实后的逻辑示例，不是具体课例，不表示仅凭表中文字就能占断。

| 场景 | 已核清的前提 | 应怎样表达 |
| --- | --- | --- |
| 求职 | 原问录用；录用主线成立，另有据支持手续反复，反复不改变录用 | 明确判断录用，并说明手续反复；不自动降成“可能只进面试”。 |
| 求财 | 所求为本人足额取得；财多有据，但取得的关键条件被有效作用破坏且未解除 | 重新判断能否取得；不以“财旺”保成功，也不凭空编一个较小到账数。 |
| 出行 | 原先阻碍确有依据，后核有效救应已经解除这一障碍，尚须核其他成行条件 | 重判成行结果；不能规定救解永远只缓过程，也不能仅凭障碍解除就宣布一切顺遂。 |
| 失物 | 有据推方位，缺少区分具体房间的条件 | 报所能支持的方位与精度；不因要具体就猜房间。 |
| 考试 | 过关支持较强，尚无足以区分高名次与压线名次的依据 | 保留过关判断，明确名次未定；不能把吉象数量换最高分，也不能因有反证自动判压线。 |
| 回款 | 只核出迟延，而用户原问为月底前到账 | 比较迟延与原期限，可能判月底前未到；不能把“最终能到”替代期限内成功。 |

## 五、拟供核心模块采用的短指令

> 依本问与课传定所主，察主象真假、气态与所宜，核主体、所求、取与及作用；辨组合、类聚和传递如何使其成就、变质或转移。不按名称数投票，也不为去重拆散有效组合；不同对象、阶段与维度不强行相抵。真正冲突时明确为何取此舍彼，关键作用失效须重判，有效救应可改方向。先核象义能否推出本问结果，再核是否足以区分等级、金额和日期。最终措辞保持裁决含义，把握程度不换成结果折扣；无新增依据或错误修正不循环改判。有据则明确主次，无据则说明不能区分，不为果断强选，也不为稳妥折中。

这段应与核心正文整合使用，不能作为脱离专业检查的独立咒语。报告要求的是可核对的判断依据与取舍，不要求披露模型内部思维链。

## 六、怎样检验是否改善

分别检验执行质量与预测效果，不用其中一项冒充另一项。

1. 用上述跨占类逻辑对照检查：有损不自动降档、有效阻断能够改判、有效救应能够改方向、细分不足可以明确未定、期限和结果标准不被替换。正反两侧都要检查，避免仅纠正偏保守却造成偏乐观。
2. 后续选择结果对研判者未知、可追踪的实际样本。事前固定题干、盘、期限、口径、输出与版本；开发组与保留组分开。同案多人作答不是独立样本，已读过答案的奖学金案只作开发复盘。历史暴露未知时注明，不能称严格盲测。
3. 比较旧版与候选版时使用同一输入、模型和资料范围；所有运行均留存，不能只挑较好的重跑结果。样本按同一事件及同源资料去重，防止答案从检索或反馈文字泄漏。
4. 执行记录重点看：是否选出有理由的主线、是否重复计证、是否说明有效反证的作用、是否存在无据降档或升档、是否在收尾阶段无依据改变结果。不以格式齐全替代内容正确。
5. 效果分别统计成败、等级／金额、时间等原问维度的正确与错误；同时报告回答精度、无法裁决比例与反馈缺失。不能通过大量弃判、扩大范围或降低精度制造准确率提高的印象；不能把“有主见”当作“判断正确”。

本轮未进行新的外部模型调用或预测试验。提示词只能改善执行条件，不能保证模型遵循或保证大六壬判断具有实际预测能力。
