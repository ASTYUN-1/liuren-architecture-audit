# 完整旺衰计算体系：现状审查与设计

2026-11-08。本轮只审查与设计，未修改现行算法、参数、活动方法及导出盘。这里的“完整”指已登记、适用于本地采用体系的作用机制得到覆盖，不能据此宣称已经涵盖一切古法或已经证明预测准确。

## 一、结论

当前工具是局部生克数值模型，尚不是完整的综合旺衰模型。缺口包括：参与资格、作用通路、特殊关系的主次选择、发动与承接、合局与制救、四建及时间变化。部分关系已经显示在盘里，但数值层没有使用；还有部分现有数值处理本身只是研究假设。

完整方案不能靠不断追加固定加减分完成。应先将已确认规则变成有条件的计算规则，再统一求解本体强弱及实际作用。空亡属于综合旺衰的条件，必须纳入；不能把它移出算法，也不能让它在AI看到分数后再次无条件推翻结果。

保留一个便于阅读的综合旺衰指数是可行的，但内部必须保留本体、发动、承接和定向作用的区别。它们不是几个可以任意相加的吉凶分。

## 四、现有建模假设也需要重审

仅新增覆盖项仍不够，下列处理会系统性影响结果。

1. **地盘目前是固定环境。**[模型27—29、64—70行](</C:/Users/QLMa_/Documents/六壬八字测算/tools/liuren-local-strength.mjs:27>)使地盘不受输入改变，也不因输出耗损。环境作为持续条件有合理建模空间，但何时作为有限作用者、是否参与同一输出预算，尚未细分。
2. **同类可以循环互相抬分。**比和双向加益，没有对应源成本。收敛只说明这个方程能稳定，不能证明比和环自然产生的增益符合本体系。应明确它表示协同还是资源输入，并防止环路反复放大同一依据。
3. **增加关系会稀释原有关系。**[输出门限归一化](</C:/Users/QLMa_/Documents/六壬八字测算/tools/liuren-local-strength.mjs:54>)按所有出边一起分配；若无参与资格过滤，新增一条不切题边也可能削弱原本关键通路。预期应满足：仅改变展示范围不改变分数；新增实际机制造成的变化才需重算。
4. **直接阴神在全图中会间接连锁传播。**每个节点都连下一阴神，同时迭代会形成多跳作用。它未必等同于现行“一层为先，新增层解决具体疑点”的分析范围。需说明哪些是允许的基础传播、哪些需要新增适用条件。
5. **空亡折损目前只按月气选档。**生扶和克制虽会改变分数，却不会改变空亡系数本身。`坐空=旬空系数开方`及`自空/坐空取最小保留率`均是待检验约定，不能代替对复合条件的分析。
6. **长生与五行生克未完成专项联合。**一般加成与一般受克同时计算，不足以落实“巳旺则长生力多、鬼克力少”等明文条件；土临申也不能把长生、受益、泄耗混成同一个简单奖励。
7. **克制能力与对人的凶害尚未分开。**数值函数可以表示五行作用强度，但若将其直接解释成事件损害，就会违背U02。应在相应性质和目标条件下才解释为伤害或制病。
8. **当前数值精度高于参数证据精度。**[固定参数表](</C:/Users/QLMa_/Documents/六壬八字测算/tools/liuren-base-index-profile.json:10>)及[关系系数](</C:/Users/QLMa_/Documents/六壬八字测算/tools/liuren-local-strength-profile.json:5>)尚未校准；小数后三位不能当作可解释的测量精度。
9. **多次限幅可能掩盖差别。**基础层和迭代层都截到0—10，再施加空亡系数。应统一分数映射与限幅位置，检查极旺输入、负损益和空亡叠加后的排序；不能靠撞上限表达一切极旺情况。

不要求把“气”当作物理能量严格守恒；要求的是同一依据不重复算、施者作用份额有解释、环境输入与角色输出不混同。

## 五、建议的完整计算结构

### 1. 先确定计算对象与上下文

基础输入包括原盘、精确时刻、采用历法/季土规则、已采用神煞规则。事件输入另列：所问对象、类神候选、目标动作、观察阶段与期限、已核年命。

无需先知道求职、求财等语义，就能预分析全12宫各自的状态、局部条件、课传关系与候选作用。需要知道“财能否为我所得”等目标时，才启用对应的定向输出；不能假装纯排盘已经自动确定一切事件角色。

### 2. 规则先选择作用方式，再决定作用量

每条规则至少含：对象及坐标、触发条件、时段、适用占类、作用方向、影响层次、来源、与其他规则的并行/替代/共享依据关系。

运算顺序建议为：

`事实与采用表 → 条件识别 → 参与及阶段过滤 → 专项主作用选择 → 生克与约束联合计算 → 时间更新 → 结果压缩`

一般规则不得覆盖已满足条件的专门解释；并行关系各保留，但共同原因只记一次。尚未支持的必要规则应在内部覆盖检查中报缺，不能默认其贡献为零再输出“完整分数”。

### 3. 一个综合旺衰结果，内部保留必要分量

| 内部分量 | 所回答的问题 | 典型情形 |
|---|---|---|
| 本体力量 | 自身得气、得地、受扶损后有多强 | 金旺而弱火难克 |
| 发动与持续 | 当前是否发动，能持续到哪个阶段 | 发用、初中末、马恋生、合绊 |
| 承接与落实 | 空、墓、坐处及通路对发挥有什么限制 | 本体不弱而坐空，不能据强度直接保证到达 |
| 对指定对象的作用 | 向谁生、克、泄、救，实际能发挥多少 | 财难为我得、父母难生我、鬼难害我 |
| 作用性质 | 这项输出在本问表现为何种作用 | 旺鬼权威与衰鬼侵扰；克病与克身 |

这是内部计算结构，不要求AI面对五张冗长表。广义综合旺衰应包含空亡、受限与救制；本体分量保留是为解释“同样综合分数，为何发挥方式不同”。

### 4. 公式的合理结构

此处给计算接口，不新增未经校准的具体数字：

```text
本体状态_i(t) = 联合求解(
  月令与临处基础条件,
  已成立的生扶、比助、泄耗、克制,
  生克并见的专项主作用,
  施者自身状态与可分配作用,
  相应空墓及结构约束
)

定向作用_i→j(t) = F(
  本体状态_i(t), 受者状态_j(t),
  实际通路, 阶段, 发动与承接条件,
  贪生合、合绊、冲启等已适用规则,
  神将性质与制救关系
)

综合旺衰_i(t,观察目标) = 统一量表映射(
  本体状态, 发动与持续, 承接限制, 必要的目标作用
)
```

不是将每个限制一律乘一次；规则需决定它是改变基础量、限制某条边、改变结构，还是只影响某阶段。例如开墓改变闭藏条件，不能既奖励开墓再无依据返还全部墓损；德解也不能同时作为独立加气和对同一鬼的重复减害。

最终固定参数应同时覆盖五气、十二气、通路强度、施受比例、约束、时间和显示分档，再整体检验。先补几个漂亮数字无法保证整体一致。

### 5. 全局气势从同一作用图导出

分别汇总有效五行来源、主要生克流向、课传阶段变化、主客强弱与关键限制。合局成员既参与个体计算，又在结构中协同，不能再作为完全独立的整局力量重加一遍。地盘环境和乘将亦不能因都属某五行便简单堆成票数。

全局摘要不反过来作为一项新加分去证明自身。低于2.5可以设为研究显示档，但不能删去节点：弱冲神可能触发开墓，弱煞或空支也可能参与关键结构。是否不可用必须针对本问所需作用，不能从一个统一分界推出全部结论。

## 六、本课应怎样检验这套设计

### 戌—午—寅三传

2026年11月6日14:43示例中，午旬空，寅自身不空而坐午空。当前这三支恰好还构成直接阴神循环，局部模型已经包含其部分五行关系；问题不是三传完全没有关系计算，而是尚无完整时序、合局及承接机制。

完整计算应依次处理：

1. 戌、午、寅及各乘将的月气、十二气、旬空/坐空和实际扶损。
2. 寅午戌成员齐全，但成员午空；成员存在、合的联系、实际合力和是否化分别判。
3. 火的实际作用来自哪些有效来源，是否被合绊、冲破或制住；寅生午的泄耗是否与合局协同共用预算。
4. 初中末阶段及救制通路是否允许后续作用；不能同时对称抵销一切。
5. 若按驿马/出行专项使用寅，另外检查其发动、承接与终局；寅坐空不能被误写成寅自身旬空。

三合不应简单统一乘1.1；午空也不应直接使整组力量归零。应先确定这些条件如何改变每条实际作用，才能讨论数值高低。

### 丑坐巳、辰坐申

- 丑土临巳为绝，同时巳火生土：保留绝态与生扶，具体判断扶助是否改变受限条件，不能先因绝忽略生，再另加一次“绝处逢生”奖励。
- 辰土临申为长生，同时土生金泄：长生状态保留；五行泄耗亦保留；还应按所问区分学历、生计、得养与求财耗泄等意义。它不是两个符号简单互相取消。

### 白虎乘申发用的求职案

该案适合暴露“强类神被旬空一票翻盘”的流程问题，但不适合独自标定空亡参数。应检查：申与白虎各自状态、发用身份、相关生处坐处制处、空对哪个求职环节形成限制、限制是否有有效解除、对所求的实际作用。职业取象和录用事实仍需原有方法判断，不能从一个力量分数自动生成A/B选项。

已知答案用于回查机制；参数检验还需正反条件对照和未知结果材料，不能为了本例正确而统一削弱全部空亡。

## 七、可直接程序化与需要校准的边界

### 可以先做成确定性预分析

1. 全部对象的身份、参照、上下层及一层阴神；本日日干保留，其他九干不默认导出。
2. 全盘状态、课传参与、完整相关关系；修补半合、三会、单见自刑等识别覆盖。
3. 明确专项条件的触发、排除、时序、方向及相互依赖。
4. 候选救制者、制谁/救谁、通路、阻断、直接临生合、合绊、空墓组合。
5. 四建/年命的实际位置及相关通路；时间改变的具体条件。
6. 同源依据去重、重复作用检测、规则覆盖检查。

这些是程序应该承担的预分析，不应继续把全部判断负担留给AI口头权衡。

### 数值层仍需整体校准

五气和十二气量级、月令与坐处权重、生扶与施生泄耗比例、克制与抗制、不同位置通路、特殊约束的强弱、空亡及坐空综合函数、合局贡献分配、分档阈值。

这些不属于新增的原文矛盾；是从明确的定性规则转为定量模型的参数问题。可以固定一套研究参数，但必须让参数接受全体已定规则及对照检验，不能以函数存在或工程收敛当作参数正确。

## 八、后续实施顺序及完成标准

1. **先完成机制清单与规则接口。**每项对应来源、条件、对象、阶段、影响层和已有代码；本报告列的是第一轮框架，尚不是全部原书条文的逐条穷尽审计。
2. **补齐预分析。**不先加分；先保证每个关键机制能够被正确触发、排除、去重和定位。
3. **统一数值内核。**重审环境、循环增益、输出预算、阴神传播和限幅，然后接入各条件分支；一次设计完整参数表。
4. **做机制对照。**同盘仅改变一项条件，验证弱火/旺金、同处生合/外来扶助、初末时序、旬空/坐空、局部救/解关键阻碍、半合/全合等；同时测试合局与单体不重复计能。
5. **检验整体及参数敏感性。**查看哪些结论依赖微小参数变化；再用未参与定参的材料检验排序与作用解释。机械正确和预测效果分开报告。
6. **最后统一交付。**排盘及事件补算共用内核，主、子智能体接收同一版结果。已算因素不由AI再次任意加扣；AI发现遗漏时指出具体事实/规则，再补算受影响结果。

完成标准应是机制覆盖、条件成立、数值记账、时序和结果语义都一致，而不是“每一宫都有一个数字”。

AI-facing盘面建议只保留：综合旺衰及分档、简短状态组合、影响本问的关键限制、必要的定向作用与时间变化。详细计算账本在本地审查文件中；不能重新把全部工程检查塞回盘面。若必要机制尚未支持，应简短标明该项未完成，不将局部值冒充完整值。
