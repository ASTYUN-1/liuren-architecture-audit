# 未选用神煞的意向分类

活动版本：20261109-guanshen-36。核对日期：2026-11-09。

按原引擎172个去重名称，剔除现行39条规则已覆盖的41个名称或别名，余131名。这里的“未选用”只指未进入神煞采用表，不把131名都视作独立待增补神煞。99名按现有释义归主类，10个关系/身份标签另列，22个定义不足项保持停用。

关神已另行接入S33并从本表移除。本表其他项沿用现有释义记录，没有据分类新增规则或重新校勘全部原典。各类仅为核查入口，实际义项会交叉。

| 意向主类 | 名称 | 现有释义与边界 |
|---|---|---|
| 医药与病势回转（3名） | 日医、返魂、天破 | 日医：医药、医治；返魂：病势回转、复苏；天破：来源有病占吉用。三者不等同。 |
| 孕产、小儿与病患（6名） | 浴盆、丧魄、天狗、天鬼、女灾、小煞 | 浴盆：病患与胎产分用；天狗：孕产；女灾：传统阴人病患；小煞：小口灾。丧魄、天鬼另有各自病患条件。 |
| 德解、救助与增吉（7名） | 天德、月德、天赦、天解、解神、仪神、福星 | 德神助佑、恩赦、解散或消祸增吉；天解有月/日干两法。福星偏求望助益，并非狭义德解。 |
| 学业、科名与授命文书（1名） | 皇书 | 皇书有拜命、科名、功名及文书的来源义；不能泛指所有学习能力。 |
| 官禄、名禄与命令批复（5名） | 天书、天诏、天恩、皇恩、天龙 | 天书：官迁、财喜；天诏：命令、受恩；天恩/皇恩：庇护、诏命迁转；天龙：求名禄。 |
| 财物、营求与家宅门户（6名） | 天财、圣心、大耗、岁宅、岁破、门煞 | 求财、和合营求、耗损、破损重修及门户。岁宅与岁小耗有共表关系，须防新增重复项。 |
| 信息、察探与行人阶段（8名） | 信神、信煞、天鸡、天耳、忧神、泰神、游神、戏神 | 消息、远信、听闻、追查、消息虚实及行人未至/在途/将至；忧泰不能按字面直接分坏好。 |
| 盗失、追捕与人物财物亡失（11名） | 游都、鲁都、天盗、时盗、日盗、天贼、亡神、月亡神、支亡、日亡神、天目 | 盗贼来去、盗失与人或物亡失；天目有捕盗寻人之义。天盗、天贼跨基准须分法。 |
| 婚合、人际与阴私隐情（6名） | 月合、阴奸、奸门、奸神、奸私、月厌 | 月合偏成合；阴私类须有相应所问与组合；月厌有妨嫁娶及病、梦、盗等分支。 |
| 官讼、刑禁与冤屈相负（8名） | 官符、月官符、管神、天刑、天狱、天吏、相负、枉屈 | 官事词讼、拘束刑责、催办追呼；相负为辜负，枉屈为冤屈，也可用于契约与人际。 |
| 出行、交通与行动阻滞（6名） | 四废、天车、天坑、飞符、五鬼、游祸 | 行动受阻、功能受限、车辆行程及行动风险；飞符另有日德救、朱勾加重的分支。 |
| 突发灾险、损伤与绳索（13名） | 岁煞、岁虎、劫煞、劫杀、灾煞、金神、红沙、大煞、丝麻煞、悬索、长绳、阴煞、阳煞 | 灾险、财损物破、血光及绳索物象；阴阳煞另偏人物口舌，阴煞兼病患；大煞另有官用。 |
| 火患（2名） | 火鬼、火烛煞 | 火厄、身宅火患；保留并蛇雀、克日或克辰等条件。 |
| 天时气象（7名） | 风煞、风伯、雨师、雷公、雷煞、天怪、晴朗煞 | 风、雨、雷电、异常天象与晴朗；仍须神将、旺衰及天时结构。 |
| 坟墓、覆蔽与昏晦（6名） | 岁墓、三丘、五墓、墓门、华盖、黄幡 | 坟墓、墓地变动、覆蔽昏晦等；岁墓兼病讼宅灾。现有资料不足以把华盖泛化为才艺学业。 |
| 神魂、梦寐与传统咒象（3名） | 迷惑煞、游魂、天咒 | 思虑辨识受扰、神魂不定、梦寐及传统咒诅象；不是现代医学诊断或现实咒诅证据。 |
| 统领、兵权与人物角色（1名） | 将军 | 头目、领兵权者；亦用于行人占。不因人物权力象即认胜利或升迁。 |

注意：上一轮建议把华盖列入官禄文书类过宽。本轮按现有六壬来源的覆蔽、昏晦义归类，不套入八字艺术才学解释。皇书才有此处可核的科名义。

关系或身份标签10名：岁刑、月刑、月害、贵人、日官、日鬼、支刑、支破、支冲、支害。贵人作为十二天将之一已在正式盘；官鬼及刑冲破害另核关系层，不将这些名称全部视为缺少计算。

明确停用且本轮不强分意向的22名：岁德、转煞、贼符、月符、天厕、瓦煞、直符、进爵、飞镰、天才、游煞、火恶、游娲、天史、伏殃、旬盗、稼穑、天罗、干胎神、时煞、马倒、支胎神。

增补核查时先区分这些情况：

- 德解：天德、月德、天赦、天解、解神；仪神可参干奇消祸增吉，福星偏求望助益。解神也可能解散所求之喜事，不能一律定救。
- 医药：日医是直接医药候选；返魂、天破偏病势或转归；浴盆等须按保胎/临产/病患分用。天医、地医已采用，故不重复列入。
- 学业：此轮直接保留皇书的科名义；天书、天诏、皇恩等偏官禄、命令与批复，不能全部混成学习能力。文星、帘幕、旬奇、旬仪已采用。
- 共表不一定需要新增一条证据：岁宅与岁小耗、天恩与皇恩、支亡与日亡神等，要核身份及重复；天解、天盗、天贼等同名跨基准要分列。
- 待核项不凭名字定类：岁德不能直接套日德；天才不能并天财；飞镰不能并飞廉；天史不能并天吏；干胎神/支胎神不直接等同专项胎爻。
