# 分类取用短答试验 61（仅本机 OpenCode）

只回答分类、一个首取主类及简单倾向，通常200—400字。主直接回答，不创建packet、不派裁决、不调用task、review/recheck/deliver，不做分数、名次、应期。专项摘录供分类、职责与条件核查；不恢复完整占断流程。

## 取用与发用

1. 固定原问的当事人、阶段与成功标准，按本问domain首取，不因旺弱或已知答案换类。考试区分单科过线、成绩、录取、证书、通知；分支不明才定点查classification-priority和连续原文。
2. 取得可信程序盘，明确主类天盘支、地盘坐处、乘将及首取依据。年命按明确资料采用；天盘支与地盘同名宫不可混淆，地盘丑不能以T:丑补算。主类以外固定检查初传，再额外兼看最多一项必要条件。
3. **初传必须实际进入取舍。**读trial_chart_basis.initial_transmission的六亲、月气、坐处十二气、乘将、旬空/坐空及采用神煞。先说明发用在本题代表发动、压力、门槛、款项还是结果线索；无据不预设为结果。同神兼职责须分清，不把官鬼与迁调驱力混成单一强弱开关。主类与发用重合时只算同一对象，不计两票。
4. 闭口、月破、空墓及神将专项状态按本问核其影响。初传闭口对于语言表达、应试作答等的相关性，不能未经解释就缩成通知迟；也不能凭闭口直接编造睡觉、不会说话等现实细节。程序列出的神将各自十二气与专项名称分层；丑土墓不等于朱雀火墓，未核专项条件须明示。旺衰数值未完整包含这些象义。

## 单一五行旺衰口径

5. 本试验只用五行月令旺相休囚死，内部参数quarter-earth：寅卯木、巳午火、申酉金、亥子水、辰未戌丑土当令；旺者所生相、生旺者休、克旺者囚、旺者所克死。禁止four-seasons作为判断依据，不并列、平均或按结果切表。此为月支取气，不是季末十八日自动取气。日干、支神、天将按自身五行取月气；坐处和阴神十二气另列。月气、局部综合指数、专项象义不能互相替代。
6. 本题相关日干、关键类神、官鬼与凶神统一喜旺恶衰。官鬼旺默认凶害减轻，衰则凶态显；低分、零不等于无害或失用。先解释生扶、取财、应试付出、资格约束或实际侵害，再论作用；泄干生主类不默认失败。制救须解除本题实际不利，不是把官鬼分数压低。
7. 主类与初传单宫状态可复用程序盘。决定性跨宫作用先核身份和实际通路，再用liuren_compute(action="strength",archive=原盘archive,strength={mode:"selected_relations",season_profile:"quarter-earth",season_basis:"五行月令旺相休囚死",actors,links,review:true})。读取trial_judgment_basis，不手调分、不凑全盘关系。不把数值负增量当现实伤害；禁止旺鬼→扣低日干→改称身弱→判凶。日干原有弱仍可考虑；衰鬼不得以“克不动”“无强压”删去凶态。已引用却未补算的日鬼也读排盘状态。

## 综合与短答

8. 分开判断：事情是否发生、事情对本人利弊、岗位待遇或物品质量。弱禄可描述待遇不厚，不直接证明不能录用；衰空马星可描述变化中的不利、迟滞或虚象，不能直接证明不调动。喜旺恶衰依然成立，但不是所有问题的事件发生开关。初传旺也不保证目标达成。
9. 围绕主类与初传，归纳一项最直接有利、一项最直接不利，解释哪一条件更切成功标准，再给事件方向与吉凶倾向。没有固定权重、票数或成败总分。不要把工作调动等中性发生问题强塞成“发生即吉”；没有期限不补造“本轮、近期”来缩窄原问。空不自动败，旺不自动成；不将当前不利改成事件永不发生。

统一层级：E=0模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null缺计算；不代表可用程度、成功概率或考试分数，不用旧数量4至6分段及harm_tendency/favorable_tendency小数。

输出：一句分类/阶段；主类可靠位置和首取依据；一句初传状态如何切题；简单倾向与一个关键条件。仍200—400字，不列工程检查项，不恢复完整报告或多轮复核。缺决定性信息最多问一个问题，已有资料先答。不查案例/经验库、旧会话、已知答案；原书仅查实际缺口。程序不证明取类或预测准确。
