# 短答61版：单一五行月令旺衰与初传取舍

已生效到本机OpenCode当前分类取用短答试验，新进程/新会话加载。仍使用原配置DeepSeek Flash/high，200—400字，不触发裁决。本轮未调用模型、未重跑五例预测，未部署网站。

## 旺衰改动

当前短答的liuren_chart、compute(chart)、lookup和strength统一采用五行月令旺相休囚死：寅卯木、巳午火、申酉金、亥子水、辰未戌丑土当令；旺者所生相、生旺者休、克旺者囚、旺者所克死。内部兼容参数为quarter-earth。它实际按月支查表，不是季末十八日自动算法。

排盘单表路径直接只计算、输出该月令的旺衰。strength禁止four-seasons请求，不生成双表对照；lookup未传profile时采用quarter-earth，显式旧表请求拒绝。compute帮助也不再提供旧表枚举。支神、天将、日干各按自身五行取月气，十二气和专项象义分开。数值算法及研究系数未改，只统一采用口径；月气不等于综合数值，分数不等于成败总分。

旧表保留在历史冻结资料和非短答兼容接口，当前短答不使用它作为旺衰依据。正式全流程和既有绑定任务没有追改。专业核心和17份完整专项原件保持原样。

## 初传怎样进入判断

排盘trial_chart_basis新增initial_transmission，直接带出初传六亲、位置、乘将、空陷、支将各自状态和已采用神煞；角色与事件效应留null，避免程序替模型取用、裁成败。定点查盘只看其他宫位时，也保留完整初传信息。

短skill、agent prompt、短方法正文、workflow帮助与工具解释均明确：初传固定检查，先定本题身份，再看旺衰、坐处、乘将及闭口空墓等切题条件，最后与主类综合。主类与初传重合不算两票，发用不自动替换主类。支神、天将与地盘坐处不可混写。

事情发生与本人利弊、待遇质量分开；弱禄可描述待遇差，不直接证明不录用；马星衰空不能直接等同不调动。相关官鬼喜旺恶衰继续保留，低分或零不当无害/失用。闭口、月破、神将专项象义未全部折入分数，不能被高分掩去，也不无据只改称消息迟。

这次没有给初传设置固定权重、成败阈值或自动投票。如何处理它与主类相反的信息，仍由模型按事件职责说明最直接的助阻。
