# 八字应期断法（bazi-yingqi）

> 本 skill 是 bazi 主 skill 与 hecan 合参 skill 的**应期技法库**，不独立启动，由主流程索引调用。
> 核心原则：**八字为应期主轴盘**——先按本表逐列查八字，再交给紫微流年验证（合参时）。

## 调用方式

- bazi 单盘：主 skill 步骤9.4 应期判断 → 按本 skill 五查表逐列执行
- hecan 合参：hecan 步骤4 → 先按本 skill 出八字应期候选年，再索引 ziwei-liunian 验证

## 按问事类别映射（优先按需查表，全盘时全查）

> **🚫 禁止社会时钟预设（⚠️ 新增 2026-08-02）**：用户问某流年发生了什么、或综合看盘时，**不得以年龄推定该查哪些表**。21岁男命 → 表二（生育）同样必查，不可因"太年轻"跳过。60岁女命 → 表一（婚年）仍有变动可能。**叙事从星象中来，不从年龄中来。**

> 五表全查是安全策略。若上下文有限或用户仅问单一类别，可按映射选择性查表，但需在输出中标注"已查表：X、Y；未查表：Z（非当前问事范围）"。**用户无明确类别时 = 全查。**

## 纪律

1. **五表全查**：每类问事必须逐列核对，显式输出"无"表示已查——防止只挑一列（上次失误根因）
2. **查表优先于推算**：红鸾天喜、劫煞等查表项必须先查再综合
3. **八字先行**：应期以本表为纲出候选年，紫微仅作验证层（合参时）
4. 验证过的技法标 ✅，待验证标 ⏳，实战反馈后更新
5. **🚫 禁止社会时钟模板（⚠️ 新增 2026-08-02）**：分析流年时不得以年龄预设人生阶段——21岁可以生子（C0014: 1989/1991连生二子，八字侧因默认"20出头看事业/婚姻"而漏查表二）、60岁可以婚变、30岁可以置业。用户问"某年发生什么"时，**必须全查表一~五**，不可根据年龄跳过任何一张表。叙事从技法信号中来，不从社会常识中来。
