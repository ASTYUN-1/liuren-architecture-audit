# 奖学金等级争议：主次、制救与无据降档核查

本轮依据用户贴出的模型分析片段和用户报告的实际一等奖结果，选段核查北海闲人《理法简易》《特训班讲义》《毕法赋全解》、古籍《壬归》《六壬大全》《六壬粹言》及《献给六壬天一群的六壬笔记》。未取得完整课盘与原始事前会话，不重排、不声称重断正确，不修改活动规则。用户提及的“任规”本轮按项目重点参考的《壬归》理解。各书使用本地文本，未与原扫描逐字校勘；文字疑误保持原样。

## 主要发现

应以本问的关键类神/结构、真假气态与有效制救裁决，不以支持和反对标签的数量平均。北海讲义LF14–16、43–51明确先依占类及课传特征定侧重，再辨真假变质；并没有给发用或课体统一百分比权重。发用重要，但中末与年命的作用不能被它自动排除，《壬归》LF419对此有明确分工。

“极旺之财有损，仍可获一等”在逻辑上并不矛盾，但它只是待本盘判定的一种情况。奖项等级、公布资格、实发金额、获款后花费、实际净所得是不同结果；必须依据原问与盘面定位区分，不能为已知一等结果临时补出“花销”。不能把破碎无条件降为过程小煞：《理法简易》LF518说大象吉多不妨凶煞，随即明确财旺逢破碎亦主破财；讲义LF363更有“拆分用光”强语。此类原文确给出直接财损方法，尚需核坐标、适用范围与本问对象，却没有“自动降一等”的量化规则。

弹射“纵成虚名虚得，不得实用”确有出处，《六壬大全》LF3750。但紧接LF3751仍分神将德合等条件。《六壬粹言》LF66在同段保存“虚名虚利”强语，同时说“仍以神将断其吉凶”，举弹射财爻发用而得末传助、课中另有支持，断“占求财最吉”，保留奔波多心。北海《理法简易》LF1489解释弹射为我干涉别人、从内到外；讲义LF195–196把“外求”与源消根断等具体结构合起来断投资亏损。这些段落说明不能将一个课名做统一结果上限；也不能反向将原书“不得实用”轻改为任何一次“过程虚惊”。

《壬归》LF385–387对财神旺相发用与岁月建财作强度判断：乘吉旺相“为数必多”，“岁月建为日财，其财必大”。北海《理法简易》LF1565–1567强调发用的时令气、临地气、所乘天将与速度规模；该书LF1703区分财大小、得财迟速、双方态度。因此用户提出的“关键类神兼发用应重点考察”有文献依据，不能只因弹射名目就推翻。但“大财”“名次好”仍不是一等奖专属判据，不能不核全局就换算为10000元。

北海《毕法赋全解》LF455–469分考试种类、主考、分数、学校与证书，特别强调幕贵只是一个类象，也可能被更有力的作用改变。把朱雀、幕贵、官鬼、财各自列成独立吉票，忽略它们可能共居一个酉节点、同一旺气，是重复计证。其不同职责应保留，独立支持强度不能按名称数累加。《理法简易》LF705–708与《毕法赋全解》的考前考后/题型表述也有具体范围，不可压成一切排名都固定用某一神。

天一群笔记保存多作者断语，不能都称作北海规则或水的规则。LF1259–1261水以丑未相加不空为过关结构，并明确不拘朱雀状态，原载反馈过关；LF1133–1137飞星以幕贵、递生等断保研成功，反馈第五名入选五个，说明“成功强支持”本身不能证明最高排名。LF1417–1421水断“二等好成绩”，但原载反馈未过；补议与原断、现实反馈应分开。LF1067–1071有折半取数且原载436分反馈，其算法条件不清，不能扩成遇反证就折半、遇6就6000的通法。上述均为原载材料参照，不增加独立预测验证。

## 对用户片段应先检查的推导

1. “戌墓”必须明确谁入墓、谁临墓、采用何套十二气；戌土本身不能通称财库。若确为火日以酉金为财，金墓在丑，戌并非金墓；同时酉之阴戌可能有生金、相害等不同关系，应核主次，不能一概只算折损。
2. “官鬼受戌克”须明确官鬼在本问是名次类、压力阻碍还是其他角色，并核土水实际力量、通路及制救。存在克不等于足以降名次。
3. “财旺身弱不能尽取”要有完整类神和理气依据，不能套一句跨体系的泛语；代占尤其要分日干、儿子类神、儿子年命和各自六亲参照。
4. “辛禄酉”“酉为财”“午为刃”等可能分别取不同人/参照，不可未经说明混在同一身财比较；缺完整盘暂不直接判其错。
5. 朱雀、螣蛇、贵人不能只贴吉—凶—吉标签，便当作获评过程。需核各自所乘支、气态、参照和实际作用。
6. 旬丁、破碎、害、冲、贵逆等不能全翻译成同一种“降等”。各有何作用、是否重复、能否改变评选边界须分别判明。旬丁不自动是财损。
7. “通常一等少、二等多”若有实际名单、比例及选人背景，可作为公开说明的现实先验；没有本校数据不可编造，更不能在声称纯盘判断时暗中替换主要依据。
8. “虚名虚得”与实得6000元并非天然相合，二等也是真实得财。若用此句区分一等奖和二等奖，须提出额外的、可在结果未知时运用的具体条件；否则属于无据等级映射。
