# 单宫旺衰与取用后补算接入

本机活动版：`20261109-palace-strength-34`。默认排盘、核心交接、主智能体提示和独立裁决者提示已经统一使用本版说明；OpenCode和Codex共用同一个计算实现。

默认导出的`strength_index`为单宫旺衰，包含月令、自身十二气、旬空/坐空和直接位置上的生扶泄耗克制。全十二宫、课传、直接阴神、天将、六亲、旬干、年命和采用神煞等原有信息继续保留；日干仍只默认列本日。没有增加独立神煞文件或冗长计算过程。

| 分值 | 当前解释 |
| --- | --- |
| 0 | 本计算无有效力量，缺失不是0 |
| 0～1，不含两端 | 极弱，通常难独立显著作用 |
| 1～2.5，含1 | 弱，仍有作用 |
| 2.5～5，含2.5 | 偏弱至中等，可发挥作用 |
| 5～7.5，含5 | 较强 |
| 7.5～10，含两端 | 强 |

**弱不等于无用，5与2.5均非淘汰线。** 不输出“低于阈值便绝对不可用”的开关；结构、触发、具体目标、应期和原法条件仍需模型判断。

## 取用后怎样补算

AI先确定所问类神与有关施受者，说明双方身份及作用通路；需要给出数值增减时，再调用`liuren_compute(action="strength")`。工具从绑定原盘计算，不接受AI手填分数或倍率。

一次提交完整的当前取用关系清单。工具保留单宫原始平衡，只联算明确提交的新关系；不把调整后的分数自动传播给未取用宫位，不沿前次补算叠加，不因同属课传就自动互克。直接关系已计则跳过，空亡与墓的通达因素各计一次。

新增关系沿用原研究生克系数，通路系数固定0.75；同源通路总额超过2按比例归一。施生方计泄耗，施克方计施力耗费，受克方强则抵抗较大；施者直接贪生合对外传递受限。完整公式、接口参数和可复制示例见[计算规则与工具调用](计算规则与工具调用.md)。

例：仅在演示中假设本课取酉金为施助者、子水为目标，并已确认生扶通路。按固定季土表计算：

| 对象 | 单宫分 | 补算分 | 差额 |
| --- | ---: | ---: | ---: |
| 子水 | 1.007031 | 1.445138 | +0.438107 |
| 酉金 | 5.688580 | 5.469526 | −0.219054 |

这是接口作用方向的演示，不主张本案实际应该如此取用。子本有“申阴神生子”的直接关系，若再提交这条，工具跳过而不重复加分。

应聘盘中，申的单宫分为5.271，原`旬空`身份仍保留；分档为“较强”。这既不把旬空抹掉，也不允许模型在此分数上又因旬空私自打折或直接判失败。最终录用、机构类型和职位仍须独立裁决，未在本轮重做盲测。
