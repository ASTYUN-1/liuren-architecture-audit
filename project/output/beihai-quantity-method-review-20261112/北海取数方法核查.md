# 北海闲人取数、修正与量级：定向原文核查

本轮只研究，不修改活动方法、工具、旺衰系数或冻结包。针对的问题是：旺衰已经改变算法后，是否还应另扣旬空；旺气如何倍进；无明确上限时如何定十、百、千。没有回查用户考试复测日志。

本轮结论：北海明确把旺衰用于选加、乘、倍、进，也按综合气势判断数目大小；书中有报出具体金额的例子。不过，所读材料没有把旺衰量化为统一阈值，也没有完整规定季节算法与旬空折半的所有叠加条件。其他书有明确承认十百尾数无定计的论述。不能把经验裁量省略，声称已经找到一套完全确定的算法。

## 1. 旺衰选算法，已经使用旺衰

《理法简易》3319—3335（证据B02）先引《壬归》，再解释：

> 旺相则相乘，并进位；相则相乘而不进位；休气取二者相加；囚气和死气取二者相加的一半。

其中“旺相”与后一“相”有文字重叠；引用原文是“财旺则相因而倍进，财相则计其所因以为数”。可以识别为旺、相有别，但不擅改书中文字，更不能由此认定任何现代指数区间。

以类神9、地盘8为例，按北海这段解释，相为72，休为17，囚死为8.5。17与8.5都已经反映旺衰选法，不是未修正的统一乘积72。这里的“成数”又被解释为相乘或相加所得、仍须进一步加工的数；这句话说明未必到此终止，**没有明示可以任意再扣，也没有明示以后只能扣某一项**。

《壬归》原段见C01，北海解释须与所引原文保留区别。

## 2. 空亡折半：有书例，缺统一的重复修正规则

《理法简易》6671与《特训班讲义》509收录同一邵彦和旧例：申7、辰5，相乘35，空亡减半，书中写17年。35/2实际为17.5，文本没有交代舍入。两本转载是同一事件，不重复计证。这是年数旧例，仅核其数法，不恢复出生运限用途。

此例证明有“乘积之后按空减半”的用法；它没有证明“先因休囚改相加之后，所有空亡还必须再半”。同段其他折半也没有逐一说明原因，不能仅凭出现一半就全归空亡。

本轮没有在已核读北海段落中找到以下任何一条完整通则：

- 因旺衰选过加法，就一概禁止再考虑空亡。
- 任何数法得数后，见旬空一概再减半。
- 因囚死减过半，而又旬空，必再半或必不再半。

因此，“已使用旺衰”和“已使用空亡”应分别登记。如果选法只依据月令休囚，空亡尚未必被使用；如果依据已经包含空亡的综合旺衰指数来选弱气算法或折减，空亡已通过该路径产生影响，再无说明地减半便有重复风险。这是本轮对流程的推论，不冒充北海原句。

其他书C05有“第二三四俱空，须是减了再减”，但该射覆文本有异文，具体节点和操作次序不够清楚。它提示古法存在多次减数的分支，不能据此认定北海采用统一重复扣减，也不能宣布古法一概禁止叠减。

## 3. 倍进确实存在，不能只保留减半

《六十四课经精讲解注》4058、4076（B08）：

> 言倍者，加一倍也。言进者一十进一百也。
>
> 旺相则加或进，加就是加倍，进就是进位，以一当十等等。

因此，书中不只是56改成稍高一些的58；其理论确实包含翻倍和十进量级变换。但同段4082又说午9酉6，春占物数多，“乘之为五十四，或加之为十五”，没有给出两种选择的完整判别条件。不可把这些并列候选包装成唯一算法。

《理法简易》农桑段“类收必倍”有类神、发用及太岁行年生扶等条件（B05），不是任何单宫旺气一律翻倍。其对象也是相对收成，不能直接等同货币金额。

## 4. 北海报金额时，实际怎么做

### 八千元：有取数线索，千位选择未写全

《六壬金针_修正版》713—723（B09），巳将酉时癸巳日占出行：

> 巳为日财……巳四数，巳为双，可得八千元。因巳为月将，旺相，故数目较大。

这说明北海实际把类神数、单双类象与旺相大小结合起来报金额。不能说他不定量级，也不能说他不用向上增加。

但“为什么8落在千元，不能是800或80000”，本段没有完整说明。结尾说实际是去办术数培训班，未在该段明确反馈实收8000。应保留其方法参考价值，避免写成独立验证的完整金额命中。

### 四千元：有预估，算式与金额反馈均未展开

同书2224—2234（B10），学生问教育岗位，北海判断需要通过关系、花大量钱财，约四千元。后文反馈通过娘舅关系参加工作，没有确认实际花费4000，也没有说明4怎样定成4000。

另有电脑“后以八千元卖出”的段落，那是售出反馈，不是事前报8000，不能混作具体金额预测证据。

### 不知借到多少：他也会只断“不少”

《毕法赋全解》4562（B13）：

> 课传没有财，不看财，虎鬼气势大……因此主来得多。

该段原断是借到不少，没有报具体金额，也未交代反馈。由此可见，北海会依实际发用气势判断所问数目，并非每一例都必须由财爻乘法产出一个精确数。不能把此特例反过来改成“借钱都不用财”。

以上依据均为本地整理文本，金针文件自带“修正版”身份。本轮未对照印本、扫描页及原始事前记录。

## 5. “气势大”与“自己得到的钱多”不能合并为同一指标

《理法简易》3131—3137（B01）论发用气势，联合看五气、地盘、天将、神煞以及日干十二运。旺相、白虎、劫煞等说明大而速；休囚、天后等说明小而缓。它不是一个已标定的0—10数轴。

更关键的是，北海把事物规模与人的实际所得分开：

- 《金针》2583—2587（B11）以日干为人、财爻为类象，特别讲身财平衡；财旺可表示竞买者众，财衰可表示竞买者少。财旺身旺与财旺身衰的个人结果不同。
- 《毕法赋全解》1275（B12）讲股票证券彩票，强调收益而“生气为用”，财旺可表示众人竞买、动了很多钱，但钱与自己无关。这与《金针》财爻取类的侧重点不同；不能未经论证声称两书已经给出完全一致的唯一彩票取用法。
- 《理法简易》4669（B06）讲整体市场大象不等于个人能获利，须看日干和行年。
- 同书3689（B04）用穷人不能借出百万美金说明，对方是否有能力施与必须考虑。这是现实能力限制，不是金额换算公式。

由此可支持的判断是：先认清某个“旺”代表个人所得、财源规模、货物多，还是竞买者多，然后才谈具体金额。不能把全局气势大、财爻旺、自己能承受财力这三种情况合成一个倍率。

## 6. 其他作者怎样面对十、百、千

《大六壬说约卷中》864（C02，本地排盘引擎内置文本）：

> 至数之多寡是十是百，数之尾零几分几厘，皆无定计，亦随机酌断可也。

同段先讲相气本数、旺气加倍、休囚死减半，又列上下、遁干天将相乘或相并的不同方法。后例确有休气折半与旺极倍数，但十进位仍有省略。因此“酌断”是书中实际保留的步骤，不应假装它已经是确定的数值接口。

《银河櫂》路程段1009—1013（C03）更具说明性：先分近处或远方，再决定进十、进百；上神旺相又倍进。示例子9亥4合13，进130里，冬旺倍260里，远地再作2600里。这里同时使用**事件远近的背景**与**旺相倍数**，二者职责可区分；不等于已经解决无背景彩票奖金的千百选择。

《一字诀玉连环》45—58（C07）记总财320贯、六月先得56贯，分别取不同节点。8×4写320而8×7写56，前者为何进十并未明示。不能用“相乘得320”的省略句证明量级问题已经不存在。

《东方朔射覆》519（C06）另有45倍进900、相进450、休和14、死空半7。其旺相休囚分支不同于《壬归》财数解释，是射覆材料，应整体保留身份，不从各书抽选有利片段拼成一条所谓通法。

## 7. 对现行体系的含义：建议，尚未实施

1. 先明确数量对象及口径：总额还是到手额、奖金还是净收益、分数还是通过与否，所取类神是否真正承载该数量。
2. 选定一套有来源的方法，说明其输入与适用范围；已经因旺衰改用相加，就登记为已经用过旺衰。
3. 季节旺衰、综合强弱、旬空、气势大象分别说明用于何处；每次减数要能说明是否已经含在前一步，避免模型无解释地叠扣。
4. 数目大小、十进量级、尾数微调分别交代理由。量级可参考事件已知背景和实际容纳范围；不得把同一旺气重复用于选乘法、加倍、进十和最后再加成，而不说明依据。
5. 彩票如已知彩种、票数、奖级及奖金表，可以先用现实规则约束可能金额；这是本轮的实务建议，不是北海原文。未知时可给有依据的估计，但须明确量级仍属经验裁量，不能以单宫指数伪装成确定换算。
6. 先前讨论的4—6本数、2.5以下半数等区间，没有在本轮书证中找到原文对应。可以后续设计成可检验的研究参数，暂不能冠以北海规则。旺相休囚死与现代连续旺衰指数也未完成标定。

当前50版的数量回执有记录与查重作用；其旬空数量折半默认属于现行项目采用口径。本轮没有发布修改。上述书证不足以把默认升级成“北海的一切数法都要求如此”，也不足以直接规定“用过旺衰便永远不再考虑旬空”。下一步若改，应先收窄适用范围和登记已含因素。
