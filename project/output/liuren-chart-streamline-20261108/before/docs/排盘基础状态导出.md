# 排盘自动附带基础状态

2026-11-08。本机默认排盘入口现附带`basic_states`（`liuren-basic-states-v1`）。它是坐标和具名采用表的查表结果，不是研究能量算法，没有综合分、加权、衰减比例、吉凶或成功率。现行专业资料仍为33版；裁决分工不变，网站和手机应用未发布。

## 一次排盘直接取得

- OpenCode：`liuren_chart`返回完整盘、修正神煞及完整12宫基础状态。
- CLI/Codex：`tools/liuren-resolved-chart.mjs`返回同一基础状态；Codex材料包由同一`buildFacts`生成，子智能体核心必读部分包含天将状态和补齐的关系。
- 已存盘：`node tools/liuren-basic-states.mjs --chart "原盘完整JSON路径"`。只派生基础状态，不重排、不改原档。
- 指定类神：原`liuren_compute(action="chart",symbols=["丑"])`及Codex对应compute入口现在同步返回该支和乘将的基础状态。日干始终保留。

新起课默认另存`*.basic-states-<hash>.json`，返回`basic_state_archive`。原档、修正盘和研究算法原文件均不就地改写。新增状态按源盘hash绑定；同一源盘同一状态内容重复保存不会覆盖已有不同内容。

## 计算范围

### 支神：branches

完整12天盘支分别列出：

- 五行、实际所临地盘、直接阴神、所乘天将。
- 月令五气的具名表值；两表一致时附`adopted`和`de_ling`。
- 自身对地盘、对直接阴神的五行十二气。
- 自身旬空、坐处空、阴神空，分别定位。
- 四课及三传槽位，保留重复，不把未入传改成不存在。

直接阴神=该天盘支同名地盘上面的天盘支。例如天盘午坐戌时，午的阴神不是地盘戌，而是地盘午上的天盘支。

### 天将：generals

完整12将分别列出：

- 天将五行、所乘天盘支、该宫地盘。
- 天将自身月令五气，不继承所乘支的五气。
- 天将对乘支、天将对地盘的五行十二气。
- 乘支旬空、地盘空位分别登记。天将没有一个由六十甲子直接派生的独立旬空支身份，所以`self_xun_void=null`；这不等于天将不会受空亡影响。

### 日干：day

日干寄宫、上神、直接阴神；日干对寄宫、上神、阴神、日支的天干十二长生；月令五气；寄宫、上神及阴神是否处于空支。阴干采用逆行，不以支神五行表替代。例如丁见未为冠带，不能输出五行火的衰来覆盖丁干。

### 局部关系：local

地→支、支→地、将→支、支→将、地→将、将→地、阴神→支、支→阴神，逐方向输出五行关系，以及相应地支六合、冲、刑、破、害等原始关系。内战、外战、夹克、夹生只标记完整构成，不据名称决定吉凶或效力。

这一层不做全局两两生克求解；AI仍按原问与专业资料确定哪些关系实际起作用。

### 同处关系并见：coexistence

自动提示长生兼泄、长生兼受克、临绝并见受生、临墓并见受生等。提示只是把同一位置两种条件并列出来，不宣布已经救成、开墓或恢复到某个力量等级，不重复制造吉凶证据。

## 季土取法必须说明

`four-seasons`指春木夏火秋金冬水，含各季末月；`quarter-earth`指辰未戌丑全月土旺。这两者不等同于“季末十八日土旺”的精确时间算法。

本次只新增导出，不在工具里静默修改现行U07/C05的取法口径。两表不同的季月，`adopted=null`、`de_ling=null`，状态`seasonal_convention_required`。两表一致的月份，可以直接给共同状态；只有旺标`de_ling=true`，相为受当令之生，不写成执令。

因此，本课戌月末应采用季土旺的讨论不会被工具反向覆盖；它会明确列土旺表与秋金旺表的来源身份。将来统一时间规则时，应另立具名政策、绑定历法依据并覆盖边界日期，不能把人工参考日期冒充四柱模式的真实占时。

## AI读取方式

先按本问定位对象，再读取同一行的坐处、阴神、天将、月令表和空亡。基础状态可直接使用，不让主、子智能体再凭心算覆盖固定坐标。比较状态时必须保持主语和参照相同。局部构成与同处并见不是综合旺衰结论，生克主次、制救、贪生停用、吉凶及结果继续按同版专业规则裁决。

这层不调用v0.2/v0.3研究能量模块，不增加一轮裁决，也不要求模型接受未经校准的数字。核心报告仍由独立裁决者完成，主智能体核事实、引用、覆盖和一致性。
