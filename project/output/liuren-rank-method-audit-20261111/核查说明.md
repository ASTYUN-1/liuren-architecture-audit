# 名次取数与优质课追问核查

2026-11-11。仅核查现行方法、原书文字及本次可见答复/工具调用；不重判优质课名次，不更改活动规则、程序或冻结运行包。

## 结论

“不能把任意数量算式直接当成名次”成立；“名次没有实物对象，所以不适合取数”“没有名次表就不能取名次”属于过度概括。现有目录仅收五项具名计算方法，不能代表原书数法全集。

名次是序数，表示某人在特定比较群体中的位置；它仍是明确的数值目标。取数对象可以是名次、等第或名次变化，不要求有一个有形实物。满分和评分制是分数问题的相关口径，并非名次问题一律必需的前提。总榜、入选者榜、分组榜，以及是否并列，才是名次口径须分清的事项。

本次调查找到直接名次取数条文、原载数值案例、相对先后方法及名次变化案例。它们足以否定普遍禁用说，但不足以建立一个所有现代评比均可套用的精确名次公式。

## 原书的几条不同路径

1. **《大六壬说约》卷末“考试”**（本地转录本第617—633行）。第625行明言：“名次即按朱雀推之。雀乘神旺相者，依水一、火二之数断之；否则依巳亥四、辰戌五、卯酉六、寅申七、丑未八、子午九，以上下相乘之数断。上下相乘数多，名次必不高。”这是直接按类神状态分支取名次的书证。其上下文先分文章、试官、获隽，再论名次，没有要求先知道满分。
   - 边界：来源文件注明“未校勘”；“上下”的具体取位、空亡如何改数等未在该句充分展开。只能登记为有原文明示的专法，不能补齐未写条件。古代县府院试向现代优质课评比的迁移也须说明。
2. **《六壬粹言》“考试章第二”**（第2015—2027行）。原载“干上未八数，发用巳四数，巳有双义，重之亦为八也。后果入泮第八名。”这是将支数用于具体名次的原载案例。
   - 边界：说明有这种用法，不证明任意盘均可这样取；“巳有双义”如何适用于其他盘、具体取数断语与反馈的先后，不能由一句话补全。原载结果不等于本轮独立验证。
3. **《壬窍》考试占**（第1438—1454行）。分别讲官星在初中末的名次高低、十干次第，并要求以旺神定之；含“似亦宜看。自记”等作者保留语。
   - 边界：多为前列、中间、后列或甲乙先后，不能硬改为甲恒等于第1名、丁恒等于第4名。初中末也不能无据均分成三个等长排名区间。
4. **《指南注解》与北海《毕法赋全解》第3法**（分别第2613—2627行、第568—578行）。原例以“午命甲寅、亥命丁未”分两人前后。北海解释遁干次第，同时质疑空亡之寅另取甲遁的做法。
   - 边界：原断只说二人先后，没有断全榜第一与第四；不将受质疑的起遁作为固定通法。
5. **《献给六壬天一群的六壬笔记》月考例**（第1095—1115行）。原载取初末16与72作差，断退步56名，载反馈退57名。
   - 边界：目标是“变化多少名”，不是最终排名；16、72的神将取表与所有增减条件未在该段充分展开，不能照反馈补成通法。这是近似相合的原载例，亦非独立验证。

《六壬经纬》考选占第929—951行另将朱雀与文字、次第、等第、榜案相联系，支持先找实际排名载体，再取数；不能据此令所有占类一律改取朱雀。

## 程序拒绝的真实原因

tools/liuren-flow-control.mjs第67—70行对quantity使用关键词正则：

```js
/多少|几[元块个次米]|金额|价格|费用|花费|取数|数量/
```

“那么分析一下他可能是第几名”不命中，而“排名多少”会命中。它漏识别了“第几名”，不是检查过名次算法后判定不可用。

实际错误仅为`explicit timing/quantity question; a supplied divination timestamp is not a timing request`。最后答复添加的“没有给出满分、评分制、分差或数量单位”，不是工具返回的拒绝理由。

## 建议的接入方式（尚未实施）

沿用现有取用、综合作用、制救、数量模块及裁决主线，补明序数目标，修复问句识别，不另开工作流。

1. 先分最终名次、相对先后、等级、变化名次；明确是在全体、分组还是入选者内部排名。人数和并列规则用于定义与排界，未知时说明影响，不一概拒答。
2. 取本问的排名载体；考试可查朱雀/榜文、官星、本人年命等的具体职责，不因问数统一取财，也不把资格、奖励、实际表现与榜上序位混成同一量。
3. 优先查有原文明示的对应专法。拟迁移通用数量法时，说明为何其输出能表示序位，先固定取位、数表、算法和状态分支，不看到答案或反馈后再选公式。
4. 旺衰可帮助定法、定相对高低或检验相关作用，不能直接将强度分换成名次或百分位。名次小为优，“衰则半数”可能反使排名变好，必须确认修正对象及本法依据；不能将分数折减、名次推后和名次数字折半混同。
5. 数字必须有形成路径；人数上限只能排除越界，不能将超界数随意折半、取余或移位。相对高低、离散候选、区间与点值各按其实际依据交付，区间同样须有定位理由。
6. 若后来找到的数法与前问倾向冲突，回查对象、条件和作用，不以旧判作强制约束，也不以孤立数值推翻综合判断。
