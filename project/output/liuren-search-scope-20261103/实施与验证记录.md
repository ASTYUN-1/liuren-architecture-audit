# 本机六壬资料检索范围限制

2026-11-03。用户要求普通研判不再扫描 docs 开发文档及其他无关区域。

## 生效方式

项目新增 `liuren` primary 模式，并将其设为未指定模式时的默认值。未指定模型、思考档位或执行时限。原有 Build 模式及权限未覆盖，仍用于开发、排盘排障和知识维护。

`liuren` 权限默认拒绝，只开放排盘 `liuren_chart`、限定资料工具 `liuren_materials`、按路径白名单的原生 read、daliuren 技能及必要的提问/任务笔记工具。任意 Shell、通用 grep/glob/list、开发和委派工具不可用，减少临时扩大范围的机会。此配置约束正常工具使用，不宣称操作系统安全隔离。

允许范围为当前活动方法、案例、经验、书籍、专业规则与审查、已内置的 QQ 原始来源。docs 不作为可扫描资料库，只按具体文件允许本机说明和方法明确引用的专业证据稿。完整清单与操作方式见 `docs/本机六壬资料检索范围.md`。

原文 read 还允许当前课盘归档、实时技能以及工具自己产生的临时候选记录；这些不会因此进入全文扫描。网站、APK、开发部署文档、旧运行版本、包内 archive、output 历史材料、依赖及缓存不进入普通研判检索。

## 实现

- `tools/liuren_material_scope.py`：固定资料库选择、当前方法登记清单、精确 docs 例外、真实路径核对、遍历时剪除备份/缓存，保留来源行号与读取续页信息。命中上限与不可解码文件均显式说明，不能将部分命中当全库无反例。
- `tools/liuren-materials.py`：固定 actions，不接受任意 Shell、脚本名、输出路径或扫描目录。methods 复用当前全文读取器；retrieve 复用原案例/经验检索及其校验、排序、条件和审查说明，完整结果写入工具专属临时目录。
- `.opencode/tools/liuren_materials.ts`：原生工具桥，参数由 schema 约束，验证可执行 Python 后无 shell 启动固定程序，保留取消和错误信息。
- `opencode.json`：研判模式权限和默认入口；高效执行及完整流程说明同步指向该范围。专业技能正文、冻结运行包和原始资料均未修改。

## 验证

- 范围测试5项通过，1项实际符号链接测试因本机创建权限限制跳过。通过项覆盖 docs 精确例外、开发/旧包/包内备份排除、路径上跳拒绝、原文行号续读、命中限额披露。真实路径检查实现存在，但不把跳过的用例说成验证通过。
- `opencode debug config` 与 `opencode debug agent liuren` 确认实际默认值和工具状态：bash/glob/grep/task 为 false，read/skill/liuren_chart/liuren_materials 为 true。实际合并规则按最后匹配原则的13项矩阵核对通过，包括绝对/相对开发文档拒绝、专业原文与PDF目录允许、旧备份拒绝。`wenheng-public-output` 保持 deny。
- 实际 OpenCode.exe / Electron 42.3.3 / Node 24.15.0 无界面宿主中，原生工具成功读取专业原文、返回完整方法批次、并行检索案例和经验、在当前方法内定位；试读 `docs/跨会话继续开发指南.md` 被明确拒绝。未由GUI内模型发起，未调用模型或操作既有会话。
- 当前案例索引1054个唯一来源、经验索引120个唯一来源全部位于允许范围，未发现因限制而丢失的已登记来源。此项只核路径覆盖，不证明全部原文均已读或预测有效。
- 最终健康检查和活动包完整性结果见 `verification.json`。

证据为 `opencode-effective-scope.json`、`permission-matrix.json`、`native-smoke.json`、`desktop-process.json`、`source-coverage.json`。

## 使用和回滚

重新打开 OpenCode 后，普通研判选择 `liuren`；新请求未明确指定模式时以它为默认。已有对话可能保留 Build 选择，需要在模式/Agent 栏手动切换。仅重新加载技能不会改变已有对话的 Agent 选择。

开发排障切回 Build；两种模式共享原盘和资料，切换不会删除会话。无关开发目录只是从研判入口排除，源文件没有移动或删除。

修改前备份在 `before/`，SHA256在 `before-manifest.json`。回滚先保存后续改动，逐项恢复 opencode.json 与两份流程说明；新增工具和范围说明可保留作追溯，不需覆盖整个仓库。未改服务器、网站、APK、全局配置或跨会话记忆。
