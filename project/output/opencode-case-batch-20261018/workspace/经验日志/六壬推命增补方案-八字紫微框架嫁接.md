## 〇、核心设计原则

### 不可触碰的边界（起课层）

大六壬起课的五个核心步骤是**不可更改**的底层：

```
月将加时 → 天地盘 → 四课 → 九宗门择传 → 三传 → 天将布列
```

这五步构成了大六壬区别于其他术数的**根本逻辑**——通过"月将加时"这一中间建模层生成"时空快照"，再从日干支锚定人物坐标，从生克中提取事变起点。任何改动这五步的操作都会破坏六壬的基本运作原理。

### 可增补的边界（解课层）

以下层面可以在**不改变起课结果**的前提下进行增补：

| 层面 | 可增补内容 | 不可改动内容 |
|------|----------|------------|
| **推理框架** | 新增分析步骤、加权规则、判断维度 | 课体名称、三传排列、天将分布 |
| **解释模型** | 引入八字/紫微的概念映射、建立新的判断矩阵 | 天地盘结构、四课关系 |
| **精度提升** | 天将状态评级、多层验证逻辑、动态引动标志 | 月将换将规则、九宗门取用逻辑 |
| **输出格式** | 新增报告模块、增强断语精度 | 课式基础数据 |

### 核心公式

```
增补后推命 = 原起课结果（不可变）
            + 月将调候加权（来自八字穷通宝鉴）
            + 天将亮度评级（来自紫微星曜庙旺）
            + 六壬四化映射（来自紫微禄权科忌）
            + 病药分析系统（来自八字神峰通考）
            + 三层叠宫验证（来自紫微大限流年）
```

## 一、起课逻辑深度解析

> 本节为增补方案提供理论基础。详细拆解见调研报告 exp-2。

### 1.1 大六壬的核心运作原理

大六壬的本质是一个**三才时空模拟系统**：

```
第一步：太阳（月将）+ 时辰 → 天地盘（"那一刻的宇宙快照"）
第二步：日干支 → 四课（在快照中定位"我"与"环境"的坐标）
第三步：四课生克 → 三传（找出矛盾点并展开为三步发展轨迹）
第四步：天将布列 → 吉凶定论（赋予神格化的主宰权）
第五步：神煞叠加 → 细节精确化
```

**一句话总结**：大六壬通过"太阳位置加时辰形成天地时空场→用日干支锚定人物坐标→从五行生克中提取矛盾点→沿天地盘轨道推进三步形成发展轨迹"来模拟天地人三才在特定时空切面下的互动。

### 1.2 与八字、紫微的根本差异

| 维度 | 大六壬 | 八字 | 紫微斗数 |
|------|--------|------|----------|
| **建模方式** | 中间建模层（天地盘）→ 再锚定 | 直接取干支（四柱） | 命宫纳局 → 安星布盘 |
| **空间维度** | 天地盘 + 十二宫（双空间层） | 无独立空间层 | 十二宫垣（单空间层） |
| **动态机制** | 三传（三步轨迹，一次性） | 大运流年（连续式） | 四化（终身标志）+ 大限流年 |
| **神格系统** | 十二天将（动态分布） | 十神（固定映射） | 十四主星（固定分布） |
| **核心优势** | 时空快照的多维映射能力 | 定量化的五行生克分析 | 精细的星曜宫位配置 |
| **核心短板** | 缺乏终身动态引动标志 | 缺乏空间维度 | 缺乏时空动态建模 |

### 1.3 三者的互补结构

```
八字（五行气数层）→ 本质、根基、喜忌方向
   +
紫微（星曜格局层）→ 结构、框架、静态配置
   +
六壬（时空动变层）→ 动态、当前切面、天地互动
   =
完整的三才合参体系
```

本增补方案的核心思路：**让六壬推命借鉴八字和紫微的"精度工具"，但保持六壬自身的"动态时空建模"优势**。

### 模块A：月将调候层 🔴 P0 【❌无据-2026-08-04审查：八字调候嫁接，禁用于实战】

> **来源**: 八字《穷通宝鉴》调候体系  
> **插入位置**: liuren-tuiming 第0步（定基）之后，成为"第0.5步·辨寒暖"  
> **原理**: 月将（太阳过宫）天然具有寒暖属性，替代八字月令的调候判断

#### A.1 理论基础

八字的调候逻辑是：生于巳午未月（夏）= 需要水润燥；生于亥子丑月（冬）= 需要火暖局。这个逻辑的底层是**太阳位置决定地球寒暖**——而这恰恰是大六壬"月将"所表达的内容。

月将本身就是太阳躔次：
- 大寒后 = 子将（神后）= 水旺极寒
- 雨水后 = 亥将（登明）= 水寒
- 春分后 = 戌将（河魁）= 土温
- 谷雨后 = 酉将（从魁）= 金凉
- 小满后 = 申将（传送）= 金温
- 夏至后 = 未将（小吉）= 土燥热
- 大暑后 = 午将（胜光）= 火极热
- 处暑后 = 巳将（太乙）= 火热
- 秋分后 = 辰将（天罡）= 土凉
- 霜降后 = 卯将（太冲）= 木温
- 小雪后 = 寅将（功曹）= 木寒
- 冬至后 = 丑将（大吉）= 土寒

因此：**六壬的月将天然可以做调候判断**，而且比八字的月令更精确（月将精确到中气而非整月）。

#### A.2 月将调候表

| 出生月将 | 节气区间 | 寒暖属性 | 调候需求 | 优先关注五行 |
|:--------:|---------|:------:|---------|:----------:|
| 子（神后） | 大寒→雨水前 | 🔵极寒 | 需火暖局 | 火（巳午） |
| 亥（登明） | 雨水→春分前 | 🔵寒 | 需火暖局 | 火（巳午） |
| 戌（河魁） | 春分→谷雨前 | ⚪温 | 调候弱 | 水木有情 |
| 酉（从魁） | 谷雨→小满前 | ⚪凉 | 调候弱 | 见火为佳 |
| 申（传送） | 小满→夏至前 | ⚪温 | 调候弱 | 水火调停 |
| 未（小吉） | 夏至→大暑前 | 🔴燥热 | 需水润燥 | 水（亥子） |
| 午（胜光） | 大暑→处暑前 | 🔴极热 | 需水润燥 | 水（亥子） |
| 巳（太乙） | 处暑→秋分前 | 🔴热 | 需水润燥 | 水（亥子） |
| 辰（天罡） | 秋分→霜降前 | ⚪凉 | 调候弱 | 见火为佳 |
| 卯（太冲） | 霜降→小雪前 | ⚪温 | 调候弱 | 水木有情 |
| 寅（功曹） | 小雪→冬至前 | 🔵寒 | 需火暖局 | 火（巳午） |
| 丑（大吉） | 冬至→大寒前 | 🔵极寒 | 需火暖局 | 火（巳午） |

#### A.3 调候有效判断

| 调候状态 | 课传表现 | 判断 |
|----------|---------|------|
| **调候有力** | 调候五行出现于课传 + 旺相 + 乘吉将 | 命局得天地之助 |
| **调候有象无力** | 调候五行出现但空亡/休囚/乘凶将 | 有调候之意无调候之力 |
| **调候缺失** | 课传无调候五行 | 需等大运走调候之地 |
| **调候被破** | 调候五行被冲克/墓绝 | 调候失败，反为寒热病 |

#### A.4 在推命框架中的应用

```
第0.5步 · 辨寒暖

1. 根据出生月将查A.2调候表，确定命盘寒暖属性
2. 检查调候五行在课传中的状态（出现？旺相？乘吉将？）
3. 将调候结论作为加权因子应用于后续分析：
   - 调候有力 → 课传吉象 +20%权重，凶象 -20%权重
   - 调候缺失 → 课传凶象 +20%权重（寒热失调加剧不吉）
   - 在十二宫分析中，优先标注调候五行所临宫位
4. 在综合论断中输出"调候判断"段落
```

### 模块B：天将亮度评级系统 🟠 P1 【❌无据-2026-08-04审查：紫微庙旺概念嫁接，禁用于实战】

> **来源**: 紫微斗数星曜亮度（庙旺平陷）体系  
> **增强位置**: liuren-tuiming 第2步（察身）和第6步（分宫）  
> **原理**: 天将所坐之地的十二长生状态 = 天将的"亮度"

#### B.1 理论基础

紫微斗数中，同一颗星曜在不同宫位的表现差异极大——太阴在亥为"月朗天门"（庙），在巳为"月暗星稀"（陷）。这种"同一星曜、不同位置、不同表现"的逻辑，与六壬天将完全同构。

六壬的十二天将本身有吉凶属性（青龙永吉、白虎永凶），但它们坐在不同地支上的表现力不同。将天将所坐之地的十二长生状态转化为亮度评级：

#### B.2 亮度映射表

| 十二长生 | 亮度等级 | 吉将在此 | 凶将在此 |
|:------:|:------:|---------|---------|
| **帝旺** | ⭐⭐⭐⭐⭐ 庙 | 吉力全开 | 凶性被压制（旺极则衰，凶虽凶但可制） |
| **长生** | ⭐⭐⭐⭐ 旺 | 吉力充盈，有生长之势 | 凶性受制，刚起势头 |
| **临官** | ⭐⭐⭐⭐ 得 | 吉力稳实 | 凶性可制 |
| **冠带** | ⭐⭐⭐ 利 | 吉力渐显 | 凶性初显 |
| **沐浴** | ⭐⭐ 平 | 吉力浮而不实 | 凶性暧昧不明 |
| **衰** | ⭐ 陷 | 吉力减退 | 凶性也减（衰则无力） |
| **病** | ⭐ 陷 | 吉力微弱 | 凶性阴柔（病则缠身） |
| **死** | ☆ 落陷 | 吉力丧失 | 凶性潜伏 |
| **墓** | ☆ 落陷 | 吉力被封存（如入库） | 凶性被封存（亦有"入墓不凶"之解，需分看） |
| **绝** | ☆ 落陷 | 吉力断绝 | 凶性爆裂（绝处逢生或绝处逢凶） |
| **胎** | ⭐⭐ 平 | 吉力孕育 | 凶性未成 |
| **养** | ⭐⭐ 平 | 吉力滋养 | 凶性待发 |

#### B.3 天将亮度速断规则

```
规则1：吉将乘庙旺之地（帝旺/长生/临官）→ 吉力全开，事必成
规则2：吉将乘落陷之地（死/墓/绝）→ 吉力大打折扣，好看不中用
规则3：凶将乘庙旺之地（帝旺/临官）→ 凶性受制（旺极有制）
       例外：白虎乘旺地而无制 → 凶性也旺（需看是否有救神）
规则4：凶将乘落陷之地 → 凶性潜伏或无力
       例外：螣蛇/玄武乘绝地 → 凶性反而可能爆发（绝处逢凶）
规则5：任何天将乘空亡之地 → 无论吉凶，其力皆虚（优先于亮度规则）
```

#### B.4 在推命框架中的应用

- **察身（第2步）**: 日干上神天将需标注亮度 → 判断命主得天之助的程度
- **十二宫分断（第6步）**: 每宫所临天将标注亮度 → 精确判断该宫吉凶程度
- **格局判断（第1步）**: 二十四格中的天将需看亮度 → 格局成破增加一层判断

### 模块C：六壬四化映射 🔴 P0 【❌无据-2026-08-04审查：紫微四化嫁接，禁用于实战】

> **来源**: 紫微斗数四化（禄权科忌）体系  
> **插入位置**: liuren-tuiming 新增步骤，位于格局判断（第1步）之后，成为"第1.6步·定四化"  
> **原理**: 在六壬课式中创建固定+动态的"四化标志"——类似于紫微生年四化的"出厂设置"

#### C.1 为什么需要四化映射

这是本次增补中**最有价值的创新**。六壬推命最大的短板是：课式分析虽然细致，但缺少"终身固定的动态引动标志"。紫微四化解决了这个问题——禄权科忌是盘中的四个"热点"，终身不变，大限流年不断引动它们。

六壬完全可以在不改变起课逻辑的前提下，创建自己的"四化映射"。

#### C.2 六壬四化的定义与取法

六壬四化**不是紫微的天干四化口诀**（如"甲廉破武阳"），而是基于**课式本身的结构化特征**提取四个终身标志：

| 四化 | 六壬取法 | 含义 | 优先级 |
|:---:|---------|------|:---:|
| **化禄** | 课传中**青龙所乘之地** × **日干长生/帝旺之地**的交集 | 一生资源流入的方向、福气所在 | 1 |
| **化权** | 课传中**贵人/白虎所乘之地** × **发用/中传的位置** | 一生权力/压力的焦点、执念所在 | 2 |
| **化科** | 课传中**朱雀所乘之地** × **日干冠带/临官之地** | 一生名声/化解的方向、贵人所在 | 3 |
| **化忌** | 课传中**螣蛇/玄武所乘之地** × **日干死/墓/绝之地** | 一生课题/阻碍/执着的方向 | 4 |

**取法详细规则**：

```
化禄标志 = 青龙所乘之地支
  若青龙不现于课传 → 取日干长生之地支上神为化禄标志
  若青龙现但空亡 → 化禄虚浮，有福难享

化权标志 = 贵人（昼贵/夜贵）所乘之地支
  若贵人不现 → 取白虎所乘之地支为化权标志
  若贵人+白虎均不现 → 取发用之地支为化权标志

化科标志 = 朱雀所乘之地支
  若朱雀不现 → 取日德（日干的德神）所在为化科标志
  若朱雀+德神均不现 → 取太常所乘之地支为化科标志

化忌标志 = 螣蛇所乘之地支
  若螣蛇不现 → 取玄武所乘之地支为化忌标志
  若螣蛇+玄武均不现 → 取日干墓/绝之地支上神为化忌标志
```

#### C.3 四化标志的状态判断

每个四化标志需要结合天将亮度（模块B）进行状态判断：

| 四化状态 | 条件 | 含义 |
|---------|------|------|
| **化禄得地** | 化禄标志乘庙旺之地 | 福气实打实，资源丰厚 |
| **化禄浮虚** | 化禄标志空亡或落陷 | 有福之名无福之实 |
| **化权得势** | 化权标志乘旺相之地 + 吉将 | 掌权得势，能主导 |
| **化权受压** | 化权标志乘墓绝 + 凶将 | 受制于人，有力难施 |
| **化科得名** | 化科标志乘旺地 + 朱雀/贵人同宫 | 名声显达，逢凶化吉 |
| **化科虚名** | 化科标志空亡或乘玄武 | 虚名在外，名实不符 |
| **化忌得化** | 化忌标志被吉将/合神/德神所制 | 虽有课题但能化解 |
| **化忌无制** | 化忌标志无救神 | 一生为此宫领域所困 |

#### C.4 四化的"动态引动"机制

这是四化映射的**核心价值**——建了一个"终身固定的热点地图"，大运小限每年检查是否走入了这些热点：

```
每年推运检查：
1. 小限是否走到化禄标志所在宫位？→ 该年利财运/福气
2. 小限是否走到化权标志所在宫位？→ 该年有权责/压力
3. 小限是否走到化科标志所在宫位？→ 该年利名声/考试
4. 小限是否走到化忌标志所在宫位？→ 该年有课题/阻碍（需特别关注）
5. 大运是否覆盖上述标志所在宫位？→ 十年主题
```

**三层引动判断**（配合模块E）：

```
原课四化有象（终身标志）
   +
大运走入该宫（十年放大）
   +
小限走入该宫（当年触发）
   =
该年该宫之事必定发生
```

#### C.5 在推命框架中的应用

新增步骤"第1.6步·定四化"：

```
1. 按C.2规则提取四个终身四化标志
2. 按C.3判断每个标志的状态（得地/浮虚/得势/受压等）
3. 标注四个标志所在的十二宫宫位
4. 在第7步（推运）中，每年检查四化标志是否被引动
5. 在综合论断中输出"四化主旋律"段落
```

### 模块D：病药分析系统 🟠 P1

> **来源**: 八字《神峰通考》病药说  
> **插入位置**: liuren-tuiming 新增步骤，位于财官分析（第5步）之后，成为"第5.5步·辨病药"  
> **原理**: 将六壬课式中原本散在的"制化"概念，系统化为"病→药"分析模型

#### D.1 理论基础

八字病药说的核心是："有病方为贵，无伤不是奇"——命局中的"病"（失衡点）若能被"药"（制化五行）所治，反而是贵格。

六壬推命中已经有"制化"的概念（如"吉课中寻凶爻有无制化，凶课中寻吉象有无被破"），但不成系统。本模块将其系统化。

#### D.2 六壬推命八种常见病与对应药

| # | 病（课传凶象） | 药（制化之道） | 判断 |
|---|--------------|--------------|------|
| 1 | **发用空亡** | 填实之神（出旬之日/填实之宫）+ 日干旺相 | 有病有药→虎头蛇尾变有始有终 |

#### D.3 药力判断

| 药力等级 | 条件 | 含义 |
|:------:|------|------|
| **药力充足** | 药现于课传 + 乘旺相之地 + 乘吉将 | 病可痊愈，凶变吉 |

### 模块E：三层叠宫验证 🟡 P2 【❌无据-2026-08-04审查：紫微大限流年嫁接，禁用于实战】

> **来源**: 紫微斗数大限流年"三层叠宫"验证法  
> **增强位置**: liuren-tuiming 第7步（推运）  
> **原理**: 引入"原课有象→大运放大→小限触发"的三层验证逻辑

#### E.1 理论基础

紫微斗数的应期判断有一条铁律："本命有题目，大限放大，流年触发——三层叠宫验证才算实。"

六壬推命目前的大运小限分析是**逐层独立**的——大运看大运，小限看小限，缺少"三层信号共振"的判断逻辑。本模块补全这个缺失。

#### E.2 三层验证模型

```
第一层：原课有象（终身底盘）
   ↓  课传中已有某种趋势（如：财爻空亡=财运本有波折）
第二层：大运放大（十年框架）
   ↓  大运走入财帛宫/财爻旺地=该十年是财运关键期
第三层：小限触发（当年应事）
   ↓  小限走到填实空亡之地=该年财运逆转
   ↓
三信号同向 → 该年该事必应
```

#### E.3 三层信号判断矩阵

以财运为例：

| 原课信号 | 大运信号 | 小限信号 | 三层判断 |
|---------|---------|---------|---------|
| 财爻旺相+青龙 | 走入财帛宫 | 化禄标志被引动 | ✅ 该年大发财 |
| 财爻旺相+青龙 | 走入疾厄宫 | 化忌标志被引动 | ⚠️ 财运虽好但身体有恙 |
| 财爻空亡 | 走入财帛宫 | 小限填实空亡 | ✅ 多年空财，该年逆转 |
| 财爻空亡 | 走入财帛宫 | 小限仍在空亡 | ❌ 该十年财运好转但不明显 |
| 财爻空亡 | 走入福德宫 | - | ⚠️ 原课财空信号未在大运被放大，仅作提示 |

**判断规则**：
- 三个信号全部同向 → **断定**（该年该事必定发生）
- 两个信号同向 + 一个信号中性 → **大概率**
- 两个信号同向 + 一个信号反向 → **吉凶互现**
- 仅一个信号有象 → **仅作提示**，不断定

#### E.4 在推命框架中的应用

增强第7步（推运）的分析逻辑：

```
第7步 · 推运（增强版）

1. 列出原课中所有"有象"的判断（从第1-6步提取）→ 作为第一层信号
2. 大运分析（十年框架）→ 作为第二层信号
3. 小限分析（逐年）→ 作为第三层信号
4. 每年按E.3判断矩阵做三层验证
5. 标注"断定级"年份（三信号同向）→ 这是最可靠的应期
6. 标注"提示级"年份（仅一两个信号）→ 仅供参考
```

### 模块F：分层时间推演体系（大运→流年→流月→流日） 🔴 P0

> **来源**: 《六壬针见血》身命磨镜药体系 + 六壬推命学行年起月法  
> **增强位置**: liuren-tuiming 第7步（推运）  
> **原理**: 承认三传只有3段的结构限制，用"分层推演+宫位旋转"突破精度瓶颈

#### F.1 根本瓶颈

六壬推命在时间精度上的根本瓶颈来自数据结构：

**三传只有3段**——初传（少年）、中传（中年）、末传（晚年）——这是六壬时间轴的数学上限。3段最多对应3个时间段，无法自然展开为12月或30日。相比之下，八字的干支链（60甲子循环）天然支持逐级细分，紫微的宫位旋转（12宫固定）可无限细分。

因此，要在六壬推命中做到流月、流日精度，必须在三传之外另建时间推演机制。

#### F.2 分层推演架构

```
Level 1: 大运（10年一次）— 太玄数起运 + 阴阳顺逆轮宫
          推理依据：大运所在宫位 → 十年主题
          
Level 2: 流年（1年一次）— 小限行年 + 太岁加命
          推理依据：当年所在宫位 + 太岁冲合 → 当年吉凶
          
Level 3: 流月（1月一次）— 二法并行（详见F.3）
          推理依据：当月宫位吉凶 / 当月课传分段 → 逐月吉凶
          
Level 4: 流日（1日一次）— 应期诀窍体系
          推理依据：类神触发 + 空亡填实 + 丁马引动
```

**核心原则**：上层定大势，下层定应期。上下层信号同向方为可信。

#### F.3 流月推演（两种方法）

##### 方法一：宫位轮值法（轻量，日常推命用）

**来源**：《六壬推命学》第十讲"行年起月法" + 紫微斗君法参考

**操作**：
1. 以当年**行年（小限）所在宫**为正月起点
2. 从此宫起正月，顺行布十二月（一宫一月）
3. 参考紫微顺行逻辑：正月→二月→三月……十二月，顺数十二宫
4. 每月吉凶 = 该宫天将状态 + 是否冲合命宫/身宫 + 是否发动课传关键地支

> **原"行年起月法"为逆行（"就行年本位起正月，一位一月，如行年在午位，就午起正月，巳位二月，辰位三月，如此逆行至十二月止"——《六壬推命学》第十讲）。本方案改为顺行（午起正月→未二月→申三月……），与紫微斗君法的顺布逻辑统一，也符合天盘月将顺行的自然规律。**【❌无据-2026-08-04审查：与《六壬推命学》逆行明文相悖】

**判断要点**：
- 该月宫位天将：吉将加吉、凶将加凶
- 该月宫位是否临命宫/身宫/宅宫 → 大事之月
- 该月宫位是否填实命课空亡 → 翻身之月
- 该月宫位是否发动年课上神 → 应事之月

**优点**：不改起课、逻辑统一、操作简便  
**局限**：只能断"某月吉凶"，不能断"某月具体何事"

##### 方法二：岁合起课法（重量，精确应期用）

**来源**：《六壬针见血》身命磨镜药

**原文**："流年：岁合加月将，以太岁干支作课传，一传管四月。流月：月合加月将，以月建支干作课传，一传管十日。"

**操作**：

**年课起法**（用于分12月）：
1. 以当年**太岁干支**为日干支
2. 以当年**月将**（仍用出生月将，因推命课以出生太阳过宫为不变之基）加于地盘
3. 以太岁干支起四课、定九宗门、取三传
4. 三传分配：初传管第1-4月、中传管第5-8月、末传管第9-12月
5. 每月吉凶看该月所在传的吉凶

**月课起法**（用于分30日）：
1. 以当月**月建地支**为日支（干取五虎遁所得）
2. 以当月月将加于地盘
3. 起四课、定宗门、取三传
4. 三传分配：初传管前10日、中传管中10日、末传管后10日

**实际运用规则**：
- 年课定各月大势（哪几个月吉、哪几个月凶）
- 月课定各旬细节（上旬/中旬/下旬何事）
- 年课凶而月课吉 → 大势不利但该月有转机
- 年课吉而月课凶 → 大方向好但该月需谨慎

**优点**：纯六壬原生方法、《六壬针见血》有明确记载、能断具体事象  
**局限**：需每年每月独立起课，操作较繁琐

##### 两法选用规则

| 场景 | 推荐方法 | 理由 |
|------|---------|------|
| 日常推命、快速浏览流月 | 方法一（宫位轮值） | 操作简便，一望可知 |
| 精确断事、需要应期判断 | 方法二（岁合起课） | 信息丰富，能断事象 |
| 验证某月吉凶时 | 两法互参 | 信号同向则确凿 |

#### F.4 流日推演

流日精度是六壬推命中**最薄弱的环节**。目前可行的方法有三：

| 方法 | 来源 | 操作 | 精度 |
|------|------|------|:---:|
| **类神触发法** | 《应期断诀窍》 | 看类神所在之地支，该地支对应的日子即应期 | 指向特定几日 |
| **空亡填实法** | 《应期断诀窍》 | 命课空亡之地支被流日填实或冲动 → 应事 | 指向特定几日 |
| **月课三分法** | 《六壬针见血》 | 月课三传各管10天，看事在何传 → 缩小到旬 | 10天粒度 |

流日建议：仅在命课或年课中有明确类神信号需要精确到日时使用，日常推命不断流日。

#### F.5 在推命框架中的应用

增强第7步（推运）的分析逻辑，加入分层推演：

```
第7步 · 推运（增强版）

7.1 大运分析（十年框架）
    - 大运所在宫位 + 天将 + 是否冲合身命
7.2 流年分析（逐年吉凶）
    - 小限所在宫位 + 太岁加命 + 三层叠宫验证（模块E）
7.3 流月分析（逐月吉凶）
    - 方法一：宫位轮值 → 逐月吉凶速览
    - 方法二（可选）：岁合起年课 → 精确到月的事象判断
7.4 流日分析（极精应期，仅关键年份启用）
    - 类神触发 + 空亡填实 + 月课三分
7.5 关键年份标注
    - 断定级年份（三信号同向）→ 可进一步用流月方法锁定到月
```

## 五、关键决策点（需确认）

在正式实施前，以下关键设计点需要确认：

### Q1: 四化取法规则是否需要调整？

当前设计以"天将×日干长生状态"取四化标志。备选方案：
- A: 以"三传之地支×天将"取四化（更贴近三传三段论）  
- B: 以"十二宫宫位×天将"取四化（更贴近紫微原意）  
- C: 当前方案（天将×长生状态）——与六壬课式逻辑最自洽

### Q2: 调候判据用月将还是月令？

当前设计用月将（太阳过宫），因为月将是六壬的原生概念。备选方案是使用八字意义上的月令（以节气分的月份），这样与八字调候表可以直接对齐。但月令不是六壬的原生概念，引入会增加复杂度。

### Q3: 病药系统的"病"是否应该包含神煞？

当前设计以课传结构（空亡、白虎、干支关系等）为"病"。是否扩展为包含神煞（如丧门、吊客、病符）？扩展后覆盖面更大但可能过于复杂。
