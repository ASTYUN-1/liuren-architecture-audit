## 二、只保留两种需要交付的数值，内部使用同一计算图

1. **综合旺衰E**：计入月气、临处、实际生扶泄耗克制、适用的空墓等条件。它回答这个节点在当前时段有多少可发挥力量。
2. **定向作用A(i→目标/动作)**：由E经过发动、通路、贪生合、合绊及具体动作条件得到。它回答此力量对指定对象能发挥多少，不是第二套旺衰投票。

作用性质另用说明或向量记录，不强压成一个正负吉凶分。财旺难得、父母旺难生我、鬼旺贪荣，均可由E与A的差别表达。

这不是要求AI阅读多张分表：默认每个关键节点最多给E、必要的A和一句限制。内部账本保留全部参数和贡献，便于审查。

### 墓的单独处理建议

墓具有闭藏机制，单纯衰弱乘数不足以处理冲开。本稿建议将同一墓条件拆成“本体参照1、可接近率0.6”，乘积仍等价于旧0.6；不是在旧0.6后再乘0.6。

多个参照时，令墓参照的本体R*为1、接近率h为0.6，其余参照R*=R、h=1：

```text
B_i = 5 × M_i × Σ(w_r R*_ir)
H_i = Σ(w_r R*_ir h_ir) / Σ(w_r R*_ir)
```

无其他作用时，B×H与旧基础量一致；联合扶损后，H约束该节点相应可发挥量。若只是作象的“墓”而非实际闭藏条件，不套该分支。冲开时改变对应h，不另加开墓奖励。此拆分为本稿新建议，需审查。

## 四、第二层：参与与通路先确定，再算多少

固定全盘事实图，不能因AI多看一个宫就改变分数。计算关系必须具备：明确的两个对象、坐标、适用来源、作用方向及阶段。

- 直接天地、神将、将地、干上系数1；直接阴神0.75。
- 相邻传位0.5；初末或其他切题课传关系0.25；跨宫天将关系0.15。
- 这些是前版研究通路强度，不能仅因地支字面关系存在，就生成全盘任意两两作用。
- 同一对对象、同种机制、同一阶段的重叠描述取最大通路系数，不按“阴神+中传+合局”重复生三次。
- 阴神基本采用一层；新增层须被具体规则触发。为防止全局迭代暗中传播多层阴神，内部先求不含主动阴神输入的E(0)，再求含一层阴神输入的E(1)；E(1)的阴神边只读取施者E(0)，普通已授权边在各自层内联合求解。进一步深度只由具体规则授予。这些是同一节点的条件参照值，不作为多个角色相加；原本十二气对阴神的查表参照仍保留，它不等同主动阴神输入。

令r_ij表示资格：成立为1，明确不适用为0；未知为缺项，不能默认为0。g为通路强度。只有资格成立的通路进入输出预算。

```text
g0_ij = r_ij × g_ij × 合作通路修正
g'_ij = g0_ij / max(1, Σ_j g0_ij / 2)
```

同一施者总门限仍不超过2。但预算按固定的适用机制图计算，不按展示的节点列表计算。直接临处的局部环境供给与环境对多个宫位的供给分账，不能把所有地盘合成一个可无限跨宫施力的同五行源。

## 五、第三层：生扶、泄耗、克制联合求解

生扶沿用：

```text
施生s→受生t：受者增加 = 0.20 × g' × E_s × τ_st
               施者泄耗 = 0.10 × g' × E_s × τ_st

施克s→受克t：受者受制 = 0.20 × g' × E_s × τ_st / (1+E_t/5)
               施者付出 = 0.20 × 本次实际受制量
```

τ是该具体方向的适用限制；普通成立通路为1，贪生停用等命中对应目标才改变τ。不能只减少受者所得而仍向施者收取一份“已经完成”的全额生扶成本。施生/施克成本与实际作用用同一份账。

比和建议改为：

```text
同类配合s→t = 0.06 × g' × min(E_s, Eseed_s)
Eseed_s = 原基础条件下、未计其他节点增益的可发挥量
```

因此受损的伙伴少出力，但靠比和得到的加成不能再完整作为一份新本金循环互抬。比和代表配合，不能直接当作受生。

最终联合方程：

```text
E_i = V_i × clip_0_10 { H_i × [ B_i + 实际受生 + 同类配合
                                  − 实际受制 − 泄耗 − 施克成本 ] }
```

注意：V、H不是在分数之外再扣一次。沿用空亡在非空得分限幅后乘一次的顺序，自身旺空的E上限仍为8.5；A的发动增幅不改写其空亡身份。非空底数与扶损统一后限幅，避免先把底数截断再扣损。所有实际流量的施者受制、救神受制和连锁作用，在同一组方程内处理，并执行上文主动阴神的深度约束。参数、图、阶段、作用语义固定后才求解。

地盘可作为局部边界环境，其月气底数固定，不因受克“消失”；地盘对可移动节点的实际作用有通路预算。涉及对地盘神本身论制救的专法时，必须另建该专法中的角色对象，不能借环境固定性质使其永不受制。

## 六、生克并见不能机械抵消：专项覆盖一般系数

### 庚辛临巳的候选数量化

已定原文要求：巳旺时长生之力相对更多、鬼克之力更少，且乘太常勾陈与乘朱雀的偏向不同。不能仍用不变生克系数，最后只补一句解释。

建议在已命中该专项条件时，对同一临处来源建立一个共同作用预算W：

```text
u = E_巳 / (E_巳 + E_金 + ε)
v = 生金的乘将实际作用量 / (该量 + 克金的乘将实际作用量 + ε)
    两量均无时v=0.5
p0 = 原长生正贡献量 / (原长生正贡献量 + 原临处克制量 + ε)
d = 0.25(2u−1) + 0.25(2v−1)
p = p0 + (1−p0)max(d,0) + p0 min(d,0)
长生解释份额 = pW；鬼克解释份额 = (1−p)W
```

此处W等于原长生正贡献量加原临处克制量；两份解释从同一已计入的预算中分配，不能在完整长生加成、完整火克之外再增减W。d为零时保持原分配，正偏置将部分克份额移向长生，负偏置反之。数值账实现时以受影响的原参照贡献和原克制量替换结算；不引入新无来源生扶边。原贡献两项均没有则不启用。乘将本身已经存在的独立生克边保留，其影响此处权衡不意味着再加一遍乘将所得。

该偏置公式是新候选，不是原书数字。寅巳生刑、未亥克合分别执行原文明示的方向和适用条件，不把这条金火公式推广到所有并见关系。

### 土临申、绝处受生

土临申保留长生状态和土生金泄耗，不相互删除。绝逢生使用实际受生输入；如需要解释绝态缺口被修复，从该输入中划账，不另发“绝处逢生奖金”。求财耗泄与学历生计等义项另在定向作用中解释。

## 七、第四层：贪生合、合绊与刑冲破害约束具体方向

对已经成立、且确实妨碍该动作的关系：

```text
单项损失d_c = λ_c × g_c × E_施者 / (E_施者 + E_受者 + ε)
```

候选λ沿用旧研究上限：刑0.12、冲0.20、破0.08、害0.10、单见自刑0.05；六合0.20、半合0.10、三合0.15、三会0.10。

同一原因不同名称先合并取最大。不同真实原因采用`1−Π(1−d_c)`组合，刑冲破害类总损失上限0.35，合绊类上限0.30。这是新建议，替代简单相加；同一个作用不能既在E中按同一原因扣过，又在A中扣相同份额。

**刑冲不默认全是受损。**先由规则选定作用：

| 实际作用 | 计算位置 |
|---|---|
| 冲伤本人、类神或救者 | 对应受者/作用通路受损，不是全盘统一扣分 |
| 冲散病鬼或阻碍 | 直接减少该阻碍的有效作用，不另给本人免费加气 |
| 冲开墓、冲破合绊 | 撤销/减轻对应约束，不再额外奖一次 |
| 冲动发动 | 更新发动资格；不是以冲克名义扣一份再加一份 |
| 刑害并见且确有不同机制 | 分别计算独立机制，同源标签不数票 |

开墓、破绊的连续释放候选为`释放度=min(1, 有效冲者力量/(0.6×解除前受约束节点力量+ε))`，前提是相应专项准许此冲解除该约束。有效冲者力量取其经过通路和自身限制后的力量；受约束节点以该限制尚未解除、其他条件相同的对照状态为参照，避免解除本身抬高自己的门槛。只解除命中的墓/合绊，不解除所有不利状态。

## 八、三合、半合、三会：增强实际协作，不凭空生成第二份力量

识别成员范围先固定为课传及被专项规则允许加入的相关对象；不能因12宫都有12支便宣布所有三合三会俱全。支神、同名地盘、年命补局不能混用。

先算成员E，已经包含成员自身旬空/坐空效应，再定义：

```text
完整度C_g = 覆盖系数 × sqrt(成员最低E × 成员平均E)/10
三字全覆盖系数1；半合覆盖系数0.5；无适用成合条件则不启用
协作修正 = 1 + δ_g × C_g
δ上限：半合0.05，三合0.10，三会0.12
```

该修正只作用于有共同目标的合作通路g，再经过总输出预算；不直接给每个成员E各乘一遍，更不生成一份完整火能量与三支重复相加。合绊作用于面向组合外部、不符合其合作方向的动作；同一目标不能无条件既奖协作又罚合绊。

午空通过午E减少完整度，不再给完整度额外乘一次午空。寅坐午空通过其自身保留率及实际路径起作用，同根事实不另作为一条“全局有空”惩罚。

合与化分开。没有采用依据及成立条件，不改成员五行。寅戌半合的火向联系可以识别；若无显现火承载者，不能凭此凭空制造与现存火神等价的输出，专项虚神作用另接规则。

完整度只描述协作强弱，不据此单独宣布成局或合化；成局/化的资格在数值前由适用规则判定。

## 九、第五层：发动、承接与最终定向作用

建议将前版“初传固定1.2、中传1.1、末传1”的通用序位表改成按问题阶段选择：当前所论阶段的对应传位1.2，其他切题传位1.0，仅四课出现0.9，其他已具切题通路的节点0.75，日干主体1.0。

```text
A_i→目标,阶段 = clip_0_10 [ E_i × 阶段发动系数 × 该动作通路资格
                         × 该目标相关约束保留率 ]
```

这里不再乘V、H，不再重复给协作倍率；协作已经进入通路预算。若约束已经在联合求解中限制同一条具体输出，此处引用该净输出，不再次套相同保留率。每项约束需要在账本注明唯一结算位置。

E、A均为0—10的研究指数；0.2等“受生贡献量”是账本中的贡献，不能拿它与2.5独立力量线直接比较。跨节点比较A必须同目标、同阶段、同一规则图。

马恋生、坐墓、缚足、马墓空等专项控制出发/到达/完成的通路资格和保留率；不把一个一般A通用化为所有行动成功率。若原法只提示受阻，不得擅自设硬零。

这是趋势初值，以对应节点的当时月气索引，综合E另表其有效能力；不能偷偷把月气与综合旺衰分档视为同一件事。这张表尚不覆盖所有凶神专法，命中特定玄蛇空等条件时必须执行专项，不能仅靠E低自动判无害。

吉将得力亦不使所有生克关系自动变成吉；权威、资源、竞争、损失等意义按本问角色解释，不能以某张系数表代替取用。

## 十一、制救、四建、神煞与时间如何闭合

### 制救与时序

每条救制规则写明施者、被制者、受益者、阻碍、阶段、到达条件。发用鬼可被末制，是终局层面可解除早先阻碍；末传鬼不能由发用按该专法反制。相同五行关系在这里可能有不同资格，不用全图无时序对称抵消。

制救的身体扶损进入E，具体通路开闭进入A，性质护解进入性质系数；同一救因只在相应层结算一次。是否改变事件结果仍看解除的是哪个关键阻碍，而非救力达到统一总分即成功。

### 四建

月令作为气候参数对全盘生效，不以入传为前提。太岁、月建、日、时的切题位置、上神与实际生克，按对应通路参与；月气和同源“得月令”不重复奖。

权柄、持续与发动速度分别是角色和时间参数。本方案不设“年×4、月×3”或“时最大”的统一本体倍数。入传加强实际参与可由传位/通路体现，同一身份不再额外叠加“四建入传奖”。

### 其他神煞及特殊格局

每项必须归入一个明确接口：角色取用、数量扶损、作用约束、结构改路、性质修正或时间触发。禄主要标识资源/待遇，马标识动变，医标识相关救治，不能仅见名称就给本体加分。

内外战、夹生夹克首先是已有方向链的组合；底层已经结算则不再收格局罚分。有独立专项轻重时只调整该专项的通路/性质。课体名亦不统一加减。

尚未编译且对本问必要的神煞或格局，不记作零，也不输出完整A；允许保留已完成的局部E并明确覆盖范围。这是适配工作未完，不是需要用户重确认的理论争点。

### 时间

固定原占坐标，按明确评价时段更新月气、空亡评价条件、流时触发及相应制救资格。不得每天将固定坐处十二气自动推进一格。出旬使对应空算子更新，不自动使A超过门槛；旺鬼转衰须同时重算性质和实际力量。

## 十二、求解、去重与可审查标准

规则图和所有参数固定后联合求解，不能边看结果边增删关系。阻尼迭代可沿用0.5，残差达到1e-9；还需从低、中、高多个初值检查是否得到同解。未收敛或不同初值得到不同稳定解，则标为数值问题，不择有利结果。

每个作用保留：原因ID、对象坐标、施受方向、目标、阶段、结算层、原始量、限制量、最终贡献、来源。事实改名、更多展示不能多出一份贡献。

审查应检查：

1. 空亡只结算一次；A不因同一空再扣；同根空能追踪。
2. 弱火对旺金影响小，但并非只凭“弱”字硬归零。
3. 同处贪生与外来生扶产生不同定向作用。
4. 开墓/解绊只撤销对应限制，不免费叠奖励。
5. 相同节点重复出现不重复生扶或增益。
6. 合局增强对应协作通路，不制造成员以外第二份完整五行力量。
7. 制救方向、阶段明确；救者受制能传递；同一救因不重复减害。
8. 低分节点仍可参与结构与触发，不以2.5为删图门槛。
9. 不根据已知求职答案反调参数；固定版本对所有研究盘复算。
