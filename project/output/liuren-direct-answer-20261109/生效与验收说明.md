# 第40版本机直接作答约束

活动版本：`20261109-direct-answer-40`。

完整规则已前置到裁决开始前必读的共用核心与报告方法，并进入OpenCode主智能体、裁决者提示词。Codex适配器从同一活动版本绑定资料。提交前自查，交付前沿用39版的 `answer_constraints` 核对，不增加额外裁决轮次。

- 是非题先给是／否或倾向是／否，再交代依据与关键反证。
- 身高等数值题给有依据的最佳估计和单位，不能只描述偏高偏矮。
- 所在地结合方向与分野给主选地区，依依据确定精度。
- 原因题先给主因；减少重复免责声明，不在后文无故撤回主判。

明确答案仍须有依据；不随机选边，不编造数值、精确住址或现实已证事实。真实缺口具体说明，第三方性经历与避孕等敏感隐私不凭盘面臆断。主智能体保持中性交接，不能自行替裁决者改答案。
