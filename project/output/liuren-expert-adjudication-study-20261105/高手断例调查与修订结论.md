# 高手断例调查与判断逻辑修订结论

本轮按用户要求，先调查断例和方法原文，再修订上一轮主要从执行逻辑出发的方案。主要资料为北海《特训班讲义》《理法简易》《指南问答》、陈公献《指南注解》中的原断、邵彦和《断案》中的原载断语、《壬归》和天一群笔记，共7份主要文本。逐项整理23个案例单元和9组方法段，另有2组同案异本／解释对照；不是全库审完，也不是23个已独立验证事件。

调查是对本地文献中明示断法的研究，未访谈作者，不能还原作者未写出的内部思路。现代笔记作者按原载署名保留，不因收录就认证水平。原载反馈未做外部核实，预测验证仍为0。未调用外部模型，未切换活动版本。

## 一、真正有依据的取舍方法

### 1. 先有所主，不能遍看而无主

《壬归》LF357引《金绳书》：“求财专视青龙则失之拘，遍推寻而无所主则失之荡。”这与当前问题直接对应：既不能只认一神，也不能把所有信息平铺成同等候选。

北海讲义LF6–51把方法明确为“明占类，定侧重，看显象”。但定侧重之后还要辨真假与变质，绝不是先定成败再找支持。其《理法简易》LF277–313进一步要求核课体与所问是否“亲”，有些课体回答主事，有些只反映侧面。

**对我们的修订：**主线应先由所问与本课显现的切题类神／关系／结构共同选择，再检查它是否真实有用。不能先给出一个吉凶答案，随后命所有象义为它服务。

### 2. 主次取决于本问中具体组合的效力，不能只比单项旺衰

E02返吟求职，北海用禄发用、进气、与干上合取成，并未让返吟、玄武把录用结论削成犹疑。E05马康庄入相却恰好相反：官龙临干发用、得末助仍让位于干支败、官空、龙化蛇等实际关系。

这两案不能整理成“类神永重”或“课体永重”。更可取的共通点是：核所取对象的真实状态及组合在本问中究竟成就什么、破坏什么。E05中末传助的是何种官鬼，也要重新判其利害，不能“生助一律加分”。

**对我们的修订：**裁决正文必须引用具体盘面作用或切题专法条件。课名和类神不各开一张权重表；五气旺衰只是作用判断的一部分，气势还包含方向、传递、动静、神将组合和类聚。

### 3. 看似有利的东西，可能已变质，不能只扣一点分

E07《断案》先说丑寅引鬼为生可望转吉，紧接着以寅空否定这条引进路径，遂转为凶断。E01分房则详细核亥虽旬空，仍有相气、生扶及与本人关系，保留得房。

**对我们的修订：**空、墓、克、闭口、阴神等须核是否改变主象的实际性质或用途。若主判赖以成立的一环已经不成立，应撤回并重判，不是继续保留原方向再减程度。若该环在所用方法下仍可用，也不能因看见空字就机械扣分。

这不是建立一条“所有空亡先看旺便一律不空”的新通则；不同文献的定义与例外仍须保留。

### 4. 要辨“财旺”与“财能给、本人能取”，不只看一个对象的好坏

《壬归》LF361–389对文书之财的论述，分别核朱神、阴神与本人关系，并核与财者的畏忌。财阴伤财是分夺，财阴伤身是他患，与财者受制可能不敢给，不能统一翻成金额减少。

E11说借而未给，E12有试用而未合作，E21明确只问编制、不问是否仍有工作，都是取与或特定目标不能被外围好处替代的例子。

**对我们的修订：**按占类具体核主客、取与与所求专类，不预造跨占类统一的成功条件链。对于一件事已有的资源、能否取得、取得后代价和持续性，分别说明有据的实际作用。

### 5. 多象会聚有方法意义，同根去重不能删掉组合

《理法简易》LF266明确把“重神”“类聚”列为气的内容。E08魁杜、退茹在六仪、三奇、禄、贵等组合中被另作判断；E02禄、进气、合也不是同一词的重复。

**对上一轮方案的直接修正：**

- 同一事实换几个名称、同案跨本转载，不增加独立证据或验证次数。
- 但同一支同时承担关键六亲、乘将、煞、旺气等不同职责，可以共同构成专门组合，改变气势或真假；不能因“同支”便删到只剩一项。
- 要交代组合成立的条件、共同作用或相互限制，不能按名称数量计票，也不能按机械去重拆散原法。

### 6. 明确成败不等于抹掉过程与后果

E06明确升迁且不久任；E10明确先得住持而后失位；E04明确已孕而后流产。这些文本没有为了兼顾两面就输出一个模糊的中间结果。

**对我们的修订：**允许不同阶段、不同对象出现各自明确的结果。过程、程度、时间、持续性按实际依据分开；如果期限或稳定性本来就是原问标准，它们仍可以直接决定本问失败，不能先划成“次要维度”来保护成功结论。

### 7. 取舍还要核“象义到结果”的推导是否成立

E15从有奖直接推胜，原载反馈输了但有奖；E16从某些文书吉象断好成绩，却反馈未过。这不是可以用一句“主次没分好”掩盖的错误。

**对我们的修订：**决定具体结果之前，核该条件究竟支持什么，是否还存在满足同一条件但结果不同的情况。若有奖与输了能并存，有奖就不能单独决定胜负；成事的支持也不能自动区分相邻名次、等级或两个金额。这个检查是本轮从正反案例归纳出的执行办法，不冒称古籍已有统一判别算法。

### 8. 有争议的断例不能当作确定的权重教材

E19的公明会试案，主次问答十分切题，但问答自己指出盘文不合，《指南注解》又列另一盘。其后“先定必中再找考中类神”的话是读者补议，不能归北海。

E20有二十六年与十六年的文字冲突，析者也质疑后添取数。E21三传表和正文传位待核；E22虽有拿到手机的反馈，原段“青龙尚可”的替代理由仍未充分展开。

**对我们的修订：**记下作者怎么取舍，同时标明哪些不能复现、哪些理由未展开。强断语不是强证据；结果吻合也不能补成作者没有写出的普遍方法。

## 二、对原方案作出的实质改动

| 原方案中的安排 | 本轮依据断例后的调整 |
| --- | --- |
| 选主线，再比反证 | 补主线的切题来源、真假变质及取与路径；主线不等于先冻结答案。 |
| 比作用与力量 | 扩明气势包括类聚、进退方向、传递与神将组合，避免收窄为旺衰或克得动。 |
| 同根不计多票 | 区分重复命名、同案转载与不同职责构成的组合，不拆散重神类聚。 |
| 反证是否足以改判 | 明确关键环节失效可以直接撤主判；有生有救也要核其实际承接。 |
| 按结果维度分开 | 增加同盘不同对象及专类职责，不把父子、编制与工作、获奖与获胜混为一事。 |
| 精度不够不强行选档 | 保留，但补上反例检查：同一依据能否同时容纳两个待选结果。 |
| 来源标注 | 增加原断、注解、合集读者补议、异盘和不同版本；挂起矛盾环节。 |

## 三、进入 Skill 前应保持的专业口径

建议在既有三阶段中，把裁决核心概括为：

> 依本问与课传定所主；察主象的真假、气态与所宜，核主体、所求及相关作用；辨组合与传递是否使其成就、变质或转移；面对相反依据，明确为何取此舍彼；再按原问给出所能支持的成败、程度与时间。成立的专法和类聚可决定结果，不按吉凶名目投票；组合失效须重判，作用未达须留条件。结尾忠实于裁决，不以谨慎降结果，也不以果断补依据。

这段是研究后的候选执行归纳，必须与原法、分类模块及案例条件一同使用。不是新的通用占断定理，不需要全案强制JSON或把所有例子变成硬门禁。

整套 Skill 的职责拟这样分配：主入口指导因问选侧重及回核；定位模块分对象、专类；理气模块核真假、气势、制救与类聚；裁决模块负责有根据地取舍；报告模块保持判断含义；案例与提取模块保存来源层次、未展开推导及反例。避免在所有模块重复一长串“禁止”而仍没有正面判断方法。
