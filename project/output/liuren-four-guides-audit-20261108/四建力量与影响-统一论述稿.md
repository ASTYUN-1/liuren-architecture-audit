# 四建力量与影响：统一论述稿

本稿供统一本机大六壬方法解释及后续规则设计使用。以本轮已核对的《壬归》、北海闲人文本与《一字诀玉连环》为依据，原文证据见同目录《四纲强弱与权柄-查证说明.md》及《连续原文与来源.json》。这是本轮有来源约束的综合解释，不是某一古籍的原文，也不声称诸家已有同一体系。尚未接入活动runtime。

**一、总论：四建有分工、有权重，实际效力取决于具体作用。**

年、月、日、时是同一占事中的不同层次。太岁具有岁中统摄及尊贵权柄之象；月建具有当月执令及官长权柄之象，月令同时规定当时五行的五气状态；日干、日支用于建立本问的人事关系与判断参照；占时表现当前端倪及临事切入。四者共同参与判断，但各自所主不同。

《壬归》明言“太岁月建，气力最大”，北海强调“其权最重，威不可犯”，又说月建“就是令，掌权的，力量大”。因此，岁月之权确实涉及实际影响和作用能力，不能只解释为历时较长。占时为先锋、日时较近较速，也有原文依据；但近速和先兆不等于总力量胜过岁月。

本稿以“岁月重权柄，日辰明人事，正时显端倪；月令定五气，气地察效力”为组织主线。其中“效力”指某节点在当前条件下能对目标发挥的具体作用，不与吉凶结果直接画等号。

**二、四建分别影响什么。**

| 层次 | 已核材料支持的主要影响 | 实际使用要求 |
|---|---|---|
| 年建、太岁 | 岁中事、尊贵及重大权柄；相关生扶刑害可有重大影响；可参与范围、规模及应期判断 | 看太岁本身及上下神在本问中的具体位置和关系，不能仅凭年支与日干的一条关系断全年结果 |
| 月建、月令 | 月中事、当月权柄；五气随四时；可参与当下势态、规模及应期判断 | 分开月令定气与月建作为盘中节点两种作用；不得把当令直接等同成事 |
| 日干、日支 | 常用于本人、彼方、事情、处所及内外尊卑等角色参照；可参与当前近事与应期 | 依占类和已知情境明确角色，日干与日支不混称一个“日主”，也不保证每问均固定为我与他 |
| 占时 | 正时为先锋门，可先显来意、当前端倪；与课传、类神的关系可提示阻碍或契机 | 分清占时地支、时上神将与时干；按实际方法使用，不能仅凭时生时克包办成败 |

月建与月令在具体历法中的取法，沿用可信排盘程序的固定采用口径，不在断事时临时切换。月将另有自身角色，不能与月建互换。年建也不等于本命或行年。

依据：SG01—SG06、SG09、SG12、SG17、SG18。

**三、统一“力量”的含义：分别判断权柄、气态和作用通路。**

首先，权柄说明其在本问中的地位与影响分量。岁月为君长，不宜轻视；但一个节点具有权柄，不代表它在任何位置都能不受条件限制地完成任何作用。

其次，气态说明所观察对象当时的状态。月令五气、坐处十二气、生扶克制及空墓等共同进入分析，必须明确对象与参照。按本次讨论，“旺衰”可作为综合状态的称呼；其中“月令五气”仍保持狭义，不能把综合旺衰与单独得令混称。日干论十二气采用天干表，支神及按五行论的天将状态采用其适用表，均明示“谁在何处”。此表法分工沿用本次已明确的研究口径，不归称本节所有引文的共同原说。

再次，通路说明它实际上作用于谁、在哪里受生、受制或被牵住。月令提供时令状态，坐处和阴神等形成具体关系，这些不同层次不能都写成同一种“某神生我”。北海说“壬课一般不讲四建（年月日时）生类象”，故不能只因盘外年支、月支的五行关系，就默认另有一股无位置限制的力量遥生遥克所有节点。特定原法允许的岁月上下神作用，须保留其位置与适用范围。

最后，作用能力与作用性质分别判断。“旺鬼”不能自动翻译为攻击伤害更大；“鬼贼当时”与刑虎并见、本人衰弱、救神失效等具体组合仍须辨条件。德解、神将、占类及受作用对象都可能改变所表现的内容。本稿不在四建层面强行裁定所有官鬼吉凶分支。

依据：SG01、SG10—SG12、SG16、SG17；十二气表法及综合旺衰的用语，属于本次讨论已明确的体系选择。

**四、入课传表示进入重要作用位置，闲地不等于无效。**

四课三传是观察本问具体关系的重要位置。岁月节点入课传，应明确它作为类神、阻碍、救应或其他角色所起的作用，而不是只因“入传”就直接判大吉大凶。

未入课传，也不能一概忽略。《壬归》明确保留岁月居闲地时其上神的关系；月令定五气更不以月建是否入课传为条件。但这也不要求把所有闲神逐一扩展为决定性关系。只有与本问相关、且有适用方法和具体作用依据的关系，才进入结论。

因此，入课传、居闲地是作用位置的差别，不是“真老虎、纸老虎”的二分。不能预设入传使力量固定翻倍，也不能预设不入传力量归零。

依据：SG01、SG02、SG17。

**五、长短问题调整观察范围，不倒置成另一套力量排序。**

占长远之事，应考察条件能否维持，期间有什么时令变化和关键转折；占眼前之事，应重视当下能够发生作用的关系。两种问法对时间窗口与结果环节的要求不同。

长事中可有决定某阶段结果的日时条件，短事中也可有当前不能绕过的岁月条件。是否起决定作用，要落到具体关系，不以事情大小将“年大”与“时大”两套排序来回切换。

北海原文在财务与移远就近的条件下，说明岁月常有较长较远的意味，日时较近较速。这些是相应方法中的判断依据，不是把每个节点的影响期限永久限定为一年、一月、一天或一时；不据此认定所有太岁因素都慢、所有占时因素都快。

依据：SG05、SG06、SG09。

**六、发生冲突时，按同一条作用链比较，不做吉凶票数抵消。**

先明确本问结果及观察时段，再明确本人、所求、阻碍与救应分别对应哪些节点。随后逐项检查：

1. 关系是否对同一对象、同一结果环节发生作用；不是同一环节的，分别表述。
2. 双方各自的月令气态与坐处如何，生合、克制、阴神、神将及相关神煞如何影响其作用。
3. 岁月权柄是否在这条具体关系中体现，是否另有受制、空陷或不能承接的条件。
4. 制救是否能够到达阻碍、发挥作用，并且足以解除本问的关键障碍；不能只因存在相克关系就认为已经救成。
5. 某条关系只能缓解过程损失，还是能改变最终结果；先后顺序有无时间或传递依据。

例如“月建克日、占时生日”，应先辨月建与占时实际对应的节点、角色和作用，再辨其气地及生扶能否有效。不能直接写成先凶后吉，也不能不经分析便以月建权大否定一切救应。“月令失令、三传得生”也不能按虚不受补直接判失败；北海明确保留“衰得生扶而暗兴”。

这是一套本轮归纳的分析次序，依据是原书对气地、生克、取与及制救的分别考察。它不冒充现成的古书公式；若具体条件仍不能裁明，须指出缺失条件，而不是随意改用另一套优先级。

**七、时间推进时更新状态，同时检查何种变化足以落实结果。**

本人、所求、阻碍与救神的状态都要随所判断时间重新比较。《玉连环》的秋、春同形盘论断，明确比较了木身、金鬼、火救在不同季节的差别。因此不能将占时所得的旺衰结论固定成整个未来阶段的永久性质。

原占盘仍是分析依据；讨论未来状态变化，不等于擅自按未来时间换一套盘。预测中的某月某日是待验的条件，不写成已经发生的事实。

旬空是综合状态中的一项条件，需记录所属旬及其作用对象。出旬、得令、受生、逢制等改变条件后，应重新判断实际作用。出旬不等于其他问题同时解除，月建有权也不等于旬空身份取消。北海一方面保留岁月仍为空亡，另一方面允许依据整体气势将空解释为迟等含义；本稿保留这种事实与效应的区分。

依据：SG10、SG11、SG13—SG15。

**八、采用口径与保留缺口。**

本稿采用《壬归》及北海已核段落对岁月权柄的说明，保留《玉连环》对占时先兆与气态随时间变化的论法。《天一群笔记》“年最小、时最大”未说明与“岁月气力最大”之间的共同尺度，因此不采用为四建总力量排序；也不据此反向建立年必胜月、月必胜日、日必胜时的无条件胜负表。

“上四纲就刑不动”不扩大成任何四建节点都免受刑伤；“月令为重”不扩大成得令必成、失令不受生扶；“发用重要”不扩大成初传压过一切；“岁月权大”不扩大成岁月自动不空。

尚未确定的部分，是各因素在相同对象、相同作用环节发生冲突时，哪些具体组合足以制胜、承接或解除障碍。现有材料支持有条件的作用分析，不提供统一能量单位、固定倍数或跨占类的数值阈值。本稿先统一观察对象、词义、关系及裁决次序，为后续条件补足和验证保留位置。

本稿未改变本次已经明确的“喜旺恶衰”、直接临生合与别处生扶须区分、十二气跟随所看对象等研究方向；未解决的具体例外仍按原文保留。书证核对不等于已经证明预测效果。
