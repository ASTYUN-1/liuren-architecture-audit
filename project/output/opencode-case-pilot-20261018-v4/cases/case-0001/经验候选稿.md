# 2026-10-18 事业占 工作调动应期（补充复核·未验证从疑）

## 经验规则
1. 中传月建不等于应本月；“一月内”是量级，不是具体月。
2. 应日冲突时，末传合神/驿马值日不得自动压过用神临宫；本课亥日未应、巳日应。
3. 用神临宫支＋传遁干可作候选生成，但取干、择日、预排除均未解决，仅单例拟合。
4. 旧验案“调令应亥月”不可直接迁移，不等于该案亥月为巧合。

## 适用条件
重审/元胎；发用申(青龙)；类神父母/驿马；用神临支且传有遁干。
