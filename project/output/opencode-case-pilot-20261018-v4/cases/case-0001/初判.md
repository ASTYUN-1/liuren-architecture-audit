# case-0001 首次独立分析（事业占·工作调动）

## 盘面事实
癸卯年癸亥月癸巳日癸亥时，月将寅，占时亥（夜）。旬甲申，空午未。贵人卯临子顺行，四课：辰(蛇)/癸、未(勾)/辰、申(龙)/巳、亥(常)/申；三传初传申（遁甲，青龙，父母，临巳）→中传亥（遁丁，太常，兄弟，临申）→末传寅（遁庚，天后，子孙，临亥）。课体重审、元胎、六仪、斩关。关键煞：申有天诏、成神、进爵、文星、旬仪、干德、小耗、支刑破；亥有皇书、驿马、丁马、支冲、阳刃、血忌、月刑；寅有月德、天解、月合、孤辰、死神、亡神、天罗、马倒；巳有日德、闭口、月破、丧门；辰有天德、解神、病符、退神；未空带勾陈；子为日禄乘玄武；午为财空。以上为facts原值；引擎课义/断曰未提供，不杜撰。

Q1会调动，且带正式文书/任命色彩（申父母青龙＋天诏/皇书/进爵/成神/六仪，生干），但不是大升：末传寅子孙克官、官星辰乘蛇、官未空＋勾陈、日禄子乘玄武、财午空，故为平调/换岗/系统内轮岗，名分有而实权待遇有限。置信中偏成。

## 规则出处与优先次序
占类与主线依sanbu-duanke、leishen-keti：父母申为调令主事位（入课传、不空、乘青龙、生干），官星辰为现状，驿马亥为移动，末传寅为结果。空亡变质依kongwang-bianzhi：主类神申亥寅不空得生旺，事可成；未官空、午财空、子禄玄为名利折；辰官乘蛇为变质有天德解；末传阴神巳带闭口月破而有日德。神煞依shensha-panduan分级：一级驿马亥不空旺冲支为真动，丁马助动；二级文书任命吉煞与三德为救，小耗闭口为耗；三级刑刃孤死罗网为阻。动态依youlu-lilun：申临巳合中带刑、亥冲巳、寅亥合、寅申冲，初末冲主速而反复；阴神链申→亥（印信同侪推动）→寅（恩泽合而孤）→巳（文书口舌有救）。课体依keti-qishi：重审主审核反复，元胎主新局胎动且验案主速，六仪吉，斩关魁临干可破关（refs/keti-quanbiao）；毕法B2三传递生人举荐、B1首尾相见。调制依jixiong-tiaozhi：申父母×青龙吉上加吉，亥兄弟×太常平中带吉，寅子孙克官×天后为温柔一刀，巳闭口×日德凶中有救；背景三德偏吉而官财禄有实损，净中平偏吉、动而有折。优先次序：入课传＞不入；初传＞末传；主类神状态＞吉将表象（参2026-08-02不验案之教训）。

先迟速：贵人顺行、元胎、斩关、驿马丁马在中传、亥冲日支为速；重审、勾陈、天后、初末冲为迟，量级取月内。两线：青龙属木，得中传亥水生、以末传寅为本家；五行值日则申、亥、寅各主一段；末传寅之合神为亥，用神申临地盘巳。亥同时满足生青龙、驿马值日、月建本气、末传合神、冲日支五条，故取12-07己亥为首选；申为初传值日主文书先到，寅为末传值日主到岗，巳为用神临宫兼日德主补文。若12-07只应消息，12-19辛亥仍在子月水旺窗口。日级低置信，月份中置信，二者不混同。
