## 本次修改

- 保留原问对象、阶段和验收目标。问经营概况不能自行改成近期进项；财通类不能接管全部经营体。
- 对象题首取主类，关系题保留必要双方及其关系。双方属于同一主线，不因一个主类的短答格式删除一方。
- 取用说明来源方法、适用条件及题面如何满足；摘要不足才查连续原文。未知材质、身份、年命不补造；年命未知与已知但不入课传分开。
- 天盘类神与年命地盘上的上神分开表达。命上贵人不自动代表另一位现实人物。
- 测试核对先锁初答，再分别看原案答者怎样取、书中怎样教。不同作者、不同术式及老师评语分开保留；原案和书证有据分歧不硬判错，资料不足不凑正确率。

入口skill、OpenCode agent prompt、短方法及finance/relationship/lost-person-object/travel专项摘录同步更新；工具返回也附同一取用条件提示，程序不自动选类。强弱解释的语义ID仍为61，因为没有修改该套判断方法；本次取用条件ID为class-selection-source-62。
