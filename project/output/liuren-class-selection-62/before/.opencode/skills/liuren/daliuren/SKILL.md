# 分类与取用试验

只认.opencode/liuren-active.json。先tool_help(workflow)确认ready，再liuren_materials(action=method,modules=["class-selection-trial",本问domain])读短规则及分类摘录。主直接短答200—400字；不派裁决、不调用task，不读judgment-core/adjudication/report，不做分数、名次、应期，不查案例库/经验库/旧会话或答案。

流程：固定所问与成功标准→首取主类及可靠坐标→核初传的本题身份和状态→确定关系含义→五行旺衰及切题专项条件→综合主类与发用给简单倾向。初传为固定检查，另加兼看最多一项，不铺开完整报告。

只用五行月令旺相休囚死：寅卯木、巳午火、申酉金、亥子水、辰未戌丑土当令；旺者所生为相、生旺者为休、克旺者为囚、旺者所克为死。内部参数只用quarter-earth，不用four-seasons、不做双表比较。这是月支取气表，不是季末十八日自动算法。支神、天将、日干分别按自身五行取月气；十二气坐处和阴神另核，不互相冒充。

初传必须核查六亲/专类职责、月气、坐处十二气、乘将及闭口/空墓/月破等切题条件。先解释它在本问代表发动、压力、门槛、款项还是结果线索，再说怎样影响问题；同一神兼多职责须分别解释。初传不自动替换首取主类，既不能只看主类分数略过发用，也不能见发用旺便判成、见衰空便判不发生。闭口等专项象义未全部折进数值，不能被较高分数抵消或无据改称消息迟。

本题相关日干、关键类神、官鬼和凶神统一喜旺恶衰。旺鬼凶害减轻，衰鬼凶态显；低分、零不等于无害或不可用。五行克先辨取财、资格约束、制救或侵害；泄干生主类可体现付出。禁止旺鬼→扣低日干→改称身弱→判凶；日干原有衰弱另论。事情是否发生、对本人利弊、岗位待遇/物品质量分开；不能由待遇差判不录用，也不能由不利调动判不调动。衰弱不是不能发动的开关。

需要盘用liuren_chart，同盘复用；初传读取trial_chart_basis.initial_transmission。旺衰、实际作用通路与能否作用分开核查。需要关系补算，先说明本题意义，再compute(strength)，season_profile="quarter-earth"，读取trial_judgment_basis；程序不选类、不裁成败。天盘支、地盘坐处与乘将分清，不能把地盘丑以T:丑提交。已引用日鬼即使未进补算也读排盘解释，不虚构其旺衰或免除衰鬼凶态。

旺衰层级：E=0模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null缺计算；不是可用程度、成功概率或考试分数。旧数量4至6分段及harm_tendency小数不用。输出分类、主类依据、一句初传切题作用、简单倾向和一个关键条件；不列工程清单或额外行动建议。
