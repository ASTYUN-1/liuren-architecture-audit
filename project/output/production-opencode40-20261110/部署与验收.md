## 流程与工具

正式任务通过 `WENHENG_NATIVE_WORKFLOW=40` 直接进入新执行链，旧单模型、强制案例经验检索、13基础模块及11环节记录门槛不再执行。旧代码和旧release仅为兼容、追溯及回退保留，不是新任务的第二套要求。

原问与本档案历史 → 网站服务器固定盘 → 主模型读取当前共用核心及本问专项 → 中性交接 packet → 独立 Sol 裁决 → 实际工具回执与 audit → 主模型五项 review → deliver → 按受众整理网页表达并提交。

旺衰、取数、取象、日历、时间评估、神煞、原书及方法查阅闭包随资源部署。旺衰仍由模型先明确取用及关系，再按原方法选取补算；程序不选类神、不按分数判成败。

固定盘适配逐项核对四柱、月将、三传及十二宫天盘和天将，发现差异即停止。网站已核人物资料与原盘保持，追问复用原盘。模型进程只有单任务网关令牌，没有供应商密钥、数据库凭据或任意Shell/文件/联网权限。该限制是现有宿主权限及代理边界，不宣称另设了OS级租户沙箱。

新版活动资源没有案例库和经验库；没有复制旧客户资料、历史任务或密钥。未删除生产数据库、客户档案、历史发布和回滚备份。

## 网页输出

第40版直接作答规则在独立裁决前生效，网页表达规则在完成技术报告与主核验之后读取。普通用户逐问直答、通俗简短，可附关键依据；卦师保留专业依据。是非给主判或倾向，数值给有依据的估计值与单位，位置依方向和分野给有依据的主选；不随机选边、不编造精度。

取消案例/经验检索门槛、案例比对必引与案例编号/名称的一概禁词；保留凭据、内部路径、真实客户隐私和原始工具输出的保护。完整技术报告、附件与计算回执留当前任务内部证据。未完成核验的报告保留通俗缺口提示，不冒充全部通过。

## 计费边界

两种模型分别保存真实用量及模型身份，不将 Sol 用量套用 DeepSeek 单价。Conpera Sol 单价尚未核实：Sol事件记录为 `conpera-sol-price-pending`，沿原有单项待核账务路径处理，不能把目前的已核供应商成本视为包含全部 Sol 成本。核实后可配置每token纳元的 `SOL_INPUT_NANO_CNY`、`SOL_CACHE_NANO_CNY`、`SOL_OUTPUT_NANO_CNY`；目前未虚填价格。

未迁移数据库，保留018及原积分、冻结、取消、欠费和待核机制，未创建生产测试订单、客户档案或权益。
