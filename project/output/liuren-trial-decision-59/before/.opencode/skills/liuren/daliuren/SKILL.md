# 分类与取用试验

活动版本只认.opencode/liuren-active.json。本机OpenCode当前为class-selection-trial；先tool_help(workflow)确认execution_health.ready，再用liuren_materials(action=method,modules=["class-selection-trial",本问domain])读短规则及专项。只查真正的取用缺口。

主直接短答：分类/阶段→主类及可靠坐标、首取依据→关键状态支持的偏吉/偏凶/暂难定及关键缺口。通常200—400字，小表加两三句即可。详细规范见class-selection-trial。

旺衰与可用性分开判断。本题相关的日干、关键类神、官鬼和凶神统一喜旺恶衰：越旺越有利，越衰越不利；官鬼凶神旺默认不以侵害为主，衰败凶态显。不得把鬼旺解释为侵害大、鬼弱或零解释为无害；不得把身分下降、鬼分高低直接当作考试失败或制救成败。能否实际作用另核职责、位置、通路、受制与时序，不设低分失用开关。泄耗先核去向，泄干生本题主类可体现付出，不默认失败。相关关系可补算，实际作用性质先于分数解释。
统一旺衰层级（不是可用程度、成功概率或分数）：E=0为本模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null是缺计算。4至6不增不减是旧数量修正分段，不用于此处；旧harm_tendency/favorable_tendency小数不参与本轮吉凶裁决。

不创建packet，不调用task或任何裁决、复核、报告交付工具；不读judgment-core/adjudication/report，不跑完整方法计划，不做分数/名次/应期。专项保留的取数及完整报告步骤在本试验不执行。需要盘时liuren_chart，已有同盘复用；缺占时用now。必要坐标/年命查核可用compute的lookup/life/source/chart。先取类再查类神旺衰：盘内单宫旺衰直接复用，关键跨宫生克用compute的strength按已选对象及有依据的关系补算；旺衰必须实际参与吉凶判断，简述它如何影响关键生克、制救及最终倾向；不得只列状态而不用于结论，也不得只列空墓或神煞就定倾向。旺衰数值不直接折成吉凶、概率或分数。

不检索案例/经验库或已知答案；不把程序通过说成取用正确。Codex和旧绑定任务仍走原协议；正式完整版本保留在55版，试验反馈后另行修订。
