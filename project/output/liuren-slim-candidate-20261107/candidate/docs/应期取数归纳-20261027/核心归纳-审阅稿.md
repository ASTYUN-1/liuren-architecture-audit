## 一、先看精简结果

应期保留**六组核心逻辑**：

1. **尺度与迟速**：先确定年、月、日、时的范围和快慢。
2. **对象与支位定位**：用神、类神、落宫等提供时间坐标。
3. **条件满足与障碍解除**：合待冲、墓待破、空待出、缺字待足等。
4. **气势与状态转变**：衰者得生、过旺转衰、关键天将达到事件所需状态。
5. **动作与行程节点**：三马、发用位置、门限二至等定位移动或转变。
6. **数理推算时长**：计算几日、几年，再核对事件关系和历法。

取数保留**六个必要环节**：

1. **定对象**：到底数谁、数什么，取哪一处课式信息。
2. **定数制**：五行生成数、干支数、后天卦数等分别使用。
3. **定运算**：直接取值、相加、相乘、重复累计等。
4. **定增减**：旺衰、月建、月破、空亡等在各自方法中的作用。
5. **定量级**：个位、十位、百位以及进退位。
6. **定单位与口径**：元/两/件/人/里/日，以及总额、部分或净额。

应期的六组是候选方法家族；取数的六环是拆解任一数法时的检查项目。不能把它们理解成每课依次叠加的十二条公式。

两方面共同采用**以支神课传及其位置、作用关系为主体，天干为参助**的定位。日干作为基础取用与生克参照，本就在结构内；额外参看遁干时须说明起法、所附对象及它解决的具体问题。《天一群笔记》明确写“天干是地支象的补充”，不把干层另立为与支层等权的平行主判。【S36—S37】

课体、对象和气势先约束取象方向，旺衰再按所选方法解释状态、相对大小、时态或运算条件。这些职责分开，不把“旺大、休旧、死小”等概括直接兑换成固定倍率或日期。【S37、S43、S46—S47】

## 二、应期的共同前提

### 1. 固定事件和阶段

“何时开始”“何时通知”“何时完成”“何时到手”须分别判断。先确定事件是否有发生依据；没有发生依据时，可保留条件式应期或未定。

《说约》转引强调“用为事始、末为事终”，已动之事才有宜视末传的条件；《壬归》求财段则以财在三传的情况谈末传应期。两者须保留占类和阶段，不能提炼成“所有事都看末传”。【S04、S07、S09】

### 2. 把迟速与精确日期分开

元首/重审、伏吟/反吟、旺衰、初中末、马星和类神离干等，多数先提供相对快慢。初传常速、末传常迟，但《壬归》明确有归日干、入宅临门反速的例外。单条快慢象不能直接换成几天。【S03、S04、S08、S09】

### 3. 时间单位、轮次和数日口径另核

同一支可能对应年、月、日、时；同一支日还会重复。按数日取期时须固定是否包含起课当日；历法上还须固定时区、日界、节气月/农历月。原文不足以区分时，保留未定。

《天一群笔记》解释古例为什么在寅月结束而不是寅日，联用鬼至绝地、救神得旺及课体迟滞；这是状态与尺度共同取舍的研究线索，不是“见寅绝便固定应寅月”。其十四日例又涉及明确的入州起点，不能任意改从起课日起算。【S47—S48】

### 4. 天干按需参助，支位与完整干支日分开

笔记所引古例以末传归计、落酉及“上丁字”解释丁酉日归；雾天例又以壬午青龙参看，因问时已过午时而另查申时。这些可补充T2、T4—T5，不另增一套必用天干法。须核干字来自哪里、附着何处、为何属于同一阶段；“午时已过”也不等于可以默认顺延到任意下一时。【S42、S45】

### T3的几种表述，实际可压缩为四种条件

- **从未动到能动**：静待冲，或具体移动对象受到催动。
- **从被束缚到解除**：合待冲、墓待破、制约者受制。
- **从条件未齐到条件齐备**：虚一待足、某些空待出/填的口径。
- **从已形成到解散/收束**：合局待破、动待合、凶事取散期。

这是本次研究的概念归组。四类条件相近的口诀可合并导航，但具体取冲、取合、填实或取墓的规则仍按原书分支执行。

### 两个值得重点保存的数理例子

1. 《神定经》例：河魁五、落未八，相乘为四十，原文说“四十日之内”。这是**窗口上限式表述**，不可升级成“精确第四十天”。【S27】
2. 《集成五要权衡》“刻日期”：先取生成数，按所得天数核刑冲；若不符合再作数值调整。它表明数日与触发关系可以并用，但倍数选择缺少充分限制，宜列为待检验的专法。【S16】

### 应期的低优先级辅助方法

外应、谐音、字形、度四、拨盘、行年运盘、杂气等另列辅助，不计作新增通用核心。现代《当代壬占汇选》对多项明确写了“推测用法”“原理不明”，不能取消这些限定。其“80%以上”“精确至秒”等自述不作为经过验证的准确率。【S32】

日内三传分段、身命三限保留专项语境：前者有古人卯至酉行路背景，后者用生时课求限数。不能统一成“一传管固定时长”的通法。【S18、S29】

### N5：量级目前能保留的三条研究线

1. **相对大小与进退位**：旺相、休囚、远近等影响大小；仍需解决进一位还是两位。
2. **位置等级歌诀**：“年为万数，月为千，日百辰十时零算”。先校勘年/月/日/辰/时的具体指代、如何取用；不能直接接成“发用岁建即万级”。
3. **主数与零数、单位结构**：干支分主数与零数、两钱分层、生数锭/成数件等。原文存在疑字和例数不自洽，须保留文本问题。

三条都值得研究。目前没有足够依据把其中一条提升为统一量级裁决法。

### 精度与大小位的裁决

精确到个位不必逐位取数，也可能由完整算式直接得到；整十数若作为精确答案，同样需要依据。分别登记**量级、精度和允许误差**，不能把“450附近”与“恰为450”混为一个命中标准。

若采用主数/零数或分位组合，须写清每部分的节点、数制、组合、单位、进位和零的处理；若采用增减修正，须在反馈前固定修正对象、条件及幅度。满分750能排除超过满分的答案，却不能独自证明400或436。当前材料支持研究这些路径，尚不能保证稳定区分相邻个位。

## 五、归并了什么，保留了什么

## 六、剔除、降级与待校内容

### 从精简核心中剔除的错误归纳

- “寅卯应辰＝三合木局末字辰”：混淆三会与三合。
- “相气相加、相乘、再倍只是同一种规则”：运算实质不同。
- “旺就加倍、休囚都减半”：把具体流派和条件抹掉；现代《射覆指掌》IF表不可代替诸本原文。
- “吉凶减七成＝金额减七成或时间减七成”：对象不同，所读引文不足以支持这种迁移。
- “四建时间层级已经证明数量级”：从相邻段落跨接，尚缺执行依据。
- “所有旬空都不应”“所有填实都能成”“末传恒为完成日”：均存在文本分歧或适用条件。
- “多本书都这样写＝多次独立验证”：转载不增加验证次数。

剔除指不纳入本稿核心，不删除原书，不覆盖原始记录。

## 七、八字与其他体系的对应边界

八字资料提供的可用对应是：**先明确原局结构与喜忌，再看大运流年怎样扶助、克损、合去或解除条件**。《子平真诠评注》强调运字须与原局统观；《滴天髓阐微》按彼我、强弱、喜忌区别冲会；梁氏待校讲义另有岁运凑齐组合的讨论。【S33—S35】

它与六壬T3/T4的概念有可比较处，但排盘对象、取用和时间层级不同，分别执行。本次抽核未形成可由八字原局直接稳定算出某笔现金金额的完整数值规则；“财旺”“富贵”等相对层次不能自动兑换成几十万或几百万。此为本次材料结论，不断言所有命理文献均无此法。

《六壬神课金口诀古本》采用四位等自己的结构，检索命中单列，不能把人元、贵神、将神、地分直接塞进大六壬四课三传。六壬命法/身命三限也保留专项边界。

## 八、供审阅的最短执行链

**应期**：定事件和阶段 → 定尺度、迟速 → 绑定对象 → 从T2—T6选有条件的主路径 → 比较其他轮次和相邻日期 → 校历并固定答案。

**取数**：定对象和单位 → 固定数制与取数节点 → 按一个有源算法运算 → 按该算法处理增减及组合 → 单独裁决量级与精度 → 给出点值或明确未定环节。

两者共同保留三条纪律：

1. 反馈前写明为什么选它、为什么排除最强竞争答案。
2. 没有区分量级、轮次或相邻日期的依据时，如实保留缺口。
3. 原预测、反馈、注解和复盘假说分开；符合一条算式不等于已经验证整套方法。

当前最需要继续验证的接口是：**取数节点怎么选、加乘及倍数怎么选、数量级怎么选、精确数的组合和修正怎么选、应期的尺度及这一轮怎么选**。原例、注释、复原假说分别登记；命中与未中并列，无原断反馈不计命中。本稿完成归类与研究整合，不将待校或未验证分支直接写入正式运行规则。
