# 八字知识提取与重整

本技能负责两个核心任务：
1. **提取**：从八字古籍中批量化、结构化提取判断规则、技法、命例
2. **重整**：对八字经验库进行格式统一和内容洗练

> ⚠️ **与六壬分离原则**：本技能只处理八字内容，写入 `八字经验库/`。六壬内容走 `liuren-extract` → `经验日志/` + `案例项目库/`。两者绝不混写。

---

## 核心原则

> **绝不尝试一次性读完一本书。** 几十万字的书，AI 读不完、读不好。正确的做法是：**关键词定位 → 分批提取 → 断点续传。**

> **蒸馏目标：留精华，剔冗余。** 只保留：
> - 判断规则（当 X 时，断 Y）
> - 技法（取用神法、调候法、格局法操作步骤）
> - 关键概念定义（有实操价值的）
> - 经典命例（可做类比的）
>
> **剔除**：
> - 冗长的无意义列举（重复的例子、流水账）
> - 纯背景/历史叙述
> - 歌诀堆砌（除非歌诀本身就是判断规则）
> - 与断命无关的文学性内容

---

## 前置条件：源文件必须是纯文本

提取前，确认来源文件是 `.txt` 或 `.md` 格式的纯文本文件，存放在 `书籍库\八字书籍\` 下。

---

## 三阶段流程

```
阶段一：建索引（只扫一遍，找到所有相关位置）
  ↓
阶段二：逐批提取（每次只处理一个主题的一个章节段）
  ↓
阶段三：写入归档（去重后写入八字经验库）
```

---

## 阶段一：建索引

### 目标

用 `grep` 对全书做一次全量扫描，记录每个主题关键词在书中的行号位置。**这一步不读正文，只读行号。**

### 操作

对每个主题，用 `grep -n` 搜索关键词，输出命中行号列表：

```bash
# 示例：搜索调候主题关键词
grep -n "调候\|寒\|暖\|燥\|湿\|冬\|夏\|喜\|忌" "书籍库/八字书籍/某书.txt" > "八字经验库/_索引-某书-调候.txt"
```

### 索引文件格式

```
行号:匹配行内容摘要
1423:庚金生于申月，壬水为先，丁火次之...
1856:正官格成，财印相辅，无刑冲破害...
2301:身强用官杀，身弱用印比...
```

### 断点记录

在 `八字经验库/_进度-某书.txt` 中记录处理进度：

```

索引完成时间：2026-07-31
已处理主题：调候（230行中已处理1-80行）、格局（未开始）
下一个待处理：调候 第81行起
```

## 阶段二：逐批提取

### 策略

**每次只处理一个"批次"**——一个主题的一个小段（约 10-15 条命中行），读完正文后提取经验，写入，然后更新进度。绝不一次处理超过 15 条。

### 单批次操作

1. 读取进度文件，确定下一个待处理的位置
2. 从索引文件中取该主题下 10-15 条命中行号
3. 对每条命中行，用 `Read` 工具读取该行前后 ±20 行的上下文
4. 从中提取判断规则、技法或命例
5. 写入八字经验库（追加模式，不覆盖已有内容）
6. 更新进度文件

### 单条提取判断

| 类型 | 判断标准 | 输出格式 |
|------|---------|---------|
| **判断规则** | 有明确的"当X时断Y"结构 | 写入 `八字经验库/古籍-[书名]-[主题].md` |
| **技法** | 取用神/调候/格局等操作方法 | 写入 `八字经验库/技法-[书名].md` |
| **命例** | 含完整四柱+断语（可类比） | 写入 `八字经验库/命例-[书名].md` |
| **剔除** | 冗余列举/背景叙述/无判断价值 | 跳过，不写入 |

### 判断规则格式

```markdown
<!-- META: 主题=调候 | 日主=庚 | 月令=申 | 喜忌=壬水为用 | 来源=穷通宝鉴 -->

### [序号] 调候 · [关键词]

**判断规则：** 当 [条件] 时，应断为 [结论]，因为 [依据]

**原文：** [摘录原文，保留原始表述]

**来源：** [书名] [章节/行号]
```

### 命例格式

```markdown
<!-- META: 类型=命例 | 日主=甲 | 格局=正官格 | 旺衰=身强 | 用神=财星 | 来源=滴天髓 -->

### [序号] 命例 · [简要描述]

**四柱：** 年[X] 月[X] 日[X] 时[X]

**断语：** [原书断语]

**验：** [应验情况，如有]

**可类比特征：** [格局/旺衰/用神/大运等可匹配字段]
```

## 阶段三：写入归档

### 写入路径

| 内容类型 | 写入路径 |
|---------|---------|
| 判断规则 | `八字经验库\古籍-[书名]-[主题].md` |
| 技法 | `八字经验库\技法-[书名].md` |
| 命例 | `八字经验库\命例-[书名].md` |
| 索引文件 | `八字经验库\_索引-[书名]-[主题].txt` |
| 进度文件 | `八字经验库\_进度-[书名].txt` |

### 去重规则

写入前，在已有八字经验库中 grep 搜索相同关键词组合。**主题 + 日主 + 月令 三者一致且规则结论相同即视为重复，跳过。**

### 每批次完成后汇报

```markdown
## 📊 批次汇报

| 书籍 | [书名] |
| 主题 | [主题名] |
| 本批处理 | 第 N-M 条（共 230 条） |
| 提取判断规则 | N 条 |
| 提取命例 | K 例 |
| 跳过（重复） | J 条 |
| 跳过（冗余剔除） | L 条 |
| 累计进度 | 已处理 80/230（34.8%） |
| 下一批 | 第 81 行起 |
```

然后询问用户：**"是否继续下一批？"**

---

## 进度恢复

如果中途中断，重新执行时：

1. 读取 `八字经验库/_进度-[书名].txt`
2. 从上次中断的位置继续
3. 已写入的经验文件不会被覆盖（追加模式）

---

## 完成后处理

全部主题提取完成后：

1. 删除索引文件（`_索引-*.txt`）和进度文件（`_进度-*.txt`）
2. 输出汇总报告：

```markdown
## 📊 全书提取完成！

| 书籍 | [书名] |
| 全书总行数 | N |
| 提取判断规则 | M 条 |
| 提取命例 | K 例 |
| 剔除冗余 | J 条 |
```

3. 建议用户手动抽查 3-5 条提取结果，确认质量。

## 重整模式：洗练已有内容

### 触发条件

当用户说以下内容时，进入重整模式而非提取模式：
- "重整八字经验库"
- "洗练八字经验"
- "统一八字格式"
- "优化八字古籍蒸馏"

### 重整目标

让每条内容达到"**3 秒可检索、10 秒可判断**"的标准：
- META 标签行放在文件最前面，grep 一下就能精确命中
- 核心判断规则用一句话写在最前面
- 剔除冗余，格式统一

### 古籍蒸馏重整的特殊要求

1. **原文不能改**：古籍原文摘录保持原样不动
2. **补充 META 标签**：在每条判断规则前面加上 `<!-- META: -->` 标签行
3. **补充判断规则行**：如果原文只有摘录没有提炼，AI 从原文中推理出规则并补充
4. **标注 AI 补充**：AI 补充的内容用 `<!-- AI补充 -->` 标记，方便用户区分和审核

```markdown
<!-- META: 主题=格局 | 格局=正官格 | 喜忌=财印 | 来源=子平真诠 -->

### 15 格局 · 正官格成格条件

**原文：** "正官之格，财印相辅，无刑冲破害，方为成格。"

<!-- AI补充 -->
**判断规则：** 当正官格官星透出 + 有财或印相辅 + 无刑冲破害时，格成为贵。

**来源：** 子平真诠评注 卷一
```

### 重整流程

```
用户指定重整范围（全部/单本/单主题）
  ↓
[步骤1] 扫描：列出目标目录下所有文件，统计数量
  ↓
[步骤2] 诊断：抽查 5-10 个文件，列出格式问题清单
  ↓
[步骤3] 确认：向用户展示诊断结果，确认后开始重整
  ↓
[步骤4] 逐批重整：每次处理 5-10 个文件
  ├─ 读取原文件
  ├─ 提取元数据（主题/日主/月令/格局/喜忌/来源）
  ├─ 按标准格式重写，剔除冗余
  ├─ 覆盖原文件（或输出到新文件，用户选择）
  └─ 汇报本批结果
  ↓
[步骤5] 汇总：重整完成，统计新增/修正的元数据标签
```

## 与现有系统的衔接

- 八字主技能 `bazi` 的步骤 6.0 通过 grep 搜索 `八字经验库/古籍-*.md` 获取判断规则
- 命例文件用于"类命例"类比（对应六壬的案例类比，但来源是经典而非实战）
- 提取过程中产生的 `_索引-*.txt` 和 `_进度-*.txt` 是临时文件，完成后自动清理
- 索引格式规范见 `八字经验库/_metadata_schema.md`（八字适配版，与六壬版分离）
