# 关键类神旺衰与制化：裁决依据研究稿

## 一、本轮结论

用户提出的方向有明确书据：裁决应着重考察关键类神本身是否得气、能否作用，以及与所问主体、其他类神、四课三传、年命之间的生克制化、刑冲破害。不能把盘上所有吉凶词排成两列，再凭数量或语气折中。

其中要分清三件事：**有这种关系，这种关系能否实际起作用，这种作用是否足以决定所问结果。**“克”“害”“墓”在盘上出现，不等于已经证明结果会降低一档；“旺”“贵”“禄”出现，也不等于已经证明最高档。

北海《理法简易》“类象分析的方法”提供了本轮最直接的骨架：察天、察地、看人。它与《壬归》的五气、加临、制救相衔接。以下对裁决流程的组织属于本轮归纳，不冒称古籍原有的统一算法。

## 三、“旺鬼难克身”应如何准确使用

本轮找到了相关明确说法，但不能把用户举的概括直接登记为无条件通则。至少存在三种不同依据。

### 1. 身或所责类神旺，不易受到伤害

E04的“主象旺相则不甚惧克制”，以及E17的“死火克不动旺金”，讲的是承受者与施作用者的实际状态。这接近“弱克不足以伤旺”的力量比较。

这里首先核的是：谁旺、谁衰、谁来克谁。不能把“身旺不易伤”偷换成“鬼旺所以克不动身”。

### 2. 鬼本身当旺，按“贪荣”解释暂不害我

E21《毕法赋全解》解释“鬼贼当时无畏忌”，以日鬼处四时旺气、贪荣旺不来害我说明，并举春占木局作土日之鬼。正文还提醒鬼衰后可能生患，宜及时处置。

E20《指南注解》也说：“如旺鬼克我，彼自贪荣，亦以吉断；衰鬼克干，却要深忌。”**同段紧接着又说：“但旺神与日上相刑不以吉论”。**因此，不能截掉相刑例外，只保留“旺鬼吉”。

这是一种原法中的性质、作用取向和时机解释，不是说鬼的五行克力因旺而物理性变弱。E21对坏人心态的譬喻属于作者解释，也不能当作现实人物必有的心理事实。

### 3. 鬼旺而临身，另有“鬼禁日”的不利判断

E15《壬归》出行章明确说：“凡日上之鬼，休则难动，鬼缠身也。旺则难当，鬼禁日也。”又强调日上鬼发用并乘凶将更不宜轻动；旺鬼乘吉、仕宦出行则另论。

北海《理法简易》E05、E07同样保留了鬼禁日、鬼缠身之说，E07还解释为旺衰在发作快慢、阻滞气势上有区别。

所以，“鬼贼当时”与“旺鬼禁日”之间，已有位置、占类、刑害、发用、所乘将及身份差异可查；但本轮没有得到一条足以完全消除所有交叉冲突的统一边界。必须保留这个缺口，不能临时挑一句迎合希望得到的结果。

**候选约束：适用“旺鬼贪荣”之前，必须同时检查日上鬼、鬼发用、相刑、凶类并聚及所占身份等反向条件。条件交叉仍未解决时，明列冲突，不自动以旺鬼不伤覆盖。**这是本轮制定的防误用约束，不宣称为古籍明载的完整优先级。

## 四、两处需要防止混用的理论口径

### 十二长生的参照

E02、E11、E12：北海与《壬归》允许看主象或应责类神自身五行在临地、阴神上的十二气；也另看日辰与三传的十二气关系。

E18：《六壬笔记》则有“一个六壬盘的十二长生气以日干为准即使太极点转换”的明确说法。

这两种表述存在口径差异，不能静默混用。按本次以关键类神审查为主的设计，可以选择北海／《壬归》的类神自身口径作为该项主方法，同时单列日干参照的关系；这是方法选择，不能宣称所有书已经一致。

记录时应写“酉金自身临申为何运”或“某支为日干之墓”，不要只写一个没有参照的“墓”。北海E05还明确五行同长生、水土生申；不能混入出生推命的阴阳干顺逆长生。

### “得生”与“贪生”

E03有“类神临生临合，自贪其荣，不能为我所用”，鬼煞临生合也可不来伤我；但E05、E06又有生鬼使灾增、扶鬼复起的判断。

因此，“生”至少要问：生起了哪一方、那一方原本要做什么、这次生究竟使它有力施作用，还是按原法取贪恋而不施作用。不能统一为“生必有利”，也不能统一为“受生就不克人”。交叉未明处列待核。

## 五、据此形成的裁决方法

以下为本轮基于书据形成的候选方法，尚未作为活动规则执行。

### 第一步：确定所问结果与关键类神

明确本次问的是成败、取得、排名、金额、时间，还是过程。按占类取主体、目标与关键关系，说明各自所据，保留必要的竞争取用。

结果涉及不同条件时，分别设问：有财、可取、取得多少，不应由同一个“财旺”包办；官鬼在功名占可以是目标，在疾病占可以是病邪，吉凶身份先定。

### 第二步：给每个关键类神建立状态

| 检查项 | 必须说明的内容 |
| --- | --- |
| 所在位置 | 干支上、发用、中末传、年命等；是否与本问题有关 |
| 四时五气 | 旺相休囚死及判断依据，不拿日干六亲冒充四时五气 |
| 空亡等限制 | 本法采用的空亡口径、实空条件及待核处 |
| 十二长生 | 谁的五行，以何处为参照，采用哪一来源口径 |
| 临地与阴神 | 生、克、合、刑、冲、破、害分别指向谁 |
| 神将关系 | 所乘将及生克、夹克夹生、内外战；不可只凭将名定吉凶 |
| 制救条件 | 救者自身是否有力、受伤，位置能否制救，是否反被生起凶神 |

不把上述状态折成统一旺衰分数，也不凭“月旺”抹掉其余状态。

### 第三步：逐条核实际作用

对足以影响主判的关系，写清：**谁 → 对谁 → 通过何种关系 → 双方状态如何 → 是否受制或获救 → 对本问意味着什么。**

例如，不能只写“末传官鬼受克，所以排名下降”。应核该官鬼是否确为本问排名类神、谁克它、施克者是否有力、所论位置是否可作用、有无化救，以及有效受伤为何足以影响排名。链条缺哪一环就说明哪一环未定。

作用结论可记为“有据成立／条件成立／条件不符／尚未裁明”。这些是研究记录用语，不是古籍术语，也不是概率。

### 第四步：沿课传始终复核变化

发用是重要起机，必须纳入；但初、中、末及年命的制救不能省略。既核初传之强，也核中间是否改变其作用、末传是否成救或成害。

E05中北海明确区分“发用之鬼末传可制”与“末传之鬼发用不能制”。此处应保留原法时序限制，不能为了让全局看起来平衡而任意互制。

### 第五步：用决定结果的作用裁决主次

证据的主次取决于它是否直接触及本问的关键条件、关系是否有效、是否经过制救改变。不是“正方六条、反方四条”，也不是一律“发用胜过其余”。

反向信息只有被证明作用于结果关键处，才足以改变主判；如只足以说明反复、阻隔、延迟或取财后患，应在对应层面交代。另一方面，不能为了维持原主判，把所有不利都未经核查降格成过程波折。

出现真正足以改变结果的反证，应回核全局；尚无能力分胜负时，保留未定。不能以“审慎”为名默认选中间档，也不能以反折中为名默认选最高档。
