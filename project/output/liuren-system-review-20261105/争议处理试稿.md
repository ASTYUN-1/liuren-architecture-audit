# 未决问题怎样收束：首轮尝试

本稿区分可纠正的整理错误、可拆清的职责混用、真实方法分歧和需要反馈检验的效果问题。以下均是研究或候选修订，本轮未改活动包。连续原段、原字节哈希与LF行号见[争议原文证据](争议原文证据.json)。

## 1. 已能核清的摘要错误

活动void模块“空亡总纲”同时写“吉神不宜空”和“吉神空亡喜落空”。《理法简易》LF2744–2745明确区分“凡凶神刑冲破害，宜空；若生我救我者，不宜空”以及“吉神不宜空，凶神宜空”。

因此“吉神空亡喜落空”作为该段的概括，方向写反，应在候选修订中撤去或纠正。这不需要占断反馈证明，也不应继续列成术理异说。原件与旧版保留；对其他段落“某凶神空反凶”的争议不能据此一并裁定。

状态：**摘要方向错误已核实；活动规则尚未改。**

## 2. 青龙和财爻：可分清体系，不能宣称已经统一

《壬归》LF285明确“求财之占，先以青龙为主”；后续分神将得气、类神临地、类阴与本人取财条件。北海《理法简易》LF2777–2778解释青龙空亡时明确说“实质上求财看财爻”，又提出青龙空而财爻不空仍可得财。

这使得“青龙、财爻、所求物类都要看”还不够，必须说明谁在所采用方法中承担什么职责。

候选处理：以北海思路组织求财时，优先按该文本确定财爻及本问财物类，再核其与本人、他方、课传、阴神的关系；青龙按相关财将或切题功能参看。复现《壬归》例法时则保留其青龙主线，不能一边删去其前提，一边调用其后续强断。两条路径可做对照，不能作为两票独立证据。

这是一项与用户“北海优先”相适应的候选选法安排，不等于已经证明财爻法比青龙法预测更准，也不意味着可以忽略《壬归》的细致关系分析。其他占类是否存在同样分歧，需要另核。

状态：**不同原文取用口径已核清；统一后的实际优劣未解决。**

## 3. 有生解空：先避免表示混乱，再研究真实分歧

《特训班讲义》LF78–81在分房例中先见亥空而转为待辨，再以旺相及生扶判可得，提出“旺不为空，得生得助不为空”。《理法简易》LF2749却直接批评“有生不为空”，说有生也为空，只是有些不空的意向。不能无依据认定两者必然属于不同时期，也不能替作者发明一条“普通生扶不算、特殊生扶才算”的分界。

目前可以先解决的是规则表示：

| 层次 | 要记录的内容 | 不能混成什么 |
|---|---|---|
| 原局事实 | 哪个对象旬空、落空或坐空，按所用定义分别标明 | 得生后直接删除程序旬空标志 |
| 力量与作用 | 自身气态、生扶来源、通路及制约 | 看到一个生字即宣布成事 |
| 事件实现 | 所选原法如何从上述条件判定能否获得、完成或受用 | 把“有些意向”自动当成已经实现 |
| 应期 | 出旬、填实等在所选方法中意味着什么 | 用候选日期反过来证明事情必成 |

这四层是本轮为避免混用提出的整理方式，不冒充北海已经提供的完整和解理论。

《壬归》LF293还明确区分：神临空地，即使所临为四吉仍非吉；“神生其将，而神自作空者”则尚有出旬之望。**神生将**与**类神得到其他节点生扶**并非同一条作用，不能都压成“有生解空”。这里已经能拆清一部分表面矛盾，但仍不能消除北海两本文本的直接张力。

继续研究的办法：先收集同一空法、同一对象、相近占类下的作者解释与完整课例，逐例记录空的类型、月令、临地、生扶者、课传位置、作者实际所用理由和原载结果。比较能否找到原文明示的条件区别。没有原文支持的区别只列研究假设，不升级规则。

然后把候选解释先固定，再用未参与归纳的材料或新可核事件检查；已读分房例只能做方法复现。若证据仍不足，候选版保留有身份的两路方法及对本问结果的影响，不能由模型临场择吉凶口径。

状态：**坐标与作用方向等混用可拆；“生扶在什么条件下足以支持实现”仍待解决。**

## 4. 凶神宜空、玄蛇空反凶

《理法简易》LF2772谈凶将空亡而无力，LF2800–2802在十二天官作日鬼空亡的断语后谈玄武、螣蛇空反凶。这里至少存在不同语境：一处侧重凶性作用是否得力，一处侧重具体事类及作鬼断语。

可以先把两组记录分开，保留角色、是否作鬼、空的位置、所问事情和实际作用，取消“所有凶神逢空一律免祸”或“一律更凶”的合并摘要。但LF2802本身也用了“一般说来”作扩展，不能仅凭分节语境就宣称已找到互斥、完备的条件分支。

继续回查本书其他解释及作者课例；若条件无法互斥，保留同书异说。不能为了让程序只有一个答案而虚构优先级。

状态：**可以阻止错误合并；尚未完整化解原书内部张力。**

## 5. “作者警告”和后加评论混在一起

当前模块在“作者在书中警告的失败模式”下面出现“命中率未必高于随机”等评价。已回查本机《理法简易》《六壬金针》相关关键词，没有取得这些句子是原作者原话的证据；这一有限检索不能证明所有版本都没有，也不能据此确定最初评论者是谁。

候选处理无需等待全部历史作者身份查明：把能够逐段核原文的作者意见放回来源方法；把尚无作者引文支持的评价标为“整理层评议，原始评论者待核”，放在研究/效果评议中。普通断课只保留必要的可操作约束，例如结果预先说清、避免事后换法，不反复插入尚未证实的随机水平结论。

同时避免另一个推断错误：未获得统计验证，不等于已证明低于或等于随机；书内全部果应也不等于已证明高准确率。

状态：**当前归属不应当作已核作者原话；最初生成来源仍待查。**

## 6. 系统内部双重指令

例如adjudication前言限制将名调制，后文仍用四象限给终局；period-outlook先要求安全不过其余维度全部打折，又说不能由单象压低各维。这类问题首先是执行规程冲突，不能全推给古法本身。

处理办法：每项写成“现行条款A／条款B→各自来源与原条件→候选执行条款→保留原文位置→依赖模块”。一个争点只有一个明确的当前执行位置，其他位置引用它。历史原论保留，但不再与当前条款同时以命令语气执行。

验收不仅查文件哈希，还要换阅读顺序试走同一课例，检查是否因为先读某条就改变选法、对象或结果；若有变化，回查是否尚存双重指令。这是流程一致性检查，不是预测准确性测试。

状态：**有明确工程与语义修复路径；尚未完成候选条款及全套实施。**

## 7. 每个争议怎样算推进或结案

每项登记：争议的具体句子、来源版本、对象与条件、两种结论、对本问影响、已经排除的混用、待查材料、下一项能够区分两种解释的证据。

- 能由原文核清的摘要错误，以文本纠正结案。
- 能由对象或职责不同拆开的，形成带条件分支，不能只写“综合判断”。
- 真异说须找到原文区别、明确选择一条候选方法并检验，或保留公开的未决分支；不强行伪装统一。
- 预测效果必须另取可核材料检查；不能用整理完整、引用正确或运行成功结案。

下一批优先处理空亡、求财取用、神将组合调制和侧重选择四个问题，因为它们同时影响多个模块。完成共同口径后再把专项逐一迁入，避免每个专项各自发明一套总则。
