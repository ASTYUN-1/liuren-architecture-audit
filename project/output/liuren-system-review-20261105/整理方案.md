# 大六壬技能体系首轮整理方案

本稿是研究与整理方案，不是已启用的新规程。首轮已核活动入口、模块清单和部分关键正文，并重点研读北海闲人与《壬归》相关原段；没有逐条审完59个模块，没有完成全书精读，也没有独立预测验证。本轮不改活动指针或冻结运行包。

## 1. 整理的中心：让理气贯穿取类和察类

建议保留用户确定的“理气为主”，把执行方式改为：**以理气为准则，因本问定侧重，围绕课传与关键类神形成一条判断主线。**

上轮“先独立定完全局结果，象法只能事后描述”的限制过窄。它容易把类神、神将与特定组合中原本用于辨事、断事的部分也一起降成修辞。原书支持调整这一点，但不支持给理气、象法各自打分再投票。

北海《理法简易》说：“类象是六壬判断的核心内容，但无论取类和察类，都要以理气为依据进行。”又说：“课体看大象，类象定吉凶，理气为准则。”《特训班讲义》以“明占类，定侧重，看显象”组织判断，所谓“看显象”包括辨类神、课体的真假、空陷和变质，不只是描绘形貌。

因此需要先澄清三个概念：

- **整体课势不是理气的全部。** 关键类神自身得气与否、和四课三传及其他类神的作用，就是本问理气的重要内容。不能把“大课体吉”叫理气，把“切题类神受伤”叫象法，然后强令前者胜出。
- **类象不只是辞典象义。** 取人取物、确定主客和目标、识别切题组合、辨具体事端，都可能参与判断。形貌、职业等描述只是其中一部分。
- **气不只等于旺衰生克。** 北海还论进退、缓急、虚实、气势、类聚等。但这些原书论述仍须逐项审条件，不能借扩充“气”的定义，把所有吉凶标签重新包装成理气。

本稿对概念、权限和流程的划分是整理建议；引用原书不等于这些工程划分都是作者原话，也不等于书中强断已获现实验证。

## 2. 主线如何运行

北海的“三步走”适合作专业主线，排盘、核查、检索、交付围绕它服务。拟定的运行方式如下：

| 阶段 | 要解决的问题 | 主要操作与回查条件 |
|---|---|---|
| 核题核盘 | 到底在问什么，怎样才算发生或成功 | 固定人物、阶段、期限与已知事实；可靠排盘；单事、阶段泛占、出生推命分流 |
| 明占类、观课势 | 哪些信息与本问亲切，课传呈什么态势 | 通看四课三传及气势；据问取主类神和相关类神，不先把课名定成终局 |
| 定侧重 | 本课主要应从哪条线入断 | 结合占类与课传特征，说明侧重类神还是切题结构及理由；其他信息留作相关补充和反证 |
| 察类、辨真伪 | 这条线实际能不能成立，怎样发展 | 连看关键对象的位置、现隐、气态、神将组合、直接阴神、课传传递、彼此作用与制救；相关细节随主线展开 |
| 收束判断 | 主结果、过程、程度各有什么根据 | 处理最强反证；分清不同对象、阶段与结果；需要时回查定位或选法，不维持一个不可修改的早期定论 |
| 定期取数、查漏与参照 | 时间数量能细到哪里，有无遗漏或方法误用 | 按需定期取数；保留八煞九宝、32项等覆盖；盘面初判后分别检索案例和经验，修正须重新落到本盘 |
| 交付 | 是否真正回答了原问 | 完整正文交代判断、决定性依据、反证取舍、来源与缺口；同一作用说明一次，避免机械重复 |

“观课势”是取得全貌，“定侧重”是选切入点，都不是在检查关键类神之前冻结成败。侧重也不是永久排除其他信息；有具体理由才能调整，调整后须重核受影响结论。

现有十一环节可以先保留为覆盖映射与工程检查表，不再直接等同于思维顺序或固定十一段报告。这是待实施建议，不在本稿中取消任何现有必查项。八煞九宝、32项仍需完成基础核查，决定性信息应在有关节点及时参与，而不是等正文已定后才补标签。

## 3. 类象权限怎样放宽

适当放宽的是**有方法依据的断事功能**，而不是孤立名词改判的自由。

| 功能 | 拟允许参与的判断 | 相应约束 |
|---|---|---|
| 取类与定位 | 确定人物、目标、主客、具体事项；发现错取时修正判断主线 | 交代本问、占类依据和课位；一个节点多义时辨职责，不随结果任意换角色 |
| 切题结构与组合 | 有条件地判断事情能否出现、性质、过程及特定变质；可以影响主判 | 按所用原法核取用、位置、组合和适用条件，检查真伪、空陷、气态、制救等相关限制；不能只凭课名或将名 |
| 事象与细节 | 区分同一作用通过什么人、什么事、什么形式表现，也可揭示此前漏看的具体争点 | 细节须有对应位置或专法根据；多解并存时保留范围，不能把故事丰富度当证据 |

不要求每条专门象法都强行改写成五行生克才准进入判断；这会把原书方法改造成另一套体系。但专法必须按自己的成立条件接受审查，也不能凭“这是象法”免除理气约束。无法判定专法与通法的适用关系时，登记未决，给出结论分支，不暗中选一个。

主结果、过程、程度与应期都应有依据，不规定象法永远只能影响程度，也不允许“吉中有忧”等空泛修饰自行增加损失。是否改判取决于新发现改变了哪个关键条件。

## 4. 出现不匹配时，不让两套系统各判一次

把争议还原成具体问题，按以下顺序处理：

1. **先核是不是同一件事。** 能获得和能受用、短时推进和最终完成、得财和因财招患，可以同时存在。说明各自对象与阶段，不用一句“吉凶参半”掩盖差别。
2. **再核定位和参照。** 是否把泛占的课势当单事结果，把神将名称当有效作用，把类神自身十二气与日干十二气混用，或把类神与其阴神的职责混用。
3. **再核方法是否成立。** 原法适用的占类、课位、组合、空陷和制救条件是否齐备；同根信息不按多个吉凶标签重复计算。
4. **比较对本问的实际作用。** 谁直接影响目标或关键环节，谁只是背景或性质。不能预设全局课名永远压过类神，也不能预设一个类神永远压过切题结构。
5. **最后处理真异说。** 记录来源、条件与不同结论；不得为贴合反馈临时换法。能凭原文解决的解决，尚无依据的保留，不编造作者年代先后或和解条件。

《壬归》求财论“专视青龙则失之拘，遍推寻而无所主则失之荡”，正适合作为选线提醒。其细论又分财将、财神、物类、日辰、阴神及课传：财本身得气，不等于本人能无患取得。这里的类与气贯通于同一件事，并非两个吉凶裁判。

## 5. 用原书断例检验这条流程

北海《特训班讲义》的单位分房例，作者先以亥为楼阁、临干取获得之象；再见亥旬空，把能否得到转为待辨；继而考察酉月相气、支上申生亥、申入中传及与太岁的关系，作出可得房判断。返吟、其他组合又用于解释反复和不满。

适合复现的是这条操作链：**问分房 → 选房屋类神为侧重 → 临干与空亡一起察 → 查气态和生扶 → 收束得失与过程。** 不是先独立判全局成功，再给房子配象；也不是见楼阁临干就直接成功。

但本例只能说明作者如何操作。原载“亥月末事果应”是书内反馈，不是本轮独立验证。其“得生得助不为空”与其他材料“有生亦空”有口径张力，需另作专题审查；本稿不凭这一个例子确定普遍空亡规则。

## 6. 全套审查的范围和次序

当前有4个活动技能入口、59个内部模块，其中14个共同必读、16个占类专项。三项专门入口还会加载归档完整规程。整理范围因此要包含入口之外的实际指令来源：AGENTS、本机模式提示、入口、路由、模块正文、参考资料、加载器、检索回流与报告要求。

首轮已发现下列问题，详细位置见调用清单与原文笔记：

| 优先级 | 已核问题 | 处理方向 |
|---|---|---|
| 高 | 新总则把象法限制为描述，与北海察类断事的操作不合 | 改写总纲与权限；不继续叠加一段更高优先级前言 |
| 高 | adjudication前言限制将名调制，旧正文仍用四象限给终局 | 逐条辨原论、当前执行条件与历史解释，形成唯一清楚的当前口径；原文另留 |
| 高 | period-outlook同时有“安全不过其余全部打折”和不能由单象压低各维 | 分清泛占与单事、背景与分项，不无条件复制统一缩放 |
| 高 | void内不同空亡说及变质断语并列 | 做来源与适用分支，未决处明示；禁止事后挑口径 |
| 高 | 部分“作者警告”包含统计偏差等评价，作者身份未核清 | 回溯出处；核清前不能作为北海原话，保留为待查评论 |
| 中 | 十一环节、正文覆盖与报告小结可能重复驱动分析 | 主线、查漏表、交付结构分开；保留深度，减少重复读取与复述 |
| 中 | cases/extract/tuiming仍分段加载旧完整规程 | 审旧新指令、路径和返回入口；归档存在不等于应再次启用旧技能 |
| 中 | long-period含逐限四象限等专法 | 与单事和阶段泛占分开审，不默认总纲改动已验收出生推命 |

每个模块最终都要回答：解决什么问题、何时进入、前置资料是什么、依据来自哪里、条件与反证是什么、与其他模块哪里重复或冲突、什么情况下结束或回查。方法正文的逐条语义审查与机器链接检查分别登记。

建议分四批推进：

1. **先建立专业底稿。** 北海《理法简易》《特训班讲义》优先，结合《六壬金针》核实际操作；《壬归》重点核气、类、主客、神将、阴神与制救。按问题精读连贯原段，保留不同文本口径，OCR疑字不擅改。
2. **再整理共同主干。** 总入口、取用、理气、空亡、课体、神将、动态、裁决和交付一起协调；先写候选规程，清理多层指令冲突，不直接覆盖冻结包。
3. **选占类试走，再扩展全套。** 建议先以求财、婚恋、求职作试整理，分别检验取与受用、双方关系、阶段与最终结果；这些是试选类别，不冒称已证明是用户最常用。阶段泛占、长期与出生推命另路审查，再覆盖其余专项、维护与提取入口。
4. **完成方法复现和工程检查后再考虑启用。** 用已暴露原书例检查能否按原法走通，用历史失败或反例检查是否遗漏条件，用真实加载与跳转检查入口一致性；三者分别记结果。候选方案、变更清单、回退方案先做具体，最终再按用户指示办理活动切换。

不为了统一而删除异说，不把每本书都拆碎后拼成貌似一致的“古法”。北海优先组织思路，《壬归》作为重点核对来源；有分歧时列明，不以书名次序自动抹平。

## 7. 怎样验收，用户需要看什么

用户不必承担逐文件审查。整理时提供三个可审结果：一张完整调用图、一份带原文条件的专业总纲、少数具体课例的新旧流程对照。只有会改变判断方向、来源取舍或方法权限的重要分歧才提给用户。

验收分别记录：

- **来源与语义：** 当前指令能追溯原段，作者与后人评论身份清楚；没有通过删条件使原法变强，也没有任意加条件使其失效。
- **专业流程：** 能说明为何选侧重、关键类神如何联系课传及彼此、反证改变什么；同题不会因模块先后或吉凶标签数量随意翻判。
- **调用与交付：** 模块能找到、触发与依赖明确；旧入口不绕回旧体系；同卦追问复用已核资料；正文完整且少重复。
- **效果：** 原书例复现、历史复盘和程序测试都不算独立预测成功。预测效果需另以未提前暴露结局、可核反馈的记录检验；本轮没有该项成果。
