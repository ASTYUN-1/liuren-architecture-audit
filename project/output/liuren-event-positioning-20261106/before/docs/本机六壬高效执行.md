## 三本常用书的检索增强

检索增强版本`20261105-three-book-search-01`；三书索引与检索工具沿用，兼容上述08方法包。需要查《壬归》《理法简易》《天一群笔记》时，主智能体优先用现有liuren_materials的`action=book_search`，按具体争点查，不先读全书或全目录。示例：`{"action":"book_search","query":"死火 旺金"}`；同一轮有多个必要争点时，可用`queries`数组集中查询，最多4项，结果数与原文预算为全批共用。

返回原文可直接核用，完整返回的同版原段不再read一次。若`passage_complete=false`，按continuation补齐；若`section_complete=false`，原段只是章内一部分，涉及前提、例外、书例身份或口径缺口时，按context的章内范围补读，不能把摘段当完整通则。不同来源的相关原文分别处理，不按排序先后定术理主次。书内断语、注解、水论、反馈仍须辨身份。

未命中不等于书中没有：先核查询词或用book_outline定位；需要其他书时仍用scan/books。不为凑次数查书，不重复已经真实读完的同版资料；原有需要查证的条件和最强反证保留。索引检测到原书变化时明确报错，切Build核对后重建，不沿用旧摘文。本增强不启用两库、不新增模型调用、不修改原书或冻结方法包，也不证明预测准确率提高。
