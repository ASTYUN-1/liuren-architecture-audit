# 本机确定性工具层35版：升级与验收

已接入版本：`20261109-deterministic-tools-35`；回退版本：`20261109-palace-strength-34`。

## 已实现

| 能力 | 本版交付 |
| --- | --- |
| 历法 | 复用排盘引擎lunar.js；节气、节月、旬界、日界查询；值冲合筛选、日内采样及原旬区间标记 |
| 具名取数 | 4个来源绑定分支；CY501、WY244为明确算法分支，WY67、WY242明确标记仅基础步骤 |
| 条件取象 | 3个方法：五气材质、十二气阶段物态、传中空虚候选；均返回原文入口 |
| 时间评价 | 历法直接驱动指定对象的单宫或明确取用关系补算，支持批量比较，原盘固定 |
| 工作流 | 主、子共用新说明；OpenCode原生工具和Codex适配器共用内核，计算回执保留 |

工具不选类神、不自行选择数法或应期、不裁事情成败。原始月令五气、十二气及空亡事实与综合分数分别使用。具名方法不接受自由增加倍率；原算式接口保留兼容。

神将相乘基础法允许AI选定天盘类神，不强制入传；其他方法的首版范围见各方法目录。古文量级有350或3500等分支时，返回离散候选，不擅自挑选。基础步不冒充完整断数。

## 空亡与盘面

空亡系数、直接作用范围、弱力分档沿用34版。三合、半合、三会数值仍暂缓。

时间评价默认original保留原空亡计算条件；evaluation-xun-research仅是明确请求的新旬替换研究情景，不当作已定案的出旬、填实、冲实规则。后续空亡机制另行讨论验证。

默认盘按需调用专项，未加整本书的分类断辞、方法目录或审计过程。验收所用寅午戌盘，与34版默认AI盘逐字段完全相同。原始归档未改，34版114个冻结文件字节未变。

## 使用

完整参数和示例见 [35版工具使用说明](../../docs/确定性工具使用说明-35.md)。

OpenCode需重启本机进程加载新工具参数与提示；首次查workflow确认execution_health.ready后再派发。Codex后续新绑定研判读取当前35版方法；历史绑定任务沿原版本，不混用新方法。

先用 `liuren_compute(action="methods", methods={kind:"quantity"})` 或kind=imagery查方法；再调用相应具名计算。普通历法和纯算式无需课盘，主智能体进行盘面取数、取象、旺衰或时间评价须附可信archive；裁决者自动绑定原盘。
