## 单价与计算

用户提供价格截图并确认使用「自营普通通道」，未开FAST。[Conpera公开定价页](https://conpera.ai/models/)通过服务器网络读取成功，其公开页面元数据确认单位为「每百万Token」。截图价格版本为`conpera-codex-pro-self-standard-cny-20261110`。

| 类别 | 元／百万token | 每token纳元 |
| --- | ---: | ---: |
| 普通输入 | 0.56 | 560 |
| 缓存读取 | 0.056 | 56 |
| 缓存写入 | 0.70 | 700 |
| 输出 | 2.80 | 2800 |

`费用（元）＝（普通输入×0.56＋缓存读取×0.056＋明确返回的缓存写入×0.70＋输出×2.80）÷1,000,000`

普通输入=input_tokens−缓存读取−明确返回的缓存写入。同一部分输入只计一次；不将全部未命中输入推定为缓存写入。推理token已包含在output_tokens，不重复收费。金额用BigInt纳元计算，显示时转换为元。DeepSeek继续用原有独立价表，两模型最终汇总。

私有环境配置：`SOL_PRICING_CHANNEL=self-operated-standard`、`SOL_INPUT_NANO_CNY=560`、`SOL_CACHE_NANO_CNY=56`、`SOL_CACHE_WRITE_NANO_CNY=700`、`SOL_OUTPUT_NANO_CNY=2800`。环境文件不导出到本地。

## 行为变化

- 完整响应、合法token分类、有效价表及普通档位齐备时自动计价，进入既有积分结算。请求不能暗中改用priority/FAST。
- 缺用量、分类不全、损坏响应、未知档位或缺价格时保留待核，不用零成本冒充已核。

「已核」表示供应商返回token与所选价表的计算条件齐备，**不表示已与Conpera实际扣款账单逐笔对账**。折扣、通道变化及供应商修账以实际账单为准。同一密钥在其他工具的调用也不能算成网站用户任务。
