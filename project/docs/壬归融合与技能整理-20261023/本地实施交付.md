## 2. 整理与融合具体做了什么

2,744个段落逐一记录源路径、原文件/段落哈希、章节、字符区间、去向、处理动作和来源身份：755段保留为运行内容，106段完全同文归并，1,883段留作原文/原例/引用/历史或独立维护任务资料。参考资料留档不意味着其方法被否定；相关来源按模块链接按需读取，不能把历史例案当当前无条件指令。

原始快照保留完整字节。校验器会重新计算每源全部非空段落区间；删除映射即使重新计算包哈希也会报错。链接只改资源位置，不修改原始出处。不同空亡、长生、内外战等口径保持来源差异，不按作者人数合成通法。

增强核心要求每问固定对象、阶段和成功标准；角色必须进入实际结论依赖，或说明不用/替代取用的理由。关键关系分开事实、状态、实际作用和覆盖范围。救应未解决重要位置/来源冲突时不能确认有效；局部缓解与关键障碍解除分别裁决。问项或共享关系改变，使依赖的结果、程度、应期失效，已提交报告也须重提。

八煞九宝与32项基础核查保留。无时间问不强加载应期；有时间问必须登记事件、尺度、触发和候选。先锋、通常用传及类神三传按职责与来源使用，不永久压倒对象关系。不新增“水未临支便绝不进水”“支上火必干”“辰库即空库”等断语。

structural只整理原有执行正文，仍保留原步骤/调用纪律；enhanced在相同结构上添加明确的候选接口适配和逐问约束。两者存在执行差异，后续结构对照必须如实记录上下文与工具差异，不能冒称严格等价。
