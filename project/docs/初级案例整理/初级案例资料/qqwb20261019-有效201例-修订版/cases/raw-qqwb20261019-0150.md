初传午为妻，午火生丑土，丑就是由妻身所生出来的胎象。丑为阴支，又乘勾陈土，土重而包裹，偏女性、阴柔、藏养之象。

生产类事情，初传为妻财天后，又是发端，午空待填，最怕也最喜午日填实。所以第一应期取：甲午日

申为末传，又是传送，有“胎儿传送而出”的象。如果甲午日只是见红、宫缩、入院、发动而未产，那么丙申日更容易落实为生产完成。
