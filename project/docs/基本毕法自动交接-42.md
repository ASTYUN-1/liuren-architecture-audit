# 基本毕法自动交接（本机42版）

现在每次通过正式入口起盘，都会独立检查**32种基本结构，涉及百法中的25法**。符合的条目自动进入完整AI盘和裁决AI实际读取的核心，字段为 `chart.bifa_conditions`。主智能体不用抄原引擎的毕法标签。OpenCode须重启后新建任务加载；Codex新任务读取当前活动指针。网站未部署。

这里的“任意盘”指任意合法盘都会运行同一组已核条件，不是仅给示例盘配规则。这里的范围也不等于百法所有正格、变格、类格都已收齐。暂未收的规则不标成“不成立”，不把偏僻、待核或来源不清的原引擎标签交成既定事实。

采用范围为第02、05、06、16、21、22、23、24、26、27、31、32、37、41、47、51、52、61、69、70、77、83、85、86、91法中的已核分支。完整32项及逐条定义见[基本条件表](../runtime/liuren/20261111-basic-bifa-42/references/bifa-basic.md)。第22法按用户决定依《六壬大全》，上下俱合取纵向两组六合。

每项交给AI的信息包括法号与结构名称、实际满足的条件、天地盘坐标、四课三传位置、旬遁及旬空/坐空、连续书证索引。按实际选定的昼贵或夜贵天将计算；不把两套天将混起来。关系成立和能否有效分开，空亡不会把原有关系从盘上删除，效力仍按旺衰、所求所忧、位置与制救综合。条目重叠不重复计票，七言标题不作为自动吉凶结论。

原引擎的毕法查表仍原样保留供独立审计，正式交接使用独立扫描器。未收的贵在干前后算法、太常日本旁格及须年命才能定义的分支，暂不自动采用。类神与占类仍由AI依专业方法选择，程序不凭匹配数量决定事情成败。
