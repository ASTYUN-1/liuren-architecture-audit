## 已实现的使用方式

1. ¥1＝10积分；精度0.1积分，库内整数记账。
2. 主报告20积分基础费＋已验证API费用（人民币元）×30积分，上限80；追问5积分基础费＋同样用量费，上限30。先确认并冻结上限，交付时结算、释放差额；未交付不扣分。
3. 使用API返回的有效token用量和公示价表，按成功最终attempt结算。未知用量、失败调用及失败重试成本不转嫁用户；计量异常暂停新积分任务。
4. 用户在账户查看可用、冻结、实付/赠送和消费明细，使用充值识别码联系客服。管理员核对真实到账后，按账户精确查找并自选充值积分；赠送、冲正、售后退积分、现金退款分别记录。
5. 真人辅助99积分，约10分钟、一个已有报告问题及一轮解释。包含预约、接单、提交摘要、用户确认/争议及期限释放流程。
6. 免费抽取从魁、六壬师、清、温温、明，均20%；头像按用户给图顺序保存。抽取后展示对应联系方式，添加好友备注为“问衡咨询”。

## 开放联系功能

目前官方充值微信及五位接待微信均为空，联系充值和付费真人辅助开关关闭，免费抽取可用。管理员可以独立登记已经核实的真实充值或赠送，不因联系方式占位而被阻断。

进入“积分运营 → 积分模式与联系配置”，填写官方充值微信并勾选“开放联系充值”；填入师傅微信及“接待开启”，再按实际准备情况勾选“开放付费真人辅助”，保存。五个身份可以填同一微信。二维码可选，为本站 `/uploads/` 图片路径，不要求先上传二维码。账户安全与管理员权限沿用现有系统。

管理充值时填写增加积分，页面按1:10自动显示对应实收金额；实付需真实交易参考及渠道，重复参考不会重复充值。赠送不伪造现金收入。现金退款按钮只登记已核实的实际退款，不执行资金划转。
