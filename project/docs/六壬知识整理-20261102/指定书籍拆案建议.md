# 指定书籍完整拆案与真人经验提取建议

2026-11-02。用户本轮提出选材与拆案思路，随后明确更正第三本为邵彦和《六壬断案》，不是《六壬指南》。本文件记录选材核查与建议，不表示已经完成批量入库。

## 建议固定的范围

1. `书籍库/现代著作/当代壬占汇选第五版.md`：完整案例、各作者群断、原断、反馈、复盘、注解与后续一起提取。第一章理论讨论不按标题冒充案例；第二、三章分别检查实际案例边界。
2. `书籍库/现代著作/《壬占汇选》.txt`：古代案例及编者按。遇“课式同前”等承接语，需要带入必要前文并说明引用关系。
3. `书籍库/经典古籍/唐宋/六壬断案-宋-邵彦和.txt`：原载占问、课式、邵先生断语、析理与结果。该文件共2332行；首案11–19行包含断语、原载结果与析理，第03案30行却明确“断语遗失”，不能将后者当完整案例强行补齐。
4. `书籍库/北海闲人/毕法赋全解-正式整理本.md`：优先提毕法运用，符合完整标准的课例另拆案。其他北海讲义只作补充来源，先不扩展到全部著作。

## 完整性的标准

保存原书这一案的全部相关内容，不能以AI摘要替代，也不能在反馈、注解或后续之前截断。案例档案包含原载背景、问题、时间/盘式、断语、判断依据、结果及后注；没有提供的字段明确标未载。没有明确反馈不等于没有学习价值，也不自动判为残缺。原文明示断语遗失、盘图缺失影响理解、承接上文尚未找到的材料，进入残缺/待补区，不计入完整案例成果。

同一事件多人作答保留在同案，逐作者区分；不同次占课建立关联，不把多个盘硬凑成一盘。跨书转引保留各版本，只在核实后统一事件身份。按占类进入现有案例库，同时保存书名、作者署名、篇章、行号与原文件哈希。文字标为“邵先生曰”或“某某注”是原载署名证据，不擅自替未知后补文字确定作者。

## 毕法整理本的特别处理

正式本6–12行整理说明明确：依据DeepSeek网页转录稿，移除残缺课盘，删节少量无法还原的课例，并有本地文献补释。因此不能把正式本所有解释均无条件认作北海逐字原文。提取须对读`课程写作/整理本/毕法赋全解/原始资料/毕法赋全解DeepSeek转录.md`和同项目的`校勘记录.md`；仍不能解决的缺口保留，不凭空重建。

毕法用法记录应包括：第几法及原句、作者解释、成立条件、占类与目标、课中位置及关系、变格/例外、与其他法则冲突时原作者如何取舍、所关联案例和原文。通用举例与真实占验分别标记。原作者经验、编者补释和本轮归纳分别记录；先保存方法，再逐步比较归并。

本轮只读核查的候选样本：正式本876–884行店发展案、2189–2195行田大冢宰案、2197–2203行寇道台案；入库前仍需核转录稿及盘式完整性。902–906与1151–1155行杨大司马案在不同法重复出现，应关联同案、保留不同解释。2125–2150行递生定义和分占举例适合方法提取，不将每组三传另造现实案例。

先选约10个跨书完整案例，加少量毕法用法样本，走完原文拆分、独立核边界、分类入库、同源检查、真人方法提取、检索验收。样本通过后按固定书目逐批做完，不为每案强求新增规则，也不把批量切段成功算作审读完成。
