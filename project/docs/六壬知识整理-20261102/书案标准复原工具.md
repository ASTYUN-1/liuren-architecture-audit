# 书案标准复原工具

`tools/liuren_book_reconstruction.mjs` 调用既有 `liuren-direct.mjs` / 原始魔改排盘引擎复原结构，不重写排盘算法，不访问网络，不修改书案登记或原书。

```powershell
node tools/liuren_book_reconstruction.mjs --request output/liuren-book-cases-20261102/bifa-reconstruction-request-001.json
node --test tests/test_liuren_book_reconstruction.mjs
```

请求 schema 为 `liuren-book-reconstruction-request-v1`，稳定 ID 为 `RC26-*`，案例 ID 为 `BK26-*`。请求只从本轮专用 output 目录读取。结果写到 `output/liuren-book-cases-20261102/reconstructions/<ID>.json`，完整原页面 JSON 写到其 `raw/<ID>/` 子目录。

有两种输入方式：

- `input`：明确 datetime 或 manual-pillars 参数、连续原文 `input_evidence`，以及逐字段 `input_sources` 来源说明。manual-pillars 必须有完整年柱、月支、日柱、时支和月将，不猜缺值。机械核引文不证明摘录的语义正确。
- `engine_reference`：固定古例导出 JSON 的 hash、0 起 index、`same_event_review_state: source_checked`、同案理由和 `match_evidence`。固定 JSON/Markdown 与当前 data.js / manifest 链必须通过。只用显式 sizhu/settings，Date/Time/tys 作为占位字段另列，手工课 facts.event_datetime 为 null。古例整理输入仍不冒充原书原载。

`settings_review` 中只有带说明和原文证据的 `source_checked` 对象算已核。普通说明字符串仍是未核。默认枚举未核的两种贵人法 × 昼夜贵 × 两种涉害法，共八组，完整保存；设置预算不足时直接停止，不截取有利盘。显式月将已定时，换将设置只是计算约定。

`constraints` 只接受已人工核原文的盘式字段：三传、天将、四课、天地盘、贵人等。每项须有连续原文证据和 `extraction_review_state: source_checked`，不能以 `原载反馈` 角色选择盘式。可保留 `source_conflict_note`，结果照录。完整白名单见模块。字段地支及天将别名仅做机械比较规范化，不改源文。

结果保存所有候选、输入及原源身份、引擎和适配器指纹、结构校验、约束差异、原始归档路径与 hash。`selected_candidate_id` 始终为 null，`semantic_review_state` 始终 pending，独立效果验证计数为 0；模块不自动改 complete，也不将引擎结构校验解释为全算法正确或断验有效。三传等结构不符时仍写完整结果并返回非零状态。

同 ID 请求不可覆盖不同请求或引擎版本。复用前重新核原书 hash/引文、当前引擎各文件 hash、结果正文 hash、每份 raw 归档 hash、raw 自身数据 hash、摘要与归档元数据及引擎身份的一致性。原始归档缺失/修改时停止复用，不静默重算覆盖。新请求或引擎版本应用新稳定 ID。

## 挂入书案

可选 `reconstruction_refs` 数组每项为 `{id,result_path,result_sha256,review_path,review_sha256,review_state,note}`。`review_state` 为 pending 或 source_checked；后者须有复核 JSON 中精确绑定该 case_id/result_id/result_path/result_sha256 的 semantic_review_state=source_checked 对象（可为根对象或 reviews 数组一项）。结果只能指向固定稳定 ID 路径，复核只能在本轮专用 output 目录。

source_checked 链接还会通过 `tools/liuren_book_reconstruction_verify.mjs` 只读核对 review.request_path/request_sha256（对象 JSON.stringify 指纹，非文件字节指纹）、B5请求/引擎/全部raw完整链。复核可列 `equivalent_candidate_groups` 与 `excluded_setting_label_paths`；只允许排除 nobleman.rule/requested_zhouye/actual_zhouye 三个设置标签，所有组员必须通过原载约束且余下全部facts相同，组hash也须吻合。

B1导入自动追加每组完整facts、展示代表身份、所有设置变体与原始归档链接。代表用于展示，不是选择唯一设置。负责人在全文齐全、只缺盘且等价结构已补足时可升级资料完整性；原图残损、历史设置未核及年命缺口照录，不能把衍生盘冒充原图，也不能把独立效果验证计数改成已验。缺断语或关键结构冲突仍不能靠补盘补齐。
