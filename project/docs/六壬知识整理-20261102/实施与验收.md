规则卡保存原文、行号、文件哈希、来源角色、成立条件、排除条件、判断步骤、其他解释及可取内容。`source_method`表示原文明示方法，`candidate`表示待继续对照的归纳；均不等于效果已经独立验证。`suspended`只暂停明列的特定推断，原始案例与其他有用判断继续保留。

按用户补充，审读单位是具体子判断：卦师给出的确定性断语、部分命中、全部命中、原载真实反馈可以分别记录。反馈身份不清不导致整篇弃用；有结果支持也不顺带认证全部归因。多位作者的不同推理分别保存，不拼接成虚构的统一思路。

实质修订示例：

- B0396：回原书核实“生占日者／克占日者”，纠正摘要反写成“占日所生／所克”。
- B0429：补回“巳上辰→辰冲戌”的加临层次，纠正旧摘要的“巳冲戌”。
- 教师编案例：保留原载“险过象”与淘汰反馈的张力，不把事后解释回填成原断已经正确；风险提示、贵马及教师角色构造仍可学习。
- B0289：原书校按质疑飞廉落点，只暂停从该落点抽出的无条件强推断，保留原载风险判断。
- 轮岗题：职务接替与工作地点变化分别审查；职位、负担及主观意愿分别提取，避免把一切动象或升任合成同一结论。

## 已接入的本地能力

`tools/liuren_knowledge_workbench.py`支持清点、校验、搜索、待办选择、状态查看和阅读登记。记录实际读过的行段，原文件变化会使旧阅读声明失效；重新构建不会覆盖人工阅读进度。登记资产不自动算作读完，程序发现的风险线索不自动算作审查结论。

`tools/experience_retrieval.py`与`tools/case_retrieval.py`在原始缓存之上动态应用有效附加记录。新规则可检索，旧条目显示审查、保留价值及处置范围；文本与批处理候选包均保留这些信息。正常入口经验索引为989项（958旧项+31规则卡），案例来源仍为256份。

审查文件损坏或证据变化会显示待核缺口，避免悄悄恢复旧强摘要。已登记同案及跨卡依赖来源参与排除；明确同源的胎产两档统一身份，其他条件比较族保持独立。未知转引及尚未登记的同源仍需人工核对。

以下命令已实跑：

```powershell
python -X utf8 tools/liuren_knowledge_workbench.py validate
python -X utf8 tools/search-experience.py --query "轮岗 职务" --limit 3
python -X utf8 tools/search-experience.py --query "巳上辰 破墓" --limit 2
python -X utf8 tools/search-cases.py --query "教师编 险过" --limit 3
```

较宽的“巳日 冲戌”查询前几条可能是其他相关旧案例，不能保证修订卡置顶；使用“巳上辰 破墓”可定位本次修订。搜索相关性不是正确率。
