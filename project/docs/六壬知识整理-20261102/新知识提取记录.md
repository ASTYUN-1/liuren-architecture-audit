## 跨案及跨作者条件对照

第一组是**职务/位移/任职完成**。古典冯知丞案同为辰午申，原论先说“本主升迁”，随后检查日干关限、丧阻和末空；徐经干案却用于赴任出外风险，且神煞依据有原书校按。韩省干案有官人催任后另有服忧。题库0026多位作者分别解释接任班主任与不外调；0002溪斜山遮把马空用于迟速修正后仍给出未来调任候选。可迁移的是先限定角色、目标、阶段和动象所指，而不是把“马空”归纳成所有变动永久不成，或把升象归纳成所有任职目标完成。原书和各作答各自的方法仍分别保留。

第二组是**同一结果下的不同论证**。0026蓝风以贵人登车/印和马星限制取舍，南郭子綦以贵人丁和驿马空、年命取舍，天一生水以本命上辰合与丁马临绝取舍；都答当班主任、不轮岗，但取用并不等价。0037晓山青以朱雀闭口减害，正文署名溪斜山遮以长生寅化解幕贵克干；分别保存，不能因为结论一致就补成共同充分条件。0037各数法的位权与折算不同，保留观察而不合造统一算法。

第三组是**阶段与反馈粒度**。旅行案1302为住院后暂稳，1388为次年病故；0026第163行结果句覆盖职务、课时和校区，不覆盖涨薪；0200已知批评是题干背景，不计新增命中。阶段、对象和已知信息分清之后，部分命中可以保留，部分未核或错误也明确留下。

## 原文异常及待核

1. **0026反馈标签遗漏。**第41–45行说未提供明确反馈，第163行却有“@全体成员 当了班主任，而且以前的工作量一分不少。没有被安排到别的校区轮岗。”按原载结果陈述保存；发布者、是否课主反馈、是否在作答前发布均未知。它不能被字段遗漏抹去，也不能直接升级为独立核验。原档没有被改写。
2. **0037的“过了，435”。**出现在7份材料的作者栏，正文另有署名。这可能含真实结果信息，也可能是抓取排列所致；本轮未核原截图/原页面。保留原样及方法内容，不作全题真值。
3. **古典同一物理行混合身份。**《壬占汇选》591、1945、2763行各自包含原断、叙事结果、后人校按；按完整连续原文引用，并在 `attribution_note` 标明混合，不能伪称逐字全是邵彦和本人口述。作者仅按“邵彦和曰”“愚按”“郑云”等原载标识，不猜“愚按”姓名。
4. **飞廉争点。**591行末有“愚按六月飞廉在卯，不在辰”，B0289旧蒸馏未保留；本轮仅提出暂停依赖这一落点的强分支，未擅定原刻或算法何者正确。
5. **韩省干到任矛盾。**2763行并载“果于三月文字来催，四月赴任，韩信先生言不去”。不把“赴任”擅改成催赴任或把“不去”删掉。
6. **现代旅行案时间域。**“不至于死/无大过”未完全限定时间，另有青山“老怕帝旺”与沈好谦“秋相冬旺可救”的分歧。留作条件对读，不强行建立统一老人旺衰法。
