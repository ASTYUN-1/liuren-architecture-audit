## 最严重的传播风险

1. **把事后解释包装为原判成功。**教师编、双B、碗面、母鸡时辰都有这一风险。原作答中可取的风险/类神/局部取象保留，但不能用修正后的结论抹掉原先失分，也不能仅凭档案当前称验就扩大到每个子问。
2. **错位标签复制后形成“多份依据”。**身份证午旬空及闭口、胎产寅冲卯，均从经验到案例或重复档流转。复写不增加独立来源，反馈与某条后设解释吻合不证明因果。
3. **摘要丢失角色和层级。**B0396生克方向反转会改变选日；B0429删掉巳上辰使加临法变成错误六冲；B0294标题末空把墓/止例导向另一条件。这三处均读到书籍库对应原文，超出仅复述旧核验报告。
4. **为合并而压平条件。**丑未族保留教资、求职、考研、丑空及朱雀/年命分支；课体与类神的两套全局优先说均不能从各自单案成立。可归规则族，不可互相消灭反证。

## 使用与验证

检索命中旧ID时，应一起显示对应审查的`finding`、`reference_value`、`action_scope`和修订规则条件。`source_checked`只表明已读文本、引用可核对；`source_method`说明书中确有该法，仍可作来源方法使用，不等于预测准确率已经验证。对暂停金额或空亡等子推断的卡，不应整案过滤，也不能将保留的参照价值自动升级为全判正确。

独立只读核对命令：

```powershell
python -X utf8 output/liuren-legacy-audit-20261102/validate_legacy_audit.py
```

该命令检查JSON必需字段、枚举、ID唯一与关联、旧条目原文区间覆盖、路径存在、136段引用逐字/行号/SHA-256一致及独立验证均为0。实际结果为PASS：17审查、17规则、20旧条目、15案例文件、27证据文件、66不重复证据区间。工程校验不能替代语义审读或独立效果验证。

临时生成与只读验证工具仅在`output/liuren-legacy-audit-20261102/`。本批未改原经验、案例、书籍、冻结包，未调用付费API，未提交Git。
