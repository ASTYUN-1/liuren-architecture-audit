## 使用与结算

1. 预约真人辅助时按既有规则冻结150积分（内部1500单位）。
2. 官方合作卦师输入分配给本人身份的分享码，点击“验证并查看”。这里只读取授权档案，不扣分。
3. 验证成功且预约可核销，“完成并核销”按钮启用；旁边说明本次冻结积分及点击后果。
4. 实际完成服务后点击按钮，将本次冻结积分结算为消费，预约改为completed，写入账本及操作审计。不会在预约已减少的可用积分上再次扣一遍。
5. 成功后显示核销金额，按钮变为禁用的“已完成”；重复请求不会再次收费。换码或清除后会清除旧档案及核销状态。

桌面是输入框与两个并排按钮；手机输入框独占上行、两个按钮并排下行。请求中禁用输入、清除及两按钮。

## 服务端约束

新增 `/api/beta/practitioner/complete`：原站来源校验、登录及已验证邮箱、beta白名单、限速，再校验当前指定advisor_accounts身份。管理员身份本身不授权核销他人分享码。

使用与既有取消/运营核销/维护一致的user→booking→hold锁序；等待财务锁后重新校验并锁住分享授权及卦师身份，核对档案/预约/冻结积分归属。金额由冻结记录决定，客户端指定金额或bookingId无效。

允许未超时pending/accepted/review且held的预约；取消、退款、争议、超时、已释放、归属不一致、过期/撤销/换码/撤销卦师身份或已删除档案不能直接核销。已有运营/用户/自动完成的完整结算可幂等返回，不重复记账。异常或争议仍由既有运营流程处理。
