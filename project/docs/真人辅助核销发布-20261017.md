# 真人辅助核销发布与操作说明

发布：2026-10-17 12:12（Asia/Shanghai）。正式地址：https://wen.qiluhub.com/admin/human-assists 。

## 运营者怎么使用

1. 用已验证邮箱的运营账号登录，进入「运营后台 → 真人辅助核销」。也可以从积分运营页面进入。
2. 在「待处理」按昵称、邮箱、充值识别码或完整预约编号查找。核对预约人、接待身份、问题和冻结积分。
3. 实际完成服务后，点击「完成服务并核销」，填写10–2000字服务摘要，勾选已实际完成服务且账户和金额无误，再确认扣费。摘要会展示给用户，不应包含内部分析材料。
4. 核销后到「核销与取消记录」核对金额、时间、操作人和摘要；用户可在自己的预约与积分流水中查看完成和实扣记录。
5. 未提供服务时，填写取消原因并释放积分。存在异议的预约禁止直接核销，可核对后释放。已结算后的售后退积分，仍从积分运营页面查找该账户，再使用「已结算服务售后退积分」。本次没有新增现金退款或自动转账。

五个接待身份都由运营者处理，不要求创建新的卦师账号，也不要求运营者切换卦师身份。保留原有分享阅读权限，不扩大普通用户访问他人档案的权限。

## 计费与兼容边界

- 预约创建仍冻结150积分；核销按该预约原冻结记录金额结算，忽略客户端金额，不按现价重算。
- 核销复用 finishHold，在一个事务中提交积分批次、账本、完成状态和审计记录；不再从可用余额扣第二次。
- 用户、预约、冻结记录按统一顺序加锁。重复或并发提交只结算一次；已由用户确认或自动完成的预约，重试只返回已完成，不覆盖原摘要或补写运营核销记录。
- 待接单、服务中、待确认的有效预约可直接核销；取消、退回、有异议、已超时或冻结记录不一致时拒绝核销。
- 原用户确认、提交摘要后48小时无异议自动完成、其他超时释放机制保留。并非旧流程永远不结算，而是本次补齐运营直接核销入口。
- 主报告邮件/追问站内提醒策略、AI计价、头像、网站及本地skill均未更改。
