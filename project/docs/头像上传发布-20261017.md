# 用户头像上传发布

2026-10-17 10:58:51（Asia/Shanghai）上线，正式入口 https://wen.qiluhub.com 。

## 用户行为

- 入口：“我的问衡 → 账户设置 → 我的头像”（`/account/settings`）。不增加注册步骤。
- 用户最终确认上传上限为 **2MiB（2,097,152 字节，页面称2MB）**，取代早先5MB方案。前端、后端实际流大小和公网代理均限制2MB；支持JPG、PNG和静态WebP。公网Nginx原有2m配置足够，本次未修改代理。
- 后台Sharp自动按照片方向旋转、居中裁为256×256正方形，以质量78转WebP并移除默认EXIF/GPS等元数据。只保存结果，硬上限100KB；原图不长期落盘。建议用户选择主体居中的照片，暂不提供手动选区。
- 设置后账户页及顶部账户入口显示图片；未设置、恢复默认或图片加载失败时，使用原昵称首字样式。更换后使用新的随机图片URL，旧文件在数据库更新成功后删除。恢复默认、完成账户注销也清理旧图。
- 图片使用随机UUID URL公开加载，缓存一天；缓存和备份不保证随删除立即失效。隐私页面已同步说明。

## 服务与存储

- 复用现有 `user.image` 字段，无迁移。`/api/me`从数据库读取当前头像并只返回受控本站路径，避免认证会话缓存造成旧头像。
- `PUT /api/account/avatar`收取原始图片字节；`DELETE`恢复默认。必须登录及满足现有Origin检查；每用户每小时最多10次设置/恢复，单进程最多2个处理请求。流读取累计超过2MiB立即中止；图片实际解码，拒绝非支持格式、损坏图片及过大像素（4000万像素），转换处理限时8秒。
- Better Auth注册不接受自定义图片URL，通用修改用户接口不允许修改image，必须走受控上传接口，避免绕过图片处理或引用他人文件。其他资料更新不受影响，注册验证回归已通过。
- 图片目录：`/var/lib/wenheng/avatars`，运行用户wenheng，目录700、文件600，由应用`/avatars/[name]`读取；仅匹配UUID WebP名称。目录独立于release，部署不覆盖。非生产默认`.local/avatars`，测试通过`AVATAR_DIR`指定隔离临时目录。
- Sharp0.35.5已随Next.js存在，此次声明为直接依赖。复用锁文件既有包，不引入独立压缩服务。源包只含17个必要文件及manifest，不包含node_modules、凭据或客户图片。
