## 已上线行为

- 后台改为同页五栏目：用户管理、积分与核销、解读任务、支付与流水、服务设置。默认用户管理；切换保留已打开栏目与筛选条件，URL hash 支持返回、前进及旧入口重定向。
- 用户表移除旧套餐订单、收退款金额和追问次数，展示可用积分、冻结积分、欠费与累计净消耗。累计消耗按已结算主报告、追问和真人服务的实扣减售后退分统计，包含尚未补足的消费欠费。
- 档案、草稿、已删数量可点击筛选，直接打开档案阅读弹窗，展示原问题、公开报告及追问对话。永久清理的档案不可读；管理员权限及读取审计保留，不返回内部证据或凭据。
- 真人辅助快捷核销为预约编号或有效分享码输入框和核销按钮，结算该预约原先冻结的积分，复用事务锁、状态限制、审计和幂等结算；重复操作不重复扣分。并非任意账户直接减分入口。
- 积分栏目保留账户查询、充值与账本；联系方式配置折叠。用户表可直接跳到同页该用户的积分账本。
- 任务表显示用户称呼、邮箱、会话档案名称，类型为首次/追问，显示状态、交付结果或故障原因、实际净扣积分和 API 成本，可筛选状态和关键词并阅读会话。列表为最近100条。
- API 成本聚合任务各次尝试的已核实用量事件，包含失败尝试；按供应商返回用量和官方单价计算，不是供应商最终账单。缺失用量和历史估算明确标记，不能把未知成本当免费。
- 旧后台深层路径仍兼容；高级真人服务管理保留在 `/admin/human-assists`，主工作区使用快捷核销。
