## 用户可见行为

注册采用唯一登录账号和密码。账号为4～24位字母、数字或下划线，不区分大小写，服务端格式校验与数据库唯一约束共同执行，注册页提示是否占用。昵称可重复；登录账号设定后不可随意修改。旧用户继续邮箱登录，可在账户设置中补设账号。

邮箱直接展示在注册表单，输入栏右侧标“选填”。无邮箱也可创建账户、登录及使用普通业务。有真实邮箱时尝试发送验证信；验证前可使用普通业务，邮箱验证后才开启邮箱找回。管理员、卦师认证、合作权限和原有二次验证等入口保留对应验证要求。邮件投递失败不让已创建的账户卡死，可在设置重发。

注册后展示一次128bit随机恢复密钥，可复制或下载，也可稍后保存。复制内容提醒存入微信文件传输助手，不向朋友、群聊或客服泄露。密钥不写入浏览器持久存储。账户设置可用当前密码重建；密钥找回成功后更换密码及密钥、撤销全部会话和旧密码重置凭证。管理员和启用2FA账户不开放普通密钥恢复，以免绕过二次验证。

新注册账户初始积分为零，不自动赠送新人积分。没有已验证邮箱且未保存恢复密钥时，没有可靠的自助找回凭证；人工联系本身也不能证明账号归属，不承诺必定找回。

## 技术与防刷

复用Better Auth 1.7.7 username插件，保留旧邮箱登录和邮箱注册API兼容。数据库仅增加`015_account_recovery.sql`：可空username/display_username、大小写无关唯一索引、格式约束及account_recovery表。为兼容框架的必填email，无邮箱账号内部使用随机UUID的`@account.wenheng.invalid`占位；不发信、不标为已验证、不向用户展示为绑定邮箱，`/api/me`返回空email。

恢复密钥由密码学随机数生成，仅保存绑定用户及用途的SHA256；128bit随机凭证不依赖弱短码的慢哈希。找回与重建使用事务和行锁，避免重复消费及并发覆盖。密码沿用框架密码哈希。

注册按可信入口来源限制6次/15分钟、10次/小时，并设隐藏诱捕字段。登录、查重、密钥恢复分别限速，密钥恢复同账号5次/15分钟。来源识别复用既有可信代理边界，不直接信任客户端XFF。

**生产未配置Turnstile。** 已保留前后端可选接入，配置后服务器校验token、hostname及action；当前生产没有演示验证框。这些措施提高批量注册成本，不能保证一人一号。后续若发新人福利，必须单独设计领取资格和额度，不能仅凭注册成功发放高价值权益。
