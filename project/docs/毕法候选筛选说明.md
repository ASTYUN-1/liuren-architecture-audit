# 毕法候选筛选与双蓝本核查

**当前状态更新：本机42版已接入独立的基本结构扫描与自动裁决交接，见[基本毕法自动交接](基本毕法自动交接-42.md)。下文“未自动接入”描述早期候选审计工具的阶段；该审计工具仍独立保留，正式交接不直接使用其全量候选。**

原引擎的毕法输出是候选索引，按日柱、干上神查表，可能同时带昼夜标签。核对蓝本采用用户指定的《六壬大全》和北海闲人《毕法赋全解》；实际布将、普通分支、例外及具体位置分别核，不从七言标题直接裁吉凶。

运行独立核查：

```powershell
node tools/liuren-bifa-audit.mjs --chart 正式resolved-chart结果.json
```

输入须是`tools/liuren-resolved-chart.mjs`的完整结果，带可信原归档引用与哈希，不是只截取的`facts`对象。可加`--out 新文件.json`保存；已有文件不覆盖。

- 实际昼贵筛昼贵条件，实际夜贵筛夜贵条件；使用正式盘实际设置，不另凭钟表猜。
- 明确模式限定与被考察贵人身份分开。“害昼贵”不直接当昼盘限定；“昼夜贵加”的标题也不能用关键词筛掉。
- 无昼夜后缀只是未明示限定，不代表结构已成立；未登记细分类格返回待核。
- `adoptable_information`只放已核结构信息；位置断语、普通分支、例外分开。失败标签和不适用模式不产生可采用结论。
- 来源字节、连续摘录或原盘绑定不符时停止采用，不自动信任旧摘要。

当前已核细分范围及本盘疑点结案见[双蓝本复核与筛选说明](../output/liuren-bifa-audit-20261111/双蓝本复核与筛选说明.md)。来源证据在`tools/liuren-bifa-source-rules.json`，测试在`tools/tests/liuren-bifa-audit.test.mjs`。

此入口尚未自动接入正式AI盘、裁决核心或网站；全250种标签的昼夜措辞解析通过不等于其全部类格语义通过。当前不修改活动41版或原引擎，也不改变原来专业判断中按条件采用毕法的要求。

## 本轮批量与AI材料入口

第22法已按用户明确决定，以《六壬大全》为采用蓝本，B上下俱合格核纵向两组合；见规则登记的`adopted_definitions`。新增批量执行及AI结构材料生成，详细范围见[批量核查与AI交接方案](../output/liuren-bifa-audit-20261111/批量核查与AI交接方案.md)。

```powershell
node tools/liuren-bifa-batch.mjs --out output/毕法批量核查-新目录
node tools/liuren-bifa-audit.mjs --chart 正式resolved-chart结果.json --handoff --out output/毕法AI材料-新文件.json
```

批量入口复核当前引擎与已保存720/1440盘的哈希，执行已登记分支并按原始标签集中待核；不把枚举执行当百法全文语义完成。AI材料排除错误、错模式及待核标题，只保留来源条件支持的信息，并执行有限范围独立扫描查漏。当前19段来源证据、14项测试；正式裁决核心仍未自动接入，不将材料文件存在说成实际AI已采用。
