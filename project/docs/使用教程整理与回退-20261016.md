## 回退方式

本记录与页面改动在同一个内容提交中。需撤销本轮时，在项目目录运行以下PowerShell命令，使用 `git revert` 生成反向提交，保留提交历史；不要使用全仓库 `reset --hard` 或 `clean`。

```powershell
$tutorialCommit = git log -1 --format=%H -- docs/使用教程整理与回退-20261016.md
git show --stat $tutorialCommit
git revert $tutorialCommit
```

执行前若这些页面又有未提交编辑，应先保留那些编辑并处理可能的冲突。修改前版本可通过 `git show 92637c4:六壬八字测算/web/src/app/guide/page.tsx` 查看。Git回退只改变源码；未来如已部署，仍需重新构建发布对应源码，不能用数据库旧备份回滚交易。
