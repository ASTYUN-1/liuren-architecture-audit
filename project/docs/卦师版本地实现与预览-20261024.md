## 身份与权限

| 身份 | 本人专业解读 | 用户分享档案 | 后台与其他账号数据 |
| --- | --- | --- | --- |
| 普通用户／认证待审核、驳回或撤销 | 否 | 否 | 否 |
| 认证卦师 | 是 | 否 | 否 |
| 官方合作卦师 | 是 | 仅用户授权给其指定卦师身份的有效分享码 | 否 |

普通认证流程：已验证邮箱账户在个人主页填写10–1200字认证备注，运营者在后台“卦师认证”栏目人工通过或驳回；审核备注对申请人可见。申请不自动授予身份。支持撤销、重新申请，审核带版本检查防止旧页面覆盖新申请。认证徽章仅在本人个人主页展示，普通认证为绿色，官方合作为金色。它们是平台账户身份标识，不宣称国家资质或预测准确率。

合作授权沿用既有 `advisor_accounts`，管理员选定卦师身份和已验证邮箱，单独授予或撤销。已有正式合作账号无需补录普通认证，自动拥有专业输出能力。普通认证与合作授权独立；要彻底撤销两者时须分别处理。管理员身份本身不自动成为卦师，也不能通过分享码入口越权。

分享码保留既有约束：指定身份、有效期、用户撤销、预约取消／退款和档案删除均由服务端校验。工作台只读取已交付内容，不重新生成解读、不扣分、不将分享阅读混作真人服务核销。保留问题、报告和追问的只读投影，不返回内部证据、账户或成本数据。

## 专业解读

worker在首次取得任务时从数据库认证与合作状态选择受众，保存为任务的 `output_audience`，同任务重试保持快照。新任务按届时身份选择；既有报告不重新生成，撤销不会收回已交付文字。请求正文、用户原问、模型指令不能选择或提升此受众。

两类卦师共用专业分支：保留现有本地十一环节、模块阅读、固定盘、逐问判断、反证、依赖及至少三条准确内部引用。直接按专业术语解释取用、理气、课传、制救和适用条件；不加载、分页或应用普通网站最终输出Skill。仍使用受限网站工具与既有计费，不开放本地OpenCode的Shell、文件、联网或子智能体权限。

专业表达与隐私分开：可使用术语、方法和公开传统书名；不能交付私有案例身份、内部编号／路径、密钥、系统配置、后台信息、工具标识或原始审计记录。服务端继续拒绝明确内部标识，引用单独保存；这不是对所有语义隐私泄露的绝对证明。真实模型的专业表达质量仍须后续实样验收。本轮无真实付费模型调用。

普通用户分支仍完整保留末步输出Skill与冻结、分页读齐、提交门禁。
