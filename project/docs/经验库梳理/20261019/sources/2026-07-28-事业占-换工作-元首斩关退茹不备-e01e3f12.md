## 模范答案总结

### 核心判断
1. **去**——太岁冲命（辰冲戌）、行年寅为年马、先锋巳腾蛇飞天冲亥白虎（领导逼迫）、退茹从公司退出
2. **能换到满意工作**——戌太常为征召、戌天马登天门、太常禄具备、行年入未为新公司
3. **补充**——主动辞职，与旧关系或官方公司有关，戌月或亥月庚辛日为应期

### 关键技法
1. **太岁冲命**：占年运必看太岁与年命关系——辰冲戌是最大动因
2. **先锋门点题**：巳时腾蛇乘午飞天，冲亥（支）白虎，官鬼冲子孙——领导逼换工作
3. **退茹退≠守**：三传退茹是退出之象，不是退缩之象
4. **魁度天门可读作破关**：戌为天马+太常登天门，冲破关隘而非被阻
5. **行年勾陈双读**：勾连旧人 + 勾陈为官方
6. **人随课走**：不问主观满意与否，看课象是否走到新位置——行年入未即接受新环境

## 复盘要点
- 初始判断"宜静不宜动"错误——忽略了太岁冲命的核心动力
- 退茹课的方向性：指向"退出"而非"退缩"
- 先锋门的重要性：占时乘将直接点题
- 魁度天门可以有正反两种读法：阻隔vs破关，看所乘天将与类神
