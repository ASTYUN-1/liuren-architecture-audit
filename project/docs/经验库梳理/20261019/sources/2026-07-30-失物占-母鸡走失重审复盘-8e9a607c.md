## 🔑 核心经验：应期速度的层级判断

### 丁马/占时同位的极速法则

```
丁马加某支 → 该支 = 占时？ → 是 → 当天该时辰（极速，第一优先级）
           → 该支 = 日支？ → 是 → 当天（次优先）
           → 否则 → 最近的该支日 → 再定具体时辰
```

**"时→日→月"逐级递推，不可跳级。**

### 速/慢信号对比

本课同时存在对立信号，但极速信号压倒一切：

| 信号 | 方向 | 权重 |
|------|:---:|:---:|
| **占时 = 中传丁神（同位）** | 极速 | ⭐⭐⭐ |
| 类神酉加干上 | 近处/速 | ⭐⭐⭐ |
| 贵人逆行 | 缓 | ⭐ |
| 类神酉在寅月休囚 | 偏慢 | ⭐ |

### 修正后的应期判断流程

1. **先看占时是否入传** → 入传则在占时所在时辰或当天
2. **再看丁马/类神是否与占时同位** → 同位则优先应当天该时辰
3. **再看丁马所在支** → 不等占时则推该支的日/时
4. **最后看类神当值** → 类神临日/时
