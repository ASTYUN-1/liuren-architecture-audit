1. 发用亥为日德，入天门，"占试必中"

  - 数学B ✅（通过但非A）

# 归因分析

## 失误原因
1. **过度解读"德入天门占试必中"中的"中"为"高等第"**："中"应理解为"考中、通过"，而非"优异"
2. **末传财空亡的信号权重被低估**：考试占中财（巳）代表成绩分数，空亡直接限制了等级上限
3. **"类神定结局"原则未被坚持**：虽然有德入天门的利好发用，但核心类神（财）空亡时应以类神为准
4. **课义提示未充分重视**："中末空脱"的课义已暗示中末传空亡脱耗

## 改进点
1. **考试占中，德入天门主要保证"通过"而非"高分"**：判断等级须看类神状态
2. **末传财空亡 → 等级打折**：成绩（财）空亡，高分无望，保守断"能过但不高"
3. **问等级（能否到A）vs 问能否过**：问等级要看财星旺衰空实，问能否过要看朱雀/日德/太常
4. **发用vs末传的优先级**：发用定事之起始趋势，末传定结局；末传空亡则结局虚
