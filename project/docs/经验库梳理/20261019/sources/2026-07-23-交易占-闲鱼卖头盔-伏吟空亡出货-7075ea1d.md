## 关键技法

### 1. 卖货占与买货占方向不同——核心一课
**卖货占 = 空亡读"货离手"（卖出），非"交易虚"。**
初传巳空亡，卖货卦中意为"货没了/出手了"，而不是"事不实"。

### 2. 子孙申为买家
申为戊土之子（戊生申），交易占中子孙=买家/客户。申乘白虎主动速。

### 3. 寅蛇砍价 + 丁酉太常速卖
- 寅为官鬼克干 → 砍价压力
- 寅腾蛇缠价 → 对方缠着你砍
- 寅通道丁（丁马）→ 卖得快
- 太常酉 → 宴喜有成

### 4. 寅三数定成交价1350
寅先天数三，断价1350（挂价1520砍170）。

### 5. 贵人丑在课
丑为贵人通行于申，有人要买之佐证。

## 后续应验
待反馈。

## 失败归因
最初读课错误地将空亡=事虚、寅克干=结果不利，忽视了**卖货占的独特视角**——空亡不是"卖不掉"而是"货不在了"（已售）。以后遇到卖货/出货占，空亡一律优先考虑"货出"而非"事虚"。
