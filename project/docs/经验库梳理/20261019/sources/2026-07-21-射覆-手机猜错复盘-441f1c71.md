### 失误1：三阳"光明"完全漏掉 ⭐最致命

**课象**：三传子寅辰皆阳支 → 三阳课 → **光明**
**误读**：完全忽略，未提及
**正确解读**：**电子屏幕发光**。手机是随身携带的最典型发光屏设备。
**《指掌赋》原文**："子寅辰向三阳而所望光明" — 此句直指发光的屏幕。

### 失误2：天后类象过度窄化

**课象**：发用子乘天后
**误读**：天后=妇女妆奁 → 护肤品
**正确解读**：天后=**润泽华美** → 手机屏幕玻璃的润泽光滑触感；天后=**皂白衣服** → 手机外壳常为浅色/白色
**教训**：天后≠必然妇女用物。天后是吉将，核心是"润泽华美"，光滑的电子屏幕同样符合。

### 失误3：报数6→巳火的电器信号被水压制

**课象**：报数6对应巳火
**误读**：只看了发用子水，全程往水类想
**正确解读**：巳火=**电器/发热/光亮**。子(水)在外(发用)，巳(火)在内(时柱)，水火并见正是电子产品的特征：外壳润泽(子水) + 内部电路发热(巳火)。
**教训**：报数对应的地支五行与发用五行冲突时，两者并看，不可偏废一端。

### 失误4：斩关=开关机，而非"未开封" 【❌无据-2026-08-04审查】

**课象**：斩关课
**误读**：被 case-002 (仔仔面碗面) 的"斩关+辰巳空=未开封包装"锚定
**正确解读**：斩关=**开关/闭合/关卡**。手机本质上就是一个不断"开关屏"的设备，比"包装封口"更贴切。 【❌无据-2026-08-04审查】
**教训**：同类案例是参考不是锚，斩关的核心语义是"关隘/开关"，不能因为一个案例就固化解读。

### 失误5：子有孔窍 → 扬声器/麦克风/充电口

**课象**：子="有孔窍"
**误读**：忽略
**正确解读**：手机底部扬声器孔、麦克风孔、充电口，满身是"孔窍"。比护肤品瓶口更贴切。
