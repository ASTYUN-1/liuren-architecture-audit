## 经验规则1：田宅宫白虎+申酉金 → 屠宰家业
当推命盘见伏吟课 + 田宅宫（第10宫）乘白虎 + 地支为申/酉金时，应断家业为屠宰/血财之业（杀猪卖肉等），不问父母宫青龙贵神之象，因为田宅宫为家业根基，白虎主杀伐刀兵，金为切割之器。父母宫青龙的"贵气"会被田宅宫白虎的杀伐象所穿破。

## 经验规则3：太常金属宫 → 刀肉常业，非必体制内

## 经验规则4：帘幕贵人乘天空 → 助力减等
当推命看学历 + 帘幕贵人乘天空（未天空）时，应断帘幕贵人为"虚贵"，助力有限，学历层级应降等判断（如硕土降为本科）。
