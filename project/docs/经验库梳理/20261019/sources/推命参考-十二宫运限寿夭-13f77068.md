## 一、十二宫分断细则

### 总则

> **"十二宫中仔细看，何宫为劣何宫优。劣则为忌优则吉，妻财子禄辨其由。"**

十二宫位生扶合助日干本命 → 其宫诸事顺利发达。见凶神恶将与命干刑冲破害 → 其宫不利。

**空亡通则：** 遇吉不吉凶不凶。不可泥而执，大道原来要变通。

---

### 各宫分断

**1. 命宫**
- 吉神良将生扶 → 一生根基稳固
- 空亡墓绝 → 根基浅薄，多波折
- 与日干相生 → 有自主能力；相克 → 多受制于人

**2. 兄弟宫**
- 吉神良将与命干无刑冲破害 → 兄弟富贵和睦
- 刑煞遇 + 天刑狱加 → 非只身即仇家

**3. 妻妾宫**
- 吉神良将与命干无刑冲破害，与干相生合 → 妻贤益夫益子
- 刑冲 → 夫妻反目。无刑无劫便为佳

**4. 子女宫（男女宫）**
- 吉神 + 长生生气临 → 多儿女，子女贤孝
- 凶神恶煞 → 子女不肖或艰难

**5. 财帛宫**
- 吉神良将与命干无刑冲破害，与干相生合 → 财帛厚产业兴隆
- 天中煞 + 比转 → 不是寒士即浮夸

**6. 疾厄宫**
- **喜空** → 少病少灾
- 忌丘墓相逢 → 大病
- 遇德神 → 有救；遭恶将 → 定主凶

**7. 迁移宫**
- 逢二空 → 空空如也
- 德禄马在对宫 → 迁到处人钦敬

**8. 朋友宫（奴仆宫）**
- 受克为顺 → 奴仆听命
- 生不逊 → 奴仆反叛
- 虎勾厌煞 → 惹祸累主人

**9. 官禄宫**
- 得二马（天驿二马）或奇仪皇恩等吉 + 龙贵朱将与命干不相冲克 → 得美官
- 见吉神倘居囚死之地 → 得微官
- 无马 → 官不显；无禄 → 官缺俸

**10. 田宅宫**
- 吉神良将无刑冲破害 → 田宅增益
- 天鬼天贼 → 不利
- 旺相吉神 → 日增盛；凶神凶将 → 渐萧条

**11. 福德宫**
- 吉神良将会 → 优游子孙绵
- 逢空遇劫煞 → 一生坎坷
- 遇吉为荣，凶则寒

**12. 父母宫**
- 吉神旺相生扶 → 得父母力
- 凶神克害 → 不得父母力
