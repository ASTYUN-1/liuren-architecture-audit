# 分类取用测试：原案与原书两路核对

本规范用于用户授权的案例测试及复盘。待测模型先独立取用，核对者在锁定原样初答后，分别查原案作答和书中方法。普通占断仍不查案例、经验或已知答案；本规范不启动裁决，不修改旺衰与凶吉判断方法。

## 每轮怎样做

1. 选未入正式库、与前轮不同且资料足够的案例，记录已知暴露。仅按公开题面选题，不因答案或某种取法筛题。不得把历史暴露未知写成干净留出集。
2. 新会话只给背景、原问、占时及已明确年命。删去评分、原断和反馈，保留会影响取用的对象、阶段与限制。锁定模型原样初答及工具记录后再打开原案作答，不能在核对前让它按答案重取。
3. 分别完成下述两路核对，再核查程序盘中的位置。报告可以自然表达，不强制模型占断输出固定JSON或多轮审判。
4. 只把有条件、有来源、能解释错误的修正写回取用规则。保留初答，后续用新案例检查迁移；已暴露案例重测只算开发回归。

## 第一路：原案答者怎样取

按作者分别摘取实际所取对象、类神、首取或兼看职责、理由及位置。保留题面与连续原句、来源行号和哈希；原书引用、答者解释、现实反馈、核对者意见分开。

多人取法不同就列出分歧；有人只给结论、未说明主类，就记未明示，不能替其补出首取。原案不是北海本人的断语时不得混称。整理字段可能把评语误识为作者，应核对原始正文，暂不能辨别的说明身份待核。不同术式分别标明，不把六爻、奇门等用神直接当作六壬主类。

老师选中或标A，只能说明原载评价；不证明该答者所有取类、盘面事实和解释都对。各答者结论相同，也不等于类神相同或某一取法已验证。

## 第二路：书中怎样教

按本问查北海闲人及已登记原书的连续原段，核对所问对象、阶段、首取顺序、兼看职责及递补条件。说明是原文明示、依原理作现代映射，还是尚无足够依据；不能只引类象词表便确认首取。

未知材质不当已知布帛，年命未知不当作已知但不入课传，称同事大哥不等于血缘兄弟。关系题保留双方；经营体、营业收入、利润和具体款项分别定位。缺少决定取类的信息，明确缺哪一项，不按已知答案补造背景。

## 怎样下核对意见

分别说明两路的支持程度，不压成一个总分：

- 原案同类、书证条件也成立：可认可本题取用；仍不等于预测效果验证。
- 原案不同类、模型符合书中另一适用方法：保留为有据分歧，不直接判错。
- 原案支持、书证未核或有条件缺口：保留候选，继续查证，不直接上线成通则。
- 模型改写原问、补造取类前提、混淆人物或盘位：指出具体错误，即使结论碰巧同向也不验收通过。
- 依据不足：注明待核，不为凑正确率硬判对错。

检查类神天盘支、所临地盘、乘将，以及年命地盘上的上神。主类选对、位置写错须分别报告，不能互相抵消。原案也可能写错盘位，须以可信盘核查。

## 每轮交付

简表列出：模型取用、原案各答者取用、书中教法、核对意见及具体缺口；附可回读原文。将取用是否有据与凶吉是否同原案分开，当前优化优先处理前者。

修改以可复用条件为单位，不把本案答案写入待测模型材料。每轮控制改动范围；是否有效须看后续模型表现，工具和哈希检查只证明规则加载与事实一致。
