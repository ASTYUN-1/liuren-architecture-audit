## 用户可见变化

- 新建问事、修改草稿和自助排盘必须提供本人性别与公历出生年份，添加其他人物时同样必填。出生年份范围为 1900 至当前年；性别不能用“未知”绕过。完整出生日期和本命仍可选，更多资料折叠显示。确认弹窗显示人物资料。
- 服务端拒绝缺失字段；旧未付款草稿须补齐后下单，历史已购输入和报告不因此失效。
- 账户页新增专属链接、复制／系统分享、邀请注册数、成功交付数、可用和占用优惠券数；只提供汇总，不暴露朋友邮箱或档案。
- 新用户经有效邀请链接注册获一次基础解读八折（¥29.90 → ¥23.92，节省 ¥5.98）；朋友真实付款且优惠报告成功交付后，邀请人获一张下次基础解读八折券。每单一张，自动抵扣、不叠加、不折现，¥9.90 追加包不参与，服务运营期间不设日历到期。30 天仅是当前浏览器中的注册归因标记有效期。
- 订单保留原价、实付金额与券关联；取消、改盘、删除、过期取消按订单状态释放；未交付全额退款按实付退款并恢复用券机会。迟到到账不重复占券，异常全退撤销对应未用邀请奖励；已完成的优惠订单不追收差价。
- 邮箱验证实际使用邮件链接，非数字验证码。后台新增 SMTP 准备步骤、端口／TLS 说明及保存后实际收件测试指引；注册、账户和找回密码明确提示未接通状态。
