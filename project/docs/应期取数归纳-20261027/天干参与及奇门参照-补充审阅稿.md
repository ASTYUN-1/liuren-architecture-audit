# 天干参与及奇门参照：应期与取数补充审阅稿

日期：2026-10-27。承接[理气与判断技法稿](理气与判断技法-工作流接入审阅稿.md)与[核心归纳](核心归纳-审阅稿.md)。本次重新读取桌面文档更新版本，其内容现为奇门应期、取数检索摘要。已按文件哈希另存输入快照，未覆盖前轮检索记录。本稿仅做研究补充，未改生效工作流。

## 一、前稿确有展开不足，但不能说六壬原本不用天干

前稿的时间触发多以支位、空合墓冲、马与三传组织，天干虽已出现在日干基准、旬丁、十干数和天盘干支取数中，却没有单独梳理其职责。这一部分应补。

日干本来就参与四课、取用、六亲和生克参照；把它省略，许多地支关系也无法完整解释。另一方面，“天干”并非一个可任意附加的统一层：

| 对象 | 在研究中可能承担的职责 | 必须区分 |
|---|---|---|
| 日干 | 本人/角色及生克取用基准，依占类确认 | 不是一切占类里唯一的“我” |
| 年月日时的实际天干 | 历法与事前时令背景；专法规定时参与定期 | 不能自动与所有遁干等权计数 |
| 旬遁干 | 课传、类神所遁之干；暗财暗鬼、旬丁等的分析输入 | 由本旬配定，不是地支藏干 |
| 五子元遁干 | 另一套依日干等起遁的专法输入 | 与旬干起法不同，不能结果不合就替换 |
| 《拃河棹》天地人三遁 | 本书体系中的分层起遁与取用 | 不自动并入通用排盘，原书起例及权重有争论 |
| 十干数 | 甲己9、乙庚8、丙辛7、丁壬6、戊癸5 | 是数值映射，不是十个十进制位数，也不是默认个位数 |

《六壬金针》对旬干与五子元干作了区分；其旬干表在甲子旬中配十支，戌亥空而无配干。[G1] 空支如何处理必须遵照已选起法，不能为计算方便强行补干。天将的五行、寄干、藏干和遁干也不是同一对象。

## 二、天干能怎样参与应期

### 1. 解释原来只看支时未展开的作用关系

《六壬粹言》“遁干加处细详察”举例：甲戌日干上辰为财而遁庚作暗鬼；甲子日干上申为鬼而得壬化之。[G2]

这表明该书确实让干层参与生克制化。它可形成关于阻碍、救助等的竞争解释，而非看支层有财便直接判得财。但“暗鬼”是方法解释，不等于已查明现实中确有某个暗害者；这两个例子也不是本次新验证的事件。

### 2. 从干的旺衰、作用条件寻找应期

《拃河棹》明说：

> 然此专论支也，究当以支上遁干所遇之旺月为应。

同段还谈“事神之遁干与日月比旺之月求克应”。[G3] 所以本地就有把干层用于定期的直接线索，不需要借奇门才获得这一思路。

但《壬学琐记》同时批评张氏天地人三遁及有关起例，讨论《中黄经》时又强调不能专凭遁干。[G4] 故这是一条应保留的有源研究分支，不能升级成“遁干永远胜过支神”。原书“未有不验”等措辞也不是准确率证据。

### 3. 以干限定日期候选

《六壬指南注解》子逃案有“寻之丙丁日可见”的表述。[G5] 它至少说明古案中存在按天干报日的做法；这处引文自身没有完整交代为何取丙丁，不能单据该案反造一个通用算法。

若一套适用方法分别给出有效的干条件和支条件，理论上可以取交集，帮助区分轮次。六十日中，同一支出现五次，各配不同的相容天干；干支同时确定时可定位到六十甲子中的一项。注意：

- 这是历法筛选性质，不是对取干方法准确性的证明。
- 天干每十日、地支每十二日循环，干支只组成六十个合法组合，不是任意十乘十二的120组合。
- 一个给干、一个给支的方法，须解释它们约束的是同一事件同一阶段；不能仅因交集漂亮便强合。
- 没有选干依据时，不能为排除其他日期而事后补干；交集为空也不能随意换起法。

因此，天干可能补充应期的作用关系与时间筛选条件，但不会自动决定“就是这一天”。

## 三、天干能怎样参与取数

前稿已保留《拃河棹》《粹言》的天盘干支法。《拃河棹》有“以天盘干支之数”取数、“大数旺取干，其零数取支”等文字。[G6] 这与用户关心的大数、小数部分确实有关，值得专项整理。

但目前须保留三层区别：

1. **干支共同参与计算。** 如甲子九乘九得81，得到的是整项运算结果，不是甲给十位9、子给个位9。
2. **主数与零数分工。** “大数取干、零数取支”提供结构线索；零数可能涉及原文的货币分层、余数部分，不等于现代任意十进制末位。
3. **具体分位规则。** 要回答百位、十位、个位分别怎样确定，仍需输入选择、数表、单位、进退位和进位处理的完整规则。

尤其《拃河棹》同段有“九九八十一”后“旺倍则一百八十二”等算术疑点，另有多种金额表述；前稿已列待校。[G6] 不能取其中一句就宣布已经解决456中末位6的定位。

天干数表本身只有5—9五组数，且两干同数。它不是0—9数字编码；即使把干的阴阳纳入，也须另有有源运算，不能把缺少的个位规则补想出来。

当前合理结论是：**加入天干能扩充有源取数节点和解释分支；能否降低误差、稳定判定量级或末位，尚未建立。** 增加输入也会增加可选算法，必须同时约束选法。

## 四、更新的奇门摘要：可参照，但先校正四项

本地书籍库未检出摘要所称《奇门法窍》《奇门统宗》等对应原书。本次未核奇门影印底本，故其中引号内文字仍属于用户提供的检索材料，不能全部列为已核古籍原文。以下判断依据为本地交叉核对和摘要内部一致性。

### 1. “数目增减在临时”不能作为奇门新增证据

摘要中的长引文，从“数目者，子午甲己九之类”到旺取35进350/3500、相取28倍56、休取14、死囚取5，与本地《六壬粹言》LF500—501相合。[G7]

因此可以确认六壬文本中已有这段；不能仅凭摘要证明它专属奇门，也不能把同一段跨体系复述计作独立支持。是否还被奇门书收录、最早出处和传抄方向，须另核版本。

摘要所说“奇门多出的进位与加乘切换”，在我们前稿S13—S14已讨论的六壬材料中就有，不构成新增方法。“350或3500”恰好保留了量级未决，而不是已经解决量级；离散的两个选项也不等于350到3500的连续区间。

另有两个逻辑缺口：35进一位是350，3500相对35是进两位，摘要不能用“进一位”同时消解两者差异；“少用河图、多用先天”若未交代如何事前判多寡，也可能把待求结果当作选数制的前提。

### 2. 伏吟、反吟的快慢表述前后冲突

摘要先写“旺相、内盘、伏吟，近而快；休囚、外盘、反吟，远而慢”，随后又写“伏吟主慢、反吟主快”。合并条件的作用没有解释，不能整理成一个确定的时间单位开关。

应把时间迟速、空间远近、内外盘归属分别核对；即使奇门内存在有条件规则，也不能据此推出六壬伏吟/反吟的统一时间规则。

### 3. “先定支，后配干”尚未给出配干算法

这句话可作为检索线索，但摘要主要展开定支，没有把“怎样从已定支选定天干”的操作交代清楚。它本身不能替我们解决应期的天干选择问题。

“出旬填实”也须拆开：出旬边界与到该支日并非同一条件；甲子旬戌亥空，出旬后首次戌亥日有相应关系，不代表每一种宫位/旬空语境都可混称。“先到者为应”“符先使后”等若无原文上下文，不提升为通用候选排序。

### 4. 状态—触发并非六壬缺少的空白

空待出/填、合待冲、墓待破、缺字待足、衰待生旺，已属于前稿六壬T3—T4。奇门摘要可提供另一种表格组织方式，但不能把六壬既有逻辑说成新从奇门引进。

尤其摘要《法窍》部分以冲待合，另一部分又说逢冲应冲日、逢合应合日。两者可能对象和语境不同；未核清时应保留为竞争分支，不强合为一条口诀。

## 五、哪些参照可以吸收

| 材料层次 | 当前处理 | 原因 |
|---|---|---|
| 对象—状态—触发—时间层级的组织方式 | 可用于完善六壬方法卡的表达 | 属于可比较的分析结构，六壬已有相应原法 |
| 生克、旺衰、动静、主客的比较问题 | 可作研究提问，分别核对本体系定义 | 相似术语不保证同一取用和计算对象 |
| 摘要的具体定支、配干和先后规则 | 待核奇门原文，并保留奇门起局条件 | 缺版本/章节及完整适用前提 |
| 九宫数、八门九星、六仪、内外盘 | 留在奇门体系；跨用另列研究假说 | 六壬十二支盘与奇门九宫无天然的一对一替换 |
| “旺乘休加”长引文 | 回归六壬已核分支，去重登记 | 本地《粹言》已有，不再计奇门新增支持 |
| “天干负责精度、地支负责范围” | 不立为通则 | 干支可能各有不同职责，没有这种固定分工证据 |

可借鉴的是“怎样把条件写清楚”；具体规则仍须在所属体系内成立。摘要称奇门“更常”用某数法等使用频率判断，本次没有统计材料支持。

## 六、对接入稿的具体增补建议

不新增一条“每课必须把全部天干都看完”的流程。在既有对象—理气—技法链中，增加一个按需检查口：

**关键问题仅靠现用支层关系是否解释充分？是否存在起法明确、对象相关、能区分候选的干层原法？**

若调用，至少记录：

1. 干从哪里来：日干、实际历法干、旬干、五子元干或其他专法；同名不同起法分别保存。
2. 附着哪个对象：不是搜遍所有干后挑有利者。
3. 解决什么缺口：状态解释、条件解除、干日筛选，或数值输入/主零分工。
4. 具体怎样用：所选来源、运算及时间转换；哪些只是作者推测或跨法外推。
5. 加入后区分了什么：是否排除了原先的竞争日期/数量；仍不能区分则保留未定。
6. 反证与重复：由同一旬和支推出的干不是一条独立观测，不能反复给相同来源加权。

补充后，应期研究多出“干层作用与干支时间条件”的明确入口，取数研究多出“干支联合取数、主零分工”的专门分支。**这使研究对象更完整，不等于已经提升了预测精度。**
