# 应期与取数研究底稿

日期：2026-10-27。性质：本地资料初查、方法问题诊断与研究设计；不是已验证的新断法。本轮未改动运行 Skill、方法卡、案例或网站。研究入口以大六壬为主，结论不可直接外推其他术数体系。

## 1. 核心问题

应期需要解决：事件是什么、何时可发生、哪种触发与本事件有关、选哪一轮、能细到什么程度。

取数需要解决：数什么、单位是什么、取哪个对象、用哪套数、怎样运算、数量量级如何定位、最后怎样选择点值。

共同缺口是：同一套符号常能生成多个可解释的答案，但缺少事前排除其他答案的充分条件。应期中的同一支可以落在多个年月日；数值中的同一个基础数可以解释成个位、几十或几百。口诀有出处与预测能精确区分，是两项不同的证据。

## 2. 本次核到的材料

### 2.1 古籍已经提出数制与增减，但仍留有量级选择

《六壬粹言》本地文本“数目”段：

> 少者以河图数取之，多者以先天数取之，仍以旺相休囚为之增减。
> 如寅加辰为用，寅七辰五，五七三十五，进一位为三百五十，或三千五百也。

它直接涉及数制、乘法和进位，也直接留下350与3500的分歧。“少者”“多者”本身需要事前定义，不能等知道结果才选择。

同段以相气举4×7再倍得56；《理法简易》相关注解则有“相则相乘而不进位”的说法。这至少表明应分别登记文本与算法口径，不能统称“旺相增数”后任意采用。异文、注解或流派差异尚须进一步校勘，本轮不裁定哪一种正确。

《六壬经纬》“数目”段并列五行数与“子午九、丑未八……”并以“旺相多，休囚少”收束。这能支持相对多寡的候选解释，尚不能单独给出十倍或百倍的边界。

《苗公射覆鬼撮脚》有十二支数值以及物性、形色、旺衰规则。本轮所读内容不能证明这些条目已解决精确数量级；物性判断与数量判断须分别研究。用户提及的《东方朔射覆歌》尚未完成独立原文校勘，不声称已经研究完其完整数法。

### 2.2 案例标签需要按问项复核

`案例项目库/交易占/case-016-服装店闭店应期复盘.md`载原预测6月30日、7月4日，反馈闭店为7月18日；整案标签却为“验”。正文又将7月4日解释为决策日，当前所读记录没有决策日的独立反馈。因此：店铺类型与应期应分项评分；两个日期不能计为闭店应期命中；决策日解释只能列待核假说。日期干支本轮未另作历法校验。

`案例项目库/事业占/case-010-工作调动应期复盘.md`则明确保留应期失准，并把“临宫巳＋遁丁→丁巳”列为事后单例拟合，指出尚不能解释为何取这一轮。这类记录边界应沿用。

`经验日志/2026-10-18-事业占-名次数取法与官鬼空误读.md`保存河图/大衍分工候选，但“名次属少数目”“阳日取生数”“初末对应两榜”等不同环节的证据强弱并不相同。不能因最后能凑出2、3，就把整条推导当成已验证规则。名次范围也由参评规模决定，不能把所有名次都预设为个位数。

### 2.3 当前独立工作流已有约束，数值模块仍待细化

本轮读取了相邻项目`大六壬研判工作流`的AGENTS、README、liuren-timing及references，以及method-timing-trigger-selection、method-linfeng-timing、method-object-attributes。

当前应期流程已要求：命名事件阶段、确定尺度、比较触发路径、区分同源证据、校历、限数和冻结。无需把这些再次包装为新发现。两张所读应期卡的校准字段均为not-calibrated、独立留出事件0；这是卡片记录，不能据此推断整个项目从未有任何验证。

所读方法目录与对象属性卡未见独立覆盖“数制—运算—量级—点值”的数值方法卡。此次为定向检查，不等于穷尽所有资料。

## 3. 建议研究的判断链

### 3.1 应期：事件—可行窗口—触发—轮次—日时

1. 事前固定终点。通知、批准、执行、到账分开；问到账不能以批准日替代命中。
2. 只使用事前已知的流程、距离、观察期限作为现实边界；未知资料保留未知。
3. 按对象与事件阶段选主路径，例如类神落宫、障碍解除、三马、视用视末。传统机制是待检验的预测解释，不视作已证实的现实因果。
4. 生成少量候选，明确为什么取冲、合、填或值，互斥规则不混算。
5. 专门解决“哪一轮”：如果只定位巳日，应比较观察窗内不同巳日；如果只能定位一段时间，不能直接声称精确到日。
6. 给出主选及其最强竞争日期为何被排除。没有区别相邻日期的证据，就记录尚未解决精度问题。

“只差一两天”应分析误差结构：是否长期偏早、是否错把通知当完成、是否偏移到相同干支的下一轮。稳定偏差须在连续样本中出现，才能提出修正规则；不能看到一例就加两天。

### 3.2 取数：对象—单位—数制—运算—量级—点值

1. 分清数量类型：件数、人数、名次、金额、重量、长度；价格还须分标价/报价/成交价，金额还须分总额/净额/本次到账。
2. 绑定取数节点：类神本支、落宫、遁干、年命上神等，各自按原文条件使用。节点不能随答案更换。
3. 事前登记数制：五行生数/成数、“子午九”一系、宫数等分别命名，保存实际映射表，避免“先天数”同名异义。
4. 逐项登记加、乘、倍、减半等运算的前提。“旺”是否支持进位、进几位，须另有规则与验证。
5. 单独推断量级。十几与几十可先放在10—99的十位层，再辨10—19和20—99；不能把“十位对了”说成数值已准确。
6. 最后选择点值。算出7并不自动证明70或700；在350和3500间没有判据时，记录量级未定。

可检验的量级线索包括：事前总额与上限、对象可容纳数量、传统旺衰进退规则、整体/部分的对象区分、分批/一次的事件区分。这些线索的贡献要分别记录。现实边界带来的缩小与课式额外带来的缩小，不混记为术数预测能力。

金额、人数等具有现实生成过程的数量，与随机编码、号码逐位还原分开研究；前者有效不证明后者有效。

## 4. 怎样研究取数很准的判断者

优先取得连续、完整的题目记录，保留失误，不能只选精彩案例。每题至少记录：

- 事前原问、背景、是否看过答案、起课口径。
- 第一取用对象、数制、运算、进退位条件；应期则记录阶段、尺度、触发、轮次。
- 最终答案与当时容差、最强备选以及排除理由。
- 原始反馈与可核依据；复盘和新假说另存。

重点追问“为什么此处取700而不取70”“为什么取本轮而非下一轮”，观察其能否对条件相近的另一题作同样可复现的选择。其经验可能含有未写成口诀的条件，也可能有题目筛选、背景信息或成功案例留存的影响；本轮证据不能预先决定原因。

若对方当时只是直觉报数，应如实保留，不能由AI替其补写一套漂亮的事前推导。可以检验判断是否稳定，暂时不知道机制。

## 5. 一轮可执行的研究安排

先限定一个事件类和一种数值类，例如退款到账日期与实际退款金额；输入条件差异很大时再拆分。先整理约30—50个事件作为探索材料，前提是确有足够可用记录；这不是证明有效的固定样本门槛。当前已看过反馈的案例属于开发材料，不能充当未见答案的盲测。

第一步：把原文整理成方法卡，逐条填对象、条件、算法、量级、反条件、版本和出处。不能完整执行的规则标明缺口。

第二步：按问项清理案例标签，区分事前命中、接近、失误、无反馈、事后解释；不覆写原预测。复盘产生候选规则，不自动进入正式方法。

第三步：在开发材料上比较少量事前定义的方法分支，形成一个冻结版本。反复调规则的全部材料都算开发数据。

第四步：在未接触反馈的新事件上连续冻结判断；历史资料若已被模型或研究者读过，则如实标注曝光限制。按事件隔离转载、复盘和衍生资料。

第五步：比较仅用事前背景、当前工作流、加入候选方法三个版本。模型、输入与题目保持一致。小样本先报告逐案误差及不确定性，不报精确胜率。

评分分层：

| 研究目标 | 同时记录的结果 |
|---|---|
| 应期 | 事件是否发生、精确命中、±1天/±2天命中、绝对误差、方向偏差、是否错轮、窗口宽度 |
| 取数 | 量级是否正确、绝对误差、相对误差、低估/高估、区间宽度；实际为0时相对误差另处理 |
| 所有题 | 主选与多选分别计分，未定率/覆盖率，现实基线成绩，反馈质量 |

应期评估须有固定观察期限，未发生、尚未观察到和明确不会发生分开。数值误差在100与10000两档不可只用同一个“差10”标准；容差须在反馈前确定。过宽区间与大量备选不能获得和单点预测相同的精度评价。

## 6. 当前可作的结论

本地资料足以支持开展专门研究，也已经暴露出“数制选择”“量级进位”“应期轮次”“整案标签掩盖分项失误”等具体问题。尚无本轮证据证明某套方法能稳定精确到一两天或少量数值误差。

最有价值的后续产物是：一套可事前执行的取数方法卡、一组专门比较相邻日期与不同轮次的应期案例，以及按冻结答案记录的连续验证结果。研究成功既包括找到有效条件，也包括明确哪些步骤目前没有足够信息可解。
