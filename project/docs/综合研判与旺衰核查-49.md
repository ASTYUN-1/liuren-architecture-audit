# 综合研判与旺衰核查：49版本机说明

活动版：`20261112-integrated-flow-49`。本机OpenCode和Codex共用；网站、APK及服务器未发布。OpenCode重启后新建任务加载；Codex新任务读取活动指针，历史任务沿绑定资料。

## 判断主线

依北海“明占类，定侧重，看显象”整理为：明确原问与成功标准→观察实际气势并确定切口→依专项取类定位→察气地、阴神及有效作用→处理最强反证后按问作答。理气贯穿，不增加六十四课独立裁决轮次。

核心新增五项简明执行要求，完整来源按需查analysis-workflow；婚恋、考试、任职晋升、应聘、财务、失物走失补入首取/职责/条件递补。官讼新增litigation，普通是非仍走interpersonal。其余原有分类保留专项方法，共17类。

首取不是不许纠错；有原问误解、职责错配、漏读专法、可靠坐标错误或新事实，可以重核。不能只因另一候选更旺、答案更合意就改选。原法明确允许依空、不现等递补时仍按条件执行。考生、成绩、学校、证书、通知等不同职责不互换；类神不现与年命未知分开。

升学采用《金针》河魁第一类象，禄/长生为学校目标，另核接纳关系；保留《理法》研究生考核的幕贵/魁星分支。不同书分支存在时按阶段与职责核实，不宣称无条件等同。其他现代未核细分继续披露缺口。

## 课体与毕法如何进入

- 默认裁决核心的bifa_conditions只列“条目、成格”，客观扫描不截断、不按吉凶排序。
- 正式完整盘导出仍保留“条目、成格、意象”；意象同时保存在任务绑定参考。需要时沿已有reader用BF-35等查百法录及已存子格，用BF-B35/BF-D35查原章。
- 先定本问职责，再决定哪条结构需要理解，不要求逐条解释。扫描成立不是相关性判定，程序不按关键词自动选择主类或主格。
- 保留45版毕法格名作描述辅助的采用边界；底层实际作用可进入综合判断，取类、空亡、阶段等基本方法继续履行。同一关系的多个名称不加票，上位结构与子型不重复计证。
- 课体表撤除固定“先定整课吉凶基调”“毕法结构定关键”和凭课名直接锁定来意等执行措辞，保留定义与来源倾向。整体气势可供切口，但北海未明确界定的氛围翻判不编成自动规则。

## 旺衰工具实际用法

先取用和说明通路，再计算。已有单宫结果足够时复用；对外关系涉及数值增减时提交完整关系快照补算，不手加分、不全盘自动生克、不沿上次结果叠加。

需要查漏或解释状态依据时，在原strength对象加可选`review:true`：

```json
{
  "action": "strength",
  "strength": {
    "mode": "single_palace",
    "season_profile": "quarter-earth",
    "season_basis": "示例：实际须说明本问所用原法",
    "actors": [
      {"id": "T:子", "role": "示例所问对象", "basis": "示例，不主张实际应取子"},
      {"id": "T:酉", "role": "示例有关对象", "basis": "示例，实际须依问取用"}
    ],
    "review": true
  }
}
```

主智能体附可信archive，裁决者沿绑定原盘；Codex仍用现有compute适配接口。`selected_relations`也可加review，不强制先跑一次single_palace。evaluation中的strength同样支持。

| 返回项 | 解决什么问题 | 不能据此宣称什么 |
|---|---|---|
| coverage | 标明提交/计算/跳过关系数和作用边界 | 已验证类神正确、已覆盖全部关键关系或可判成败 |
| review.state_basis | 看各已选对象五气、十二气参照、空亡、通达、直接关系及适配提示 | 总体有效作用已经完整计算 |
| review.relation_candidates | 查已声明对象之间生克、刑冲合害等事实，分是否提交及已有直接关系 | 所有事实都切题或都应当补算 |
| review.season_comparison | 同一对象与关系分别核双表，显示数值差异 | 自动择高分表、平均两表或按两份证据使用 |

默认不输出扩展review；它不是每题新增的必做轮次。范围仅为已声明对象，不扩为十二宫任意关系网。候选事实不进入计算，只有经原法确认后明确提交的links才补算。将的乘支空、地盘空与支神自身空分列，不给天将另造旬空身份。

## 仍缺什么，以及暂不补什么

| 边界/缺口 | 本次处理 | 后续需要的工作 |
|---|---|---|
| 取用理由及作用通路的专业真伪 | 明确专项职责；工具不伪装已经验证 | 依原文及重复输入、条件对照检验模型执行 |
| 关键关系是否漏选 | 允许定点检查已选对象间关系；沿现有核对查漏 | 验证最强反证及相关施受者能否稳定纳入；不能把全部五行关系自动算入 |
| 生克系数与通路比例的专业精度 | 维持原研究参数，新增双表差异可见性 | 建立参数来源及敏感性、结果校准证据；本次未新增系数扫描功能 |
| 三合、半合、三会数值与自动合化 | 依原决定暂缓 | 原法条件先核，不因缺分数从专业判断删除 |
| 刑冲、神煞及事件专项完整效力 | 展示相关事实及适配提示；按原法定性 | 分条件补适配，不能统一加减分 |
| 出旬、冲填及未来兑现 | 保留既有时间工具与政策身份 | 审核不同阶段到底解除什么条件；不自动把出旬当成功 |
| 现代考试、岗位、司法全部细分 | 补已核首取与职责，缺口保留 | 专项逐段回源，不能把传统映射无据机械现代化 |
| 真实预测效果与执行稳定性 | 不宣称已经通过 | 新题重复执行、条件对照与有明确结果的独立验证分别记录 |

此次没有改变旺衰系数、空亡综合口径、季土双表取法、合局数值暂缓决定、模型选择或额度；没有新增裁决者或补核次数。材料增补有连续来源，来源已核不等于预测已验。
