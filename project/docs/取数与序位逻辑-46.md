本次修正“第几名”被数量问句预检漏识别后，AI把接口限制解释成术理禁令的问题；同时补强抽象数值目标的取用、专法来源与修正逻辑。沿原来的取用—综合作用—数量方法—独立裁决—核对交付，不新开工作流，不新增裁决或固定名次公式。

- 数量规程明确物数、连续量、序数、等第和变化量的区别；没有实物或满分，不构成禁止取数的理由。
- `quantity-rank`提供《说约》《粹言》《壬窍》《指南》及北海注解等有源方法入口；`quantity-rank-evidence`提供QR01—QR07连续书证，保留未校勘、起遁争议、案例缺步及原载反馈身份。
- 具名计算目录明确其非穷尽性。有完整适用算式可沿现有quantity expression执行，算式执行不证明取用或现实含义正确。
- 旺衰补算、数量公式分支及数值修正继续分层。名次数字通常越小越好，不机械折半；研究指数不能直接换排名、百分位或概率。
- 区间和中心估计同样核形成依据；不将人数中位当个人名次，也不把前问倾向擅改成用户后问的条件。
- 原五项review核原问、实际计算及精度。遇具体错误仍只走原有一次补核，不增加强制字段。

OpenCode用同一任务的`liuren_adjudication_read`及file_path/sha256，按module查询上述模块；Codex沿同一run的`action=read,module=quantity-rank`查询。准备者读活动quantity；裁决核心含简短路由，详细页仍按问触发。
