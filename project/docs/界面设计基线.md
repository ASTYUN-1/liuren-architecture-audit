# 问衡界面设计基线

设计参考：`output/imagegen/home-concept.png` 与 `workspace-concept.png`。由用户授权的 Conpera Image API 生成，已逐张查看。图片只作为设计参考，不作为页面截图贴片。概念内虚构档案/报告文字只说明版式，生产界面只展示后端真实数据。

背景锁定纸白 #F6F4EE，正文墨青 #182A28，操作绿 #205C50，强调朱砂 #A84532，分隔线 #DDDCD3。正文为系统中文无衬线，标题以 Noto Serif CJK SC/宋体后备表达克制的东方阅读感。正文 16px/1.75，报文 17px/1.9；桌面首页标题 72px，手机 44px。圆角以 10px 为主，避免层层卡片；细描边、低阴影；绿色实心主按钮，描边次按钮，明确可见 focus ring。

首页 1280px 容器：左 38% 叙事和十二支原生线图，右 62% 问事输入。原生组件实现完整三种起课设置、确认、登录后创建真实草稿。下方开放式三步说明和一条价格带。允许首屏文案：品牌“问衡 · 六壬问事”、导航“开始问事 / 自助排盘 / 我的档案”、标题“把一件事，问清楚。”、“一事一档，先看完整解读，再把疑问逐一聊清。”、问事与定价文案。无营销假指标、勋章、虚构成功率。

档案工作台：左 230px 文件列表、中间弹性阅读区、右 280px 固定盘面和权益；宽度不足 1100px 时右栏转下方，手机文件栏折叠为返回列表。报文采用安全 Markdown，报告、回答与盘面都来自服务器。视觉参考中篇章侧线朱砂用于真实报告标题，不预设实际结论。

组件：AppProvider 管理语言和真实账户；Header/Footer 公共框架；QuestionForm 管理必要输入；ChartPanel 精简/展开盘面；PaymentPanel 明确占位和人工核验；CaseWorkspace 真实任务/报告/追问；账户与运营页共享表格、状态与 notice。所有必需功能双语，手机触控目标不小于 40px。

无图片覆色。收款占位为原生非二维码图案并明确不可付款；正式支付图片只读取后端配置URL。状态、付款、报告和追问均不使用浏览器假数据库。仅登录前待提交输入可用 sessionStorage 暂存，语言偏好可用 localStorage，不存密钥。

无障碍与响应：表单标签关联，键盘可操作 tabs/按钮，语义 main/nav，错误 role=alert，加载 role=status；移动阅读和流程优先。尊重 reduced-motion。不得把模型工具、供应商密钥和内部上下文展示给普通客户。
