# 业务虚拟机固定6GB内存调整

2026-10-25 01:52（北京时间），用户授权优先稳定运行、给业务虚拟机6GB内存。此次只调整旧电脑Hyper-V的SlopeUbuntu，不发布应用代码、不改变VPS配置或账号权限。

## 变更与原因

旧电脑Windows物理可见内存15.84GiB，变更前可用9.20GiB；SlopeUbuntu原动态内存最低2GiB、启动3GiB、最高6GiB，实时分配约2.7GiB。最高6GiB是上限，不是启动3GiB再额外分配6GiB。

改为关闭动态内存，固定启动/运行6GiB。用户确认宿主机基本不运行其他应用，固定分配可避免业务内存被动态回收。变更后Hyper-V确认MemoryAssigned=6442450944、DynamicMemoryEnabled=false、Startup=6442450944；Windows仍可用约6GiB，未向虚拟机分配全部物理内存。

启动内存决定虚拟机开机时获得的内存；固定模式下也就是正常运行的分配量。不能仅提高动态上限就声称始终有同等内存。
