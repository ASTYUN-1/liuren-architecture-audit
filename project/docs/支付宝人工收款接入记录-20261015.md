## 人工核验流程

1. 用户注册并验证邮箱，提交问题、确认档案，创建订单。
2. 订单页面显示应付金额和此支付宝收款码。
3. 用户自行扫码、支付准确金额，并提交交易参考。
4. 管理员在自己的支付宝流水核对真实到账，再到运营后台确认并填写实际交易参考。
5. 系统事务发放权益、排队 AI 任务，交付报告并支持追问。

个人静态码没有支付回调，不能自动认定到账。网站不会因为截图、点击“已付款”或填写任意参考号而发放权益。退款也须先实际退回资金，再在后台记录退款交易参考。
