# 同类网站参考与大陆版调整建议

核查日期：2026-10-15。用途：产品与接入方案研究；本轮未修改网站、收费、模型提示词或服务器配置。

## 一、结论与证据边界

大陆版应按真实的“专业排盘与 AI 辅助研习工具”建设，保留对 AI 盘面分析的产品规划，不预先裁剪为纯历法网站。个性化事件解读和收费能力能否在大陆入口开放，需按实际服务确认受理与支付准入；不能只替换文案。

同类网站的存在说明产品有运营案例，不足以单独证明其全部现有功能已获审核或我们必然能取得同样准入。大陆可访问、搜索引擎收录、ICP备案、经营与支付资质是不同事实。没有登录、充值、注册测试，也没有绕过内容限制。

## 三、为什么这些站可以提供服务

目前无法核实每个站的具体接入与审批路径。常见可能是境外节点有较好的大陆线路，或已有大陆备案与相应接入；公开页面不足以判断是哪一种。域名后缀、简体中文、搜索收录、积分与会员界面均不能确定服务器所在地或许可范围。免责声明用于解释服务边界，不能保证免责或备案通过。

本项目已实际遇到的阿里云未备案域名拦截，与页面是否使用“算命”字样不是同一个问题。调整产品不能直接解除该网络拦截；改善香港线路也需单独测量。

- https://help.aliyun.com/zh/icp-filing/basic-icp-service/change-the-record

## 四、问衡大陆版建议

### 产品结构

候选定位：问衡——专业排盘与传统术数辅助研习工具。实际申报功能需据最终开放范围准确描述。

导航建议：排盘工具 / AI辅助分析 / 典籍与规则 / 案例研习 / 我的记录。

首屏以免费排盘和真实盘面示例为主，介绍起课设置、盘面阅读、分析依据。保留随机起课与移动端弹窗。输入问题用于明确讨论范围，不在首页承诺预测一定准确或保证现实结果。

AI结果建议保留：盘面事实、推理依据与引用、不同解释、条件与不确定性、现实核实建议。若实际提供个性化预测，须在功能说明与准入咨询中明确披露；不能把这种输出仅改名为“学习”就声称业务性质改变。香港版原专业 skill 与判断流程不因大陆定位调整而直接覆盖。

增加来源可追溯的知识、规则说明和脱敏案例；有检索或阅读古籍功能时，另核对资料使用权及对应服务要求，不能假定改成“书籍服务”必然更容易接入。

### 交易与增长

- 免费排盘保持无需登录；深度AI分析明确免费体验范围和实际消耗。
- 初期优先按档案购买，待复购与成本数据明确后评估额度会员，避免无限次承诺。
- 若采用积分，购买页同时显示人民币金额、对应权益及每次消耗。购买积分、赠送积分分账，失败退回、订单幂等、退款与奖励撤回留痕；赠送额度受控。
- 真实自愿打赏与购买指定服务分别描述，不用“打赏”替代实际交易说明。
- 邀请采用单层双方优惠，经过邮箱验证、真实使用或有效订单验证后发放；设置总额和重复注册限制。现有活动要先核实再修改，不凭本报告认定当前实现缺失。
- 上线前确认渠道确实接受实际业务，查明收款方、结算周期、退款和冻结处理；积分不改变渠道审核的基础交易性质。

### 双版本实现原则

保留香港业务。大陆与香港共用排盘引擎、可复用组件；用独立部署配置和服务端权限决定各入口开放功能。不能仅隐藏UI或信任前端字段；大陆入口不应通过同源API、历史结果、邮件链接或订单接口意外开放未纳入范围的能力。

共用账户/数据时保留host-only会话和明确授权，数据权限不因新增入口扩大。通知、回跳、支付回调和邀请归属需按版本核对。是否使用同一主域名或另购工具域名应向接入商确认；子域名与境外部署均不自动隔离实际业务责任。

## 五、执行顺序

1. 提交真实的页面样稿、AI样例、付费说明和同类参考，取得人工备案受理意见：纯排盘、AI规则说明、个性化事件解读、收费分别确认。
2. 在已确认范围内制作大陆工具版；香港业务继续运行，不用临时审核壳替代长期版本。
3. 同时对香港入口做大陆多运营商访问测试，分别测DNS、TLS、静态首屏、API和AI任务恢复，根据数据调整线路。
4. 以真实主体和真实业务申请支付接入；先低额测试订单、交付、退款和结算再扩大流量。
5. 大陆版上线验收包括服务端功能边界和实际公网连通；后续普通UI迭代正常推进，实质服务范围变化先核对变更和资质要求。

本报告是调整建议，不代表备案、支付或公网可用性已经获得保证。
