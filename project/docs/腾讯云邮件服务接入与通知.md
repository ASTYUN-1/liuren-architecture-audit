## 邮件种类与内容

| 种类 | 模板 ID | 触发与内容 |
|---|---|---|
| 邮箱验证／更换邮箱 | 225066 | 用户主动申请，发送有时效的验证链接；不是数字验证码 |
| 重置密码 | 225067 | 用户主动申请，发送重置链接；非本人操作可忽略 |
| 结果就绪 | 225068 | 主报告或追问完成，提醒登录档案查看 |
| 服务状态 | 225069 | 补充资料、任务失败、退款进度，提醒登录查看；不宣称退款已到账 |

## 队列与费用控制

- 数据库迁移 `005_mail_outbox.sql` 已上线。业务事务内产生去重事件，worker 逐条发送；邮件失败不回滚报告或退款。
- 队列不保存邮箱地址、认证链接、问题或报告；发送时读取账户当前已验证邮箱。删除档案、未验证邮箱、超过七天的通知不发送。
- 全站每日最多 100 次发送尝试（含失败），同收件人验证／重置共 5 次／小时，服务通知共 20 次／小时。腾讯控制台当前域名日上限为 500，以控制台后续实际规则为准。
- 腾讯免费额度、充值余额、日上限是不同限制；免费额度不是永久免费承诺。此版本没有自动购买、充值或升级功能。
- 明确限流／未配置等失败最多重试 5 次、间隔 30 分钟。超时或 worker 中断不能确认是否已经发出，标记待检查并停止自动重发，避免重复轰炸。
- 后台显示 pending／accepted／failed／suppressed 汇总。定位问题应查腾讯发送记录和安全错误码，禁止输出原始 API 请求、认证链接或密钥。当前没有自动投递回执，因此不能将 accepted 命名为 delivered。
