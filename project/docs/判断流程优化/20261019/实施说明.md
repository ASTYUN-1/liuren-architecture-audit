# 判断流程与占类 skill 优化：首轮实施

本轮已修改项目级 `.opencode/skills/`。目标是让模型更清楚地选择判断方法、处理反证并按不同目标分别作答。保留原书引述、历史例案和所需主干检查，不把新方法观察伪装成已验证术理。没有启动批量分析、调用付费模型或发布网站资源。

## 本轮依据与覆盖

程序清点新201例中的1619份作答材料，从中目的抽样精读并登记16份论证，另核对本地原书9段，形成25张可追溯观察卡。原载作者身份及作答是否先于反馈未独立核实，因此称“原载作答方法参照”，不能声称已还原真人真实心理过程。

- [方法观察](方法观察.json)：原句、文件、行号、哈希、逐份作答指针、观察身份和未采纳部分。
- [开发样本](开发样本.json)：16个方法来源案，加4个本轮看过作答但未采纳的案，共20个已暴露来源。它们及其转引不能作为本轮新方法的独立盲测。清单不自动修改分析队列。
- 没有声称精读全库1619份作答或所有808个经验条目。原始案例、经验日志与201例资料没有被重写、转正或增添验证次数。
- 异体系作答和混用保留在源资料，不将其中六爻、紫微、小六壬公式改写为大六壬规则。作者归属疑点、缺失权重、方向矛盾与数值缩放疑点均保留。

观察身份分为“原文明示”“文本可推知”“无法确定”。实际有据才记录步骤，缺失处不补出一套完整思路；书写顺序不直接当作决策顺序。反馈后的解释不回填成初判。

## 主 skill 的实质变化

| 原有问题 | 当前执行方式 |
|---|---|
| 只分成败、存现、趋势，复合问题容易混为一问 | 先定义对象、阶段、成功标准、时间范围；数目/程度/方位/时间另列目标 |
| 课体优先、类神定结局、将高于神同时存在 | 按本问、位置、状态和例外选择主线，明确最强反证改变的是哪一层；没有理由就保留分歧 |
| 命中凶煞或凶课体后跳过结构/位次 | 保留检查，先成倾向后核反证，不以一个信号提前结案 |
| 要凑三个最不利信号 | 检查实际最强反证；偏凶判断也检查吉证，不强凑数量 |
| 判断完成后才检索 | 定侧重前查方法、条件、反例；步骤10复用核未解决冲突，有新问题才补查 |
| 古籍排在最后兜底 | 原书用于定义方法及其条件，案例反馈和优秀作业用于不同目的的对照 |
| 两条方法同向自动高置信 | 内部一致性、条件适配、材料完整性、独立验证分记 |
| 任何题都加载应期并追求精确日期 | 有时间任务才执行；先定事件节点与尺度，依据不足可停在范围或标待核 |
| 已有程序盘仍可能回到起盘步骤 | 可靠 facts 直接使用，发现来源/历法矛盾待核；不由模型手算改盘 |

仍要求实际执行相关 skill、进行检索与出处核对，DeepSeek 不得调用子智能体、task或后台智能体。没有为了少用 token 截短原文或免除必要检查；同轮已加载的规则和候选包可以复用。

- 25张观察卡逐条核对原句、行号/指针与哈希。17个修改入口的原书引述和历史A1例案完整保留。

- 未调用真实模型、未做独立盲测，不声称判断准确率已经提高。后续须用未参与开发且未泄露答案的独立案例，对比旧版和新版；分别统计真实结果命中、优秀作业一致性与方法执行完整性。
