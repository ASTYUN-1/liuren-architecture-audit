# 2026-07-23 交易占·闲鱼卖头盔·伏吟元胎空亡出货

## 课式指纹
- **四柱**：丙午 乙未 戊戌 戊午
- **课体**：伏吟、元胎、斩关、孤辰
- **三传**：巳（空·勾陈）→ 申（白虎）→ 寅（腾蛇）
- **旬空**：辰巳（甲午旬）
- **月将**：午

## 占问
闲鱼挂卖闲置头盔，挂价1520，有人问价。问①能否成交 ②成交价。

## 模范结论
能成交，砍价卖，成交价1350（寅三数）。

## 关键技法

### 1. 卖货占与买货占方向不同——核心一课
**卖货占 = 空亡读"货离手"（卖出），非"交易虚"。**
初传巳空亡，卖货卦中意为"货没了/出手了"，而不是"事不实"。

### 2. 子孙申为买家
申为戊土之子（戊生申），交易占中子孙=买家/客户。申乘白虎主动速。

### 3. 寅蛇砍价 + 丁酉太常速卖
- 寅为官鬼克干 → 砍价压力
- 寅腾蛇缠价 → 对方缠着你砍
- 寅通道丁（丁马）→ 卖得快
- 太常酉 → 宴喜有成

### 4. 寅三数定成交价1350
寅先天数三，断价1350（挂价1520砍170）。

### 5. 贵人丑在课
丑为贵人通行于申，有人要买之佐证。

## 失败归因
最初读课错误地将空亡=事虚、寅克干=结果不利，忽视了**卖货占的独特视角**——空亡不是"卖不掉"而是"货不在了"（已售）。以后遇到卖货/出货占，空亡一律优先考虑"货出"而非"事虚"。
