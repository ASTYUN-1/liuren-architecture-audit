# 2020-06-08 疾病占 狂犬病虚惊——发用空亡断"忧不能成"

## 经验规则
当 疾病占（未病先防/恐病型）见 发用空亡 + 课传无官鬼 + 救神（天医/生气/解神/天赦）齐现乘吉将 时，应断为 虚惊为主、所忧之病未成实，因为 发用空亡不能成愁（集应钤直断"虽谓之愁课，幸发用空亡，不能成愁"）、课传无鬼则病根不立、救神乘吉将则医药得力。

## 辅助规则
1. 白虎乘日干旺地（比劫同位）→ 惊恐之象 > 病实之象；白虎归本家+闭口+多凶叠加才是死课（对照 case-004）。
2. 二烦/三交等极凶课体，在夏占凶轻，且发用空亡可整体削弱——"课体定环境，类神定结局"。
3. 罡塞鬼户（贵人临寅鬼户）→ 鬼气出入被塞，病不发作之象。
4. 空亡是"暂虚"非"永虚"：应期看出空（出旬）或冲空（卯冲酉填实），行动上宜"填实验证"（如完成接种/检测）。
