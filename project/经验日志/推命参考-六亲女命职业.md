## 一、六亲详断

### 六亲类神总表

| 六亲 | 天将类神 | 六亲爻 | 辅助类神 |
|------|---------|--------|---------|
| 父 | 太常 | 印星 | 贵人、德神、长生 |
| 母 | 天后 | 印星 | — |
| 兄弟姊妹 | 太阴 | 比劫爻 | — |
| 妻（正室） | 天后 | 财爻（阳神） | — |
| 妾（偏房） | 太阴 | 财爻（阴神） | 从魁所乘之将 |
| 子女 | 六合 | 子孙爻 | 太冲、登明 |

> **注：** 天将说与六亲爻说各有理据。壬诀云："体用勿从呆处觅，类神须向活中看。"

### 六亲判断原则

1. **类神旺相生扶日干或本命，不逢空落空** → 有缘扶助，得其力
2. **类神克害干命** → 不得其力
3. **类神反伤或逢空落空** → 与该亲无缘
4. **须参看十二宫之对应宫位** 方为完善

### 父缘判断
- 太常旺相生扶日干或本命 → 父有缘扶助
- 太常克害干命 → 不得父力
- 太常临克或刑 → 父不力
- 太常逢当年太岁冲 → 当年丧父
- 太常受三传所克 → 父缘薄
- 贵人（辅助）落陷 → 父缘薄
- 偏财逢空 → 父缘薄

### 母缘判断
- 天后旺相生扶干命 → 得母爱
- 天后受克或逢空 → 母缘薄
- 天后所乘之神被干支上神冲克 → 母离开或死亡
- 天后虽逢空，得支阴神合起 → 母缘仍可论厚

### 兄弟判断
- 太阴旺相生扶干命，无刑冲克害空亡 → 得兄弟姊妹之力
- 比劫逢伤或入墓 → 兄弟少或孤独
- 兄弟爻被三传会局克伤 → 无兄弟
- 兄弟爻逢空又受克 → 无兄弟
- 兄弟爻之数可用地支数推算（如辰土为五 → 五兄弟）

### 妻妾判断
- 天后（妻）财爻与干命相生，无刑冲破害 → 得贤妻
- 日辰相生相合 → 夫妻和顺；相克相冲 → 夫妻反目
- 龙后互伤 → 琴寒瑟冷；阴阳欢合 → 夫唱妇随
- 辰克日 → 河东狮吼（妻克夫）；日犯辰 → 鼓盘而歌（夫克妻）

### 子女判断
- 六合子孙爻旺相生扶干命 → 得孝顺之子
- 子孙爻乘凶将或受克 → 悍逆之子
- 子孙旺相 → 多；休囚 → 少；空散 → 刑冲
- 带吉神 → 贤良；加凶神 → 顽劣
- 子作白虎而下见离明 → 多主螟蛉承嗣

### 出身判断
- 本命落旺相、乘吉将、不逢空 → 富贵之家
- 胎神旺相 → 出生富贵
- 咸池凶杀临身 → 出身微贱
- 禄马贵神扶日 → 立命清高

## 二、女命专法

### 总则

> **"推妇人之命与男命不同，惟取其柔顺情正为吉。"**

- 女命专看支爻
- 以官为夫，喜长生福德禄神，忌咸池丁马
- 支爻最宜安静，少推天后，老验太阴
- 以青龙为夫，六合为子，太阳为姑

### 夫星判断

| 天将 | 夫之类型 |
|------|---------|
| 天乙（贵人） | 必为尊贵 |
| 太常 | 富室 |
| 勾陈 | 平庸 |
| 青龙衰弱 | 良人愚蠢 |
| 官星强盛 | 夫主才权 |
| 龙并吉 | 淑而又慈 |
| 虎倚凶 | 淫而且悍 |

### 女命坐宫判断

| 坐宫 | 含义 |
|------|------|
| **克宫** | 慎重而有礼 |
| **生宫** | 太过而娇恣 |
| **冲宫** | 动摇，再嫁之虞（抱琵琶而过别船） |
| **害宫** | 不睦而嫉妒 |
| **刑宫** | 多刑伤暴戾 |
| **德禄宫** | 命妇，端庄有福 |
| **空乡无救** | 寡妇孀居无依 |
| **丁马+勾玄阴合** | 恐弃礼义而私奔 |
| **丁马+吉将他宫遥制** | 又当以贵论 |

### 女命特殊判断
- 男命德与学堂 → 为官清正；与长生并 → 富厚
- 女命遇破害为学堂 → 青楼之人
- 女命值德禄为学堂 → 贤德之母
- 合多而众杀加驰 → 烟花之女
- 鬼聚而诸凶互对 → 再嫁之妇
- 支带勾陈兼福德 → 孟光再见（贤妻）
- 财临玄合并咸池 → 河间重见（淫妇）

## 三、幼童命法

### 总则
看幼童命，先看六合子孙爻，次看四课阴阳、三传德禄。

### 易养难养

| 条件 | 判断 |
|------|------|
| 六合子孙爻旺相相生扶助 | 易养 |
| 旺相身肥 | 终易养 |
| 休衰体弱 | 难为 |
| 干临父母 | 必得抚育之恩 |
| 日驾子孙 | 完获劬劳之报 |
| 父母被冲 | 儿缺乳 |
| 金爻动合 | 哭无声 |
| 纯鬼 | 难养 |
| 俱兄 | 易长 |

### 聪明才智

| 条件 | 判断 |
|------|------|
| 四课阴阳旺相、三传德禄交加 | 才高名远，仁厚荣华 |
| 吉会乾宫 | 白香山期年识字 |
| 凶加震位 | 李魏公九岁能行 |
| 纯阳驭德 | 豁达高明 |

## 四、职业品格

### 职业判断
- 看支上辰（地盘日支上之天盘神）
- 金 → 刑、兵属金行业；木 → 农林或木业
- 水 → 水利或运输业；火 → 炉冶兵工厂、空军
- 土 → 税局或步兵陆军
- 旺相生干命 → 称职；更乘吉将 → 更好

### 品格判断（看干上辰天将）

| 天将 | 品格 |
|------|------|
| 青龙、贵人、太常 | 人品高尚 |
| 朱雀 | 品质高且文学高 |
| 太阴 | 风雅且好音乐 |
| 玄武、螣蛇、勾陈、天空 | 卑劣好勇奸诈 |

### 出生环境
- 支左为左（亦为前），支右为右（亦为后），支所冲之辰为对面

**天干象物：** 甲（大树/雷/龙）、乙（草木/花卉/风）、丙（太阳/炉冶）、丁（灯光/列星）、戊（高山/雾/霞）、己（小山/云）、庚（铁路/月）、辛（金属/霜）、壬（大海/雨露）、癸（河流/雨/泉）

**地支象物：** 子（江湖沟涧/墨池）、丑（宫殿桥梁/柳岸）、寅（广谷/梁栋）、卯（丛林/琼林/门窗）、辰（草泽/高岗坟墓）、巳（大驿/弓弩）、午（烽埃/山林）、未（花园/酒肆）、申（名都/神祠）、酉（寺钟/仓廪）、戌（原野/城牢）、亥（天门/悬河/台榭）

|------|------|

### 身材·痣·酒量·饮食

| 项目 | 方法 |
|------|------|
| **高矮** | 木长、火烟高、土卑下、金遇火可高、水依地势。看日上辰参四课三传 |
| **肥瘦** | 看食神有无伤害，财得食生+印扶日干→肥 |
| **痣** | 课传年命见木土→有痣；丙丁红痣、壬癸黑痣 |
| **酒量** | 火土多旺无水→量大；金水多旺→一饮即醉 |
| **饮食** | 甲乙日→蔬菜；丙丁→甜品；戊己→汤物；庚辛→辣；壬癸→肉 |

## 五、富贵贫贱僧道九流

| 类型 | 关键特征 |
|------|---------|
| **贵命** | 禄马官星得位，贵常龙雀司权，旺相扶援 |
| **富命** | 龙常旺相交遇财神，干命和平互加生合 |
| **文学名士** | 朱雀长生得位有气，官印墓陷，垂老蹭蹬 |
| **贫困命** | 龙常失位禄马空陷，日辰互克休衰，课体刑害 |
| **僧道命** | 空亡+华盖临午+孤寡+太冲伤支 |
| **九流命** | 玄武天空和顺+寅申丑未组合 |
| **隐逸命** | 日辰和洽但官印受制，凶煞乘空 |
| **危险命** | 犯日月亡劫，刑冲克害干命，雀虎互伤 |
