# 拂尘射覆复盘——反吟元胎课中传朱雀毛羽法

## 一、事件概述

2024年10月20日 20:20，群友出覆图中涂鸦下何物。以正时起课，得**反吟·元胎·励德**课（丁巳日第七局干上丑）。

**AI断课推理**（与射覆指掌十步法对照复盘见后）：
- 步推理链：可开合或转动 → 动物或有关 → **毛** ✅ → **一撮毛** ✅ → **有柄** ✅ → 鸡毛掸子/拂尘/扇子 → **拂尘** ✅

**实际反馈**：✅ 拂尘

## 二、课象→拂尘正确映射

| 课象 | 正确解读 | 说明 |
|:----:|:---------|:-----|
| **中传亥+朱雀** ⭐ | **毛羽主体**。亥=细碎柔绵，朱雀=毛羽光彩 | 此为中传，却是物的核心特征 |
| **干上丑+勾陈** | **握柄**。丑=土金坚硬，勾陈=方厚有柄 | 柄的类象 |
| **反吟课体** | **拂扫动作**。来回往复、天地皆反 | 拂尘拂动之象 |
| **发用巳+太常** | **根部束口**。巳=尖细束口，太常=纺织品束带 | 柄根连接处 |
| **支上亥+朱雀** | **物的本质是毛羽制品**。支为物本身 | 直接定位物类 |
| **三传巳→亥→巳** | **来回拂扫** | 反复动作 |
| **巳加亥双胎** | 两部分构成：柄+毛 | 结构特征 |
| **元胎四孟** | 毛束收束未散 | 状态特征 |

## 三、关键经验教训

### 1. 🚨 中传不可忽略——射覆三传各有其位

射覆指掌说"专用初传，中末不取"，但此案例**中传才是物象核心**（亥+朱雀=毛羽主体）。

**修正后的三传射覆权重**：
| 三传 | 一般射覆 | 此案的权重 |
|:----:|:---------|:----------:|
| 初传(发用) | 物大类/材质 | 柄根束口（次要） |
| **中传** ⭐ | 物本质/核心特征 | **毛羽主体（核心）** |
| 末传 | 价值/属性/收束 | 同初传，上下对称 |

**教训口诀**：**射覆三传各分工，发用定类中传质，末传收束见始终。中传朱雀毛羽现，亥为细碎柔绵物。**

### 2. 🚨 支上神 = 物本身——射覆必须看支

射覆须"刚日视干上神+发用，柔日视支上神+发用"，但**支为物其上是物之本质**。
- 此案支(巳)上神=亥+朱雀 → 物的本质是毛羽制品
- 干上丑+勾陈 → 物的外观/握柄

**教训口诀**：**干上定外观支上定本质，射覆不读支上如盲射。**

### 3. 🚨 朱雀≠文书——第一类象毛羽

朱雀的射覆类象优先级：
1. **毛羽/光彩**（本象：朱雀是鸟）⭐
2. 文书/信息（延伸象）
3. 彩色/赤色（颜色象）

射覆中见朱雀，**优先考虑羽毛/毛羽类物品**，这是本次案例最核心的技法是"中传朱雀=毛羽法"。

### 4. 🚨 巳≠必然电器——多义性解象

巳的类象层级：
- 射覆通义：尖细、束口、缠绕、火电
- 此案读作：**束口/根部扎紧**（柄与毛的连接处）

**教训口诀**：**巳宫类象两路分，一为火电一尖细，射覆先看尖细象。**

### 5. 🚨 反吟≠仅折叠开合——也有来回拂动

反吟的射覆类象：
- 结构义：折叠/开合（如订书器、折叠伞）
- **动作义：来回/拂扫/摆动**（如拂尘、钟摆）⭐
- 空间义：往返/远来

此案反吟读作**拂尘拂扫的来回动作**，而非折叠结构。

### 6. 🚨 太常≠仅饮食——衣帛纺织品

太常的射覆类象：
- 饮食/食品（最常见的解读）
- **衣帛/纺织品**（重要延伸）⭐
- 印绶/形圆质实

巳+太常 → 尖细+纺织品，读作**柄根系的束带/线绳**。

## 五、梳理的射覆法则（经验沉淀）

### 射覆中传核心法
三传各有分工：初传定材质中传定本质末传定属性。
射覆遇中传类象极突出时（如朱雀毛羽），**中传权重高于发用**。

### 支上本质法
干上定外观、包装、握持方式。
支上定物之本质、核心功能、材质属性。
射覆必须干上支上两读，不可偏废。

### 朱雀毛羽法
射覆课传见朱雀，优先考虑羽毛类、毛绒类、光彩毛羽制品。
结合亥(细碎柔绵) → 一撮毛/毛束。
结合未(酒食衣物) → 毛绒衣物。
结合申(硬而有毛) → 毛刷。

### 反吟动作法
反吟在射覆中可读作：
- 折叠/开合（结构）
- 来回/拂扫（动作）
- 往返/来回（轨迹）

需结合三传、干上、支上综合判断是结构义还是动作义。

### 巳宫多义法
巳在射覆中的优先级：
1. 尖细束口（梳齿、刷毛、束带）
2. 火电发热（电器、电池、芯片）
3. 蛇虫缠绕（线缆、绳带）
