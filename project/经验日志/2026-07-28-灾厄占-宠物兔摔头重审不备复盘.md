# 断课结论

## 关键依据
1. **不备课定基调**：事有缺陷，但非绝症之课。头部受伤是"缺陷"的具象化。
2. **末传白虎官鬼最凶，但寅为长生救之**：白虎乘寅，寅是戊土的长生位。白虎入长生，凶中藏生机。核心技法：**白虎乘长生=不死之象**。
3. **中传天医贵人**：医疗观察（医生建议）是课象中的正确路径。
4. **驿马空亡主虚动**：巳为驿马丁马，但旬空。头部发抖对应"马落空亡，虚动非实动"——暂时性神经反应，非器质损伤。
5. **日干戊土未月旺相**：能扛得住压力。
6. **卯（兔类神）乘太常吉将**：不在课传核心，说明兔子自身没有长期问题。

# 新增/修正技法
1. **白虎乘长生≠死**：此前案例（case-008、case-005）显示白虎入墓+无救=死。此课验证了反例——白虎乘长生+有救=不死。占病时白虎的十二长生状态是判断生死的关键维度。
2. **动物占取类**：兔以卯为类神，看卯的天地盘状态。不在课传中则问题不构成核心矛盾。
3. **不备课的预后**：不备课主"缺陷"而非"绝症"，有救神则预后可好。
4. **驿马空亡辨虚实**：发抖等神经性症状遇马空亡，主虚性反应，非实病。
