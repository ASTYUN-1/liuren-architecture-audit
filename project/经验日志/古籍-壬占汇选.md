## 【仕途官禄占】

### 1. 官星发用逢空，权摄不正

**来源**：《壬占汇选》— 邵彦和（戊申日课）

**核心技法**：官星空亡则正任不可望，禄临支上为权摄不正

**课式特征**：
- 占类：赴任占
- 课体：伏吟/玄胎
- 关键神煞：官星空亡、禄临支

**判断思路**：
寅为官星乘青龙，寅空则官必不得。戊禄在巳，巳与申合，禄在支上，故正任不可望，乃权摄不正之象。内主陈姓人不足，当西南避嫌，待陈姓退去方得正任。

**反馈**：验 — 邓某行至半途因陈提刑与父有仇不敢往，权摄公使及酒税，次年八月陈替去始得正任

**可复用规则**：
IF 官星发用（如寅）乘青龙但逢旬空，THEN 正任不可望，必为权摄；待官星填空之月（或冲空之月）方能正任

### 2. 德禄马入天门，位居显要

**来源**：《壬占汇选》— 陈公献（甲申日课）

**核心技法**：德禄马会入天门，定然位居显要；但忌旬空，难以久远

**课式特征**：
- 占类：功名占
- 课体：玄胎
- 关键神煞：德神、禄神、驿马、天门（亥）

**判断思路**：
初传青龙内战，必有奇遇趋迁；中传朱雀生日，公卿交誉；末传驿马德禄俱入天门（亥），居官定然显赫。寅为天吏，天后为恩泽，非天官而不可。嫌贵履地网，龙神下贼，主自欲退位。

**反馈**：验 — 后屡旨另推七次，终入相；次年果请旨归田

**可复用规则**：
IF 课传见德禄马会聚于天门（亥），THEN 主高位显赫；IF 同时见贵履地网、龙神下贼，THEN 先升后退，不自安位

### 3. 登三天课，占官宜升迁但忌空亡

**来源**：《壬占汇选》— 邵彦和（丙寅日课）

**核心技法**：登三天课主升迁，但登不过关则难升，过关则进锐退速

**课式特征**：
- 占类：升迁占
- 课体：登三天
- 关键神煞：辰午申登三天

**判断思路**：
辰午申登三天课，本主升迁之象。但嫌登不过关——关者，日干是也。既不过关，难以升迁；若跳过，则又进锐退速。加白虎入宅临父母，必因丁艰而阻。末传空亡，逢空则止。

**反馈**：验 — 服满得一任差遣，赴任数月因病假归，十二月卒

**可复用规则**：
IF 得登三天课（辰午申为三传），THEN 占升迁主升；IF 三传被日干截断（不过关），THEN 升迁有阻；IF 中末空亡，THEN 有始无终

### 4. 催官符与恩泽并见，必有升迁

**来源**：《壬占汇选》— 邵彦和（丙寅日课）

**核心技法**：日上官星作贵人会火局，金被火官逼，必然动身赴任

**课式特征**：
- 占类：赴任占
- 课体：炎上
- 关键神煞：官星、贵人、火局

**判断思路**：
日上官星作贵人，会火局。金被火官逼，行年又添一层官星来赶，必然动身。须见尊长病酒几死即应。宅上丁神已动，临交代时必有所阻。

**反馈**：验 — 二月催赴任，二月二日父大醉几死，越七日文字果至；八月方交割，因前任官要认亏空故迟

**可复用规则**：
IF 官星贵人发用会火局（炎上），THEN 赴任速；IF 丁神入宅，THEN 交代时必有阻隔；官星旺相即赴任，常人怕官鬼克身，仕官则喜

### 5. 三传递克，仕途大忌

**来源**：《壬占汇选》— 陈公献（丙申日课）

**核心技法**：凡占仕途，三传递克是大凶之象，主台省参劾

**课式特征**：
- 占类：仕途占
- 课体：伏吟
- 关键神煞：三传递克

**判断思路**：
三传递互相刑克，全无和洽之气。伏吟见马，归象已现。纵发用德禄月将，但旬空乘空，空之极矣。月将不空之说大谬。后两公枚卜不果，被参去位。

**反馈**：验 — 袁公被参去，郑公为钦件狱拟罪而归

**可复用规则**：
IF 占仕途见三传递克（递互相克），THEN 大凶，必被台谏参劾；纵有吉神亦减力，月将不空之说不可全凭

### 6. 官星空亡，主解任去位

**来源**：《壬占汇选》— 陈公献（甲子日课）

**核心技法**：现任得夜贵即为不仕闲官；干支乘死绝、德丧禄绝，必去位

**课式特征**：
- 占类：官运占
- 关键神煞：夜贵、死绝、德丧、禄绝

**判断思路**：
朝官占此必主去位。现任得夜贵即为不仕闲官。干支乘死绝，德丧禄绝。朱雀月将加巳，知四月有温旨相留；课传二马逢冲，知交秋必驰驿而去。

**反馈**：验 — 周延儒六月罢

**可复用规则**：
IF 占官得夜贵发用（非现任之象），兼干支乘死绝，THEN 必主去位；IF 二马逢冲，THEN 应期在本季末

### 7. 顾祖课，仕途不满任

**来源**：《壬占汇选》— 陈公献（庚寅日课）

**核心技法**：在朝为官占得顾祖，多不满仕

**课式特征**：
- 占类：仕途占
- 课体：顾祖
- 关键神煞：初中空亡、龙化为蛇

**判断思路**：
不但不能入相，且不日归乡。凡在朝为官占得顾祖，多不满仕。又初中空亡，龙化为蛇，只宜猛省退步。龙神克下，倘欲强进，定遭不足。

**反馈**：验 — 枚卜不就，次年察处归里

**可复用规则**：
IF 仕途占得顾祖课（初传生中传，中传生末传，末传回顾初传），THEN 主不满任；兼初中空亡、龙化为蛇尤确

### 8. 钦差官以马为主，守土官以禄为主

**来源**：《壬占汇选》— 陈公献（乙巳日课）

**核心技法**：守土官论禄，钦差官论马

**课式特征**：
- 占类：差遣占
- 关键神煞：驿马、禄神

**判断思路**：
彼以禄临戌上故云北差，不知守土官则论禄，钦差官只论马。今驿马长生居午，必是南差。后拈得利者，初传中传空亡，末见贵人生日故也。

**反馈**：验 — 后得九江钞关（南差）

**可复用规则**：
IF 占差遣，THEN 守土官看禄神方位，钦差官看驿马方位；禄马入传且不空则必得

## 【科举考试占】

### 9. 三传递生格合周遍，必中高魁

**来源**：《壬占汇选》— 陈公献（乙丑日课）

**核心技法**：传将递生、格合周遍、干支交车生合，主文思滔滔

**课式特征**：
- 占类：会试占
- 课体：周遍格
- 关键神煞：朱雀乘旺气、遁丙奇

**判断思路**：
传将递生，格合周遍。干支交车生合，主文思滔滔，题目合举子之意。朱雀乘旺气，遁丙奇，文章华藻，合时宜，试官必首荐。

**反馈**：验 — 果中

**可复用规则**：
IF 占会试见三传递生、干支交车生合，THEN 必中；IF 朱雀旺相更遁奇仪，THEN 文章合试官意

### 10. 幕贵临行年，考试必中

**来源**：《壬占汇选》— 陈公献（辛卯日课）

**核心技法**：先锋为幕贵且临日上，月将官贵加命，必中无疑

**课式特征**：
- 占类：科举占
- 关键神煞：幕贵、月将、官贵

**判断思路**：
先锋为幕贵（寅时为幕贵），且临日上。月将官贵又加寅命，是以必中无疑。然发用作旬空，必俟未年太岁填实方中甲榜。

**反馈**：验 — 未年填实果中

**可复用规则**：
IF 占科举得幕贵临日或临行年，THEN 必中；IF 幕贵空亡，THEN 待填实之年方中

---

### 11. 七马聚会，科举必胜

**来源**：《壬占汇选》— 郭御青（丁亥日课）

**核心技法**：课传七马聚会，科举必胜

**课式特征**：
- 占类：会试占
- 关键神煞：日马、年马、月马、时马、天马、命马、赠马

**判断思路**：
初传巳为本日、行年、月建三马；中传寅为命马；支上申为时马、天马；末传亥为赠马。真七马聚会。三传自下递生，干上青龙，末传贵人。初天空旺相，天空见贵人为奏书之神。断为十名以外之魁。

**反馈**：验 — 果中高魁

**可复用规则**：
IF 占科举课传见多马聚会（日马、年马、月马等），THEN 必中高魁；马多则速，马少则迟

### 12. 斗鬼相加合"魁"字，必中魁首

**来源**：《壬占汇选》— 陈公献（戊辰日课）

**核心技法**：丑未两贵相加为"斗鬼"合"魁"字，必中高魁

**课式特征**：
- 占类：会试占
- 课体：返吟
- 关键神煞：丑未两贵、魁星

**判断思路**：
戊日返吟是德入天门，又丑未两贵相加，斗鬼合为魁字，是以必中高魁。冲克生空，必荷圣恩之象。

**反馈**：验 — 果中

**可复用规则**：
IF 占会试见丑未两贵人相加或相合（斗鬼为魁），THEN 必中魁首；IF 返吟得解（冲空填实），THEN 出人意料而中

### 13. 朱雀乘旺遁奇，试官首荐

**来源**：《壬占汇选》— 陈公献（甲戌日课）

**核心技法**：朱雀旺相遁乙奇，文字贴试官之意

**课式特征**：
- 占类：会试占
- 课体：炎上
- 关键神煞：太阴临卯、朱雀旺相、传送加子

**判断思路**：
河魁临干发用，贵居命年上下。太阴临卯，传将递生，格合盘珠。朱雀遁乙奇乘长生旺气，文字甚贴试官之意。传送加子箭中中垛，是以中甲无疑。

**反馈**：验 — 中三十九名，后官至大元戎

**可复用规则**：
IF 占科举见传将递生、朱雀旺相且遁奇仪（乙丙丁），THEN 中；IF 传送加子（箭中中垛），THEN 文字中的

### 14. 墓库加干，埋没不得出头

**来源**：《壬占汇选》— 郭御青（戊子日课）

**核心技法**：墓库加干乃埋没不得出头之象，科举最忌

**课式特征**：
- 占类：会试占
- 关键神煞：墓库覆日

**判断思路**：
墓禄覆日，虽初传有戌冲之，奈年上又乘墓神。命上乘酉合住辰墓，则戌墓不能冲开矣。大端不美。

**反馈**：验 — 不中

**可复用规则**：
IF 占科举见墓库覆日（辰戌丑未加干），THEN 主埋没不得出头；IF 墓被合住不能冲开，THEN 无解，不中

## 【求财经商占】

### 15. 三传全财化为鬼，财多反害

**来源**：《壬占汇选》— 邵彦和（乙未日课）

**核心技法**：三传全财化为鬼，财多反为祸

**课式特征**：
- 占类：求财占
- 课体：从革
- 关键神煞：三传全财

**判断思路**：
乙日得辰戌丑未四土为财，三传全财。经云："三传全财化为鬼，若非春占，乙木旺于春则财可得，否则反损己财。"春占木旺胜土，故财可得；若非春占，土旺克水（乙木），则反为祸。

**反馈**：验 — 得财后又因争讼失财

**可复用规则**：
IF 三传全财（日干之财），THEN 看时令旺衰；日干旺则得财，日干衰则财化为鬼，反受其害

---

### 16. 杂气财局，利坐贾不利行商

**来源**：《壬占汇选》— 王牧夫（庚辰日课）

**核心技法**：行商看干克之财，坐贾看支克之财

**课式特征**：
- 占类：经商占
- 课体：润下
- 关键神煞：脱气、元武

**判断思路**：
庚金生润下之水为脱气。以支所克者为财，行商看干克之财，坐贾看支克之财。固窝与坐贾同，当看支所克者。三传脱干而断其价长，以脱尽庚身而止，数不过八。

**反馈**：验 — 由数分长至八钱，甲子旬为官司所禁而止

**可复用规则**：
IF 占窝价（固定商业）涨落，THEN 看支克者为财；三传脱干则价长，脱尽干身为止；数不过日干之数

---

### 17. 财乘玄武必有失，类神在传可寻

**来源**：《壬占汇选》— 徐次宾（壬午日课）

**核心技法**：财乘玄武为失财之象，类神在传则可寻

**课式特征**：
- 占类：失财占
- 关键神煞：财乘玄武、类神在传

**判断思路**：
胜光为日下之财，元武临之。本合失马，以胜光无气故言失驴。末传为归计门，白虎加申主西字又主贝字配成贾字。胜光空亡至甲午旬填实，故甲午日得信。

**反馈**：验 — 甲午日于牛市得信，往姓贾处牵回

**可复用规则**：
IF 占失财物，THEN 看类神（失马看午，失驴看类）；类神在传可寻，不在传难寻；类神空亡待填实之日可寻

---

### 18. 脱上逢脱，费力而财不实

**来源**：《壬占汇选》— 王牧夫（乙丑日课）

**核心技法**：脱上逢脱，干上逢脱又脱气，费力无实利

**课式特征**：
- 占类：索债占
- 关键神煞：脱气、白虎、元武

**判断思路**：
支上亥水生干是有心要还，奈阴神酉加亥上为日鬼乘元武（酒色），未乘白虎为赌博。三传自生传鬼，自鬼传墓，安得不败坏。卖屋者支为宅，末传未乘虎冲之。

**反馈**：验 — 其人好赌好饮，卖屋始得财，不全

**可复用规则**：
IF 三传自生传鬼、自鬼传墓，THEN 事必败坏；IF 脱上逢脱（干上脱气又逢脱气神），THEN 费力无实利

## 【家宅风水占】

### 19. 人宅皆死各衰羸

**来源**：《壬占汇选》— 郭御青（壬寅日课）

**核心技法**：干支上皆逢死气，人宅皆死各衰羸

**课式特征**：
- 占类：宅居占
- 关键神煞：干支死气

**判断思路**：
干支上皆逢死气。毕法云："人宅皆死各衰羸。"遂同督师于次日北回。越日，贼至许而城破矣。

**反馈**：验 — 城破

**可复用规则**：
IF 干支上神皆乘死气（日干死地+支辰死地），THEN 人宅皆衰，大凶；主不可久居

### 20. 两蛇夹墓凶难免

**来源**：《壬占汇选》— 邵彦和（丙寅日课）

**核心技法**：两蛇夹墓凶难免，宅中有伏尸为祟

**课式特征**：
- 占类：家宅占
- 关键神煞：两蛇夹墓、死神、迷惑煞

**判断思路**：
干支带墓，第四课见子鬼发动，却又传归日上。六月死神在戌作蛇，主有伏尸，带迷惑煞殃及于人。因宅中皆是旧墓，前后俱有尸骸。鬼入四课，在内之鬼也。传出日上，渐次侵害于人。主不出八年痨病相缠，当死五人。

**反馈**：验 — 掘得十四穴无主之墓，庚戌年何公不禄，七年中果丧五人

**可复用规则**：
IF 课见两蛇夹墓（蛇覆墓神），THEN 家宅大凶，主有伏尸为祟；IF 鬼入四课传归日上，THEN 鬼自内出渐害于人

### 21. 太岁入宅克宅，家破屋拆

凡天驿二马加日辰发用，定主行人至。更传尽处定归。或传送在日辰之后，阴神在日辰之后未到也。

**反馈**：验

**可复用规则**：
IF 占行人见天驿二马加日辰发用，THEN 行人必至；IF 传尽处（末传）合行人方位，THEN 至期可定

## 【盗贼失物占】

### 44. 类神在传物不失，类神加日辰不日见

**来源**：《壬占汇选》— 邵彦和（庚午日课）

**核心技法**：凡占失物须看类神，类神在传或加日辰，定见

**课式特征**：
- 占类：失物占
- 关键神煞：类神

**判断思路**：
银在南方炉灶前水湿处寻之，乃自家人盗耳。辰作元武当主仆辈。酉作类神作勾加午，末传更见太阴临水，太阴亦类神也。凡占失物须看类神，类神在传或加日辰，定见；传日不出日，传时不出时。

**反馈**：验

**可复用规则**：
IF 占失物，THEN 看类神（金子看酉，银看酉，马看午，羊看未等）；类神在传或加日辰则可见；类神未见则以初传为方向

### 45. 元武临处为贼方，元武阴神为藏处

**来源**：《壬占汇选》— 元轸（辛巳日课）

**核心技法**：经云只于元武临处责之，元武阴神为贼藏处

**课式特征**：
- 占类：盗贼占
- 关键神煞：元武

**判断思路**：
贼有五人，当是年及五旬妇人，原是婢女出身，一目有疾。在郊外东北五十里坟墓间居住。经云只于元武临处责之。今元武临丑故言东北。武之阴神酉从丑至酉为五辰故云五人。三传逆治其贼不远。

**反馈**：验 — 捕人至东北五十里苏相公坟后拘获正贼

**可复用规则**：
IF 占贼盗，THEN 元武临处为贼所处方向，元武阴神所临为贼藏身之所；从元武所临数至阴神为贼人数

### 46. 贼符游都临干支，盗贼必来

**反馈**：验 — 次日北关外行劫，遂获二名

**可复用规则**：
IF 游都贼符临干支，THEN 贼至；IF 元武驿马同见，THEN 贼来速去亦速；以发用之地支数断贼人数

## 【天时气象占】

### 48. 铸印课冬占必雪

**来源**：《壬占汇选》— 邵彦和（己卯日课）

**核心技法**：火伏于下水升于上为雨雪象，铸印课冬占必雪

**课式特征**：
- 占类：天气占
- 课体：铸印
- 关键神煞：火伏于下、水升于上

**判断思路**：
数日来天气和暖宛如三九月，今得此课今日天色必变。巳时风起转寒，未时有雨，亥时作雪厚有七寸。火伏于下水升于上不拘占雨占雪皆当日有。初传巳火临子被克上见元武水夹克变成大风雪。巳戌卯铸印春夏秋必雨冬必雪。

**反馈**：验 — 巳时果风起，未时微雨，二更后下雪积七寸

**可复用规则**：
IF 占天时见火伏于下水升于上之象（巳加子等），THEN 当日有雨雪；IF 巳戌卯铸印课，THEN 春夏秋雨冬雪；末传卯作白虎为雪象

### 49. 龙神飞天、贵登天门皆行雨之象

**来源**：《壬占汇选》— 郭御青（己巳日课）

**核心技法**：贵登天门、龙神飞天皆行雨之象

- 占类：天气占

巳午之日先有狂风起，出旬甲日小雨，乙日大雨。斗罡加未为风伯，发用功曹劫杀克日故主有狂风。贵登天门，龙神飞天皆行雨之象。中末亥申空亡故言出旬有验。

**反馈**：验 — 风雨如期而至

**可复用规则**：
IF 占雨见贵登天门（贵人临亥），THEN 雨象；IF 龙神升天（青龙临天门），THEN 雨至；斗罡加未为风伯主风

### 毕法精华

**1. 德丧禄绝格**
- IF 德临绝地（德神坐于绝乡），THEN 为德丧；禄临绝地则不能食禄
- 案例：邵彦和判甲子日徐学士，禄临绝地岂能食禄

**2. 权摄不正禄临支**
- IF 禄神临支（日干之禄加于支辰），THEN 主权摄不正，或得他人物业
- 案例：邵彦和判戊申日课，戊禄在巳临支，权摄不正

**3. 鬼临三四讼灾随**
- IF 鬼临三四课（官鬼在三四课），THEN 主讼灾、疾病
- 案例：邵彦和判壬戌日课，鬼临三四多灾不得考试

**4. 两蛇夹墓凶难免**
- IF 蛇覆墓神（两重蛇加墓），THEN 大凶，主伏尸为祟
- 案例：邵彦和判丙寅日何三公宅

**5. 人宅皆死各衰羸**
- IF 干支上神皆乘死气，THEN 人宅衰败不可居
- 案例：郭御青判壬寅日课，城破

**6. 三传递克众人欺**
- IF 三传递克（初克中、中克末、末克干），THEN 主被众人攻讦
- 案例：陈公献判丙申日课，被参劾去位

**7. 合中犯煞蜜中砒**
- IF 三合局中藏刑冲克害，THEN 吉中有凶
- 案例：陈公献判辛巳日课，炎上局合中犯煞

**8. 干神归支利静不利动**
- IF 干上神临支（干神归支），THEN 利静守不宜动
- 案例：陈公献判乙丑日课

**9. 年命填实填空亡**
- IF 旬空之支恰是行年或本命，THEN 空亡被填实，不以空论
- 案例：郭御青补注，行年填实则凶减

**10. 制鬼之位乃良医**
- IF 课中克鬼之支（制鬼者），THEN 为良医所在方
- 案例：郭御青判戊子日课
