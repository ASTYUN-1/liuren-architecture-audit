# 断课结论（复盘对照）

## ✅ 命中项

### 命中1：方位——类神下临地盘=东南方
**课象**：类神酉（鸡）加干上，下临地盘辰
**断语**：辰为东南方
**实际**：✅ 东南方水渠上
**归因**：类神下临地盘之法，验证于 case-001（钩针·巳地→东南）、case-016（神像·午地→南），本课再次验证。酉下临辰→东南。

### 命中2：环境——水边/潮湿低洼处
**课象**：酉下临辰（水库湿土）+ 乘六合（草木/篱笆）
**断语**：草木丛/篱笆附近、潮湿泥土、水边或低洼处
**实际**：✅ 水渠上趴着（农村渠道）
**归因**：辰为水库、湿土、田园；六合为草木围栏。叠加=水渠。

### 命中3：走失性质——非被盗
**课象**：玄武（盗贼之神）乘卯为旬空；重审课"事从内起"
**断语**：不是被人偷走，鸡自己走失
**实际**：✅ 鸡自己跑出去的
**归因**：玄武空亡=盗贼虚象。支阴见玄武乘空，偷盗之象不成立。

### 命中4：斩关——越过围栏
**课象**：斩关格（支上戌天魁临巳+初传寅功曹）
**断语**：鸡越过围栏/关口而去
**实际**：✅ 鸡跑出了院子范围
**归因**：课经"天魁为天关，功曹为天梁"，课得斩关主逃亡越关。

## ❌ 失分项

### 失分：应期偏晚两天
**断语**：2月13日未时（丁未日）或2月15日酉时（己酉日）
**实际**：✅ 当天（2月11日）未时（13:40）

**失误链条**：
1. 看到丁马加未 → 应用规则#15"丁马加地支主该地支之时/日/月应事"
2. 跳过了"时"这一层 → 直接推到"最近的未日=2月13日丁未日"
3. 忽略了最关键的信号：**占时未时 = 中传丁神未**（同位重叠）

## 🔑 核心经验：应期速度的层级判断

### 丁马/占时同位的极速法则

```
丁马加某支 → 该支 = 占时？ → 是 → 当天该时辰（极速，第一优先级）
           → 该支 = 日支？ → 是 → 当天（次优先）
           → 否则 → 最近的该支日 → 再定具体时辰
```

**"时→日→月"逐级递推，不可跳级。**

### 速/慢信号对比

本课同时存在对立信号，但极速信号压倒一切：

| 信号 | 方向 | 权重 |
|------|:---:|:---:|
| **占时 = 中传丁神（同位）** | 极速 | ⭐⭐⭐ |
| 类神酉加干上 | 近处/速 | ⭐⭐⭐ |
| 贵人逆行 | 缓 | ⭐ |
| 类神酉在寅月休囚 | 偏慢 | ⭐ |

### 修正后的应期判断流程

1. **先看占时是否入传** → 入传则在占时所在时辰或当天
2. **再看丁马/类神是否与占时同位** → 同位则优先应当天该时辰
3. **再看丁马所在支** → 不等占时则推该支的日/时
4. **最后看类神当值** → 类神临日/时
