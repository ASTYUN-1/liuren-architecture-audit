# 射覆大典编纂 + 梳子反推复盘

## 一、事件概述

2026年7月20日，用户要求使用大六壬射覆猜"左手握何物"，报数7活时起课，得**遥克·蒿矢·进茹**课（乙未日第十二局干上巳）。

**最初断语**：真无线蓝牙耳机（含充电舱），黑白色
**实际反馈**：❌ 粉色小梳子

## 二、错误归因分析

| 错误点 | 根因 | 改进措施 |
|--------|------|----------|
| 酉乘玄武=黑白色 | 被案例库case-001（酉+勾陈=黄白）锚定，黑即黑白色的错误跳跃 | 玄武也可="暗藏小物"，不必然是颜色 |
| 巳青龙=绿色 | 只读青龙本义"青色"，没优先看巳宫的第一类象"梳妆" | 巳的第一类象是梳妆台/化妆用品，此课干上巳正是梳子关键 |【❌无据-2026-08-04审查】
| 粉色未提取 | 忽略干上巳的粉色信号 | 巳属火，色粉红/桃红，干上巳直接表征粉色 |
| 塑料≠酉金 | 只想到酉=金银金属 | 化工合成品=火炼之金，归酉金 |【❌无据-2026-08-04审查】
| 酉为"针"被忽略 | 酉的"针、刀剑"类象没考虑 | 梳齿如针或排细针，酉"为针"完全匹配 |
| 进茹三传盲读 | 耳机=外壳+舱+配件，但梳子同样符合 | 梳子(酉)→收纳(戌)→梳发(亥)同样合理 |【❌无据-2026-08-04审查】

## 三、正确射覆对应（反推）

### 课象→粉色小梳子的正确映射

| 课象 | 正确解读 | 说明 |
|------|---------|------|
| 发用酉(玄武/官鬼) | 梳子本体。酉为针=梳齿，酉为金银=塑料(火炼金)，玄武暗藏 | 梳齿如针排列 |
| 干上巳(青龙/旬空) | **粉色+梳妆**。巳为梳妆台/化妆品，属火色粉红；青龙为装饰美饰 | 此是最关键类神，被漏读 |
| 中传戌(太阴/妻财) | 收纳/女用。太阴女性私密，戌为收藏 | 梳子收纳于化妆包 |
| 末传亥(天后/父母) | 梳理养护。亥为头发细丝，天后为护养 | 梳子梳理头发 |
| 蒿矢"射中" | 梳子在发中梳理之轨迹 | 不是蓝牙配对 |
| 进茹(酉→戌→亥) | 梳子→收纳→梳理，物尽其用的三步 | |

## 四、教训总结

1. **巳宫第一类象"梳妆"不容忽视** — 巳为梳妆台、化妆品，射覆中见巳优先考虑美容美妆类 【❌无据-2026-08-04审查】
2. **天将解读不唯颜色** — 玄武≠必然黑，太阴≠必然白，颜色需结合干上神和旺衰
3. **案例库只能作参考、不能作锚定** — 上例耳机是酉+勾陈(黄白)，本例是酉+玄武，大不同
4. **射覆必须先看干上神** — 刚日看日上神，本例干上巳才是全课最有特征的类神
5. **苗公的"酉为针"** 是梳齿的直接对应，射覆时物件的细节特征比大类更重要
