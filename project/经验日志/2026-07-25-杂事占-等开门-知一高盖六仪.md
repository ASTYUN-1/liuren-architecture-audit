## 反推核心发现 ⭐

### 1. 类神取用：支上神为"开门人"

**失败教训：** 初取初传午（腾蛇）为来人，但午为日鬼官鬼，是"我焦急等待"的象，非开门人。

**正确取法：** 支（子）为门/环境，支上神**酉（太阴）** 才是出现在门附近的人。
- 酉为**阴支** → 阴柔 → 女性
- 乘**太阴** → 阴将 → 女性
- 断语反馈验证："阴酉为女子" ✅

**法则：** 问"谁出现在门口"，取支上神为来人，不取发用。支为环境，支上神为环境中出现的对象。

### 2. 三传逆行主"出"

三传午→卯→子为**逆行**（午巳辰卯寅丑子）。
**法则：** 三传顺行主进/入，逆行主退/出。
酉时占问回家（我要进去），三传逆行则对方与我反向→**对方从小区出来** ✅

### 3. 对宫法定方向

卯酉相冲。我要回小区（进），卯酉冲则对方是相反方向→**出来** ✅
**法则：** 对方方向取支上神（酉）的对宫（卯为冲），以冲定反向。

### 4. 时间应期：支乘虎主速 + 发用数折半

| 线索 | 解读 |
|------|------|
| 支（子）乘**白虎** | 白虎主速疾、迅猛 |
| 发用午为7数 | 未月土旺午火休囚，**折半取4→2分钟** |
| 知一主邻近 | 事在咫尺，时间短 |
| 干上巳空亡 | 空则虚、短，等不久 |

**法则修正：** 午数为7，未月午火休囚折半得3.5→约2分钟。白虎在支（环境/门外）主外面的人动作快，很快就到门边。

1. **支上神取人法**：问"谁来开门/谁出现在门口"，取支上神，不取发用
2. **阴支+太阴=女性**：阴支乘太阴，女性信号确凿
3. **三传逆行主出/退**：逆行对方向外，顺行向内

5. **白虎为速**：虎在支（环境），外面的人动作快、来得快
