# 2026-08-04 — 事业占·朋友工资数额反推复盘（财爻空亡定财薄）

## 占问
- 课式：丙午年乙未月庚戌日癸未时，蒿矢退茹课，午将，甲辰旬寅卯空
- 三传：午(青龙/官鬼)→巳(勾陈/官鬼)→辰(六合/父母)
- 四课：干上未(天空)→午(青龙)｜支上酉(太常)→申(白虎)
- 问：朋友本月15号发工资多少

## 断数过程（两次皆错）
1. 初断用地支序数（午=7）→ 断 7,000 —— 错
2. 重断用《壬归》相因法：禄申(7)×财地酉(6)=42，再以"申坐酉帝旺"倍进 → 断 8,400 —— 错
3. **实际反馈：该人工资从未上过 6,000**

## 错因分析（教训）
1. **拿禄神旺相当"钱多"**：禄神申坐酉虽帝旺，但工资多寡的最终定盘星是**财爻**，不是禄神旺相。本课财爻寅卯**旬空**且未月**囚死**，财空则财薄——《壬归》"财作空亡，近出旬可冀，远到底无形"。
2. **违反"课体定大象"**：蒿矢力弱（求财难成）+ 退茹收缩（收入不前）+ 三传官鬼重重——课经明言"此卦宜占官，余不宜，常人深畏"。局部禄神帝旺不能逆转课体财薄之象（参照 case-002 遥克蒿矢事业占：课体定大象压过局部类神）。
3. **忽略白虎削减**：禄神申乘白虎（白虎本家），俸禄被削、常有扣项——工资低且不稳的根本表征之一。

## 反推修正（本课真正支持"工资低"的依据链）
| 依据 | 出处 |
|------|------|
| 财爻寅卯旬空 → 财源空薄、难增收 | 《壬归》"财作空亡，远到底无形" |
| 财爻木未月囚死 → 减成数之半 | 《壬归》"囚死，减成数之半" |
| 禄神申乘白虎 → 俸禄被削减、有扣 | 《天一群笔记》"禄神主工资"；白虎主削 |
| 蒿矢无力+退茹收缩+官鬼重重 → 增收无望 | 课体定大象（case-002教训） |
| 三传火鬼 → 财生鬼、钱留不住 | 毕法"传财化鬼财休觅" |

## 修正结论（定性为主，数额从宽）
- 定性：**财薄、有扣、难破六千**——与反馈吻合。
- 数额（从疑）：按囚死减半，若寅7卯6相因42 → 减半 21 数级（约 2,000 上下）或取禄虎削减后在 4,000–5,000 一线。**精确到元不可强断**。
