# 2026-07-29 推命占 伏吟元胎白虎田宅屠户之业（反推提炼）

## 经验规则1：田宅宫白虎+申酉金 → 屠宰家业
当推命盘见伏吟课 + 田宅宫（第10宫）乘白虎 + 地支为申/酉金时，应断家业为屠宰/血财之业（杀猪卖肉等），不问父母宫青龙贵神之象，因为田宅宫为家业根基，白虎主杀伐刀兵，金为切割之器。父母宫青龙的"贵气"会被田宅宫白虎的杀伐象所穿破。

## 经验规则2：小限冲类神 → 类神六亲有灾
当推命按年看事 + 小限所在宫位对冲六亲类神（如小限卯冲太常酉）时，应断该年为此六亲有灾的年份（冲为冲击动荡），而非仅读小限宫位本义（如卯妻妾宫/桃花）。冲克类神优先于本宫寓意。

## 经验规则3：太常金属宫 → 刀肉常业，非必体制内
当推命断父母职业 + 太常居酉（金）+ 羊刃/闭口等金属神煞时，应断父业为刀肉切割的常业（屠户/庖厨），而非必然为官方编制。太常本义"常"——日常常服常业，不限于官方。

## 经验规则4：帘幕贵人乘天空 → 助力减等
当推命看学历 + 帘幕贵人乘天空（未天空）时，应断帘幕贵人为"虚贵"，助力有限，学历层级应降等判断（如硕土降为本科）。
