# 断课结论

## 关键依据
1. **元胎课体应孕产**：三传绝→病→临官，课体与问事吻合，说明此事确实在课象范围内
2. **初传空亡绝地**：发用巳空亡，壬水绝地，事之起始已虚，发端门虚花不实
3. **中传子孙爻不空**：寅为子孙爻，在三传中出现且不空，保留一线生机
4. **不备课+寡宿课**：双课体压制，气势不足+子息缘分薄
5. **课义直读**："生被虎攻，往就徒空，舍益就损，终身困穷"——已指明结果方向
6. **白虎乘长生**：长生本是吉神，但被白虎凶将所乘，"生被虎攻"
7. **年命丑上见戌勾陈**：本命被勾陈迟滞之神所覆，行年卯上子青龙，今年有喜象但与课体矛盾

# 技法提炼
1. **元胎课孕产占断**：元胎课应孕产之事，但需结合其他课体判断吉凶，不可因元胎即断为吉
2. **初传空亡绝地断事虚**：发用空亡+绝地，事之起始已虚，占胎产则主空想/虚花
3. **不备课+寡宿叠加断**：不备主气势不足，寡宿主子息缘薄，双课体叠加压制力更强
4. **课义直读法**：此课课义"生被虎攻，往就徒空，舍益就损，终身困穷"直接对应反馈，课义可作断课提纲
5. **中传子孙爻不空≠必然有子**：中传子孙爻出现是有子之象，但需看整体课体组合。初传空亡+不备+寡宿三重压制下，子爻虽现亦难成
6. **白虎乘长生的双重性**：长生被白虎凶将所乘，吉中藏凶，"生被虎攻"之象
