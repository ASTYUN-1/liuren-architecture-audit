# 断课结论

## 关键依据
1. **干上巳 — 睨上逢脱防虚诈**：甲木生巳火，巳火生太常，泄气脱耗之象；且巳为**破碎煞**+**小耗**，耗财无疑
2. **驿马申空亡 — 虚动非实动**：课义"动意尤浓"，但驿马申逢空亡，故心动而未行
3. **初传申鬼空亡 — 凶不成凶**：官鬼虽克日干，但逢空亡，压力虚而不实
4. **末传寅天后+日禄**：最终回归根基，结局不差，苦去甘来
5. **年命申即初传**：事主本人正处在此课势的核心位置，课象直接对应其身

## 断语

- 细节说明：
  - ✅ **耗财对**：反馈确认近期有耗财。干上巳为破碎煞+小耗+睨上逢脱，象意直指耗财。
  - ⚠️ **驿马空 → 他没有动**：AI原断强调"必有变动"，但老师傅反馈"驿马空，他没有动"。课义虽有"动意尤浓"，但驿马申是空亡的——空则虚，虚则心动而未动。这是"心动测近运"的课象真意：心动而未行。

# 归因分析（技法制高点）
- **失误原因**：过于依赖课义"动意尤浓"的字面提示，而忽略了**驿马落地（空亡）的状态判断**。课义是总纲，但具体类神（驿马）的状态才是决定性因素。
- **老师傅建议**："可以多向神煞方面看看资料"——干上巳耗财的精确判断需要破碎煞+小耗+睨上逢脱三重神煞叠加；驿马虚动需要驿马+空亡的神煞认知。神煞是精细化调整的关键，不能停留在课体+类神的粗粒度断法。

# 技法提炼
1. **🚩 驿马空亡 ≠ 动（核心技法制高点）**：驿马是否空亡决定动的虚实。驿马现于课传且不空→真动；驿马空亡→虚动/心动/计划动。本课驿马申空亡应"心动测近运"——心动了但实际未动。
2. **🚩 破碎煞+小耗+睨上逢脱三重叠加断耗财**：干上巳一身兼三煞——①破碎煞（甲戌日巳为破碎）主破财损耗；②小耗（丙午年小耗在巳）；③睨上逢脱（干生上神，上神又生天将）主虚诈脱耗。三象并见，耗财无疑。
3. **🚩 课义与类神状态需分别看**：课义"动意尤浓"是课体总纲，但具体到落实，必须看类神（驿马）的个体状态（空/旺/衰/墓/绝）。课义提供方向，类神提供结果。
4. **🚩 神煞不是"调料"而是"细化器"**：粗粒度断课（课体+类神）能看出大致方向，但精细化的神煞叠加才能得出准确判断。本课若只看课体+类神，只能看出"有压力+变动+先苦后甘"；加入神煞后，才能精确到"耗财+虚动不动"。
5. **🚩 年命申即是初传=事主正处课象核心**：年命直接落在发用，说明这件事不是旁观，而是事主本人就是"被克"的那个。但申空亡，克也是虚克。
