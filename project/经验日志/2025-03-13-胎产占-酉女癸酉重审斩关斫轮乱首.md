# 高价值技法萃取

## 【技1】血忌刑动法
占月经/血事，以当月血忌所在支为动点。课中见该支被刑/冲/害 → 血忌被破则血行。
本课：卯月血忌未，末传丑刑未，血动。

## 【技2】换旬冲空法 ⭐
空亡填实不限于六冲/三合/六合，旬尾换旬同样让空亡失效。
本课：甲戌旬申酉空，过戌日换甲申旬（空午未），申不再空。戌日为冲空应期。

## 【技3】午遁子孙遭害法
时柱先锋遁干六亲状态直读。本课午遁壬（辛子孙），午临丑遭害，子息无着。

## 模范作业推导逻辑
1. 血忌未 ← 丑刑未 → 血动
2. 发用卯为财血 → 经血流失
3. 中传申空 → 换旬戌日填实
4. 末传丑应 → 丑日
5. → 丙戌、己丑（模范一）/ 辛巳、丙戌（模范二）
6. → 实际戊戌日来（戌日窗口）
