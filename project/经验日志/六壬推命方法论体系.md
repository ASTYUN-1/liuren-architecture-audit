# 六壬推命方法论体系

> 综合《六壬推命学》与《大六壬终身论命秘要（总论）》两部著作
> 编制日期：2026-07-29

---

## 一、体系总览

六壬推命是独立于常规占卜的**终身命运推演体系**。相比普通占课，推命需额外布列十二宫、身宫、宅宫、大运、小限等要素，并以生月合神（太阳过宫）为月将加生时起课。两本书共同构建了以下七大方法论模块：

```
六壬推命方法论体系
├── 甲、命盘结构（课式构建）
├── 乙、格局论命（二十四格 + 二十六/十六局）
├── 丙、身命五纲（根基、妻子、财官、限运、寿数）
├── 丁、运限系统（大运、小限、流年、月令）
├── 戊、六亲体系（父母、兄弟、妻妾、子女）
├── 己、分类命格（富贵贫贱、僧道九流、女命幼童）
└── 庚、杂项与心法（相貌、环境、赋文精要）
```

## 二、甲——命盘结构

### 共同共识

| 要素 | 两书记载 |
|------|---------|
| 起课法 | 以生月合神（太阳）为月将，加生时起天地盘，以生日干支立四课三传 |
| 十二宫 | 一命宫、二兄弟、三妻妾、四子女、五财帛、六疾厄、七迁移、八朋友、九官禄、十田宅、十一福德、十二父母（逆行排列） |
| 身宫 | 日干所寄宫（如丙寄巳，壬寄亥） |
| 宅宫 | 地盘日支所在之位，看天盘加临之支 |
| 三限 | 初传管少年，中传管中年，末传管老年 |

### 各自侧重

- **《六壬推命学》**：详列十二宫顺序与"三限"以太玄数计岁数之法，大运有大衍数计法、大小限顺逆起法两个体系，并引入飞限概念。
- **《大六壬终身论命秘要》**：强调"课命旺不如爻象旺"——课命定根基，爻象（三传）定际遇。

## 三、乙——格局论命

### 3.1 二十四格（两书共有，内容一致）

#### 分类体系

| 类别 | 格局 | 核心逻辑 |
|------|------|---------|
| **青龙类** | 正跨青龙、倒跨青龙、双骑青龙、双龙御命 | 命支与青龙（寅）的交互关系 |
| **龙蛇转化类** | 土蛇化龙、龙化土蛇 | 龙蛇互化，命运转折 |
| **白虎类** | 乘虎登天、履虎尾、立虎首、双骑虎背、虎化狸、狸化虎 | 与申酉戌相关，从公侯到恶徒 |
| **天门类** | 命司天门、天门不开、明入天门、暗入天门 | 以亥为天门，看所乘天将 |
| **地户类** | 坐守地户、夹拱地户 | 以巳为地户，主财富 |
| **朱雀类** | 朱雀束翅、朱雀腾辉 | 雀临水位→才困，雀临木火位→文贵 |
| **杂类** | 四墓交错、河魁贯甲、甲贯河魁、朱勾拱拜 | 土命加四土→富，戌寅互加→文武 |

#### 核心心法（两书一致）
- 有格有局亦有穷士，无格无局亦有贵人
- 遇破者虽有格而不贵，有情者纵无局而不贫
- 要详于生旺比合，更究破害刑冲

### 3.2 十六局 vs 二十六局

| 对比项 | 《六壬推命学》 | 《大六壬终身论命秘要》 |
|--------|--------------|--------------------|
| 数量 | **十六局** | 二十六章标题实为**十六局**（命名差异） |
| 五行局 | 庚星呈瑞、祥光摇拱、帝座渊穆、稳坐中宫、青帝施恩 | 同（稳坐中宫不同名） |
| 方位局 | 北斗司权、南极献图、西方专美、东海探珠 | 同 |
| 反吟局 | 坎离交泰、兑震投合 | 同 |
| 伏吟局 | 周天守躔 | 同（名"周天守踱"） |
| 连茹局 | 海云双秀、林火扬光、金含北极、火明西岳 | 红云隽秀、林火扬光、天合北极、火明西岳 |

#### 规则共识
五行局（三合局）：喜生命生身+吉将扶助+别宫有情+时令旺相→富贵奇局。
方位局（四方秀气）：喜生身吉扶旺相。
特殊局（返吟伏吟连茹）：各有其特定条件。

## 四、丙——身命五纲

### 身命五纲（两书体系完全一致）

| 步骤 | 内容 | 核心方法 |
|------|------|---------|
| **一·根基** | 日上为主 | 贵龙吉将生旺→富贵；墓绝→虚花；无气凶杀→下等；有气凶杀→假杀为权 |
| **二·妻子** | 辰上神 | 日辰相生合→夫妻和，相冲克→反目；辰上神吉→妻好，凶→妻恶 |
| **三·财官** | 日月有气 | 禄马官星印绶生合日→官贵；子孙妻财龙常临日合日→富贵 |
| **四·限运** | 日旺/日衰 | 旺遇财官→发福，遇鬼煞→艰险；衰遇官鬼→官变鬼，遇父母→艰辛 |
| **五·寿数** | 本命上神 | 生旺德合→延年，刑害→夭；长生帝旺→寿，死墓绝空→夭 |

### 重要心法（两书共同）
- **身命大忌**：空亡（作事无成）和入墓（昏晦不明）
- **课命与爻象之辨**：课命定根基，爻象定际遇。课命旺不如爻象旺
- **三传定荣枯**：初吉→少年好，中吉→中年立业，末吉→晚年春风

## 六、戊——六亲体系

### 六亲取用（两书一致）

| 六亲 | 天将法 | 六亲爻法 |
|------|-------|---------|
| 父 | 太常、贵人、德神 | 偏财 |
| 母 | 天后、正印 | 正印 |
| 兄弟姊妹 | 太阴 | 比劫 |
| 妻妾 | 天后、神后、太阴 | 财爻 |
| 子息 | 六合、太冲、登明 | 子孙爻 |

### 六亲断法心法
- 类神旺相生合日干→缘厚得助
- 类神冲克刑害→缘薄无力
- 类神空亡墓绝→缘浅或无
- **类神须向活中看**——天将法+六亲爻法双轨并行，不可死执一端

- 支禄（家中现成）→次重

- 三者得一为美，不得则终身无靠

### 核心共识

1. **身命五纲**（根基、妻子、财官、限运、寿数）为推命基本框架
2. **二十四格**（24 pattern system）为定格局标准
3. **十六局**为定局格标准
4. **三传定三限**为终身际遇核心
5. **课命定根基、爻象定际遇**为课爻关系总则
6. **有情无情高于格局本身**为最高心法
7. **身命忌空墓**为第一凶兆
8. **女命以支上神为核心**为女命总则
