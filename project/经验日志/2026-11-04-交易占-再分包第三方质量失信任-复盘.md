# 交易占：再分包合作中第三方作品失信任

- **类型**：条件规则（复盘归纳）
- **验证**：本案单一实测复盘，未独立验证；结论来自一次真实反馈，不构成命中率
- **来源**：本机实测 `案例项目库/交易占/case-030-华为品宣分包-20260922.md`（2026-09-22 己亥日酉时，问华为品宣分包能否谈成）
- **反馈**：未谈成；总预算 20 万、拟赚 4 万；原因是事主找的第三方制作人员作品太差，甲方看完不再信任事主（选项 A）

## 规则

1. **再分包占，子孙爻为下游执行方/作品，不因不入四课三传而删。**  
   核其所临地盘（是否入墓）、所乘天将（腾蛇主虚惊反复不实）、所带神煞（破碎、丁马）、直接阴神（空亡、玄武）。本案子孙酉临丑（金墓）、乘腾蛇、带破碎丁马，阴神巳空亡乘玄武，作品入墓且背后不实。

2. **兄弟临支上克支，可读“事主一方伤甲方”，不先读成外部关系户。**  
   兄弟对日干为同类：在“事主再分包”语境可指事主找的执行方/合作者。方向看它临支还是临干、克支还是克干：临支上而克支，是事主一方带来的人/东西伤对方；临支上而被支克，才是对方压住事主一方。本案初传未为日干兄弟，临支上且克支亥，乘天后主私下惊慌。

3. **六合不空只主有接触/意向，不主签约。**  
   签约须另核：父母是否空墓、官鬼是否闭口、财是否坐鬼乡、财是否被合入鬼局。本案末传亥财乘六合不空，但亥卯未合木鬼局、财坐卯鬼乡，父母巳空午墓，中传癸卯闭口，故合而不实。

4. **全阴、逆传、闭口、月破、空墓同现时，否定结构权重大于单一吉将。**  
   不能把“财现 + 六合”当主证，再把其余降为“过程瑕疵”。本案四课三传全阴、未→卯→亥逆布、官鬼癸卯闭口、卯月破、父母空墓，已越过“成”的门槛。

5. **先钉死“成”的标准。**  
   谈成 = 签约/明确授权；有接触、有意向、谈到钱，都不等于成。本案初判把“签下执行/拿到一部分”也算成，等于替问主降低成功标准。

## 反例与边界

- 不是所有“六合不空”都不成；须核父母、官鬼、财坐处与合局。若父母不空不墓、官鬼不闭口、财不坐鬼乡，六合仍可主成合。
- 不是所有“兄弟临支”都指事主一方；须结合六合/六亲参照与实际事件阶段。本案是“事主再分包”这一已知背景，才取“事主一方执行方”义。
- 本案为单一案例，未做跨案例统计；规则强度只到“条件候选”，不写成“必不成”。
- “子孙入墓”不等于作品必差；本案是入墓 + 腾蛇 + 破碎 + 阴神空玄武同现，才取作品不实/失信任。

## 与既有规则的关系

- **H0070**（八专合作：兄弟空 + 六合不入课传 → 合作不成）：本案非八专、六合入末传不空、兄弟未不空，条件不成立；不能用 H0070 直接断本案，但“兄弟/六合定合作”的检查方向可复用。
- **LR26-MP10-042-FAIL**（六合发用传空 → 合作失败）：本案六合在末传不空，条件不同；该卡不能直接支持本案“不成”，本案靠父母空墓、官鬼闭口、子孙入墓等另立证据。
- **LR26-TXY-C10/C13**（财现不等于能取；财阴、坐鬼乡、位置可改变可得性）：本案采用其“财现不等于签约”的检查，但不把“财现”当主证。
- **LR26-BOOK-BIFA-042**（鬼化财须鬼局两传空、余财实）：本案鬼局全实，不构成“鬼化财”，反主财被鬼局牵制。

## 待验证

- 再分包占中“子孙入墓 + 腾蛇 + 破碎 + 阴神空玄武”是否稳定指向第三方作品失信任，需更多案例。
- “兄弟临支克支”在合作占中区分“事主一方伤对方”与“对方压事主一方”的稳定判据，需反例核对。
- 六合不空但父母空墓/官鬼闭口时，合作“谈过但未签”的边界，需跨案例验证。
