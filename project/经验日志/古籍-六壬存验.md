# 《六壬存验》——吴师青 核心经验全量提取

> **作者**：清·吴师青  
> **地位**：清代六壬名家独立案例集，与《壬占汇选》基本不重叠  
> **特色**：清代风格，注重神煞格局，案例涉及科举、仕宦、刑狱、兵乱、疾病等  
> **现代可迁移性**：清代社会场景（科举、仕宦、诉讼、出行、商业）比宋代更接近现代

---

## 【总论】清代六壬断课特色概览

**来源**：《六壬存验》吴师青

**核心技法**：全书采用"断例（口诀纲领）+ 案例验证"的双层结构。前半以简洁口诀分门别类列出断法纲领，后半以十二种课式分类实战案例印证。

**清代特色**：
1. **神煞运用极密**——丧门、吊客、病符、亡神、天赦、皇恩、皇诏、游都、鲁都、贼符、劫煞、天鬼、风伯、雷公、雷煞、天喜、天医等大量神煞与课式结合论断
2. **格局为先**——先定课体（重审/元首/涉害/八专等），再配神煞格局综合判断
3. **注重刑冲克害空墓绝**——尤其重视空亡、墓库、旬空的应期判断
4. **案例真实具体**——事件有清晰的前因后果反馈
5. **干支身命并重**——日干为身，日支为宅/事体，结合行年本命综合断

## 【孕产】占孕产吉凶

**来源**：《六壬存验》吴师青

**核心技法**：以胎神、长生、三传格局断孕产

**断男女法**：
- 阳日干乘阳支 → 男；阳日干乘阴支 → 女
- 三传曲直（亥卯未）→ 男；炎上（寅午戌）→ 男
- 三传从革（巳酉丑）→ 女；润下（申子辰）→ 女
- 二阴包阳 → 男；二阳包阴 → 女
- 课传纯阴 → 男；纯阳之课 → 女（吴氏特殊用法）
- 天罡比日 → 男

**受胎时期**：以妇命年支所乘之神长生推之

**产期判断**：
- 干支胎位逢冲为产期
- 胜光加地盘之支，如加子则子日
- 地盘冲着胎之支可产
- 胎之养位可究产期

**吉兆**：胎神临地盘得生旺比和、干支无伤、天乙发传、贵人三传顺行

**凶兆**：
- 胎乘鬼 → 胎死堕
- 日支被伤损母，日干被伤损子
- 六合受下克伤儿，下贼天后危母
- 胎加生方 → 生子难
- 贵人三传逆行 → 生难
- 河魁度天门 → 阻滞
- 卯加戌上手先出，戌加卯上足先来
- 干加支上子恋母，支归干位速生儿

**现代可迁移**：孕产占断法至今通用，胎神框架不变。

## 【诉讼】占讼吉凶

**基本原则**：
- 日干有鬼主客不利
- 发用克日干主客输
- 日干上神受克主客输
- 朱雀/勾陈克日干莫讼
- 日支有鬼主不利
- 发用克日支主输
- 日支上神受克主主输
- 末传生初传鬼主凶
- 朱雀克太岁凶
- 朱雀入勾陈事情重大（午入辰）
- 螣蛇夹墓小反大
- 勾陈白虎同克日必遭刑戮

**决罪五行**：木笞杖、火流、金刺刃、土徒、水

**结讼期**：在鬼绝处定期（如火为鬼，长生在寅绝在亥，以亥日断）

**散讼期**：在末传冲处定（末传子，以午日断）

**救解之兆**：
- 太岁贵人作恩星（生日）→ 解轻重罪
- 初传白虎末传蛇 → 祸中不凶
- 子孙爻制鬼 → 患中有救
- 父母爻化鬼 → 祸中无伤
- 天赦皇恩生干支 → 解凶

**现代可迁移**：诉讼占断框架完全适用于现代法律纠纷。

## 【重审课之一】双胎产子，男女生死异数

**来源**：《六壬存验》吴师青

**核心技法**：胎神死气生气对比、三传卦象定男女

**课式特征**：
- 占类：六甲（孕产）
- 课体：重审、斩关、伏吟

**重审课**：先迷后利——用于孕产、刑狱、讼事、兵战等多类，占比最大

**元首课**：先喜后忧——用于国运、出师、升迁等大事

**涉害课**：用于阴宅风水、科场、会试等需要深入分析之事

**遥克课（蒿矢/弹射）**：力量不雄——用于天气、行人、考试等，主难成但并非不成

**昴星课**：无克无遥——用于特殊事件
- 冬蛇掩目（螣蛇发用）→ 不能害人

**别责课**：不备无力——凡占罔济，不过利守

**伏吟课**：诸神归位——逃人盗贼俱离不远
- 贵人顺行支前一位寻，逆行支后一位寻

**返吟课**：反复不宁

**八专课**：干支同处——主淫泆，用于阴阳贵杂占

## 【神煞体系运用特点】

**来源**：《六壬存验》吴师青

**吴师青用神煞特点**：
1. **皇恩+天赦**：刑狱占断核心救星组合
2. **皇诏（皇书）**：春寅夏巳秋申冬亥——朝廷诏命
3. **游都+鲁都**：兵战贼盗必备——游都所在知贼来，鲁都为埋伏
4. **贼符**：春卯夏午秋酉冬子——季节贼神
5. **天喜**：逐月定，喜庆之事
6. **丧门+吊客+病符+亡神**：疾病死丧四神组合
7. **天鬼**：正酉二午三卯四子——时疫/鬼祟
8. **风伯+风煞**：天时占断风的大小
9. **雷公+雷煞**：极端天气
10. **天医**：日干天医和月家天医两套体系
11. **劫煞**：三绝位——申子辰巳、巳酉丑寅、寅午戌亥、亥卯未申

## 【应期判断技法】

**来源**：《六壬存验》吴师青

**应期常用方法**：
1. **空亡填实**：出旬/年/月填实
2. **末传合处**：末传子，丑日成期
3. **鬼绝处**：火鬼绝在亥，亥日结讼
4. **末传冲处**：末传子，午日散讼
5. **贵人加临**：贵人加未为六月应
6. **三合定日**：本命+发用+日支三合
7. **冲胎定产**：八月建酉冲卯胎
8. **养神定月**：养神发用定月份
9. **干支冲合**：干支胎位逢冲为产期

## 【课传关系判断特色】

**来源**：《六壬存验》吴师青

1. **传将递生**：凶中转吉
2. **传将递克**：吉中转凶
3. **初生末墓**：多忧
4. **自墓传生**：危反安
5. **虎头蛇尾**（初虎末蛇）：重还轻
6. **虎初龙末**：凶变吉
7. **初末引从**：得人推荐（年命被引从）
8. **初中末与旺相休囚**：初旺末囚不利长久
