## 一、十二宫分断细则

### 总则

> **"十二宫中仔细看，何宫为劣何宫优。劣则为忌优则吉，妻财子禄辨其由。"**

十二宫位生扶合助日干本命 → 其宫诸事顺利发达。见凶神恶将与命干刑冲破害 → 其宫不利。

**空亡通则：** 遇吉不吉凶不凶。不可泥而执，大道原来要变通。

---

### 各宫分断

**1. 命宫**
- 吉神良将生扶 → 一生根基稳固
- 空亡墓绝 → 根基浅薄，多波折
- 与日干相生 → 有自主能力；相克 → 多受制于人

**2. 兄弟宫**
- 吉神良将与命干无刑冲破害 → 兄弟富贵和睦
- 刑煞遇 + 天刑狱加 → 非只身即仇家

**3. 妻妾宫**
- 吉神良将与命干无刑冲破害，与干相生合 → 妻贤益夫益子
- 刑冲 → 夫妻反目。无刑无劫便为佳

**4. 子女宫（男女宫）**
- 吉神 + 长生生气临 → 多儿女，子女贤孝
- 凶神恶煞 → 子女不肖或艰难

**5. 财帛宫**
- 吉神良将与命干无刑冲破害，与干相生合 → 财帛厚产业兴隆
- 天中煞 + 比转 → 不是寒士即浮夸

**6. 疾厄宫**
- **喜空** → 少病少灾
- 忌丘墓相逢 → 大病
- 遇德神 → 有救；遭恶将 → 定主凶

**7. 迁移宫**
- 逢二空 → 空空如也
- 德禄马在对宫 → 迁到处人钦敬

**8. 朋友宫（奴仆宫）**
- 受克为顺 → 奴仆听命
- 生不逊 → 奴仆反叛
- 虎勾厌煞 → 惹祸累主人

**9. 官禄宫**
- 得二马（天驿二马）或奇仪皇恩等吉 + 龙贵朱将与命干不相冲克 → 得美官
- 见吉神倘居囚死之地 → 得微官
- 无马 → 官不显；无禄 → 官缺俸

**10. 田宅宫**
- 吉神良将无刑冲破害 → 田宅增益
- 天鬼天贼 → 不利
- 旺相吉神 → 日增盛；凶神凶将 → 渐萧条

**11. 福德宫**
- 吉神良将会 → 优游子孙绵
- 逢空遇劫煞 → 一生坎坷
- 遇吉为荣，凶则寒

**12. 父母宫**
- 吉神旺相生扶 → 得父母力
- 凶神克害 → 不得父母力

### 十二宫诗诀（全文）

```
命到财官一惶忧，身更入吉又何求？
旺相为善休囚恶，德为喜悦刑冲忧。
十二宫中仔细看，何宫为劣何宫优。
劣则为忌优则吉，妻财子禄辨其由。

财帛宫见天中煞，更有比运转在其家，
将来依理推了去，不是寒士即浮夸。

兄弟之宫刑煞遇，更有天刑狱而加。
凶丧死气或冲害，若非只身是仇家。

田宅宫中是虚抵，天鬼天贼怕相交。
旺相吉神日增盛，凶神凶将渐萧条。

男女宫中见吉神，长生为用生气临，
良将并见多儿女，反此息无处寸。

奴仆宫中何以论？受克为顺生不逊。
若遇虎勾并厌煞，将惹祸累主人。

妻妾之宫怕刑冲，无刑无劫便为佳。
有善逢吉为良德，益夫益子善持家。

疾厄之宫却喜空，支忌丘墓莫相逢。
若遇德神为有救，如遭恶将定主凶。

迁移宫内逢二空，空空如也复空空。
若迁到处人钦敬，则德禄马在对宫。

官禄之乡所系重，天驿二马动人应。
若也无马官不显，或再无禄官缺俸。
学堂龙德禄官星后作空，
若非官职有黜革，便为庸庸世上翁。

福德之宫照得宽，遇吉为荣凶则寒。
此处逢空遇劫煞，一生坎坷无足言。
如有吉神良将会，便得优游子孙绵。

二相貌看时辰，不正相不真。
若带勾玄并蛇虎，何须论。
贵常龙合旺相吉，相貌魁伟人敬亲。

以上所说若入空，遇吉不吉凶不凶。
此际不可泥而执，大道原来要变通。
```

### 大运起法

| 方法 | 起法 | 步长 |
|------|------|:----:|
| **大衍数大运** | 不论阴阳，总以命宫起，以太玄数计之 | 十年一宫 |
| **阴阳顺逆法（阳男阴女）** | 从命宫顺数 | 十年一宫 |
| **阴阳顺逆法（阴男阳女）** | 从身宫逆数 | 十年一宫 |

| 性别 | 起宫 | 方向 | 步长 |
|------|------|:----:|:----:|

| 另法（行年） | 男从寅顺数，女从申逆数 | — | 一岁一宫 |

### 飞限
- 飞限 = 小限间一宫
- 飞限吉 → 虽逢殃咎无忧郁
- 飞限凶 → 须防灾祸不从容

### 三厄推算法
- 男以天罡加本命视寅上，女以天罡加本命视申上
- 初厄 = 上下神太玄数相乘
- 中厄 = 初厄 × 2
- 终厄 = 初厄 × 终厄数（相乘）
- **须刑冲克害或墓绝空亡方能相应**

## 三、寿夭细则

### 命上神长生状态定寿

| 状态 | 寿数判断 |
|------|---------|
| **长生** | 主寿 |
| **冠带、临官、帝旺** | 壮健，可望寿 |
| **沐浴** | 好色多病，禀气不足 |
| **死、墓、绝、胎、养** | 俱主夭 |
| **见生气** | 亦可上寿 |

### 三传定寿

| 三传组合 | 寿数 |
|----------|------|
| 四孟（寅申巳亥）作三传递生日干本命 | 长寿 |
| 从干递生去（根断源消） | 必主夭死 |
| 四仲（子午卯酉）作三传 | 不夭不寿（中等） |
| 四季（辰戌丑未）作三传 | 命无寿 |
| 死神带虎克日 + 空亡 | 黄泉鬼也 |

### 四课三传定寿应期

1. 四课凶神恶煞来克本命
2. 三传白虎有气
3. 行年上丧吊克本命
→ **此年夭亡**

**命上得何神即寿尽于其支年：** 功曹临寅年，太冲临卯年，余类推。

> **若有救：** 日上见吉神良将来救者，纵见灾厄命不损也。

### 寿数推算法

- **太玄数法：** 初传数 + 末传数 = 基础寿数
- **五行数法：** 按五行生成数计算
- **十二支序数法：** 按地支顺序排计
- **综合法：** 数理配合大小限、流年印证

**例：** 发用午（9数），末传子（9数），9×9=81。日支子为第一位，81+1=82岁。

### 日上/辰上神

- 日上神生日 → 主寿
- 辰上神生辰 → 壮健（难言长寿）
- 四课凶煞克本命 + 三传白虎 + 行年丧吊 → 该年夭
