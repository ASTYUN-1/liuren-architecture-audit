# 大六壬推命·格局速查表

> 来源：《大六壬终身论命秘要》二十四格 + 二十六局；《六壬推命学》二十四格 + 十六局
> 用途：推命时审格查阅

## 一、二十四格

### 龙系格局

#### 1. 正跨青龙
- **条件：** 生人本命是子，加于寅上，寅上青龙
- **辅助条件：** 命带吉将并驿马生合学堂于课传，身宅无遇破格之神
- **断语：** 极贵台阁之命
- **破格：** 他处有带蛇虎来冲克坏其贵气 → 名跨龙不住

#### 2. 倒跨青龙
- **条件：** 生人本命是子，寅乘青龙加于其上（龙反来就我）
- **辅助条件：** 喜课传扶助、吉神良将加护
- **断语：** 大富贵之命
- **破格：** 乘冲克更兼空亡或自败气 → 不美

#### 3. 双骑青龙
- **条件：** 生人本命是辰加于寅上，或寅加于辰上
- **辅助条件：** 喜傍宫生扶比合，吉神良将拱护
- **断语：** 富贵奇局
- **破格：** 最怕申戌来冲；课传中凶神恶将来冲克见伤 → 格破

#### 4. 双龙御命
- **条件：** 生人本命是子，遇寅加于辰上，又辰上为龙加于寅上
- **断语：** 贵命
- **破格：** 最怕无气冲克；合去一龙则不御命；再遇凶冲 → 二龙伤命，贫困至贱

---

### 蛇龙互化格局

#### 5. 龙化土蛇
- **条件：** 生人本命是寅，加于巳为蛇之本家，更有螣蛇乘之
- **断语：** 贱命，纵有大志而不得伸。多生富贵之家
- **救格：** 反喜来冲；合去蛇之乘神为福吉；反怕吉神陷于蛇口中生

#### 6. 土蛇化龙
- **条件：** 生人本命是巳，或带蛇临于寅上
- **辅助条件：** 前后吉神良将拱护，又太冲六合居于有力地位
- **断语：** 化则显贵。多生贫贱之家（白屋出公卿之喻）
- **破格：** 龙作空或被冲破 → 化而不化，反主贱

---

### 虎系格局

#### 7. 乘虎登天
- **条件：** 生人本命是午，带白虎临于亥上；或本命是申加于亥上
- **断语：** 威镇边夷，公侯之命
- **特点：** 固喜吉神将，亦不畏凶神将，冲合俱宜见
- **破格：** 惟怕无气 → 无赖恶徒

#### 8. 履虎尾格
- **条件：** 生人本命是未，或本命临未
- **辅助条件：** 逢吉辰良将扶助
- **断语：** 有福；不见吉神良将 → 术士吏卒之流
- **特点：** 喜见冲合，不怕无气。猛则虎惊，不猛则虎睡

#### 9. 立虎首格
- **条件：** 生人本命是酉，或本命临酉
- **断语：** 折冲万里，功名盖世
- **破格：** 无气 → 伏立虎首而抱惊惧之心，不敢出头

#### 10. 双骑虎背
- **条件：** 生人本命是申，又乘白虎
- **断语：** 猛烈刚傲，人不敢犯。武则好杀，文则轻刑
- **特点：** 最喜制伏，不问神将吉凶，最喜有气

#### 11. 虎化狸格
- **条件：** 生人本命或申加戌上，或带白虎临戌上
- **断语：** 军卒吏役或凶恶悍徒
- **破格：** 再无气并空 → 朱门饿殍
- **半格：** 逢吉将，上下逢冲合而终不化 → 半福之象

#### 12. 狸化虎格
- **条件：** 生人本命或戌加于申上，或带白虎
- **辅助条件：** 再得寅立于有力处，有气遇吉神良将扶助
- **断语：** 化则贵，白屋出公卿
- **破格：** 否则不能化 → 贱

---

### 天门系格局

#### 13. 命司天门
- **条件：** 生人本命之神加于亥上
- **辅助条件：** 带贵常龙后合朱并四马皇书皇恩觉察堂城吏
- **断语：** 掌职人枢秘之职
- **破格：** 凶将并空亡，或别有冲克 → 不得司，轻则减福，重则不流

#### 14. 天门不开
- **条件：** 生人本命之神作闭口临亥，或亥作闭口
- **断语：** 有大志而不得伸，寒儒之命
- **救格：** 别宫有神冲之刑之 → 可少发福

#### 15. 明入天门
- **条件：** 生人本命作太阳，或亥自作太阳，本命立于其上
- **断语：** 主富贵，不怕冲合空亡
- **破格：** 忌无气 → 恐为寒儒之命

#### 16. 暗入天门
- **条件：** 生人本命上乘玄武临于亥上，或亥自作玄武
- **断语：** 喜夜不喜昼，再逢旺气有魁罡厌煞照 → 绿林豪杰或乱世奸雄
- **破格：** 无气逢良善之神将 → 猥琐之小使

---

### 地户系格局

#### 17. 坐守地户
- **条件：** 生人本命加于巳上，带贵常勾空
- **断语：** 守财虏。最喜有气 → 中人产业
- **破格：** 无气再带凶将 → 至贫薄之命

#### 18. 夹拱地户（来拱地户）
- **条件：** 生人本命是辰，加于午上（往来求巳）
- **断语：** 中格之极富。别宫遇文明之星照应 → 以财得官
- **破格：** 忌冲克，如有冲克更带凶神将 → 不以富贵论

---

### 朱雀系格局

#### 19. 朱雀束翅
- **条件：** 生人本命上乘朱雀临亥子丑之处（朱雀落水）
- **断语：** 有七步之才而不得展
- **救格：** 别宫土多 → 朱雀免水患；见木神 → 雀得生腾，稍有微福

#### 20. 朱雀腾辉
- **条件：** 生人本命带朱雀临寅卯辰巳午之上
- **断语：** 文章盖世，官由翰苑
- **破格：** 无气更带凶神将 → 寒儒

---

### 其他格局

#### 21. 四墓交错
- **条件：** 生人本命属土，加于四土之上
- **断语：** 丰厚有财产
- **升格：** 别宫透出秀气，官禄显霞，学堂印杀加拱 → 以贵论
- **破格：** 无气再带凶神将 → 不见其富而见其贫

#### 22. 河魁贯甲
- **条件：** 生人本命是戌加于寅上
- **断语：** 宜修武业。别宫透出文明之星朝拱 → 文武全备之贵命
- **破格：** 无气又被别宫冲破 → 不以此推

#### 23. 甲贯河魁
- **条件：** 生人本命是寅加于戌上
- **断语：** 取用与河魁贯甲相近。有气得吉神良将扶助 → 贵命

#### 24. 朱勾拱拜
- **条件：** 生人本命是午加于辰上，或本命乘火者临辰上
- **断语：** 有气 → 性刚好辩，有贵
- **破格：** 无气 → 徒抱不平之气，逐日讼斗之人

## 二、十六局

### 五合局（三合五行局）

| 局名 | 三合局 | 五行 | 喜忌 |
|------|--------|------|------|
| **庚星呈瑞** | 巳酉丑 | 从革/金 | 喜生身扶助、吉将、旺气 → 富贵；忌刑冲破害身命、凶将 |
| **祥光摇拱** | 寅午戌 | 炎上/火 | 同上 |
| **帝座渊穆** | 申子辰 | 润下/水 | 同上。润下生身多富贵 |
| **青帝施恩** | 亥卯未 | 曲直/木 | 同上。曲直扶命必峥嵘 |
| **稳坐中宫** | 辰戌丑未 | 稼穑/土 | 同上 |

**总断：** 以上五格喜生命生身，更有吉神将扶助，别宫有情，且居时令旺气 → 富贵奇局。如刑冲破害身命，更带凶将，别宫无情 → 贫薄。倘在空亡，分三限优劣，究始末穷通。

### 四方连珠局

| 局名 | 三传 | 方位 | 喜忌 |
|------|------|------|------|
| **北斗司权** | 亥子丑 | 北方水 | 无破 → 必少登科甲 |
| **南极献图** | 巳午未 | 南方火 | 有成 → 定早步青云 |
| **西方专美** | 申酉戌 | 西方金 | 喜有气得吉助 |
| **东海探珠** | 寅卯辰 | 东方木 | 恶无气而招凶损 |

**总断：** 以上四格取各方秀气为三传，喜生命生身，吉将扶助，别宫照应有情，居旺相气 → 大富贵。如刑冲破害身命、凶将入传、别宫无情 → 贫贱。三传有情无情而少壮老三限系焉。

### 反吟局

| 局名 | 条件 | 喜忌 |
|------|------|------|
| **坎离交泰** | 本命亥子丑临巳午未，或巳午未临亥子丑 | 有气吉将俱集 → 发福；无气凶将 → 始终贫困 |
| **兑震投合** | 本命寅卯辰加申酉戌，或申酉戌加寅卯辰 | 取用与坎离交泰同 |

### 特殊局

| 局名 | 条件 | 喜忌 |
|------|------|------|
| **周天守躔** | 本命坐本宫不动而作三传 | 喜丁马有气入传 + 吉神良将 → 富贵；否则不以富贵论 |
| **海云双秀** | 寅卯辰↔亥子丑，从命发用入传 | 喜吉神，不忌冲合；带恶煞 → 秀而不秀反不贵 |
| **林火扬光** | 寅卯辰↔巳午未，从命发用入传 | 同海云双秀。凶将亦损其光明 |
| **金含北极** | 申酉戌↔亥子丑，从命发用入传 | 喜吉神良将，嫌空破煞；遇德禄二马旺相 → 大亨达 |
| **火明西岳** | 巳午未↔申酉戌，从命发用入传 | 旺相有气无蛇虎凶将 → 峥嵘；否则不以此论 |

## 四、格局总断原则

> **"有格有局亦须观其成破，无格无局宜详其有情无情。遇破者虽有格不贵，有情者纵无局不贫。"**

1. **格局成：** 有气 + 吉将扶助 + 别宫有情 + 旺相时令 → 富贵
2. **格局破：** 无气 + 凶将 + 刑冲破害 + 别宫无情 → 贫贱
3. **化格原则：** 化则贵，不化则贱（蛇化龙、狸化虎等）
4. **变通原则：** 课体全吉要详吉中藏凶；课传枯冷当审寒谷回春
5. **不可执一：** 虽跨虎骑龙遇刑克反断为寻常；一气有刑害岂推作出奇
