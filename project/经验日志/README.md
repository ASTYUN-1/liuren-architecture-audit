# 解课经验日志库

## 用途

每次解课后，AI **自动**在此记录断课经验。目的是建立"断课→验证→归因→改进"的反馈闭环。

## 文件结构

```
经验日志/
├── README.md              ← 本文件
├── _template.md           ← 新建经验记录的标准模板
├── 古籍-*.md              ← 八本古籍的蒸馏经验
├── 提取-*.md              ← 从其他书籍提取的经验
├── 1-案例库经验提取.md    ← 案例库经验提取（36条）
├── 2-案例库经验提取.md    ← 案例库经验提取（36条）
├── 3-案例库经验提取.md    ← 案例库经验提取（36条）
├── 4-案例库经验提取.md    ← 案例库经验提取（35条）
└── YYYY-MM-DD-占类-关键词.md  ← 单次解课经验记录
```

> 📌 **注**：`_metadata_index.md`（案例索引）与 `_metadata_schema.md`（META 规范）实际位于 `案例项目库/` 目录，本库不重复存放。

## 使用流程

### 解课前（查经验）
1. **先查 `案例项目库/_metadata_index.md`** — 用 grep 按占类+课体+发用快速定位匹配案例
2. **再查案例库经验提取** — 在 `1/2/3/4-案例库经验提取.md` 中按占类搜索同类课式经验
3. **查古籍蒸馏经验** — 在 `古籍-*.md` 和 `提取-*.md` 中搜索元数据标签行

### 解课后（记经验）
1. 按 `_template.md` 格式，新建 `YYYY-MM-DD-占类-关键词.md` 记录本次经验
2. 文件第一行必须是 `<!-- META: ... -->` 标签行
3. 同步更新 `案例项目库/_metadata_index.md`（追加标签行+表格行）

### 反馈到达后（验证闭环）
1. 更新对应的经验记录，标注验/不验/部分验
2. 更新 `案例项目库/_metadata_index.md` 中对应条目的 `反馈` 字段
3. 不验时填写失误原因（归因分析），下次遇到同类课式可避免

## META 标签体系

所有案例和经验文件统一使用 `<!-- META: 字段=值 | ... -->` 格式作为第一行，便于 grep 精确检索。详见 `_metadata_schema.md`。
