# 神将同用与神将互换

本机围绕本问与同一判断主线，按需用神将同用/互换补查对象、属性及切题关系。类象可参与取类定位和有条件的结果判断，不一律压成结论后的描写；互换不转移原节点真实旺衰、坐标、乘将与生克力量，也不凭本家名目另增一份救应。关键定位、有效作用或专法条件改变时，回 `liqi` 重核受影响主线及依赖结论。

## 两种说法与共同基础

北海《神将释》论本家关系及象意同用；喜爱六壬的水《天一群笔记》第十四节进一步用互换查事件中的对象。二者分层保留，不宣布后者全部等同北海或统一古法。

本家对应：子—天后、丑—贵人、寅—青龙、卯—六合、辰—勾陈、巳—螣蛇、午—朱雀、未—太常、申—白虎、酉—太阴、戌—天空、亥—玄武。多数在北海有明文，辰—勾陈参《金针》LF2638“午加辰为朱雀入勾陈”交叉支持；对应关系不表示全部词义等价，也不是本课实际乘将表。

北海明确保留：申庚白虎基本同用而白虎更峻烈；戌偏健动暴躁而天空妄起事谋较甚；子较无天后仁慈、恩泽之能。十二神具体义见 `shen-symbols`，十二将职能见 `jiang-symbols`。

## 有条件地使用互换

1. 先定子问、目标对象及按分类所得的正取法。写清是找梦、文书、人物、钱款还是别的对象；不先把梦、口舌、盗贼加进题干。
2. 引天一笔记的替代路径时，记“某将不见→转查本家某支”的来源与查找范围。例如梦问无蛇看巳；成绩文书消息无雀看午。北海关于类不现的分类分支仍先核，不能以互换取消所有不现条件。
3. 转查对象可另看该支的状态、实际乘将、所临及阴神；先说明每个节点代表什么。作者另举巳为梦、乘蛇之神为做梦者，是该示例的角色分解，不能推广成所有神将必定两个人。
4. 财乘玄武再看亥是笔记的对象细查示例，原文未给完整盘；不能把其“卯为玄武地盘”写为永久坐标。是否真有盗窃、由谁实施，不由象单独证成。
5. 回到本问，说明互换增加的是对象、属性还是作用线索，以及它是否改变关键定位或本问结论及其条件；反证同查。原天将、所乘神、天地盘坐标保持原值；未入课传的天将不能因本家出现而改写成已入。来源同根不重复计证，不另造三传。

“天官所乘之神就是天官的地盘”是该作者的角色比拟；不替换排盘中的真实地盘。翻宫在该节指阴神深化，合宫另论，不合并成互换。笔记开篇说四课、后节列八门，范围变化留作作者说法，不覆盖北海分类路径。原文“子午合”不采用为六合，北海巳章两句阴阳吉凶相反不生成通断规则。《万占》仅为有身份的候选象辞补充，后段盲派/奇门口径不并入六壬。
