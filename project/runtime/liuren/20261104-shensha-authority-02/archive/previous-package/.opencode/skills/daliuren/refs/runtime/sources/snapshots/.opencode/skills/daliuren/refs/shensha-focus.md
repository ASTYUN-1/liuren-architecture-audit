# 用户常用神煞与盘面散见项目：逐项核查表

完整断课必须核到以下32个去重项目，同时执行 [八煞九宝综合核查](bashajiubao.md)。这里的基础检视不只限三传：日干支、四课三传、相关类神和已核年命及其上神/直接阴神，连同与本问有关的盘面散见落点一起查。每项记录起法是否可核、具体位置、是否切题；无关者止于基础检视，相关者再查力量和作用。神将状态是主要判断依据，神煞作辅助。

## 原称、去重与待核

用户已澄清名称为“帘幕贵人、月破、桃花、丧门”，本轮按这四个名称执行；先前口述误识仅留在历史记录，不再列作当前定义缺口。“丁马成神”分查丁马与成神，重复成神去重。阳刃、羊刃分别核查；六壬文献确有混称，必须同时署明实际起法，不能凭字面互换，详 [两刃排法](blade-methods.md)。

实际读取须执行 [本地引擎神煞字段](engine-shensha-output.md)：完整JSON逐宫核查，不能只读keyShensha摘要；输出存在、起法成立与实际有效分别判断。

旧覆盖按本次修改前的本地skill审阅：有名字/触发词/个案出现不等于已具备可执行起法和取舍规则；“新增重点”包括缺项及原只有名录/零散示例者，并不宣称其他所有资料从未提过。

基本象义及如何随本问取义见 [32项释义](shensha-meanings.md)。刃类取用以阳刃为重要项目，羊刃次之；二者象义相近，但起法与落点分别核对，不能并列为同等重要或重复计证。

## 占类深化重点

以下是检视重点，不是封闭适用范围，也不是吉凶权重或可靠性排名。先看所问、角色/类神和神将力量，再用神煞补象；基础32项仍逐项核到，重合项复用，不计多份独立支持。

| 占类/子问 | 深化重点 | 必须分开的判断 |
|---|---|---|
| 疾病、生死、疗效 | 病符、死符、死气、丧车、丧门、生气、天医地医、德禄、血光及刃；已有丧吊/死神继续查 | 病人/病神/救神三方力量；病因、程度、转归、疗效与时间分别裁决 |
| 胎产、保胎、生产方式 | 生气、天喜、天地医、血光/血支血忌、刃、破碎、月破及成神 | 保胎与临产喜忌可不同；出血、发动、顺剖方式、完成、母胎安危不合并 |
| 考试、求职、任职、文书 | 帘幕、日德支德、日禄、文星、旬奇旬仪、成神、闭口、进退神及马 | 考官/文书/职位各定位；通过、录用、报到、长期任职、待遇分判 |
| 婚恋、人际、来访 | 桃花、孤辰寡宿、天喜、成神、德合、闭口 | 认识、来访、情意、关系确立及婚姻分判，不由一桃花断第三者 |
| 财物、经营、工程 | 小耗、破碎、月破/岁破、生气、日禄、成神、德合、马 | 收到财与发生支出可并存；损耗方向、用途、程度不由煞名给数额 |
| 出行、调动、行人 | 驿马天马丁马、进退神、成神、破碎、血光及刃，按场景补病符/丧车等 | 动意、发动、成行、到达、平安及办成分开，不把动名当完成 |
| 家宅、年运、综合运 | 太岁、日支/年命相关状态、小耗、孤寡、生死气、天喜、月破等 | 岁/月/日基准分开；家庭成员与本人分开，不能全取日干为一个人 |

各项出处在 [来源卡](shensha-sources.md) 及 [释义补充来源](shensha-meaning-sources.md)，同名异法须明示所选口径。月医、旬奇、岁干/岁支死符、岁/月小耗和文星等分歧不可用有利结果择表。

## 核查记录与简洁输出

用一份简短记录区分：已核成立且采用、已核但受限/无关、已核未成立、待核。可以写S01–S32状态及相关坐标；同一作用已在理气主线解释则交叉指向，不重复堆表。缺原始字段时说明哪些项目未能核，不把来源表本身当盘面命中。

最终报告只保留关键采用项及影响结论的待核项，写明对象、位置、力量、具体影响与主要反证。名单长短不决定吉凶。“本次未能采用”仍不排除该结果，依 [规则语义](rule-semantics.md) 表述。
