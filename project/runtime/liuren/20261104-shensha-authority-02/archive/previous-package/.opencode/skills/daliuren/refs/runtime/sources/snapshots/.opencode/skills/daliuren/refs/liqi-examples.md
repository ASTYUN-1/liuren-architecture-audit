# 理气与取用的正反对照

以下为方法边界示例，不是新增实测案例，不提供任何真实患者的结局。配合 [理气规则](liqi-analysis.md) 使用，不能将例子中的缺省条件补入实际课。

## 有克与制得住

已确认巳火为医药候选、申金为病鬼，只能先确定火克金。若所用口径下火死而金旺、巳又受制，不能跳到“中传子孙实，所以治得住”。反之，施制者得气且有明确作用位置，也不能因为“已有凶课体”就取消它的可能作用。须再看是否解除本问关键阻碍。

## 长生与扶助对象

亥为甲木长生，是以甲木为参照；亥本身临何地、自身是否受克，是另一层。另论金长生于巳时，应明确改以金为本，不因此自动取消巳火克申金的关系。两个层次共存，取舍必须落到对象与力量。

## 神将与内外战

在《壬归》卷一口径中，若地盘金克天盘木、天盘木克天将土，是完整内战链；不能只看到天盘克天将就声称已核完三层。若改为地盘水生天盘木，神克将仍可能使该类将不和，但不再具有同一条完整内战链。不要把“天将为贵人”直接写成有权相助。

## 合与作用方向

巳与申有刑合关系，要看所用合化条件及双方状态。牵制病鬼和牵制医药，结果不同；月建补虚成局是附带条件的方法，不得将“可能合金”在复盘中无依据升级为“已经化金”。

## 空亡与病程

病鬼空与病人所赖的禄、长生或救神空不是同一件事。先辨所空的对象，再结合急慢病程及状态取义；不将高龄一概改成久病，也不将起病急一概豁免。若题干只给“两天前发病”，不能增补长期衰竭史。

## 反证与重评

结论依赖天医、行年与长生，后两项输入口径改变或天医起法被质疑，应先重评这些节点。剔除后仍能维持原判断，需要新的有效支持说明；不能以“方向不变”代替复核，也不能为了改判临时增加老人元胎必死之类通则。

## 同源支持和反馈

一支兼德禄解神，按一个相关节点理解，不算三次验证。若反馈只说某日离世，不能据此将持续卧床、从未好转、治疗无效及具体合化机制分别判为已验；题干已给的头晕也不算新预测命中。

## 日期精度

规则只能指向申日，而所定范围内有两个申日时，应说明区分条件；无法区分就停在该精度。后来得知其中一日发生事件，不补称事前准确选出了它。出旬填实是所选应期法的解释，原局旬空记录不随流日而改写。
