# 问题定位与主线

每个子问明确原问、事件主体、提问/代问关系、阶段、期限、判断维度及成功标准。成败、存现、趋势、数量、程度、属性、身份、方位和时间分别定位：进水不等于成灾，录用不等于通知或入职。背景只取题干和已核事实，不由盘象补造。

用正文或必要表格说明“现实对象→候选类神→采用来源与条件→实际位置→所答子问”，包括干支含义、主辅类神、六亲参照和已核年命归属；未知留缺。身份、角色不只贴标签，必须参与实际判断。分类取用与人物细则读所选专项，神将与其他显象纪律依 class-mapping，不另设统一人物表。

定位未成立，暂停依赖它的生克吉凶与应期，可继续核盘和查源。多个有据取法先分其适用子问；不能因某法更吉凶而倒换。变更定位时重核受影响关系、六亲及应期，不能换主体却沿用另一参照的“生我”“脱我”。特殊代占和年命法说明来源，不按亲属称谓机械替换。

主线须直接回答本问：具体对象核对应类神，人事相互作用核日辰关系，方向形势核课传结构；三者互核，无永久主次。以直接性、位置、状态和完整专法说明选择，给主线及最强相反依据；不将病象偷换病人，资格偷换考生。无法裁决留分歧。

司法行政尚无通用机构表：报警、调查、处罚、诉讼、羁押、取证、办证先分事件，不能仅凭机关名同取勾陈/鬼/虎。未齐专项查本题原书，不套邻类。旧“十类”是检索标签，十二研究分类是取用路由，两者不互相限定。

仅用户未明事项时用来意法：占时及所临类神、天将相参，泛占察课传紧事与干支实际落点；“干上主思、支上主行”是该法口径，不冒称所有四课的固定角色。明示为推测占类，不改写用户已说的问题；紧事越问例外须有原法条件。
