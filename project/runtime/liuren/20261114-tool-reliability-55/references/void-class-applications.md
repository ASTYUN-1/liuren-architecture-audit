# 空亡详释：按对象、环节与时间应用

范围：《理法简易》LF-U5467—5610“三 空亡详释”全节，并连读5611—5693寄宫空论；关联3195—3245、4961—5017及6671。正文以用户已采用U08/U10为执行主线；原书、北海解释与用户本轮推广分列。逐段连续原文见book-annotation-evidence。本次不宣称已穷尽其他书的空亡论。

## 统一检查顺序

1. **谁空、哪里空**：天盘旬空、本支坐空、日干寄宫空、日上神空、天将乘空与天空天将分别定位。同名支不自动是同一坐标。类神、类将、救神、身禄、障碍物等不可互换。
2. **所求还是所忧**：需要取得、维持或借助的对象空，可能无着、虚量、难兑现或失去支持；所忧的阻碍、病因、争讼因素空，可能减阻、无实或未发。还要核对象实际状态和制救，不把“凶名空”当一律免患。
3. **影响哪个环节**：没有开端、过程断接、最终未成、成而不久、数额不足、消息失实、旧事再发是不同命题；先定位再作结论。
4. **气地和通路**：月令、生处、坐处、制处、阴神及神将结构，共同影响有效作用。生扶可能增强迹象和推动力，仍不自动填实；衰弱也不是删掉节点。旬空字段保留，沿U08综合其效应。
5. **时间变化**：依U10察出旬、逢值、冲填及季节变化改变什么条件。出旬解除原旬空条件不保证实现；冲墓可启、冲合可破仍须冲者有力、通路成立并对准障碍。原局不重排。

原段常用“空则不成、必死”等强语保留为原作者判断，执行须有原完整对象和组合，不自动变成跨占类成败开关。传统五行金鸣水流木朽火发土崩只作合题物态或动作候选，不能据金水不嫌空就取消空亡。

## 跨占类条件表

| 场景 | 必须区分的对象和条件 | 可执行的分析 |
|---|---|---|
| 求财、收益、成绩或数量 | 财/关键类神空、出财者空、受者空、龙将乘空及数量公式有无修正 | 无资源、无通路、难取得与份额不足分开；原文财空防损仍要察是否已有本钱及支出。关键量有据减数才进算式，见quantity-strength |
| 求职、升迁、办事 | 所求职位/官禄、关键承办者或贵人、文书、本人 | 贵空且害身可能求助失效；某职位通路空不扩成一切职业道路皆败。贵人有名、实际办不成与完全无人出现分开 |
| 交易、合同、婚姻关系 | 六合或承诺环节空，双方类神和实现条件 | 合意、说合可能无着，不能仅合空就断对方骗人。现有关系、撮合、正式签约/成婚是不同阶段 |
| 文书、消息与考试 | 朱雀/文书、实际文件/分数类神及到达环节 | 文件迟滞、内容虚误、未到或无效分别论；不能从消息空直接推考试0分或彻底无信 |
| 疾病 | 病鬼/病因空，与患者身、禄马、医药救神空；新病/久病须事实 | 病空可减病，身或救助空可减承受与支持；新久病及蛇虎死墓组合保留原段条件。年龄不代替病程，不能由单项空亡下现实死亡结论 |
| 官讼、纠纷和忧患 | 争端未起、已起、实施伤害者、救助或诉讼程序 | 勾空等可表未形成争讼，已进入的程序还看后续；敌害空未必凶，救应空未必吉。不能把“无讼”误成必胜诉 |
| 失盗、受骗与谋害 | 玄武所指人事/行为、财物和受害者，是否作日鬼或附已采用凶煞 | 企图不实、盗者难入与财物损失分开；作鬼附煞的专项不能仅凭玄空就豁免，也不因名象指控现实犯罪 |
| 胎产 | 占已孕待产、是否受孕、胎儿、产妇及胎爻/救助 | 胎空在占产可表脱离而速，在求孕可表难实，不是同条件相反；胎空不能独立支持医学异常 |
| 出行和状态转移 | 身、马、路线、罗网、关墓和目的；求稳或求动 | 身空或马墓空可妨行动/持续，障碍空可利脱离；旺火空仍可动不等于一定到达。可推广转岗调动，但须指出被阻或被放开的转换环节 |
| 物态、坟宅或处所 | 实际物体、内外空间、支左右和居住取得通路 | 空虚、孔窍、空置等可能是属性；租得、买得、住得及产权不同。不得把空置当不存在，或宅空便推出所有住房途径皆败 |

除原文各占类外，成绩、岗位状态转移等为用户要求的条件推广，保留此身份；并非作者原文已经逐项写过。

## 三传空与阴阳的阶段关系

LF-U5487—5489、5507—5539：初空末实可先无着后落实，中空可能过程阻断，末空可能归结虚或难持久；要先核三传各自代表本问何对象和阶段。初空也可能旧事重启：原节“空用入生、复临干支”等有重新发动语境，不得抹成绝无起事。初实末空不等于开始即败，初空末实也不保证最终必成。

妻、子孙等类的先后空实依对象变化与关系阶段看，不把每一传都当同一人的连续命运。阳显阴藏可用来区分显露的条件与背后难以落实的承接，但不能自行把空阴神认定为隐私或欺骗。

## 寄宫空、作用与长期事项

LF-U5611—5693将日寄宫空、日上空、落空等并论，并讨论常占与长期、天时地理的取法。当前位置须逐项标清，不以一种坐标的空推翻另一种。有原文说常占月将等空、天时地理长期不空，先保留原占类职责与时段差别；长期事项仍有阶段和承接，不能简单改成“长期都不空”。

同节科甲与荫官、租宅与购宅等例提醒：被否定的可能是某条实现路径，不是整类事项永远不可能。旧例中的终身命运和断语留作方法来源，本机仍只占事，不恢复出生运限。不要把原书“应空”当已验证的新旬算法。
