# classical-conflict 占类方法

本机事件定位：攻守用事件中的攻方/守方，干攻支守不随谁问而倒换；盗捕另分捕者、盗者、赃物。代问者不因与某方的亲属关系成为额外干支角色。

来源方法：`zhinan-zhanbing`；依总入口加载，完整条件见下文。

下列I段是原书方法的来源摘要，不是无条件执行指令。现行判断须按judgment-core及下文E段核角色、气态、有效作用、制救和最强反证；“必得”“任一即获”等强语不能直接结束判断。所列贼符、游都/鲁都等只有本盘程序已采用且resolved时才能引用为程序神煞事实；未登记者仅留研究，不自行补起冒充已采用。

## I — 方法论骨架 (Interpretation)

- **面对的问题**：占兵事/贼盗/逃亡时，先要分辨"到底有没有这件事"，再推演攻守胜负或贼去何方，最后给出现实可用的行动结论（守城/报案/寻人路线）。
- **兵占有无兵事框架**（f32/p12）：第一层只问"有无军事行动、有无贼兵来"，查四类神——**贼符**（子卯巳申）、**游都/鲁都**（兵贼来向，如辛日寅为游都）、**天乙贵人**、**日鬼**；再在课传中比较诸神**力大者**（乘太岁、当令旺相者力大）定有无与时机。
- **贼符断兵警**（f34/p13）：贼符（子卯巳申）加干=外敌来、加支=内乱起，加干支=内外皆有兵战之象；以所加支神之旺衰（如子水太岁旺于冬）定应时。
- **攻守定位**（f33/p14/p15）：**干=攻方、支=守方**（支为城）；干之阳神=攻方大将、干之阴神=攻方部属，支上两课=守方大将与部属；三传中以**发用=敌方、末传=守方**。据此读：干上阳阴相克害=敌人内部有矛盾；**干神生支=居守保固、无破城之患**；发用生末传、中传制初传=敌攻不破城。
- **贼占玄武四步**（f35/p97-p101）：占逃亡/失物以**玄武为类神**，四步定位——①**方向**：玄武所临地盘支的卦位（"地支临处知贼去"，如玄武地盘亥游于未=坤卦西南）；②**里数**：以玄武阴神（盗神）与其所临地盘支序数**上下相乘**（卯六×未八=48里）；③**亲属/居处**：玄神所乘支与地盘成**三合**或居长生之地=在亲戚处（"三合支辰眷属亲"），再以支象细断（亥=近水、卯=阁、未中鬼柳=门前有羊柳）；④**捕获**：发用**勾陈克玄武**且三六相呼=必得寻获。
- **贼可获三条件**（f36/p69）：①勾陈或官鬼克玄武；②玄武自坐败地；③玄武坐月将上。三条**任一成立**即可断贼可获。
- **非占现类勿言之的原例讨论**（f46/p68）：书中以玄武发用、人宅受脱、衰土难担旺财、传归支上等讨论越占。现行只在有充分切题作用链时作为待核线索，不由这些名象认定现实已遭盗窃或自行扩大原问。

## E — 可执行步骤 (Execution)

1. **分清事件**：兵事、攻守、盗失、逃亡、普通行人分别定位；非兵事不跑兵事有无。普通失物优先用 [shiwu-xunren（方法模块）](<lost-person-object.md>) 辨失落/遗忘/被盗，不见玄武就假定盗窃。
2. **兵占先有无后攻守**：沿用贼符、游都/鲁都、贵人、日鬼等，在具体位置与状态中比较；先说明攻守角色为何对应干支与三传。古代军阵不直接等同现代纠纷或游戏，类比须标明条件。
3. **盗失/逃亡按子问选法**：先辨事件性质及目标角色，再用上文玄武四步检查方向、距离、处所、能否寻获。寻物与寻人、自己遗忘与盗窃的取用不能无条件共用；三条可获条件是书籍候选，仍检查反证。
4. **空间和时间各自核算**：说明方位的天/地盘锚点、里数数制与单位；原书上下相乘不可擅改为现实精确距离。时间须先定节点与尺度，原作者待议项保持待议，不为完整而硬给。

沿用上文 z01、z10、z16 的书中论证，补充 M08、M10 的环境/原因分层；原书叙事不是现代独立验证。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- ce30（非占现类勿言之边界）：既不能忽略本问已有的切题作用，也不能把玄武发用等原例条件升为自动越占开关；额外事实需可靠信息，不凭盘面指认盗者或补造被盗情节。
- ce25（待议断法）：续二"何以言丙丁日可见"作者自标"（此点待议）"，推导（丙丁为子孙/天地合德/会神）证据链不足——不可升格为已验证法则引用。
- 贼符/游都鲁都等神煞必须核起例再断（如 z01 原书"血忌"实为"血支"之误），照抄原书名号易全盘错位。

### 作者的盲点 / 时代局限

- 本模块所引z01、z10、z16等含原载“果应”叙事；本轮没有完成全书反馈、失败例或盲测统计，不能宣称全书均应或据此证明预测效果。
- 兵占语境是明末清初的边关合战/城防/卫所，贼占是冷兵器时代偷盗逃亡——对现代战争形态、城市治安、司法报案体系均需大幅类比转化，类神映射（陈姓同音、里数相乘）对现代失物寻人仅为文化推演参考。
- 神煞/星宿考据（未中鬼柳、春分点移动）占篇幅，与断法应用关系弱；"壬学根于天文又独立于天文"是对古诀的解释学立场，非实证结论。
