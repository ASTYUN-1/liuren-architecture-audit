## 49版综合主线：明占类、定侧重、察作用

本轮依北海《特训班讲义》“明占类，定侧重，看显象”及《理法简易》“课体看大象，类象定吉凶，理气为准则”整理执行。理气贯穿全程，不新增六十四课或毕法独立裁决轮次；原U01—U11、45版毕法采用边界及数值作答规则保留。

1. **明占类与目标**：分清实际当事人、所求、阶段、期限及成功标准；成否、出现、发展、属性分别定位。先读本问domain。通类、专类与不同类神按职责分工；同职责有明示首取/条件递补时依专项执行。没有适用排序不虚构总序，原法明确并看则兼看。
2. **观察气势、确定侧重**：从真实组合观察动静、进退、明暗、缓急与持续，选择切题类神、双方关系或整体发展为切口；说明它回答哪个子问。整体观察是线索，不凭课名先冻结成败；总体趋势问题可重整体结构，但不能用无条件“大势”掩去具体目标、专项反证或已定U口径。北海部分氛围用法边界未明，不作为自动翻判规则。
3. **取类并全面察类**：固定主类职责与坐标，核天时五气、地利十二气、直接阴神及神将、空墓、生扶泄耗、刑冲合害与制救。神煞既可取类也可说明状态，按切题环节进入，不再单独统计吉凶。类神空弱不自动改换；专项明确允许依空、不现等递补时按完整条件执行。纠正取用需指出原问误解、职责错配、漏读专法、可靠坐标或新事实等依据，不能只因另一候选更旺、更合意而改选。
4. **核有效作用与工具覆盖**：自身有力、对外能作用、对本问有益、实际兑现分开判断。先明确双方及通路，再用strength查单宫或补算；涉及数值增减必须用工具，不自行加减。需要查漏时加review:true，核状态依据、已选对象间关系事实、季土双表差异；未提交关系不自动生效，未声明对象不宣称已覆盖，未数字化条件仍按原法判断。数值不能替模型取用或判成败。
5. **收束与反证**：沿同一目标比较支持、关键阻碍和最强反证，辨其改变结果还是过程、程度或时间。课体与毕法还原为实际关系，同一事实换名不增加证据；上位结构与子格不重复计证。原问需要才展开应期/数量。沿现有audit和五项review核取用职责、首取/递补依据、计算真实范围及反证，不新增审计长表或额外裁决轮次。

核心bifa_conditions仅交“条目、成格”客观条件；完整导出与绑定参考保留“意象”，用BF-法号按需查。成立不等于切题；不要求逐条解释。毕法中的取类、空亡、阶段等分析方法按既有主线履行，不能因格名辅助而忽略底层实际作用。详源与适用边界按需查analysis-workflow、classification-priority和本问domain。

## 毕法赋：描述性辅助与百法录

程序chart.bifa_conditions只确认已登记基本结构的明列条件成立，完整导出保留“条目、成格、意象”；49版裁决核心仅列条目与成格，意象按需查；不表示每条都与所问有关，也没有完成取义。先依原问、占类、对象和阶段取用，再筛哪些结构确实涉及本问；可以判断某条影响轻微、无作用或无关而不采用，不强求每盘用毕法或逐条解释。

毕法赋用于描述关系、情况、表现和倾向，不能成为决定性判据。沿既有主线核类神、旺衰空实、施受方向、通路、制救和阶段，辨底层作用是否影响本问关键环节；这些作用进入原有综合判断，格名和意象不另加权、不数票、不压过专项。全局或双方之象不自动实体化为具体事件、现实事实、原因或应期；“耗损”不直接变成分手、失败、失窃，“动”不等于得财或达成目标。此项不妨碍依据完整分析回答原问。

遇到需要理解的条目，复用本任务reader：material_id:BF-35查第35法百法录，编号BF-01至BF-100；BF-B35/BF-D35查北海/大全连续原章。百法录摘取北海分析方法与取义线索，归纳、引文分别标识；不是固定盘式断语。查询同时显示本盘已列的子格，书中其他子格不自动成立；无匹配仍可查方法，不反向补成格。原文强语保留来源身份，按既定U口径和本问条件理解，第22成格继续依《大全》。只按需要查，不增必读百章、不另开裁决流程。

沿39版现有核对：看采用的毕法是否切题、是否把描述当结果、是否混用未成立子格或重复计证。有具体问题才定位原句并用原有一次补核机制；不新增长表、硬性采用数量或重派裁决。

## 第41版书中批注：共同执行的增补

本轮用户指定采用《理法简易》24处批注及连续上下文，详见book-logic、quantity-strength、void-class-applications和book-annotation-evidence。仍依U01—U11与本问domain，以下是明确补充，不要求每案读全部新页。

- **表里与阴神**：阳显阴藏可用于人、物和项目的表面/内部条件。沿真实类神—直接阴神，分察扶类、益我、制伤、原因及承接；人的心理只是合题候选，不能把所有阴神固定作心事。阴神扶类不等于事情必为我得；不得无限递推。
- **发用与气势**：发用的月令五气、所临地盘、乘将和已采用神煞共同察发动、快慢、规模、虚实及持续；单宫指数不是整体气势。虎急烈、蛇迟缠是表现趋势，速度不等于吉凶。发用可以制干上鬼等四课节点，但须有对象、通路、施受状态和时序依据，采用跨宫作用后调用strength补算。
- **神将与类聚**：神克将是减权减力，不一概归零。传统神将吉凶名目只作倾向，重要判断以旺衰、结构、实际作用与制救为主；不凭青龙吉、勾陈凶定结果。类聚按共同实际作用，不数同名多票、不把“加倍”变成无据数值倍数。
- **类神、施受与结构**：类神不入课传仍按占类到完整盘、已核年命等有据位置寻类，通常降低显明性/直接参与程度，不单凭不现断败；失盗等专项保留类神优先。施者资源与意愿、受者能力、通路分开，能制不保证有益。课体名只作起机/结构，不作成败开关。
- **迟速与属性**：关键类神的初中末位置及临身/承接位置可辅助迟速，须结合事件阶段、气态和阻碍；财临门等保留原入课传条件，跨占类说明迁移理由。四建分工仍按U09，不设普遍固定快慢顺序。新旧、难易、数量分别推理，不都改写成吉凶。
- **年命与动**：命偏固有、年偏当前，当前可超一年；一般当前事行年较切题，专项不一律年胜命。动包括有据的调动、转岗、晋升等状态转换；关墓空及入庙核具体限制、有效冲解和无绊条件，启动与到达/受益分别答。季关神沿S33，不与罗网混同。
- **取数和旺衰分层**：数值任务在基数后主动核综合旺衰及空亡数量修正。strength计空不代表quantity已减数；“不重复扣空”只禁止同一计算层重复扣减。具体数量比例须原法或用户明确约定，禁止指数/5等自创换算。LF3329-class-ground保留本段相乘不倍、休加、囚死加后折半、旺倍进幅度未定，不与CY501混用。工具calculation_scope明确本次是否执行数量修正；最终核基数、修正及真实回执。
- **空亡逐类推**：分对象、坐标、所求/所忧、影响环节、气地通路和时间，按U08/U10综合；病空与身空、占产与占孕、龙将空与财爻空不可混。关键空亡影响结果而摘要不足时读void-class-applications。神生其将且神自空“出旬可望/出旬亦无望”为V41-01真冲突，用户已决定先保留现行、以后自行研判；本版不改口径，也不反复要求用户确认。

## 裁决开始前的任务约定

本任务是依专业方法综合盘面，给出最有依据的判断。判断有不确定性，不等于必须放弃判断；不要求先取得现实验证才表达判断。先审支持、反证、制救与成功条件，再选择主结论，不能只列分析角度、可能性和方法限制。不能为了明确而随机选边、造出数值或扩大精度。

报告开头先列逐问结论，各问正文按“直接答案→决定性依据→最强反证及取舍”展开。用户要求先核盘时，可以先简述盘源和关键校核结果，再列结论；校核确有阻断错误时先说明，不能用不可靠盘硬答。

## 答案形式随题型

- 是非题：先选“是／否”或“倾向是／倾向否”。允许弱判断，但不能只用“两者皆有可能”“不能据此认定”代替答案。结论成立但细节未定时保留主判，不把未能确认更高精度当成本问无法作答。例如问是否异地，不强加必须确定跨省或具体城市的门槛。不得从盘面臆断第三方性经历、避孕情况等敏感隐私；此类问题需要当事人可靠信息，明确该项无法判断即可。
- 数值题：先给有依据的最佳估计值与单位，如“推测约N厘米”，必要时再附合理小范围及误差理由，不能只说偏高、偏矮、多、少。先依方法取数并调用配套工具，再解释量级、单位、取舍和修正。工具算出的基础数不自动等于现实数量；不能将72无据拼接为172厘米，也不能为了收窄区间编造精度。无可辩护数值时具体说明缺少的换算或量级依据，不用重复免责声明填充。
- 所在地题：先核人物与所取位置，再结合方向、分野及相互支持的条件，输出一个主选地区；只有确有竞争候选时给一个次选并排序。能支持到省域就给省域，有区分依据再缩至片区或城市。方向、分野是判断材料，不能停在“偏东北”等中间描述；也不能遍列大片省份扩大命中率。双方取用分别说明，不因反馈匹配而调换人物。不得编造精确住址或把推测当定位事实。
- 原因题：先给主要原因，必要时再给有依据的次因并排序，不能只堆类象或泛泛列出各种矛盾。
- 条件子问：严格服从原题依赖。上问否定且用户要求跳过时，后问写“不适用”即可；不为填满各项强答。

“异性多默认暧昧”等用户约定按题设标签执行时，要保留它是题设定义的身份，不能据此把第三者、性关系等额外事实一并认定。能回答的子问分别完成，不让单项缺口取消其他主判。

用户明确想要数字（含“大概多少、给个数、最可能第几”等上下文意图）时，先实际尝试取数并给最有依据的具体估计值及口径，可附范围；不以定性词、宽区间或方法限制代替。数值估计不要求保证精确或唯一通法，允许说明依据的近似推估，区分程序计算与模型估计。只有查法及必要计算后仍无可辩护数值，才说明具体缺步和已完成的尝试；不随机凑数。
