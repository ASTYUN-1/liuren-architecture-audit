## ① 甲旬首规则

- 六十甲子以**甲统领每旬十天**，六旬首：**甲子、甲戌、甲申、甲午、甲辰、甲寅**。
- **定旬法：从日干逆推至最近的甲，甲所在之支即旬首**。
  - 例：庚午日，逆推庚午 → 己巳 → 戊辰 → 丁卯 → 丙寅 → 乙丑 → 甲子，得甲子旬。
- 六甲即六旬之首；**旬首即六仪课之仪神**——旬首发用或入传成六仪课（礼仪喜庆线索，不保证病愈狱出；旬仪与成格条件分判，见 [S27](<shensha-focus.md>)）；无旬仪不名六仪课。

## ③ 旬中遁干（"遁"的含义）

- **"遁" = 给课传各支配其所居旬之天干**。
- 同一地支在不同旬所遁天干不同：如午在甲子旬遁庚（庚午）、在甲戌旬遁壬（壬午）。查法：先按日干定旬，再查上表该旬行内对应支的天干。
- 用途：
  1. **遁干六亲读象**（见下节）——旬煞皆以遁干与日干的六亲关系读象；
  2. **查旬遁类神煞**（丁 / 癸 / 庚 / 乙 / 辛，见下节）；
  3. **遁干五合是有路引动之一**（步骤 6 有路扫描；标准通识：甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火）。

## ④ 遁干六亲取用

以**日干为主**，与各遁干论生克定六亲：

| 生克 | 六亲 |
|------|------|
| 生我者 | 父母 |
| 我克者 | 妻财 |
| 我生者 | 子孙 |
| 比和者 | 兄弟 |
| 克我者 | 官鬼（**阴阳异者为官、阴阳同者为鬼**）|

- 例（甲日，甲子旬）：遁丁卯——六亲阴阳以**遁干与日干**论，不以支论：遁丁为阴火，为甲（阳木）所生（我生者），为子孙（子孙不细分阴阳，故丁阴甲阳之异不论）；若乙日占，则卯遁乙与乙日比和，为兄弟。
- 旬煞皆以遁干六亲读象：如遁丁为**财** → 财动；遁丁为**鬼** → 凶祸（丁鬼并见大凶）。
- 总则：**凡凶神将喜空亡，吉神将忌空亡**——凶神（鬼、白虎、丁鬼等）逢空反主虚惊、凶中得脱；吉神（财、禄、贵等）逢空则落空、吉象打折。

| **丁马（旬丁/遁丁）** | 丁 | 甲子旬丁卯、甲戌旬丁丑、甲申旬丁亥、甲午旬丁酉、甲辰旬丁未、甲寅旬丁巳；**丁神所临之支为马** | 摇动、身不由己之动、官非惊怪；**金日逢丁凶祸动，水日逢丁财动（婚动）**；丁神入宅人宅俱动；求稳之事逢丁 = 风雨飘摇（步骤 5 凶断扫描项） |

| **响动（旬庚）** | 庚 | 甲子旬庚午、甲戌旬庚辰、甲申旬庚寅、甲午旬庚子、甲辰旬庚戌、甲寅旬庚申 | 能发声音、雷响动之事；官病忌；天时占乙庚合化金主雨雪 |
| **盗神（旬乙）** | 乙 | 甲子旬乙丑、甲戌旬乙亥、甲申旬乙酉、甲午旬乙未、甲辰旬乙巳、甲寅旬乙卯 | 主盗贼；失物占看乙神 |
| **五亡（旬辛）** | 辛 | 甲子旬辛未、甲戌旬辛巳、甲申旬辛卯、甲午旬辛丑、甲辰旬辛亥、甲寅旬辛酉 | 五亡七煞出行逢盗；并空亡主走失 |
| **旬空** | — | 每旬配剩二支（见上表） | 吉凶皆虚、事应期未到；**应期看填空**；凶煞逢空为喜、吉神逢空为惧 |

> 注意：
> - **丁马 ≠ 天马**：丁马是"旬丁"（按**日干**所在旬查），**不是天马**（天马正月起午顺六阳位，属月份起例，见 [daliuren-shensha.md](<daliuren-shensha.md>)）。
> - **闭口有两般**（① 旬尾加旬首 ② 旬首上神乘玄武发用），断时应**两般并看**。
> - 原始字段是读取起点，关键起法与落点仍核；与所选来源冲突标待核，不私改原盘。岁/月小耗等异法见 [S08](<shensha-focus.md>)。
