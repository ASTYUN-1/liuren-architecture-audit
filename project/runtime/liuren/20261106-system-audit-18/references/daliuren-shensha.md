## 神煞运用总则（2026-10-22）

实际取用以 [神煞取用](<shensha-use.md>)、[八煞九宝综合核查](<bashajiubao.md>) 和 [用户常用项目](<shensha-focus.md>) 为准。八煞九宝包括关系与状态，不局限于普通神煞；指定32项逐项核到，按占类深化。主要看神将状态、生克制救，神煞辅助补象；必查不等于全用或全部写入报告。旧分级不再决定是否漏查。

同一支兼多标签保留各自职责和有条件的类聚意义，不按名称投票，也不为去重拆散有效组合；不设“三煞无疑”。不相干的名目不能推翻有效主线；若改变关键条件须重评主判。天将、旬空、六亲与一般神煞分层，不因统称“煞”混为同一类。

---

解释星名时读 [常用神煞释义](<shensha-meanings.md>)，不把起法表当作完整释义。刃类取用以阳刃为重要项目，羊刃次之；二者象义相近，但起法与落点分别核对，不能并列为同等重要或重复计证。

## 常用神煞起法公式（校验用）

> 本节为现存资料的起法参照，用于校验排盘产物与速查理解；异法须署基准，不能统称无分歧的标准。**程序输出保留原样并作为读取起点，关键神煞仍核起法、成立条件和坐标；冲突标待核，不由模型静默改盘**，本 skill 不自算天地盘/四课/三传/天将。
> 标注 **「待知识校验复核」** 的条目，请以权威古籍版本为准后使用。

### 贵人（天乙贵人）

**口诀：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎。**

- **昼夜分贵**：占昼用昼贵，占夜用夜贵（**卯昼酉夜**：正时卯时至酉时前为昼用昼贵，酉时至卯时前为夜用夜贵——**先定昼夜、再取对应之贵，勿混淆**）

| 日干 | 昼贵（阳贵） | 夜贵（阴贵） |
|:----:|:----:|:----:|
| 甲 | 未 | 丑 |
| 乙 | 申 | 子 |
| 丙 | 酉 | 亥 |
| 丁 | 亥 | 酉 |
| 戊 | 丑 | 未 |
| 己 | 子 | 申 |
| 庚 | 丑 | 未 |
| 辛 | 午 | 寅 |
| 壬 | 卯 | 巳 |
| 癸 | 巳 | 卯 |

> **帘幕贵人（易混点，必读）**：贵人分昼夜两贵，**帘幕贵人 = 与当前昼夜相反的贵人**——**夜时昼贵人为帘幕，昼时夜贵人为帘幕**（卯昼酉夜）；入夜身份互换。例：昼时 贵人=昼贵（辛=午）、帘幕=夜贵（辛=寅）；入夜则 贵人=寅、帘幕=午。帘幕主科甲文书（毕法"帘幕贵人高甲第"，临干为用）。
> **贵人起例须核口径**：上表及过去整理曾记录昼夜起例分歧，这不是本次对引擎的重新验算。以原始字段为读取起点，引用贵人/帘幕前核昼夜分界、所用起例、实际身份与坐标；与SF-18或其他所选来源不符则标待核，不能一律相信引擎，也不能凭静态表私改原盘。

- **顺逆布将**（通识）：贵人临地盘亥子丑寅卯辰则顺行，临巳午未申酉戌则逆行（具体以排盘引擎输出为准）。

### 禄神

**口诀：甲禄到寅乙到卯，丙戊在巳丁己午，庚禄在申辛在酉，壬禄在亥癸在子**（即十天干"临官"之位）。

### 驿马

**口诀：申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳**（三合局**长生**位的对冲）。

| 支三合局 | 驿马 |
|:--------:|:----:|
| 申子辰 | 寅 |
| 寅午戌 | 申 |
| 巳酉丑 | 亥 |
| 亥卯未 | 巳 |

### 旬空

**口诀：甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。**

规则：以日干支确定所属旬（甲子/甲戌/甲申/甲午/甲辰/甲寅），该旬十个地支中未排入的两个地支即为旬空。

### 丁马（旬丁/遁丁）

**口诀：甲子旬丁在卯，甲戌旬丁在丑，甲申旬丁在亥，甲午旬丁在酉，甲辰旬丁在未，甲寅旬丁在巳。**

规则：取日干所在旬中**遁干为"丁"**的地支，即旬丁/丁马。

### 闭口

**口诀：甲子旬癸在酉，甲戌旬癸在未，甲申旬癸在巳，甲午旬癸在卯，甲辰旬癸在丑，甲寅旬癸在亥。**

规则：闭口即**旬尾**——本旬中遁干为"癸"的地支（癸为天干之末，不能开口）。

### 破碎煞

**口诀：子午卯酉日破碎在巳；寅申巳亥日破碎在酉；辰戌丑未日破碎在丑。**

> 异说注记：《神煞赋》有"四仲金鸡四孟蛇"异文，与《六壬指南》相反；本表采《六壬指南》"四孟金鸡四仲蛇四季丑"（金神破碎鸡蛇牛）。

### 游都 / 鲁都

| 日干 | 游都 | 鲁都（游都六冲） |
|:----:|:----:|:----:|
| 甲 / 己 | 丑 | 未 |
| 乙 / 庚 | 子 | 午 |
| 丙 / 辛 | 寅 | 申 |
| 丁 / 壬 | 巳 | 亥 |
| 戊 / 癸 | 申 | 寅 |

**口诀：游都甲己丑、乙庚子、丙辛寅、丁壬巳、戊癸申；鲁都即游都之六冲。**

> 待知识校验复核：原文档仅载"甲丑乙子丙寅丁巳戊申"五日，己~癸按五合对称推得；请以权威版本校验后使用。

### 其他常用起法

- **天马**：正月午顺行六阳支（午→申→戌→子→寅→辰，七月复午）。
- **月德**：寅午戌月在丙，申子辰月在壬，亥卯未月在甲，巳酉丑月在庚。
- **天德**：正月丁、二月申、三月壬、四月辛、五月亥、六月甲、七月癸、八月寅、九月丙、十月乙、十一月巳、十二月庚。
- **天赦**：春戊寅、夏甲午、秋戊申、冬甲子。
- **华盖**：年支/日支三合局之**墓库**（申子辰→辰、寅午戌→戌、巳酉丑→丑、亥卯未→未）。
- **文昌**：甲巳、乙午、丙戊申、丁己酉、庚亥、辛子、壬寅、癸卯。

## ④ 遁干四煞（旬煞）

| 遁干 | 含义 | 用法提示 |
|:----:|------|----------|

## 神煞状态判断

| 状态 | 对神煞的影响 |
|------|-------------|
| **空亡** | 核哪个节点、何坐标和阶段受限；身、病、财、救神空的结果不能通断 |
| **旺相气** | 相关神将得气的线索，仍核临地、制约和作用对象；不保证应验 |
| **休囚气** | 一层得气不足，仍比较双方、党助、坐处与引动 |
| **死气** | 本行若指月令五气须明示，不与月煞死气/十二气死混用；强弱仍综合 |
| **坐墓** | 谁入谁墓、是否闭藏及能否冲开须另核，不直接取消所有作用 |
| **被克** | 比较施受双方与制约条件，有克不等于有效受制 |

**典型应用：**
- 驿马空亡：先核动意、发动、成行、到达哪一步受影响。
- 驿马旺而不空：仍须合绊、坐处及所求条件，不从标签直接承诺行动。
- 生气空：该项救应可能受限，回查患者、救神与其他结构，不单项断不保。
- 劫煞空：不直接保平安，另核有效风险与制救。
- 白虎：天将本气与所乘神分论，旺休只是状态一层，须看本问身份及实际作用。
