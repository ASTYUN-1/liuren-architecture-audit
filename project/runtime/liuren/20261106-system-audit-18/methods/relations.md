# 固定课位，落实日辰与对象关系

## 干支角色与四课坐标不可互换

先执行positioning的事件角色，再解释四课。第一课为日干上神，第二课为干上神的上神（干阴）；第三课为日支上神，第四课为支上神的上神（支阴），具体坐标以程序facts为准。干二课/支二课是两组关系层，不是求测人、父母、孩子、学校四个人的席位；不因代问人数重排，不把第一课下神改成代问者的本命。

日干的寄宫、干上神和日干本身分列。六亲仍以占日干计算；“子孙”可为作用义，不因代问者有晚辈便把子孙自动等同考生。日支取病证/学校/宅/相对方时须有本题专项依据，不能把同一论证中的支随意改成代问者或别的对象。改定位须撤销并重核受影响作用、制救和应期。


## 关键类神进入全局关系

坐标核清后，把分类关键类神同时放入四课三传的理气关系中。对每个关键类神，核与日干支、干上支上及相关四课、三传节点的作用，并核关键类神彼此的生克扶损、合刑冲害、空墓与制救。注明施受双方、力量、通路及影响的结果环节；不机械穷举无关关系。主体、目标、阻碍和救应按本问实际需要确定，不强行增补角色。关系矩阵是全局理气的输入，不能只用来贴人物与物品标签。

完整研判须覆盖本文件的坐标与相关对象关系；同轮已核坐标和作用链直接复用，不为模块边界再重判。旺衰制救依理气模块，阴神深化依动态模块，结构构成依课体模块。

## 数据与坐标

1. 使用可靠程序 facts；缺盘按排盘手册取课，不能由模型推算天地盘、四课三传或静默改盘。原始导出、题干、课义/断曰/毕法解释、以后反馈分层。相关断语须核字段与成立条件，不锚定“病苏/必死”等答案。无可靠关键盘式暂停；局部可选缺项只限制相关方法。
2. 列四柱、占时、月将、原局旬空、四课上下与乘将、三传。天盘支、所临地盘、所乘天将、该节点上神/直接阴神分别列；日寄宫地盘、寄宫上神、日上神不可混同。天空天将与旬空不是同一字段。
3. 关键节点说明六亲相对谁。默认六亲相对本课日干计算；采用其他参照须单列，不能计算中不变参照、解释中却变了主体。命支出现、某神临命宫、命宫上神是不同位置。

## 关系检查矩阵

| 位置/关系 | 对本问须回答 |
|---|---|
| 日干与日支 | 各代表谁或何事？本人/事物/环境之间怎样生克脱耗、刑冲合害？ |
| 干上与支上 | 分别如何影响所定位的主体与客体？两上神之间相生、相克、相害的作用是什么？ |
| 四课及直接阴神 | 干阳干阴、支阳支阴如何扶损本对象？不能以“没入三传”一概剔除，也不能把任一象的出现当实现 |
| 发用与日干、日支 | 事情发端是什么？与本问主体、宅/事的害、冲、刑及其他关系是否成立？ |
| 三传与类神 | 依专项分别看阶段、转移、归宿或指定角色，核每传空墓和作用；不固定等成过去现在未来 |
| 类神全位置 | 天地盘、将、六亲、叠加神煞、状态及相关上下，是否真的涉及对象？ |
| 占时先锋 | 提供何种端倪，是否与明确事件相关？不能无条件否决全部其他关系 |
| 年命与所临 | 已核人物的年命对关键节点有何实际引动？未知不能填作确定救应 |

必列干上、支上、三传的六亲序列与参照。例如考试“财财父”若涉及传财破印，应判断所伤是否确为资格及力量是否成立，不把历史例自动当全部考试规则。末传生干还须核其乘将、临地和阴神；禄空/墓先问本题禄代表能力、待遇还是生命之源。

对象与位置须进入判断：支取车库，就说明某神是否临及车库及相关上下，对“进水/损坏”的作用；不能以整体水势或“不成大灾”替代。阴神扶某病象，未必益患者；某神生干是在生哪个已定位的人，不能临时移给另一六亲类神。

## 时间与展开边界

三传全局、日上当前近事是一种有来源的时间层读法，使用时分别标明，不机械把每课三传解释成一生。类神三传与通常三传分列；有明确来源和本问需要才展开，不拿任意下一传当阴神。

直接阴神从本节点的明确坐标取一层；新增层须解决具体未决关系，重复节点或无新增信息即停。原局、流月流日引动、另起课分层；未来换旬不重写本课旬空、天将、四课三传。

完成标准：定位后的关系矩阵，决定结果和最强反证的真实字段、参与双方和作用方向；无关项说明范围，未核项标待核，不能把“未看见”写成“没有”。


确定性工作与交接按[程序事实接口](../references/deterministic-tools.md)执行。位置/阴神/查表/算式由程序给出，关系效力仍核原法；应期与数量任务保留完整专法记录，正文不得被简短结论替代。
