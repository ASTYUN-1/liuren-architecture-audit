# 神煞组合义补充

固定起法、别名、采用状态和坐标直接用程序结果；本页仅保留旧参考独有的组合候选。普通32项及其他单项义见shensha-use、shensha-meanings、shensha-other-meanings。历史公式和星级已退出执行，原文件留在冻结基线。

组合只在本问、成员位置、气态及制救条件齐备时参与，不把几个名相加当作已发生事件；未采用成员不凑组合。

## 神煞叠加速查

| 叠加组合 | 条件性线索与后续核查 |
|----------|----------|
| **丧门+吊客**上课传 | 死丧之事，需注意 |
| **破碎煞+脱气+空亡** | 财物损耗候选，核谁脱谁、谁空及得财/支出两面，不直接定损额或必破财 |
| **驿马+空亡** | 动象可能受限，核空的对象、阶段与引动；不能保证绝不动 |
| **驿马+不空+旺相** | 动力线索较实，仍核合绊、坐处、对象及成行/到达条件，不保证必动 |
| **墓+死气+白虎** | 病占风险组合；须辨墓谁、死气哪层、虎的状态及有效救制，不能组合即死 |
| **墓+空亡（墓空待人）** | 先核具体成格及患者/年命坐标，结合神将与救制；不因两个字同见就定生死 |
| **皇恩+天赦**临干支 | 讼狱有赦免之机 |
| **丑未相加（魁星格）** | 核临日干/年命等所用条件、空墓与文书考官作用，不单独保证中第 |
| **丁马（旬丁/遁丁）+驿马+天马**三马并见 | 多方动意、快速变动 |
| **生气+胎神** | 孕育线索，核母胎对象、阶段、取用与反证，不单项证明已孕 |
| **劫煞+玄武+鬼克日** | 贼盗风险候选，须核对象、克力和通路，不由三个标签认已遭劫 |
| **劫煞+吉将+日合** | 急速成合候选，核本问、合绊及神将作用，不保证必成 |
