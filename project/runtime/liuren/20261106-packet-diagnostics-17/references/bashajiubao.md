# 八煞九宝：德合禄、生旺与刑害等综合核查

本项用于完整断课的主流程，不局限于神煞表。它同时涉及关系、气地状态、课传结构及附着信息；不能只在程序的神煞字段里搜索几个名称就算完成。用户所说“生气”还须辨是生扶、长生/生旺，还是特定月煞生气，三者分别核查。

## 书中具体口径与检查范围

《六壬拃河棹》明列九宝为**德、合、奇、仪、禄、马、生、旺、贵**，八煞为**刑、冲、破、害、墓、鬼、废、空**。这是本次查得的具体文献口径，不据此宣称所有书或用户的传承只许这一名单。原书“干星”说明十干长生为天地生气；“干旺”另论五行自旺，不能把“生、旺”统改成月煞生气。依据 [来源卡](<shensha-sources.md>) SF-08～10。

《壬归》“八杀”章则论**德、合、鬼、墓、破、害、刑、冲**，并详德化为鬼、灭德和临陷制化。它与上一清单不是同一组，不将“德、合也叫杀”误读为德合必凶，也不以书名相同就合并成新的八项。依据SF-06。

完整断课覆盖上述有据关系，并补一般生扶、脱耗和月煞生气；与理气、类神、32项核查重合者复用同一分析，不另跑一次断课。具体太岁、帘幕等见 [常用项目](<shensha-focus.md>)。未成立、无关和资料待核如实区分，不用猜测填“无”。

## 九宝逐项核查

| 项目 | 核查内容 | 判断边界 |
|---|---|---|
| 德 | 分清日德、支德及所用天/月德，定位于谁、何宫；查旺衰、空墓、刑害及是否化鬼 | 德名不保证救解；《壬归》有灭德、德化为鬼。德的关系成立与实际得救分判 |
| 合 | 干合、支六合、三合及有关结构分别核参与对象和位置 | 联系、成合或牵绊须按本问定；合不自动化，救神被合与病鬼被合不能同断 |
| 奇 | 区分旬奇、日/干奇、三奇结构，不因出现一个奇支就认三奇课 | 核完整成格条件、占类与状态；《笔记》三奇还有乌龙奇怪事的解释，不承诺百祸消散 |
| 仪 | 旬仪取六甲旬首之支；支仪、干仪若用则另列口径 | 旬仪节点与六仪课不是同一判断；得仪不直接保证康复、获释或中第 |
| 禄 | 日禄所在支、谁得禄、与财官及日干年命的关系 | 食禄、待遇、养身等按目标取义；不得因禄出现就认已经到手或一生稳定 |
| 马 | 驿马、天马、丁马各按自身基准核；所用年/月/命马另署来源 | 动机、发动、出发、到达、调任成功分开；旺不空也不能省略合绊、坐处和本问条件 |
| 生 | 明确生扶的施受双方；长生以谁为本、临何地；月煞生气另列 | 生可扶身也可扶病鬼；长生不直接证明活命。月煞生气不能取代生扶/长生分析，反之亦然 |
| 旺 | 神与将分论月令五气，按现行口径核临地十二气，说明参照对象 | 病鬼旺与救神旺所利不同；旺相不自动有利，也不把月令、临地、六亲混为一个量 |
| 贵 | 天乙及帘幕分身份，核乘神、坐处、空墓、阴神及与本人的实际作用 | 贵可能助力，也可能职责驱策或其他人象；仅有贵名不保证援助或考试成功 |

## 八煞逐项核查

| 项目 | 核查内容 | 判断边界 |
|---|---|---|
| 刑 | 哪两/三字、何方向、作用于本人、类神或所忧之神 | 刑名不直接给灾级；核双方力量、位置和本问作用 |
| 冲 | 冲谁、从何处冲，有无有效冲动/冲散条件 | 冲身、冲救、冲病、冲墓结果不同；不一律凶或一律解 |
| 破 | 支破、月破、岁破与破碎煞分别核基准 | 破不只指坏结果，解散旧约与谋求成合的喜忌不同；用户已确认本项为月破，不与日破碎合并 |
| 害 | 相害的具体双方、气势与对象；是否伤类或伤救 | 不只报“有害”，也不由一害直接定人品、伤病或死亡 |
| 墓 | 谁的墓、天盘/坐处何层、墓神状态及冲开/合闭条件 | 墓病、墓身、墓鬼或墓救分开；不以同一个墓字抵消所有关系 |
| 鬼 | 相对谁为鬼，明神、遁干或阴神哪层；能否克及能否得救 | 官鬼含义随占类；有鬼须查身、鬼、救三方力量及通路。未知遁干不自造暗鬼 |
| 废 | 分辨实际的无气、休囚、败、绝、死、脱等状态和关系 | 原文列“废”但邻文分说败脱绝死，未给单一“废煞”起法；不可凭字造一颗新煞，脱鬼可救身，绝旧事未必不利 |
| 空 | 空的对象、坐标、旬及原局/应期层；查相关填冲合等条件 | 身空、病空、财禄救神空不可同断；未到时与不存在也不能混用 |

每项查到日干支、四课三传、关键类神、已核年命及其上神/直接阴神中的相关关系；太岁、月建、正时等在本问已有定位时一并参看。盘面散见的重点不因未入三传被删掉；也不把无关宫位无限扩成新人新事。未知年命不得伪造补齐，纯起课或无判断目标的资料查询无需强行跑完整断课。

## 先看神将状态，再说明附着信息的作用

按 [理气规则](<../methods/liqi.md>) 先明确神、将、坐处、月令、上神/阴神、施受双方及制救；八煞九宝中的生克刑合旺衰本就是这层分析，不能被归为“神煞仅辅助”而略去。普通神煞是在此基础上补事件、人物、阶段和克应。书中的辅助定位见SF-01、05、07，出行制鬼的具体条件例见SF-23。

检查完成后，采用、受限、未成立、待核、与本问无关分别标记。判断摘要只呈现改变本问结果、过程、程度或应期的项目及关键缺口；保留简短检查记录供复核，不强迫把十七项和所有神煞抄入用户报告。不能以名称数量投票、固定凶煞数翻判，亦不能以“辅助”封死有效反证；若揭示关键状态或制救变化，返回主线重评。

“单见某吉项不足定吉”仍保留吉的可能；“单见某凶项不足定凶”也保留凶的可能。依据不足时留未定，而不是强行反断，详见 [规则语义](<rule-semantics.md>)。
