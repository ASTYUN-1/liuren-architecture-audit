# 大六壬毕法速查（《毕法赋》结构化）

> **毕法赋**：宋·**凌福之**据邵彦和《断案》课例总结的一百条七言判断法则，收于《六壬大全》，分上下两卷（上卷 1–50 法、下卷 51–100 法）。每法 = 一句七言赋文 + 补充说明 + 正格 + 变格 + 类格 + 特例。
>
> 本文件为**速查骨架**：按主题分九组（A–I），每条给出格名（七言原文）与一句话断法。各组格目以 P0 知识校验报告第四节为准；未覆盖处按标准通识补断语，**不自行发明**。
>
> 本表用于定位需核的课传结构。课体、毕法、类神及制救在共同主线裁决；不是先把九宗门吉凶锁死，再把相反的有效作用永久压为次要。具体采用回读本法完整原文，不能以速查强语代替条件。

## 使用总则

- 排盘自带毕法标注及本表先作候选定位，核实际构成、对象、位置、气态与制救后再采用；标签命中不自动成为本课关键结构。内置断语不是本问结论。
- 每条格局须结合**位**读：干上 vs 支上、发用 vs 末传、四课 vs 三传，力度不同（"壬占最重位"）。
- 与步骤 7 三层读法衔接：第一层九宗门大势（[keti-quanbiao.md](<keti-quanbiao.md>)）→ **本表第二层定关键** → 第三层位次定力度。
- 毕法与课体冲突时，按共同理气和裁决规则核支持、最强反证及作用范围；有效条件改变可以重裁决，不能靠固定“只微调”保住原先结论。

## A. 干支（日辰/人宅）关系类

> **使用场景/位置**：看四课**干支上神**——干上神 = 我/人（日辰主客我方），支上神 = 宅/事/对方。比较干支上神的生克、合害、互传、脱耗、乘墓乘绝乘败，定人宅与宾主关系。这是步骤 7 第二层最先读的结构（对应排盘"四课"）。

- **A1. 交车相合交关利**：干支上下神交合，利合作、交易、合谋之事
- **A2. 彼求我事支传干 / 我求彼事干传支**：初传自支传干 = 彼求我，初传自干传支 = 我求彼，定求者方向
- **A3. 富贵干支逢禄马**：干上支马、支上干禄为真富贵；禄马并临主财官两得
- **A4. 彼此全伤防两损**：干支上神互克干支，两边俱损
- **A5. 夫妇芜淫各有私**：干支上神互乘淫合之将，夫妇各怀私情
- **A6. 干支值绝凡谋决**：干支乘绝神，凡事至绝处须决断
- **A7. 干支皆败事倾颓**：干支上神皆乘败气，事必倾颓
- **A8. 干墓并关人宅废 / 支坟财并旅程稽**：干乘墓又有关煞主宅废；支乘墓又见财主旅程稽留
- **A9. 人宅受脱俱招盗**：干支上神皆脱干支（泄气），防窃盗
- **A10. 互生俱生凡事益**：干支上神互生，凡事有益
- **A11. 宾主不投刑在上**：干支上神相刑，宾主不投合
- **A12. 眷属丰盈居狭宅**：干旺支衰，眷属丰盈而居宅狭小

## B. 三传结构类

> **使用场景/位置**：看**三传**干支生克链条（传生 / 传克 / 传财 / 传鬼）、初末是否夹拱干支、三传是否入课、三传动静。初中末可按本问及原法表达进程，但不在所有占类、角色序列或应期中固定为始/过程/结局。

- **B1. 首尾相见始终宜**：初末传夹拱干支，事有始有终
- **B2. 三传递生人举荐**：三传递相生，得人举荐
- **B3. 三传互克众人欺**：三传互克，被众人欺
- **B4. 传财化鬼财休觅**：三传皆财生干上鬼，取财反致祸
- **B5. 传鬼化财钱险危**：三传皆鬼而末传化财，得钱险危
- **B6. 末助初兮三等论**：末传助初传，分吉助 / 凶助 / 平助三等
- **B7. 初遭夹克不由己**：初传被夹克，身不由己
- **B8. 万事喜忻三六合 / 合中犯杀蜜中砒**：三六合主喜；合中犯煞则蜜中藏砒
- **B9. 传墓入墓分憎爱**：三传逢墓 / 入墓，须分所憎所爱（吉入墓为憎、凶入墓为爱）
- **B10. 不行传者考初时**：三传不动，考初传定应期
- **B11. 六爻现卦防其克**：课传演成六爻卦象，防卦爻相克之事

## C. 空亡/墓库类

> **使用场景/位置**：配合**步骤 4 看显象**（空亡二重鉴别）——干支上神与三传逢空逢墓读虚化与困守；所空对象和原法分歧按void核对，凶神将空的例外、生扶和填实分路保留；不一律待填或认虚惊。

- **C1. 空上乘空事莫追**：空亡之上又乘空，事不可追
- **C2. 进茹空亡宜退步**：进茹课逢空亡，宜退步
- **C3. 踏脚空亡进用宜**：踏脚空亡（初传空而中传实），进用反宜
- **C4. 喜惧空亡乃妙机**：吉神空亡为惧、凶神空亡为喜，全课枢机
- **C5. 旬内空亡逐类推**：旬内空亡，逐类推详
- **C6. 避难逃生须弃旧**：有难须弃旧图新、另寻生路
- **C7. 朽木难雕别作为**：干上神衰朽，难以雕琢，宜另作打算
- **C8. 华盖覆日人昏晦 / 太阳射宅屋光辉**：华盖（三合墓库）加日干主昏晦；太阳（月将）加支主宅光辉
- **C9. 干乘墓虎无占病 / 支乘墓虎有伏尸**：干乘墓 + 白虎勿占病（病危）；支乘墓 + 白虎主有伏尸之象

## D. 禄马类

> **使用场景/位置**：看**禄神、驿马、丁马、三奇**在三传与干支上神的落点（配合 [daliuren-shensha.md](<daliuren-shensha.md>) 一级神煞：禄神/驿马/丁马每课必查）。定事业、财运、动象。

- **D1. 旺禄临身徒妄作**：干上旺禄，守之即是，妄作无益
- **D2. 权摄不正禄临支**：禄临支上，权柄受制
- **D3. 尊崇传内遇三奇**：日奇/旬奇/联珠结构分开核，旬奇六旬映射及异文见 [S26](<shensha-focus.md>)；尊崇是原法取义，仍核本问与神将状态，不单项保证吉
- **D4. 任信丁马须言动**：伏吟遇丁马提示发动，核旬丁真位、相关对象和空墓合绊；动意、发动、成行及达成分判，见 [S05](<shensha-focus.md>)

## E. 贵人与天将类

> **使用场景/位置**：看**贵人**所加位置（昼夜贵、顺逆布）与日辰关系、贵人状态（受克/空亡/入狱/差迭），以及**白虎、玄武**等凶将乘鬼之象（配合步骤 3 断课三看之"类神定人事"、步骤 5 凶煞过滤）。天将布列以排盘引擎为准。

- **E1. 帘幕贵人高甲第**：帘幕贵人 = 与当前昼夜相反的贵人（**夜时昼贵人为帘幕、昼时夜贵人为帘幕**，卯昼酉夜，身份随昼夜互换），临干主科甲高中（详见 [daliuren-shensha.md](<daliuren-shensha.md>) 贵人节，贵人/帘幕从完整盘面读取，并核本盘昼夜分界、起例与坐标；摘要不证明起法正确）
- **E2. 催官使者赴官期**：虎乘日鬼为催官使者，主催官上任之期
- **E3. 害贵讼直作曲断**：贵神被害，讼直反作曲断（有理反被无理断）
- **E4. 课传俱贵转无依**：课传皆见贵人，贵多反无依
- **E5. 昼夜贵加求两贵**：昼夜贵并加，可求两处贵人
- **E6. 贵人差迭事参差**：贵人差迭（颠倒），事参差
- **E7. 贵虽在狱宜临干**：贵临辰戌入狱，但临干则不忌
- **E8. 鬼乘天乙乃神祗**：鬼乘天乙（贵人为鬼），主神祗之事
- **E9. 两贵受克难干贵**：两贵受克，难以求贵
- **E10. 二贵皆空虚喜期**：贵人都空亡，喜期落空
- **E11. 太阳照武宜擒贼**：太阳（月将）照玄武，宜擒贼
- **E12. 后合占婚岂用媒**：天后 + 六合入传，占婚不需媒人
- **E13. 虎临干鬼凶速速 / 龙加生气吉迟迟**：虎临干鬼凶来得速；龙加生气吉来得迟
- **E14. 虎乘遁鬼殃非浅**：白虎乘遁干为鬼，殃祸非浅
- **E15. 将逢内战所谋危**：按relations/liqi中所选原法分别核地盘、天盘神、天将与作用方向；旧“将临相克地盘”不足以代表全部内战链，条件未齐不能径用所谋危。

## F. 遁干（旬遁）类

> **使用场景/位置**：结合**旬遁**读遁干六亲（配合 [daliuren-shensha.md](<daliuren-shensha.md>) 遁干四煞：丁/癸/庚/甲）。丁马主摇动、闭口主不言、响动主发声——以遁干与日干六亲关系读象。

- **F1. 金日逢丁凶祸动 / 水日逢丁财动之**：金日逢丁（丁马）凶祸动；水日逢丁主财动
- **F2. 虎乘遁鬼殃非浅**：遁干为鬼又乘白虎，殃祸非浅（与 E14 同法，遁干侧读象）
- **F3. 任信丁马须言动**：与D4同一法，旬丁位置、空墓合绊及动意/发动/成行/达成分判；不因重复列出而增一份证据。

## G. 课体/格局类

> **使用场景/位置**：看**天地盘特殊盘式与加临格局**（六阳六阴、闭口、魁罡加临、天网、罗网）。定整体格局吉凶大方向（配合步骤 7 第一层课体大势与 [keti-quanbiao.md](<keti-quanbiao.md>) 特殊课体表）。

- **G1. 六阳数足须公用**：六阳位传齐全，公事可用（利公不利私）
- **G2. 六阴相继尽昏迷**：六阴传，尽昏迷不明
- **G3. 闭口卦体两般推**：旧“旬首乘玄空”摘要含糊，不能直接当定义；按kundun及原毕法全文核两般、位置和发用条件，旬癸标签与闭口课不互代。
- **G4. 魁度天门关隔定**：戌加亥（魁度天门），关隔定
- **G5. 罡塞鬼户任谋为**：辰加寅（罡塞鬼户），任谋为
- **G6. 所谋多拙逢网罗 / 天网自裹己招非**：天网凶课，自招是非
- **G7. 前后逼迫难进退**：三传前后逼迫，进退两难

## H. 疾病/灾祸类

> **使用场景/位置**：专用于**健康占 / 官讼占**（原"灾厄占"并入健康占；配合步骤 2 占类命名与步骤 5 凶煞过滤）——胎财、虎鬼、病符、丧吊、鬼临三四为病讼灾祸核心信号。

- **H1. 胎财生气妻怀孕 / 胎财死气损胎推**：胎财 + 生气主妻怀孕；胎财 + 死气主损胎
- **H2. 受虎克神为病症 / 制鬼之位乃良医**：受虎克之神为病症所在；制鬼之位为医治之方
- **H3. 病符克宅全家患**：病符克支，全家患病
- **H4. 丧吊全逢挂缟衣**：丧门吊客全逢，主丧服
- **H5. 鬼临三四讼灾随**：旧摘要把“三四”展开为“三传四课”未在本批回源核清，暂不按此泛化；采用前查原毕法所指课位、对象和制救，不能将任意鬼入传认作讼灾。
- **H6. 费有余而得不足**：费多而得少，入不敷出

## I. 断法/方法论类

> **使用场景/位置**：断课纪律层——贯穿全流程（配合步骤 2 来意占"非占现类勿言之"、步骤 10 组织断语）。防妄用三传、防越占、防常课误断。

- **I1. 妄用三传灾福异**：三传不可妄用，须辨真伪（同一三传不同用法吉凶迥异）
- **I2. 所筮不入仍凭类 / 非占现类勿言之**：所占不入课传仍凭类神；非所占之现类勿言（不越占）
- **I3. 常问不应逢吉象 / 已灾凶逃返无疑**：常事问而逢吉象为不应（反常）；已受灾而见凶逃返无疑
