# 旺衰、数量与旬空：51版接口

月令五气用于原法分支；strength含空分数用于状态分析；quantity_basis.without_void用于实验数量校正。它们来自同一组盘面事实而用途不同，不能互相冒充，也不能把单宫分数当综合作用链。

## 真实无空重算

strength请求和原来一致，不接受调用者手填指数或系数。程序同时保留原含空结果，并用相同对象、月令表和已选关系，移除所有数值旬空/坐空衰减后重新计算，输出quantity_basis。源和目标一起重算，保留墓和生克，原空位事实不修改。取用、跨宫关系是否有效仍按原法判断；不是自动全盘联算或全面制救评分，合局数值继续暂缓。

quantity_basis.rows每项有id、seasonal、with_void、without_void、void_self/void_ground/void_carrier，以及body_base、tomb_access、local_net、outward_restriction。含空和无空各有自身作用范围；local_net等说明原含空单宫依据，不冒称无空全局分解。模型baseline_reference=5只是程序基准，calibration=research-unvalidated。

## 数量怎么使用

source路径已按旺衰选乘/加/半时，不再用该分数打一次折。experimental路径以尚未纳入气态及空减的expression本数，按真实without_void的固定实验函数修正，必要时再独立一次数量空半。选择顺序、参数、量级及接口完整条件见quantity-correction。其他原法的倍进保留方法身份，不强迫套本项目函数。

以固定本数56为例，E=5且主类空、采用项目数量半数时是28；E=1且独立弱气与空半各用一次时是14。这只说明项目参数的算术，不是现实预测。若源法休气9+8=17，17已经用过季节旺衰，不能接着乘实验弱气系数；另半与否必须说明原法或项目研究身份。

旬空减半不是所有书所有数法的统一条文。北海所录35空半17旧例只证明有这种用法，且舍入未明；不能因此强制各源法叠半。相反，状态分数含空也不能证明数量本身已做空减。51版通过重新分离输入，消除这个混淆。

## 不由数字自动决定的内容

身财平衡、施受能力、分类类神、成败、作用是否到达、强旺为何指多、十百千量级等仍需解释。财旺可表示货物或竞买者多，不能一概映射个人所得。满分只作范围约束，不能把指数直接换成分数；序数/日期/编号不乘实验系数或空半。取数先固定所求数量和类神，不因某一数字接近反馈而换类或选法。

现有五气、十二气、生克、墓和空亡保留系数均不改变；新增的是无空重算视图、数量实验函数及回执约束，不声称原旺衰研究模型已经完成预测校准。
