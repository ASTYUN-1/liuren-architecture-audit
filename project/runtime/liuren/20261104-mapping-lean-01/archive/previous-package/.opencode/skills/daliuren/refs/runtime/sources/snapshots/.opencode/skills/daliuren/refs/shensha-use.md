# 神煞取用：必查不漏，神将状态为主

神煞使用优先参考喜爱六壬的水《献给六壬天一群的六壬笔记-2023年》，以《壬归》核气地、生克和制化；未详项目再用本地专项资料。本次用户指定的常用项目也是必查范围，《笔记》作者没有列到，不等于可以漏掉。新增出处见 [来源卡](shensha-sources.md)，此前理气出处仍见 [原依据](liqi-sources.md)。

## 两层必查，不按星名数量裁决

1. 完整断课先按 [八煞九宝综合核查](bashajiubao.md) 看德合禄、生旺、刑冲破害、鬼墓空等。它们包括实际关系和状态，不局限于一般神煞。用月煞生气替代所有“生”的分析，或以“神煞只是添头”跳过德合生旺，均未完成检查。
2. 再按 [用户常用项目清单](shensha-focus.md) 逐项核到盘面。基础检视包括其相关落点；涉及占类的重点项须深化。可复用同一节点的既有分析，但不能只看三传，或见《笔记》未列便跳过。纯资料查询按其目标处理，无需强行断课。

“必查”是核起法、落点、成立与相关性，不等于每项都有效、都需深入叙事或都要写进最终报告。缺字段/异法未裁决标待核；已核未成立与尚未核清分开，不能写成“无”。完整断课保留简短核查记录；用户报告只交代真正影响本问的项目与重要缺口。

## 神煞释义与刃类取舍

需要解释某神煞、或不确定如何随占类取义时，读取 [常用神煞释义](shensha-meanings.md)，把基本象义、应用归纳与出处缺口分开；不要只会查支位或只列禁断。刃类取用以阳刃为重要项目，羊刃次之；二者象义相近，但起法与落点分别核对，不能并列为同等重要或重复计证。相近象义可参照，各自命中仍按各自起法记录。

其余常用项目查 [补充释义](shensha-other-meanings.md)，引擎原名查 [名称索引](shensha-engine-index.md)。资料只有起法或近名未对应时保留缺口；《神煞全解》本地按LF分行的六壬段主要在L9–68，L75起转入八字，不能直接移用后段命理释义。旧skill的历史行号另有分行口径，保留原标注，当前按段落内容核。

## 判断顺序和准入条件

1. **先定神将状态**：明确人物/事件、类神及日干支年命坐标；分列天盘神、天将本气与所临地盘，核月令五气、临地十二气、生克脱耗、上神/直接阴神及刑害空墓。按 [理气规则](liqi-analysis.md) 比较作用双方，定救谁、制谁、能否得力，不先用吉凶煞名定结局。
2. **核名称与成立**：按 [引擎神煞字段核查](engine-shensha-output.md) 读取完整12宫，不只看keyShensha摘要；阳刃、羊刃按 [两刃排法](blade-methods.md) 分列。先区分已输出、所选起法成立、实际有效三层；病符/吊客/天地医已核差异不得隐藏。读取程序原始字段，再核起法基准、历法月序、季节、日干支及条件。参考位标不等于已成立，schema正确不等于起法正确。引擎与书、书与书有冲突时保留各自口径，相关结论作条件分析；不静默改盘。旬空、十二天将、六亲和附着神煞分别说明身份。
3. **按占类判作用**：同一神煞可补不同事象，也可能与本问无关。说明它对应哪个人、何阶段及结果/过程/程度/应期哪一维。天医伤日不能凭医名保康复；皇书不能未经依据作救命；丧吊并见也不足以定死。天喜等作用还须得气得地，不能只有喜名。
4. **合并并复核**：同支兼德禄、几颗马或几个近名死煞不按标签数增信。神煞是添头和辅助，主要仍凭神将状态及实际作用。若核查揭示了新的关键状态、作用对象或有效制救，须回主线重判；不能仅凭一个吉名推翻主判，也不能以“只辅助”为由拒收有效反证。

## 占类侧重

常用清单按占类给出了深化重点，属于检视安排，不是未经验证的固定权重/评分或排他名单。病占重病人、病神与救神三方，医煞、病符、生死气、丧车、二血/刃等只在有关位置与作用下参与；胎产须分保胎、发动、出血、方式、完成和母胎安危。考试求职看实际考官/岗位/文书及德禄贵、文星、闭口、成神等；婚恋看双方、成合和关系阶段，孤寡、桃花、天喜不能越过这些条件。

出行调动查各马及成行、到达和沿途风险；财物查得财与损耗的实际链；家宅年运把太岁与年命基准定位清楚。切题的其他项目仍可补入，不因表内未列而永久作废。详细表见 [常用项目](shensha-focus.md)。

## 完整语义与维护

“天医不能单独保证康复”仍保留康复；“丧吊不能单独定死”仍保留死亡风险。“未见某煞”不证明相反结果，“该煞待核”也不证明整盘吉凶。按 [规则语义](rule-semantics.md) 写清占类、对象/位置、阶段、前提与断言强度，不能把不充分条件写成反向排除。

来源中的强语保留历史身份，不升成无条件执行分支。原始排盘、书籍、R原文、A1原例、案例与经验原件继续保留；本规范约束取用，不执行排盘JSON过滤。发现疑似错字或算错，说明缺陷和受影响推断，缺口保持未知。
