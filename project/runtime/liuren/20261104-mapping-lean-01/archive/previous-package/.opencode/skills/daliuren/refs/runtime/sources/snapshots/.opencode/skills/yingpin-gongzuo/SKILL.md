## R — 原文 (Reading)

> 薪水的代表是禄神，而生活来源的代表是父母爻，而长生爻也代表安身立命。所以，禄、父母、长生都是职位类神。职位类神现于课传，而吉旺，不空陷，则职位必得，应聘必成。……课传中生合吉旺、龙常贵合等吉象并聚，虽类神不现，亦可以成就论之。
>
> — 北海闲人, 第八讲《应聘与工作状况》

## I — 方法论骨架 (Interpretation)

> 2026-10-19执行口径：下列原有方法保留出处；应用时按 E 节核对本问、位置、状态和最强反证，不能将单项命中或作者“必”字作为提前结案。

面对的问题是"能否得到某个职位/工作"（应聘、投考、跳槽、等待录用）。判断分四条线，按序执行：

1. **取职位类神**：禄神=薪水，父母爻=生活来源，长生爻=安身立命，三者都代表"职位"。先扫课传（干上、支上、三传、年命上）找三者。
2. **判必得**：类神现于课传 + 旺相（月建/进气）+ 不空陷 + 不变质 ⇒ 职位必得、应聘必成。
3. **补救路线**：仅凭类神不现不足以判失败，也不自动支持成功；若另有吉象并聚等方法依据，须核本问位置、力量、成事通路与反证后再裁决。原资料所列生合吉旺、官局、贵人等为有条件候选，不是任一命中便成就。
4. **快速细则**：禄神发用 + 合干上 + 所占之爻进气 ⇒ 虽乘玄武（取巧/走关系）亦必成且速；课名返吟则反复进退、数次方成。空亡非死刑：旺不为空、得生得助不为空（如长生落空但作月将/太岁仍得）。

产出：必得 / 可成（带速度与渠道特征）/ 不成 / 不确定（需结合他象）四级结论 + 依据链。

## A1 — 书中的应用 (Past Application)

### 案例 1: 欲另谋公司高就能否进入（c25）
- **问题**: 某因厂里待遇差，欲另谋一公司高就，问能否进入。
- **方法论的使用**: 取禄神为职位类神。禄神发用（卯）又与干上相合，寅月占卯乃进气——命中"禄发用+合干上+进气"三重信号；禄乘玄武提示"取巧"；课名返吟提示反复进退。
- **结论**: 必成且速，但过程反复、走非常规渠道。
- **结果**: 成功且成得别具一格——其嫂之情人为公司老总，犹豫再三，至卯月接受其入公司上班。

### 案例 2: 占投考一公司（c26）
- **问题**: 占投考一公司能否入。
- **方法论的使用**: 禄神不现于课传（类神未现，本应存疑）；末传申作长生虽落空，但作月将又是太岁——"旺不为空、得生得助不为空"，申月必得。发用寅龙作马=能力超群、善于行动；支为辰，支上丑、丑辰相加为房室即公司之象，丑作空亡=虚位以待，寅引丑（有路引动）=获得此位。
- **结论**: 申月必得。
- **结果**: 后参加考试，拖到申月，得到通知而上班。

### 案例 3: 占应聘（c27）
- **问题**: 占应聘结果。
- **方法论的使用**: 虽无禄神、长生现于课传（类神全缺），但三传进茹官局，生起干上印绶青龙，发用引动支上贵人，龙神又与幕贵生合——走"吉象并聚"补救路线（类神不现亦可成）。
- **结论**: 虽有波折，最终可成。
- **结果**: 后果于本月成功上班。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户直接问占求职类：应聘、投考、面试、等 offer/录取通知、跳槽另谋高就、"工作好找吗"。
2. 用户已起课（或给出盘面/时间/年命），要求 AI 作为分析框架判读"能否获得职位、何时成、走什么渠道"。
3. AI 在综合运势课（时运/年运）中识别到求职子问题，需按职位类神判据单独拆出判断。

### 与相邻 skill 的区分

- 与 `s01 三步断课法` 的区别: 本 skill 是三步法在"求职"占类的实例化；三步法管全局流程，本 skill 管职位类神取用与判据。
- 与 `s02 类神/课体双侧重选择` 的区别: 本 skill 固定以类神为主（禄/父母/长生）、课体为辅；s02 教何时选哪条主线。
- 与 `s03 空亡与变质辨析` 的区别: 本 skill 调用其判据（旺不为空、变质）但不展开内部机制。
- 与 `s04 类象之动·有路理论` 的区别: c26 的"寅引丑"用到引动机制，本 skill 只借其结果判断到位。
- 与 `s05 凶煞速断` 的区别: 求职等待期必查朱雀乘丁（结果被篡改，ce04），凶煞扫描是求职课的否定式前置过滤。
- 与 `s06 课体气势阅读法` 的区别: 取不到类神且无吉象并聚时，看课体大势（如火局逆合留北不南）定去向。
- 与 `s07 时运课综合断法` 的区别: 时运课含"官运/工作"维；问一年综合运势用 s07，单问求职成败用本 skill。
- 与 `s08 财禄判断` 的区别: 禄神兼管收入，但本 skill 判"职位能否到手"，s08 判"收入/钱多少"。
- 与 `s09 人际关系判断` 的区别: 职场人际（同事/上司态度）用 s09；"能否进单位"用本 skill。
- 与 `s11 升职加薪判断` 的区别: 已入职后的晋升加薪用 s11；本 skill 只管入局/换工作。
- 与 `s12 恋爱判断` 的区别: 无涉。
- 与 `s13 应期判断` 的区别: 本 skill 可给粗略时间线索（如申月必得、本月成），精细断日调用 s13。
- 与 `s14 终身与年运课法` 的区别: 年运课中"换工作"事件可借本 skill 的职位判据；问终身格局用 s14。
- 与 `s15 吉凶调制与缩放` 的区别: 吉象并聚之成可用四象限调制质感（如"取巧之成"vs"正常之成"）。

## 本占类的理气落实

固定求职者、雇主/审批者、岗位和通知/入职节点。贵人、官星或文书出现须查乘时得地、神将是否无权、阴神能否实际相助；生合有情但自身受制可有心无力，不能直接写成录用。

## E — 可执行步骤 (Execution)


1. **确定招聘阶段**：报名、资格审查、考试/面试、录用通知、正式入职、试用留任分别定位；问职位还是问收入/去留也分清。题目只问面试通过，不据此断长期任职。
2. **取职位与双方角色**：沿用禄、父母、长生及单位/本人关系，先说明选用理由，再列位置、旺衰、空墓、变质、阴神与引动。不因一个类神旺现就跳过其余检查。
3. **检验主线**：核对课传结构、单位接纳与最强不利证据；没有类神时，“吉象并聚”必须具体说明怎样连到录用，不能作万能补救。反吟先论过程反复，能否推翻录用另给理由；朱雀乘丁等不得直接当现实篡改事实。
4. **逐阶段收束**：明确通过/未通过/条件性或不确定，附过程与持续性边界；只在题目要求或可靠证据支持时论渠道和应期。若先断必得后遇反证，允许修订并记理由。

设计来源 B03、M04。M04 没解释清反吟等与录用结论的冲突，保留这个缺口，不能替作者补圆。共用 [判断方法规则](../daliuren/refs/judgment-workflow.md)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问的不是"能否获得职位"，而是收入多少、晋升加薪、同事关系——分别归财禄 / shengzhi-jiaxin / 人际 skill。
- 用户把书中的"果应"案例当命中率统计证据时——应先提示幸存者偏差（ce12）。
- 无课传盘面（只有起课时间/年份而无盘）时本 skill 无法执行——需先起课。

### 作者在书中警告的失败模式

- **ce04 旬丁篡改结果**: 占考试/应聘，在考完等待公布结果的日子里，若占得朱雀乘丁神，则录取结果会被篡改；想求安稳之事（工作、生计）遇丁则风雨飘摇、意外倒台。
- **ce02 空亡陷阱**：空亡不直接等于失败或可解；核本人、官禄/进达节点及救应的坐标、力量和实际作用。天空为天将，其北海风险象义另核，不以“不论旺衰”省略对本问的制化判断。
- **ce12 幸存者偏差 / ce13 同一课可多解 / ce14 可证伪性 / ce15 映射前提未论证**（公共方法学边界，见下）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: 全书求职案例全部"果应"，无失败样本、无对照、无盲测，真实命中率不可知。
- **解释自由度（ce13）**: 类神不现时"吉象并聚"补救线几乎总能成立，结论对侧重选择高度敏感，同一课可多解。
- **可证伪性（ce14）**: 象意组合自由度极大（干支×天将×位×阴神×年命），断"后应验"可能是事后合理化。
- **信仰前提（ce15）**: "禄=薪水、父母爻=生活来源"等干支五行→人事映射被当作不言自明的公理，从未论证。

### 容易混淆的邻近方法论

- 与 **财禄判断（s08）**: 禄神管薪水但求职判"位"、财禄判"钱"，勿混。
- 与 **升职加薪（s11）**: 以入职为分界——入局/换工作用本 skill，已任职的升加用 s11。
- 与 **应期判断（s13）**: 本 skill 只给月将/太岁级别的粗略线索，精确断日走 s13"先定迟速、再定日期"两步走。
