# 问题定位与主线

## 理解事件，依分类专法定位

本节为用户明确指定的本机占事规则。参考北海《六壬金针》LF584、586—589、2365—2368及《理法简易》LF377—381、1346：先识别所问之事及实际承担该事的对象，再依分类专法定干支和类神。不是“谁来问谁为日干”，也不是“所有占类日干永远为某个人”。

考试、考核、升学录取：日干代表实际考生；疾病、治疗、恢复：日干代表实际患者。换成父母、子女、姨舅、朋友或其他人代问，事件角色不随之改变。亲属称谓用于准确记录代问背景，不能以代问者为日干，再由父母/子孙/兄弟等递推来替换考生或患者。年命属于谁须单列，未知不借用代问者。

婚姻、攻守、胎产、人宅、交易等仍依该事件的专项对待轴确定角色，例如传统婚配干男支女、攻守干攻支守、占产干儿支母；提问者的身份不能挤占这些位置。没有人物的天气、作物等问题直接围绕对象取类，不强安一个代问人为中心。

《理法简易》LF1005—1007转引《说约》的嫡属六亲法，以及旧疾病亲属变法，保留原文和来源身份，属于可供知识研究的异法；本机普通单事流程不自动启用、不与事件定位并行投票，也不因哪条能得吉或吻合反馈而换法。只有用户明确要求比较该异法时，才单列参照分析，不能覆盖本流程主判断。这一执行选择不冒称古籍一致或经预测验证。

主智能体理解原问时，自然分清发生什么事、实际涉及谁或什么、各方职责与目标，再依已读分类专法确定干支、关键类神及年命归属。将会影响判断的取用理由融入正常分析即可，不另填角色表、不新增身份检查阶段；当事对象可以是人、物或组织，代问者没有参与事件时无需安排课位。成绩、学校、病证、医救等各司其职，不因六亲名称就当作现实亲属。

交接每问保留domain以读取和传送对应分类占；不要求actor_entity_id，不由程序将考试、疾病实体强绑日干或冻结裁决中的对象取用。程序负责原盘坐标、关系查表、日期算式和资料版本，模型负责理解事件与适用专法。裁决者在正常研判中处理取用，遇到会影响判断的具体错误才纠正，不增设逐人核验或额外派工。


定位服务于全局理气，不以角色表或象义清单替代判断。明确主体和关键类神后，按 `liqi` 同时检查其自身状态、与四课三传及彼此之间的关系；定位修订须重核整条作用链。

每个子问先定现实对象、事件阶段、期限及原问成功标准，分开成败、过程、程度、属性与时数。题干/已核事实、用户猜测、盘面推断、未知分别说明；有据推断可提出待核，不能再冒充已知前提排除其他方案。结果标准不随判断滑动：有进程不等于终局成功，部分得到也不自动等于本问成功。

先确定实际需要区分的结果；获奖与获胜、有工作与取得编制、评定等级与实发金额不能互代。只列会影响本问的候选，不穷举全盘。现实门槛、比例及常见结果须有已知资料，不能编造后作为取舍依据。

按“现实对象→候选类神及来源条件→实际位置→关系方向→所答子问”定位，说明谁对谁起作用、六亲相对谁、年命归谁。人物、行为/作品、所得、病象/伤处等不同职责不混为一物。存在会改变结论且不违背本节事件定位的候选时，比较各自条件、关系和最强反证；不能先选结论再配象义。分类细法依专项，神将与显象依 class-mapping，不另设统一人物表。

定位未成立，暂缓依赖它的结论与应期，可继续核盘查源或保留分支。有新事实或更强关系依据可修订定位，交代原取法为何退让，并重核受影响的六亲、制救和应期；不能换主体仍沿用原参照的“生我”“脱我”。仅反馈后换象义是待验解释，不能证明初判时已能如此定位。代问不改变既定事件角色；特殊年命参照须有来源，不按称谓机械替换。

主线须直接回答本问：具体对象核对应类神，人事相互作用核日辰关系，方向形势核课传结构。依占类和课传特征定侧重，将旺衰、生克传递、切题类象组合、阻断和制救纳入同一主线；不先冻结成败再安排象义。说明本问为何以该类神、关系或结构为主，核其切题性、实际位置、状态和完整专法条件，给待核主线及主要阻碍；选择侧重不等于先选答案。类神多现先辨同职责候选、不同对象或不同方面，再择用或兼看；不将病象偷换病人，资格偷换考生。无法裁决留具体分歧。

司法行政尚无通用机构表：报警、调查、处罚、诉讼、羁押、取证、办证先分事件，不能仅凭机关名同取勾陈/鬼/虎。未齐专项查本题原书，不套邻类。旧“十类”是检索标签，十二研究分类是取用路由，两者不互相限定。

仅用户未明事项时用来意法：占时及所临类神、天将相参，泛占察课传紧事与干支实际落点；“干上主思、支上主行”是该法口径，不冒称所有四课的固定角色。明示为推测占类，不改写用户已说的问题；紧事越问例外须有原法条件。
