# 北海综合断课流程：原文明示与操作归纳

范围：核查《特训班讲义》《括囊赋略疏》《理法简易》《毕法赋全解》中的总论与相邻段落。不是对北海全部书籍逐页复审，也不根据书中例证宣称独立预测效果。本页原文核查作为49版方法来源；已采用执行补充以judgment-core为准。

## 一、最明确的总流程

《特训班讲义》8—16行明示：“明占类，定侧重，看显象。”

- 明占类：明确追求什么结果，区分某事能否成、某人事物能否出现、某人事物向何方向发展。
- 定侧重：“占类+课传特征”决定断课主线，侧重点可以是类神，也可以是课体结构。
- 看显象：辨类神、课体的真假与变质条件，不能只停在出现某名象。

同书34行特意说明：“我们在用课体的时候，不要只是盯着《课经》里的，《毕法》里的课传结构也是课体的重要内容。”因此，这里的课体不能缩成六十四个名称，更不能以为分类、六十四课、毕法、神煞是四套相互独立的裁决器。

## 二、先看大象与先取类神的关系

《括囊赋略疏》20行：“占课先观课体大象，定其进退迟速。次观类神，以验吉凶。”

《理法简易》623—627行给出另一种明确表述：“课体看大象，类象定吉凶，理气为准则。”先感受气势氛围，再取类象作全方位分析，再结合所问事情的内在特征辨宜忌。

这支持先作整体观察，但不支持不分占类、仅按课名先冻结最终成败。《理法》553—567行一面承认部分大象可作主要依据，一面说多数与所问不亲；一般可由组成类象的分析替代课体分析，不善用课体而引起混乱时可以不用。

《特训》43—44行强调课传上何者显明而选择侧重；103—107行又讲能找类神的看类神，找不到类神的看课体大势。“缺少清楚的类神定位”不能直接改写成“任何类神未入课传都可凭课体翻判”，后者仍须依占类区分，《毕法》97、98法对此有明确分路。

## 三、各部分承担的职责

| 内容 | 在北海总论中的职责 | 不能机械化成什么 |
|---|---|---|
| 分类占 | 明确问题、对象、取类和宜忌，决定分析侧重 | 同属婚姻、考试就永远只有一项类神 |
| 课体、大象 | 观察气势、结构和整体趋势；部分切题结构可作主线 | 每个成立课名都必须解释，或全部课体永远只能作轻微辅助 |
| 毕法 | 提供结构及关系的成例，也包含取类、空亡、阶段等方法 | 与底层关系额外叠加的一份吉凶权重 |
| 神煞 | 可作具体所占对象的类神，也可修饰状态、动静和复合意义 | 最后一轮统一加吉减凶 |
| 理气、生克制救 | 指导取类、察类和综合取舍；判断力量、通达和实际影响 | 仅看五行生克，或最后用一个旺衰分数概括全部判断 |

《理法》503—535行把类象作为核心、理气作为指导，气不只包含月令旺衰，还包括气势、进退缓急、类聚等。《理法》1035行承认神煞既可形成具体复合类象，也可改变原有吉凶；不能一概称作无足轻重的附加信息。

## 四、把原文展开为一次综合分析的操作顺序

以下是本轮跨章节归纳，**不是北海原书中逐字列出的七步法**：

1. **明白所问。**明确对象、目标及问的是成败、出现还是发展；同类事情的问法不同，主线也可能不同。
2. **观察整体。**从真实课传组合、旺衰和神将等观察动静、进退、明暗、缓急及持续，不只凭课名的吉凶标题。
3. **依题定侧重。**明确本问是以具体类神、双方关系，还是整体发展气势为主要切口；必要时兼看，但要说明各自解释什么。
4. **取类定位。**依专项明确人、事、物和干支职责，区分本问主类、相关类及不相干的出现之象。
5. **全面察类、辨真假。**察天时五气、所临地盘及十二气、阴神与神将、空亡、刑冲合害、夹生夹克和制救等。不是发现旺、空、合某一项便停止。
6. **结合事理取舍。**同一关系在不同占类的宜忌不同；看实际作用是否支持本问所求。课体与毕法还原为组成关系，神煞落实到对象与影响环节，不将同一事实换名累加。
7. **形成结论并按问细断。**分开结果、过程、代价、程度；有应期问题再依实际阶段选定期方法。其间若发现关键反证，应返回相应环节核实，而非依书目机械重跑全部模块。

察类的天、地、人思路见《理法》2139—2151行及3151行：“知五气之殊，知加临之变，知制救之情”。这里的“人”主要是制救、阴神等分析层次，不能直接虚构成盘外多一个现实人物。

## 五、不能被整理掉的复杂处

《毕法赋全解》3761—3763行说，生克与神煞、四课与三传，并不能普遍预定谁先谁后，要看课的特色。其神煞用语还包括刑冲破等关系，与程序中狭义的神煞清单并非同一范围。

同书4773行更说：“氛围，是一种整体的类象，高于单个的类象”，并承认其用法“无法界定，何时用，何时不用”，属于“如履薄冰”。4828行也有“大氛围能解决的，就不用看类象”的较强表述。这些是北海原载方法，不能为了让流程整齐而删去；同时，它们尚不足以构成可复现、随时允许用“大势”覆盖明确专项反证的自动规则。

因此，北海的总原则相当明确，但并非每种冲突都有固定优先级。其明确、可核查部分与高度依赖综合经验的部分，应分别保留。书中示例的必成、必败等强语也不能无条件激活为现行系统规则。

## 六、对现行本地体系的含义

“不增加六十四课独立裁决轮次”与北海诸系统相互融贯的思路相容。但本机45版把毕法定位为描述辅助，是本地采用边界；北海原书确实允许某些切题结构成为主要判断依据，不能把本地较保守的规则说成他原书的全部立场。

上一份核查所指出的风险，应准确理解为：参考表把大象压缩成固定吉凶基调、未充分保留切题条件，并与本地现行辅助定位方向不一致；**不是说北海“先观大象”本身没有依据。**

更适合当前系统的归纳是：依问确定主线，沿同一对象和实际作用关系综合；书籍与格局提供查证、成例和解释，不按资料模块逐轮独立投票。本轮已将有界执行补充接入49版；原书强断及未定氛围边界不自动激活。
