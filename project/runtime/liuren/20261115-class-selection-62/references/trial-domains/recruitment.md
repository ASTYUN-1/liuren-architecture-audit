# 事业任职：取用与专项判断

## 依所求事件分流

一般求职、指定单位录用、报到与待遇。一般求职首禄，其他类按职责兼看；指定单位另核干人支单位及接纳关系。获得机会、面试、通知录用、报到及待遇兑现分别验收，不用一般有工作替代指定岗位录用。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

## 取用职责

一般应聘以禄为第一类；父母之来源、长生之生计和具体职员类分职责，不在几者中择最吉者。问指定单位还核人/单位关系及该岗位接纳条件，一般有工作不保证目标单位录用。 本试验倾向依class-selection-trial；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：问某人应聘/录用，围绕该应聘者、单位及岗位，不把代问亲属当本人；问单位招人则先明确招聘双方，不能照抄个人求职角色。考试过关与最终录用分子问，涉及考试的子问另登记exam并实读。

### LR26-TXY-C07 事业与组织：人职关系和总分关系分别定位

适用：分清问人任职、单位经营，还是总公司与分公司的关系。

北海工作常法干为人支为单位；单问总公司运营可支为总公司，问总分关系则总为干分为支。干支关系轴随着实际问题改变，不能由机构名字固定。

边界：同事信任问不因发生在公司就套任职；公司盈利须另取经营与利润目标。

出处：理法 LF188—188；理法 LF709—713；完整引文见同 ID 卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

出处：理法 LF705—713；理法 LF1344—1349；理法 LF558—561；完整引文见同 ID 卡。

### LR26-TXY-C09 事业：催官使者、催官符与任所分支

适用：所问是官职升迁、赴任或任所；核日鬼乘虎、三传财生鬼等具体组合与位置。

催官使者是日鬼乘白虎，北海限定出现于日干、年命、三传等处；催官符另指日鬼临身年命且三传财生鬼。任所可分别看禄、父母及日支的有条件路径。

边界：普通病讼财婚不能照搬“催官为吉”。；不以古代官员职位直接证明现代求职必录用；第二三四课的统计边界依本条原文。

出处：北海毕法 LF608—620；指南 LF803—811；完整引文见同 ID 卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

出处：金针 LF1190—1202；北海毕法 LF461—467；理法 LF1346—1346；完整引文见同 ID 卡。
