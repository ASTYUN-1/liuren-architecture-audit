# 财务经营：取用与专项判断

## 依所求事件分流

经营、财源、利润与款项实得。经营持续/生计核长生及财源；约定款、盈利净得以财爻及与者/取者承接为主线。背景兴旺、承诺、可收款与真正到账分阶段；有业务、营业额与净收益不能互代。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

## 首取前核对题意

问店铺经营或生意概况，先定位经营根源（长生及相关财源）、经营者和店业；不能自行改问为实际进项，再以财爻接管全部经营职责。财可兼察收入、利润或款项，不替代经营体；明确只问某笔实收或盈利净得时才按对应财务分支首取。北海《理法》LF713、LF1348区分求财与经营，LF1369—1378明说开店“通类虽在财，但专类却不在财”，并分干人、干上主顾、支店。不同职责按实际所问取，不把一个宽泛财类覆盖所有生计问题。

## 取用职责

实际钱款以财爻为主线，经营/生计以其专类；与者能给、取者能取、财阴、款项归我通路分别核。通类吉不能替代文书、财源或具体交易条件，忙碌、承诺及批准不等于利润或到账。 本试验倾向依class-selection-trial；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：先定哪一笔钱、哪个经营/交易事件及实际收付双方，代问者不自动成为求财者。下文“我、本人、讨者”指事件中的相应角色；动静改位须来自事件阶段，不来自谁转述。钱、货、经营体与所得分开取类。

### LR26-TXY-C06 人际：去求人与等待答复阶段可改变干支

适用：所问确为主动求办或已求后等待答复，实际阶段已知。

北海分别取：尚未去而打算求人，我动为干；已去、现待对方消息，我静为支，对方为干。此法不可因结果不利而临时倒换。

边界：不是所有代问或人际都按谁动谁为干；先核具体专法。

出处：理法 LF182—186；理法 LF636—638；完整引文见同 ID 卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

出处：理法 LF705—713；理法 LF1344—1349；理法 LF558—561；完整引文见同 ID 卡。

### LR26-TXY-C10 财务：得财、财源性质、与财之人和迟速分别看

适用：原问是实际财物或款项得失，明确对象、财源与是否已达成交易。

北海以财爻为首要候选，分开察其得失、所乘天官所示财源、支上所示与财之人及出现位置与旺衰所示迟速。壬归财将察类仍可作有身份的对照，不混抄为同一规则。

边界：求财不等于经营事业，收入、利润、资金周转、债款到账须分目标。；通类与专类按LR26-TXY-D01分层，财不现依原书所列年命、遁财、生合气地等条件分析，不从单句推出全盘无财可得。

出处：理法 LF1711—1728；壬归 LF285—301；完整引文见同 ID 卡。

### LR26-TXY-C11 财务：讨债定位随主动追讨与等待变化

适用：实际已确认债权债务关系，分别问能否还、是否有钱或何时到账。

去讨者动，可为干，对方为支；已要求还款而静待答复者为支，对方为干。关系上有无还意或压力，与财爻旺衰所示有无可还之财须分别核。

边界：朋友、亲属、同事只是债款关系的条件，不自动把主问题改成人际。；顺从或口头答应不能替代实际还款。

出处：理法 LF636—638；完整引文见同 ID 卡。

### LR26-TXY-C12 财务：店业、行商外销与交易的钱物分配

适用：区分开门面、外销行商及具体买卖。

开店干可为客商支为店业，宜店业得生合；外销干为行者支为他乡，重彼地对人的作用。金针交易例又以干为买家支为店家，财可分别取钱与物，须有该题交易背景。

边界：这些是不同子问的关系轴，不可不说明就叠成同一永久分配。；交易个案的钱物读法不能推成所有干财必为钱、支财必为货。

出处：理法 LF1357—1358；金针 LF1178—1178；完整引文见同 ID 卡。

### LR26-TXY-C13 财务：财的真实性、阴神、地盘和暗鬼须核实际作用

适用：已定位财物与求取者，再看财阴、所临和遁干。

财现不等于能取；财阴与所临的生克、空墓、破碎、闭口、玄夺等可改变可得性或带来后患。遁财与财遁鬼是不同明暗组合，不能只计为多一财。

边界：“因财致祸”须核具体组合与本题财所指，不直接断违法。

出处：金针 LF1237—1240；理法 LF1723—1728；理法 LF1743—1746；壬归 LF293—301；完整引文见同 ID 卡。

### LR26-TXY-D01 已明确：通类与分类分层，得财与财源分职责

适用：先明确问的是实际钱物能否取得，还是某项财源、办证、经营等具体事件。

通类定大方向、分类/专类定具体对象，二者分层兼看，不列作互斥方法。实际财物得失以财爻为主线；财源、办证等具体事项依对应专类细断，不能拿通类吉替代专类所示的具体阻碍。

执行：通类提供一般方向，专类提供精确条件。问贵人办证，不能以贵人实替代朱雀所指文书的状态；问实际得财，以财爻的气态、阴神、与财者及取者通路判断得失，同时由天乙、勾陈等说明对应财源及条件。原文“财现以财为主”落实到财物得失主线，“俱入以专类为断”落实到具体所问，不当作两个模型可以任选的全局优先表。

财不现亦须读完整条件：课传、年命、遁财、生合有路、旺相不空伤及类阴益日等按各自原条使用；不能把课传不现和与我完全无涉混同。

身份：用户本轮确认的执行解释及连续原文分层；不是更改原书字句。C01关闭，不再列候选未裁定。

出处（Python splitlines）：《理法简易》1393—1395、2709—2715、3437—3447、3479—3487；《壬归》355—359。原书措辞保持，当前解释不能冒称原书逐字一致。
