# period-outlook 占类方法

## 依所求事件分流

限定时段的整体处境与具体主题。整体气势定侧重，逐项具体事件依所属专项，不把统一旺衰分当各主题吉凶。时段、机会出现和实际完成分开；用户未问的数量/应期不自动展开。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

本机事件定位：只有原问确为某人某时段的综合状况才用本模块，围绕被问对象而非代问者。年命和“我之所遇”归该对象；有明确单事目标时加载相应分类占，不用泛论替代考试、疾病等问题。

来源方法：`shiyun-zonghe`；依总入口加载，完整条件见下文。

## 本试验解释边界

以上仅供分类、取用职责及适用条件；任何生克、鬼虎、制救或结果措辞都须依class-selection-trial先定本题作用性质，再按统一喜旺恶衰解释。不将旺鬼当成更强攻击，不以制不住旺鬼判凶；不以衰鬼数值小免除凶态。空墓、时序、实际通路保留，不能由低分直接判失用。原问未给的成功标准不补造。首取条件仍不足时只定点读classification-priority/原段，不用预训练通则补定。完整专项原件保留，未覆盖。
