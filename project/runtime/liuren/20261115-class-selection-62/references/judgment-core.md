# 本机占事共用判断规范

这是主智能体和裁决者共用的分析路线。原书、讲解、项目归纳、用户采用及反馈分明；U01—U11控制本版执行。先读本页、本问专项和adjudication，report交付前读；详细方法及连续原书只为实际缺口查询。旧版说明不叠加，普通占断不检索案例/经验库、旧缓存或已知反馈；原书及书内例证保留。

## 从所问事件走到判断

**明问 → 定侧重与职责 → 取用定位 → 全面察类 → 有效作用与制救 → 同标准综合 → 按问细断。** 这是分析顺序，正文自然表达；不是固定报告栏目，也不是把全部模块各算一次。

### 明问：实际要判断什么

以实际当事人、所求对象和可验收变化界定本问，分清成败、出现、发展、原因、位置及数量等目的。代问者不自动占日干。原问给出的事实、推测、程序换算及未知分别保留，不以缺少用户未要求的精度停用已有资料。

按所求事件选择domain及其分支：同样出现考试、工作、钱款、感情等词，所求可能是评分过线、拿证、录用、报到、经营维持、款项实得、婚配或态度，取用随职责分开。不同事件可以分子问；同一结果的分数和过线相互核对，不能切成各自任意取类、互不相干的两条结论。条件子问保留原题依赖。

阶段同时看事情在何时形成、何时评定、何时可见和何时实际兑现。已有动作不等于最终完成，后来有通知也不自动说明之前的结果有利。考后还可能阅卷、审批或复核，只有相应条件改变才据此更新；原问给占时不自动触发应期任务。长期跨度亦保留具体事件的阶段。

每问在现有input_review中简记route：event、focus、primary_entity_ids、selection_basis、time_scope。它保存本轮理解、首取理由及时间职责，不预断吉凶。class侧重具体主类，relationship明确双方，overall侧重整体发展，unresolved保留具体定位缺口。程序只核ID/覆盖；裁决者依据原问与专法复核，可说明真实纠错理由后改正。

### 定侧重：通类、分类和整体如何结合

先观察真实课传的动静、进退、明暗、缓急及持续，用占类与课传特征决定从何处深入；课名本身不预先冻结结论。具体人事物有已核专法时沿其主类，关系题以双方及其作用为轴，整体时运沿切题结构和气势。无明确专类映射时说明功能推定，不造一个适用所有问题的统一类神排序。

同一职责有首取/条件递补时，说明本题满足的分支并照其先后取用；不同职责各解释对应环节。通类提供背景与大方向，分类决定本题具体对象；首取贯穿实判，不只出现在取用小节。辅助类有真实作用时可以影响主类及结果，须解释作用怎样到达；候选更旺、算数更高或出现吉名，不是改首取的理由。专项允许不现/空陷递补时按完整条件执行，不把这种递补推广所有占类。详细职责与原段查classification-priority/evidence。

### 可靠定位与察类

复用完整可信程序盘及坐标，区分日干/寄宫、干上/干阴、天盘支/坐处、同名地盘上神、天将/所乘支与直接阴神；天空和旬空各有身份，不按人数分四课。主类、施者、受者、救神及最强反证均察月令五气、地利十二气、空墓、神将、直接阴神及相关刑冲合害、生扶泄耗。狭义月令气态与综合状态分名，先判断实际作用再按需量化。

年命为实际当事人的参考层，命偏固有、年偏当前，当前可超一年，依本问作用兼看而非恒定年胜命。用户给出生年、本命或行年即交year_life/life采用；05→2005、99→1999，只知支亦可算行年支，缺性别列男女候选。无生日/出生月/旧userinfo未验证不妨碍使用。干支年直接作为birth_pillar，不无据扩成某个公历出生年。同盘新增用life回执和computation_requests进入原盘材料，不作出生推命。

### 有效作用与制救是判断主体

沿**施者 → 实际通路 → 受者 → 本问环节**分析决定性支持和阻碍，公开说明能支持结论的依据即可，不提交私下推理。分别回答：自身状态如何；能否对外作用及受何限制；这种作用对当前所求有何利害；是否已经达到所问结果。旺是能力和条件，不等于有益或兑现；弱也不等于无作用。

救应同样核施受：救谁、制谁、救神自身状态、位置/承接、是否被制绊、作用先后、究竟解除哪一阻碍。生扶、转生、化泄、制克、冲解和德解按实际条件解释；一种关系存在与它在本题有效是两步。局部缓解只支持局部判断，关键障碍被实际解除才支持改变结果；未解除的阻碍继续参与综合。不能把两个单宫指数大小直接写成已经综合算出制胜。

支持和反证采用相同审查标准。凡依制救、空解、旺衰变化推翻关键反证，须给该作用的切题通路和时间；不能一边要求不利必须直达结果，另一边仅凭相生吉名就认定成功。相反，也不因谨慎自动降档、缩量或把局部不利扩大为失败。最强反证处理后回看原问的验收条件，再形成主结论。

### 课体、毕法、神煞进入同一作用关系

发用联月令、坐处、乘将和切题神煞察发动及快慢虚实，核与四课、主类的真实通路和时序；单宫指数不是整课气势。速度不等于吉凶，虎急蛇缠等只是表现趋势。

课体/大象帮助定侧重、描述结构；毕法按本地已采用边界作描述性辅助，所含取类、空亡、阶段方法照常履行。每条名象还原为组成关系及本题宜忌，不额外加权、不按重叠格名数票，也不另开裁决轮次。核心bifa_conditions只确认结构，相关意象和原章按BF-01至BF-100、BF-B35/BF-D35查询，第22成格依《大全》。无关条目可不用；整体耗损/动象不直接实体化为分手、失窃或成事。北海原书更广的氛围论与当前采用边界分别保留，见analysis-workflow。

神煞只用程序resolved项，落实对象、天盘支归属、地盘坐处、状态与制救。切题时可承担专类或修饰作用，不作最后一轮统一加减吉凶。同位多名和底层关系不重复计证；吉将得吉不免核内外战，神克将为减权而非一概归零。支神偏质、天将神煞偏意情的分工按事理取义。阴神先直接一层，新增层只解决实际疑点，重复即止；不一律解释为心理秘密。季关S33春丑夏辰秋未冬戌，阻隔及仓库吉用依原段，不见关便断不动；S23同表义不同。详查shensha-use/meanings。

## 旺衰工具如何服务主线

strength_index默认是单宫直接关系研究指数，含月令、自身十二气、旬空/坐空、天地、本身直接阴神及同宫神将生克；将对地盘只列十二气，不新增将地生克边。它不是全局力量、吉凶概率或自然能量单位。0与null不同，5是基准，2.5不是失用开关；标签是旺衰层级，非可用程度；完整作用A为null是适配不足，不表示作用不存在。

先解释取用与通路，需要表达跨宫作用的数值增减时再用strength补算，提交完整已选对象与关系，不手加分、不层叠上次结果、不默认全盘联算。已含本宫关系自动跳过，未提交关系不扩散。取用纠正后重算有关清单；定性刑冲、神煞仍定性说明，三合/半合/三会数值暂缓。review:true只为具体查漏，程序候选关系不是已采用有效作用。

季土双表同表前后比较并说明依据，不按结果择表、平均或计两票。时间推进按U10核具体事件：evaluation保留原空亡并更新节月五气，evaluation-xun-research属新旬替换研究，不是既定出旬/冲实算法。日历值冲合不等于事件填实，不能自动以最高分日期择期。

## 从主线进入取数与应期

按问才进入数量/时间。数量先复核本次所求量和对象：总额、净得、分数、名次等不同；成败与数量可以同源但不能无复核互代。天将类定位所乘T:支。先查具名法及适用原段；直接适用的source原法保留，基础步之后还有依据成立的步骤便继续完成，不因base-only就禁止后续修正，也不为统一接口强迫改用另一算法。

source已依旺衰选乘/加/半，算使用了气态，不再叠实验倍率。是否已用旬空看实际选法输入和数量运算，不因状态指数计空就声称本数已扣，也不把同一空在选法和后续减数中再消费。源法未明示的空半或补充步骤说明是项目研究/估计，保留有据条件与例外，不假称北海已有现代百分制通法。仅数量主类自身旬空适用本项研究空半，身空/坐空/载体空不自动同义。

原法不足才说明转experimental的理由，采用未含气态与空减的raw本数。strength真实同对象/同关系/同表重算without_void，不从含空指数倒除。实验倍率E≤2.5为0.5，2.5至4连续至1，4至6为1，6至7.5连续至1.2，以上维持1.2；空半独立一次。系数未经预测校准，不是北海原文、成败阈值或准确率证明。两路不算后择有利。

基数、数法、量级、单位和修正各有依据。满分和奖金上限只约束范围，不能把个位本数自动乘十或按E/10折成得分；财源规模不是个人所得。无上限仍可有据估计，但旺衰不能独自决定20/200/2000。超界复核，不截满分；序数/日期/编号沿专法，不套实验分段或空半。

最终quantity_adjustment消费本任务真实回执，保留本数也兑现。54版source的expression说明base书证，非零进位和免空减例外绑定evidence的具体原句及适用解释；来源可查不等于应用正确，复核仍审实质。字段查quantity/quantity-strength/quantity-correction。先实际尝试给最有依据的具体近似数及单位、可附范围；无法形成可辩护数值才明示已做步骤与具体缺口，不随意凑数。

应期先确定所问节点、起算和期限，再核值冲合及条件变化。结果形成、评定、通知与兑现各按事件选法；出旬不自动使既有结果转吉，未发生的制救为待验条件。候选期不反向保证成败。

## 独立裁决与实质复核

主准备真实题意、路线候选和必要观察，不预写成败；focus_issues只留实际未知或同条件真冲突，不把已定优先级重新摊平。裁决者读全盘及同版材料，纠正候选时说明题意/职责/坐标/适用条件，不按旺弱或数值高低换类。

逐问直接给结论，说明决定性作用和最强反证取舍，保留精度、条件与具体缺口。正文自由表达，audit复用现有附件，不新增固定判词模板。主智能体五项review依次核原问事实、职责阶段、真实计算及数量依据、有效反证与制救、逐问约束；引用route:问ID、原问/绑定方法/实际回执。回执一致不能替代专业依据的复核。

题意偏移、首取口头保留却在实判被替代、无充分制救、量级或空减例外无依据，均属于可凭报告原句与绑定证据补核的问题。一次原会话recheck先处理这些实质缺口，不要求保留某一结论/数字再补齐标签。可据证据保留或修正相关结果；排版/引句格式只修格式，不另开裁决。主不自行折中改判，剩余缺口如实交付。程序始终不选类神、不裁成败；工程通过不证明语义遵守或预测准确。

V41-01依用户决定保留U08/U10待后续研判，不反复询问；已确认采用不从旧摘录反向执行。书证不足或新反证只定点回连续原段。


## 已确认判断口径 U01—U11（主智能体与裁决者共同执行）

身份：这是用户本轮确认采用的本地体系及工作约定，不声称诸书完全一致或预测效果已经验证。原书保留原字；下列口径控制本版本的执行。旧摘录中的相反说法只作来源，不是可以逐盘任选的另一条指令。pending-conflicts保留历史条目的分类复核；已明文解释者直接执行，只有经同条件检验仍互斥者才列真正矛盾。

- **U01 原文与执行。**“凡、必、百无一成”等强语保留原貌，执行时解释其对象、条件、机制及范围，不做无条件成败开关；也不能借“夸张”随意否定切题的反证。区分原书、讲解、本轮归纳、用户体系选择和现实反馈。
- **U02 喜旺恶衰。**采用北海喜旺恶衰趋势，以下数值执行解释由用户本轮确认，不冒称古籍原有数值阈值。旺衰与可用性分开判断。本题相关的日干、关键类神、官鬼和凶神统一喜旺恶衰：越旺越有利，越衰越不利；官鬼凶神旺默认不以侵害为主，衰败凶态显。不得把鬼旺解释为侵害大、鬼弱或零解释为无害；不得把身分下降、鬼分高低直接当作考试失败或制救成败。能否实际作用另核职责、位置、通路、受制与时序，不设低分失用开关。泄耗先核去向，泄干生本题主类可体现付出，不默认失败。相关关系可补算，实际作用性质先于分数解释。统一旺衰层级（不是可用程度、成功概率或分数）：E=0为本模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null是缺计算。4至6不增不减是旧数量修正分段，不用于此处；旧harm_tendency/favorable_tendency小数不参与本轮吉凶裁决。旺鬼贪荣有时段条件，不据当前有利保证长期无患；当前结果和后患分开。刑虎等组合仍核其具体条件，不因有组合便否认本段的统一倾向。
- **U03 直接临生合、类神状态与对我作用。**“类神临生临合，自贪其荣，不能为我所用”按原文执行，不限官鬼：所减弱或难发挥的是该类神对日主、本问本应承担的作用，不是断其自身能量消失。财贪生合则财难为我得，父母/生气贪生合则难以生我，鬼煞贪生合则难来刑冲克害于我；所求为何决定这种停用是利是弊。须定位上下直接临处，不能把别处生扶等同贪恋所在之处。自身得养、旺相有权与对我实际发挥作用分层看；日干、吉神得旺禄照喜旺恶衰论，不因一切生合便自动判失用。此为已定解释，C02关闭，不再要求用户确认非官鬼范围。
- **U04 十二气跟随所看对象。**日干状态采用天干十二长生：阳顺阴逆，甲亥乙午丙寅丁酉戊寅己酉庚巳辛子壬申癸卯起长生。支神、天将等按自身五行采用木亥火寅金巳水土申顺行。明确“谁在何处”：丁见未为冠带；白虎（金）乘申为临官，申（金）坐午为沐浴；天将对乘支、支对地盘、天将对地盘分列。不采用天一群笔记“十二长生永远以日干为准”，也不以五行顺行表覆盖阴干。日干寄宫不是日干五行替身。 胎爻专项依北海《毕法》1463—1467另按其明示取类：甲乙寅卯胎酉，丙丁巳午胎子，庚辛申酉胎卯，壬癸亥子胎午，戊己辰戌丑未胎子或午；干支胎同等重要，土胎两处都登记。该专项取类不改通用日干状态表，不以事后结果选有利胎位；不等同采用引擎未登记的同名神煞。C08关闭。
- **U05 生克刑合并见。**生克、刑合可能并行，不因有两种关系便列两套结论。依相应连续原文的双方旺衰、乘将、上下位置及时间确定主作用；如庚辛与巳兼长生和火克、寅巳兼生刑、未亥兼克合，须保留各自条件。半合、刑、合化的存在与效力分开；不凭“大势”循环证明大势，也不自行合化。
- **U06 制救。**同时看受者、施者：身、鬼和救神各自的气态、位置、通路、神将及吉煞条件。鬼衰而凶态显、旺子孙能实际制之，可减害；救神气弱，不能因有子孙或吉名保证救成。德等可增强化煞吉力，仍核落点、受制及作用；既不一德包治，也不忽略有效德解。只缓解局部就只判局部；关键阻碍确被解除，可改变结果。发用之鬼末传可制、末传之鬼发用不能制等时序条件按对应专法保留，不作全盘无时序相抵。
- **U07 天时、地利与综合旺衰。**月令主管天时及五气，坐处主管地利；月令得气是重要源条件，不把它与坐处看成可任意互换的二说。失令得地不自动大成，得令失地亦须看受限处；一个“衰”字不抹去天时，一个“旺”字不保证实现。狭义月令旺相休囚死和广义综合旺衰分名记录；广义旺衰描述对象的总体状态，空亡亦为其条件之一。生处、坐处、制处和承接条件共同分析；现采用34版固定研究算法描述单宫旺衰，并由工具依明确取用关系补算，模型不得自创系数或胜负阈值。该指数不是已验证的自然能量单位，不替代原法裁决。季土条件表差异属C05程序取法记录，不据此宣称已发现同条件理论矛盾。
