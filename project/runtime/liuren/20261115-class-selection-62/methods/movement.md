# 动静、通路与直接阴神

围绕主线和最强反证看三合、六合、遁干五合、刑冲破害及临宫关系，说明实际双方、位置、力量与切题作用。“有路”提供引动候选，不等于吉或成事；预先按所选方法取路，不事后任意凑合冲编故事。

直接阴神用程序结果，先看一层，分别判扶类、伤类及对主体的作用；新增一层须解决具体未决关系，节点重复或无新信息即停。年命/行年用用户明确输入或新year_life计算回执，不因无生日弃用；命支出现、临命宫、命宫上神分别论；未知只限制依赖它的方法。行年上神的思想动向、官常升迁/勾陈受役等是有条件候选，不当已知动因。

旬丁为移易动摇，支上、卯酉门户等依实际位置判；求稳与求变喜忌不同。丁马虎魁罡通常是辅助动因，所问正是动变时可成为侧重，不由一丁断篡改、盗劫或死亡。

## 动静专法条件

1. **问动象先查驿马**：需要使用驿马法时查其状态——驿马坐长生（恋生不去）、坐墓（入墓止）、被地盘合（缚足恋厩），原法以此提示动象受阻，仍核具体对象及能否解除。
2. **干神归支辨静**：干神加支上为"归支"，支为家、在家不动之象——但必须辨支神与干神关系：支克干则连家居也居不住（被迫奔波）；被支脱、墓则在家心力交瘁动不了；日禄归支则禄属他人（有人顶替）。
3. **首尾相见始终宜**：旬首旬尾分临干支，无空亡则吉凶事皆成就（纠缠之事亦成局）；有空亡则首尾中断事不成。
4. **河魁动神**：魁罡（戌/辰）加临日干、年、命之上，动者静而静者动——问答录六的丽天僧例结合河魁临卯命、驿马临行年及既知缠扰背景断相携而逃之意，不抽成“双动象必逃”通则。

### 空亡例外与出行（问答录扩展）

动象在空亡与方位上的例外判定：

1. **旺火逢空仍可燎天**：干支上临时令旺气之火，虽落空仍具燎天之势，马星虽空仍可出行速动——空亡≠不动，须辨时令旺衰。
2. **罗网逢空即解脱**：天罗地网（辰戌）临日主受困，但网逢空则"网空即脱"，原例断解脱而去；仍须核本问确受何种罗网、空的是何物及其他制约，不将原例结论推广为任意辰戌逢空必脱。
3. **马星坐墓落空纵动无终始**：马星虽临干但坐地盘墓又落空→不能行动，纵动亦无终始（进京不得意而归）——与旺火空亦动构成空亡动象对照组。
4. **支干定位出行法**：支为城/干为城外（占居处），干为陆路/支为水路（占出行）；支二课皆鬼则城不可居、干二课皆空则外不可居、干支俱被上克则水陆皆不可行。
5. **一旬周遍格去而复来**：三传一旬内周遍，《毕法》"交加用事，去而复来"——原例兼有一旬周遍、自干发用、末传为支神及六合，再断回归；单独末传归支不保证现实必回。
6. **干支互乘败气**：干上支上互乘败气为败坏之事（不正当关系缠扰），可配合动象断缠扰与去而复来。

- 传将逆行在原法占官当退、行人当归、出行不宜强进的语境中用；不是任何逆序都定失败。
- 中末空亡、有始无终与初传吉分判，升迁可成而不久，不能因初传吉统断全吉。
- 原局引动、流月流日触发、另起课分层；流时不重排原局课传旬空乘将。无有据通路就不强编动态事件链。时间任务另按 timing 定期，动象不代替定日法。
