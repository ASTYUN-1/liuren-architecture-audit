# 50版：基数、气态与数量兑现

本页分清三种身份：北海著作及所引原法、其他作者书例、用户2026-11-12指定的研究采用口径。连续原文和原始文件哈希见quantity-correction-evidence；本页归纳不构成预测验证。

## 一、原文支持什么

QC-01《理法简易》3317—3335：引原法“财旺则相因而倍进，财相则计其所因以为数”，休不相因、囚死减成数之半；北海解为旺倍进、相乘、休加、囚死加后折半。原段是财占，不能只取其中8×9便称已完成现实数量。3331“旺相”与后句“相”文字重叠保留校勘身份，不默改原字。

QC-02《64课经精讲解注》4057—4084：课经“数目颜色言倍者，加一倍也。言进者一十进一百也”；北海解释“数目、颜色、新旧等，都依旺衰等来推……加就是加倍，进就是进位”。同段又列乘得54或加得15，明确这些用法复杂。它说明有按气态改变算法、倍数和量级的分支，不是任何公式均可自动进十倍，也未给综合指数的线性换算。

QC-03《理法》6671：北海转引邵彦和林子成旧例，“申七辰五，五七三十五，空亡减半，得十七年”。身份是所引旧例，不是北海独创的统一分数公式；35/2=17.5，原载17的取整缺口保留。不因此恢复出生运限。

QC-04《金针》原载求财例：巳四数、巳双得八，再因月将旺相论8000元。双数和量级分别有依据，不能把任何相乘数当元数。QC-05—07天一群笔记分别记水、胜晏理等人的减半和断数，不能署为北海本人方法；其中436分例的拼位等步骤不完整，不激活为通法。

以上支持“数随气变、基数须检验后才作为现实量”的方向；没有发现北海把本机工具4—7分定义为直取区、2—3分定义为折半区的原文。

## 二、用户本次研究采用口径

常数直取、加乘等先得到基数；实际数量须结合综合旺衰、旬空和兑现条件判断。以本机基准5附近为参照，气态和实现条件平稳时可以保留基数；明显不足或过盛时应实际考虑减增。用户所举4—7、2—3折半是近似研究示意，不是硬阈值、失用线或已校准公式。强弱不等于必成败，现有旺衰参数不改。

允许以有源方法及已核实际作用作比例估计，身份标为user_research/model_estimate，不再因古书没有唯一精确系数而一律不调整。系数必须解释与基数参照、气态差异和兑现份额的关系；不可只罗列几个气象便从56随意改58。不把指数/5作为自动通法；若个案用比例估计，应说明选取参照和适用原因，承认其研究估计身份。

对于分数、实得金额、件数、重量等基数转实际数量的问题：数量主类在所判阶段本身旬空，且本数尚未包含该项数量折减时，默认执行一次数量减半；若原法另有明确处理、未来阶段有可靠解除依据或该数的含义不宜折半，必须具体说明例外，不能仅写“未执行”。将空、坐空、身空不自动等同数量主类本身空，不把状态层统一清零或折半。名次数字、类别编号、日期及原始常量不机械减半。

## 三、执行顺序及防止重扣

1. 固定所求量、主类、位置和阶段，说明采用数法。源法中的旺相加乘、月建月破等已含条件逐一认清，不能把已完成气态分支称为毫无修正的裸常数。
2. 调用quantity算基数；调用或复用本问实际strength回执。涉及外来作用时仍依原法选择关系并补算，不把单宫冒充整条作用链。
3. 决定剩余修正：基数可用、数量减半、其他比例/加减或有据量级变化；明确原法/用户研究/模型估计身份。未量化的专项也要依原法考虑。
4. 旬空与气弱可能是同一原因。若数量比例0.5已包含这次旬空，不再乘0.5；若气弱另有独立原因且还须空半，分别说明。本次数量修正与strength状态已经计空属于不同层，不能以状态计空抵销尚未执行的数量修正。
5. 用quantity expression实际运算最终值。正文一条链即可：对象与阶段→基数/已含条件→实际旺衰→增减及理由→最终量和单位。需要取整也明示规则和实际运算，不暗改尾数。

示例只用于说明算术：56按一次数量空半为28，不会因此得到22；40按半数为20。没有原盘与独立形成的修正规则，不能以已知22倒挑系数。基数保留需说明理由，不强迫每题改数；无可辩护估计按47版说明具体缺步，不能编数。

## 四、核对实际执行

新绑定数值问在现有audit增加每问一项quantity_reviews，绑定真实基数、strength和最终quantity回执；依序登记有来源身份的乘/加步骤，以及旬空已扣、已含、例外或不适用的具体理由。此为同一轮数量判断的紧凑核对，不新增裁决者或补核次数；正文不要求长表。

程序检查回执属于本任务、主类一致、声明步骤与最终值的算术一致性、数量旬空是否有明确处理。缺项或错算标核验未完成；原有一次补核后仍未解决则显式交付缺口。程序不能证实系数的专业合理性，不能证明模型解释充分、最终预测命中或审查没有遗漏。语义正确性仍须主智能体核原句和依据。
