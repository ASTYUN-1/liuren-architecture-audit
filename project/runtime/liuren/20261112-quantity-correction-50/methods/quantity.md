# 数量、量级与精度

## 50版数量兑现：用户研究约定与实际执行

原书数随旺衰增减的方向与本机指数的比例估计分开。基数是中间结果；查本法已含的旺相加乘/休囚分支后，核综合旺衰、旬空及实际实现份额。允许有依据并标明身份的比例估计，不能因为无唯一古法系数便跳过；不把指数/5作为自动通法。用户所举5附近、4—7直取及2—3折半是研究示意，不编成硬阈值或失用线。

分数、实得钱物等数量主类在所判阶段本身旬空，基数尚未含该数量减损时默认实际减半；状态层strength已计空不能替代。数量比例已含同一次空减则不再乘半；独立气弱与空半叠加须说明独立依据。其他空位、序数/日期/编号不机械套用；源法或可靠阶段解除有例外须具体说明。56乘半是28，不能见已知反馈22再倒选系数。

数值问沿同轮判断给audit.quantity_reviews，每问一项，绑定真实基数、strength和最终quantity回执，登记修正步骤及其原法/用户研究/模型估计身份、旬空处理及正文引句；详形状见consistency_guide。保留基数也说明为何可用；无可辩护估计则登记unresolved和具体缺步，不编数或把基础数冒充最终量。主智能体沿原calculation_scope核算术、职责和比例理由；程序仅核回执与声明，不验证专业准确率。详见quantity-correction及其原文证据。

同一 `daliuren` Skill 内的条件方法。只在原问要求金额、分数、数量、重量、距离、名次、序位、等第或进退差值等数值，或所用应期专法确需数日时读取；问财运、考试或寻回而未问数，不自动展开。沿用占类、定位、理气和制救已经核过的对象，不另起一套取用。时间任务仍由 [应期](<timing.md>)确定事件、尺度和起算点。

## 数字的含义先于算式

物数、连续量、序数、等级和变化量分别确定对象；无形目标也可取数，不因没有实物或满分一概拒用。名次第几、前后次序、几等奖及进退几名按[名次、等第与变化量](../references/quantity-rank.md)查适用专法；总榜/分组榜、人数、并列规则只在相关时纳入，不把评分制当作所有名次题的前提。百分比要明确分母；已有旺衰指数不能直接转成分数、百分位或概率。

先选对象和有源适用方法，再取数。具名工具目录只是已实现算式，不是数法全集；目录无匹配时沿现有reader查原书/参考，完整有据的算式可用quantity expression计算。工具拒绝某个参数或问句只说明接口问题，不替代术理判断，也不得虚构工具没有返回的拒绝理由。需要补充信息时指出具体缺步，不通过改写原问来规避检查。

## 六环执行

| 环节 | 本问要固定的内容 | 关键区别 |
|---|---|---|
| N1 对象 | 谁的什么量，哪个类神/课位，取天盘支、所临地盘、乘将还是特定遁干，理由和出处 | 总额/实得、原始分/赋分、距离/方位、最终名次/变化名次/等级不是同一对象；不由“问数”统一改取财爻 |
| N2 数制 | 实际数字映射、输入位置及来源；需要时查 [数法来源与条件](<../references/quantity-sources.md>)或对应原书 | 同名数表未必同表；同表多名不算多种验证。旬遁、五子元遁、藏干和天将不混用 |
| N3 运算 | 采用直接值、加、乘、重复倍数还是分项合计，说明本法条件 | 相乘与相加不可因算出值不合期待而互换；重复倍数不等于十进位 |
| N4 增减/组合 | 每次修正的对象、触发和幅度；主数与零数怎样组合 | 旺衰在本式承担哪一职责须说清；同一条件不无据重复加倍、进位、折半；多触发的先后未明就保留缺口 |
| N5 量级 | 为什么为个位、十、百或更大，是否进退位及依据 | “旺多衰少”可说明相对大小，不能单独指定十倍/百倍。题干上限可排除越界，不能单独证明剩余某个值 |
| N6 单位口径 | 分、元、件、斤、里/公里、天、名次及等级口径等；总数与分笔、毛额与净额、原量与换算值 | 古代里制、钱贯、锭件须另核；物理单位换算与术数倍率分开 |

这是检查职责，不要求每问机械写六张表。已有完整、有出处且适用的数法可以直接形成点值；不因尚无统计校准就一律拒用。原法只给相对大小或若干量级时，就保留该精度与未决条件，不用现实猜测补成“精确推得”。区间、中心值与点值都要有形成依据；人数中位、候选平均、可见几个同类宫不能无据变成当事人的排名或全体样本。

## 精确数与后位

先声明点值、近似值、离散候选或区间，以及题目要求的允许误差；“450附近”与“恰为450”分别判验。精确个位可来自完整算式，不必逐位编码。若本法确实分主数和尾数，须有各部分节点、组合、进位及零值处理；不能把干数当作十进制数字表，或默认天干百位、地支个位。

源文有直接精确断数而步骤省略时，保留原断及省略处；读者复原只能标假说，不能补写成作者规则。多法冲突时按适用条件和直接性裁决，不取平均或轮流尝试修正直到接近期望值。原问有范围、历史成绩或预算时标作题干约束，区分它与课中独立推出的部分。

## 与主线和交付的接洽

数量判断复用第3—8环节结论，在第9环节与应期分别完成。问有无收益不被金额算式替代，问分数不被通过与否替代；专项中发现真实定位或规则错误时，按 [理气的依赖重评](<liqi.md>)回查受影响结论，记录原因。

在原报告逐问结论中给一条可复核记录即可：**对象/位置 → 数表和算法 → 条件修正与量级 → 数值、单位、精度及未定处**。非数值题不增加这项。反馈前固定算式及候选；反馈后分评口径、量级、点值绝对/相对误差和作答覆盖，原断、反馈、注解分存。完整记录与静态检查都不能证明准确率提高。

本规程为2026-10-27研究整理；六环是工程归纳，具体数法的身份、条件与异文见所链接来源，不当作古籍统一算法。


确定性工作与交接按[程序事实接口](../references/deterministic-tools.md)执行。位置/阴神/查表/算式由程序给出，关系效力仍核原法；应期与数量任务保留完整专法记录，正文不得被简短结论替代。


## 35版确定性工具层（主、子共同执行）

AI依原书取用、选法和裁决，工具提供确定性计算，不自动选择应期或裁成败。月令五气、十二气、空亡位置与综合旺衰分数分别保留，不能用分数重写原始状态。

取数先用liuren_compute(action="methods",methods={kind:"quantity"})查具名方法和必填条件，再用action="quantity"及quantity_method调用；expression仍兼容但不与具名方法混用、不无据叠加倍率。工具读取盘面和本法数表，不能凭量级候选或base-only基础数冒充最终数量。方法适用性、单位及量级依据由AI确定；程序数值直接采信，不重复手算。首批CY501-use-ground、WY244-month为明确分支，WY67-shenjiang-base、WY242-generated-base仅基础步。

calendar复用排盘引擎历法，支持节气/节月/旬界/日界准确时刻、值冲合筛选及日内采样；日柱与时干共用所选00:00/23:00日界。出原旬与旬名重复分开，关系事实不等同已经填实或冲开。evaluation将指定日历时间交给单宫/明确取用关系的旺衰计算，原盘坐标及原日干不变，不自动选择最高分日期为应期。

空亡系数和现行直接作用范围保持34版；evaluation默认original保留原空亡，仅按评价节月更新五气；evaluation-xun-research是新旬替换的明确研究情景，不是已经定案的出旬/冲实算法，不能按结果切换政策。三合、半合、三会数值继续暂缓。

需要辨物态时先methods(kind="imagery")查适用原段，再以imagery返回材质、新旧、阶段、空实等条件候选；没有匹配不等于无物或失败，射覆专法不直接推广成人事成败。专业报告仍自由撰写，不增固定裁决字段。详细参数见deterministic-tools；默认盘不附整套数法、判辞和审计。


41版：数值题必须查quantity-strength。strength计空不表示quantity已减数；区分状态层、数法层、数量修正层。基数后核气态及空亡是否另需有据修正，禁止遗漏或同层重复折减。新增LF3329-class-ground与CY501分支分开；calculation_scope=false表示本次未算，不代表本案不必考虑。

## 用户有数字意图时先完成数值回答（47版）

识别原问及上下文的数值意图，不要求用户说“取数”或使用固定关键词。“大概多少”“你给个数”“最可能排第几”等均应沿原任务接数量方法；结合上下文核清所指对象，不把用户只问有无、成败或前后倾向自动扩大成精确数字任务。task_basis保留原句及上下文理由，接口词句识别不替代语义判断。

先选对象和适用方法，查看所需原法，执行必要计算与有据修正，再在逐问结论给一个最有依据的具体数值及单位/名次/等级口径，例如“主估约N分”“主选第N名”。范围用于补充误差与条件；用户只要区间或候选时按其要求。不能默认只给区间、只说偏多偏少或仅列出方法而不尝试得数。

“具体数值”可以是近似估计，不要求已有唯一算法、统计校准或保证个位命中。允许结合有源数法、已核作用及题设约束作可解释的近似推估，说明其中哪一步是推估以及为何选这个数；不能将其冒充程序精确算出或古法明定。区间已有依据且中心值有代表性时可以选主估值，但不能无据取中点或平均候选。完整有源算式可直接形成点值，不把“还没有精确通法”当作停止理由。

确实查不到适用方法，或关键取位/运算/量级映射未明到无法形成可辩护估计时，具体说清查了什么、算到哪一步、还缺什么，给现有方法支持的程度；不虚构一个数填满答案。缺口应针对该数值，不扩大为“这种事不能取数”。已有可解释估计时，以“约/主估”标明一次，不再用后文将答案全部撤回。无需重复查同版已读资料，也不增加裁决轮次。

主智能体沿现有answer_constraints核“用户要数却只给定性或范围”，沿calculation_scope核尝试和估计依据。若报告有具体缺口，附原句及绑定规则走原有一次补核；主智能体不自行补数字或改裁决。程序继续只做计算和传输，不以数字是否出现自动验收专业正确。
