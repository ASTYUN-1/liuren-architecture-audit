# 空亡与变质：分对象、辨真伪

执行采用judgment-core的U01—U11；本页引文是来源材料，不恢复已停用的相反指令。历史C01—C11的关闭或重新分类见pending-conflicts；明确的分层、阶段及条件解释直接执行，只有完整上下文不能化解的同条件互斥才列真正矛盾。

空亡核查在同一判断主线内完成。类现、空陷、变质各有原法条件，不能由“类现”“有空”两字直接结案。

## 执行

1. 使用程序给出的原局旬空、落空、坐空与天空天将，分天盘支、所临地盘、乘将；日寄宫、该宫上神与日上神不能混同。定位所空是身、病鬼、财禄、救应、罗网或其他对象。
2. 比较月令、坐处、生扶来源、施受方向和制救。神生将、神受其他节点生扶、神临空地不是同一关系；作用判断不删除原局旬空字段。
3. 按U08及U10分析空的事实、综合效应及时间变化。下列摘录保留原法身份，不允许任择“空必败”或“旺必不空”；由裁决者依实际组合分析，只有缺少决定性事实或同条件原文确实互斥才具体报告；C04保留来源措辞的复核记录。
4. 对关键节点核闭口、破碎、凶将、阴神/遁干鬼、墓和丁等变质条件，说明伤谁、何层、是否切题得力。财可得而因财受伤、财难到手、发生支出是不同判断，不设统一吉转凶开关。
5. 合并气态、切题组合与制救，说明净影响、最强反证及未定条件。填实/冲空/出旬按所选应期法另论，不重排原局，不由日期反证事件必成；关键依据改变则重核依赖结论。

## 生扶、填实与实现的选法分路

| 来源 | 原方法及条件 | 采用范围 |
|---|---|---|
| 特训班讲义 LF78–81 | 分房例：亥空先待辨；亥于酉月相气、支上申生亥且申入中传等，作者以“旺不为空，得生得助不为空”判房可得 | 复现该法须保留对象、位置、气态和生扶通路，不扩成凡生即成，也不删除旬空事实 |
| 理法简易 LF2749–2751 | 有生也为空；财空逢生只是有些意向而终究未得；反对以岁月日时年命填实为不空，并要求依课体总气势灵活对待 | 原文强度保留，执行按U01/U08，不把绝对强语当开关；具体实现依U08综合分析，C04留存来源措辞差别，不虚构“特殊生才解空”或著作年代先后 |
| 壬归 LF293，求财例 | 神临空地，即四吉也非吉；惟神生其将、神自作空者尚有出旬之望 | 严守神→将方向、神自空与求财语境；不是神得到任意生扶即可不空，也不是所有坐空皆出旬可得 |

原局事实、综合状态、实现与应期按U08/U10分开。此分析口径已确定，原书并未因此字面一致；不设未经确立的数值阈值，也不以缺少阈值为由要求用户确认每种组合。

## 对象与作用边界

- 生我救我者不宜空、凶神刑冲破害宜空，是《理法简易》LF2744–2745该段原法。LF2771–2772、2790–2791又谈凶性或谋害类象空而无力/事不发生；LF2800–2802在天官作日鬼空亡后说玄蛇空反凶，LF2802还作一般化扩展。条件语境须分别保留；同书文字张力未完全化解，不能把某一处合成所有凶将一律免祸或一律更凶。
- 三传空按位次和对象分：初空末实、中空、末空所限阶段不同。初传有力不自动等于初传吉；有始无终、成而不久与绝无开端不混同。
- 病占先辨真实病程、患者、病神、身禄和救应。理法简易LF2746–2747、问答录二LF76有病空/身禄马空及新久病的强断，按原对象和组合保留；年龄不能代替病程，病鬼空与救神空不互代，原载断语不当现实已证。
- 事类宜忌决定空的作用：财禄救应不宜空与障碍/罗网宜空分别论；金鸣、水流、木朽、火发、土崩不能取代事类。旺火空仍动，与马坐墓又空而纵动无终始另核；能动不等于到达或久成。
- 日寄宫空不能静默改作日上神空；脱上脱、脱气乘玄武、脱空、空上乘空四种构成不能互代。涉及该专法时，读 [空亡条件参考](<../references/void-method-conditions.md>) 的相应段；该页同时保留寄宫、动静与空鬼的原法来源和边界。
