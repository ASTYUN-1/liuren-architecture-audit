## R — 原文 (Reading)

> 时运课，是综合运势的判断，运势涉及健康、婚姻、财运、官运、出行、家运等方面，课传中显示出什么，就断什么。……首先要看安全与否……凶象，即太岁、岁破、勾蛇虎空玄等作日鬼或克行年。……占时运问收入，看父母爻、日禄之虚实旺衰……占时运问家运，看支上……占时运，注意课体，逢吉课则吉，遇凶课则凶。
>
> — 北海闲人，第五讲《时运》

## I — 方法论骨架 (Interpretation)

> 2026-10-19执行口径：下列原有方法保留出处；应用时按 E 节核对本问、位置、状态和最强反证，不能将单项命中或作者“必”字作为提前结案。

时运课是"泛占一段时间运气"的综合课，问题没有单一类神。作者把判断拆成一组合的逐维检查清单，核心逻辑是"课传中显示出什么，就断什么"——哪一维有明确象就细断哪一维，无象的维度不强断。

1. 先验课体定大势（吉凶先验）：吉课（龙德、铸印、互生俱生）整体偏吉；凶课（天网、解离、芜淫、鬼临三四）整体偏凶。
2. 安全维优先（凶煞优先法）：吉象=长生、父母爻旺相；凶象=太岁/岁破/勾蛇虎空玄作日鬼或克行年→死丧、官司、病伤、盗贼。安全不过，其余各维全部打折。
3. 收入维：看父母爻、日禄的虚实旺衰；空陷或乘凶将→减薪减收。
4. 婚姻维：六合、太常旺相生合干支为吉；怕解离格、芜淫课。
5. 官运维（有官职者）：贵人、青龙、太常作父母爻/长生爻→有升迁之象；怕勾虎克干克行年。
6. 家运维：以支上为主，喜生气，怕支上作鬼。
7. 看课重点：干上（我之所遇）、支上（他人他物）、三传（初中末三阶段）；重神、夹、空、墓、拱、并聚等"纠结之处即显明之事"。
8. 年命锚点（g13）：年命入课传看本身、不入课传看年命上神；行年上神代表占者当前状态。
9. 产出：逐维结论 + 综合吉凶定性 + 特别事件提示。有官职者"官比财更重要、发用比末传紧迫"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 乡镇干部问时运 (c15)
- **问题**: 有官职之人占时运——时运涵盖官运、财运、健康、灾祸。
- **方法论的使用**: 干上戌作六合临门户发动→有行动之象；"动往哪里"看其阴神=官星太常→官职变动。但巳火太常月破又岁破→疑丢官罢职（凶象）；再看支上卯作月将生起巳常、又作太阴→巳"破而不破"（挽救象）。按"官比财更重要、发用比末传紧迫"取行动之象，以阴神定去向。
- **结论**: 官职有变动但不会丢，是平调。
- **结果**: 后果乡镇撤并，自己调到另一镇，职权不变。

### 案例 2: 事业单位职员占时运 (c16)
- **问题**: 男性职员占时运——重点看有无升迁、工作麻烦、私事、财运、身体。
- **方法论的使用**: 逐维过：课传纯阴+遍地贵人→贵人=职责驱策、阴晦太重无阳气→暂无升迁；纯阴主阴私（家事婚姻）→末传丑为天喜、酉加未发用→下月有婚姻之喜；蛇雀乘酉、酉带日鬼→目疾、咽喉肿痛、身体不佳；末传丑为腹生酉→饮食建议。
- **结论**: 暂无升迁、忙乱于工作；下月有婚姻之喜；身体（咽喉、眼睛）有疾。
- **结果**: 反馈逐条应验——受领导器重忙得跟头把式、打算八月份结婚、喉咙不好眼睛发红、装修房子心里烦乱。

### 案例 3: 某领导占有无升迁可能 (c17)
- **问题**: 领导占时运，核心问有无升迁可能。
- **方法论的使用**: 官运维：干支上皆乘墓神、鬼墓发用→墓主阻滞，既不能升也不能迁、工作繁剧；天后主厌翳不明→运势晦滞。安全/官司维：鬼墓带勾陈克干→会有官司缠身；末传寅克掉鬼墓→不成凶象，只是暗中寻人。家运/单位维：支上太常→单位尚稳，但墓覆支=走下坡路。
- **结论**: 不升不迁，运势晦滞，有官司纠缠但可化解。
- **结果**: 两年后仍未升迁，退休年龄快到；07 年单位被审计罚款、内部有人告他，但没出问题，只是工作很忙累。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 泛问未来一段时间运气："看看明年怎样"、"这段时间运气如何"、"眼老是跳，会有什么事吗"（书中原文列举的三个常见问法）。
2. 用户只给身份+笼统担忧（如"我是公务员，最近总不顺"），未聚焦到单一问题，需要五维扫描定位。
3. AI 端作为分析框架：当用户输入不足以确定单一占类时，用五维清单生成追问清单，或给出初步综合判断。

### 与相邻 skill 的区分

- 与 `cailu-panduan`：时运只把收入当一维（看父/禄虚实旺衰一句）；财禄 skill 专断收入六条件与纯财类神、脱气/破碎/三传全财大忌。

## 本占类的理气落实

按用户关心的事业、财务、关系等维度选关键节点，不把同一结构重复变成多项独立验证。日干上神与三传的当期/全局读法须注明所用体系和时段；每一维比较本体与对象的强弱、坐处、制救，年命未核只影响对应分支。

## E — 可执行步骤 (Execution)


1. **定义时段与现实身份**：确认是阶段综合运势，而非一个具体事件；记录题干已知职业/关系与年命，缺项不推造。用户已给核心问时优先回答，不能用五维泛论覆盖。
2. **背景与分维并读**：沿用安全、收入、关系、官运/工作、家宅五维；各维有明确象才论，标对象、位置、作用时段。背景只作暂定框架，不因一个安全凶象自动压低全部维度或直接定死丧。
3. **跨维核对**：同一象可能表示职责、压力、收入等不同层面，须说明选择理由，不把一种不顺扩成处处不顺。取最强反证检查，发现救应时重新确认作用范围；一维变动不等于其他维度同向。
4. **输出**：各维结果及边界、共同主线和有依据的转折；工作内部事务可路由应聘/升职，财务路由财禄。无象写不足，不按固定数量编特别事件。

保留上文 c15–c17 的逐维论证，参照 M06 的分年分问组织；不是整体命中验证。共用 [判断方法规则](../daliuren/refs/judgment-workflow.md)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问单一具体事项（能否买房、能否升职、能否怀孕）——用类神侧重或对应专项 skill，综合断法会稀释结论。
- 用户未提供可起课的时间信息（月将、时辰）——无课传盘面只能做追问框架，不能断。
- 占终身、逐年应期——那是 `zhongshen-nianyun` + `yingqi-panduan` 的领域。

### 作者在书中警告的失败模式

- ce05（白虎）：见虎即断死丧大凶，忽略"壬占最重位"——白虎作阴神只显象不主吉凶、发用才主吉凶；长生带白虎=先吉后祸（先得死丧之财、后有横祸）。时运安全维必须查虎的位、受制、克谁。
- ce06（勾陈）：只断官司打斗，忽略"迟滞"义——勾陈临干或作大运主题=运势极度低迷、像时间停止、麻烦不断，恰如被捆住手脚。
- ce11（凶课体）：只按类神断而漏课体凶格（天网难逃、解离婚姻先好后坏、芜淫私情、干支乘墓为"止"）；吉课体（轩盖课）遇空亡变质转凶（乘轩落马→丢官罢职）。且同一课体吉凶随占类而变（解离问婚姻凶、问牢狱反可逃脱）。
- ce12-ce15（公共边界）：全书案例全部"果应"=幸存者偏差，不可当统计证据；同一课可多解、结论对侧重选择敏感；象意系统模糊、无预注册检验，命中率未必高于随机；干支五行映射人事是未论证的信仰前提。

### 作者的盲点 / 时代局限

- 案例集中于 2004–2009（股市、房改、金融危机），经济语境过时；方法论本身不依赖时代。
- 五维"课传中显示出什么，就断什么"的对应关系被默认为稳定唯一，实际同一课不同侧重可得相反结论（ce13）。
- 反馈多为占者事后自述、时间跨度短（多为数月），缺乏长周期检验；"果应"=判断正确未被证明。

### 容易混淆的邻近方法论

- 时运"安全维"与 `xiongsha-suduan`：本 skill 用凶煞作安全闸，凶煞 skill 是独立否定工具；"先凶后吉、找凶的充分理由"是作者明示的速断顺序。
- 时运"官运维"与 `shengzhi-jiaxin`：时运只判有无升迁之象，升职 skill 判"能否升"（进达象）+ "能否加"（增益象）两象。
- 时运"婚姻维"与 `lianai-panduan` / `renji-guanxi`：时运是粗判；恋爱 skill 断"成否"，人际 skill 的 p26 框架断夫妻相处态度。
