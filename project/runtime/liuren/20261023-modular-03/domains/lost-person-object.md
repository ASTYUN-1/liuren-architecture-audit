# lost-person-object 占类方法

来源方法：`shiwu-xunren`；依总入口加载，完整条件见下文。

## 判断流程

1. **确定对象和已知条件**：物品、人或宠物，最后确认出现时间、可能范围、是否题干已说明找到。丢失、遗忘放置、借出/转移、被盗分别作为原因候选；题目已确认在场所内就不强加盗窃情节。
2. **先辨原因，再判寻回**：依据对象性质与来源明确的方法取类神，说明位置、旺衰、空墓、阴神及引动。玄武出现只是候选信息，须有针对盗窃的支持与反证；能找到、已找到、何时找到分别判断，方位取象不能替代寻回依据。
3. **空间信息分层**：分近远、内外、遮挡/容器、环境和方向；每项标明采用天盘、地盘、类神临处还是阴神。多个锚点冲突须解释选择，不将各方向任意并成全方位。
4. **距离/数量独立推导**：原书数制和里数公式只在相应条件下使用，列数源、单位、倍率；不能直接换成精确现实距离。没有可靠规则只给空间层次，不硬算。
5. **时间与结论**：先定义发现线索、相见、自回、寻回物品或追回财物等节点，再接 [yingqi-panduan（方法模块）](<../methods/timing.md>)。人/宠物的状态不由单一墓空判死；信息不足就保留未知，不编精确地点或确定指认盗窃者。

需要古典盗逃四步、勾玄关系等细则时加载 [zhinan-zhanbing（方法模块）](<classical-conflict.md>) 的对应部分；兵占攻守部分不用于普通失物。输出每问判断、锚点、支持/反证及边界，可给有依据的优先查找环境，不声称现实已确认。
