# 理气分析与救制裁决

用于所有大六壬判断的关键节点。以《壬归》《献给六壬天一群的六壬笔记-2023年》为主要理气依据，保留北海方法的具体条件。书籍是方法依据，本文的检查顺序是工程整理；两者均不等于预测准确率验证。

原文定位见 [来源与适用口径](<../references/liqi-sources.md>)，逐条引文与文件哈希见 [理气引文映射](<../archive/previous-package/.opencode/skills/daliuren/refs/runtime/sources/snapshots/.opencode/skills/daliuren/refs/liqi-source-map.json>)。神煞另读 [神煞取用](<../references/shensha-use.md>)；疑难处参看 [正反对照](<../references/liqi-examples.md>)。

完整断课还须执行 [八煞九宝综合核查](<../references/bashajiubao.md>)：德合禄、生扶长生生旺及刑害鬼墓空等，本就包括理气关系与状态，不能缩成神煞名单。月煞生气另核；主要看神将状态，普通神煞辅助，见 [必查32项](<../references/shensha-focus.md>)。

## 表述范围：单项不足与结果排除分开

本文“有克不等于制得住”“长生不直接等于存活”等，是限制仅凭单项关系定结果，不是否认它在条件齐备时的作用，更不排除受制或存活。写新规则时同时写清对象、适用条件、保留可能与后续判断；具体见 [规则语义](<../references/rule-semantics.md>)。明确的计算定义及有据排除仍保留其强度，不一概软化。

## 1. 固定对象，区分关系与作用

先明确所问人物、事件、阶段和时间范围，固定日干、日支、患者/代问者、类神及年命的对应理由。日支已取为宅时，不因流月冲支便直接改称“冲身”；更换取用须另有本问方法依据。

对参与主判的节点，记录地盘宫、天盘支、乘将、上神/阴神、必要时的旬遁干。天盘某支出现、某支临地盘年命、年命宫的上神，是三种不同位置关系，不能互相替代。阴神通常为该天盘支对应地盘宫上的上神；确认当前方法的定义，不把原位乘将、本支六合或任意下一传都叫阴神。

先记录“甲木生巳火”等关系事实，再判断它对具体对象是否有利。生可能扶助病鬼，克可能制病也可能伤身；类名“子孙”“长生”“贵人”先提供取用候选，不自动提供有效救应。

依据 RG-01、RG-02、RG-15、TY-01、TY-02。

## 2. 对关键节点检查得气与受伤

每个实际支撑结果或最强反证的节点都应完成以下相关检查；同轮同一节点可复用。缺数据标未知，不把未检查写成无影响。不限于三传，也不无差别遍历全盘。

| 项目 | 检查内容 | 所需判断 |
|---|---|---|
| 月令五气 | 依所用历法口径定季节和旺相休囚死；分清神、将各自五行 | 本方与作用对象的强弱；五气不是日干六亲 |
| 坐处与十二气 | 明确是在论日干、类神还是天将，比较该对象与所临地盘 | 得地、失地，或该层只提供类象；不是看到“病”字便断人有病 |
| 生扶与泄耗 | 谁生谁、谁脱谁；生扶来源是否自己受制、落空 | 有来源的扶助是否能到达目标，是否扶敌或耗身 |
| 克制与救制 | 谁克谁，施制者与受制者各自力量、位置和其他关系 | 有克的关系不等于制得住；制住一项不等于全局无忧 |
| 神将与内外交战 | 分列地盘、天盘、天将的生克，不混淆天将本气与所乘支 | 按所用方法判冲突作用于神还是将，是否使类将无权 |
| 上神、阴神 | 检查对原节点的生、克、脱、合及对本人的作用 | 表面有情但暗受制、明吉暗损、能扶类而可能伤身等 |
| 刑冲破害、合与空墓 | 定方向、参与对象、位置、旺衰及成立条件 | 约束、损伤、冲散、牵连；合不自动化，墓不自动制住远处之神 |

对旺衰关系，只在有相应事实与依据时判强弱，不编百分比或逐项扣分。旺者若为所忧之病、官鬼，得旺可能加重风险；欲脱散之事渐无气，与欲进取之事渐无气，意义相反。类神旺，还须看本人能否承受和取得。依据 RG-03、RG-05、RG-06、RG-11、RG-12、TY-03、TY-04。

### 内外战的具体口径

采用《壬归》卷一此法时，完整链为：地盘克用神、用神克天官，称内战；天官克用神、用神克地盘，称外战。部分资料又用“神克将”“将克神”概述神将不和，应注明它是在概述还是已满足完整链，不用单一关系冒充完整格局。《壬归》求财章对内战其将、外战其神有轻重说明，此轻重仍须保留该求财条件，不改写成所有案件固定几级的权重。依据 RG-04、RG-07、RG-09。

## 3. 分清五气、十二气和六亲的参照

- 五气随四时：由月令判断相应五行的旺相休囚死，不能由日干的六亲替代。日干六亲、月令状态分别记录。
- 十二气有参照对象：《笔记》的十二长生总论以日干为准；《壬归》类神临地法考察类神自身与坐处。论天将自身气数又是另一层。使用时写明“以谁为本，在何地”，不能从甲木长生跳到申金长生而不说明。
- 不把不同层次相加计票：日干得长生、长生所在支自身失地可以同时成立，须判断哪条作用直接对应本问。
- 遇到土寄生、阴阳顺逆、月令用节月还是其他约定等资料分歧，保留选定来源和差异。关键结论对口径敏感时给条件分支；不能为贴合答案改口径。
- 一个“衰”字不取消月令生扶，一个“生”字也不能免除临克、内战、空墓。没有充分依据不预设任何一层永久优先。

依据 RG-03、RG-08、TY-03、TY-07。

## 4. 合、刑冲破害与遁干

先写参与对象，再写关系和作用。合为联系或牵制的候选，不能直接等于成事、治愈或合化。半合、月建补虚、四纲引化等，须分别定位来源和条件；《笔记》的四纲合化条件作为该书方法使用，不自动取代所有流派。

冲作用于谁：冲开墓、冲散病邪、冲伤病人或冲散救神不是同一判断。刑害也需核对能否实际作用，不因名称自动判灾。空亡使哪一方无力、是病空还是身/禄/救神空，必须说明，不能只因新病或高龄就预先固定其义。

关键节点的遁干在能揭示暗鬼、合联、扶损反证时定点查阅，记录相对谁论六亲。不得由一个暗鬼直接跳到死亡，也不为每个宫位扩出多层新人物。阴神默认先看直接一层；确有未解决关系才继续，说明新增一层解决什么问题，并在重复节点或无新增证据时停止。

依据 RG-02、RG-13、RG-16、TY-05、TY-08、TY-09。

## 5. 裁决救制的作用范围

救应进入结论前回答：救谁/制谁，实际作用关系，自身得气与否，能否到达目标，是否另有刑合空墓或阴神损伤，以及解决的是哪个阻碍。状态未知的救应只能算候选。

按作用事实区分三种情况：

1. **阻碍仍在，只有局部缓解**：作用只覆盖过程或某项损失，不能扩大成全局成功。
2. **关键阻碍确实被解除**：重新判断主结果，可以修订初判；《壬归》有末制凶神、课内制鬼而转凶为吉的方法，不能以“救解绝不改方向”禁止复核。
3. **作用条件矛盾或缺失**：保留分歧和条件结论；不能凑足吉名换成“有救”，也不能为了维持凶断屏蔽有效救制。

《指南》局部减罚未改去官结果的例子，保留为该例方法；它不是所有生死、考试、财务题的无条件禁令。反之，某一存活案例也不能推出“元胎有长生便可苏”。依据 RG-05、RG-10、RG-14、TY-10。

## 6. 结果依赖与必要的重评

保留简短可核对记录：本问结论、主要依据、最强反证、取舍理由、未确认前提。把同一支兼德禄解神归为相关信息，结构派生的多种课名也不算独立验证。

主要依据被撤销、起法改为存疑、年命口径改变时，回到受影响节点检查，再重新裁决依赖它的结果、程度和应期。允许原结论仍成立，但须说明剔除该依据后剩余理由；不能仅说“方向不变、程度下调”。也不能事后增设原规则没有的翻判门槛。

当剩余冲突不足以裁决，明确偏向及边界；确定性不足不能靠扩大日期窗口或改换成功标准补救。最终报告只展示决定性关系和取舍，内部检查齐全不等于报告必须罗列全盘。

## 7. 与时间及反馈的边界

原局四课三传、旬空及坐处不因未来流日到来而自行重排。流月流日的生扶、刑冲、填实或另起一课，分别说明规则与层次。应期只在已定义事件或条件分支中选择，不能从候选日期证明该事件一定发生。

所取干支在允许时间内重复出现时，应比较同类候选；若只能选申日而不能区分两个申日，就只报告这个精度，不事后指定其中一天为准确推出。

反馈前冻结结论与窗口；反馈后只记录用户明确反馈的事件。题干已知症状不是预测命中，离世不自动证明此前从未好转或药物始终无效。现实反馈、原载作答和事后解释分别保存；同案多份作答不是多次独立验证。
