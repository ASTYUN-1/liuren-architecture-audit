# 2026-10-19 感情占·胎产 末传应期与白虎入墓断剖

## 状态
三条候选，均为单案反馈后反推，未验证从疑；独立验证次数0。不得作可复用主判据、不增强旧规则、不增加验证次数。

## R-A 产占应期分支（仅胎产，单例）
**规则**：当产占已见发动象（胎神空、腹空、胎冲日支、临盆）时，应期取**末传**（值日、临宫、所乘天官、行年），不取初传墓库量级。

- **依据**：《说约》末传两法——“古人于应期每视用神，不视末传”适用于事未动之占；“惟吉事已动、凶事已萌之际占，应期宜视末传”（`yingqi-panduan` 收录）。
- **本案**：胎神子空、丑（腹）空、占日午冲胎神子＝已发动；末传寅＝日干长生＋天医＋行年，寅日即丙寅日10/19；寅又冲申（子孙爻青龙）。初判却取初传戌（月建／三合库神／前三辰），三说实为同一神，且戌为火墓、日干墓，**以墓断生方向相反**，结果出窗2天。
- **边界**：仅胎产；单例；“事已动”的判定标准（胎神空／腹空／胎冲日支）需更多案例固化。
- **外推纪律**：先在胎产方向积累到成熟技法，再考虑推广到其他占类，不得直接套用。

## R-B 顺剖判据（修正 N0066 的歧义）
**规则**：白虎主刀刃、金刃，性本偏向剖宫产。判顺剖看“闭”不看“血”：

- **单纯见血**（白虎＋羊刃＋血支／血忌＋金神，但无墓无闭）→ 见血、侧切、催产、出产出血，仍可顺产。
- **见闭**（白虎／胎神／子孙**入墓、入库**，产道被闭）＋金神＋血支血忌 → 胎不能出，偏向剖宫产。

- **依据**：`keti-qishi`“墓者止也”；《六壬直指》本课原文“午乘白虎入墓”；本案午（白虎）加戌入墓、初传墓发用、三传自墓传生（须破墓才生）、酉（子孙）带金神＋血支乘勾陈加丑（金库）、巳带金神＋血忌应巳时开刀。
- **N0066 修正**：该条只否定“见白虎／见血即剖”的单因果，**不可反读为“白虎偏顺产”**。已在 `经验日志/2026-10-18-感情占-raw-anli001-0027-待验证记录.md` 补注。
- **反证**：case-014（白虎＋羊刃＋金神＋血支＋三刑，实际顺产）、case-011（同类凶象，材料指顺产）——两案均缺“入墓／入库／闭”的结构，与本条不矛盾。
- **边界**：仅产占；单例；丑空时“入库”须打折。

## R-C 时辰线索（单例）
**规则**：金神＋血忌同宫之支，可作手术／见血时辰线索。

- **本案**：巳上金神＋血忌（巳又为日禄、日德、破碎），实际巳时剖腹产。
- **边界**：单例，仅作时辰线索，不能单独定时辰。

## 与旧经验的关系
- 本条 R-B 是对 N0066 的**限定性补充**，不是推翻：N0066 的“见血≠剖”仍成立，但须补上“白虎性偏剖、判剖看闭”的前提，避免下次检索时被反向引用。
- R-A 与 case-012 的“应期多法并列”不冲突：本案是“分支选择”（初传 vs 末传）问题，不是“多法并列”问题。
