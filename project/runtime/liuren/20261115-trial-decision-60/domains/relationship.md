# 婚恋伴侣：取用与专项判断

## 依所求事件分流

婚配、关系状态、态度、复合及财礼。先看所问是双方关系还是其中一方状态；婚配成否以干男支女及双方上神关系为轴，龙后解释双方处境。态度、媒合、财礼或配偶状态按各自专类，不能用一方旺替代关系已成立。具体取用依下文及classification-priority；沿共用主线核双方状态、有效通路、制救、时序和最强反证后再裁结果，不将辅助类单独另立结论。

## 取用职责

婚配成否先核本题双方关系；个人发展、媒合、财礼与偕老分职责。传统干男支女不因提问者性别倒置；龙后状态不直接替代婚配。 综合主线依judgment-core；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：围绕所问伴侣双方及关系阶段，代问亲属不占婚配双方席位。采用传统异性婚配时依干男支女；女性本人来问也不据此改成干女支男。其他关系保留方法边界，不因“事件核心”就删除专项对待轴。

### LR26-TXY-C01 婚恋：干支、三传、龙后及年命有不同职责

适用：采用书中传统男女婚配方法，已明确婚配、相处还是个人发展。

干为男支为女，干二课看男方及男家、支二课看女方及女家；北海以干支侧重态度与婚配，龙后侧重各人发展，不能把龙后相克直接顶替干支的成否判断。

边界：此法原适用传统异性婚配；同性伴侣不能按提问先后或主动性硬配男女。；不把原书尊卑、贞淫等评价当成已证实现实人格。

出处：理法 LF1991—2006；壬归 LF475—491；完整引文见同 ID 卡。

### LR26-TXY-C02 婚恋：三传初男中媒末女是专门角色读法

适用：所用婚姻专法以三传作双方与中介的对待关系。

初传男、中传媒、末传女，考察彼此生克、旺衰与所乘。不能默认每张婚恋盘的三传都等于过去现在未来；也不能因有中传就认定现实必有一个媒人。

边界：媒的现实承担可未明，不能按表补造中介人数。；专门过程读法若另有来源须单列，不能与本法无说明混用。

出处：理法 LF2027—2036；壬归 LF493—501；完整引文见同 ID 卡。

### LR26-TXY-C03 婚恋：龙后、六合、年命与财官分别查所问

适用：婚配之外另问品貌、媒合、妆奁或偕老等。

龙男后女及各自阴神察其本身处境；六合可为媒，妆奁以财为类；北海以本命看品性、行年看容貌。指南又以夫问妻财、妻问夫官及虚实论配偶、偕老。必须先辨所答子问。

边界：财官与干支不必是互斥取法；成婚与偕老不能混为一个结论。；原文的品貌与性别评价只存方法身份，不作为本案已知事实。

出处：理法 LF1994—2000；壬归 LF505—527；指南 LF699—706；理法 LF2250—2253；完整引文见同 ID 卡。

### LR26-TXY-C04 婚恋：喜庆、孤寡、谩语等需结合占类和搭配

适用：已确认所问婚恋，所用煞起例、位置、乘将及空实可靠。

北海列天喜、太常、长生等为婚姻欲得之类；孤辰寡宿在婚问与一般人物问取义不同；谩语乘朱雀或天空才取言语不真。财乘暗鬼等是有明示条件的专门组合。

边界：见孤寡不直接断必孤，见朱雀不直接断说谎。；未满足专法组合时，朱雀勾陈天空等仍须察其对本问的作用，不能删除，也不能据名扩写指控。

出处：理法 LF567—571；理法 LF3127—3136；指南 LF704—708；北海毕法 LF4796—4798；完整引文见同 ID 卡。

## 原有方法的独有检查

旧法独有候选与变法（原来源 lianai-panduan，须依理气、空墓、制救和反证裁决）：
- 原法以干支上神生合取成、冲克刑害取散；交车相合取暂时融洽终分，解离格（干支互克上神）取先好后坏，干支乘墓取止而分，人宅皆死取死心、干支皆败取灰心。这些是有待理气与制救裁决的关系候选，不由名目直接结案；干支合神空亡或乘天空还核虚实无心之义，天空与旬空分开。
- 年命变法：支辰为男方本命/行年、或干寄宫为女方本命/行年时，原法另有倒置读法；年命迭现以命为先，互为行年以行年为先。须核真实年命及本问，不能按期待结果倒换。
- 旧法以天后/妻财/太阴临干与青龙/官星/贵人临支组合提出另有对象候选，但又有课传成合甚明反速成的分支；男占后财临干并与干上生合、支上不见官龙贵的成合支，女占相应分读。不能据此认定第三者。
- 铸印不空陷、龙后旺相、太常天喜旺相生合、戌/父母乘六合的婚证候选；男女本命或行年相加临课传及太常发用是旧法强成合线索，仍核制救反证，不由原文“虽空无事”取消空亡检查。
- 琐象保留原载的条件对应：四课不备三课取三角、两课取同居；男占鬼临三四或人宅受脱取被骗风险；勾陈作鬼取情事痛苦拖拉；太阴现课传取女子缠绕；财克干上长生取女方失礼义；玄阴后合过多、子作六合、未作天后取旧私情评价；小吉单逢六合取聘礼。仅存有条件的候选方法身份，不据此认定同居、欺骗、私情或人格。妻夫类乘蛇虎等仍核是否变质。
- 旧夫妻法以支为妻位，天后/太阴/妻财为妻星察何者入课传；其中“两财同现”才用初夫、中媒、末妻。这是旧专项的条件分支，与 LR26-TXY-C02 所载另一三传专法分别说明，不能无说明放宽触发条件。

## 专项执行与收束

1. **明确关系阶段与成功标准**：联系、见面、约会、确立关系、订婚、结婚、相处质量分别定位；按题干实际伴侣双方与所选专项取角色，代问者不占双方位置，不预设每种关系的固定性别分工。
2. **建立角色与主线**：沿用干支上神关系、对象类神和已知年命取用；说明角色分配及是否有充分理由采用变法。多个对象分别比较，并保留均不成，不因换取用能得期望答案就倒置角色。
3. **检验成合是否落实**：检查空墓、旺衰、阴神、引动、现实阻碍与最强反证。年命相加等为书中强成合候选，不能直接判必成并停止。关系有联系不等于订婚，邀约失败也不自动等于关系结束。
4. **输出分层结论**：成否、关系意愿、过程/相处、所需应期分开。第三者等标签只能标有条件的解释，不能凭琐象认定事实或给人格定罪；相反证据无法裁决则留分歧。

原载 c31–c33，参照 M05、M13。多对象定位和发起/回应可借鉴，具体对象成婚与动机未核验。共用 [判断方法规则](<../methods/positioning.md>)。

## 本批定位与三传分工核读

本批直接核《理法简易》原字节LF1991–2006、2027–2036及《壬归》LF475–501：北海把干支作为态度与婚配的重要主线，龙后另查个人发展；婚姻三传原法初男中媒末女，并明说按课体灵活定侧重，不能一律写为过去/现在/未来，也不能由中传媒位置补造现实必有媒人。原文中的人格与尊卑强语保留来源身份。

本批全文已读，以上仅覆盖LR26-TXY-C01/LR26-TXY-C02相关核心段；LR26-TXY-C03/LR26-TXY-C04全部来源、年命倒置、两财分支、琐象和B/M作业尚未逐条重审。传统男女定位的来源范围保留；超出该范围的关系不能把未经验证的新映射说成该原法已覆盖。
