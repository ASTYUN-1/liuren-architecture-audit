# 分类取用短答试验 60（仅本机 OpenCode）

只回答分类、一个首取主类及简单倾向，通常200—400字。不创建packet、不调用task、不派裁决、不跑review/recheck/deliver，不做分数、名次或应期。下面是本试验唯一的倾向判断流程；专项摘录及原书供分类、职责、条件核查，不能带回旧版制鬼强弱裁成败的流程。完整占断与Codex原协议不在本次改动范围。

## 先确定所求，再确定作用性质

1. 固定原问的当事人、阶段和成功标准，读取本页及本问domain。工具在当前模式返回trial-domain专项摘录，保留分流、取用条件与出处，省去完整流程。不因关键词、旺弱或已知结果换主类。考试区分某科过关、日常成绩、升学录取、资格拿证及通知；首取依专项，不预设所有考试都取幕贵。条件缺口才查classification-priority及连续原文。
2. 取得可信程序盘，给主类的天盘支、坐处、乘将和一条首取依据。必要兼看只保留真正改变本题取舍的一项，不遍列吉凶。年命按用户明确资料采用，缺换算查life；日支地盘位、该位上神、同名天盘支落宫必须分清。程序坐标不手排。
3. 在讨论旺衰之前，先说明本题这条关系究竟是生扶主类、取得财物、应试付出、资格约束还是确有为害。五行克不自动等于侵害，泄不自动等于损失。先有需要解除的实际阻碍，才谈制救；不能先把所有官鬼设为敌方，再要求压低其指数。

## 旺衰怎样进入倾向

4. 本题相关日干、关键类神、官鬼和凶神统一喜旺恶衰：越旺越有利，越衰越不利。官鬼凶神旺默认凶害减轻、不以侵害为主；衰败凶态显，低分乃至零也不能当成无害或不可用。这项局部倾向必须实际进入综合，不能只复述后弃用。旺衰与能否作用分开，后者另核位置、通路、受制和时序。
5. 先看主类单宫状态与关键作用方的原有状态。确需跨宫补算，用liuren_compute(action="strength",archive=原盘archive,strength={mode:"selected_relations",season_profile,season_basis,actors,links,review:true})，参数不明查tool_help(compute)。先按本问解释关系，再提交有依据的links，不能为凑计算塞全盘关系。读trial_judgment_basis中的局部方向、被禁止的推导及待核生扶通路；它不裁整件事成败。原始actors/adjusted/负增量保留供追溯，不是现实伤害量。主类受生的相关通路与泄耗去向应同样核查，不能只计算制鬼，然后说没有救应。候选不等于必加关系。
6. **禁止绕回旧逻辑**：旺鬼→数值扣低日干→改称身弱→判凶，不成立；不能把同一扣减改名作独立反证。日干原有衰弱可以考虑，但必须区分原有弱与这次假定克制所减。旺鬼不以侵害为主时，“子孙比鬼弱、制不住旺鬼”本身不是失败理由。若仍判凶，必须有独立、切题的主类/兑现阻碍，说明为何足以影响原问。反过来，衰鬼不能因为克出负增量小就删去凶态。制救须解除实际不利，压低官鬼指数本身不等于救成。
7. 最后围绕主类归纳一项最强有利、一项最强不利，解释谁对原问的实际影响更直接，给偏吉／偏凶／暂难定。没有固定票数、成败总分或所有题目通用的权重。旺不保证成、空不自动败，通路受限不等于完全不可用；不把消息空弱自动升级为实体目标不成。季月两表不按结果切换，分歧如实保留。原问借点钱不能改成足额借款；有迟缓/费力也不能自动改判不能成。

统一旺衰层级（不是可用程度、成功概率或考试分数）：E=0本模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null是缺计算。没有低分失用开关；4至6不增不减的旧数量分段和harm_tendency/favorable_tendency小数不用于本轮吉凶判断。

输出：一句分类/阶段；主类位置及首取依据；两三句切题旺衰和作用取舍，明确倾向及一个关键保留条件。可用小表，但不罗列所有兼看或数值。出答前在同一轮修正与本页冲突的推导，不另开复核流程、不输出内部检查清单。已有资料先答，缺决定性信息最多问一个关键问题。不查案例/经验库、旧会话或已知答案；原书只查实际缺口，不以预训练通则覆盖本试验口径。程序不能证明取类正确或预测准确。

补充：已引用的日鬼即使未进补算，也按排盘trial_chart_basis读其旺衰；不得把衰鬼或零称为“不旺不衰”“没有强压”。不切题者不纳入，不编其状态。输出不扩展行动建议、金额大小或具体应期。
