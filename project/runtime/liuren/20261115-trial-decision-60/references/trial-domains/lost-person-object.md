# 失物盗逃：取用与专项判断

## 依所求事件分流

失物、宠物、走失人、盗捕与追回。先取实际物品/动物专类或当事年命，再核现处与寻回；已知遗忘不预置盗者。当前走失的年命/玄武分工按首取条件，捕贼与追回物品分答；线索、见人和物品回手各有节点。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

## 取用职责

普通遗失及宠物先寻本物专类，不先套盗贼；人员走失年命、玄武俱现时按《理法》先行年。一般行人在外或来归依《金针》年命第一、马第二、六亲参看，无第一才依本条递补，不将第二第三重作同一人。年命未知与已知不现分开；方位、安危、捕获和物品追回分职责。 本试验倾向依class-selection-trial；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：先定所寻之人/物、失主、寻找者及是否已知被盗，代问身份不改变目标。所寻亲属不因六亲称谓替换本物专类/行人取用；玄武作走失者和作盗贼是不同事件职责。

### LR26-TXY-C26 失物盗逃：先分物、人、盗与赃，不混同目标

适用：确认是自失、被盗、人员失联、逃亡还是追捕；未确认盗窃时保留未知。

失物按本物专类，如犬戌等；人走失可察玄武并与年命比较。北海明确：走失以玄武为人，受制可能被禁；盗贼以玄武为盗，受制可主易获；赃物失得另看财。

边界：寻人不是捉贼；不能把走失者受克制当成一律利寻。；不由象辞直接认定某现实人物盗窃；多人区分仍须有据。

出处：理法 LF717—717；理法 LF1349—1350；指南 LF843—854；完整引文见同 ID 卡。

### LR26-TXY-C27 失物盗逃：捕者、贼身、赃物与三传角色须核方法

适用：确为盗贼、追捕或赃物问题，并采用相应专项。

指南以鬼、玄武察贼，子孙察追寻，勾陈与玄武关系察捕获；又有初贼中赃末捕者的专门三传分配。不能把该角色读法泛用于所有失物盘。

边界：贼被捕与赃物追回分别判断。；类神三传与本课三传不是同一组；不把两种角色序列混写。

出处：指南 LF846—858；粹言 LF811—829；北海毕法 LF4804—4814；完整引文见同 ID 卡。

## 本试验解释边界

以上仅供分类、取用职责及适用条件；任何生克、鬼虎、制救或结果措辞都须依class-selection-trial先定本题作用性质，再按统一喜旺恶衰解释。不将旺鬼当成更强攻击，不以制不住旺鬼判凶；不以衰鬼数值小免除凶态。空墓、时序、实际通路保留，不能由低分直接判失用。原问未给的成功标准不补造。首取条件仍不足时只定点读classification-priority/原段，不用预训练通则补定。完整专项原件保留，未覆盖。
