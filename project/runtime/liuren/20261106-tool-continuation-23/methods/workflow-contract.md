# 本机可选结构化审计

本机默认按 daliuren 的专业十一环节研判、按当前无两库对照规则复核本盘与原书条件、调用liuren-adjudicator独立裁决后输出完整判断；不执行案例/经验检索。同卦追问复用原盘、前情和有效来源，只补新争点；不强制 prepare、JSON 或 check。

prepare/read/check 仅供需要结构化留痕或工程排错时选择。read 页码只表示工具输出；check 核声明的结构、来源与事实原值，不能证明实际阅读、术理或预测效果，不能充当网站报告交付门禁。网站公开报告隐藏、格式/字数约束和末步改写不在本机生效。

完整执行方式见项目 docs/本机六壬完整研判流程.md；专业方法的条件、反证、来源身份仍须实际裁决。

独立裁决的输入输出JSON属于工具交换契约，必需；用户最终报告仍为完整中文正文。可选prepare/read/check与这一交换契约不是同一门禁。主智能体不再代为裁决。


21版工具自说明：liuren_tool_help(topic=packet/compute)返回当前实际schema；workflow带domains返回就绪缺项及next_calls。仅补缺读，不替代方法全文。记录id全局唯一，事实F_、争点I_分开；神煞观察kind可为shensha，不升级为程序事实。主智能体compute的chart/lookup/life均须原样带archive。packet/reader成功按next_call继续；剩余页为空后才提交自由正文，不设固定专业输出字段。


23版工具接续：工具回执按当前阶段给出可执行next_call：领取后缺report先用liuren_materials读取，读取回执再指向deliver；已读不重读，不移除交付前校验。课盘程序事实用liuren_compute，完整引擎神煞用liuren_materials(action=shensha,path=archive.path)，不为读取归档而改用通用read。
