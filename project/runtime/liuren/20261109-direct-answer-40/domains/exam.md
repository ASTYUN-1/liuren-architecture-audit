# 学业考核：取用与专项判断

本机事件定位：所问考生就是日干所代表的人，无论本人、父母、姨舅或朋友来问。成绩、学校、考官、资格和通知分别为该考试的对象/条件；不能先将代问者当日干再取子孙作考生。入学、转校以进入目标学校为标准，不以“答题顺利”或“有文书”替代录取。

### LR26-TXY-C14 学业：试卷、评分、学校与通知随阶段分工

适用：明确考试类型、考前考后、问分数或录取或某科过关。

理法列考前朱雀试卷、考后幕贵分数、朱雀通知书；学校取禄或长生，职称另重证书印绶，业务考试重幕贵。北海毕法对日常考试又以朱雀看分高低，须保留题型范围。

边界：考试发挥、取得分数、被录取、收到通知不是一事。；古籍“选举”可能指科举选拔，不自动对应现代投票。

出处：理法 LF705—708；理法 LF1346—1346；北海毕法 LF455—469；完整引文见同 ID 卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

出处：金针 LF1190—1202；北海毕法 LF461—467；理法 LF1346—1346；完整引文见同 ID 卡。

## 判断流程

1. **界定判验标准**：通过线、理想成绩、等级、排名、笔试进面、最终录取、需否补考/二辩、毕业分别标目标；明确分数满分、允许误差、时间与候选限制。题干未提供的分数线不自行编造。
2. **定位考试与关键角色**：按北海《六壬金针》LF2365以日干为考生，不论谁代问；依本题阶段另取考核、文书、资格和学校/录取类神，说明位置与职责。朱雀、文昌、父母、官星等是候选，不是全部自动成立；缺年命不补造。
3. **形成主线并核反证**：核课传结构、旺衰、空墓、变质、阴神与引动。考试时焦虑、导师严厉、受批评或过程出错，须说明怎样影响最终资格，不能直接等于失败；反过来也不能以“虚惊”消除真实阻碍。
4. **分判成败与程度**：通过、分数、排名各有依据。德入天门等原论保留出处与条件，不能用一次双B复盘把它重定义为“只保通过”；末传空等也不能无条件成为成绩上限。只有通过倾向并不足以精确断分或排名；区分候选等级须有切题区别依据，不能用共同的吉象或无定位的折损自动定高低。奖学金等兼有评定与实发的问题按原问分别核，不因大财便定最高奖，也不因有损便降一档。
5. **数值和时间单列**：要分数时接 [数量与精度](<../methods/quantity.md>)（`--condition quantity`）；本占类明确原始分、赋分、单科/总分、满分及误差，再由共用规程核算法和精度。完整有源算法可给精确候选，缺口如实说明，不临时平均、打折或按满分补尾数。答辩通过时间、通知时间、拿证时间分别取节点，再接 [yingqi-panduan（方法模块）](<../methods/timing.md>)。

输出每问判断、方法出处、盘面支持/反证及取舍、精度边界。初判冻结后才比较作业与反馈；“和优秀作业一致”与“真实成绩命中”分记。

旧定位的考生/资格/文书职责按本节分别核，不能把某一资格类神当作考生本人。
