## R — 原文 (Reading)

> 如果看整体的人际关系，则以课传中的生、合、德为对我有利的人事物，以课传中的刑、克、穿、鬼为对我不利的人事物。具体是何人何事何物，以天将、支神的象断之。……看某个人对自己的态度，就看其类神对日干、日干上神以及本人年命上神的损益。所谓"益"，指生、合；"损"，克、脱、刑、穿。
>
> — 北海闲人，第七讲《人际关系》

## I — 方法论骨架 (Interpretation)

> 2026-10-19执行口径：下列原有方法保留出处；应用时按 E 节核对本问、位置、状态和最强反证，不能将单项命中或作者“必”字作为提前结案。

人际判断以日干为自己，核心是把"关系"翻译成可判的损益矩阵。作者给出一条总则 + 一条态度法 + 一个夫妻专用框架：

1. 整体人际总则（p24）：扫课传——生、合、德=对我有利的人事物；刑、克、穿、鬼=对我不利的人事物。具体是何人，看天将、支神的象（蛇=小人、轻薄女子；寅=老年人、带草头木字边姓氏；六合=中介/意愿……）。
2. 某人态度损益法（p25）：取其类神，看它（类神）对三个锚点——日干、日干上神、本人年命上神——的损益。益=生、合；损=克、脱、刑、穿。三个锚点皆损→实质有害；皆益→可靠助力；混合→有条件的合作。
3. 夫妻占框架（p26）：以支为妻位，天后、太阴、妻财爻为妻星，看何者入课传；干支上神生合则和、冲克则恶；两财同现时按古法"初夫末妻中传媒人"定位。
4. 年命锚点（g13）：年命入课传看本身、不入课传看年命上神；他人类神克年命上神=此人对我实质不利，即使表面上生合日干。
5. 关键前提：人际关系不主吉凶，但"关键时刻别人的态度往往能使乾坤扭转"——它决定钱的来源、家庭的组成、贵人或麻烦的降临。
6. 产出：整体环境定性 + 特定人物态度矩阵（益/损）+ 人物类型提示 + 夫妻关系专项结论。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占"当前环境"（整体人际，c22）
- **问题**: 某占"当前环境"如何——整体人际与自身处境的综合。
- **方法论的使用**: 以干为自身思想：天后临干脱气→厌翳不乐、运势低迷；末传太阴克干→抑郁、阻塞、晦暗（克=损）；支为家，支上戌作空亡、寡宿穿害酉金（穿=损），发用亥作太常空亡→婚礼喜庆空亡=独身之象；中传日禄乘玄武→禄神沉没不见（禄变质），生活困难、工作不顺。
- **结论**: 整体人际与环境偏损：抑郁、独身、生活困难、工作不顺。
- **结果**: 事事符合当时情况。

### 案例 2: 问夫妻关系（c23）
- **问题**: 男问夫妻关系如何。
- **方法论的使用**: 夫妻框架：以支为妻位、天后/太阴/妻财为妻星。干上朱雀、支上白虎→夫妻怒目相向；课传有两财（干阴酉贵、末传申蛇），以何者为妻→按古法"初夫末妻中传媒人"：初传青龙居夫位=夫贤，末传申蛇空亡=妻非贤妻（财作蛇=小人琐碎、带来无尽小麻烦）；申蛇本空、由支上寅虎冲起（有路引动）→寅为妻之尊长即岳父介入。
- **结论**: 夫贤妻不贤，岳父介入，家庭小麻烦不断。
- **结果**: 文中未给明确事后反馈（作为方法论示范）。

### 案例 3: 女问与同事关系能否搞好（c24）
- **问题**: 女问与一 1967 年男同事的关系能否搞好。
- **方法论的使用**: 问"能否搞好"，课传却一片六合太阴龙神之象且支来加干→强烈的男女关系象（判断对象错位）；四课不备→三角关系；干上六合作戌（六合=私门）→男方风流，支上官星太阴→女方亦风流；卯与支上戌合且寅月旺→女已有老公；末传羊刃白虎岁破来合支上、穿害贵人丑土→争竞、损财、流血，应于男方。
- **结论**: 不是"能否搞好同事关系"，而是私合关系，且引致损财流血之祸。
- **结果**: 此女已婚，与本单位一经理有不正当关系；午月夫归家捉获二人，痛打并敲掉经理数千元。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问与某个具体对象的关系走向：同事、上司、朋友、亲人、夫妻——"能不能搞好""他对我什么态度""他会不会帮我/害我"。
2. 用户问整体人际环境："周围都是些什么人""最近老有人找我麻烦""我的人缘怎么样"。
3. AI 端：分析"某人对当事人是助力还是损害"时（尤其对方类神可辨识：官星贵人=上司/权威、六合=合作者/中介、天后/妻财=妻子/女性、虎蛇勾玄=麻烦人物）。

### 与相邻 skill 的区分

- 与 `lianai-panduan`：恋爱 skill 断"能否成婚/关系发展成否"（常法/变法/琐象）；本 skill 断"对方态度/关系好坏/损益"。夫妻占框架（p26）两者共用——问"能不能成"走恋爱，问"相处怎样/谁贤谁不贤"走本 skill。
- 与 `shiyun-zonghe`：时运是五维综合（人际只是其中暗线），本 skill 是人际专项，用损益矩阵精判。
- 与 `cailu-panduan`：作者明言"与别人的关系决定是否有钱花"（钱是别人给的），但财禄 skill 直接看类神，本 skill 管"人"不管"钱"。
- 与 `youlu-lilun`：态度判断中的"冲起/引动"依赖有路机制（如 c23 申蛇被寅虎冲起），但那是机制层，本 skill 的主干是损益矩阵。
- 与 `zhongshen-nianyun`：年命上神（g13）是两 skill 共用锚点；但终身 skill 用它断流年运势，本 skill 用它断"他人对己损益"。
- 其余 `sanbu-duanke`（总入口）、`leishen-keti`（类神侧重）、`kongwang-bianzhi`（空亡变质）、`xiongsha-suduan`（凶煞）、`keti-qishi`（课体）、`yingpin-gongzuo`（应聘）、`shengzhi-jiaxin`（升职加薪）、`yingqi-panduan`（应期）、`jixiong-tiaozhi`（吉凶调制）——均为不同主题专项。

## 本占类的理气落实

固定我方、对方、合作事项及利益。表面生合与阴神受制、扶对方而耗我须分层检查；同一官鬼对不同角色的意义不同。意愿、能力、实际交付分开，不以吉将直接担保帮助，也不把玄武等直接写成欺骗事实。

## E — 可执行步骤 (Execution)


1. **定位关系与视角**：确定问自己与谁、对方态度、实际合作还是关系后果；按题干身份取角色/年命，缺失留空。关系成否转恋爱专项，但相处、利益与意愿仍分别判断。
2. **建立关系矩阵**：沿用类神对日干、干上神和已知年命上神的损益法，注明位置和状态。区分我求彼/彼求我、表态/行动、对我有利/对其有利，不能把多个锚点当独立验证次数。
3. **检查反证与条件**：表面生合也看空陷变质；相克也核是否针对同一层面或仅现实阻碍。说明为何判为助力、损害或有条件合作，不由单一天将推定人格或隐私事实。
4. **输出**：对方态度、可观察行为倾向、关系结果分别给依据；疑似私情、动机、人物职业只作解释候选，不回填为既知背景。未问的重大事件不凭弱象越占。

沿用上文 p24–p26 与年命锚点，补充 M13 的发起/回应区分；未知动机保留未知。共用 [判断方法规则](../daliuren/refs/judgment-workflow.md)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问"恋爱/婚姻能否成功"→ `lianai-panduan`（常法/变法/琐象）。
- 问综合时运、财运、官运等非人际主题→ 对应专项 skill。
- 无具体对象也无课传盘面时，只能做"环境扫描"提问清单，不可硬断某人态度。

### 作者在书中警告的失败模式

- ce03（变质）：看他人类神生合就断友善，忽略类神变质——如贵人作鬼、日德作鬼被勾陈夹带则"没德"、六合空亡=虚情假意、合神空亡=双方无心。c24 中"六合太阴阴私甚重=私合"即表面合、实质坏。
- ce13（同一课可多解）：同一课既可断"环境"又可断"夫妻/同事"，对象归属依赖解读侧重（c22-c24 对象都在变），结论对侧重选择高度敏感。
- ce14（可证伪性）：天将支神象意（蛇=小人、寅=老年人、六合=私门）是未论证的映射常量，事后总能自圆其说。
- ce12（幸存者偏差）：书中人际案例全部"果应"，其中 c24 事后才知是私合关系——断前无法证明判断成立。
- ce15（信仰前提）：干支五行映射人事是未论证公理。

### 作者的盲点 / 时代局限

- c24 中"同事关系"事后证实为"不正当男女关系"——作者以结果倒推课堂逻辑，未讨论判断对象错位/断错的概率。
- "人际关系不主吉凶，但关键时刻别人的态度能使乾坤扭转"——益/损的量化判定无法独立验证。
- 夫妻框架中"妻非贤妻"的判断基于天将/支神象意，含有主观道德评价色彩，与现代性别语境有偏差。

### 容易混淆的邻近方法论

- p26 夫妻占框架与 `lianai-panduan` 共用：先问清用户意图（"成否" vs "相处态度"）再选 skill。
- 整体人际 vs 特定态度是两种粒度：前者扫全课生合德/刑克穿鬼，后者做单一类神×三锚点矩阵——不要混用。
- 与 `youlu-lilun` 的引动机制：损益矩阵中的"冲/合引动"依赖有路机制，但那是机制层，本 skill 是结论层。
