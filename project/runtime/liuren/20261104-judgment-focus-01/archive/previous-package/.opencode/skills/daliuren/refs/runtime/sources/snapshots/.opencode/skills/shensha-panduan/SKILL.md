关键节点须辨月令五气、坐处/十二气、生克脱耗、神将、上神/阴神、刑冲破害及空墓；比较作用双方，写明救谁、制谁、能否得力。遁干定点查，合不自动化，吉凶名称不直接等于结果。固定角色与坐标，同支多标签不重复计证；必要依据撤销后，重新裁决依赖它的结果及应期。

## I — 方法论骨架 (Interpretation)

面对的问题：课传中神煞数十上百，如何**取用**（选重点）、**断状态**（力大力微）、**判叠加**（组合意义），而不被神煞淹没、说明神煞对本问的有效作用。

完整断课还须执行 [八煞九宝综合核查](../daliuren/refs/bashajiubao.md) 与 [用户32项](../daliuren/refs/shensha-focus.md)：八煞九宝包括关系和状态，不局限于神煞。主要依据神将气地、生克制救，普通神煞补象；旧R中“神煞更重要”的论断保留来源身份，不作为本次无条件优先级。

当前方法以 [神煞取用](../daliuren/refs/shensha-use.md) 为执行入口：《六壬笔记》优先，《壬归》核气地制化；旧《神煞全解》清单保留作专项参考，《六壬思辨-神煞》保留理解假说身份。

神煞先核成立、切题、有效位置与力量，再说明净影响。多标签不是多次独立证实；“三煞无疑”不作为数量门槛。课体背景可以复核，有效作用触及关键前提时重新裁决，不因神煞身份而永久排除。

### 季煞推演法（旧来源思辨，保留理解参照，不作新煞起法）

以春木局为例的推演坐标（理解法，非死记）：

| 地支 | 季煞 | 推演逻辑（五气旺衰 × 十二长生气） |
|:---:|------|------|
| 亥/子 | 返魂煞 | 木之长生沐浴，冬形死而气生，返魂 |
| 寅 | 皇书、吏神 | 木之临官，旺气未掌权，得书任职、小吏传书 |
| 卯 | 转煞、贼神 | 帝旺生变是转折；旺则争斗为羊刃故亦为贼神 |
| 辰 | 天目、浴盆 | 衰为退气、预见之象（目主出去）；浴盆产煞占产吉、占病凶 |
| 巳 | 孤辰 | 酉金亲戚被囚后成社会边缘人 |
| 午 | 火鬼 | 火旺克木之象 |
| 未 | 狱神 | 囚气之象 |

## A1 — 书中的应用 (Past Application)

### 案例 1: 太岁断流年与成败（《神煞全解》L19）
- **问题**: 占流年吉凶、竞选成败、病者生死。
- **方法论的使用**: 太岁为天子元首之象，主一岁吉凶"应在一年之内"；占流年以太岁为主要类神观三传；竞选看太岁加临日干年命之上主胜出；寅卯辰作太岁乘龙神=真龙天子象；**占病太岁作阎王祖宗之象大忌见之**。
- **结论**: 太岁是岁煞之首，全占类年度性判读核心。

### 案例 2: 驿马状态全集（《神煞全解》L115）
- **问题**: 占出行/调动/变动是否真动。
- **方法论的使用**: 驿马卦卦要推课课要看，最喜与禄神并（禄马同乡）；**若驿马空亡、落空、疾病、恋生、入墓、被合，皆主虽有出门动身之象实不行也**；临干身动、临支宅动、临年命身动；年马月马命马与日马相并主速动远动大动。
- **结论**: 驿马非见即动，须查六种"实不行"状态。

### 案例 3: 月厌四组合断（《神煞全解》L67）
- **问题**: 占嫁娶、盗贼、怪梦、病死、忧禁。
- **方法论的使用**: 月厌妨嫁娶；**加玄武→盗贼，加蛇→怪梦，加虎克日→病死，加朱勾→忧禁**；逃者忌向此方。
- **结论**: 同一煞随所乘天将不同而转义——神煞×天将组合断法。

### 案例 4: 丁马避险与妖神（《神煞全解》L99）
- **问题**: 占变动、忧惊、避难。
- **方法论的使用**: 丁马主摇动不安，亦为妖神专主不祥怪异忧惊；**本命逢丁马心惊不安，坐地盘长生之上可作避难逃生论**；长生禄神乘丁皆主生意、但禄神不安恐难持久；壬癸日逢丁多主财动婚动，庚辛逢丁多主凶动；六庚六辛丁临宅人宅俱动俱灾。
- **结论**: 丁马兼具动象与妖象，须按日干六亲分断吉凶方向。

## E — 可执行步骤 (Execution)

1. **先核综合关系和神将状态**：读八煞九宝与理气规则，德合禄、生旺、刑害鬼墓空等不是可有可无的普通神煞。明确对象、神将、坐处、月令、上神/阴神及制救；普通神煞在此基础上辅助。
2. **逐项核到重点**：读32项清单，核起法、成立及相关盘面落点，不只限三传，不以作者没列过而漏查用户项目。按占类深化；待核、未成立、成立但无关分别记录。名称按用户澄清为帘幕贵人、月破、桃花、丧门；丁马成神分项，成神去重。完整遍历12宫 `tiandipan[].shensha`，不以 `keyShensha` 摘要漏项为无；详 [引擎字段](../daliuren/refs/engine-shensha-output.md)。
3. **署清基准与分歧**：岁/月/日/旬及年命的基准不混。阳刃、羊刃按 [两刃排法](../daliuren/refs/blade-methods.md) 分列；文献混称按实际表核，不以字面合并。小耗、死符、旬奇、文星、天地医等采用哪一表须清楚；引擎冲突不私改盘，缺字段不虚构起法。来源见 [新增出处](../daliuren/refs/shensha-sources.md)。
4. **按占类核实际作用**：释义未清时查 [常用释义](../daliuren/refs/shensha-meanings.md)，区分原书象义、整理归纳与待核项。刃类重阳刃、羊刃次之，二者象义相近、起法分列，不重复计证。说明对应人物、事件与阶段，比较神将力量、生脱克制、阴神和刑害。天医克日/脱日、德空刑害等不凭吉名保康复，丧吊/死符不凭凶名独断死亡。相同节点多标签归并，不按数量定无疑。
5. **裁决并简洁输出**：解释采用项影响结果、过程、程度或应期的哪一维。神煞辅助不等于排斥有效反证，关键条件变动回主线重判。保留逐项核查简记，报告只写关键采用项及影响结论的待核项；单项不足仍保留该结果，不反向排除。

旧R/A1、季煞思辨继续保留其历史身份；指定项目与新增重点标记见上述清单。不得把推演假说、原文残句或后加补注冒充先前完整规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯凶煞否定式速断（课传吉象并聚时的单一凶煞否决）→ 转 `xiongsha-suduan` 或 `jixiong-tiaozhi` 综合。
- 空亡/变质的类神真假校验 → 转 `kongwang-bianzhi`。
- 纯课体大势阅读 → 转 `keti-qishi`。
- 只需要起法/口诀 → 读 [必查清单](../daliuren/refs/shensha-focus.md) 和 [现存公式](../daliuren/refs/daliuren-shensha.md)，保留基准/异法；不强行执行完整断课。
- 八字命理神煞（以年柱/命宫起法）→ **不混入六壬体系**（《神煞全解》L151-1010 八字区，起法基柱不同）。

### 作者/来源警告的失败模式

- **名称替代判断**：不相关吉凶名不能推翻有效主线；若神煞揭示关键作用条件，须核力量并返回主线复核，不能无条件限制为只改过程。
- **起法冲突未裁决**：天医优先《六壬笔记》正月辰、地医对冲，仍核月序；旧正月戌等异法保留分歧不静默改盘。疑似OCR/排印错误须核原文上下文，不从推演结果反推为既定公式。
- **八字区混入**：八字神煞（驿马以年支、桃花年支等）起法与六壬（以日支/日干）不同，混用则全盘错位——只允许禄马象意作"人物/性格注解"并标注"八字义"。
- **空表格/民俗煞**：《神煞全解》L1044-1057 三张空表与道教十二神煞，弃用不引。
- **单源经验（友人思辨）**：季煞推演法为单源未验证的推演方法论——用于理解"煞从何来"、增强判读，不替代权威起法。

### 作者的盲点 / 时代局限

- 《神煞全解》为网络文（2016），署名【神宵玉清，秋玄道人】，非古籍——六壬区（L9-137）与《指南》体系兼容，但八字区为转载，权威性弱于六壬正典。
- 《六壬思辨-神煞》为友人个人思辨，季节煞推演仅以春木局为示例，未覆盖四季全推演（"片面"即此）——蒸馏时以方法论收录，不以清单完备度要求。
- 神煞判读"果应"案例缺乏统计支撑（ce12 幸存者偏差通用）；"三传吉凶有狐疑全凭神煞解心迷"为经验断言（ce14 可证伪性通用）。

### 容易混淆的邻近方法论

- 与 `xiongsha-suduan` 的凶煞清单重叠（白虎/丁马/天空等）：凶煞 skill 管"凶的否定力量"，本 skill 管"煞的整体取用"——同一煞两个视角。
- 与 refs 速查表的分工：速查表=起法/分级静态数据；本 skill=判读流程/推演法/组合断。
