# 结构整理与执行增强的差异

structural 保留当前 I/E/B 与近期修订的原执行强度，只做分组和完全相同段归并；原 R/A1、审计、参考及维护任务全文留档。它仍含旧步骤/调用要求，不能宣称已经完成增强执行。enhanced 在同样正文前增加明确优先的执行适配，以下均为工程约束，不冒充原书逐字规定。

| ID | 增强内容 | 处置与边界 |
|---|---|---|
| D01 | 原问、对象、阶段、成功标准逐问固定 | register_questions 修订须理由，并使旧判断失效；不自动识别语义偷换 |
| D02 | 角色须实际参与结论依赖 | 无关或替代角色可说明不采用理由；程序检查引用，取用是否正确仍须语义复核 |
| D03 | 关键关系的状态、通路、范围及反证显式记录 | 固定盘事实与来源须已读；关系存在不证明作用有效 |
| D04 | 救制确认与冲突约束 | 重要位置/来源冲突未解禁止确认有效救应；允许条件或未定，不强求转吉 |
| D05 | 逐问依赖失效重评 | 改问项或共享关系则废弃其依赖结论，包括程度和应期；不得无理由沿用 |
| D06 | 模块入口取代八个方法重复调用 | 完整正文与旧别名均保留；默认 legacy 不变，不删旧 REQUIRED_SKILLS |
| D07 | 时间模块按任务需要加载 | 有时间问必须登记事件、尺度、触发和候选；无时间问不增造日期 |
| D08 | 先锋、发用、通常三传、类神三传职责明确 | 据实际问项使用，不加永久象义权重，不强迫重复展开 |

不新增“水不临支则不进水”“支火必干”“辰库为空库”等断语。旧正文中的历史绝对措辞保留来源身份，适用时必须核近期理气/语义规则。来源口径不同不强行统一。
