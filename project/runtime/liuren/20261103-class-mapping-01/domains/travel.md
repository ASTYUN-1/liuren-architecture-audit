# 出行行人：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C23 出行：成行、目的地、途中与办事目标分别取

适用：区分尚未出发、途中、到彼地办事或在外问家。

干为行者支为所往之地，北海以干上察成行、支上察彼地、三传察路途；指实问外出办事时干又可为外务，须说明问题范围。年命是个人层，水陆另有干陆支水的分法。

排除与边界：能走、路途安全、到了办成事分别判断。；不同定位不能在同一论证中无说明切换，也不固定三传为所有占类的时间线。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：壬归 LF759—773（工作台759—773）；理法 LF2387—2398（工作台4773—4795）；理法 LF2418—2424（工作台4835—4847）；指南 LF743—751（工作台1485—1501）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C24 行人：出行、归来与外人来访的动静方向须分

适用：已明确是本处之人归来，还是外人来到本处，另核是否已起程。

北海区分出行与归来对内外、进退、中末空的不同要求；行人年命及马星有专项作用。指南保留干支互传皆可来之说，北海毕法又区分归与来并评议原说，不能只见动象便断已出发或必到。

排除与边界：“归”与“来”是目标方向不同；年命未知时指南有查辰上等分支。；干支互传与中末空的各说须保留完整条件，未厘清处不拼成保证到达的合取式。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1349—1349（工作台2697—2697）；金针 LF1451—1453（工作台1451—1453）；指南 LF759—779（工作台1517—1557）；北海毕法 LF1797—1809（工作台1797—1809）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C25 行人：音信类与人到类必须分开

适用：所问包含联系、书信或何时人到，分别编号子问。

指南以朱雀、天鸡、信神及其乘马空陷察音信，另有支前四位上神的书信层。收到消息不等于行人已经到达，信神也可在其他明确的信息问题中用。

排除与边界：不能以音信通达直接保证归来、复合或录用。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF772—783（工作台1543—1565）；理法 LF944—945（工作台1887—1889）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。
