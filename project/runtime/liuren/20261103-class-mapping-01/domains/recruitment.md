# 事业任职：本轮取用补充

先读 class-mapping。本节针对对象定位和类神职责，与原专项理气、动态和制救并用。涉及同一取用口径，以本节所列适用条件和待辨优先审查；不同阶段、目标、层级不直接称冲突。未齐的专项不能由邻类补造。

### LR26-TXY-C07 事业与组织：人职关系和总分关系分别定位

适用：分清问人任职、单位经营，还是总公司与分公司的关系。

北海工作常法干为人支为单位；单问总公司运营可支为总公司，问总分关系则总为干分为支。干支关系轴随着实际问题改变，不能由机构名字固定。

排除与边界：同事信任问不因发生在公司就套任职；公司盈利须另取经营与利润目标。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF188—188（工作台375—375）；理法 LF709—713（工作台1417—1425）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

排除与边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF705—713（工作台1409—1425）；理法 LF1344—1349（工作台2687—2697）；理法 LF558—561（工作台1115—1121）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C09 事业：催官使者、催官符与任所分支

适用：所问是官职升迁、赴任或任所；核日鬼乘虎、三传财生鬼等具体组合与位置。

催官使者是日鬼乘白虎，北海限定出现于日干、年命、三传等处；催官符另指日鬼临身年命且三传财生鬼。任所可分别看禄、父母及日支的有条件路径。

排除与边界：普通病讼财婚不能照搬“催官为吉”。；不以古代官员职位直接证明现代求职必录用；第二三四课的统计边界依本条原文。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：北海毕法 LF608—620（工作台608—620）；指南 LF803—811（工作台1605—1621）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

排除与边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：金针 LF1190—1202（工作台1190—1202）；北海毕法 LF461—467（工作台461—467）；理法 LF1346—1346（工作台2691—2691）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。

## 原有专项（保留来源与适用条件）

# recruitment 占类方法

来源方法：`yingpin-gongzuo`；依总入口加载，完整条件见下文。

## I — 方法论骨架 (Interpretation)

面对的问题是"能否得到某个职位/工作"（应聘、投考、跳槽、等待录用）。判断分四条线，按序执行：

1. **取职位类神**：禄神=薪水，父母爻=生活来源，长生爻=安身立命，三者都代表"职位"。先扫课传（干上、支上、三传、年命上）找三者。
2. **判必得**：类神现于课传 + 旺相（月建/进气）+ 不空陷 + 不变质 ⇒ 职位必得、应聘必成。
3. **补救路线**：仅凭类神不现不足以判失败，也不自动支持成功；若另有吉象并聚等方法依据，须核本问位置、力量、成事通路与反证后再裁决。原资料所列生合吉旺、官局、贵人等为有条件候选，不是任一命中便成就。
4. **快速细则**：禄神发用 + 合干上 + 所占之爻进气 ⇒ 虽乘玄武（取巧/走关系）亦必成且速；课名返吟则反复进退、数次方成。空亡非死刑：旺不为空、得生得助不为空（如长生落空但作月将/太岁仍得）。

产出：必得 / 可成（带速度与渠道特征）/ 不成 / 不确定（需结合他象）四级结论 + 依据链。

## E — 可执行步骤 (Execution)

1. **确定招聘阶段**：报名、资格审查、考试/面试、录用通知、正式入职、试用留任分别定位；问职位还是问收入/去留也分清。题目只问面试通过，不据此断长期任职。
2. **取职位与双方角色**：沿用禄、父母、长生及单位/本人关系，先说明选用理由，再列位置、旺衰、空墓、变质、阴神与引动。不因一个类神旺现就跳过其余检查。
3. **检验主线**：核对课传结构、单位接纳与最强不利证据；没有类神时，“吉象并聚”必须具体说明怎样连到录用，不能作万能补救。反吟先论过程反复，能否推翻录用另给理由；朱雀乘丁等不得直接当现实篡改事实。
4. **逐阶段收束**：明确通过/未通过/条件性或不确定，附过程与持续性边界；只在题目要求或可靠证据支持时论渠道和应期。若先断必得后遇反证，允许修订并记理由。

设计来源 B03、M04。M04 没解释清反吟等与录用结论的冲突，保留这个缺口，不能替作者补圆。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- **ce04 旬丁篡改结果**: 占考试/应聘，在考完等待公布结果的日子里，若占得朱雀乘丁神，则录取结果会被篡改；想求安稳之事（工作、生计）遇丁则风雨飘摇、意外倒台。
- **ce02 空亡陷阱**：空亡不直接等于失败或可解；核本人、官禄/进达节点及救应的坐标、力量和实际作用。天空为天将，其北海风险象义另核，不以“不论旺衰”省略对本问的制化判断。
- **ce12 幸存者偏差 / ce13 同一课可多解 / ce14 可证伪性 / ce15 映射前提未论证**（公共方法学边界，见下）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: 全书求职案例全部"果应"，无失败样本、无对照、无盲测，真实命中率不可知。
- **解释自由度（ce13）**: 类神不现时"吉象并聚"补救线几乎总能成立，结论对侧重选择高度敏感，同一课可多解。
- **可证伪性（ce14）**: 象意组合自由度极大（干支×天将×位×阴神×年命），断"后应验"可能是事后合理化。
- **信仰前提（ce15）**: "禄=薪水、父母爻=生活来源"等干支五行→人事映射被当作不言自明的公理，从未论证。
