# 分类取用：本轮共同执行规则

这是接入本机十一环节的取用整理。来源方法、当前项目操作约束分别说明；没有新增自动断吉凶算法。

## 从背景和子问进入十二类

先保留原问，明确谁、什么事、已经进行到哪一步、要判断什么结果。按目标路由，身份和场所作为条件：朋友借款仍先查财务债款；公司同事是否信任先查人际；应聘录用与薪水到账分别查事业、财务。不按现实人数把四课一人一格。

| 十二类 | 模块 ID | 需要先分清 |
|---|---|---|
| 婚恋伴侣 | relationship | 婚配、相处、联系、个人发展、偕老 |
| 人际交往 | interpersonal | 求人、待答复、合作、态度 |
| 事业任职 | recruitment / promotion-salary | 应聘、经营生计、任职、调动 |
| 财务经营 | finance | 财物、经营、收入、利润、债款 |
| 学业考核 | exam | 考试类别、成绩、资格、录取 |
| 疾病求医 | illness | 患者、疾病、医药、救应、代占法 |
| 胎产生育 | pregnancy | 存孕、孕育、生产，胎神起例 |
| 家宅地产 | home | 人宅、房产、结构、方位、环境 |
| 出行行人 | travel | 出发、行程、在外、回归 |
| 失物盗逃 | lost-person-object | 遗失、被盗、走失、逃亡不可混同 |
| 天时环境 | weather | 雨晴、风雷、灾害、期限 |
| 农渔畜养 | agriculture | 生长与捕获目标不同 |

阶段综合、年运和古典兵占保留原入口；司法行政、梦怪等未齐专项时，查有据原书子段，不能硬归邻近类别。传统入口映射是研究索引，不表示所有专项已经完成。

## 取用：九系统按职责参与

1. 先按分类专法确定干支的对待轴，再展开干阳干阴、支阳支阴；阴阳、动静、尊卑、内外等只用与本问有关的轴。日干不由谁提问机械决定，也不永久等于所有事件主体。见 G01、C06、C07、C11、C16。
2. 支神取形质、物类、功能；天将可取人、物、事和职能。神煞可以直接为类或限定性质，先核起法与专项组合。六亲须注明相对谁，分人物义和作用义。见 G04—G08。
3. 长生运分直接取胎库等对象与描述已取对象的状态，核五行/十干、参照与位置；土胎差异连读 D02。课体须构成完整并核占类；不由课名定结论。年命注明归属，区分本身、上神、所临；遁干先辨旬遁/五子遁，再取暗六亲和旬煞。见 G09—G12。
4. 多类神各自回答什么先分工。同目标再按专项择主；人物、文书、资金、职位等不同目标兼看。九系统没有永久权重表，不要求每问填九格或十二乘九的 108 格。主类神未必就是决定结果的关键作用点。见 G02。
5. 类不现先按占类和子问分支：成败、属性、方向所需位置不同。不得一律删除或无边界遍盘搜有利象；北海、壬归不同路径及北海内部待辨见 G03、D01。不能把互换查得的支神冒称原天将已经入课传。

## 取类与循盘察象同时执行

环节 3 用一小段正文或必要表格说明：现实对象→候选类神→采用依据/条件→实际位置→所答子问；有歧义保留备选。人数多不等于必须分给多个神将，多象也可共指一人。定位变更后复核受影响的生克、六亲、应期。

环节 4 同时察看四课三传及已核年命中的相关显象：婚问不只龙后合，出现朱勾空等仍检查其作用；不能因不是常用类神而删除，也不能据其名凭空扩写官司或第三者。先问它通过何种盘面关系影响本子问，再比较状态、制救与最强反证。通法、专法、不同子问先分层；同条件仍互斥才按北海→壬归→指南→毕法原文取用，北海内部不同说法保留待辨。见 D03。

## 按需深化神将

采用神将同用、互换或具体神将类义时，在环节 3 读取 `shenjiang-use`；需要十二神或十二将义表分别选 `shen-symbols`、`jiang-symbols`。专项已明示的义项可复用该段；遇扩义、异义、互换再补读，不要求每问灌入全部象辞。同版本完整读过可复用。互换沿实际盘寻找节点，不改盘、不补人、不把同一组合当两份独立证据。
