# 失物盗逃：取用与专项判断

## 49版首取与职责

普通遗失及宠物先寻本物专类，不先套盗贼；人员走失年命、玄武俱现时按《理法》先行年。一般行人在外或来归依《金针》年命第一、马第二、六亲参看，无第一才依本条递补，不将第二第三重作同一人。年命未知与已知不现分开；方位、安危、捕获和物品追回分职责。 综合主线依judgment-core；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：先定所寻之人/物、失主、寻找者及是否已知被盗，代问身份不改变目标。所寻亲属不因六亲称谓替换本物专类/行人取用；玄武作走失者和作盗贼是不同事件职责。

### LR26-TXY-C26 失物盗逃：先分物、人、盗与赃，不混同目标

适用：确认是自失、被盗、人员失联、逃亡还是追捕；未确认盗窃时保留未知。

失物按本物专类，如犬戌等；人走失可察玄武并与年命比较。北海明确：走失以玄武为人，受制可能被禁；盗贼以玄武为盗，受制可主易获；赃物失得另看财。

边界：寻人不是捉贼；不能把走失者受克制当成一律利寻。；不由象辞直接认定某现实人物盗窃；多人区分仍须有据。

出处：理法 LF717—717；理法 LF1349—1350；指南 LF843—854；完整引文见同 ID 卡。

### LR26-TXY-C27 失物盗逃：捕者、贼身、赃物与三传角色须核方法

适用：确为盗贼、追捕或赃物问题，并采用相应专项。

指南以鬼、玄武察贼，子孙察追寻，勾陈与玄武关系察捕获；又有初贼中赃末捕者的专门三传分配。不能把该角色读法泛用于所有失物盘。

边界：贼被捕与赃物追回分别判断。；类神三传与本课三传不是同一组；不把两种角色序列混写。

出处：指南 LF846—858；粹言 LF811—829；北海毕法 LF4804—4814；完整引文见同 ID 卡。

## 判断流程

1. **确定对象和已知条件**：物品、人或宠物，最后确认出现时间、可能范围、是否题干已说明找到。丢失、遗忘放置、借出/转移、被盗分别作为原因候选；题目已确认在场所内就不强加盗窃情节。
2. **先辨原因，再判寻回**：依据对象性质与来源明确的方法取类神，说明位置、旺衰、空墓、阴神及引动。玄武出现只是候选信息，须有针对盗窃的支持与反证；能找到、已找到、何时找到分别判断，方位取象不能替代寻回依据。
3. **空间信息分层**：分近远、内外、遮挡/容器、环境和方向；每项标明采用天盘、地盘、类神临处还是阴神。多个锚点冲突须解释选择，不将各方向任意并成全方位。
4. **距离/数量独立推导**：原问要数时接 [数量与精度](<../methods/quantity.md>)（`--condition quantity`）；本占类先固定直线/行路距离、范围层次或件数，再核原书数制、里数公式及单位换算。适用算法可给点值，依据只支持空间层次时保留该精度，不把古里数直接当现代公里。
5. **时间与结论**：先定义发现线索、相见、自回、寻回物品或追回财物等节点，再接 [yingqi-panduan（方法模块）](<../methods/timing.md>)。人/宠物的状态不由单一墓空判死；信息不足就保留未知，不编精确地点或确定指认盗窃者。

需要古典盗逃四步、勾玄关系等细则时加载 [zhinan-zhanbing（方法模块）](<classical-conflict.md>) 的对应部分；兵占攻守部分不用于普通失物。输出每问判断、锚点、支持/反证及边界，可给有依据的优先查找环境，不声称现实已确认。
