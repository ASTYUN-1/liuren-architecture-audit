# 事业任职：取用与专项判断

## 49版首取与职责

一般应聘以禄为第一类；父母之来源、长生之生计和具体职员类分职责，不在几者中择最吉者。问指定单位还核人/单位关系及该岗位接纳条件，一般有工作不保证目标单位录用。 综合主线依judgment-core；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：问某人应聘/录用，围绕该应聘者、单位及岗位，不把代问亲属当本人；问单位招人则先明确招聘双方，不能照抄个人求职角色。考试过关与最终录用分子问，涉及考试的子问另登记exam并实读。

### LR26-TXY-C07 事业与组织：人职关系和总分关系分别定位

适用：分清问人任职、单位经营，还是总公司与分公司的关系。

北海工作常法干为人支为单位；单问总公司运营可支为总公司，问总分关系则总为干分为支。干支关系轴随着实际问题改变，不能由机构名字固定。

边界：同事信任问不因发生在公司就套任职；公司盈利须另取经营与利润目标。

出处：理法 LF188—188；理法 LF709—713；完整引文见同 ID 卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

出处：理法 LF705—713；理法 LF1344—1349；理法 LF558—561；完整引文见同 ID 卡。

### LR26-TXY-C09 事业：催官使者、催官符与任所分支

适用：所问是官职升迁、赴任或任所；核日鬼乘虎、三传财生鬼等具体组合与位置。

催官使者是日鬼乘白虎，北海限定出现于日干、年命、三传等处；催官符另指日鬼临身年命且三传财生鬼。任所可分别看禄、父母及日支的有条件路径。

边界：普通病讼财婚不能照搬“催官为吉”。；不以古代官员职位直接证明现代求职必录用；第二三四课的统计边界依本条原文。

出处：北海毕法 LF608—620；指南 LF803—811；完整引文见同 ID 卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

出处：金针 LF1190—1202；北海毕法 LF461—467；理法 LF1346—1346；完整引文见同 ID 卡。

## 原有方法的独有检查

旧法独有候选（原来源 yingpin-gongzuo）：
- 职位主类依 C08 的应聘禄优先；旧禄、父母、长生路径分别核待遇、来源和生计职责，不能不加区别全部叫职位。类现、旺相/进气、不空陷、不变质是旧成事组合，仍须核单位接纳、位置、通路和反证。
- 禄发用、合干上且所占之爻进气的旧快成分支，虽乘玄武仍须核完整条件，不转写为现实走关系；反吟先论反复进退，是否能成另判。
- 类不现的“吉象并聚”须说清生合吉旺、官局或贵人如何通向录用。旺不为空、得生得助、作月将/太岁等分别属于所载应聘原例的方法路径，按 [空亡模块](<../methods/void.md>) 的生扶/填实分路使用；不能仅以“有力”统一解空或删除原局旬空。与《理法简易》有生亦空冲突且影响实现者明列分支，不作万能补救。
- 等待公布结果时的朱雀乘丁、求安稳遇丁是旧资料风险候选，不由此断现实篡改或必倒台；天空与旬空分开，不省制化。

## 专项执行与收束

1. **确定招聘阶段**：报名、资格审查、考试/面试、录用通知、正式入职、试用留任分别定位；问职位还是问收入/去留也分清。题目只问面试通过，不据此断长期任职。
2. **取职位与双方角色**：按C08区分应聘禄优先与薪水/来源/安身立命等职责，并说明采用理法或讲义哪条路径；单位/本人角色随实际子问确定。先说明选用理由，再列位置、旺衰、空墓、变质、阴神与引动。不因一个类神旺现就跳过其余检查。
3. **检验主线**：核对课传结构、单位接纳与最强不利证据；没有类神时，“吉象并聚”必须具体说明怎样连到录用，不能作万能补救。反吟先论过程反复，能否推翻录用另给理由；朱雀乘丁等不得直接当现实篡改事实。
4. **逐阶段收束**：明确通过/未通过/条件性或不确定，附过程与持续性边界；只在题目要求或可靠证据支持时论渠道和应期。若先断必得后遇反证，允许修订并记理由。

设计来源 B03、M04。M04 没解释清反吟等与录用结论的冲突，保留这个缺口，不能替作者补圆。共用 [判断方法规则](<../methods/positioning.md>)。
