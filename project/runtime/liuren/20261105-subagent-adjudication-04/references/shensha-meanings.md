# 常用神煞释义：基本象义、取义范围与出处

本轮38项起法已逐项回查，35项有直接表文/规则，旬丁、旬癸2项依古籍概念按六十甲子推算，阳刃1项仅采用有据阳干位，阴干逆取停用。另22个定义不足名称仍停用，未登记名称不自动采用；未采用项不得作辅助或背景风险。证据按需回查，不增加必读模块。

执行按程序 `shensha_resolution` 及 [采用规则](<shensha-use.md>)：未采用项不进入主判、辅助或背景风险；本页文献异法保留研究身份，不授权临时择表。

本表解释用户指定32项的“是什么意思、在本问怎样取义”，保留《六壬笔记》《壬归》等原有象义与判断条件；起法以本轮古籍复核表为准，象义转述不充作起法证明。出处SF编号对应 [来源卡](<shensha-sources.md>)，ME编号对应 [释义补充来源](<shensha-meaning-sources.md>) 及其逐字原文；“整理归纳”“应用方向”“待核”各保留身份，不冒称书中原话或已验证结果。其余常用项目见 [补充释义](<shensha-other-meanings.md>)，引擎原名及尚缺定义/映射见 [172名索引](<shensha-engine-index.md>)。

## 如何从象义走到判断

先查该项的基本象义，再按所问定位人物/事物、天盘与地盘位置、作用对象及阶段。以 [理气规则](<../methods/liqi.md>) 核神将状态、生克制救、旺衰、坐处、上神/阴神、刑害空墓，最后说明它补充了何种事象、过程、程度或应期。神煞辅助，不能只由释义直接宣判结果。

词义相近不保证起法相同；同一词义也不保证在不同占类指同一事件。起法与基准见 [32项核查表](<shensha-focus.md>)，程序读取及已核差异见 [引擎字段](<engine-shensha-output.md>)。按当前涉及项检索本表，同轮已完整读取可复用，不把整表照抄进用户报告。

刃类取用以阳刃为重要项目，羊刃次之；二者象义相近，但起法与落点分别核对，不能并列为同等重要或重复计证。阳刃、羊刃均可参争斗、刀刃、煎熬、血光等象，具体取舍以用户本次指定的层级执行；共有象义的依据与各自起法的依据分开，详 [两刃排法与取用](<blade-methods.md>)。这是刃类内部的取舍，不把阳刃升成所有占类的最高判据。

## 其余常用项目的入口

[补充释义](<shensha-other-meanings.md>) 收录德解、官书财喜、信息行人、病患阻滞、财物盗失、出行伤损及天时等其他常用名称，羊刃、吊客、死神、岁破、血支血忌亦在其中。它们按本问补查，不把每个名称自动增为第33项以后的同等级必查名单。

对引擎星名先查 [172名释义索引](<shensha-engine-index.md>)，可看到对应入口以及“仅有起法、原文疑讹、同名/近名映射未核”等不同缺口；不能把找到近名解释当已经核实本地字段。

## 完整取义的例子与缺口

- **生气**：基本象为生存、新事等；若它作用于病鬼而助其持续，不能仍按“患者必得救”解释。先确定扶谁，再比较双方状态。
- **天医**：可定位医药/医者线索；若相关节点伤身或脱身，要说明具体影响，不能仅凭医名认定治疗必奏效，也不能单项认定现实医生庸劣。
- **桃花**：婚恋问可查情意；另类问题还可取笑容等象。第三者、出轨、来访、死亡方式必须各有支持，不由桃花一词补出整个故事。
- **阳刃**：在有关的病产或争竞问题中可补刀刃、争斗等线索，仍核对象、位置和实际作用。单项不足以确定剖产，仍保留剖产；不能反写成必不剖产。

支德已有解凶增吉的明确原义及四德状态条件；QZ文星已有“并龙加子”的具体用法，不能仍称只有表无释义，也不能把它扩大成无条件科甲成功。关于具体人物、行业、物品等更细象义，只有在所据材料与当前占类均支持时扩展；未列不等于永远不可取，但须补出处及适用条件。仍未核清者见索引，不用命名直觉填满。
