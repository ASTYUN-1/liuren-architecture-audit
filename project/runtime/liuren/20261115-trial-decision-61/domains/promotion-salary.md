# 事业任职：取用与专项判断

## 依所求事件分流

任职、晋升、调动、加薪与到账。明确所求职位/变化及期限；有据职位类承担具体目标，贵人、德禄、催官、丁马等解释促成或阻碍。任所方向才用禄→父母→日支的条件路，不推广到全部事业问；薪资变化与实发兼核财。具体取用依下文及classification-priority；沿共用主线核双方状态、有效通路、制救、时序和最强反证后再裁结果，不将辅助类单独另立结论。

## 取用职责

明确职位或在任处境首取有据职位类；现代映射未核时明示推定。催官、德禄、贵人与动象按职责兼看，不能仅见动便断升。任所方向才用禄→父母→日支的原法条件递补，不泛化所有工作问。职称、晋岗、加薪和到账分别答。 综合主线依judgment-core；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：围绕实际任职者、单位和职位/薪资变化；下文“人、本人”指该任职者，代问者不因开口就占日干。升职、调动、加薪的目标类神分别核，官鬼不自动等于某位提问者的长辈。

### LR26-TXY-C07 事业与组织：人职关系和总分关系分别定位

适用：分清问人任职、单位经营，还是总公司与分公司的关系。

北海工作常法干为人支为单位；单问总公司运营可支为总公司，问总分关系则总为干分为支。干支关系轴随着实际问题改变，不能由机构名字固定。

边界：同事信任问不因发生在公司就套任职；公司盈利须另取经营与利润目标。

出处：理法 LF188—188；理法 LF709—713；完整引文见同 ID 卡。

### LR26-TXY-C08 事业：求职、经营、生计与升迁的类神不相同

适用：明确问应聘、在职发展、生意经营、钱款还是迁调。

北海应聘以禄为第一类神并参河魁、天空、从魁、太阴；经营侧重长生，打工取禄及相关职员类；迁调另察马星、催官及行业地位的专类。

边界：“有工作”“有钱到账”“能调动”“有权位”分别判断，不以单一官鬼统包。；现代面试流程与合同签署的更细专法本批未齐。

出处：理法 LF705—713；理法 LF1344—1349；理法 LF558—561；完整引文见同 ID 卡。

### LR26-TXY-C09 事业：催官使者、催官符与任所分支

适用：所问是官职升迁、赴任或任所；核日鬼乘虎、三传财生鬼等具体组合与位置。

催官使者是日鬼乘白虎，北海限定出现于日干、年命、三传等处；催官符另指日鬼临身年命且三传财生鬼。任所可分别看禄、父母及日支的有条件路径。

边界：普通病讼财婚不能照搬“催官为吉”。；不以古代官员职位直接证明现代求职必录用；第二三四课的统计边界依本条原文。

出处：北海毕法 LF608—620；指南 LF803—811；完整引文见同 ID 卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

出处：金针 LF1190—1202；北海毕法 LF461—467；理法 LF1346—1346；完整引文见同 ID 卡。

## 原有方法的独有检查

旧法独有候选（原来源 shengzhi-jiaxin）：
- 升职的进达象核旺气（月建/进气）、吉神（龙常贵合、仪神、月将、长生、德禄）与要位（干支上、三传、年命上）；龙常并见、德入天门、龙德、时泰等结构还核身份和完整构成。
- 加薪的增益象可察父母生计及申酉虎阴、贵常龙、后福利分红、合增益等候选；旺相不空仍不能替代净收入目标，财克父母须分所伤。升、加、迁三者不互证。
- 发用空且衰、干支上皆乘墓、鬼墓发用的旧否定倾向，须核针对哪个子问及救应。原轩盖三传午卯子遇卯或午空，作乘轩落马、变三交，且三神临死地，取丢官罢职风险；保留完整条件，不由旧酒色贪污叙述指认现实违法。
- 日禄乘玄闭口、日德作鬼被勾夹等变质候选保留；传统任命、事业单位与现代市场职场须核实际身份，不能把职责增加等同职级或待遇提升。

## 专项执行与收束

1. **拆职位变化**：新职责、正式职级提升、加薪、平调、外派和离职是不同事件。先按题目选目标，双问分别判断；不要把增加工作量当升职或加薪。
2. **按目标扫描**：升迁用进达象，增薪用增益象，调动另查动象、目的地和实际可动条件。保留本节各专项判据，标明位置、状态、身份适用范围；非仕宦场景不机械套官职断语。
3. **核对否定与救应**：发用空衰、墓、合绊等形成阻碍倾向，再查其针对的是职责、待遇还是空间迁移，是否有对应救应；不能一个信号同时否掉所有子问，也不提前跳过反证。
4. **输出变化类型**：逐问给结果与边界，必要时列“职责增加但未外派”等组合，不把可能的顺带待遇写成题干事实；应期按具体事件节点另判。
