# classical-conflict 占类方法

## 依所求事件分流

兵事攻守、盗捕与逃亡专法。先确认是否真正问兵事攻守或盗捕逃亡，再用对应角色轴；普通失物走lost-person-object，口角走interpersonal，司法程序走litigation。取物、获贼、双方胜负与安全分事件。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

本机事件定位：攻守用事件中的攻方/守方，干攻支守不随谁问而倒换；盗捕另分捕者、盗者、赃物。代问者不因与某方的亲属关系成为额外干支角色。

来源方法：`zhinan-zhanbing`；依总入口加载，完整条件见下文。

下列I段是原书方法的来源摘要，不是无条件执行指令。本试验判断只依class-selection-trial；“必得”“任一即获”等强语不能直接结束判断。所列贼符、游都/鲁都等只有本盘程序已采用且resolved时才能引用为程序神煞事实；未登记者仅留研究，不自行补起冒充已采用。
