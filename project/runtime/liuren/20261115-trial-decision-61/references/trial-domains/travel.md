# 出行行人：取用与专项判断

## 依所求事件分流

动身、途中、抵达、办成、来归与音信。先定实际行者及目的地，分别核干上、支上、三传及年命。动象、成行、到达、办成和收到消息分节点；行人年命/马星递补依原法，不因音信有利便认定人到。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

本机事件定位：实际出行者/所候行人及目的地、归宿构成主线。家人代问不以家人作行者再用六亲替代出行者；行者、等待者、音信和到达分开，干陆支水等专法不与人物轴暗中混用。

### LR26-TXY-C23 出行：成行、目的地、途中与办事目标分别取

适用：区分尚未出发、途中、到彼地办事或在外问家。

干为行者支为所往之地，北海以干上察成行、支上察彼地、三传察路途；指实问外出办事时干又可为外务，须说明问题范围。年命是个人层，水陆另有干陆支水的分法。

边界：能走、路途安全、到了办成事分别判断。；不同定位不能在同一论证中无说明切换，也不固定三传为所有占类的时间线。

出处：壬归 LF759—773；理法 LF2387—2398；理法 LF2418—2424；指南 LF743—751；完整引文见同 ID 卡。

### LR26-TXY-C24 行人：出行、归来与外人来访的动静方向须分

适用：已明确是本处之人归来，还是外人来到本处，另核是否已起程。

北海区分出行与归来对内外、进退、中末空的不同要求；行人年命及马星有专项作用。指南保留干支互传皆可来之说，北海毕法又区分归与来并评议原说，不能只见动象便断已出发或必到。

边界：“归”与“来”是目标方向不同；年命未知时指南有查辰上等分支。；干支互传与中末空的各说须保留完整条件，未厘清处不拼成保证到达的合取式。

出处：理法 LF1349—1349；金针 LF1451—1453；指南 LF759—779；北海毕法 LF1797—1809；完整引文见同 ID 卡。

### LR26-TXY-C25 行人：音信类与人到类必须分开

适用：所问包含联系、书信或何时人到，分别编号子问。

指南以朱雀、天鸡、信神及其乘马空陷察音信，另有支前四位上神的书信层。收到消息不等于行人已经到达，信神也可在其他明确的信息问题中用。

边界：不能以音信通达直接保证归来、复合或录用。

出处：指南 LF772—783；理法 LF944—945；完整引文见同 ID 卡。
