# 学业考核：取用与专项判断

## 依所求事件分流

单科评分与过线、日常成绩、升学、拿证、通知。日常成绩→朱雀并依《金针》兼父母；某一专业科能否过关→幕贵；学校录取→升学专法及目标学校接纳；评职称/最终证书→戌印及太常之绶；通知→通知类。先按验收标准匹配，考试名称中的“职称”不等于问拿证。已经作答、阅卷评定、通知出分和拿证分别定时间职责，过线与分数相互核对。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

## 取用职责

日常成绩以朱雀并依《金针》兼父母；升学以河魁为第一类象，禄/长生为学校目标，另核指定学校接纳关系。研究生的幕贵/魁星考核职责保留，证书、学校、评分和通知不自由互换。专业过关重幕贵，职称资格取得重河魁/戌印，太常之绶不等于证已到手。交叉条件不足查classification-priority及原段，不挑最旺者。 本试验倾向依class-selection-trial；条件和连续来源按需查classification-priority / classification-evidence，本节补充优先于旧摘要的宽泛候选并列，不替代未重审专项条件。

本机事件定位：所问考生就是日干所代表的人，无论本人、父母、姨舅或朋友来问。成绩、学校、考官、资格和通知分别为该考试的对象/条件；不能先将代问者当日干再取子孙作考生。入学、转校以进入目标学校为标准，不以“答题顺利”或“有文书”替代录取。

### LR26-TXY-C14 学业：试卷、评分、学校与通知随阶段分工

适用：明确考试类型、考前考后、问分数或录取或某科过关。

理法的考学分支列考前朱雀试卷、考后幕贵分数、朱雀通知书；另明言某一科目能否过关以幕贵为类神。学校取禄或长生，最终职称证书另核印绶，业务专业过关重幕贵。北海毕法对日常考试又以朱雀看分高低，须保留题型范围。

边界：考试发挥、取得分数、被录取、收到通知不是一事。；古籍“选举”可能指科举选拔，不自动对应现代投票。

出处：理法 LF705—708；理法 LF1346—1346；北海毕法 LF455—469；完整引文见同 ID 卡。

### LR26-TXY-C15 学业任职：河魁印与太常绶的细分及组合例

适用：所问重在证书、盖章或职称资格。

金针以河魁印绶及虎催官分析评职称，不以三传鬼或虎头蛇尾名目直接否定。北海毕法进一步说戌为印、太常为绶，太常出现本身不能保证证书到手。

边界：理法1346“河魁太常”是候选并列，细说印绶属于职责分工，不必判成实质冲突。；金针所载评职称结果是原载例，未作为独立验证。

出处：金针 LF1190—1202；北海毕法 LF461—467；理法 LF1346—1346；完整引文见同 ID 卡。

## 本试验解释边界

以上仅供分类、取用职责及适用条件；任何生克、鬼虎、制救或结果措辞都须依class-selection-trial先定本题作用性质，再按统一喜旺恶衰解释。不将旺鬼当成更强攻击，不以制不住旺鬼判凶；不以衰鬼数值小免除凶态。空墓、时序、实际通路保留，不能由低分直接判失用。原问未给的成功标准不补造。首取条件仍不足时只定点读classification-priority/原段，不用预训练通则补定。完整专项原件保留，未覆盖。
