# 书中批注增补：类神、阴阳与气势的推理

## 取类之后分问题推理

先确定对象、实际阶段和成功标准，再把同一关键类神用于不同问题：有无与成败看存在状态、实现通路及制救；难易看双方能否施受、显藏和障碍；迟速看位置、气势、发动与承接；大小看对象本身及供给能力；数量另走quantity；新旧看实物或关系发展阶段，不能把所有属性都变成成败证据。原书在财占明确说明理气方法可推广（LF-U3143—3165、3195、3227、3395—3415）。本页推广仍须回到各占类的真实取用，不能把其他事情都改取财爻。

推理顺序为：**什么对象 → 在哪里、何种阶段 → 自身状态与实际作用 → 阴神及施受条件 → 发动和结构发展 → 分答结果、难易、速度、规模、数量、物态**。这是本轮整理的检查顺序，不声称原作者逐步照此思考。

## 阳显阴藏：一般关系与阴神专项

LF-U3233—3289：阳见其象，情归于阴。显现的类神可表示表面状态、已出现的条件；其直接阴神用于察背后支持、限制、成因与后续承接。干上神察自身现状，干阴在合适人事占中可察内在考虑；支上神察对方或所求对象，支阴察该方的限制与顾虑。这些是条件候选，不能仅凭一个阴神宣布某人的秘密心理。

用户采用的推广：不只看人心。物的外观与内在状态、项目的公开进展与内部资源、承诺与落实条件、制度表面要求与实际约束，均可沿本问类神—直接阴神的关系查。须先说明为何这对位置代表本问表里，不能把第二、第四课固定配成另两个人，也不能把任意未见事实都塞给阴神。

实际察阴神分四问：

1. **它对类神如何？**生扶类神可能增强其能力；制伤类神可能削弱事项的供给或落实。按U03区分别处扶助与直接临生合贪恋，不以“生”字一律成事。
2. **它对求者如何？**类阴扶类与类阴益我不同。所求有力而类阴伤日，可能得到但有代价，也可能因本人受损而难取；要定位受伤环节，不能只说类神旺便可得。
3. **为何如此？**类阴所乘将和实际作用可提供病、争议、手续、隐耗等原因候选。神将名象须有占类和关系支持，不据虎断死亡、不据玄武指控盗窃。
4. **何时起作用？**原段以旺速、相方来、休已过、囚死迟察类阴；空时不能仅凭这一气态断速缓。与本问阶段、位置、阻碍和制救合看，不能把这套类阴细法改成全盘固定时间表。

默认只查直接一层。需要再追阴神时写明待解决的问题、坐标与新增信息；重复回环即止。阴神同时有吉凶关系不是矛盾，而是分开说明它对类神、对我和对结果的不同作用。

## 发用气势、三传推进和四课作用

LF-U3093—3137、4895—5017：发用既察事端，也察事情发动的规模、快慢和来势。分别核初传自身月令五气、临地十二气、空墓、乘将、已采用神煞及对日干所处十二运。对象自身气态与日干对它的状态不得互换；“发用坐长生”等也不能只读成日干长生。

旺相、得地、峻急乘将与急煞相应，支持来势大或发动快；休囚、受阻和迟缓条件相应，支持势小或滞。虎偏急烈、蛇偏迟缠，是LF-U3079明示的表现倾向，**速度不等于吉凶**：财乘虎可能来得急，病害乘虎可能来得急。天后等柔缓之象也不是金额必小、事情必败的充分条件。

用户采用：神将的传统吉凶名目只保留为倾向，重要判断以旺衰、结构、实际作用及制救为主。青龙不能因吉名保证成，勾陈不能因凶名保证败。类聚看多个有关节点是否确实形成相同作用、指向同一环节；同一神多名或同一事实反复出现不重复计证，不把原文“加倍”编成数值乘2。

整体气势至少分**发动强弱、快慢、规模、虚实、持续和通达**。旺衰分数只协助所选对象的力量比较，不能将一个单宫分数宣布为全盘气势，更不能以“气势很大”替代结果论证。发用急而中途合绊、末传空陷，可发端快而完成迟或不能持久；旺也可能因恋生、合绊或坐墓而缓。各维度相反须说明，不硬拼成单一高低分。

LF-U4915、4997—5017支持发用作用于干上之鬼等四课节点。先明确谁克谁、何种救助、双方状态和可到达通路，再据U06分析解除哪个障碍；不是三传只作用于三传，也不是任意两个节点可全盘自动互相抵消。初传制干上鬼可支持先阻后顺；末传才到的救助不能倒写成开始时已无阻碍。实际采用跨宫作用后调用strength补算，不自行加减指数。

## 类神、课传与神将各司其职

LF-U3807—3899：先取准类神再察其气地与对我作用，课传结构仍反映发动、过程和归结。用户明确修订原段“类不现一般不成功”：**类神不入课传，继续到完整天地盘、已核年命等有出处的位置找本问类神；其显明性和直接参与程度通常降低，不能单凭不入课传断败。**仍保留原真实位置，不能写成已经入课传。失盗等专项即使类不入课传仍以该类神为主，不强降其专项职责。寻找须有本问关系，不能无限换神凑成吉象。

类现并不抹去中末空、龙化蛇等过程反证；类神与课体不是一票对一票，须说明各自在什么阶段影响什么结果。课体名只作起机和结构参考，不设成败开关。

按LF-U3195—3229、3885—3899，类将看所乘神的承载、得气及内外战；类神看自身月令和所临地盘，兼察乘将和阴神。神克将是将的权能受损、减力，不等于将消失。神旺而克将时，不能把神旺自动算作将旺；神将同宫仍分对象和作用方向。将的表现方式与神的承载力量相互参看，不能把“精神/力量”硬译成已验证的两个数值变量。旺相不甚惧克亦须核施受状态及结构，不以一条生克符号代替判断。

LF-U3843—3867列天时、地利、生干及遁干扶身的理想组合，可用于检查支持是否齐备；这是完整条件的例示，不是缺一项就败，也不是任一项强便全吉。阴神、遁干、乘将须各署身份，不能把“财阴两建”无据改成任意两份支持。

## 施受双方及行动能力

LF-U3251—3289、3313—3317、4925—4929：分开问施者有无资源、是否愿给，受者有无取得能力、是否能承受，双方是否有通路。施者弱，即使愿意也未必给得多；受者弱，即使资源在前也未必取到。能制对方不等于能获益，取尽一个衰弱对象仍可能所得甚少。这一用户推广可用于付款方与收款方、岗位资源与求职者、服务方与使用者等，不能预设某课位恒定代表出财者。主观意愿与客观资源也不能互相替代。

LF-U4961—4995：动不局限地理出门，可研究调动、转岗、晋升及职责转移；这是用户指定的推广，需先定位究竟哪一状态转换才算本问“动”。关神、墓、空、天官归本位可表示阻隔或敛藏，仍核具体占类和解除条件。季关神只用已采用S33（春丑夏辰秋未冬戌）；干前一辰罗网另署身份，不混为同一神煞。

原段给出行年有力冲关墓可启、旺空逢冲可动而休空冲之未必有益、入庙受困须察二马旺且无绊等条件；依U08/U10核冲是否真的解除障碍。地盘贵人丑、蛇巳等归本位不是“一定辞职/不能升迁”。原段五行墓用于该行动对象，通用日干十二气仍按U04。能启动、能变动、能到任和变动后受益分别答，不从有马或冲开直接跳到目的达成。

## 迟速、新旧与属性的迁移

LF-U3291—3317、3535—3565：关键类神在初、中、末，可依相应事项阶段取近、中、远的相对迟速，结合气态及阻滞。临身、入宅、临门的财占速象有“类入课传方论临门”等条件。用户要求推广到其他关键类神：应先解释本问何为临近当事人、已到承接处或门槛，不能把卯酉自动套成所有事件快速完成。类未入课传而有其他实现迹象，可参发用定起机；先核有无与通路，再论迟速。太岁、月建、日时表示权柄、时段和近速的分工，不许一律年慢时快、也不由此断精确年月日。

新旧可按LF-U3319—3335孟新仲中季旧取对象阶段候选；实物新旧、关系早晚、制度成熟各需说明迁移理由。“旧”不等于差，“新”不等于吉。另有十二气物态法须保留该法取位，不把两套象混成同一确定结论。数量修正见quantity-strength，具体时间任务另读timing。
