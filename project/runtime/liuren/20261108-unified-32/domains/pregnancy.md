# 胎产生育：取用与专项判断

本机事件定位：围绕是否受孕、孕期或分娩事件分清母体与胎儿。采用产时干儿支母是专项角色，丈夫、长辈代问不将日干自动改成自己；不把所有胎儿一律改成代问者子孙。

### LR26-TXY-C19 胎产：是否怀孕先取干支胎，不以子孙统代

适用：具体问是否受孕或孕期维持，核干支各自胎神及所用长生法。

金针以干支之胎作有孕类象；北海毕法将胎爻、财爻、月内生气死气区分。胎财生气是复合条件，不能删成只见财或子孙便有孕。

边界：土胎子午存在北海内部起法差异，须列法别，不能双取凑命中。；原例私孕、堕胎等描述不是据盘即可认定的现实事实。

出处：金针 LF1367—1379；北海毕法 LF1449—1467；北海毕法 LF1630—1634；完整引文见同 ID 卡。

### LR26-TXY-C20 胎产：孕期宜静与分娩宜动，母子分别取类

适用：先明确在孕期保胎还是临产分娩阶段。

北海将动神、血神等在孕与产的宜忌分开；产时兼看干支、合后。指南以支母干儿，又察天后母、六合子及其受克，胎位与产期另查，不能单凭动象就说母子平安。

边界：同一符号“孕中受损”与“分娩发动”不冲突，前提是阶段确实不同。；生产动象、母子安危和是否怀孕分别回答，不把古法当医学结果。

出处：理法 LF1344—1345；北海毕法 LF1449—1461；指南 LF719—727；完整引文见同 ID 卡。

### LR26-TXY-D02 待辨：五行长生、土随水火与胎位的法别

适用：采用长生运、胎神或墓绝类方法前，核所据书、计算对象与起例。

理法447主五行长生水土申；指南庄按2567区分五行与十干并主张土干随火；北海毕法1463—1467保留土胎子或午。这是算例基准差异，不能只汇总象义后隐去。

边界：同属北海的材料仍有不同口径，作者优先序不能抹平。；同一论证不能混用起法而不标，不能双法取有利结果。

本版采用：通用状态按U04，日干天干阳顺阴逆、支将五行顺行，不能再任择土随水火。尚待辨的是专项胎神/互胎格是否另有独立取类法，见C08；此处原书差异保留为来源。

身份：本轮候选辨析，未裁定。

出处：理法 LF447—447；指南 LF2560—2567；北海毕法 LF1463—1467；完整引文见同 ID 卡。

## 原有方法的独有检查

旧法独有候选（原来源 yunchan-panduan）：
- 未明来意时，时为胎神、干上子孙、支上巳、干支皆乘子孙等可相参；不设无来源的“三象以上”阈值，题干已明孕产不重猜来意。
- 胎儿性别原法：元首男/重审女、纯阳反阴女/纯阴反阳男、阳不备女/阴不备男；干上与日干比和男/不比女、卯震长男/酉兑少女等按各法条件分列。旧金口诀另法为巳加女方本命宫顺布至占时，上神阳男阴女，保留跨体系身份，不当六壬统一起法。多法同向不证明独立，互斥不强合，不反推相反性别。
- 产时支母干儿，互临生合的母子相恋难产候选，与支加干上低头见子的已生/顺利候选均按阶段和状态核；不能据此保证母胎安全。
- 不备只作原例不足月线索，不保证早产；“贵儿”原例有北海自评圆滑及财德贵马空亡的反证，不作身份承诺。
- 旧产期层级：太岁发用取一年内、月建取一月内、日辰取当日、时发用取当时；前三辰法为发用之神在岁/月/日/时之前三辰范围内，应其当令之时，示例未发用在月建巳前二辰取六月仅是原例。与通用 timing 并核尺度和具体出生节点，不回改第一候选。

## 专项执行与收束

1. **先分孕与产**：已孕与否、妊娠过程、分娩方式、胎儿性别、是否足月和出生时间分问；题干已明孕产则不重做来意猜测。未明来意时以多象作候选，不用未经来源支持的“至少三象”阈值认定事实。
2. **角色定位**：明确本人/配偶/胎儿的取用和出处；书籍占产干支定位与当代作者妻财/天后取用是不同路径，不拼为同一法，也不为凑答案临时切换。
3. **按子问取法并检查反证**：先核所用经验否定的是单项推断还是现实结果，保留尚未排除的顺/剖候选；保留原课体、比和、年命等既有方法，但区分体系及共享信息。两法一致不证明独立；不备只能先记该方法的不足倾向，不一律当现实早产。顺产、母胎状态和性别不能互作证明。
4. **产期节点**：区分见红、宫缩、入院、发动和分娩完成，先定尺度，再调 [yingqi-panduan（方法模块）](<../methods/timing.md>) 定主选/备选。反馈事后落在第二候选也不能回改第一候选或增加命中项。
5. **输出与复盘**：仅回答所问，列各自依据、分歧及缺项。六壬论证不能据此作医学诊断或治疗方案；不把作答中的病理猜测写回背景。
