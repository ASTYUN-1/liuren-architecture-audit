# 关键对象的有效作用

执行采用judgment-core的U01—U11；本页引文是来源材料，不恢复已停用的相反指令。历史C01—C11的关闭或重新分类见pending-conflicts；明确的分层、阶段及条件解释直接执行，只有完整上下文不能化解的同条件互斥才列真正矛盾。

理气贯穿取用与判断：四课三传、关键类神及其彼此关系在同一主线内分析。类象可在占类、位置、真假、气态和制救条件成立时参与结果，不凭孤立名称翻判，也不一律降为事后描写。初势仅定侧重，不冻结成败。

## 位置与关系范围

程序给出的日干、寄宫、干上与干阴，日支、支上与支阴，各自分列；天盘某支、它所临地盘、同名地盘宫的上神、所乘将及直接阴神不互代。天空天将与旬空分开。四课、三传、发用与日支、干上支上、相关年命及关键类神彼此的切题关系均纳入判断，不穷举无关两两组合。干上、支上、三传六亲序列明确参照；末传生干还要看乘将、临地及阴神。三传不固定等于过去现在未来。

对参与结论或最强反证的节点，一次说明：**对象与位置 → 关系方向 → 双方气态与通路 → 实际作用 → 影响的结果环节**。神将五行与名称辞义分开；生可扶病鬼，克可制病也可伤患者。关系存在不等于已经有效，局部作用不等于全局成功。

月令五气、临地十二气、神将内外战、生扶泄耗、生克刑合冲破害、空墓、直接阴神及已核年命，按实际相关性一起分析。同支德禄等不同条件可构成有效组合，同一事实换名不增独立证据；不按标签数或分数投票。

## 节点得气与受伤

每个实际支撑结果或最强反证的节点都应完成以下相关检查；同轮同一节点可复用。缺数据标未知，不把未检查写成无影响。不限于三传，也不无差别遍历全盘。

| 项目 | 检查内容 | 所需判断 |
|---|---|---|
| 月令五气 | 依所用历法口径定季节和旺相休囚死；分清神、将各自五行 | 本方与作用对象的强弱；五气不是日干六亲 |
| 坐处与十二气 | 明确是在论日干、类神还是天将，比较该对象与所临地盘 | 得地、失地，或该层只提供类象；不是看到“病”字便断人有病 |
| 生扶与泄耗 | 谁生谁、谁脱谁；生扶来源是否自己受制、落空 | 有来源的扶助是否能到达目标，是否扶敌或耗身 |
| 克制与救制 | 谁克谁，施制者与受制者各自力量、位置和其他关系 | 有克的关系不等于制得住；制住一项不等于全局无忧 |
| 神将与内外交战 | 分列地盘、天盘、天将的生克，不混淆天将本气与所乘支 | 按所用方法判冲突作用于神还是将，是否使类将无权 |
| 上神、阴神 | 检查对原节点的生、克、脱、合及对本人的作用 | 表面有情但暗受制、明吉暗损、能扶类而可能伤身等 |
| 刑冲破害、合与空墓 | 定方向、参与对象、位置、旺衰及成立条件 | 约束、损伤、冲散、牵连；合不自动化，墓不自动制住远处之神 |

对旺衰关系，只在有相应事实与依据时判强弱，不编百分比或逐项扣分。采用U02喜旺恶衰，官鬼得旺不可直接当作害力加大，须辨贪荣时限、具体凶态及受者/救者状态；欲脱散之事渐无气，与欲进取之事渐无气，意义相反。类神旺，还须看本人能否承受和取得。依据 RG-03、RG-05、RG-06、RG-11、RG-12、TY-03、TY-04。

### 内外战的具体口径

采用《壬归》卷一此法时，完整链为：地盘克用神、用神克天官，称内战；天官克用神、用神克地盘，称外战。部分资料又用“神克将”“将克神”概述神将不和，应注明它是在概述还是已满足完整链，不用单一关系冒充完整格局。《壬归》求财章对内战其将、外战其神有轻重说明，此轻重仍须保留该求财条件，不改写成所有案件固定几级的权重。依据 RG-04、RG-07、RG-09。

## 五气、十二气和六亲的参照

- 五气随四时：由月令判断相应五行的旺相休囚死，不能由日干的六亲替代。日干六亲、月令状态分别记录。
- 十二气按U04跟随所看对象：日干用天干阳顺阴逆；支神与天将用五行顺行。天一群笔记的日干总参照不采用；《壬归》类神临地法保留对象与坐处。使用时写明“以谁为本，在何地”，不能从甲木长生跳到申金长生而不说明。
- 不把不同层次相加计票：日干得长生、长生所在支自身失地可以同时成立，须判断哪条作用直接对应本问。
- 通用土寄生与阴阳顺逆按U04已定，历法沿可信程序盘；胎爻专项按北海已定；C05季土条件表差异单列程序口径，真实影响本问时依相应来源说明所用表及理由；不能为贴合答案改口径。
- 一个“衰”字不取消月令生扶，一个“生”字也不能免除临克、内战、空墓。月令主管天时、坐处主管地利，按U07分工综合，不建立无条件胜负表。

依据 RG-03、RG-08、TY-03、TY-07。

### 应期和取数怎样复用理气

同一气态可以涉及作用力量、时态、相对大小、特定数法的增减条件，但须逐项说明依据，不能自动互推：旺未必速，相气“方来”未给出哪一天，相对量大也未给出十倍或百倍。倍半、进退位只按选定数法执行；同一旺衰条件不无据重复修正。五气可提供大小及权柄程度的标准（《笔记》TY-03），尚不能据此统一换算金额或分数。

以支神课传、位置和实际作用关系为主体。日干本已参与定位、六亲与生克，不因“支为主”省略；关键遁干是补充层，参与数值或日干定期时须注明起法、课位与适用规则。旬遁、五子元遁、藏干不互代；不默认干管百位、支管个位。天干参助的来源分歧与具体待校条文见 [天干核查](<../../../../docs/应期取数归纳-20261027/天干参与及奇门参照-补充审阅稿.md>)。奇门九宫等只作比较，未形成兼容的六壬起法不接入本课。

## 合、刑冲破害与遁干

先写参与对象，再写关系和作用。合为联系或牵制的候选，不能直接等于成事、治愈或合化。半合、月建补虚、四纲引化等，须分别定位来源和条件；《笔记》的四纲合化条件作为该书方法使用，不自动取代所有流派。

冲作用于谁：冲开墓、冲散病邪、冲伤病人或冲散救神不是同一判断。刑害也需核对能否实际作用，不因名称自动判灾。空亡使哪一方无力、是病空还是身/禄/救神空，必须说明，不能只因新病或高龄就预先固定其义。

关键节点的遁干在能揭示暗鬼、合联、扶损反证时定点查阅，记录相对谁论六亲。不得由一个暗鬼直接跳到死亡，也不为每个宫位扩出多层新人物。阴神默认先看直接一层；确有未解决关系才继续，说明新增一层解决什么问题，并在重复节点或无新增证据时停止。

依据 RG-02、RG-13、RG-16、TY-05、TY-08、TY-09。

## 救制的作用范围

救应进入结论前回答：救谁/制谁，实际作用关系，自身得气与否，能否到达目标，是否另有刑合空墓或阴神损伤，以及解决的是哪个阻碍。状态未知的救应只能算候选。

按作用事实区分三种情况：

1. **阻碍仍在，只有局部缓解**：作用只覆盖过程或某项损失，不能扩大成全局成功。
2. **关键阻碍确实被解除**：重新判断主结果，可以修订初判；《壬归》有末制凶神、课内制鬼而转凶为吉的方法，不能以“救解绝不改方向”禁止复核。
3. **作用条件矛盾或缺失**：保留分歧和条件结论；不能凑足吉名换成“有救”，也不能为了维持凶断屏蔽有效救制。

《指南》局部减罚未改去官结果的例子，保留为该例方法；它不是所有生死、考试、财务题的无条件禁令。反之，某一存活案例也不能推出“元胎有长生便可苏”。依据 RG-05、RG-10、RG-14、TY-10。

三传全局、日上当前近事是有来源的时间层读法，使用时分别说明；类神三传与通常三传分列，确有专法需要才展开，不把任意下一传叫阴神。占时先锋仅作本问相关端倪，不无条件否决其他关系。

## 主客取与和结果依赖

所求有力不等于对方能给、本人能取；分别核所求、与者、取者及相关阴神的生合、受伤和畏忌。分夺、得财后患、不敢与、不能取不能都写成“财少”，不另造跨占类统一成功链。

主线说明本问侧重、关键力量、阻碍、有效制救与最强反证。新定位、主要依据撤销或关键作用改变，重评所依赖的结果、程度及应期；若仍维持原结论须有剩余理由。冲突比较同对象、位置、阶段、力量和关键环节，不设课名/类神永久优先。无法裁明就保留具体分支，不用扩大时间窗口、滑动成功标准或自动降档掩盖缺口。

现实已核资料可限定问题，世理猜测与盘推不能反向证明现实事实。判断与运筹分开，“建议去做”不算已发生或预测命中；原书断语、原载反馈和独立验证分开。同轮已核节点复用；程序计算只取结果，不手工重起盘或复算既定表。

| 项目 | 核查内容 | 判断边界 |
|---|---|---|
| 德 | 分清日德、支德及所用天/月德，定位于谁、何宫；查旺衰、空墓、刑害及是否化鬼 | 德名不保证救解；《壬归》有灭德、德化为鬼。德的关系成立与实际得救分判 |

### 八煞的对象与作用

| 项目 | 核查内容 | 判断边界 |
|---|---|---|
| 刑 | 哪两/三字、何方向、作用于本人、类神或所忧之神 | 刑名不直接给灾级；核双方力量、位置和本问作用 |
| 冲 | 冲谁、从何处冲，有无有效冲动/冲散条件 | 冲身、冲救、冲病、冲墓结果不同；不一律凶或一律解 |
| 破 | 支破、月破、岁破与破碎煞分别核基准 | 破不只指坏结果，解散旧约与谋求成合的喜忌不同；用户已确认本项为月破，不与日破碎合并 |
| 害 | 相害的具体双方、气势与对象；是否伤类或伤救 | 不只报“有害”，也不由一害直接定人品、伤病或死亡 |
| 墓 | 谁的墓、天盘/坐处何层、墓神状态及冲开/合闭条件 | 墓病、墓身、墓鬼或墓救分开；不以同一个墓字抵消所有关系 |
| 鬼 | 相对谁为鬼，明神、遁干或阴神哪层；能否克及能否得救 | 官鬼含义随占类；有鬼须查身、鬼、救三方力量及通路。未知遁干不自造暗鬼 |
| 废 | 分辨实际的无气、休囚、败、绝、死、脱等状态和关系 | 原文列“废”但邻文分说败脱绝死，未给单一“废煞”起法；不可凭字造一颗新煞，脱鬼可救身，绝旧事未必不利 |
| 空 | 空的对象、坐标、旬及原局/应期层；查相关填冲合等条件 | 身空、病空、财禄救神空不可同断；未到时与不存在也不能混用 |
