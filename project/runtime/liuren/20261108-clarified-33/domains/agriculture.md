# 农渔畜养：取用与专项判断

本机事件定位：围绕实际农作、田圃、作物/畜禽、捕获或收成，干农人支田圃、干网支禽鱼等依具体专法。代问亲属不替代实际经营者；物类不是提问者的六亲人物。

### LR26-TXY-C30 农事：农人、田圃、所种与收获分别定位

适用：分清已定种何物，还是问宜种何物；区分人安、作物长势和实利收获。

干农人支田圃，支上可为所植，日上可为所仰天时；禾谷按水木火金土分类，结合所求作物、旺衰、地盘、阴神与干支作用。初中末可分早中晚之宜。

边界：壬归专分“已有所主”和“原无所主”，不一律要求类现才可察类。；古代粳糯大小等释义保留文本身份，不改写为现代农学事实。

出处：壬归 LF662—696；理法 LF2273—2296；完整引文见同 ID 卡。

### LR26-TXY-C31 桑蚕：蚕、桑、茧、丝与蚕娘须各有类

适用：明确问养蚕生长、结茧或丝绵收成，核阶段。

壬归以午蚕、未桑、寅茧等分取，并仰看午上神；心镜本歌分午蚕未桑、寅茧、巳筐、卯丝、辰箔、申绵等。再核所求类及蚕娘年命关系，不能用财爻一项统包。

边界：指南864—865与心镜940对卯絮申丝、卯丝申绵文字不同，详D04，不擅自统一。；单见有利蚕之象不保证人的实际收益或安全。

出处：壬归 LF702—710；壬归 LF730—748；心镜 LF938—940；完整引文见同 ID 卡。

### LR26-TXY-C32 畜养：按动物本类取用，临地、栏舍与乘将兼察

适用：明确所养品种及问生长、病损、栏舍还是买卖收益。

指南列戌犬寅猫酉鸡午马丑牛未羊亥猪等；心镜注本又察动物类神所临及物命。断案吴四公例逐种察栏舍、宅基与各动物处境，不能把多个品种压成一个总类。

边界：畜安、生长、是否获利是不同问题；不由一个类神强行得出全群动物同命。；断案的伏尸叙事属原载解释，未被本批核实；金针转引戌亥有异文。

出处：指南 LF866—868；心镜 LF970—974；断案 LF1844—1852；完整引文见同 ID 卡。

### LR26-TXY-C33 渔猎：人网与禽鱼是不同对象，取物不等于通用求财

适用：所问确是捕获禽鱼，已明确方法、对象及子问。

心镜渔猎本歌取支为鱼鸟、干为网，入式及郇注又以干为渔猎人与网罟、支为禽兽鱼鳖，核人和所获物的状态与制约；欲知何物又看支上神。

边界：养殖宜物长旺与捕猎宜制获物属于目标不同，不强行统一吉凶。；心镜1208本歌“干伤支吉”与注文的有气无气、干克支读法须保留各层；本批不擅改歌文。

出处：心镜 LF1206—1208；理法 LF641—641；完整引文见同 ID 卡。

### LR26-TXY-D04 待辨：蚕桑丝绵异文与转引个案的戌亥差别

适用：需要以丝绵的精确取类或吴四公个案做进一步推断。

指南865作“寅茧卯絮申为丝”，心镜940作“卯是丝、申为绵絮”；断案1851作“戌加亥作白虎”，金针1224的转引另作亥。前者是词义或版本差别待校，后者是盘位转引疑点，均不应静默修正。

边界：指南在作者优先序中可作本批优先检索口径，仍须保留异文身份，不说明孰真。；未核扫描页，不用异文直接新增一种神将关系。

身份：本轮候选辨析，未裁定。

出处：指南 LF862—868；心镜 LF938—940；断案 LF1844—1852；金针 LF1221—1228；完整引文见同 ID 卡。
