# 名次、等第与变化量取数

原问要求第几名、进退几名、几等奖等时，接既有quantity及quantity-strength。对象可以是无形的序位或差值；无实物、未提供满分、工具目录未收录专法，都不是一概拒用取数的理由。这里是有源方法与适用条件的查询页，不设每盘统一名次公式。

## 先辨数字的含义

| 目标 | 应明确的口径 | 不能互代 |
|---|---|---|
| 最终名次 | 全体、分组还是入选者内部；人数和并列规则在已知时纳入 | 不能由“没进前七”直接定位第8或第11名 |
| 相对先后 | 比较的是哪两人、哪一榜或哪一阶段 | 甲在乙前，不代表甲是全榜第一 |
| 名次变化 | 与哪一次比较；进退方向；已知旧名次的来源 | 退步几名不等于最终第几名 |
| 等第/奖级 | 本次等级体系及高低方向，数字是类别还是序位 | 一等奖、第一名、第一批不是同一个目标 |
| 分数、分差或份额 | 实际评分尺度、对象及差值基准 | 相同分数可有不同名次；无评分分布不作固定换算 |

人数上限只能排除越界，不能证明范围内某数。名次通常取整数，遇并列或差分需依实际规则；不随意取整、取余、截尾或将超界数反复折半。未知口径只限制受影响的子判断，不把它扩成整题拒答条件。

## 原书方法入口

以下是不同分支，不把它们混为一个算法。连续原文、路径、哈希及本轮读取行号见module:quantity-rank-evidence；原载反馈与本轮推论分开。

- **QR01《大六壬说约》卷末，考试**：明言“名次即按朱雀推之”，雀乘神旺相依水一火二数，否则依十二支数并论上下相乘；数多则名次不高。可研究“排名载体＋气态分支＋取数”的专法。该本来自引擎内置转录，未校扫描底本；旺相分支是否还有上下运算、“上下”确切取位及空亡改数，不能自行补写。采用前核清所需步骤和本问适用性。
- **QR02《六壬粹言》入泮第八名例**：干上未取八、发用巳取四又因“双义”重为八。说明原载有具体名次取数；“双义”不能扩成所有巳一律乘二，也不能仅因两种算法得到同数便认定独立验证。
- **QR03《壬窍》考试占**：官星在初中末分迟早和名次高低，十干次第须以旺神定之。可用于层次与先后分析；不将初中末机械均分人数，不把甲乙等直接固定成全榜第1、2名。作者“似亦宜看。自记”的推测身份保留。
- **QR04《指南注解》兄弟乡试例；QR05北海《毕法赋全解》第3法解释**：以“午命甲寅、亥命丁未”分前后。原例只判两人相对先后；北海质疑空亡寅另取甲遁的做法，不能把有疑问的起遁定成通法。
- **QR06《天一群笔记》月考退步例**：原载初传16、末传72作差断退步56名，载反馈退57名。可参照“原位与后位—差值”的分析，16/72的取表与条件须另核，不按反馈补齐算法。此为近似相合的原载记录，未独立验证。
- **QR07《六壬经纬》考选占**：朱雀可对应文字、次第、等第及榜案，青龙另有中式等职责。提供类神职责线索，没有因此完成具体名次算式。

## 在现有主线中采用

先取本问的实际对象与排名载体，再看哪个专法有直接出处且条件适用。考试可查朱雀/榜文、官星、年命等各自职责；其他竞赛、遴选或评比按对象迁移，不能凡问名次都取财、都取朱雀。迁移时说明保留了哪种机制和条件，未明的关键步骤保持缺口。多个方法不按答案好坏挑选，也不取平均凑数。

工具methods只列已程序化算式；未收录时沿同一reader查本页、quantity-sources或绑定原段。完整且适用的有源算式可以用quantity expression计算，不要求先编成新的具名工具。表达式返回算术值，不负责证明所取位置或名次解释正确；不得因会算而省略适用性判断。

旺衰用于核类神自身及关键施受作用、选择原法分支，或检查名次高低的相对倾向。**单宫或补算指数不是分数、排名、百分位或概率。**可见几个兄弟宫不能视作所有参评者逐人的成绩，人数的中位数也不是当事人的预测名次。

名次数字通常越小越好：数量减半、成绩折损、排名推后是三件事。按原法先确定修正对象及方向；不能把“衰则少、空则半”直接搬到第N名，使不利反而升名次。已有分支用旺气取小数、衰气取大数时，更不能再无据叠加别法的折半。实际分数可以有据修正，但转成排名还须解释序位关系。

前问倾向及后问数值互为检查材料；用户未限定“若落选”，不得把无条件“第几名”改为落选后的名次。专法与前判冲突时，回核取位、作用与适用条件，不以旧判冻结新问，也不以孤立数字取代综合判断。

交付仍用原报告的一条方法记录：**所求含义/比较范围 → 类神和位置 → 来源、数表和算式 → 状态分支及有据修正 → 数值及精度**。点值、区间和离散候选都须有形成依据；无可辩护点值时说明具体缺步及现有方法支持的程度，不用“名次天生不能取数”代替查法，也不以宽区间掩盖缺口。此页不证明任何方法的预测准确率。
