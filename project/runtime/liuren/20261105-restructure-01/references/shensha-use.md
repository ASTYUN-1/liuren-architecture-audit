# 神煞取用：必查不漏，神将状态为主

以理气为准则，以本问定侧重，围绕四课三传与关键类神形成同一判断主线。类象可参与取类定位、切题组合和事象表达；适用占类、位置、真假空陷、气态及制救等原法条件须核清，条件成立时可影响结果。不得凭孤立吉凶名、象义数量或原案结局翻判；也不把类象一律压成事后描述。 神煞起法和32项覆盖保持；直接为类或限定性质须遵循专项条件，德合生旺、鬼墓空中的实际关系不因神煞名而漏查。

本轮38项起法已逐项回查，35项有直接表文/规则，旬丁、旬癸2项依古籍概念按六十甲子推算，阳刃1项仅采用有据阳干位，阴干逆取停用。另22个定义不足名称仍停用，未登记名称不自动采用；未采用项不得作辅助或背景风险。证据按需回查，不增加必读模块。

本轮执行口径以 `shensha_resolution` 为准：已核起法与位置才进入取用；`missing_input / invalid_input / disabled` 均不采用，也不得改称“背景风险”参与结论。旧表中的“待核、异法、条件分支”保留文献研究身份，不授权本盘临时择表。原始标签仅作比对。32项与补充项由程序一次核算，输出不是吉凶结论；专项其他煞须补齐可复算起法、基准、来源、位置与使用条件，不能直接拿原标签断事。

神煞起法以对应基准的六壬古籍直接表文为先，北海闲人等可靠解释互证；群笔记、杂抄及旧引擎不充作最终权威。先辨岁/月/季/日/旬、起法与断法、通则与专例；同层异法明确择定版本，不逐盘择吉换表。《壬归》继续用于气地、生克和制化；《六壬笔记》保留方法参照价值。本次用户指定的常用项目也是必查范围，《笔记》作者没有列到，不等于可以漏掉。新增出处见 [来源卡](<shensha-sources.md>)，此前理气出处仍见 [原依据](<liqi-sources.md>)。

## 两层必查，不按星名数量裁决

1. 完整断课先按 [八煞九宝综合核查](<bashajiubao.md>) 看德合禄、生旺、刑冲破害、鬼墓空等。它们包括实际关系和状态，不局限于一般神煞。用月煞生气替代所有“生”的分析，或以“神煞只是添头”跳过德合生旺，均未完成检查。
2. 再按 [用户常用项目清单](<shensha-focus.md>) 逐项核到盘面。基础检视包括其相关落点；涉及占类的重点项须深化。可复用同一节点的既有分析，但不能只看三传，或见《笔记》未列便跳过。纯资料查询按其目标处理，无需强行断课。

“必查”是核起法、落点、成立与相关性，不等于每项都有效、都需深入叙事或都要写进最终报告。缺字段标本盘未采用；文献异法按固定表选择，不逐盘重裁；已核未成立与尚未核清分开，不能写成“无”。完整断课保留简短核查记录；用户报告只交代真正影响本问的项目与重要缺口。

## 神煞释义与刃类取舍

需要解释某神煞、或不确定如何随占类取义时，读取 [常用神煞释义](<shensha-meanings.md>)，把基本象义、应用归纳与出处缺口分开；不要只会查支位或只列禁断。刃类取用以阳刃为重要项目，羊刃次之；二者象义相近，但起法与落点分别核对，不能并列为同等重要或重复计证。相近象义可参照，各自命中仍按各自起法记录。

其余常用项目查 [补充释义](<shensha-other-meanings.md>)，引擎原名查 [名称索引](<shensha-engine-index.md>)。资料只有起法或近名未对应时保留缺口；《神煞全解》本地按LF分行的六壬段主要在L9–68，L75起转入八字，不能直接移用后段命理释义。旧skill的历史行号另有分行口径，保留原标注，当前按段落内容核。

## 判断顺序和准入条件

1. **先定神将状态**：明确人物/事件、类神及日干支年命坐标；分列天盘神、天将本气与所临地盘，核月令五气、临地十二气、生克脱耗、上神/直接阴神及刑害空墓。按 [理气规则](<../methods/liqi.md>) 比较作用双方，定救谁、制谁、能否得力，不先用吉凶煞名定结局。
2. **核名称与成立**：按 [引擎神煞字段核查](<engine-shensha-output.md>) 读取完整12宫，不只看keyShensha摘要；阳刃、羊刃按 [两刃排法](<blade-methods.md>) 分列。先区分已输出、所选起法成立、实际有效三层；病符/吊客/天地医已核差异不得隐藏。读取程序原始字段，再核起法基准、历法月序、季节、日干支及条件。参考位标不等于已成立，schema正确不等于起法正确。引擎与书、书与书有冲突时，原法保留研究，执行统一采用当前固定表；不静默改原盘。旬空、十二天将、六亲和附着神煞分别说明身份。
3. **按占类判作用**：同一神煞可补不同事象，也可能与本问无关。说明它对应哪个人、何阶段及结果/过程/程度/应期哪一维。天医伤日不能凭医名保康复；皇书不能未经依据作救命；丧吊并见也不足以定死。天喜等作用还须得气得地，不能只有喜名。
4. **合并并复核**：同支兼德禄、几颗马或几个近名死煞不按标签数增信。普通神煞以辅助为常规；专项明确以神煞直接为类或构成切题组合时，按原法条件参与判断，不预设只能描写。若新核对象、有效作用或专法条件改变关键环节，重核主线及依赖结论；不能凭孤立吉名翻吉，也不能以“只辅助”拒收有效反证。

## 占类侧重

常用清单按占类给出了深化重点，属于检视安排，不是未经验证的固定权重/评分或排他名单。病占重病人、病神与救神三方，医煞、病符、生死气、丧车、二血/刃等只在有关位置与作用下参与；胎产须分保胎、发动、出血、方式、完成和母胎安危。考试求职看实际考官/岗位/文书及德禄贵、文星、闭口、成神等；婚恋看双方、成合和关系阶段，孤寡、桃花、天喜不能越过这些条件。

出行调动查各马及成行、到达和沿途风险；财物查得财与损耗的实际链；家宅年运把太岁与年命基准定位清楚。切题的其他项目在补齐可复算取用记录后仍可补入，不因表内未列而永久作废。详细表见 [常用项目](<shensha-focus.md>)。

## 完整语义与维护

“天医不能单独保证康复”仍保留康复；“丧吊不能单独定死”仍保留死亡风险。“未见某煞”不证明相反结果，“该煞待核”也不证明整盘吉凶。按 [规则语义](<rule-semantics.md>) 写清占类、对象/位置、阶段、前提与断言强度，不能把不充分条件写成反向排除。

来源中的强语保留历史身份，不升成无条件执行分支。原始排盘、书籍、R原文、A1原例、案例与经验原件继续保留；本规范约束取用，不执行排盘JSON过滤。发现疑似错字或算错，说明缺陷和受影响推断，缺口保持未知。
