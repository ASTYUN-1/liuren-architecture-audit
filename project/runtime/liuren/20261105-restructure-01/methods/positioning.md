# 问题定位与主线

定位服务于全局理气，不以角色表或象义清单替代判断。明确主体和关键类神后，按 `liqi` 同时检查其自身状态、与四课三传及彼此之间的关系；定位修订须重核整条作用链。

每个子问先定现实对象、事件阶段、期限及原问成功标准，分开成败、过程、程度、属性与时数。题干/已核事实、用户猜测、盘面推断、未知分别说明；有据推断可提出待核，不能再冒充已知前提排除其他方案。结果标准不随判断滑动：有进程不等于终局成功，部分得到也不自动等于本问成功。

按“现实对象→候选类神及来源条件→实际位置→关系方向→所答子问”定位，说明谁对谁起作用、六亲相对谁、年命归谁。人物、行为/作品、所得、病象/伤处等不同职责不混为一物。存在会改变结论的候选时，比较各自条件、关系和最强反证；不能先选结论再配象义。分类细法依专项，神将与显象依 class-mapping，不另设统一人物表。

定位未成立，暂缓依赖它的结论与应期，可继续核盘查源或保留分支。有新事实或更强关系依据可修订定位，交代原取法为何退让，并重核受影响的六亲、制救和应期；不能换主体仍沿用原参照的“生我”“脱我”。仅反馈后换象义是待验解释，不能证明初判时已能如此定位。特殊代占/年命须有来源，不按称谓机械替换。

主线须直接回答本问：具体对象核对应类神，人事相互作用核日辰关系，方向形势核课传结构。依占类和课传特征定侧重，将旺衰、生克传递、切题类象组合、阻断和制救纳入同一主线；不先冻结成败再安排象义。以直接性、位置、状态和完整专法说明选择，给主线及最强相反依据；不将病象偷换病人，资格偷换考生。无法裁决留具体分歧。

司法行政尚无通用机构表：报警、调查、处罚、诉讼、羁押、取证、办证先分事件，不能仅凭机关名同取勾陈/鬼/虎。未齐专项查本题原书，不套邻类。旧“十类”是检索标签，十二研究分类是取用路由，两者不互相限定。

仅用户未明事项时用来意法：占时及所临类神、天将相参，泛占察课传紧事与干支实际落点；“干上主思、支上主行”是该法口径，不冒称所有四课的固定角色。明示为推测占类，不改写用户已说的问题；紧事越问例外须有原法条件。
