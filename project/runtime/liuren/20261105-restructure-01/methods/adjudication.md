# 结果、反证与程度裁决

以理气为准则，以本问定侧重，围绕四课三传与关键类神形成同一判断主线。类象可参与取类定位、切题组合与事象表达，原法的占类、位置、真假空陷、气态及制救条件须核清；条件成立时可以影响结果。不凭孤立象名、象义数量或原案结局翻判，也不把类象统一压成事后描写。

## 执行

1. **沿原问审结果**：明确成功标准、当前阶段、支持与阻碍及切题专法条件，不另造跨占类固定条件链。结果未定不先保成功；过程、程度、快慢与持续性分别给依据。
2. **比较最强反证**：核同一对象、同一阶段、作用通路及双方力量；指向关键环节不等于机械否决。失败法的前提不成立，只撤该条失败依据，不反向支持成功；吉凶同理。同根多标签不计多票。
3. **裁定救解范围**：说清救谁/制谁、自身状态、能否到达及解除何种阻碍。只缓过程或一项损失，不能扩成全吉；关键障碍确实解除，重新裁决结果，不以“救解只减不改”封死改判。缺乏依据则保留具体条件分支。
4. **说明背景影响**：背景须落到对象、通路、时段与具体维度；不把一个凶名扩成处处不顺，也不设全局背景统一折扣。多年财运的“凶大吉小”原论有其问事语境，不作每一单事的统一乘算；采用该占事方法时读 [裁决条件参考](<../references/adjudication-method-conditions.md>)。
5. **按原标准收束**：用有据的迟延、费用、部分得到等可核事件表达程度，无数源不编折扣，不以比喻替代结论。主判、定位、有效作用或切题专法条件改变时，重核依赖金额/应期。面试不等于录用、承诺不等于到账，不能改成功标准或顺延日期保原判。

## 重要对照

- 问答录九LF237–239：所论皇帝是否降罪的救解是局部，朱雀乘天喜、其阴神巳为驿马和旬丁且生日，解释好旨归里而未保官职。此为该例范围，不把“有救”直接改成全吉，也不推广为所有救解永远不能改变结果。
- 问答录十LF256–261：发用官德、中末克之、干支皆墓等与“一德解百祸”并论，作者解释退位可免进一步灾祸而忧寿不久。德的存在、实际作用和结果范围分别核，不把该例的日德挪作问答录九的原理由。
- 问答录五LF133–141：原断有目今制鬼、来年初夏太岁生鬼可虑，注解又以病玄胎、中末空亡、马与日鬼等作死断。当前与未来、原断与后人解释分开，不能按凶名数量建立死亡程序；本段未载明确死亡反馈，不能虚计结果已验。
- 问答录十二LF297–307：虎马发用的快、虎作月建的力度、落空后不成或成而不久、贵临空害和末传鬼的任职持续性分论。原作者取速成不久，不能把月建增力当成败定法。
