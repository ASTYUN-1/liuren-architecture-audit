# 天时环境：取用与专项判断

## 依所求事件分流

指定地点时段的天气现象。围绕晴雨风雪等实际目标取类，不为传话者强设人物主位；依季候、乘临和本问核天气类。天气出现、强度及某宅/作物受损分开，损失另接对应专项。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

本机事件定位：核心是所问地点、时段与晴雨风雪等现象，无须为传话者安一个人物主位。天气类神按本专项，房屋受灾或作物损失是另外的事件，分别加载home/agriculture。

### LR26-TXY-C28 天时：龙虎等随乘临、季候与所问天气取义

适用：明确地点、时段、晴雨风雷雪的具体目标，采用指南天时法。

指南列青龙入庙与升天的晴雨分支、白虎临寅卯之风、水火阴阳与课体等象；雪又另有太阴、龙后及冬季组合。应把将、乘神、临地与气候问题合看。

边界：白虎在天时取风不等于疾病或凶伤。；天气与某宅或作物是否受害分子问，不能只凭天气象推出具体损失。

出处：指南 LF648—661；理法 LF700—700；完整引文见同 ID 卡。

### LR26-TXY-C29 天时：不见水或见空仍须核类寻与强弱条件

适用：按指南所载天时法，并已核衰旺、空刑及相关位置。

指南653—654既讲课传不见亥子或见空可类寻，又分有气与无气空亡的雨势。本占类不能机械照搬财孕类不见或空即绝无的判断。

边界：雨期专法须另核，不能把“有微雨候选”当确定现代气象结果。

出处：指南 LF653—659；完整引文见同 ID 卡。

## 本试验解释边界

以上仅供分类、取用职责及适用条件；任何生克、鬼虎、制救或结果措辞都须依class-selection-trial先定本题作用性质，再按统一喜旺恶衰解释。不将旺鬼当成更强攻击，不以制不住旺鬼判凶；不以衰鬼数值小免除凶态。空墓、时序、实际通路保留，不能由低分直接判失用。原问未给的成功标准不补造。首取条件仍不足时只定点读classification-priority/原段，不用预训练通则补定。完整专项原件保留，未覆盖。
