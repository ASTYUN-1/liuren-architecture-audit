# 占事的长期时序与近况

## 依所求事件分流

长期占事、阶段发展与具体结果。保留实际事件及时间跨度，按其职责和阶段综合；长期不等于出生推命。涉及具体工作、财、婚病等接相应专项，后期变化须说明改变哪一作用条件。具体取用依下文及classification-priority；本试验只从本段采用分流与取用条件，倾向依class-selection-trial，不沿用完整占断流程。

本机事件定位：年限不改变事件对象。多年事业/财务仍围绕真正经历该事的人或组织，代问不切换成代问者的人生分析；各具体事件按相应分类占，正常年命归明确对象。

本模块处理同一问事课所问的若干年、单年及当前近况。先限定实际问题、事件、结果标准和时段，不自动扩展人生档案；出生推命、大运、小限、飞限不在本轮大六壬占事范围。年命、行年与正常应期按大六壬自身规则另核，不因排除出生运限混删。

## 本试验解释边界

以上仅供分类、取用职责及适用条件；任何生克、鬼虎、制救或结果措辞都须依class-selection-trial先定本题作用性质，再按统一喜旺恶衰解释。不将旺鬼当成更强攻击，不以制不住旺鬼判凶；不以衰鬼数值小免除凶态。空墓、时序、实际通路保留，不能由低分直接判失用。原问未给的成功标准不补造。首取条件仍不足时只定点读classification-priority/原段，不用预训练通则补定。完整专项原件保留，未覆盖。
