# 分类与取用试验

只认.opencode/liuren-active.json。先tool_help(workflow)确认ready，再liuren_materials(action=method,modules=["class-selection-trial",本问domain])读短规则及专用分类摘录。主直接短答200—400字；不派裁决、不调用task，不读judgment-core/adjudication/report，不做分数、名次、应期，不查案例库/经验库/旧会话或答案。

本试验判断依次是：原问分类与固定成功标准→首取主类及可靠坐标→确定关系对本问的实际含义→喜旺恶衰解释状态→综合主类与最关键条件。主类之外最多一项必要兼看。专项摘录只供分类、职责和条件，旧完整判断流程不进入本试验。

本题相关日干、关键类神、官鬼和凶神统一喜旺恶衰。旺鬼凶害减轻，不要求先制弱才可成；衰鬼凶态显，低分、零不等于无害或不可用。旺衰与作用通路分开。五行克先辨取财、资格约束、制救还是实际侵害，不能自动作凶；泄干生主类可体现付出。禁止旺鬼→扣低日干→改称身弱→判凶；日干原有衰弱另论，不能用同一次扣减绕回旧逻辑。不能仅凭“制不住旺鬼”判凶，也不能用“衰鬼克不动”免除凶态。

需要盘用liuren_chart；同盘复用。主类单宫状态可复用；决定倾向的跨宫关系先说明本题含义，再用compute(strength)补算。必须读取trial_judgment_basis：程序给局部旺衰方向和不成立的推导，不替模型选类或裁整件事成败。原始数值保留追溯，负增量不是现实伤害量；主类受生与泄耗去向不能遗漏后再称没有救应。输出主类、首取依据、简单倾向和一个关键条件，不列工程检查项。

旺衰层级：E=0本模型计算下限；0<E<1极衰；1≤E<2.5衰弱；2.5≤E<5偏弱至中等；5≤E<7.5较旺；7.5≤E≤10强旺。null为缺计算，不是可用程度、成功概率或考试分数。4至6旧数量分段及harm_tendency小数不用于本试验。
