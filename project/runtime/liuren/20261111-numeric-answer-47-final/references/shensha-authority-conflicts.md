# 神煞起法冲突与差异清单

本轮范围为已登记39项的起法、坐标与采用口径，以及其引用材料中的已发现分歧。不是全库172名神煞均已逐项核定。依据本地古籍电子文本及注解本，未完成原刻影印校勘；不以工程运行代替术理或预测验证。A编号均对应同目录 evidence.json 的完整连续原文、LF行号及原始文件SHA256。

## 基准或体系不同，应当分列

| 项目 | 差异实质 | 当前采用与边界 |
|---|---|---|
| 岁干死符与岁支死符 | 《指南》以年干列申申亥亥寅寅巳巳辰辰；《大全》“前五死符并小耗”以岁支为基准。A13、A01 | S20明确为岁干死符。两者不是同一输入的一张表，不能合成一个身份，也未证明岁支法无效；本轮不叠加岁支死符 |
| 岁小耗与月天鼠小耗 | 《大全》岁支顺五；《壬归》正月子逆十二。A01、A07 | S08岁小耗与S08M月天鼠小耗分列，不按同名自动归属。注意上节还存在另一种月小耗异法 |
| 月死神与日支死神、岁病符与日支病符 | 《指南》日支表也列死神、病符；月表另列正巳顺行死神，《毕法》岁病符为旧太岁。A03、A10、A18 | S21S采用月死神，S19采用岁病符。日支表不能冒充月/岁表证据；未另行登记的同名分支不自动合并 |
| 六壬与择日天医 | 《协纪辨方书》为正月戌顺十二，并以“月建后二辰生气，又后二辰”解释。A19 | 保留择日体系身份，不用来覆盖本轮六壬辰起法。寅月天医：所选六壬辰，择日戌；前后方向必须连同实际映射解释 |
| 血光、血支、血忌 | 《指南》分别为正辰逆十二、正丑顺十二，以及丑未寅申卯酉辰戌巳亥午子全表。A10、A15、A16 | 三个名称三种月表，分列；它们不是同一种神煞自相矛盾，也不能按三名投票 |
| 文星、文昌、长生等近名 | 本轮S25取《指南》原称文星的日干表。A09 | 不由近名、同位或部分日干相同而替换成文昌或十二长生表，比较必须先明确各自身份 |

## 不宜误判成起法冲突的情况

- **天盘所属与地盘所临**：午加丑，午的神煞仍属午；地盘无神煞。庚日德禄在天盘申、申加丑时，不能因宫标题丑就认作德禄算在丑。此前截图不足以证明德禄全局算法错误。
- **通法与专例、起法与作用条件**：《毕法》帘幕“昼占夜贵”是定位，临年命、空墓、朱雀关系等是使用条件；病符也有成合旧事的条件。不能将条件不同的句子当互相否定的起法。A02、A18。
- **本家等未展开措辞**：《笔记》禄刃采用“本家”等短句。原词含义未核清时，不自造十干表，也不简单将其列作已证错表。A21。
- **残表/错漏**：《六壬拃河棹》本地天马段“二八戌”且缺三九等，与同段“正月起午顺数六阳神”不能完整对应；采用《大全》明确总则，不把残表逐字执行。A04、A23。疑似文本问题不等于已完成原刻校勘。
- **月界约定**：程序按可靠盘月建节月、寅起正月，季随月建，年沿原盘年柱。这是当前操作约定，古籍所有月界/闰月问题尚未逐一考证，不能冒称书书已统一。
- **22个定义不足名称**：岁德、转煞、贼符、月符、天厕、瓦煞、直符、进爵、飞镰、天才、游煞、火恶、游娲、天史、伏殃、旬盗、稼穑、天罗、干胎神、时煞、马倒、支胎神。当前均停用，不作为主判、辅助或背景风险。部分名称在古书可找到，不等于本地字段身份和算法已经核定；未登记名称同样不自动采用。

现有“飞镰/飞廉”“天才/天财”等近名疑点仍处于上述未核区，不伪装成本轮已解决的冲突。清单覆盖本轮已核范围，未宣称全神煞体系无其他分歧。


## 36版新增采用：季关神 S33

用户明确加入关神。可信盘按月建节月定季，寅卯辰春、巳午未夏、申酉戌秋、亥子丑冬；季关神春丑、夏辰、秋未、冬戌，直接使用程序S33，不自行重算。神煞属于天盘支，所临地盘不是其归属支。当前39条规则，原38条起法不变，22个停用名称不变。

关神主阻隔不通。出行关墓临干有难动之象，须结合原段的冲关破墓、用传年命及斩关等条件，不能见关便断不能动。关与墓的组合须分别核定；关神不自动等于入墓、罗网或管神。北海讲解还保留掌管仓库时关神入课的吉用，仓库大小、业务旺等须另核墓旺为库条件；不将它写成一律凶煞。具体原段与版本身份见shensha-authority-evidence的A24—A26及shensha-meanings。S23寡宿与S33同季表而身份、义项有别，不合并，也不把同一落点的两个名称自动算作两份独立证据。是否切题及实际作用仍依现行专业方法裁定。
