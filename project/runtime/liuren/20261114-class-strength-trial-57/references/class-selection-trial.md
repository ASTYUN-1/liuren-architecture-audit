# 分类取用短答试验 57（仅本机 OpenCode）

本轮只练分类、取用及简单倾向。主智能体直接回答，不创建packet、不调用task、不派裁决者，不做review/recheck/deliver，不写完整报告。此范围优先于保留资料中的完整占断、取数和应期指令。Codex与历史已绑定任务仍按原协议。

1. 先依原问的实际所求、当事人和阶段选专项分支；不是按考试名称等关键词取类。读本页与该专项即可，不通读judgment-core/adjudication/report，也不跑methods完整计划。
2. 用完整可信程序盘；已有同盘直接复用，缺盘用liuren_chart（未给占时用now）。程序坐标、贵人和神煞采信程序，不手排。用户给年命可直接采用，不要求生日；仅新增年命用life。
3. 给出主类神、对应职责、天盘支/坐处/乘将及一条首取依据。兼看类只写真正影响本题的一项；同职责递补须满足专项条件，不能因主类空弱或辅助更旺就换主类。位置不清只lookup；取用条件不清才查classification-priority或连续原文。
4. 取类之后，必须结合主类及关键作用方的旺衰、空墓、有效生克与必要制救给“偏吉／偏凶／暂难定”。先读盘内月令、十二气、空墓及单宫旺衰；月令旺衰不等于综合状态，单宫指数也不含取用后的跨宫作用。旺衰必须实际参与吉凶判断：说明它如何影响关键作用方的生克、制救，并据此支持或改变最终倾向，不能仅列出状态后弃置不用。主类必须贯穿倾向依据，不能只凭辅助类空弱或神煞名目定成败。
5. 对决定倾向的跨宫生扶、泄耗、克制，用liuren_compute(action="strength",archive=原盘archive,strength={mode:"selected_relations",season_profile,season_basis,actors,links,review:true})补算。actors只填已取用主类、必要作用/制救方（id为T:支、J:天将或S:日干，含role与basis）；links只填已依原法确认适用的关系（source、target、basis）。只需单宫可复用原盘；不做全盘两两计算，不为工具凑作用。刑冲合化及神煞依适用条件解释，不自动塞入生克计分。参数不明查tool_help(topic="compute")。
6. 核双方是否有力、作用通路及解除范围；有救应候选就查能否真正解除本题关键阻碍。季月四季/季土双表须同一依据一致使用；有分歧且无已定依据时保留分歧，不按结果换表。附一两条切题理由及最关键保留条件。旺不直接等于成功、空不直接等于失败，旺鬼不直接等于攻击更强，局部救应不自动解除全部阻碍。指数是研究计算参考，不是吉凶阈值、成功概率或考试分数，不手填/编造指数。

考试特别区分某科专业过关、日常成绩、升学录取、最终资格拿证及通知。首取依exam及classification-priority原有适用条件，不预设所有考试都取幕贵，也不因考试名称含职称而改取证书；考生定位按专项，不把代问者自动当日干。

输出通常200—400字：一句分类/阶段；小表“主类或必要兼看｜位置｜职责与首取依据”；两三句主类旺衰及有效作用/制救、倾向和缺口。依据写模块/条目即可，不堆来源。确有取用歧义才列竞争候选及条件，不强造唯一正确答案；缺决定性信息最多补问一个关键问题，已有信息先答。

即使原问含分数、名次或日期，也只答对应的分类取用和倾向，末尾一句“本试验暂不判断具体分数、名次和应期”。不计算、不估数字、不扩展建议，不拿过线倾向冒充已知过线事实。普通试验不查案例/经验库、旧会话或已知反馈。

取用理由供用户核验；程序只核坐标和状态计算，不能证明取用正确或预测准确。反馈用于指出具体错配，未经用户确认不自动改规则或升级正式版。
