# 核心交接与独立裁决

准备读judgment-core、adjudication和本问domain，report交付前读。先按实际所求事件与验收标准确定专项分支和侧重，沿同一条察类—有效作用—制救—反证主线综合，不按书目逐轮裁判。

主保存原问及input_review身份，每问route记录event、focus、primary_entity_ids、selection_basis、time_scope。路线保存有依据的题意/职责候选，不预断成败；已接受首取不重新并列择旺。不同职责兼看，同职责按明确条件递补。facts不复述全盘，observations保留必要解释，focus_issues无真缺口则[]。原书用精确handoff，method_modules只列必要备查。

packet绑定完整可信盘、分析路线和同版资料。OpenCode原样task_prompt只派一次；Codex按原生Sol/high/fork_turns=none并bind。裁决者读全核心，独立核路线并从全盘查漏；真实错配可说明原问/条件/位置依据后纠正，不能按候选强弱或数字大小换类。参考用同文件hash/run的material_id/module按需查。

按施者、受者、状态、通路、时序及本问效果分析支持与阻碍；制救说明救谁、制谁和解除范围。数值表达跨宫增减才补算已选关系，局部指数不冒充综合。quantity按适用source完成后续修正，或有理由转experimental；非零进位和免空减例外附绑定evidence。给自由完整正文和现有audit，缺必要条件如实说明，不造数过检。

主领取读全报告后，五项review实质核题意、职责主次/阶段、数量依据及计算范围、反证及有效制救、逐问约束；各项附可查evidence_refs，职责项引用每个route:问ID。程序审计只核声明和回执，review承担应用是否成立的核对。

有具体报告原句及原问/绑定方法/真实回执证据时，原会话recheck一次；题意偏移、首取被替代、制救未成立和量级/空减理由不足都是可补核事项。一次聚焦实质缺口，不要求保留原答案或数字；有据可保留或修正。主不折中改判、不另派，未解如实review并交付。

格式/保存错误只修格式和字段。长度停止且完整已读、无公开正文时按next_call原会话recover一次；仍无正文明确未完成，不以内部推理拼接。历史任务沿原绑定协议领取，不追改旧packet或原盘。
