# 数量、量级与精度

同一 `daliuren` Skill 内的条件方法。只在原问要求金额、分数、数量、重量、距离等数值，或所用应期专法确需数日时读取；问财运、考试或寻回而未问数，不自动展开。沿用占类、定位、理气和制救已经核过的对象，不另起一套取用。时间任务仍由 [应期](<timing.md>)确定事件、尺度和起算点。

## 六环执行

| 环节 | 本问要固定的内容 | 关键区别 |
|---|---|---|
| N1 对象 | 谁的什么量，哪个类神/课位，取天盘支、所临地盘、乘将还是特定遁干，理由和出处 | 总额/实得、原始分/赋分、距离/方位不是同一对象；不由“问数”统一改取财爻 |
| N2 数制 | 实际数字映射、输入位置及来源；需要时查 [数法来源与条件](<../references/quantity-sources.md>)或对应原书 | 同名数表未必同表；同表多名不算多种验证。旬遁、五子元遁、藏干和天将不混用 |
| N3 运算 | 采用直接值、加、乘、重复倍数还是分项合计，说明本法条件 | 相乘与相加不可因算出值不合期待而互换；重复倍数不等于十进位 |
| N4 增减/组合 | 每次修正的对象、触发和幅度；主数与零数怎样组合 | 旺衰在本式承担哪一职责须说清；同一条件不无据重复加倍、进位、折半；多触发的先后未明就保留缺口 |
| N5 量级 | 为什么为个位、十、百或更大，是否进退位及依据 | “旺多衰少”可说明相对大小，不能单独指定十倍/百倍。题干上限可排除越界，不能单独证明剩余某个值 |
| N6 单位口径 | 分、元、件、斤、里/公里、天等；总数与分笔、毛额与净额、原量与换算值 | 古代里制、钱贯、锭件须另核；物理单位换算与术数倍率分开 |

这是检查职责，不要求每问机械写六张表。已有完整、有出处且适用的数法可以直接形成点值；不因尚无统计校准就一律拒用。原法只给相对大小或若干量级时，就保留该精度与未决条件，不用现实猜测补成“精确推得”。

## 精确数与后位

先声明点值、近似值、离散候选或区间，以及题目要求的允许误差；“450附近”与“恰为450”分别判验。精确个位可来自完整算式，不必逐位编码。若本法确实分主数和尾数，须有各部分节点、组合、进位及零值处理；不能把干数当作十进制数字表，或默认天干百位、地支个位。

源文有直接精确断数而步骤省略时，保留原断及省略处；读者复原只能标假说，不能补写成作者规则。多法冲突时按适用条件和直接性裁决，不取平均或轮流尝试修正直到接近期望值。原问有范围、历史成绩或预算时标作题干约束，区分它与课中独立推出的部分。

## 与主线和交付的接洽

数量判断复用第3—8环节结论，在第9环节与应期分别完成。问有无收益不被金额算式替代，问分数不被通过与否替代；专项中发现真实定位或规则错误时，按 [理气的依赖重评](<liqi.md>)回查受影响结论，记录原因。

在原报告逐问结论中给一条可复核记录即可：**对象/位置 → 数表和算法 → 条件修正与量级 → 数值、单位、精度及未定处**。非数值题不增加这项。反馈前固定算式及候选；反馈后分评口径、量级、点值绝对/相对误差和作答覆盖，原断、反馈、注解分存。完整记录与静态检查都不能证明准确率提高。

本规程为2026-10-27研究整理；六环是工程归纳，具体数法的身份、条件与异文见所链接来源，不当作古籍统一算法。
