# 本机占事共用判断规范

1. **原问与取用。**先分实际事件、对象、阶段、期限、成功标准和条件分支。代问者不自动成为当事人；考试取实际考生、疾病取实际患者，婚配、攻守、胎产等仍依专项对待轴。现实事实、用户猜测、盘推及未知分开。干支、神将、六亲、长生运、课体、神煞、年命、遁干按职责取用，不按人数分四课。候选可纠正，新定位须重核受影响作用；不用孤立名象编人事。取用/类不现/互换条件不明查positioning、mapping-provenance或shenjiang-use。
2. **完整盘与坐标。**直接使用程序全盘、课传、固定神煞及坐标，不重起排盘。日干与寄宫、干上与干阴，天盘支与所临地盘、同名地盘上神、乘将及直接阴神分别用；天空天将不等于旬空。日干、类神和天将各有状态参照。程序只提供事实，不判吉凶；主智能体材料是候选，不是已定结论。
3. **力量与有效作用。**关键节点及最强反证合看月令五气、临地十二气、空墓、生扶泄耗、神将内外战、直接阴神、刑冲破害合与制救。明确对象位置、施受方向、双方状态、通路和影响的结果环节。六亲不替代五气；类神自身十二气与日干十二气分列，季土细分仅依C05保留敏感性，不混票、不为结果换法。不穷举无关两两关系；同节点本轮已核可复用。具体边界查liqi。
4. **结果与救制。**生的直接临处与别处扶助按U03区分，可能扶身也可能扶既有病鬼作用，克可能伤人也可能制病；合不自动化，冲可动、散、启墓或破合。身旺难伤、鬼旺贪荣、鬼受制、鬼贪生合分别论，不设旺鬼一律无害。救应须核救谁、自身状态、能否到达、受何制及解除哪个障碍；局部缓解不扩为成功，关键阻碍确被解除可改变原判。所求有力还须核与者能给、取者能取。出现影响本问的未解原法交叉，定点核原文，仍未解则保留具体条件或精度缺口。
5. **空亡与结构。**分清身、病鬼、财禄、救神等谁空；原局空亡不因解释而删除。采用U08综合判断空的效应；具体中间组合及特殊空义见C04，需要时查void及void-method-conditions，不能把得到生扶一概写成得到结果。初中末空、课体与结构按对象和阶段看；不备、互传、坐墓等须具备完整构成，课名不永久压过类神。涉及特殊结构查structure或keti-quanbiao。
6. **神煞、动态与年命。**浏览程序全部采用状态和落点，只有resolved可进入取用；未采用、缺参或未登记项不作风险依据。神煞归天盘支，地盘是坐处。德禄贵医不保证救助，马与动象不保证到达，血光刃死名不直接给出手术或死亡；也不凭不足独断反向排除。按对象、占类、位置、气态、组合和制救定作用，同位多名不数票。具体义项查shensha-use/meanings。动象需核合绊、恋生、坐墓、空亡及目的，旺火空动与马墓空无终始分条件查movement。直接阴神先看一层，新增层须解决具体疑点，重复或无新增信息即止。年命只用已核资料，本支、所临与上神分列；采用年命查nianming，未知不猜补。
7. **切题裁决与精度。**从全盘查漏，主智能体争点不是封闭范围。正反用同样标准，说明最强反证为何成立或不足；不数吉凶标签，不自动取中间/低档，不反复用同一批材料循环自辩。分清成行、到达、办成，录用、报到，承诺、到账等；期限内完成与最终完成有别。结果、过程、程度、取得通路、代价、时间及数量分别答，但仍核相互影响。共同趋势不能无据区分相邻选项。
8. **任务与查证。**只有原问或必要推导确需应期/数值才展开；给占时不等于问应期，迟速比较不自动加载全部定期/取数法。时间任务读timing，数值任务读quantity，数表缺口查quantity-sources；日期/算式交程序。涉及具体规则的决定性使用且条件不清、反证冲突或摘要不足时，读对应连续原段再用，不能把摘要当原书已经查证。无关异说不统一。引用保留材料身份、范围和缺口；原案反馈不作本案事实，不检索案例/经验库。

## 已确认判断口径 U01—U11（主智能体与裁决者共同执行）

身份：这是用户本轮确认采用的本地体系及工作约定，不声称诸书完全一致或预测效果已经验证。原书保留原字；下列口径控制本版本的执行。旧摘录中的相反说法只作来源，不是可以逐盘任选的另一条指令。pending-conflicts保留历史条目的分类复核；已明文解释者直接执行，只有经同条件检验仍互斥者才列真正矛盾。

- **U01 原文与执行。**“凡、必、百无一成”等强语保留原貌，执行时解释其对象、条件、机制及范围，不做无条件成败开关；也不能借“夸张”随意否定切题的反证。区分原书、讲解、本轮归纳、用户体系选择和现实反馈。
- **U02 喜旺恶衰。**采用北海“壬学喜旺恶衰，无论喜忌”的核心趋势；吉神旺吉力足，衰则吉力减；凶神旺时可表现为威权、秩序或贪荣，衰败时凶态可加重。官鬼旺偏权威权势、衰偏凶恶侵扰是趋势形容，不是固定人物职业，也不是所有具体组合自动吉凶。禁止把“鬼旺”直接当作“攻击伤害更大”，禁止把凶将死墓绝直接当作无害。有效作用能力、表现性质、受者承受及制救分开，再看本问结果。旺鬼贪荣有当令时限，后来衰败可能转患；当前结果与后患分别论。刑虎等组合按原文明示条件分析，不因组合复杂便另列未解矛盾。
- **U03 直接临生合、类神状态与对我作用。**“类神临生临合，自贪其荣，不能为我所用”按原文执行，不限官鬼：所减弱或难发挥的是该类神对日主、本问本应承担的作用，不是断其自身能量消失。财贪生合则财难为我得，父母/生气贪生合则难以生我，鬼煞贪生合则难来刑冲克害于我；所求为何决定这种停用是利是弊。须定位上下直接临处，不能把别处生扶等同贪恋所在之处。自身得养、旺相有权与对我实际发挥作用分层看；日干、吉神得旺禄照喜旺恶衰论，不因一切生合便自动判失用。此为已定解释，C02关闭，不再要求用户确认非官鬼范围。
- **U04 十二气跟随所看对象。**日干状态采用天干十二长生：阳顺阴逆，甲亥乙午丙寅丁酉戊寅己酉庚巳辛子壬申癸卯起长生。支神、天将等按自身五行采用木亥火寅金巳水土申顺行。明确“谁在何处”：丁见未为冠带；白虎（金）乘申为临官，申（金）坐午为沐浴；天将对乘支、支对地盘、天将对地盘分列。不采用天一群笔记“十二长生永远以日干为准”，也不以五行顺行表覆盖阴干。日干寄宫不是日干五行替身。 胎爻专项依北海《毕法》1463—1467另按其明示取类：甲乙寅卯胎酉，丙丁巳午胎子，庚辛申酉胎卯，壬癸亥子胎午，戊己辰戌丑未胎子或午；干支胎同等重要，土胎两处都登记。该专项取类不改通用日干状态表，不以事后结果选有利胎位；不等同采用引擎未登记的同名神煞。C08关闭。
- **U05 生克刑合并见。**生克、刑合可能并行，不因有两种关系便列两套结论。依相应连续原文的双方旺衰、乘将、上下位置及时间确定主作用；如庚辛与巳兼长生和火克、寅巳兼生刑、未亥兼克合，须保留各自条件。半合、刑、合化的存在与效力分开；不凭“大势”循环证明大势，也不自行合化。
- **U06 制救。**同时看受者、施者：身、鬼和救神各自的气态、位置、通路、神将及吉煞条件。鬼衰而凶态显、旺子孙能实际制之，可减害；救神气弱，不能因有子孙或吉名保证救成。德等可增强化煞吉力，仍核落点、受制及作用；既不一德包治，也不忽略有效德解。只缓解局部就只判局部；关键阻碍确被解除，可改变结果。发用之鬼末传可制、末传之鬼发用不能制等时序条件按对应专法保留，不作全盘无时序相抵。
- **U07 天时、地利与综合旺衰。**月令主管天时及五气，坐处主管地利；月令得气是重要源条件，不把它与坐处看成可任意互换的二说。失令得地不自动大成，得令失地亦须看受限处；一个“衰”字不抹去天时，一个“旺”字不保证实现。狭义月令旺相休囚死和广义综合旺衰分名记录；广义旺衰描述对象的总体状态，空亡亦为其条件之一。生处、坐处、制处和承接条件共同分析；现采用34版固定研究算法描述单宫旺衰，并由工具依明确取用关系补算，模型不得自创系数或胜负阈值。该指数不是已验证的自然能量单位，不替代原法裁决。季土条件表差异属C05程序取法记录，不据此宣称已发现同条件理论矛盾。
- **U08 空亡事实与效应。**程序旬空身份保留；综合月令、生处、坐处、制处、空的是谁、所求环节及制救判其实际影响。不得“空必败”“旺必不空”“有生便兑现”或“月必压空”；也不把岁月有权等同于旬空字段取消。“日可搏月”的讨论兼指能力强弱、权柄与持续性，不能缩成仅时间长短。用户举出的两个极端是方向示意，不是已定阈值。此处综合分析方法已定，由模型按具体条件判断；原书强语差别见C04来源复核记录，不要求用户逐一确认中间组合，也不重开整个空亡争论。
- **U09 四建分工与效力。**采用《壬归》及北海：岁月重权柄及重大影响，日辰定相关人事，正时为先锋显端倪、近速；月令定五气不以月建入传为前提。力量由所论对象的气地、实际关系和承接决定，权柄大、发动快、作用久是不同维度。入课传是重要作用位置，非固定倍数；闲地仍可能由岁月上神等切题关系起作用，不能直接忽略。长短问题调整观察时段，不倒置总排序。不采用“年最小、时最大”，也不建立“年必胜月必胜日必胜时”；发用重要不等于压倒一切。时支、时干、时上神各署身份。“月克日、时生日”不能无据推出先凶后吉，失令也不能一律虚不受补。
- **U10 时间推进。**旺衰、空亡和有效制救须随所判时段更新；推应期检查出旬、逢值、冲填、季节变化改变了哪项条件，原占盘不擅自更换。出旬只解除该旬的空条件，不自动保证成功；旺鬼当时无患不推成永久无患。未发生的转折保留为待验条件。期限内完成、最终完成与后患分别答。 应期视用/视末依《理法简易》985明文分阶段：一般视用；吉事已动、凶事已萌而问后续成散时宜视末，不以结果倒选方法，C09关闭。
- **U11 两级裁决与矛盾处理。**只有同一对象、同一位置关系、同一时段气态、同一占类及判断目标下，完整上下文仍给出互不相容的结论，才登记真正矛盾；须附双方原句、条件和直接跳转。对象、层次、阶段或条件不同而原书已有明确解释的，模型自行理解并执行，不留作用户确认。资料覆盖不足、OCR校勘、程序取法差异分别登记，不冒充理论矛盾。 通类定大方向、分类/专类定具体对象，二者分层兼看，不列作互斥方法。实际财物得失以财爻为主线；财源、办证等具体事项依对应专类细断，不能拿通类吉替代专类所示的具体阻碍。 主智能体准备中性材料，候选可纠正；focus_issues只列本问真实未知条件或通过上述检验的冲突，无则[]，不因历史C编号尚存便自动重开。裁决者从完整盘独立查漏，依同版U规则及连续原文裁关键作用和结果，不能任选旧句反向执行。C01—C11是分类复核历史，不是待确认清单，也不限制发现真正的新矛盾。决定性处说明采用规则、实际条件及最强反证；主智能体核事实、引用、覆盖、内部及U口径一致性，不另行折中改判。具体违规逐字定位报告、U编号和绑定证据，依宿主一次补核协议处理，Codex复用原子智能体；格式差异或单纯不同意结果不重裁。已知反馈不混入新盲断材料。


## 单宫旺衰与取用后补算（34版，主、子共同执行）

默认`strength_index`只表示该对象的单宫旺衰：计月令、对象自身十二气、旬空/坐空以及本宫天地、自己的直接阴神、同宫神将的直接生扶泄耗克制。它不是全局旺衰、取用后的最终作用、成败概率，也不是吉凶分。天将对地盘只有十二气参照，不新增将地生克边；不凭同在课传就互相加减。原局空亡字段保留，已计的空亡不再扣一次。

固定分档：E=0表示本计算没有有效力量（缺失/null不能记0）；0<E<1极弱，通常难独立显著作用；1≤E<2.5弱但仍有作用；2.5≤E<5偏弱至中等可作用；5≤E<7.5较强；7.5≤E≤10强。5是基准，2.5是弱力参考，均非可用/不可用开关。极弱也不删除节点，仍看结构、触发、应期与具体任务；不能以低分直接断事情不成。不得把这些研究分档冒充已验证的自然能量单位或准确率。

实际取用后，其他宫位可能生扶、泄耗或克制类神。先依原法明确双方类神身份、实际影响通路和依据，再调用`liuren_compute(action="strength", strength=...)`补算；不能因五行相生克便自动全盘联算，不能自行估算、手加分或另乘空亡倍率。工具推导生克类型及固定系数，返回单宫分、补算分、差额与分档；主、子均直接采信程序数值，不复核排盘算术。工具不能验证取用理由的专业真伪：模型仍须解释取用、能否兑现及最强反证。取用纠正时，用完整的新关系清单重算，不在上次补算结果上层叠加。原有直接关系工具自动跳过，未提交关系不扩散。

补算沿用原盘月令条件表，季月有双表时说明原法依据并沿同表比较，不按得分高低择表；需敏感性比较则两表各算且分别解释，不平均、不计两票。时间改变另按U10查应期，当前补算不自动更新时柱或旬空。三合/半合/三会数值继续暂缓。

单宫E与对某对象的实际作用分层：官鬼、财、父母的直接贪生合及制救仍依U03/U06；自身旺不保证能为我用，弱也不等于不能用。补算已适配的直接贪生/合绊降低对外传递，尚未量化的刑冲、神煞、事件条件仍由原法分析，不拿研究分数覆盖。完整定向作用A若为null代表适配不足，不是没有作用。

仅在需要给出取用后的数值增减时强制调用补算，不把所有盘面关系变成新待办。主智能体准备保持中性，裁决者可改候选类神并调用同工具；主智能体核对分数含义、关系依据和口径一致性，不重新折中改判。详细参数及调用例见`deterministic-tools`，工程接口不限制自由裁决报告。
