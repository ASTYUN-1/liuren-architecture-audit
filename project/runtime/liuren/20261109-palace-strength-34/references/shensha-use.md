# 神煞位置与取用

直接使用 shensha_resolution / deterministic.adopted_shensha：固定38条规则及常用32项的采用状态、天盘所属支 places.tian、所临地盘 places.di 和乘将 places.jiang 均由程序给出。神煞附天盘支，地盘仅为坐处；午加丑，午之神煞仍属午。不要只用 keyShensha 摘要；缺全量时复用归档调用 liuren_materials(action="shensha",path=archive.path)，不重起盘。

不重算岁月季日旬公式，不比较旧引擎与固定表，不逐盘记录已解决异法。missing_input / invalid_input / disabled 不作判断或背景风险依据；未登记标签不自行转正。发现具体异常才说明受影响字段并转维护，不让模型改盘。阳刃/羊刃、小耗岁/月、旬癸/闭口课等保持程序身份，近名不互代。

## 在同一主线中使用

浏览程序全量状态和落点，结合下表识别相关项，不只限三传；课传、关键类神、相关年命及直接上下有切题作用者纳入。不另写32项核算法或全通过台账，报告只说明关键作用和影响本问的缺口。

神煞可为专法类神或限定性质。对有关项说明对象、阶段、位置、气态、组合及制救，影响结果/过程/程度/时间中的哪一环；普通神煞通常补象，不能以“辅助”为由拒收改变关键条件的有效反证。同支多名不投票，但有效类聚/重神/变质组合不能拆散。

表内简义用于初选；具体含义或专法条件未清时读 shensha-meanings / shensha-other-meanings；字段名称不明用 shensha-engine-index。神煞全解中八字段不挪作六壬义项。仅有某项不足以保证或排除其结果；未见某煞也不证明相反结果。

## 常用项目的应用边界

| ID | 项目 | 占类与作用条件 | 来源 |
|---|---|---|---|
| S01 | 太岁 | 年运、家宅、权威及尊长人象；病占不能单见太岁便认死亡。 | SF-02、SF-15 |
| S02 | 帘幕贵人（引擎名帘幕） | 考试、文书、求助、官禄深化；查临干/年命、乘神与朱雀关系、空墓。现任官员等语境不同，不能统一断高中/获助。 | SF-05、SF-18 |
| S03 | 驿马 | 出行、调动、行人及疾病变化；动与达成分判，查合绊、空墓、恋生及所乘将。 | SF-04、SF-14 |
| S04 | 天马 | 迁动、升迁、远行等深化；不能用驿马或丁马公式替代，月序缺参则本盘未采用。 | SF-12 |
| S05 | 丁马/旬丁 | 动变；金日丁鬼、水日财动仍核作用和状态，不能由日干类别单独定凶福。“成神”另见S06。 | SF-03、SF-13 |
| S06 | 成神 | 成合、谋事、婚事/求职等结果节点重点；有成神不保证成事，要看主事神将和成合链是否有效。 | SF-12 |
| S07 | 旬癸闭口 | 消息、面试、求人、财禄或病不食等按对象分判；旬癸在盘中不等于全局事不成，未见闭口也不证明开口/成功。 | SF-03、SF-13 |
| S08 | 小耗（岁/月分列） | 财物损耗、失物、家宅与年运；是否真损及多少另看财与本人。 | 岁法SF-11、SF-15；月法《壬归》LF963 |
| S09 | 破碎煞 | 财、器物、工程、关系或损伤的破损线索；与天空/丁鬼并见不能直接写成吉象全破、破财无疑。 | SF-14 |
| S10 | 月煞生气；与生扶/长生另分层 | 病产、新事、新旧等深化，核是否在日干年命或真能生扶目标；可生病鬼，空亡也不能单独保证存亡。 | SF-03、SF-12、SF-08 |
| S11 | 天喜 | 婚喜、孕产、官迁财喜等；RG要求不空墓绝，喜的具体事件和阶段须有主线支持，不是万能救。 | SF-11、SF-19 |
| S12 | 日德/干德 | 取用、专家助力、德解；核是否德化为鬼或受空刑害，不能德即救命；同支德禄不算两次独立证实。 | SF-06、SF-13 |
| S13 | 日禄/禄神 | 工作待遇、财源、饮食、养身等随目标；旺禄也须看能否到手，空墓闭口等只在对应对象和作用中定限制。 | SF-04、SF-09 |
| S14 | 支德（日支为基准） | 明确原义为解凶增吉；合参四德宜生旺、忌空落空及神将外战等条件，实际助佑须有通路。不是日德、月德的另一名字，不能以年支静默代日支。 | SF-17、ME-01、ME-02 |
| S15 | 月破 | 家宅、婚约、财事等；月破可散喜事也可解忧，须核对象、力量和本问目标。月破与破碎不合并，不因一个破名断月内必败。 | SF-12、SF-21 |
| S16 | 丧车 | 病、丧事等重点；来源有克日断死强语，实际须核患者、类神、神将气地及救制，不直接变为死亡程序。 | SF-11 |
| S17 | 天医 | 病占医药类象重点；天医受伤、克日/脱日等不能只凭名字认医术必效或病愈，疾病/阶段有别。 | SF-03、SF-12 |
| S18 | 地医 | 病占医药类象；土医/老中医是原书象义，不能据此断真实医疗身份或保证疗效。 | SF-03、SF-12 |
| S19 | 岁病符 | 病占、旧事、家宅等；优先笔记有克或临年命日干等条件，不因盘内出现就判特定人生病。 | SF-02、SF-11 |
| S20 | 死符（固定岁干法） | 病、年运重点；任一名中不单独定死，多种死名不计票。 | SF-15、SF-16 |
| S21 | 月煞死气 | 病、孕产、旧事/物品等；核落点、克害及制救。没有命中死气不证明无死亡风险，命中也不足以独断。 | SF-03、SF-12 |
| S22 | 季孤辰 | 婚恋、家宅、人际、支援力量等；可为势单力薄/独处，不直接证明终身无伴或必分手。 | SF-02、SF-11 |
| S23 | 季寡宿 | 婚恋、人际、家宅等，与孤辰可相关但不是同支表；不因名寡认丧偶。 | SF-02、SF-11 |
| S24 | 桃花 | 婚恋、人际、交往等随所问深化；不能单见桃花便断出轨、来访、死亡方式或剖产。若另用上门等格局，须另有完整定义与成立条件。 | SF-04、SF-14 |
| S25 | 文星（具体表） | QZ明确有文星并龙加子的条件用法；学习/文书为应用整理，仍须相关主线。JH另称长生为学堂/文星，不能互相证明，不并作文昌或保高中。 | SF-16、SF-08、ME-03 |
| S26 | 旬奇 | 功名、奇遇、新事等；单旬奇与三奇结构分判。TY不认三奇必吉； | SF-24、SF-09、SF-13、SF-22 |
| S27 | 旬仪/旬首支 | 礼仪、庆会、考试等；是否成六仪课另核其定义，空刑害和神将状态仍须查，不能有仪即病愈狱出。 | SF-03、SF-09、SF-13 |
| S28 | 退神（日干分组法） | 退避/推进、求职、谋事、出行等；原文“不可进”在其方法内作提示，须与进退目标和主线比，不等同退连茹。 | SF-16 |
| S29 | 进神（日干分组法） | 进取、谋事、考试、工作、出行等；原文“不可退”不保证推进必成，不等同进连茹课。 | SF-16 |
| S30 | 血光煞；另核血支/血忌 | 病、胎产、伤损、争讼/出行风险等；须有对象与损伤通路。见血不等于剖腹产，也不排除剖腹产；发作阶段与安危分别判。 | SF-17、SF-12 |
| S31 | 阳刃（与羊刃分列） | 阳刃为重要项目，羊刃次之；相近象义可参，起法、命中及证据身份不互代。病、胎产、争竞与刀伤等须核对象、位置、神将气态及实际作用；不凭刃位保证或排除手术、意外、剖产。 | 《理法简易》LF2656；原文称羊刃，名称身份与程序标签分开。 |
| S32 | 丧门 | 病、丧事、家宅、年运及失物等按本问；丧门未必凶，须核具体人物、落点、力量与救制。丧门与吊客并见不单独证明死亡，也不能因不足独断便排除死亡风险。 | SF-02、SF-11 |
