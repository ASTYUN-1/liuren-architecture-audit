# 家宅地产：取用与专项判断

共同规则只按 class-mapping 执行一次。以下保留每条适用、结论和排除；通法/专法先分层，不将旧默认扩成无例外。各 ID 的完整引文、双行号、哈希、候选身份和细节见原规则卡。

### LR26-TXY-C21 家宅：人宅定位与课传对双方的作用

适用：所问是宅况及居住损益，已明确该宅与居住者。

干人支宅，先分别看支干及上下，再核三传生克脱耗究竟作用于谁。三传生干脱支、生支脱干等分别描述人宅的不同损益，不以整体旺相替代宅本身的判断。

边界：人旺不等于房屋每个方面都好；宅受损也不自动等于某种具体灾害。；交易成否、贷款、产权过户的现代专法本批未齐。

出处：指南 LF662—675；北海毕法 LF2033—2055；心镜 LF820—824；完整引文见同 ID 卡。

### LR26-TXY-C22 家宅：构件、邻里与迁居另有位置分工

适用：明确问构件、邻里、居住或迁居，不把宅况与搬迁混为同一目标。

指南以支左右察邻、支上对冲察对门，卯门酉户、未井巳灶等配乘临；迁移再核旺禄、死绝、墓网、丁马及变格。象意须在相应构件和关系中有作用。

边界：家宅构件词表不是现实勘测证明。；阴地的龙神、明堂、水口定位另属专项，不能直接套到阳宅房间。

出处：指南 LF680—697；壬归 LF917—921；完整引文见同 ID 卡。

人宅实查补充：支取宅或车库时核其上下及水火对宅的真实作用；不能由整体水势、“不成大灾”、水不入传或辰为水库保证无水。亥楼、午堂、卯房、丑勾田产等候选依具体构件和乘临取义，不是见象即成事。
