## R — 原文 (Reading)

> 终身课，以本命看口质，以行年看相貌和当前状况。有两点，切记：1、年命入课传，看年命本身；不入课传，要看年命之上神。……占人终生，以三传为初中末三限。……一课中，既显示整体的、长久的信息，又显示现在的、当前主要的事件。
>
> — 北海闲人, 第三讲《类象之动》/ 第九讲《升职与加薪》/ 第十一讲《断应期之一》

## I — 方法论骨架 (Interpretation)

> 2026-10-19执行口径：下列原有方法保留出处；应用时按 E 节核对本问、位置、状态和最强反证，不能将单项命中或作者“必”字作为提前结案。

面对的问题是"占人一生/较长时段的运势"。目标不是单一吉凶，而是输出**结构化人生档案**。按固定管线读取：

1. **年命管线（g13/f09）**: 先定位本命与行年——年命入课传看年命本身，不入课传看年命之上神。本命看品性/本质，行年看相貌与当前状况；品性以天将为主、支神修正，相貌以天将为气质、支神为人体的突出部位特征。
2. **三传三限（g14）**: 三传=初中末三限（人生三段）。每限两读：天将=该限主要运势特征（贵人公职、白虎变化急躁、玄武遗漏郁闷…）；支神对日干六亲关系 + 与命上/干上神的合刑冲破害=该特征的具体吉凶事件。
3. **一课双时层（f17）**: 同一课同时承载"长期全局"（三传链）与"当前近况"（日干上神）两层时间信息，结论分两个命名空间输出，避免串层（林子成例：三传=从小到老，干上=四十八岁当下）。
4. **三传定位法（f16）**: 发用=我方/出发点、中传=道路、末传=他乡——"去哪/留这"类空间问题用初末旺衰比较（初旺末否不宜远行，初囚末旺彼处有机缘）。
5. **吉凶调制（f18）**: 爻吉凶 × 乘将吉凶四象限——吉×吉=吉上加吉；吉×凶=吉中有忧；凶×吉=灾缓（温柔一刀）；凶×凶=灾烈（人间地狱）。每限结论都过一遍此调制。

产出：终身档案 = 本命品性 + 行年相貌/当前 + 三限逐限（运势特征+吉凶事件）+ 当前状态 + 逐年应期要点（配合 s13）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 男占终身（本命行年+三限）（c10）
- **问题**: 男占终身（八字：乙丑 壬午 癸未 己未）。
- **方法论的使用**: 年命三限管线。本命丑入课传乘太阴=外表文雅寡言、实际充满斗志，太阴临未为观书=好学习、一生事业有成学历高；行年上勾陈临丑=脸偏圆、肩背略驼；干上丑太阴=管我的、干阴未勾陈=我管的→断学工程机械专业；三传为三限：发用巳作天空与本命丑相合=铸印、象的激发→少年孤闷、母病；一课双时层+逐年应期（2000 家变/04 威望/05 学习认真/08 找工作受制于女）。
- **结论**: 一生事业有成、学历高；少年有运势蹇滞时段；08 年技术工作受制于女子。
- **结果**: 逐条反馈应验（16 岁前开朗后沉闷、00 年父厂破产母糖尿病、04 有威望、05 学习认真、08 在亲戚公司任技术副总、受制于女上司）。

### 案例 2: 占运势（勾陈大限，辛酉命）（c13）
- **问题**: 占运势（辛酉命，问一生阶段运势）。
- **方法论的使用**: 大限+凶煞。本命酉乘太常=为人实际、能克制自己踏实工作；发用天后作财=沉静好学生；第二大限为中传，丑鬼作勾陈且被地盘午害=22 岁后麻烦不断、如被捆住手脚（勾陈"迟滞"义，非只断官司）。
- **结论**: 早年顺遂、第二大限长期低迷麻烦不断。
- **结果**: 反馈逐条应验（00 年大病高考失利、01 奖学金、02 感情不顺、04 有经济收入、06 婚后转幼儿教师、07 生病抑郁 8 年需吃药、工作换多份做不长）。

### 案例 3: 女占终身（性格/姻缘课）（c34）
- **问题**: 女占终身（八字：丁卯 丙午 辛丑 癸巳）。
- **方法论的使用**: 年命+三限+凶象。本命卯上亥作贵人=正统、遵规守纪、多少阴郁；行年亥上未作太常=圆脸略偏长额头大，受三传火生故胖大、贪吃肠胃不好；发用戌加寅，孤寡全逢又空闲=空孤→寄养外祖母家；干上丑管我的、干阴酉我管的=自动化/控制机械专业；发用戌加寅主 24 年、空寡作后=24 前姻缘不成；05 后酉作太阴切入、酉戌穿害=三角恋爱痛苦。
- **结论**: 性格正统阴郁、专业机械自动化、24 岁前姻缘不成、05 后有三角恋爱之痛。
- **结果**: 反馈逐条应验（自小寄养外祖母家十几岁方回、自动化专业、多次恋爱不深入、05 后三角恋爱极其痛苦）。

## 本占类的理气落实

先区分问事课多年/年运与出生课推命，固定时间层及对象。三传、年命、流年各说明参照，不用一条当下凶象覆盖一生。每个主维度查理气和有效救制；流年引动不重写原局，重大结局不由元胎、墓空等单一课名确定。

## E — 可执行步骤 (Execution)


1. **确认跨度与材料**：终身、若干年、单年或当前近况分清，记录本命/行年及其来源，缺失不补。只问一年不强展整个人生，也不以个性/外貌描述替代事件判断。
2. **分开长短时层**：沿用年命定位、三传三限、干上近况，但说明采用三限的条件；当前不顺不能外推终身，回顾既往与预测未来分节。具体年龄边界需有数源与算法，不任意推三段年龄。
3. **逐时段分维检查**：每一时段分别读神将、六亲、位置与引动，核最强反证；勾陈鬼等形成阻力倾向也不停止核对救应。不能用一个课体列出很多可能事件再以中一项算验。
4. **逐年推断与输出**：逐个实际问题给主要判断、必要备选和时间范围，职业/婚年等不无限列举；需要精细应期转 `yingqi-panduan`。已知经历只作核对，不冒充事前预测。

设计来源 B04、M06。M06 多婚年、多职业的自由度作为边界保留，没有把其断法直接提升。共用 [判断方法规则](../daliuren/refs/judgment-workflow.md)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单问未来一年综合运势——用时运课综合断法（s07），本 skill 覆盖多限/终身。
- 单问升职加薪/恋爱成否/财运——用对应专项 skill，本 skill 只在限运事件中借其判据。
- 需要精确应期断日——用 s13（先定迟速、再定日期）。

### 作者在书中警告的失败模式

- **ce06 勾陈大限（全条）**: 勾陈不只主官司、打斗，更主"迟滞"——运势极度低迷、像时间停止、做啥事没啥进展；遇勾陈临干、或占某一大运（中限）主题，则麻烦不断、恰如被捆住手脚不能动弹（c13 丑鬼作勾陈且被地盘午害，22 岁后麻烦不断）。
- **ce13 同一课可多解**: 终身课"以本命看品性"自由度极大，同一课用不同侧重可得不同结论；f18 调制再放大组合空间，结论对侧重选择高度敏感。
- **ce14 可证伪性**: 象意系统（干支×天将×位×阴神×年命）组合自由度极大，逐年应期几乎总能事后自圆其说；书中无对照、无盲测、无统计。
- **ce12 幸存者偏差**: c10/c13/c34/c37 全部"果应"且多为占者事后自述，无失败样本，真实命中率不可知。

### 作者的盲点 / 时代局限

- **长周期检验缺失**: 终身课宣称覆盖数十年，但反馈多为数年内的近期事件，缺乏完整生命周期检验。
- **历法门槛**: 依赖月将加时起课、太岁/行年推算，对不掌握干支历法的现代读者门槛高。
- **信仰前提（ce15）**: "干支五行→人事存在客观映射"（如太阴=抑郁、勾陈=工程）被当作不言自明，从未论证。
- **时代语境**: 案例中"干部/有威望/工厂破产/技术副总"等判断依赖 2000 年代社会语境，需转化为现代职业形态。

### 容易混淆的邻近方法论

- 与 **时运课（s07）**: s07 是一课一时段的五维检查，s14 是多限结构档案；年运课若只问一年用 s07，问一生/多限用 s14。
- 与 **应期（s13）**: s13 是通用时间算子，本 skill 在限运/逐年外推时调用它——二者是"内容"与"时间轴"的配合关系。
