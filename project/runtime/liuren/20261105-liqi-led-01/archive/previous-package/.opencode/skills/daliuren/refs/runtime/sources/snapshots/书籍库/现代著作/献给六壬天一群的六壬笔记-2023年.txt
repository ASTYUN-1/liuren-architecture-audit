二.四课

四课是显著的象，类神的时候不要出四课，这个很关键。

若找不到类神则用神将互换换出来。方法请见第十四条。

四课对比则有了阴阳，分别代表不同的象，需要注意的是阴阳全靠对比，无对比则无阴阳。

其次，阳是显露的内容，阴是隐秘的内容。

巳乙

四.四纲

年月日时就是四纲，六壬中四纲是一个力量强弱的判断系统。

年（国家）（年长）（力量最小）（宽泛）（环境）

月（省份）（中年）（力量次小）（范围）（旺衰）

日（当地）（青年）（力量次大）（粗略）（主体）

时（村镇）（少年）（力量最大）（细致）（征兆）

在理解上简要而言：

1.  时作先锋门，由于它力量最大，是事物的先兆，也是事件的切入方向。

2.  日就是我的本身。

3.  月代表天时的旺衰，掌管着五气休囚。

4.  年就是太岁。

在技法的运用上：

地支六合找信息的时候，是需要四纲的地支，例如子丑合化土，则需要四纲上有土支，否则是

合而不化，合的力量就少了许多。

天干五合在找信息的时候，同样的需要四纲的天干，例如乙庚合化金，需要四纲有金干，否则

同样是合而不化，力量也少。

日干日支需要力量对比的时候，就需要看月，以此来判断五气的旺衰，月令的气代表的是一种

权柄。

十二.六亲关系

我实际应用中六亲关系是可以一直延伸的，不一定是官鬼一定是不好的，可以取象。是一个辅

助的类象。

1.  官鬼：一般主丈夫，旺气四纲上官员居多，也住麻烦，乘贵人太阴主鬼神，这些是老生常谈

的。那么官鬼我认为一个比较特殊的象是不利，就如果不测官事，什么象克日干就是什么对

日干不好，就会反常。比如朱雀神克日干，这个人成绩估计不行，六合子神克日干，那么也

断作孩子不听话，天后神克日干，也代表女人爱和我吵架，当然是举例子嗷，就六亲一定是

辅助的象，代表一个动作当然也代表身份。

2.  妻财：一般的妻财肯定就是说妻子财物，在案例中我们能常常看到，天后也是妻子也关什么

六亲，这个时候六亲关系变成了辅助，我们同样看到财是我的所有物，也代表吃喝玩乐，当

乘玄武神也未必是偷盗，也可能是享乐不正当那种。

3.  子孙：脱气这是我们常用的，损耗的气，也代表创造的产品，成果，文书一类，当然还是要

说这个象是辅助，子孙也代表孩子，子孙的子孙又是孙子对于日干而言是财，但是这个时候

就不能说是财，要说是子孙。请看邵彦和先生《邵木匠占终身》就有一课是我所说的这个情

况。子孙爻克官鬼，所以占疾病子孙就是救神，占官就不好，驳斥官鬼之神。

4.  父母爻：这个代表父母的象，也有长生代表父母的象，取哪一个？都取，优先取上了课传的，

这个很有必要，父母爻也做考试是印，一般朱雀和午没上传看父母的状态，长生的状态都是

可以的。

课式体要
庐溪徐次宾述
    中式大体有八门，一曰先锋，二曰直事，三曰外事，四曰内事，五
曰发端，六曰移易，七曰归计，八曰变体，曰时、日、辰、年、命、三
传也。

先锋门者，谓所占之正时也，为财、为合、为刑、为害，不待运式

而先有所主，故曰先锋门。

直事门者，谓天上正时也。假令甲日未时为日下之财。若小吉上乘

天空，是虚妄干财也。谓天上正时将直事，故曰直事门。

外事门者，以日干为外也。若时与日合为外合，若时与日害则主外

忧。盖日为阳、为尊、为外事，故曰外事门。

内事门者，以辰为内也。若时与辰害则内忧，若与辰冲即主内动。

盖辰为阴、为卑、为宅、为内事，故曰内事门。

发端门者，初传是也。假令正月占事，若用起大吉丑，即为过去
事；用起功曹寅，即为目前；用起太冲卯，即为将来；以其为灾福发用
之端，故曰发端门。

移易门者，中传是也。谓如初传凶，中传吉，即移易其凶象，变而

为吉，若初吉中凶，即移易其吉象，变而为凶，故曰移易门。

归计门者，末传是也。如四月甲日占事，而用传见申酉，末传见

午，即主五月内无事，故曰归计门。

变体门者，人命之事也。谓四课虽同时而人命不同，以人命所见神

将各异，故变其卦体，所主灾福亦不同，故曰变体门。

凡占一课，八门之内须要消息详审，择其精要而断之。若习之不
正，择之不当，则毫厘之差，千里之失。当首立此章以明课体之要，次
标假令以明课式之用，故学者于此当尽心焉。

二.三十五岁丁卯生男子占来意

卯命上神寅乘六合，为私门

发用戌乘天后也作私情，三传有戌酉二婢也有后阴二女，发用在内，正时在外主与二婢女

有不正往来，且戌酉申为死墓之乡，天后玄武皆克丁日干，主咳血。

三.八十一岁辛巳占来意

巳命乘天空，下临道路，加上发用戌临支上斩关发用，主二婢女逃亡，此人来追逐。

正时门午克申乘玄武，是为被马姓男子捕获。

总结：徐次宾先生给我们提供了断课的一个思路，把握 720 课结构，一定有相似处，但是

如何分辨到底细节如何，需要我们根据已知因来判断，从年命入手。

此三则，一二则皆是得病，二三则皆是婢女之事，说明了结构有相似处，以人事不同来决

之。
