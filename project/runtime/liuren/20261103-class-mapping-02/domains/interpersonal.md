### LR26-TXY-C05 人际：四课先看人我对待，阴神可揭助阻环节

适用：问题确涉请求、会见、合作中一方对另一方的作用；先说明动静主客。

壬归以日辰及两上神看双方处境与相投，再看阴神的生扶制约：明面相助而阴神制之，不能直接认定相助必能落实；阴神的乘将用于分辨所畏之事或帮助来源。

排除与边界：原文以干求为例，朋友、同事、上下级的具体身份仍须本题与来源支持。；不因现实有三个人就把阴神固定为第三人；阴神也可指事。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：壬归 LF405—415（工作台405—415）；壬归 LF443—459（工作台443—459）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C06 人际：去求人与等待答复阶段可改变干支

适用：所问确为主动求办或已求后等待答复，实际阶段已知。

北海分别取：尚未去而打算求人，我动为干；已去、现待对方消息，我静为支，对方为干。此法不可因结果不利而临时倒换。

排除与边界：不是所有代问或人际都按谁动谁为干；先核具体专法。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF182—186（工作台363—371）；理法 LF636—638（工作台1271—1275）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C07 事业与组织：人职关系和总分关系分别定位

适用：分清问人任职、单位经营，还是总公司与分公司的关系。

北海工作常法干为人支为单位；单问总公司运营可支为总公司，问总分关系则总为干分为支。干支关系轴随着实际问题改变，不能由机构名字固定。

排除与边界：同事信任问不因发生在公司就套任职；公司盈利须另取经营与利润目标。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF188—188（工作台375—375）；理法 LF709—713（工作台1417—1425）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C25 行人：音信类与人到类必须分开

适用：所问包含联系、书信或何时人到，分别编号子问。

指南以朱雀、天鸡、信神及其乘马空陷察音信，另有支前四位上神的书信层。收到消息不等于行人已经到达，信神也可在其他明确的信息问题中用。

排除与边界：不能以音信通达直接保证归来、复合或录用。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：指南 LF772—783（工作台1543—1565）；理法 LF944—945（工作台1887—1889）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

出处：金针 LF1432—1444（工作台1432—1444）；理法 LF893—895（工作台1785—1789）；理法 LF913—923（工作台1825—1845）；北海毕法 LF4796—4798（工作台4796—4798）；北海毕法 LF4816—4832（工作台4816—4832）。完整连续引文见同 ID 规则卡。

## 原有专项（保留来源与适用条件）

# interpersonal 占类方法

来源方法：`renji-guanxi`；依总入口加载，完整条件见下文。

## I — 方法论骨架 (Interpretation)

人际判断以日干为自己，核心是把"关系"翻译成可判的损益矩阵。作者给出一条总则 + 一条态度法 + 一个夫妻专用框架：

1. 整体人际总则（p24）：扫课传——生、合、德=对我有利的人事物；刑、克、穿、鬼=对我不利的人事物。具体是何人，看天将、支神的象（蛇=小人、轻薄女子；寅=老年人、带草头木字边姓氏；六合=中介/意愿……）。
2. 某人态度损益法（p25）：取其类神，看它（类神）对三个锚点——日干、日干上神、本人年命上神——的损益。益=生、合；损=克、脱、刑、穿。三个锚点皆损→实质有害；皆益→可靠助力；混合→有条件的合作。
3. 夫妻占框架（p26）：以支为妻位，天后、太阴、妻财爻为妻星，看何者入课传；干支上神生合则和、冲克则恶；两财同现时按古法"初夫末妻中传媒人"定位。
4. 年命锚点（g13）：年命入课传看本身、不入课传看年命上神；他人类神克年命上神=此人对我实质不利，即使表面上生合日干。
5. 关键前提：人际关系不主吉凶，但"关键时刻别人的态度往往能使乾坤扭转"——它决定钱的来源、家庭的组成、贵人或麻烦的降临。
6. 产出：整体环境定性 + 特定人物态度矩阵（益/损）+ 人物类型提示 + 夫妻关系专项结论。

## E — 可执行步骤 (Execution)

1. **定位关系与视角**：确定问自己与谁、对方态度、实际合作还是关系后果；按题干身份取角色/年命，缺失留空。关系成否转恋爱专项，但相处、利益与意愿仍分别判断。
2. **建立关系矩阵**：沿用类神对日干、干上神和已知年命上神的损益法，注明位置和状态。区分我求彼/彼求我、表态/行动、对我有利/对其有利，不能把多个锚点当独立验证次数。
3. **检查反证与条件**：表面生合也看空陷变质；相克也核是否针对同一层面或仅现实阻碍。说明为何判为助力、损害或有条件合作，不由单一天将推定人格或隐私事实。
4. **输出**：对方态度、可观察行为倾向、关系结果分别给依据；疑似私情、动机、人物职业只作解释候选，不回填为既知背景。未问的重大事件不凭弱象越占。

沿用上文 p24–p26 与年命锚点，补充 M13 的发起/回应区分；未知动机保留未知。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- ce03（变质）：看他人类神生合就断友善，忽略类神变质——如贵人作鬼、日德作鬼被勾陈夹带则"没德"、六合空亡=虚情假意、合神空亡=双方无心。c24 中"六合太阴阴私甚重=私合"即表面合、实质坏。
- ce13（同一课可多解）：同一课既可断"环境"又可断"夫妻/同事"，对象归属依赖解读侧重（c22-c24 对象都在变），结论对侧重选择高度敏感。
- ce14（可证伪性）：天将支神象意（蛇=小人、寅=老年人、六合=私门）是未论证的映射常量，事后总能自圆其说。
- ce12（幸存者偏差）：书中人际案例全部"果应"，其中 c24 事后才知是私合关系——断前无法证明判断成立。
- ce15（信仰前提）：干支五行映射人事是未论证公理。

### 作者的盲点 / 时代局限

- c24 中"同事关系"事后证实为"不正当男女关系"——作者以结果倒推课堂逻辑，未讨论判断对象错位/断错的概率。
- "人际关系不主吉凶，但关键时刻别人的态度能使乾坤扭转"——益/损的量化判定无法独立验证。
- 夫妻框架中"妻非贤妻"的判断基于天将/支神象意，含有主观道德评价色彩，与现代性别语境有偏差。
