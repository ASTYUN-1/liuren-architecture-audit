# 胎产生育：本轮取用补充

### LR26-TXY-C19 胎产：是否怀孕先取干支胎，不以子孙统代

适用：具体问是否受孕或孕期维持，核干支各自胎神及所用长生法。

金针以干支之胎作有孕类象；北海毕法将胎爻、财爻、月内生气死气区分。胎财生气是复合条件，不能删成只见财或子孙便有孕。

排除与边界：土胎子午存在北海内部起法差异，须列法别，不能双取凑命中。；原例私孕、堕胎等描述不是据盘即可认定的现实事实。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：金针 LF1367—1379（工作台1367—1379）；北海毕法 LF1449—1467（工作台1449—1467）；北海毕法 LF1630—1634（工作台1630—1634）。完整连续引文见同 ID 规则卡。

### LR26-TXY-C20 胎产：孕期宜静与分娩宜动，母子分别取类

适用：先明确在孕期保胎还是临产分娩阶段。

北海将动神、血神等在孕与产的宜忌分开；产时兼看干支、合后。指南以支母干儿，又察天后母、六合子及其受克，胎位与产期另查，不能单凭动象就说母子平安。

排除与边界：同一符号“孕中受损”与“分娩发动”不冲突，前提是阶段确实不同。；生产动象、母子安危和是否怀孕分别回答，不把古法当医学结果。

待辨：具体使用仍以完整专项条件为限；本批无独立效果验证。

出处：理法 LF1344—1345（工作台2687—2689）；北海毕法 LF1449—1461（工作台1449—1461）；指南 LF719—727（工作台1437—1453）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D02 待辨：五行长生、土随水火与胎位的法别

适用：采用长生运、胎神或墓绝类方法前，核所据书、计算对象与起例。

理法447主五行长生水土申；指南庄按2567区分五行与十干并主张土干随火；北海毕法1463—1467保留土胎子或午。这是算例基准差异，不能只汇总象义后隐去。

排除与边界：同属北海的材料仍有不同口径，作者优先序不能抹平。；同一论证不能混用起法而不标，不能双法取有利结果。

待辨：通用讨论可先列北海理法五行法为默认研究口径；实际胎产条文中另起例须明示，待专项校勘后才能固化计算。

出处：理法 LF447—447（工作台893—893）；指南 LF2560—2567（工作台5119—5133）；北海毕法 LF1463—1467（工作台1463—1467）。完整连续引文见同 ID 规则卡。

### LR26-TXY-D03 层级辨析：主象、课体、显象及非占现类的边界

适用：比较的是同一子问中某结构或显象的实际作用，不只看“主”“辅”等字。

北海说大部分课体是支流，又承认特定组合能决定结果；非占现类要求不越问，却保留婚姻财乘暗鬼等专门例外。专项常用类神之外的显象应核相关作用，不预设只能作细节。

排除与边界：不是任见勾陈就增官司，也不是常用龙后不现便删除其余课传。；金针1444“不作为类象”等表述与其课体章总论有文字张力，保留来源，不删改原文制造一致。

待辨：先以构成要素、占类与所答维度分层，确仍不能统一之处另记，不用一张九系统权重表替代。

# pregnancy 占类方法

来源方法：`yunchan-panduan`；依总入口加载，完整条件见下文。

## I — 方法论骨架 (Interpretation)

面对的问题是"是否为胎产占、生男生女、顺产难产、足月早产、产期何时"。五步逻辑按序执行：

1. **来意断六甲——多象共振（p21/p23/f37）**: 占时为日干胎神（《毕法》"胎财生气妻怀孕"）+ 干上见子孙爻 + 支上见巳火太乙（胎产类神）+ 干支皆乘子孙。四象中多象共振方可断"六甲/胎产占"，勿凭单象；干支定位"干上主所思、支上主所行"辅助还原所问（z03 先由戴羲断来意、陈公献续断）。
2. **生男生女——多法并观（f38/p24/p25/f39/p26）**: 三套判据可对照，但独立性未证明，不能以同向代替验证：
   - 课体法：元首男 / 重审女 / 纯阳反阴女 / 纯阴反阳男 / 阳不备女 / 阴不备男；
   - 干上神比和法：干上神与日干比则男、不比则女；干上卯属震=长男、干上酉属兑=少女；
   - 金口诀法（《大六壬金口诀》"欲占孕育课中求，太乙常加本命头。阳将为男阴是女，更看生克定因由"）：巳火加女方本命属相宫，顺布至占时，上神阳=男、阴=女，作者称此法极验。
   - 判读纪律：原例以课体和干上神等方法互参；同向不自动证明结论，未同向也不自动证明相反性别。各法口径与适用条件分列，金口诀法另作方法参照，来源独立性未由此证明；支持不足则留未定。
3. **占产支干定位（f40/p27）**: 支=产母、干=胎儿；干支互临而生合=母子相恋主难产；支加干上=产妇低头见子=已生下来之象，主生产顺利。
4. **不备的原例取义（p28）**：原作者以气数不足解释本例不足月，作为产期/足月程度的候选线索；不是不备出现便必早产。须核相关结构、状态与反证，未能支持早产也不直接证明足月。
5. **应期——产期（f19/p29/f20/p31，细化转 yingqi-panduan）**: 太岁发用应一年内、月建一月内、日辰当日、时发用当时；前三辰法则——发用之神在岁/月/日/时之前三辰范围内，应在发用神当令之时（z03 未土发用、在月建巳前二辰，断六月生）。

产出：占类确认（六甲）+ 生男/生女 + 顺/难产 + 足月/不足月 + 产期（量级→月份→日时）。

## E — 可执行步骤 (Execution)

1. **先分孕与产**：已孕与否、妊娠过程、分娩方式、胎儿性别、是否足月和出生时间分问；题干已明孕产则不重做来意猜测。未明来意时以多象作候选，不用未经来源支持的“至少三象”阈值认定事实。
2. **角色定位**：明确本人/配偶/胎儿的取用和出处；书籍占产干支定位与当代作者妻财/天后取用是不同路径，不拼为同一法，也不为凑答案临时切换。
3. **按子问取法并检查反证**：先核所用经验否定的是单项推断还是现实结果，保留尚未排除的顺/剖候选；保留原课体、比和、年命等既有方法，但区分体系及共享信息。两法一致不证明独立；不备只能先记该方法的不足倾向，不一律当现实早产。顺产、母胎状态和性别不能互作证明。
4. **产期节点**：区分见红、宫缩、入院、发动和分娩完成，先定尺度，再调 [yingqi-panduan（方法模块）](<../methods/timing.md>) 定主选/备选。反馈事后落在第二候选也不能回改第一候选或增加命中项。
5. **输出与复盘**：仅回答所问，列各自依据、分歧及缺项。六壬论证不能据此作医学诊断或治疗方案；不把作答中的病理猜测写回背景。

设计依据 B09、M09；M09 有反馈但作答先后未知，仅作方法参照。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- **"生贵儿"附会（z03/北海闲人自评）**: 干上卯为幕贵、阴神又见财德贵马故曰贵儿，然财德贵马空亡，贵也不久——北海闲人评此断"有点圆滑"。定性附会辞（贵儿/贵格）须核对课盘支撑，空亡在象则断语打折。
- **多法互斥**: 生男生女三法（课体/干上神/金口诀）互证是纪律；若互斥不可强合，宁可存疑。
- **“不备”误读**：原例把不备取为不足月线索，仍须核本问条件，不能由单一课名保证早产。分娩难易与足月程度分判；限制一项证据也不自动排除早产。

### 作者的盲点 / 时代局限

- **无统计背书（ce12 同型）**: 金口诀法作者称"极验"，z03 结果"果一一如所断"，均为叙事性反馈，无统计、无盲测、无失败样本，真实命中率未知。
- **事后附会风险（BOOK_OVERVIEW 最强反对意见）**: 任何断语几乎都能事后找齐干支/天将/神煞/阴神任取其一作解释路径；读古断须按 p46 纪律回盘核对。
- **时代局限**: 古典产占以"六甲""足月早产"为语汇，无现代产检概念；性别、产期判断在现代语境仅作文化参考。
