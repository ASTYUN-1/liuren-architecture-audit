# 数法来源、数表与适用边界

按 [数量规程](<../methods/quantity.md>)选定对象后，需查数表、比较算法或核对原断时读取。本页是来源导航及条件摘要，不是按结果自由选公式的菜单。完整原文及文件哈希见 [研究证据摘录](<../../../../docs/应期取数归纳-20261027/原文证据摘录.md>)和 [定位数据](<../../../../output/应期取数归纳-20261027/curated-evidence.json>)；S编号沿用该研究。行号按源文件LF计，未核扫描底本。

## 数表

| 数制 | 映射 | 来源和使用条件 |
|---|---|---|
| 五行生数 | 水1、火2、木3、金4、土5 | 《六壬神定经》S01明确列数；生/成选择由具体方法定 |
| 五行成数 | 水6、火7、木8、金9、土10 | 同上；不自动按阴日使用。别处“成数”也可能只是计算所得数 |
| 十二支数 | 子午9、丑未8、寅申7、卯酉6、辰戌5、巳亥4 | S01、S13、S31；先天/大衍/太玄等名称按实际表辨认 |
| 十干数 | 甲己9、乙庚8、丙辛7、丁壬6、戊癸5 | S01；先说明取日干、哪种遁干及所附课位；这不是0—9的位数编码 |
| 后天卦数 | 坎1、坤2、震3、巽4、中5、乾6、兑7、艮8、离9 | 《天一群笔记》S31；卦宫与支位对应仍须有本法，不能与干支表临时互换 |

天将取数必须核对本法将数表，不能以该将所乘支代替其本数。本页不把特定案例中的朱雀、玄武数扩成统一十二将表。

## 保留为不同分支

| 分支 | 本地材料 | 执行边界 |
|---|---|---|
| 财神与着落之地相乘 | 《壬归》S04，9×8=72，再论旺衰 | 绑定所问之财与位置；后续增减、量级须查该段原法 |
| 天盘干支相乘 | 《拃河棹》S12、《粹言》S14，甲子9×9=81 | 与财神×财地分开，不再擅乘落宫；“旺倍182”等算术疑文保留待校 |
| 神将相乘 | 《集成五要权衡》S15，丑8×腾蛇4=32 | 使用本法的神、将及数表；不能把所有“上下”都译作同一对位置 |
| 相气加倍 | 《六壬粹言》S13—S14，4×7=28，再倍56 | 该书不同段落也有不进倍解释，须带上原段条件 |
| 月建倍、月破半 | 《集成五要权衡》S16，二月卯倍、寅虽旺不加 | 窄于一般旺衰；不自动叠到上一分支 |
| 减半、减三成、减七成 | S12、S22等载空、孤神、刑冲等不同条件 | 减的是何量、叠加次序和对象均须核原文；“吉凶减”不能径改为金额扣减 |

量级另有旺衰/远近进退位、“年万月千日百辰十时零”、大数与零数等研究线（S12—S14、S19、S22），尚未形成统一裁决表。“350或3500”是未定的离散量级，不等于已经解决量级。仅据应期四建层级不能推出金额等级。

## 精确数值案例：有反馈，仍须辨算法完整性

以下只在核对相应分支时查阅，不默认注入数值任务。它们已在本轮研究中曝光，不能再充作独立盲测。

| 记录 | 源文与反馈 | 不能补成通法的缺口 |
|---|---|---|
| 436分（S38） | 《天一群笔记》LF1049—1071；750满分，巳遁乙8折半4，另取朱雀9、巳4，原断与反馈436 | 为什么二课、折半及百位未全述。4×100＋9×4是整理者复原假说 |

| 6.5斤（S41） | LF2538—2560；9/2＋4/2，反馈6.5 | 两项选择、折半、单位与记录时序待核 |
