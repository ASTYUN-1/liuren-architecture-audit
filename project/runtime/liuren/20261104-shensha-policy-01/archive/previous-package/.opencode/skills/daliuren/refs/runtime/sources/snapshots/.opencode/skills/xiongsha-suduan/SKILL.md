# 凶煞速断（否定式过滤）

## 理气与取用修订（2026-10-22 · 当前执行规则）

进入实际判断前读取 [理气、救制与重评](../daliuren/refs/liqi-analysis.md) 和 [主流程方法规则](../daliuren/refs/judgment-workflow.md)；同轮已完整读取可复用。涉及神煞时再读 [神煞取用](../daliuren/refs/shensha-use.md)，核对出处或口径分歧时读 [来源卡](../daliuren/refs/liqi-sources.md)。

遇否定句、条件省略或经验摘要时，读取 [规则的适用范围与否定含义](../daliuren/refs/rule-semantics.md)。首次整理即写清范围、条件和断言强度；“仅凭A不足以确定B”仍保留B，不能改成“A排除B”。检索残句须回原文补齐限定，缺口保持未知，不自行造条件。纠错后的补注不当作误用前已有的规则。

关键节点须辨月令五气、坐处/十二气、生克脱耗、神将、上神/阴神、刑冲破害及空墓；比较作用双方，写明救谁、制谁、能否得力。遁干定点查，合不自动化，吉凶名称不直接等于结果。固定角色与坐标，同支多标签不重复计证；必要依据撤销后，重新裁决依赖它的结果及应期。

## R — 原文 (Reading)

> 凶的东西，总比吉的东西，更能以一种激烈的、迅速的气势出现，因此，断课的时候，找凶煞，往往比找吉气更容易，因此，在断课之时，我们可以先找到一个"凶"的充分理由，则可确定人有灾病，而事不成功。这虽然是一种"偷懒"的法子，却是一种极有效的法子，盖非吉即凶，肯定了一个方面，则否定了它的反面，自然之理也。
>
> — 北海闲人, 第四讲

## I — 方法论骨架 (Interpretation)

面对的问题是课传吉凶混杂，北海以先查凶提出风险。当前使用须把风险候选与终审分开，比较力量和有效救制，不能用非吉即凶跳过不确定。

四大凶煞各管一段：
1. **旬丁**（对事，移易）——按本问查待定结果/求稳之事的变化，朱雀乘丁不证明现实篡改，丁劫须核对象、力量与具体救制。
2. **白虎**（对人，伤损；对事，转折中断）——核发用/课上/阴神的具体作用。受制比较双方力量与位置，不把一处火克金直接等于病愈；天将与所乘支分开。
3. **勾陈**（对人=斗讼争官，对事=迟滞）——最常见的误用是只看官司打斗，忽略其"迟滞"义：运势极度低迷、如被捆住手脚。
4. **天空**（虚耗风波等候选）——保留北海凶义来源，仍核本问位置与制化；天空天将不等于旬空，不能以名称自动否决全局。

产出：风险候选、有效状态及作用范围，交主流程裁决；命中不是终局，未命中不是吉。

## A1 — 书中的应用 (Past Application)

### 案例 1: 徐盟鹿占远行被劫（旬丁+劫煞，古课）
- **问题**: 徐盟鹿携妻子远行，问吉凶（八专、绝嗣）。
- **方法论的使用**: 先扫凶煞——中传巳为旬丁又为劫煞，"飞祸横来，全家遭难"；再叠加：男干女支行入空墓之地、末传日死加巳"合为死字"、壬戌加卯发用"河井相加"主车船破坏。巳本为长生、太常为父母（生命之源），作丁神劫煞则"见生不生，不如无生"。
- **结论**: 全课凶象并集，断全家远行遭难。
- **结果**: 近江西百余里，男女五人被盗而死。

### 案例 2: 何子重占平生（白虎活用，古课）
- **问题**: 何子重四十八岁占平生福泽。
- **方法论的使用**: 白虎活用看"位"——干上长生作太阴（福佑），申为金银为僧、白虎为死丧，亥阴带申虎来＝"死丧之财"；课上的白虎作阴神只是显象，而虎之阴神见勾陈＝刑罚之象。
- **结论**: 先得死丧之财（僧人溺亡、拾银四锭）而宽余，宽余之后横祸即来，犯刑发配。
- **结果**: 次年拾银四锭作生意宽余十一年；第十二年伤人受刑，后被陈姓人告发配池州。

### 案例 3: 辛酉命占运势（勾陈大限）
- **问题**: 占整体运势（辛酉命）。
- **方法论的使用**: 勾陈双义——中传丑鬼作勾陈发用（第二大限主题），"本来就主麻烦多多"；又被地盘午害，"更是雪上加霜"。断 22 岁以后麻烦不断，主迟滞低迷而非单一官司。
- **结论**: 第二大限麻烦不断、工作做不长、身体长期不佳。
- **结果**: 反馈逐条应验：00 年大病高考失利、06 年后转做幼儿教师、07 年生病、抑郁 8 年需吃药。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **占事吉凶不明**：用户问"这事能成吗？会不会有麻烦/灾祸？"——先跑否定式过滤，查实际风险和救制后裁决，未命中不等于吉。
2. **结果会不会生变**：考试/应聘等待公布结果、工作生计姻缘等求稳之事——旬丁"移易"信号。
3. **怎么老没进展/低迷拖沓**：事情长时间无进展、运势停滞——勾陈"迟滞"信号。
4. **会不会落空/没来由的麻烦**：担心白忙一场、莫名风波——天空信号（北海风险象义，另核实际作用）。
5. **AI 作为分析框架**：问题与角色固定后检查相关风险和有效救制；不能以命中一煞提前定结论。

### 与相邻 skill 的区分

- 与 `jixiong-tiaozhi` 的区别：本 skill 提出并校验风险候选，调制 skill 分清结果、过程和程度，均不能跳过力量与制救。
- 与 `kongwang-bianzhi` 的区别：天空是天将，旬空是状态；两层分别核对象与条件，不能用“天空不论旺衰”省去全局理气。
- 与 `keti-qishi` 的区别: 天网课等凶课体是**课体层**否定，凶煞是**神将层**否定；同一课两者可叠加，先各自扫过再合并。
- 与 `yingqi-panduan` 的区别: 凶神"没则吉事来"（蛇居丑为蟠龟）是应期信号，但本 skill 只管吉凶定性，不管"何时"。

## E — 可执行步骤 (Execution)

1. **提出风险候选**：围绕本问核旬丁、白虎、勾陈、天空所处的干支上神、课传、类神或直接阴神；区分动变、伤损、迟滞和虚耗，对人/对事分别说明。未命中只表示本筛查无依据，不等于吉。
2. **核是否实际得力**：按共享理气比较天盘神、所乘将和地盘，查月令、坐处、生克制化、阴神及刑害空墓。白虎金与它所乘支的五行分别记录；见火不等于制得住，局部受制不等于病必愈。发用是位次条件之一，阴神伤类也须核查。
3. **同样检查最强救应**：风险候选须与所问发生明确关系；朱雀乘丁不直接证明篡改事实，天空不直接否定全局，白虎不直接证明死丧。核救制作用范围，关键阻碍被解除则可重评结果；只缓一项则限制在该项。
4. **返回条件化风险**：输出有效风险、受限/无效项、最强反证和剩余未知，交主流程及 `jixiong-tiaozhi` 裁决。不能以“命中/未命中”代替成败、生死或现实责任认定。

完成标准：风险对象、准确位置、关系与力量、制救范围及净影响。原书速断是方法参照，不是自动终审。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问**应期/何时**，不涉吉凶——交 `yingqi-panduan`。
- 纯**课体大势**走向问题（经济走势、方向）——交 `keti-qishi`。
- 课传**吉象并聚**（生合吉旺、龙常贵合并聚）已成局时，不可因单一凶煞就全盘否定——吉象并聚可替代类神不现（c27 应验），须交 `jixiong-tiaozhi` 综合裁定。
- 本方法是"速断"不是终审——命中凶煞后仍要复查课传是否另有救应（如 c15 中卯月将生起巳常，"破而不破"）。

### 作者在书中警告的失败模式

- **ce04 旬丁**：旧例强调待定结果及求稳之事的移易风险；不能把同类朱雀/旬丁关系直接判作人为篡改、倒台或遇盗的事实，须核完整作用条件。
- **ce05 白虎**：旧书以位次与受制讨论病伤；实际须比较白虎金、天盘所乘支、地盘和阴神的具体作用，既不见虎即死，也不见克即愈。
- **ce06 勾陈**：只断官司斗讼，忽略"迟滞"义——运势极度低迷、如时间停止、被捆住手脚。
- **ce10 财煞**：求财见财就断得财，忽略脱气（乘玄武/天空成脱耗格、脱空格，主钱财耗尽）、财怕空、财乘破碎煞、三传全财大凶、三传财局生鬼因财致祸。

### 作者的盲点 / 时代局限

- **ce12 幸存者偏差**：全书凶煞例（c11-c14）全部"果应"，无失败样本、无对照，不能当作命中率统计证据。
- **ce13 解释自由度**：同一课凶象与非凶象并存，断凶后仍可自圆其说——凶煞命中不等于判断被证实。
- **ce14 可证伪性**：凶煞判定缺预注册检验，未回应"命中率未必高于随机"的质疑。
- **ce15 信仰前提**：干支/天将/神将→人事的映射（如"白虎=死丧"）被当作不言自明、从未论证。

### 容易混淆的邻近方法论

- 与**空亡变质**（`kongwang-bianzhi`）：分别核天空天将、原局空亡及作用对象；原文的不同解释不拼成无条件结论。
- 与**吉凶调制**（`jixiong-tiaozhi`）：凶煞是定性输入，调制是程度输出，功能互补。
- 与**课体气势**（`keti-qishi`）：凶课体（天网课）与凶神将（白虎发用）是两层否定，都要扫，但来源不同。
