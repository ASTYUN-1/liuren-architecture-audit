# relationship 占类方法

来源方法：`lianai-panduan`；依总入口加载，完整条件见下文。

当前定位补充：传统常法干男支女，女问男不自动倒置；同性关系缺完整专法时先明确两位当事人及问题，不按性别刻板或主被动硬套；仅使用有据且适用的关系方法并说明边界。

## I — 方法论骨架 (Interpretation)

面对的问题是"两人恋爱能否成、关系如何发展、有无第三者、何时成"。三套逻辑按序执行，结果可叠加：

1. **常法（基础判据）**: 干=男、支=女，看干支上神关系——生合则成，冲克刑害则散；交车相合=暂时融洽终究分手。课体断语：解离格（干支互克上神）=先好后坏；干支乘墓=墓为止最终分手；人宅皆死=死心；干支皆败=灰心丧气。
2. **变法（纠偏判据）**: ① 年命倒置——支辰为男方本命/行年、或干寄宫为女方本命/行年时，干支角色互换而看；年命迭现以命为先、互为行年以行年为先。② 第三者象——天后/妻财/太阴临干 + 青龙/官星/贵人临支=另有对象、不成之象；但课传成合之象甚明反为速成。③ 男占：天后妻财临干与干上生合且支上不见官龙贵=成；女占反之。④ 铸印课不空陷=姻缘可成（形成整体）。⑤ 婚喜之象并聚（龙后旺相、太常天喜旺相生合、戌/父母乘六合=结婚证）则婚成。
3. **琐象（高准验快查清单）**: 四课不备三课=三角关系、两课=放荡同居；男占鬼临三四或人宅受脱=防被骗；课中勾陈作鬼=为情痛苦拖拉；太阴现课传=女子缠绕；财克干上长生=女方非礼义；玄阴后合太多=淫乱；子作六合=荡妇；未作天后=妇女奸淫；小吉单逢六合=婚姻聘礼。
4. **强信号（p37）**: 男女本命相加临课传、或行年相加临课传 ⇒ 婚必成，虽空无事；太常发用=婚礼之象佐证。

产出：成/散/先好后坏 + 风险标签（第三者/被骗/三角/无心）+ 婚期线索。

## E — 可执行步骤 (Execution)

1. **明确关系阶段与成功标准**：联系、见面、约会、确立关系、订婚、结婚、相处质量分别定位；按题干当事人与代问视角取角色，不预设每种关系的固定性别分工。
2. **建立角色与主线**：沿用干支上神关系、对象类神和已知年命取用；说明角色分配及是否有充分理由采用变法。多个对象分别比较，并保留均不成，不因换取用能得期望答案就倒置角色。
3. **检验成合是否落实**：检查空墓、旺衰、阴神、引动、现实阻碍与最强反证。年命相加等为书中强成合候选，不能直接判必成并停止。关系有联系不等于订婚，邀约失败也不自动等于关系结束。
4. **输出分层结论**：成否、关系意愿、过程/相处、所需应期分开。第三者等标签只能标有条件的解释，不能凭琐象认定事实或给人格定罪；相反证据无法裁决则留分歧。

沿用上文 c31–c33，参照 M05、M13。多对象定位和发起/回应可借鉴，具体对象成婚与动机未核验。共用 [判断方法规则](<../methods/positioning.md>)。

## B — 边界 (Boundary) ★

### 执行范围

本模块基础检查由总入口安排；旧版的独立 Skill 分流不再适用。细节只在本问相关节点展开，时间任务另读应期模块，不跳过基础检查。

### 作者在书中警告的失败模式

- **ce09 恋爱琐象凶例（全条）**: 四课不备只有三课=三角关系（准验度很高）、只有两课=放荡同居；男占鬼临三四或人宅受脱=防被骗；课中勾陈作鬼=为感情痛苦、拖拉好长时间；太阴现课传=女子缠绕；财克干上长生=女方非礼义之辈；玄阴后合太多=必淫乱之人；干支上神虽合但合神空亡或乘天空=双方无心（c31 酉丑相合而酉空丑天空，女有奸私事）。
- **ce02 空亡陷阱**: 恋爱课"干支上神生合"须查合神是否空亡/乘天空——空合=虚合=无心；天空之空不论旺衰皆凶。
- **ce03 变质**: 妻星/夫星类神乘凶将（如末传申蛇空亡=妻非贤妻、财作蛇=小人琐碎）则吉转凶。
- **ce12–ce15 公共方法学边界**: 全部恋爱案例"果应"无失败样本（ce12）；常法与变法结论冲突时选择权大（ce13）；琐象口诀可证伪性未解决（ce14）；"天后=妻、六合=媒"等象意映射是未论证前提（ce15）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: c31–c34 全部按作者断语应验于叙事，无断错样本，无法估计真实命中率。
- **解释自由度（ce13）**: "干支上神相合但空亡"可断"无心"，"空亡但得生"又可断"虽空无事（c33）"——同一空亡两种用法，结论弹性大。
- **可证伪性（ce14）**: 琐象口诀组合（干支×天将×位）几乎总能事后自圆其说。
- **时代与文化局限**: "女方非礼义之辈""荡妇/奸淫"等断语带明显旧伦理色彩，现代多元亲密关系语境需慎用（ce15 象意非普适常量）。
