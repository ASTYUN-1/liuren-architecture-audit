## I — 方法论骨架 (Interpretation)

> 2026-10-19执行口径：下列原有方法保留出处；应用时按 E 节核对本问、位置、状态和最强反证，不能将单项命中或作者“必”字作为提前结案。

面对的问题是：单看某爻/某支/某传的吉凶不够用——同一个"吉"（如得财），有人拿得轻松，有人拿得痛苦；同一个"凶"，有的灾来得平和，有的祸至猛烈。需要给吉凶加上**程度与质感**。

两个机制：
1. **四象限调制**——每个判断单元 = 爻/神本身的吉凶 × 所乘天将的吉凶，落四象限：
   - 吉爻 × 吉将 ＝ **吉而又吉**；
   - 吉爻 × 凶将（虎蛇等）＝ **吉中有忧**（如"拿到钱也是拿得极痛苦的"）；
   - 凶爻 × 吉将 ＝ **温柔一刀**（不能免祸，但灾来得平和）；
   - 凶爻 × 凶将 ＝ **人间地狱**（悖然祸至）。
2. **大背景缩放**——先定全局背景再缩放局部：背景凶（如贵人差迭、二贵受克）则"若有凶象则凶大，若有吉象则吉小"；背景吉则反之。课体气势（九宗门/毕法格局）作为先验参与缩放。

产出：把"吉/凶"升级为"吉到什么程度、凶到什么程度、体验如何"的带质感终局，避免把单个信号当最终结论。

### 救解与德化（《大六壬指南》问答录扩展）

- **救解作用范围**：问答录九示范日德、生合等改变处分方式而未改去官结果；须保留该例条件。其他案件先辨救应作用对象与环节，不能无条件扩大为全吉，也不能禁止有效救应修订原先主判。
- **德解的具体范围**：问答录十在干支、中末皆墓等条件下讨论解祸有限；保留该案解释，不将“一德解百祸”或“只减不改”转成跨占类保证。依本问力量、位置和障碍解除程度重评。
- **虎马发用暴成暴败的质感判定**：虎马发用=事极速且力度大，但"虎者暴成暴败"——速成亦速败；发用落空则事或不成、或成而不久。速度（快慢）与久暂（长久与否）是两维，须分断；虎乘月建只增力度、不改变成败本身（问答录十二）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 男问近几年财运（贵人差迭大背景）
- **问题**: 问近几年财运（非一次短期财运，须全局综合评价）。
- **方法论的使用**: 先定大背景——昼贵子临戌夜地、夜贵申临昼地午＝"贵人差迭"；申受午克、子受戌克＝"二贵受克"。在此大背景下，"这课的一切吉凶之象，都是：若有凶象，则凶大；若有吉象，则吉小"。再逐象调制：干上朱雀脱气午火＝头脑发热会投资；龙禄居支＝开店可维生但麻烦绝不少；太常为养命之源被地盘所克＝捉襟见肘。
- **结论**: 计划多不能成，吉小凶大，坏运势一直到 08 年。
- **结果**: 三年中屡屡借钱投资、收入平平艰难度日，08 年负债压力很大。

### 案例 2: 男占终身（四象限调制逐限）
- **问题**: 占终身（本命丑、乙丑年生）。
- **方法论的使用**: 三传三限每限做调制——"合为吉，刑破害为吉，空绝死墓为凶"，再以天将修正：发用巳作天空与本命丑相合（铸印象、象的激发）＝少年孤闷、母病（吉的结构里带着闷）；太阴逢子为入内、子官鬼与命丑合又带天后＝08 年找到工作但"妾妇相侮"、受制于女子。
- **结论**: 先闷后成——少年运蹇、中年受制于女子，整体吉凶交织、逐限质感不同。
- **结果**: 逐条反馈应验：16 岁前开朗后沉闷、00 年父厂破产母糖尿病、08 年在亲戚公司任技术副总受制于女上司。

### 案例 3: 女占终身（性格姻缘，吉凶交织调制）
- **问题**: 占终身（已给八字，问性格姻缘）。
- **方法论的使用**: 本命卯上亥作贵人（吉将）定品性，却"多少有些阴郁"；发用戌加寅＝孤寡全逢又寅戌空闲，空孤→寄养外祖母家；05 后酉作太阴切入、酉戌穿害→家中人有病 + 三角恋爱痛苦。吉象（贵人、太阴）乘凶位、凶象（孤寡穿害）叠加，逐项调制。
- **结论**: 性格正统阴郁、24 前姻缘不成、05 后恋爱极其痛苦。
- **结果**: 逐条反馈应验：自小寄养外祖母家十几岁方回、自动化控制机械专业、05 后三角恋爱痛苦。

### 案例 4: 占章奏上书·救解局部性（问答录九，z08）
- **问题**: 张维枢占上书吉凶、旨意（无禄无路大凶课）。
- **方法论的使用**: 大背景极凶（无禄无路、财官禄马俱入墓绝、八专主专横）；但朱雀乘戌与日干不生不克、其阴神巳火为驿马又旬丁且生日——有救解但**救解是局部的**，不能改变课凶总趋势：主降罚削权之凶不变，仅由"极刑/下狱"降级为"好旨归里"。
- **结论**: 宜急流勇退；上书得好旨归里（无大咎退职），但总凶不变——回家未久仙游（死）。
- **结果**: 后唯冠带闲住，回家未久仙游。

### 案例 5: 占显宦不能久任·一德解百祸（问答录十，z09）
- **问题**: 王射斗占仕途长短（干支皆墓、禄马空陷、太阳入山）。
- **方法论的使用**: 发用亥水遁辛为日德，"一德解百祸，更新则可无事"——只减祸（退而无灾），不改总凶：干支皆墓、中末传墓，"恐怕回家寿也不久"。
- **结论**: 不能久任；次年三月因言请归。
- **结果**: 次年三月因言请归，后知为大冢宰王射斗。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **基础吉凶已定、追问程度**："能成，但会不会很痛苦？""得财是不是风险很大？"
2. **课传吉凶参半**：有财又有白虎、有禄又被克、有吉课体却遇空亡变质——需要综合裁定而非单线表态。
3. **大背景异常**：贵人差迭、二贵受克、纯阴课、课体先验偏凶——全局缩放（"凶大吉小"）。
4. **终身/年运分限调制**：逐年/逐限解释吉凶质感（"拿到钱也是拿得痛苦的那种"）。
5. **AI 作为分析框架**：终局综合器——汇总类神/课体/凶煞/空亡各线信号，输出带程度与体验的结论，避免"断吉就一切皆好"的粗放。

### 语言信号 (用户的话里出现这些就应激活)

- "程度/多严重/多好/到底好不好/how bad/how good/severity"
- "吉中带凶/得财有风险/好但有隐患/good but risky"
- "综合分析/总体怎么样/整体如何/overall"
- "会不会很难受/痛苦/painful/hard"
- "影响多大/影响大不大/impact/scale"

### 与相邻 skill 的区分

- 与 `xiongsha-suduan` 的区别：前者校验风险，本 skill 结合有效救制区分结果、过程和程度；不把风险命中直接当凶定性，也不把描述象限当作数值概率。
- 与 `cailu-panduan` 的区别: c21 的"贵人差迭"是财运课的**大背景缩放**，但收入/纯财的类神与忌讳规则（脱气/破碎煞/三传全财）属财禄 skill——本 skill 用背景，不重复规则。
- 与 `zhongshen-nianyun` 的区别: 三传三限是终身课**骨架**；四象限调制是给每限**定性程度**的调料（骨架+调料串联）。
- 与 `keti-qishi` 的区别: 课体气势作为**先验输入**本 skill 的缩放系数；本 skill 不负责读出气势本身。
- 与 `sanbu-duanke` 的区别: 三步断课法产出初步结论，本 skill 是"看显象"之后的**最终调制层**。

### 救解与德化 触发场景（《大六壬指南》问答录扩展）

1. **偏凶判断出现救解/吉将**：核施救者得气得地及具体通路，局部缓解只影响对应部分，关键障碍解除则重评主结果。
2. **占官/占病见日德发用遁干**（如亥遁辛）——查"一德解百祸"能否免大灾，同时确认总凶未改（干支皆墓/中末传墓者寿仍不久）。
3. **虎马发用占快速事件**——判"暴成暴败"质感：速度与久暂分断，发用落空则成而不久。
4. **用户追问"会不会很凶/能不能免/能保住什么"**——用救解定降级幅度、用虎马定暴烈质感。

## E — 可执行步骤 (Execution)


1. **接收已说明依据的暂定结论**：分开结果成败、过程阻碍、程度、快慢与持续性。四象限用于描述同一判断单元的质感，不直接替代成败裁决。
2. **定位背景与救解的作用范围**：列背景所依据的结构，说明救解实际作用于谁、哪一环节。B08 展示局部减罚并非全局转吉；其他案件须重新检查，不能反过来禁止有效救应改变原先误判的方向。
3. **核对反证与重复**：有凶背景仍检查最强吉证，有吉倾向也检查关键凶证；数量按实际证据，不凑三个不利信号。同一神将被课体、六亲、神煞重复描述只作一组相关信息，不连续打折。
4. **输出程度与边界**：用可核对事件描述，如迟延、费用增加、部分得到、过程反复；无数源不编折扣百分比。证据改变主结果时返回主流程重裁决，不能只为保持背景定性而压低反证。

完成标准：结果/过程/程度各自依据，背景与救解边界，是否需要回改主判。见 [主流程方法规则](../daliuren/refs/judgment-workflow.md)。设计依据 B08、M02、M12，四象限和救解原论仍保留于上文。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 简单成败/单点状态问题（能/不能、有/没有）不需要程度描述——直接类神线（`leishen-keti`）。
- 用户只问"何时"不问程度——交 `yingqi-panduan`。
- 无吉凶参半、无大背景异常时调用是过度工程——会稀释结论清晰度。
- 程度词不得用于**回避明确判断**（见 ce14）。

### 作者在书中警告的失败模式

- **ce13 解释自由度**：四象限的灵活性正是其风险——"吉中有忧""温柔一刀"这类表述可在事后自圆其说；书中多次"以课体为侧重也可，以类神为侧重也可"，结论对侧重选择高度敏感。必须给出可检验的具体指征，不允许空泛的程度修饰。
- **ce14 可证伪性**：程度性描述天然难证伪——"拿到钱也是拿得极痛苦的"这类质感判断，若无预注册指征，命中率未必高于随机；禁止用模糊修饰语代替明确结论。
- **ce12 幸存者偏差**：调制式断语的"应验"全部来自无失败样本的占者自述（c10/c21/c34 全部果应），不能当作统计证据。

### 《大六壬指南》问答录扩展失败模式（B 段追加）

- **ce10 见救解即改吉断**：见课中有救解（日德、天喜、生合、天马）就把整体改为吉断，忽视课体凶局未变——"有救解为何还凶"是初学最典型误断；问答录九所举救解只缓解局部（如好旨归里、只丢官），未解除其关键阻碍；这是该例的作用范围，不能扩成所有德合生旺都只能减灾。若有效救制确实解除本问主要障碍，须按共享理气重新裁决，不凭救名直接翻吉。
- **ce17 多重凶叠加心存侥幸**：多个凶象叠加时仍逐一找"余地"（马被合也许不凶、禄神不明显），不按凶象总量断生死——病玄胎+中末空亡+日鬼发用多重凶叠，救解均为局部，无法挽回总凶，断死依据的是叠加后的总势（问答录五）。

### 勘误备忘（问答录扩展）

- **天马→驿马勘误（问答录九）**：原书"阴神见天马"有误，实为驿马（又是旬丁，且生日）——从戌为地盘论巳火则不云入墓。断救解须先正神煞之名再论临地盘墓绝生克，不可将错就错（配套 ce03）。

### 作者的盲点 / 时代局限

- **ce15 信仰前提**：四象限调制建立在天将象意（虎蛇凶、龙常贵合吉）与人事之间存在客观映射这一未论证前提之上；"同样的吉，见吉将则吉而又吉"依赖该映射的稳定性。
- 时代局限：案例集中于 2004–2009（股市/房价/08 金融危机），语境过时但方法不依赖时代。

### 容易混淆的邻近方法论

- 与**凶煞速断**（`xiongsha-suduan`）：否定式 vs 调制式，功能互补不重复——先定性（凶煞），后定量（调制）。
- 与**应期判断**（`yingqi-panduan`）：五行旺衰在两处用法不同——应期看"时间位"（火旺待灭），调制看"吉凶程度"（旺衰决定爻的吉凶基数），不可混用。
