# 取数、旺衰与数量修正的配合

本页按用户批注6、7及《理法简易》LF-U3319—3347整理，接quantity六环，原文见book-annotation-evidence。用户要求将取数结果与实际气态配合，不把工具返回的基础数直接当最终现实量。

## 三层分清，再作修正

1. **状态层**：月令五气、临地十二气、旬空/坐空及关键施受关系。单宫或selected-relations旺衰工具描述所选对象的状态和作用范围；明确跨宫依据后须补算。
2. **数法层**：哪种数表、取哪对位置、加乘及原法自带的旺衰分支。源法以月令五气分支时，按其明确season_profile，不把综合2.9分直接替代“休/囚/死”。《粹言》相气倍与《壬归》相气不进位保留不同方法，禁止串用。
3. **数量修正层**：在实际所问数量上，是否另有空亡、受阻、范围或单位修正。**strength已经计空，不代表quantity的基础数已经折半。**反之，数量公式本身已经用了同一数量折半，再折半才是数值层重复扣减。状态层与数量层的职责不同，不能用“避免重复计空”取消本来尚未执行的数量修正。

LF-U3329原文：旺相因而倍进；相取相乘所得而不进；休不相因；囚死再减成数之半。北海随后将休解释为上下相加、囚死为相加之半。LF-U3331首句又写“旺相则相乘，并进位”，与下一“相则相乘而不进位”词面交叠，列为文字校勘；本轮依据3329明确区分旺/相，**不默改原字，也不凭“进位”擅定十倍或百倍**。本段“成数”指中间计算所得，不必是五行成数6—10。

具名方法LF3329-class-ground执行这一清楚的基本分支：AI选定类神及适用理由；类神支数与所临地盘支数，旺/相相乘、休相加、囚死相加折半。旺支只返回进倍前基础数，倍进幅度未定；不混入《粹言》的相乘2或旺10/100倍。原文以财为例，其他数量任务采用须说明关键类神和迁移理由。旬遁/复建另按原段的占类职责查，不把藏干、旬遁、五子元遁当同一项重复加数。

## 空亡减数：落实用户要求，保留适用条件

用户2026-11-11报告的开发例：类神基础数40分，strength约2.9，先前回答误以为计空后数量也已修正；用户主张该例应按类神空亡另减半，得到约20分。本轮把它登记为**用户报告及采用的该例修正要求**；未取得原盘、完整算式与反馈原件，不把“贴近反馈”当作独立验证，也不倒推所有分数题均减半。

《理法简易》LF-U6671确有“申七辰五，五七三十五，空亡减半，得十七年”的原载方法片段；它处于旧终生三限例，不能据此恢复出生运限算法或把35/2=17.5静默截为17。保留原作者数值和其省略的取整问题，只借其“基础数与空亡数量修正分开”的参照价值。LF-U5553另有“龙空一半可得”，5555解释财爻不空仍可得；将空、财爻空、身空并非同一对象，不能合成凡空半数。

**当前执行**：取得基础数之后，必须主动检查关键类神的综合旺衰和空亡是否需要数值修正。若采用原书已有减数条件或用户已指定的同例修正，说明为何空落在所问量的实现环节、是否有足够气态/通路，明确乘1/2等算式并调用quantity expression，不以“强弱已算”跳过。没有足够理由时可保留基数及减数候选、给出适用取舍；不为接近反馈逐次尝试倍率。

不得创造strength_index/5、2.9/10等自动换算，也不把弱可作用理解为满额兑现。旺衰程度可帮助判断规模、实现份额与修正方向；**具体比例仍须原法或明确的用户研究约定**，不能凭分档编出任意小数系数。此处新增的是执行检查与有据运算，不更改34版研究指数或空亡系数。

## 工具回执和交付

取数先查methods；具名quantity回执新增calculation_scope，说明本次实际用了哪个季节分支或月建修正，并明确：未读取综合旺衰指数、未执行空亡数量修正、未解决现实量级。false仅指该次计算未执行，不等于本案不需要。

独立修正另用已有quantity expression，例如已确定基数40且本案有减半依据：`{"op":"divide","args":[{"value":40},{"value":2}]}`。该算式只负责算出20，不负责证明减半适用。基数的具名回执、修正的expression回执及理由共同保留；具名方法与expression分次调用，不能把尚未实施的步骤写成已经算过。

数值题一条记录足够：**对象/位置 → 方法及基数 → 旺衰计算范围 → 数量修正触发、比例、是否已包含 → 结果/单位/量级与精度**。在calculation_scope核对是否把单宫冒充综合、把状态修正冒充数值修正、遗漏应作修正或同层重复折减。不能为了完成记录反而拒绝有依据的最佳估计。
