## 一、九宗门表

| 宗门 | 取用规则 | 备注课格 | 双轨标注 |
|---|---|---|---|
| **1. 贼克** | 先看四课有无下贼上（下克上），有则以下贼上为初传；无下贼上再看上克下。"取课先从下贼呼，如无下贼上克初"。仅一下贼上 = **重审**；仅一上克下 = **元首** | 元首 / 重审 | — |
| **2. 比用（一名知一）** | 有二、三、四处下贼上（或上克下，或混杂）时，**取与日干阴阳相比者**（阳日用阳神、阴日用阴神）为初传。"常将天日比神用，阳日用阳阴用阴"；**若俱比或俱不比 → 转入涉害法**。二下贼上称比用，二上克下称知一 | 比用 / 知一 | — |
| **3. 涉害** | 多克贼且与日干俱比或俱不比时，各神由天盘涉归本家（地盘本位），数途中所受克之重数，受克多者为用；涉害相等取地盘四孟上神（**见机**），次四仲（**察微**），再等则阳日取干上神、阴日取支上神（**缀瑕**） | 见机 / 察微 / 缀瑕 | — |
| **4. 遥克** | 四课上下无克：先取四课上神遥克日干者发用（**蒿矢**）；无则取日干遥克上神者发用（**弹射**）；多者以与日干比者为用 | 蒿矢 / 弹射 | — |
| **5. 昴星** | 无上下克亦无遥克：刚日仰视取地盘酉上之天盘神为初传（中传支上神、末传干上神，**虎视**）；柔日俯视取天盘酉下之地盘神为初传（中传干上神、末传支上神，**冬蛇掩目**） | 虎视 / 冬蛇掩目 | — |
| **6. 别责** | 四课不全（三课）且无克无遥：刚日取日干五合之干所寄宫的天盘上神为初传；柔日取日支三合局中"支前"一位为初传。中末传俱取干上神 | 别责课 | — |
| **7. 八专** | 日干日支同位（甲寅 / 庚申 / 丁未 / 己未四日）四课只成两课：阳日从干上神顺数三位发用，阴日从支上神逆数三位发用，中末传俱取干上神 | 八专课 | — |
| **8. 伏吟** | 月将与占时相同，天地盘同位（**宗门法**）。有克以克发用；无克刚日取干上神（**自任**）、柔日取支上神（**自信**）为初传；中末传以初传所刑之神递推 | 自任 / 自信 / 杜传 | **双轨**：宗门 = 伏吟法；课体 = 伏吟（天地盘同位盘式） |
| **9. 返吟** | 月将与占时为六冲，天地盘对冲（**宗门法**）。有克照常以贼克 / 比用 / 涉害取传；无克仅丁丑己丑辛丑丁未己未辛未六日（**井栏格**），取驿马为初传、支上神中传、干上神末传 | 井栏（无依） | **双轨**：宗门 = 返吟法；课体 = 返吟（天地盘对冲盘式） |

### 九宗门要点（纠错级）

- 比用的"比"是**阴阳相比**（子寅辰午申戌阳、丑亥未巳酉卯阴），**不是五行比和（比肩）**。"多克取比"是错误表述。
- 元首 / 重审是贼克法课格名，非独立宗门——故九宗门为**九项**而非十项。
- 涉害课须辨取用法（古法受克多者 vs 陈公献孟仲季法），不同取法可能取用不同。
- 伏吟 / 返吟**双轨**：既是九宗门之末二门（起传法层面），又是独立课体（天地盘特殊盘式层面）。

### 特殊课体纠错要点

- **登天 ≠ 昴星**：登天是间传"登三天格"（三传辰午申）或"贵登天门"（贵人临亥）；昴星是无遥无克取酉上下神之取传法，二者概念层级不同。
- **游子 = 三传皆土 + 逢旬丁（丁马）、天马发用**——不是三传皆孟（四孟发用为**元胎课**，属另一课体）。

## 三、三合局与稼穑/游子辨析

### 1. 三合局仅四局

| 三合局 | 三支 | 名称 | 全局课断法 |
|:---:|:---:|:---:|---|
| 水局 | 申子辰 | 润下 | 沟渠鱼网，天阴雨 |
| 火局 | 寅午戌 | 炎上 | 炉冶文书，天晴旱 |
| 木局 | 亥卯未 | 曲直 | 舟车种植，利修造 |
| 金局 | 巳酉丑 | 从革 | 兵戈金铁，利更改 |

- **三传全见某局三支**称"全局课（三合课）"；三合局只此四局，**辰戌丑未不在其中**。
- 全局课断法（上表右列）：润下 = 沟渠鱼网天阴雨；炎上 = 炉冶文书天晴旱；曲直 = 舟车种植利修造；从革 = 兵戈金铁利更改。

### 2. 稼穑课与游子课（四库土）

- **辰戌丑未 = 四土、四库（墓库），不是三合局**。
- 三传皆土（辰戌丑未四季土）课体名 **稼穑课**（"土主稼穑事"），断：田土稽停沉滞（土主稼穑）；戊己日艰难，壬癸日为脱难。
- 三传皆土而**逢旬丁（丁马）、天马发用**，则名 **游子课**（占病不宜，亦名五坟卦）。

### 3. 严格区分要点

- 稼穑 / 游子三传皆土，**不可称"稼穑局"并入三合局体系**；三合局必须三支同见（申子辰 / 寅午戌 / 亥卯未 / 巳酉丑），四库土支互不成三合。
- 游子课 ≠ 三传皆孟（四孟发用为元胎课）；游子课必须满足"三传皆土 + 旬丁/天马发用"两条件。
- 稼穑无丁马（静滞）、游子逢丁马（主动）——一静一动，区分判读。
