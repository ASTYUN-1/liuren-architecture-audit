# 排盘存档库

> 三套术数系统(八字/紫微/六壬)排盘产物的统一归档位置。
> **目的:防止排盘 JSON 散落项目根目录,保证可追溯、可复核。**

## 目录结构

```
排盘存档/
├── README.md        ← 本文件(归档规范)
├── 八字/            ← 八字排盘 JSON(paipan 包输出)
├── 紫微/            ← 紫微排盘 JSON(iztro 服务输出)
└── 六壬/            ← 六壬课式 JSON(本机直接排盘工具默认自动保存完整原导出及附加校验记录)
```

## 命名规范(强制)

```
[术数]-[YYYYMMDD-HHmmss]-[备注].json
```

| 部分 | 规则 | 示例 |
|------|------|------|
| 术数 | 八字 / 紫微 / 六壬 | 八字 |
| 时间 | 排盘生成的本地时间,精确到秒 | 20260801-135021 |
| 备注 | 简短说明(人名/流月年份/用途),无则省略 | 马庆磊-流月2026 / 表弟-终身 |

**完整示例:** `八字-20260801-135021-马庆磊-流月2026.json`

## 硬性规则(各 skill 强制执行)

1. **禁止散落**:任何排盘 JSON 一律写入本库对应子目录,禁止写入项目根目录或其他位置
2. **禁止同名覆盖**:文件名必须含时间戳;同一批多次排盘(如不同流年)必须区分备注,不得互相覆盖(本次迁移已发生过覆盖事故,以此为戒)
3. **写入后即归档**:排盘结果读入上下文后,JSON 保留在本库,不删除(可追溯);如需清理,由用户明确指示
4. **工具目录隔离**:排盘工具自带的验证产物(如 ziwei-paipan/verify-*.json)属于工具测试文件,留在工具目录即可,不必移入本库
5. **不存敏感信息**:归档文件只含命盘数据,不含姓名身份证等隐私(姓名可用代号)

## 各 skill 的调用约定

| 系统 | 排盘方式 | 归档命令 |
|------|---------|---------|
| 八字 | `node bazi-paipan/paipan.js --out ...` | `--out 排盘存档/八字/八字-YYYYMMDD-HHmmss-备注.json` |
| 紫微 | HTTP 3458 + Node 脚本 | 脚本内写文件到 `排盘存档/紫微/紫微-YYYYMMDD-HHmmss-备注.json` |
| 六壬 | `liuren_chart` 或 `node tools/liuren-direct.mjs --datetime 时间` | 自动保存 `六壬-YYYYMMDD-HHmmss-代号-UUID.json`，北京时间生成时间，独占创建不覆盖 |

## 清理策略

- 默认:保留(可追溯复核)
- 用户明确要求清理时:删除过期/无用归档
- 归档文件体积小(20-30KB),长期保留无压力
