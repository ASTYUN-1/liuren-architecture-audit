# 大六壬推命精要

> 本书以《六壬推命学》（八六居士）与《大六壬终身论命秘要》为基，融贯《六壬针见血》身命磨镜药之法，兼采诸家推命心法，去芜存菁，归于六壬本宗。凡所立论，皆以课传为本，不假他术之名。

# 卷一 · 起课根本

## 一、何以六壬能推命

六壬推命与六壬占卜，同源而异用。

**占卜者**，以问事当下之时起课。月将加于占时，取天地当时之气，观一事之吉凶。一课一占，事过则课废。

**推命者**，以人出生之时起课。月将加于生时，取天地降生之气，观一生之荣枯。一课既成，终生不易。

二者起课之法无异——皆以月将加时立天地盘，以日干支定四课，依九宗门取三传，布十二天将。所异者，推命须更布十二宫、定身宫宅宫、起大运小限，为占卜所不用。

**天地人三才之理**：

- 月将者，太阳躔次之宫，天之阳气所宗。加于生时，乃以天道注于人道之始。
- 日干者，人之自身。日支者，人之所处（宅舍、配偶、环境）。
- 四课者，日干日支各分阴阳——干阳为外显之我，干阴为内藏之我；支阳为外显之境，支阴为内藏之境。合为四象，备矣。
- 三传者，四课中有克之处为事发之初（初传），沿天盘轨道推演三步（初传→中传→末传），乃事物从起、经变、至终之全程。

**终生只立一课，一课而决一生。课中万有，全在此盘。**

## 二、月将加时：定天地之盘

月将者，太阳过宫也。每月中气之后，太阳入次宫，即为月将。

| 中气 | 月将 | 地支 | 寒暖 |
|------|------|:---:|:---:|
| 雨水 | 登明 | 亥 | 寒 |
| 春分 | 河魁 | 戌 | 温 |
| 谷雨 | 从魁 | 酉 | 凉 |
| 小满 | 传送 | 申 | 温 |
| 夏至 | 小吉 | 未 | 燥 |
| 大暑 | 胜光 | 午 | 热 |
| 处暑 | 太乙 | 巳 | 热 |
| 秋分 | 天罡 | 辰 | 凉 |
| 霜降 | 太冲 | 卯 | 温 |
| 小雪 | 功曹 | 寅 | 寒 |
| 冬至 | 大吉 | 丑 | 寒 |
| 大寒 | 神后 | 子 | 寒 |

**月将寒暖辨**：月将即太阳之位，太阳所在即阳气盛衰之根。生于亥子丑月将者，太阳在北，天寒地冻，课传中见火为贵；生于巳午未月将者，太阳在南，炎暑燥烈，课传中见水为贵。此非他术之"调候"，乃六壬本有之理——太阳躔次，本来就有寒暖。

## 三、日干支定四课：立人我之分

日干为身，日支为宅。四课乃以日干日支为纲，从天地盘各取两层：

- **第一课（干阳）**：日干寄宫之上神——事之见于外者
- **第二课（干阴）**：第一课上神——事之藏于内者
- **第三课（支阳）**：日支本宫之上神——境之显于外者
- **第四课（支阴）**：第三课上神——境之藏于内者

日干寄宫：甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。

## 四、九宗门取三传：定事变之机

四课既成，于上下神之间寻"克"——有克则有动，无克则无变。九宗门者，因克之有无多寡而分：

| 宗门 | 条件 | 事机 |
|------|------|------|
| 元首 | 一上克下 | 事从外来，顺势而为 |
| 重审 | 一下贼上 | 事从内起，内因为主 |
| 比用 | 多克取比 | 同类竞争，择善而从 |
| 涉害 | 克贼同等，取受克深者 | 利害交织，历尽艰险 |
| 遥克 | 无克取遥 | 暗中角力，隔山打牛 |
| 昴星 | 无克无遥 | 伏藏不动，待时而发 |
| 别责 | 课不备（三课） | 不全之象，权宜之计 |
| 八专 | 干支同位（二课） | 独断专行，自我中心 |
| 伏吟 | 天地盘同 | 静止不动，呻吟等待 |
| 反吟 | 天地对冲 | 反复不定，来回折腾 |

**宗门即命格之大象**。元首重审者，一生多由外缘或内因主导；涉害者，一生多曲折；昴星者，一生多伏藏；伏吟反吟者，或静守或动荡。宗门定一生之气运基调，后之格局、课传、运限，皆在此基调上展开。

初传即发用，为一课之主。初传上神为中传，中传上神为末传。三传成而事之始、中、终定矣。

## 五、布天将：定吉凶之主宰

以日干定贵人（昼夜），贵人既定，顺逆布十二天将：

贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后

**天将高于地支**。贵人青龙，虽临绝地，其吉不灭；白虎螣蛇，虽临旺地，其凶犹存。吉将受制则力减，凶将有制则祸轻。

# 卷二 · 身命根基

## 一、日干旺衰

日干为通盘之太极，一身之主。先看"我"之强弱，再论吉凶。

**三看日干**：

- **天时**：日干五行与月将之关系。春木旺、夏火旺、秋金旺、冬水旺、四季末土旺。得月将生扶者为得天时。
- **地利**：日干寄宫与所坐地盘之关系。地盘生扶寄宫者为得地利，克墓者为失地。
- **人和**：日干与干上神之关系。上神生扶日干者为得人和，克耗者为受压。

**旺衰五等**：

| 等次 | 条件 | 断语 |
|:---:|------|------|
| 极旺 | 三看俱全 | 能担大任。课传吉则大吉，课传凶亦能扛 |
| 偏旺 | 得二看 | 可成事业。需看课传有无克泄以平衡 |
| 中和 | 得一看 | 不弱不强，最吉之象 |
| 偏弱 | 仅微根或微助 | 需扶助。课传有生扶则转吉 |
| 极弱 | 三看全无 | 难自立。课传吉亦难享，课传凶则不堪 |

**口诀**：课传凶而日干旺，凶可减半；课传吉而日干衰，吉亦打折。

## 二、身宫与宅宫

**身宫**即日干寄宫。甲身寅、乙身辰、丙戊身巳、丁己身未、庚身申、辛身戌、壬身亥、癸身丑。

身宫所临天将及神煞，代表命主立身之本。身宫旺相得吉将者，根基稳固；身宫空亡入墓者，一生多谋少成。

**宅宫**即日支上神（天盘临于日支者）。宅宫代表家宅、妻室、基业。宅宫旺相得吉将者，家业兴隆；宅宫空亡乘凶将者，家基不固。

身宫与宅宫相生相合者，内外和谐；相冲相克者，身心不宁。

## 三、命宫与十二宫

命宫为十二宫之首。以生时加月将，命宫所在即天盘与生时交汇之处。

十二宫自命宫起，**逆行**排列：

| 序 | 宫名 | 所主 |
|:--:|------|------|
| 1 | 命宫 | 一生根基、性格、福泽 |
| 2 | 兄弟宫 | 手足、同辈、合作伙伴 |
| 3 | 妻妾宫 | 婚姻、配偶 |
| 4 | 子女宫 | 子嗣、晚辈、生育 |
| 5 | 财帛宫 | 财运、理财、收入 |
| 6 | 疾厄宫 | 健康、疾病、体质 |
| 7 | 迁移宫 | 出行、变动、外地 |
| 8 | 朋友宫 | 交友、下属、人际关系 |
| 9 | 官禄宫 | 事业、官职、社会地位 |
| 10 | 田宅宫 | 房产、家宅、基业 |
| 11 | 福德宫 | 福气、精神享受 |
| 12 | 父母宫 | 父母、长辈、出身 |

**十二宫断法总则**：宫位得天将吉神生扶日干本命者为吉，见凶将恶煞刑冲破害者为凶。不可孤立看一宫——对宫（相隔六位）为冲、三合宫（相隔四位）为照，须合而观之。

**强宫优先**：命宫、财帛宫、官禄宫、迁移宫、夫妻宫、福德宫为六强宫，推命时以此六宫为主。其余六宫为辅。

# 卷四 · 课传推演

## 一、三传三限

**三传即人生三段**：初传主少年（约前二十年），中传主中年（约中二十年），末传主晚年（约后二十年）。

**三传关系断一生大势**：

| 关系 | 断语 |
|------|------|
| 递生（初生中、中生末） | 层层有助，一生顺畅 |
| 递克（初克中、中克末） | 处处受阻，一生多难 |
| 先克后生 | 先难后易，渐入佳境 |
| 先生后克 | 先好后坏，晚景堪忧 |

**三传六亲断各限**：初传见财爻旺相则少年得志，见鬼墓则早年多病；中传见官星贵人则中年发达；末传见子孙长生则晚景安康。

**课命与爻象之辨**（心法）：

> 课命（四课）定根基，爻象（三传）定际遇。课命旺不如爻象旺。
>
> 根基好而际遇差——虽有家底而自身难展。
> 根基差而际遇好——出身寒微而白手起家。

## 二、天将乘旺衰

天将各有吉凶，而所坐之地支决定其力之大小。此非借用他术之"亮度"，乃六壬固有的**长生十二宫**之理。

| 坐地 | 吉将在此 | 凶将在此 |
|------|---------|---------|
| 帝旺 | 吉力全盛，福泽深厚 | 旺极有制，凶中带转机 |
| 长生 | 吉力充盈，福气生长 | 凶势初起，尚可遏制 |
| 临官 | 吉力稳实，福禄可享 | 凶力受制，危害有限 |
| 冠带 | 吉力渐显 | 凶力初露 |
| 沐浴 | 吉力虚浮，华而不实 | 凶力暧昧，暗藏危机 |
| 衰病死 | 吉力渐消 | 凶力亦衰，危害不大 |
| 墓 | 吉力被封（入库） | 凶力被封（入墓不凶） |
| 绝 | 吉力断绝 | 凶力爆发（绝处逢凶） |
| 胎养 | 吉力孕育 | 凶力未成 |

**运用口诀**：青龙乘帝旺临身，终身福厚；白虎乘帝旺无制，一生多厄。贵人乘绝地，贵人无力；螣蛇乘旺地，虚惊实害。

## 三、六亲取用

六亲取用有双轨：**天将法**与**六亲爻法**，可互参不可偏废。

| 六亲 | 天将类神 | 六亲爻（生克关系） |
|------|---------|-----------------|
| 父 | 太常、贵人 | 生我者（印星） |
| 母 | 天后 | 同上 |
| 兄弟 | 太阴、比肩 | 同我者（比劫） |
| 妻妾 | 天后、财爻 | 我克者（财星） |
| 子女 | 六合、子孙爻 | 我生者（子孙） |

**类神须向活中看**：同一六亲，课传不同取法不同。如问妻，先看天后所临，如天后不入课传则看财爻，财爻亦不现则看日支辰上神。

**六亲断法**：类神旺相生扶日干本命、不空不墓者，该亲得力有缘。类神克害干命或逢空落空者，缘薄力寡。

## 四、财官论断

**贵命之征**：日月有气，官禄贵人、驿马、印绶诸吉生合日干。

**富命之征**：财爻旺相得地，与命上干上相生相合。龙常旺相交遇财神，干命和平互加生合。

**禄神三重**：
- **干上禄**——自身荣华之禄（最重）
- **支上禄**——家中现成之禄（次之）
- **用传之禄**——往来营求之禄（再次）
- 三者得一为美，三者俱全大贵，三者皆无则无所立脚

## 二、小限（一年一换）

小限一年行一宫。阳男阴女从身宫逆行，阴男阳女从命宫顺行。

**流年三法**（可互参验证）：
1. **太岁加命法**：以太岁加本命，视行年上神——见功曹传送加官进禄，见魁罡灾害疾病

## 三、流月推演

流月推演有二法，一轻一重，因需取用。

### 法一：宫位轮值法（日常推命用）

1. 以当年**行年（小限）所在之宫**为正月起点
2. 自此宫起正月，顺行十二宫，一宫一月
3. 每月吉凶看该月宫位：
   - 天将吉凶——吉将则月吉，凶将则月凶
   - 是否临身命宅宫——临之则为大事之月
   - 是否填实课中空亡——填实则困局可解
   - 是否合冲课中关键地支——合冲则事机发动

> **顺行之理**：传统行年起月法为逆行（行年在午→午正月、巳二月、辰三月），然天盘月将顺行于地盘，太阳东升西落亦为顺行。改逆行之法为顺行，与天道一致，且便于记忆。

### 法二：岁合起课法（精确应期用）

此法源自《六壬针见血》身命磨镜药：

> "流年：岁合加月将，以太岁干支作课传，一传管四月。流月：月合加月将，以月建支干作课传，一传管十日。"

**年课起法**（分十二月）：
1. 以当年太岁干支为日干支，仍用命课月将加临
2. 以太岁干支起四课、定宗门、取三传
3. 三传分配：初传管第一至四月，中传管第五至八月，末传管第九至十二月
4. 某月吉凶，看该月所在之传的吉凶

**月课起法**（分三十日）：
1. 以当月月建为日支，仍用命课月将加临
2. 起四课、取三传
3. 三传分配：初传管上旬十日，中传管中旬十日，末传管下旬十日

**年课与月课合参**：年课定各月大势（何月吉何月凶），月课定各旬细节（上旬中旬下旬何事）。年课凶而月课吉者，大势虽不利但该月有转机。年课吉而月课凶者，大方向好但该月宜谨慎。

### 两法选用

日常推命以宫位轮值法为主，简便快捷，一望可知逐月吉凶。遇关键年份需精确应期时，再以岁合起课法深入，二法互参。

## 四、流日推演（附）

流日精度为推命之极处，非必要不轻用。三法可参：

- **类神应期法**：课中类神所在之地支，该地支逢值之日即有可能应事
- **空亡填实法**：课中空亡之地支逢值或逢冲之日，事机发动
- **月课三分法**：月课三传各管十日，观事在何传，可缩至旬内

## 五、运限参证总诀

**课命运三层参证**（心法）：

> 命课有象，运限放大，年命触发——三层同向方为实。

- 命课中有某象（如财爻空亡，命中财运当有波折）
- 大运走入相关宫位（如走入财帛宫，此十年为财运关键期）
- 小限走到发动之地（如走到填实空亡之支，该年财运逆转）
- **三层信号同一方向，方可断定为实。**

仅命课有象而大运未至者，象在而事不发。大运已至而小限未动者，机在而时未到。必待三层俱全，方为应期。

# 卷六 · 制化救应

## 一、课中病处

课传之中，以下诸象为"病"——命局之阻碍与困境所在：

| 病象 | 含义 |
|------|------|
| 发用空亡 | 事之起始即虚，虎头蛇尾 |
| 白虎发用乘旺无制 | 一生多压力疾病，须看有无制神 |
| 干支互冲互刑 | 内外不和，身心相战 |
| 身命入墓 | 一生昏晦，有志难伸 |
| 三传递克 | 层层受阻，事事不顺 |
| 财爻空亡 | 财运虚浮，到手即散 |
| 日干无气而凶将临身 | 身弱逢凶，难以承受 |

## 二、制化之道

有病需有制，有制则病不害。制化之道如下：

| 病 | 制化 | 说明 |
|----|------|------|
| 发用空亡 | 待填实之神、日干旺相 | 出空填实则虚事变实 |
| 白虎无制 | 贵人、青龙、天后临课传 | 吉将制凶，转压力为动力 |
| 干支互冲 | 六合、三合之神 | 合能解冲 |
| 身命入墓 | 冲墓之神（辰戌冲、丑未冲） | 冲则墓开，困局可解 |
| 三传递克 | 能克初传之神 | 截断克链，转凶为吉 |
| 财爻空亡 | 青龙临财爻旺地 | 吉将填实，空财得实 |
| 日干无气 | 长生、帝旺之地有吉将生扶 | 扶身助气，弱中转强 |

**制化之力分三等**：
- **有力**：制神现于课传，乘旺相之地，乘吉将——病可痊愈
- **力弱**：制神现但休囚空亡——有制而难用
- **待时**：制神不现于课传，需看大运何时走入制神之地——运来方解

## 三、有情无情

> **格局之有无不足恃，有情无情乃定高低。**

此心法高于一切格局规则。何为有情？

- 干支相生相合
- 三传递生
- 天将乘旺相之地而不空不墓
- 日干得令得地得助
- 身宫宅宫互相生扶

何为无情？

- 干支刑冲克害
- 三传递克
- 天将乘死绝空亡
- 日干休囚无气
- 身命空亡入墓

有情者，纵无格局，亦不至于贫贱。无情者，纵有格局，亦难逃困厄。

# 卷七 · 杂法拾遗

## 一、女命专法

女命与男命不同。男命以干为主，女命以支为主。

- 日支上神为女命之核心——支上吉神良将者，柔顺端庄有福；支上凶神恶煞者，命途多舛
- 女命喜支爻安静，忌丁马冲刑——支静则家安，支动则多变
- 支上见青龙为夫星得力，见六合为子女有缘
- 支被干克为夫制妻，支克干为妻制夫
- 少看天后，老看太阴

## 二、寿数参看

寿夭先于富贵。若人命早丧，富贵何用。

**寿征**：命上神见长生、印绶，值旺相，乘吉将——主寿。
**夭征**：命上见死墓绝，日鬼乘凶将无制——主夭。

**三传与寿**：四孟作三传递生日干——长寿。四季作三传——寿促。从干递生出去（根断源消）——必夭。

**寿数推法**：以太玄数计初传与末传之数，相乘或相加，再配合日支顺序数。

## 三、出身环境

**出身富贵**：本命落于旺相之地，乘吉将吉神，不逢空。胎神旺相，禄马贵神扶日。
**出身贫寒**：本命休囚无气，逢空落空，咸池凶杀临身。
