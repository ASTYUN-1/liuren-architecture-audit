# 九宗门与支位排序速查

## 九宗门 → 定课体大方向

| 九宗门 | 核心含义 | 限制思维方向 |
|--------|----------|-------------|
| **元首**（一上克下） | 事从外来，顺势而为，尊长主导 | 被动接受型，自己不用太主动 |
| **重审**（一下贼上） | 事从内起，反复斟酌，内因主导 | 主动应对型，需要自己拿主意 |
| **比用**（多克取比） | 同类竞争，择善而从 | 需对比选择 |
| **涉害**（克贼同等） | 利害交织，历尽艰险 | 过程曲折，深浅难测 |
| **遥克**（无克取遥） | 暗中较劲，隔山打牛 | 明枪易躲暗箭难防 |
| **昴星**（无遥取酉） | 伏藏不动，待时而发 | 宜静不宜动 |
| **别责**（课不备） | 不完整，权宜之计 | 非常规手段 |
| **八专**（干支同处） | 独断专行，自我中心 | 与他人关系难处理 |
| **伏吟**（天地盘同） | 静止不动，呻吟之意 | 等待、维持现状 |
| **反吟**（天地对冲） | 反复不定，事有反复 | 易变故、不易安定 |

## 支位排序 → 定能量流动节奏

| 支位排序 | 含义 | 节奏 |
|----------|------|------|
| **连茹**（三传相接） | 连续推进，链式反应 | 快、连续 |
| **间传**（三传隔位） | 有间隔，跳步前进 | 慢、有停顿 |
| **进茹**（顺连茹） | 由近及远，逐步扩展 | 向前发展 |
| **退茹**（逆连茹） | 由远及近，逐步收缩 | 后退、回缩 |
| **三合局** | 三方汇聚，合作之势 | 汇聚、合作 |
| **递生**（初生中中末） | 层层生助，源源不断 | 吉利、顺畅 |
| **递克**（初克中中末） | 层层克制，前阻后碍 | 阻滞、不利 |

- 贵人顺行 → 事速、顺遂
- 贵人逆行 → 事缓、反复
