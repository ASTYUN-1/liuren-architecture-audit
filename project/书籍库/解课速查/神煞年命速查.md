# 神煞年命速查

## 重要神煞

| 神煞 | 含义 | 何时重点看 |
|------|------|-----------|
| 驿马 | 走动、变化、快 | 占出行、事业变动 |
| 天马 | 快速的变化 | 占调动、升迁 |
| 桃花（咸池） | 感情、异性缘 | 占感情 |
| 华盖 | 孤独、玄学、艺术 | 占学业、自身状态 |
| 天乙贵人 | 贵人相助 | 占求助、求职 |
| 文昌 | 考试、学问 | 占学业 |
| 魁星 | 科举、提名 | 占考试、名声 |
| 日德 | 喜事、积德 | 看整体吉凶 |
| 日禄 | 俸禄、待遇 | 占工作待遇 |
| 破碎煞 | 破损、失败 | 占事看能否成 |
| 天赦 | 赦免、解脱 | 占官司、困境 |

**注意：** 神煞是"调料"不是"主菜"。课体+类神定吉凶大框架，神煞在框架内做精细化调整。

## 年命状态

| 年命状态 | 含义 |
|----------|------|
| 年命上于课传 | 事切身相关，必看 |
| 年命不入课传 | 看年命本身的上神状态 |
| 课传吉，年命吉 | 事情顺利，个人也有助 |
| 课传吉，年命凶 | 好事但个人福报不够 |
| 课传凶，年命吉 | 外部环境差但个人能化险为夷 |
| 年命上神空亡 | 一年（行年）无成 |
| 本命上神空亡 | 一生（本命）无成 |

**徐伟刚年命四规律：**
1. 本命重于行年（本命管一生，行年管当下）
2. 年命本身重于其上神
3. 年命可直接入课传讨论
4. 日干与年命为"体用"关系
