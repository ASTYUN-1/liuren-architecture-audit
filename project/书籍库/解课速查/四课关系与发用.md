# 四课关系与发用速查

## 干支关系（最优先）

| 干支关系 | 含义 |
|----------|------|
| 干生支 | 我生他/宅→付出、消耗 |
| 支生干 | 他/宅生我→得助、受益 |
| 干克支 | 我克他/宅→能控制 |
| 支克干 | 他/宅克我→被压迫 |
| 干支相合 | 和谐、合作 |
| 干支相冲 | 分离、远行、变动 |
| 干支相刑 | 摩擦、纠纷 |
| 干支相害 | 猜忌、不和 |

## 四课格局

| 四课格局 | 含义 |
|----------|------|
| 皆受生 | 雨泽润露，处处有人帮助 |
| 皆受克 | 彼此全伤，处处碰壁 |
| 皆有刑 | 宾主不投，互相伤害 |
| 皆相冲 | 各离分析，难以聚合 |
| 皆相害 | 彼此猜忌，互不信赖 |
| 皆入墓 | 昏迷招晦，到处碰壁 |
| 皆相合 | 两心契合，合作顺利 |

## 发用的十二长生状态

| 长生状态 | 含义 |
|----------|------|
| 长生发用 | 事之初始，欣欣向荣 |
| 帝旺发用 | 事已极盛，盛极则衰 |
| 墓库发用 | 发旧事、过去之事重现 |
| 绝地发用 | 绝处逢生，否极泰来 |
| 胎养发用 | 萌芽阶段，尚未成型 |

## 发用的生克关系
- **发用克日**（克干）→ 忧身、压力、疾病
- **发用克辰**（克支）→ 家宅不宁、外部环境不佳
- **发用克时** → 心惊、变动、突发
- **发用生日** → 有助、得利、好事

## 发用与重要时间
- 发用即月建 → 当月应事
- 发用即太岁 → 当年应事
- 发用即月将 → 事在眼前
- 发用即占时 → 事起当下

## 发用特殊组合

| 发用组合 | 含义 |
|----------|------|
| **卯酉发用** | 门户之事、分别、变动 |
| **辰戌发用** | 争斗、冲突、诉讼 |
| **魁罡发用** | 刚猛、急速、权威 |
| **丁马发用** | 快速变化、调动、出行 |
| **贵人发用** | 有贵人相助 |
| **白虎发用** | 压力、疾病、变动 |
| **空亡发用** | 虚象、事不实、虎头蛇尾 |
