# 十二天将与分类取类速查

## 十二天将层次（将高于神）

核心：天将行使主宰权，地支行使生克权。

| 天将 | 吉凶定论 | 主宰权范围 |
|------|---------|-----------|
| 贵人 | 吉将 | 贵人、助力、尊长 |
| 螣蛇 | 凶将 | 虚惊、变化、缠绕 |
| 朱雀 | 平（吉凶看所乘） | 信息、文书、口舌 |
| 六合 | 吉将 | 合作、婚姻、中间人 |
| 勾陈 | 凶将 | 争斗、拖延、土地 |
| **青龙** | **大吉将** | **喜事、财富、升迁** |
| 天空 | 凶将 | 虚假、空亡、文书 |
| **白虎** | **凶将** | **疾病、压力、道路** |
| 太常 | 吉将 | 宴席、常规、稳定 |
| 玄武 | 凶将 | 盗失、隐秘、小人 |
| 太阴 | 平（吉凶参半） | 隐秘、女性、暗中 |
| 天后 | 吉将 | 保护、恩泽、女性 |

**核心论点：** "吉将永吉，凶将永凶。" 即使青龙乘绝地，其吉性仍在，只是打折扣。即使白虎乘旺，其凶性仍在，只是凶的程度不同。
