# 三传走向与三合局速查

## 三传递生 / 递克 / 递合

| 三传关系 | 含义 |
|----------|------|
| **递生**（初生中、中生末） | 层层有助，源源不断，大吉 |
| **递克**（初克中、中克末） | 层层受阻，前堵后追，大凶 |
| **先克后生** | 先难后易，渐入佳境 |
| **先生后克** | 先好后坏，先甜后苦 |
| **三传递合** | 循环相合，合作之势 |

## 三合局

| 三合局 | 五行 | 象意 |
|--------|------|------|
| 申子辰 **润下局** | 水 | 流动、智慧、隐秘 |
| 亥卯未 **曲直局** | 木 | 生长、发展、仁爱 |
| 寅午戌 **炎上局** | 火 | 热烈、名声、礼仪 |
| 巳酉丑 **从革局** | 金 | 变革、决断、经济 |
| 辰戌丑未 **稼穑局** | 土 | 稳定、积蓄、农业房产 |

## 干支传变
- **支传干**：事从内到外、从私到公、从环境到自身
- **干传支**：事从外到内、从公到私、从自身到环境
- **三传不见干支**：事与己关系不大

## 进茹退茹

| 类型 | 走向 | 象意 |
|------|------|------|
| **进茹**（顺行） | 逐步向前 | 进展顺利、步步高升 |
| **退茹**（逆行） | 逐步后退 | 退缩、退缩、收敛 |
| **间进** | 有间隔的进 | 进中带阻，需努力 |
| **间退** | 有间隔的退 | 退中带缓 |

## 虚实墓生传变
- **空传实**（空亡发用→实传）→ 先虚后实
- **实传空**（实发用→空末传）→ 虎头蛇尾
- **长生传墓** → 盛极而衰
- **墓传长生** → 否极泰来
