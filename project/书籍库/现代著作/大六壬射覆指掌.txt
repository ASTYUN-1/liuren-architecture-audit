大六壬射覆推理框架（六派归一·精简十步法）
================================================

一、六派共同核心原则
--------------------
• 起课：月将加时→天地盘→四课→三传。刚日看日上神，柔日看辰上神。
  专用初传（发用），中末不取（东方朔例外）。
• 五行定大类：发用五行决定物质大类（金木水火土）。
• 形状：孟圆、仲方、季尖（四家共识）。
• 颜色：旺从本色、相从子色、死从妻色、囚从鬼色、休从母色。
• 新旧死活：旺相为新/活，休囚为旧/死。
• 有无：天空+空亡=无物；仅空亡=有物。
• 八体入射覆：仅取八体——润下、曲直、炎上、稼穑、从革、伏吟、返吟、不备。

二、各派互补技法
----------------
• 苗公：地支加临组合象（酉加巳=海，巳加亥=双胎等）
• 东方朔：孟仲季三传分工（季用→初事类中形色末贵贱）
• 袁天罡：分门别类（有无/虚实/生死/水陆/完缺/可食/数目）
• 银河櫂：天官体段+月将物类+人元颜色+方位真伪 四纲法
• 课体结构派：结构决定功能，课体>类神
• 赵向阳：先锋门定第一印象+活时起课法

Step0 — 定背景（三才法）
目的：缩小判断范围。
依据：天时（季节物产）、地理（场所物品）、人物（身份习惯）。
操作：排除不合场景的选项。例：夏季办公室→电子/文具类。

Step1 — 起课观式
目的：得发用、干上、支上。
依据：月将加时排盘。刚日视干上神，柔日视支上神。
操作：发用=物之本体，干上=外表，支上=内里。

Step2 — 辨有无
目的：是否空射。
依据：天空发用+落空亡=无物；仅空亡=有物。
操作：无则止，有则继续。

Step3 — 定五行大类
目的：物之材质类别。
依据：发用地支五行：
  金（申酉）→金属/精密/电子
  木（寅卯）→木质/纸品/植物
  水（亥子）→液体/饮料/存储
  火（巳午）→电器/发热/发光
  土（辰戌丑未）→陶瓷/食品/容器

Step4 — 辨形状
目的：物之几何形态。
依据：发用孟仲季：
  四孟（寅申巳亥）→圆形/有角
  四仲（子午卯酉）→方形/端正
  四季（辰戌丑未）→尖碎/细碎
  旺圆软、相方嫩、死僵直、囚碎细、休轻缺

Step5 — 定颜色
目的：物之主色。
依据：①干上神天干（甲青乙碧丙赤丁紫戊黄己红庚白辛缥壬黑癸绿）
      ②旺相休囚（旺从本色，相从子，死从妻，囚从鬼，休从母）
      ③天将改色（玄武→黑，白虎→白，朱雀→红等）
示例：干上丙+发用旺→红色为主。

Step6 — 别新旧虚实生死
目的：物之状态。
依据：旺相休囚死：
  旺相→新/完好/活物
  休囚→旧/磨损/死物
  火神临日辰→虚；水神→实
  旺相相生→活；休囚死气相克→死

Step7 — 课体扣类（八体入射覆）
目的：物之功能结构类型。
依据：三传三合局：
  润下（申子辰水）→液体/流质
  曲直（亥卯未木）→纸木/家具
  炎上（寅午戌火）→电器/发热
  稼穑（辰戌丑未土）→陶瓷/食品
  从革（巳酉丑金）→科技/电子
  伏吟→贴身/固定
  返吟→远来/可动
  不备→配件/缺件

Step8 — 天将加临定精细特征
目的：质感、花纹、来源、细微特征。
依据：天将体段 + 地支加临组合：
  天将：贵=贵重、蛇=盘曲、朱=彩色、合=成双、
        勾=方正、龙=木纹、后=水润、阴=精工、
        玄=黑藏、常=食品、虎=金属、空=灰空
  苗公加临：酉加巳=小/霜雪、巳加亥=双胎等
  银河櫂方位：子午=可食有孔窍、寅申=四角物

Step9 — 综合推断
目的：输出具体物品。
操作：合Steps 0-8特征，匹配现代物象表。三才过滤，特征叠加。
示例：酉(金)+仲(方)+干上白+从革+新+加巳(小/霜雪)
      → 白色方形小型电子产品+口袋三才→蓝牙耳机。

四、AI 调用建议
--------------
1. 每步输出一个特征标签，Step9合并匹配。
2. 优先Step0三才（大幅缩范围）。
3. Step2可提前终止。
4. Step8无加临象可跳过。
5. 现代物象参照《_射覆_temp_D》现代表。
6. 数法：子9丑8寅7卯6辰5巳4午9未8申7酉6戌5亥4。

大六壬射覆 IF-THEN 规则库
（萃取自苗公/东方朔/袁天罡/银河櫂四派口诀）

起课前题：刚日视干上神+发用，柔日视支上神+发用。专用初传，中末不取。

▌维度1：定有无
IF 发用=天空+落旬空 THEN 无物
IF 天空临日辰+落旬空 THEN 无物
IF 发用=天空(不空) THEN 中虚之物
IF 无天空+有空亡 THEN 有物
ELSE 有物

▌维度2：定五行大类
IF 发用=申/酉 THEN 金类(坚硬/金属/白色/辛味)
IF 发用=寅/卯 THEN 木类(细长/木质/青色/酸味)
IF 发用=亥/子 THEN 水类(曲形/液体/黑色/咸味)
IF 发用=巳/午 THEN 火类(尖虚/发热/赤色/苦味)
IF 发用=辰戌丑未 THEN 土类(圆厚/陶瓷/黄色/甘味)
【精分子类】金：旺金银、相铜铁、休铅锡、囚砖石、死瓦碟 | 木：旺材木、相竹苇、休朽木、囚船车、死棺椁 | 水：旺江河、相流泉、休湿地、囚沟渠、死池湖 | 火：旺炉冶、相灯烛、休烟尘、囚灰炭、死余烬 | 土：旺山岳、相丘阜、休屋宇、囚砂泥、死墙壁

▌维度3：定形状
IF 发用=孟(寅申巳亥) THEN 物圆(或有棱角)
IF 发用=仲(子午卯酉) THEN 物方(平直)
IF 发用=季(辰戌丑未) THEN 物尖碎(或圆厚)
IF 阳孟 THEN 四角形 | 阴孟 THEN 不团圆 | 阳仲 THEN 端正 | 阴仲 THEN 不坚侧
IF 旺 THEN 圆软 | 相 THEN 方嫩 | 死 THEN 硬直 | 囚 THEN 碎细 | 休 THEN 轻缺

▌维度4：定颜色
IF 旺 THEN 发用五行本色 | 相 THEN 从子色(我生者) | 死 THEN 从妻色(我所克者) | 囚 THEN 从鬼色(克我者) | 休 THEN 从母色(生我者)
【本色】木青、火赤、土黄、金白、水黑

一、现代射覆三才背景法则
─────────────────────────────
来源：四无君。起课前先定三才，将可能从数千缩至数十。

【天时】季节决定物产
·春(寅卯木旺)→木器/文书/纸品/花果
·夏(巳午火旺)→电器/发热体/发光物/屏幕
·秋(申酉金旺)→金属/精密仪器/电子产品
·冬(亥子水旺)→液体/饮料/存储设备
·四立前各18日(土旺)→陶瓷/食品/土产
示例：冬季射覆，优先排除西瓜、冷饮等反季物。

【地理】场所反推物性质
·书房/办公桌→文具/书籍/电子设备/文件
·卧室/口袋→个人用品/首饰/钥匙/耳机
·厨房/餐桌→食物/餐具/食材/小电器
·客厅/茶几→遥控器/茶具/装饰品
示例：办公室射覆，食物概率极低，文具/电子优先。

【人物】身份缩小范围
·儿童→玩具/零食/饰品/文具
·女性→化妆品/首饰/包/墨镜
·男性→打火机/钥匙/钱包/手表
·长者→老花镜/药盒/保温杯
示例：女性卧室射覆，化妆品概率远高于工具。

─────────────────────────────
二、课体优先法则
─────────────────────────────
来源：四无君。结构>类神：先读课体，再看类神具体化。课体错则全盘输。

【课体→物象】
·从革(金局)→科技电子/通信/更新换代品
·炎上(火局)→电器/灯具/发热体/屏幕
·润下(水局)→液体/饮料/存储/数据流
·曲直(木局)→家具/文具/纸品/木器
·稼穑(土局)→陶瓷/食品/容器/玻璃
·伏吟→贴身物/随身物/固定装置
·返吟→外来物/可动物/投掷/折叠
·不备→配件/半成品/有缺件/单件

【推理顺序】课体→发用→天将→加临
示例：从革+酉+白虎+丑→白色充电舱

【课体冲突】课体与类神冲突时以课体为准。
例：发用寅木+课体从革→电子类，寅木读作外观(绿/纸盒/木纹)，非木头。

─────────────────────────────
三、先锋门法则
─────────────────────────────
来源：赵向阳新派

【活时起课】射覆用活时优于正时
·牙签法：抓一把数总数÷12取余(子1丑2…亥0)
·报数法：随意报数÷12取余

【先锋门地支物象】
子→液体/圆小/暗色  丑→容器/陶瓷/食品
寅→长条/木质/文书  卯→细长/成双/编织
辰→药物/网络/渔具  巳→电器/发热/小件
午→发光/彩色/屏幕  未→食物/衣物/包/硬中带软
申→金属/工具/药品  酉→精密/贵重/金银
戌→陶瓷/印章/奖杯  亥→小件/玩具/配件

【三才修正】先锋门提供第一特征，三才做方向修正。
示例：办公桌+先锋门未(食物)→修正为笔握软胶→圆珠笔。

─────────────────────────────
四、现代射覆错误防范清单
─────────────────────────────

【错误1】忽略干上神——干上神是外观信号。玄武=黑，朱雀=彩色/有字。
防范：每案必查干上神，与发用互参。

【错误2】被案例锚定——同地支不同天将物不同：酉+白虎=金属外壳；酉+玄武=银灰；酉+太阴=首饰。
防范：同类地支必须结合天将重新解读，不可套案例。

【错误3】只读天将颜色不看地支本义——巳=梳妆/炉冶/火电，非青色；未=食物/衣物，非黄色。
防范：先读地支物象，再用天将修正颜色。

【错误4】忽视旬空——空亡=虚：空盒/没电电器。发用空则核心特征不存在。
防范：每案必查空亡。

【错误5】忽略库墓——入墓为"藏"(装盒/盖住/收起)。墓神覆日=保温/干燥/覆盖。
防范：见墓先判收藏/覆盖/保温，不直接断坟墓。

【错误6】不分主从层次——发用=主象，中传=容器/附件，末传=价值/属性。不可颠倒。
防范：三传各有分工，分层解读。

六、射覆推理禁忌
─────────────────────────────

【忌1】不看背景套类神——无三才不射覆。

【忌2】只读发用忽略干上——发用定大类，干上定外观。
例：干上玄武+发用酉→白金属件但外观黑(黑手表)。

【忌3】过度解读——发用只定大类，细节靠天将+加临。需≥3条证据再下结论。

【忌4】忽视旬空——空亡=虚。发用旬空则核心特征不存在。

【忌5】单维定物——须综合课体+发用+天将+加临+三才+干上交叉验证。

【忌6】执泥古籍——古刀剑今美工刀/手术刀，古窑灶今芯片。取理不取形。

【忌7】层次混乱——发用=主象，中传=容器/附件，末传=价值/属性。

【忌8】忽略递生育克——递生到干=有价值之物；递克到干=危险品。
