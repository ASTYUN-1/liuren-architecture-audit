## 这本书在讲什么

这是一本大六壬实战判断的**内部特训讲义**（11 讲，约 35 个完整课例），回答的问题是：**一个课拿到手里，该从什么角度入断？** 这是困扰所有大六壬学习者最大的问题。

作者的答案是：不需要背烂全部课经，只需要一条**"三步断课法"**主线——先**明占类**（要的结果是"能否成 / 能否出现 / 向何方向发展"中的哪一类），再**定侧重**（从"类神 / 课体"两条主线中选一条），最后**看显象**（对选中的象做真假校验）。在这条主线之下，作者给出了"有路"理论（如何识别被引动的象）、凶煞优先的快速否定法、以及六大分类占断门类（时运 / 财禄 / 人际 / 应聘 / 升职加薪 / 恋爱）和应期断法。

这套方法论之所以值得读，在于它**以简驭繁**：把浩瀚的壬学收敛成少数几条可重复的判断规则，并且每条规则都配有真实的课例和事后反馈。

> 第二部分（[第二本扩展：《大六壬指南》问答录](#第二本扩展大六壬指南问答录)）是本书的扩展卷，把古典断法细节（占病四维 / 官五要素 / 古典应期 / 动象三查 / 课体界定 / 兵贼逃亡 / 孕产 / 来意占）逐项补进同一套方法论骨架。

## 三步断课法：全书的总入口

### 明占类 → 定侧重 → 看显象

**它解决什么问题**：一卦一课拿到手，从哪里下手断？

**核心逻辑**：任何占问先归入三类结果——①能否成（升职、伤病）；②能否出现（买房、得贵人）；③向何方向发展（终生运势、经济走向）。结果类型决定主线选择：存现类问题用**类神**（代表该事物的干支神将组合，如亥午卯丑勾=房产），方向/大势类问题用**课体**（整体结构，如登天课主上扬、凝阴课主低迷）。主线选定后做真假校验：类神现于课传 + 不空亡 + 不变质 ⇒ 事必成；空陷或变质 ⇒ 向反面。

**书中的用法**：占鹏博士股票次日走势——先归"向何方向发展"，取课体气势；四课不备+六阴相继尽昏迷=低迷；干支各被上神克=《毕法》"彼此全伤防两损"；三传木局逢白虎=谣言动摇。结论"股必降"，次日降 7%。

**什么时候会失效**：同一课"类神也可、课体也可"的多解自由度较大（见"陷阱"节）；盘面数据缺失时无法硬断。

→ 深入: [`sanbu-duanke`](./sanbu-duanke/SKILL.md)

### 类神 / 课体双侧重选择

**它解决什么问题**：主线到底选哪一条。

**核心逻辑**：能取到类神（该事物的干支神将组合）就取类神；取不到类神（或问的是大势走向）就转课体。以"入课传为重、不入课传为轻"加权。注意课体不只是《课经》九宗门课名，《毕法赋》的干支上神结构（解离格、彼此全伤、交车相合）同样是课体。

**书中的用法**：占能否分房——取房屋类神（亥为楼阁加干），类神现于干上有"到手"之意；但亥为旬空成"不确定"，再查旺衰（亥在酉月旺相）与得助（申生亥），最终断"房必得但过程反复"。

**什么时候会失效**：只翻《课经》忽略《毕法》会漏掉决定性结构。

→ 深入: [`leishen-keti`](./leishen-keti/SKILL.md)

## 真假校验：空亡与变质

### 空亡辨法：旺不为空，得生得助不为空

**它解决什么问题**：类神现于课传，但空亡了，还算不算数？

**核心逻辑**：空亡不是"没有"，而是"不确定"。辨别看两点：旺衰（旺相如乘月建则"旺不为空"）与是否得住（得生得助不为空）。真正空亡时结论从"成"降级为"待定/需旁证"。唯一例外：**天空**所主之空不论旺衰一律以凶论。

**书中的用法**：占孕以胎神为类神，胎神空亡但为月建（旺相），断必有孕——应验。

**什么时候会失效**：见空亡一律断凶是常见误判；空亡须结合生扶、旺衰、位置综合判断。

→ 深入: [`kongwang-bianzhi`](./kongwang-bianzhi/SKILL.md)

### 变质论：吉象反查校验

**它解决什么问题**：类神是吉象，但一定吉吗？

**核心逻辑**：类神现于课传只是事成的必要不充分条件。类神若"变质"则吉转凶：乘凶将（日禄乘玄武作闭口则禄难到手）、作空亡（财空反为损耗）、逢破碎煞（财作破碎则花费）、阴神带鬼（财之阴神见鬼则因财致伤病）。判断模式 = 类神象意 × 所处状态。

**书中的用法**：占工作见日禄本为吉象，但禄乘玄武作闭口，断"禄难到手、工作如鸡肋"。

**什么时候会失效**：忽略所乘天将、空亡、闭口、破碎、阴神六亲，只见吉象即断吉。

→ 深入: [`kongwang-bianzhi`](./kongwang-bianzhi/SKILL.md)

## 象之动："有路"理论

### 合刑冲破害皆可为路

**它解决什么问题**：课传里一堆静态类象，哪个才是真正的判断重点？

**核心逻辑**：静态类象不被引动时意义模糊；一旦"有路"被引动，就成为突出的判断标志，力量强、显象明确。有路共六种引动方式：三合、六合、遁干五合、刑、冲、破、害，另加类象与其天盘、落宫之间的关系。陈公献只说"合处为来之路"，作者扩为六种——这是本书最有辨识度的扩展。

**书中的用法**：年运课中日禄乘白虎本属"惊危之象、守之无味弃之可惜"的鸡肋，但行年一介入就把虎引动，由惊危变成破坏——断其辞职（行年上神蛇代表他自己起异心），反馈果然辞掉工作炒股大亏。

**什么时候会失效**：被引动不等于吉凶；"动"是判断深入的辅助，不是吉凶本身。

→ 深入: [`youlu-lilun`](./youlu-lilun/SKILL.md)

## 凶煞优先：先找一个"凶"的充分理由

### 旬丁 / 白虎 / 勾陈 / 天空

**它解决什么问题**：断课最怕吉凶两头摇摆、逻辑不闭环。

**核心逻辑**：凶比吉更易识别，所以**先扫描凶煞**，找到一个"凶"的充分理由就否定吉面（非吉即凶的排中律）。四大凶煞从人与事两角度分：对人主病伤惊忧（白虎死丧、螣蛇惊扰、勾陈囚禁、死气墓神）；对事主拖拉失败移易（勾陈迟滞、太阴抑制、玄武消失、旬丁移易）。

**书中的用法**：占远行携妻子同往——中传巳为旬丁又为劫煞，飞祸横来，全家遭难。凶象极多时凶势成定局。

**什么时候会失效**：白虎须看"位"（发用才主吉凶，课上显象不主吉凶）；凶煞否定后可被吉象并聚或受制所化解，不能一锤定音。

→ 深入: [`xiongsha-suduan`](./xiongsha-suduan/SKILL.md)

## 分类占断六门

### 时运课：五维检查

**它解决什么问题**：泛问"未来一段时间运势"。

**核心逻辑**：按五维逐项检查——安全（吉凶二象）、收入（父/禄旺衰）、婚姻（六合太常旺相生合干支）、官运（贵龙常作父母长生）、家运（支上为主）。另先看课体定大方向（吉课则吉、凶课则凶）。

**书中的用法**：职员占时运——纯阴课遍地贵人=天天忙乱无升迁；支加干带日德贵人+末传天喜=八月有婚姻之喜；蛇雀乘酉=眼赤喉痛。三项全部应验。

→ 深入: [`shiyun-zonghe`](./shiyun-zonghe/SKILL.md)

### 财禄判断：收入 ≠ 财运

**它解决什么问题**：把"看看财运"拆成可操作的判断。

**核心逻辑**：收入看禄与父母爻（六条件全吉：旺相、不空陷、不乘蛇虎玄空、不作闭口、不乘丁神、不落墓）；纯财看财爻或龙虎阴（属金主金银）。大忌：三传全财大凶、脱气为求财最忌、财怕空怕破碎煞、财局生鬼主因财致祸。无财爻时看传递象（干支互传、申卯相加为帐目划拨）。

**书中的用法**：打零工者占 08 财运——太岁作蛇鬼一年麻烦多；干上父母爻作勾陈生活磕绊；天空发用作巳=打工但落空懒惰；末传财作太阴钱财隐而不见。断"身无余钱"，年底果然还要借钱过年。

→ 深入: [`cailu-panduan`](./cailu-panduan/SKILL.md)

### 人际关系：生合德 vs 刑克穿鬼

**它解决什么问题**：某人对我是助力还是损害？

**核心逻辑**：以日干为自己。整体人际看课传中生、合、德（对我有利）与刑、克、穿、鬼（对我不利）；看某人态度取其类神对日干 / 干上神 / 年命上神的损益（益=生合，损=克脱刑穿）。

**书中的用法**：问同事关系能否搞好——课传一片六合太阴龙神、支来加干=强烈男女关系象；四课不备=三角；干支卯戌合+六合太阴阴私甚重=私合。断其与经理有私情，午月夫归捉获、敲掉经理数千元。

→ 深入: [`renji-guanxi`](./renji-guanxi/SKILL.md)

### 应聘 / 升职加薪 / 恋爱

**应聘**：职位类神=禄+父母爻+长生爻，现课传而吉旺不空陷则必得；类神不现但"吉象并聚"（生合、龙常贵合）亦可成。[`yingpin-gongzuo`](./yingpin-gongzuo/SKILL.md)

**升职加薪**：升要有**进达之象**（旺气吉神据要位），加要有**增益之象**（生气现课传、金钱类象旺相不空）——两种象不可混用；发用空亡又处衰气断不果。[`shengzhi-jiaxin`](./shengzhi-jiaxin/SKILL.md)

**恋爱**：常法（干支上神生合则成、冲克刑害则散）、变法（年命倒置、第三者象、铸印、婚喜并聚）、琐象（四课不备=三角关系、勾陈作鬼=为情痛苦，作者标注"准验度很高"）三套逻辑按序执行。[`lianai-panduan`](./lianai-panduan/SKILL.md)

## 应期：先定迟速，再定日期

**它解决什么问题**：占断的"老大难"——什么时候应验？

**核心逻辑**：应期没有固定模式，"年发用应年、月发用应月"之类基本无征验。正确流程两步走：**先定迟速**（近期/远期），再**定具体日期**。定日期用天将变化法（《心印赋》十二天将居位判辞——找关键天将在哪个时空达到事情发展要求）+ 五行法（如火旺于巳午死于酉戌），**两线定一点**交叉验证。

**书中的用法**：占朋友出行何日归——五行法：火旺待灭，申被克到酉戌才安闲；天将法：贵人入私室=回家（酉日）。两线都指向酉日，断丁酉日必归。

**什么时候会失效**：未读透课传细节就硬断应期=盲人摸象；应期必须在吉凶已定之后断，顺序不可颠倒。

→ 深入: [`yingqi-panduan`](./yingqi-panduan/SKILL.md) / [`jixiong-tiaozhi`](./jixiong-tiaozhi/SKILL.md)（吉凶调制）

## 终身与年运课法

**它解决什么问题**：占人一生 / 一段较长的运势。

**核心逻辑**：结构化读取管线——年命（本命+行年）处理：入课传看本身、不入课传看年命之上神；三传=人生初中末三限，天将=该限主要运势特征，支神六亲关系=具体吉凶。一课双时层：三传看长久全局，干上神看当前状态。

**书中的用法**：男占终身——发用巳作天空与本命丑相合（合动太阴=心里空落落），断少年运势蹇滞；太阴逢子为入内（08 年找到工作）但妾妇相侮（受女上司压制）——全部应验。

→ 深入: [`zhongshen-nianyun`](./zhongshen-nianyun/SKILL.md)

## 陷阱与反例

**1. 空亡陷阱（最常见）**：见类神现课传就断"事必成"，忽略空亡使结果变"不确定"；或见空亡就断凶，忽略"旺不为空、得生得助不为空"。预警：类神临旬空而休囚死绝、天空乘类神。

**2. 类神变质**：吉象乘凶将 / 作闭口 / 作破碎煞 / 阴神见鬼则吉转凶。预警：日禄乘玄武、财作破碎煞、财之阴神见鬼。

**3. 只盯《课经》忽略《毕法》**：课体=九宗门大势 + 毕法赋干支上神结构两层，只看课名会漏掉决定性结构（解离格、彼此全伤）。

**4. 应期迷信单一模式**：吹嘘"应期神准"不可信，"年发用应年"类口诀基本无征验；未读透课传细节就报应期是断错根因。

**5. 财运只问"有没有钱"**：收入（禄/父母爻）与纯财（财爻/龙虎阴）类神体系不同；脱气乘玄武/天空=钱财耗尽，三传全财=大凶。

## 作者的局限 (读这本书要打的折扣)

**幸存者偏差**：全书 30+ 例全部"果应"，无失败样本、无对照、无盲测、无统计——案例个数≠命中率，不可把书中案例当统计证据。

**同一课可多解**：书中多次"以类神为侧重也可、以课体为侧重也可"，解释自由度较大，却未讨论这种自由度本身的风险——输出单一结论时必须声明"多解风险"。

**信仰前提未论证**：天干地支、五行生克、神将象意与人事之间存在客观映射——这是全书不言自明的前提，从未被论证；象意系统的组合自由度使"事后自圆其说"几乎总能成立（可证伪性问题）。

## 关键术语速查

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 占类 | 占问结果三分类（能否成/能否出现/向何方发展） | ≠"问哪类事"的分类学 |
| 侧重点 | 断课主线只有两条：类神 / 课体 | 反对逐项硬套课经 |
| 类神 | 代表某类人事物象的干支神将组合 | ≠ 课体，≠ 单个天将 |
| 课体 | 九宗门课名 + 毕法赋课传结构两层 | 不能只盯《课经》 |
| 空亡 | 不确定，旺不为空、得生得助不为空 | 空亡 ≠ 一律凶（天空除外）|
| 变质 | 类神乘凶将/空亡/破碎/闭口等而吉转凶 | "象的变形"而非"没出现" |
| 有路 | 合（三合/六合/遁干五合）、刑、冲、破、害及天盘落宫 | 陈公献只说"合"为路 |
| 凶煞 | 旬丁/白虎/勾陈/天空，从人与事两角度 | 一套否定式速断法，非神煞清单 |
| 年命 | 本命+行年；入课传看本身，不入看其上神 | ≠ 普通属相 |
| 三传三限 | 三传=人生初中末三限，天将为运势特征 | 终身课结构法 |

完整词典见 [GLOSSARY.md](./GLOSSARY.md)。

### 本书定位：古典课例注疏，与第一本互补

**它解决什么问题**：《指南》每一句"铁口直断"到底是怎么断出来的？

**核心逻辑**：第一本回答"一个课拿到手从哪入断"（现代实战方法论，案例年代 2004–2009）；本书回答"陈公献的断语凭什么这么断"——把明末清初《大六壬指南》（1607–1651 课例，130 占例）高度浓缩的古典断语逐句拆开，还原成可理解、可复用的法则链（占病四维、官五要素、应期法则、动象三查、主次取舍）。整本书示范同一条主线：**课体大势 > 类神细节 > 主次取舍**。

**书中的用法**：每课先录《指南》原文断语，再以问答形式逐句追问"为什么这么断"，以课盘数据（干支上神/三传/天将/神煞/年命/驿马）还原推导路径，引用《毕法赋》《指掌赋》《心印赋》《会纂指南》《玉成歌》《曾门》等佐证，多数课例补充事后验证，个别给出修正（如"原书说是血忌，实际上是血支"）。

**什么时候会失效**：默认《指南》断语全对、以注释经典为务，缺少对古典断法本身的批判性检验；古典制度语境（科举/总督/卫所）映射到现代需类比转换。

### 新增体系一：占病四维（病因 / 症候 / 医药 / 生死）

**它解决什么问题**：占病不再靠一句"白虎临门"蒙，而是拆成可逐一取类神的四个维度 + 应期。

**核心逻辑**：
- **病因**三候选：虎鬼受克神 / 日鬼 / 脱气，取"上卦传且力量最强"者——以力强者为断。
- **症候**：课体象人体——四课不备=气虚、火受克=血病；日鬼乘蛇=气不顺、食神空=不进饮食。
- **医药**：以官鬼星五行辨受症脏腑，治本脏不治标（如病玄胎木局→理肝清心，勿健脾补肺）。
- **生死**：**必死四忌**——马星（魂游千里）、玄胎（别处投胎）、三传传空（没有活路）、日鬼太旺（病重难医），多忌叠加断死；**日墓发用乘玄武=收魂杀**，必死。
- **应期**：长生/墓/绝、鬼旺之时，并须与占者本命行年较量。

**书中的用法**：问答录十一占酒色伤身之病——四维逐面取类神，断死忌叠三，又辨官鬼五行出"理肝清心勿健脾补肺"的医方。

**什么时候会失效**：墓发用≠一律凶，须按事类定向（失物=在、行人=归、诉讼=判刑、病=死）；"果应"叙事无统计。

→ 深入: [`xiongsha-suduan`](./xiongsha-suduan/SKILL.md)

### 新增体系二：占官仕途（官五要素 / 幕贵科甲 / 铸印乘轩 / 顾祖课）

**它解决什么问题**：把"官运好不好"审计成一串可逐项检查的要素。

**核心逻辑**：
- **官五要素**：贵（上人支持）/ 龙（官类神）/ 禄（薪水=职位）/ 财（官之源）/ 马（行动）——任一入墓绝空，即该方面受损；官星贵人即当官者本人。
- **幕贵定科甲**：幕贵坐空=不由科甲；再查长生父母+皇恩断恩荫之官。
- **铸印乘轩**=迁转升迁；虎马发用=速迁速败、暴成暴败；发用落空=成而不久。
- **顾祖课**=归乡/不满仕；龙化为蛇=由大变小。
- 三传递克主参劾（方向不限、不必克到干）；干支坐墓甘招晦；传将逆行=有退无进；财官禄马入墓绝=急流勇退。

**书中的用法**：续一占田大冢宰被参——三凶叠加（贵履天罗、禄马入空墓、传将逆行）断丢官入狱；问答录十五末传龙乘月建断"由小至大、统治一方"。

**什么时候会失效**：古典官职映射到现代公司职位需类比转换，映射风险未讨论。

→ 深入: [`shengzhi-jiaxin`](./shengzhi-jiaxin/SKILL.md) / [`yingpin-gongzuo`](./yingpin-gongzuo/SKILL.md)（考试类神）

### 新增体系三：古典应期法则（岁日月时发用 / 前三辰 / 地盘临处）

**它解决什么问题**：补第一本"先定迟速再定日期"之后、具体定月定日的空白。

**核心逻辑**：太岁发用应一年内、月建一月内、日辰当日、时发用当时；发用加地盘岁日月时同上。**前三辰法则**：发用之神在岁/月/日/时之前三辰范围内，断其当令之时。**六壬定应期很重视地盘**，多以类神临处为断（类神临某月建即应于该月）；病死期看长生/墓/绝或鬼旺，须随课体择法。

**书中的用法**：占六月钦召——天诏（亥）加未，未为六月，断六月应验；占何时生子——未发用在巳前二辰，断发用当令之月生。

**什么时候会失效**：古典"应年/应月"层级须与课传细节互证，不可孤立套用口诀。

→ 深入: [`yingqi-panduan`](./yingqi-panduan/SKILL.md)

### 新增体系四：动象三查（驿马三怕 / 干神归支 / 首尾相见）

**它解决什么问题**：判断一件事"动不动、能不能动"。

**核心逻辑**：
- **驿马三怕**：坐长生、坐墓、被地盘合（缚足恋厩）→ 马不动；但**旺火逢空仍可燎天**——时令旺气空亡仍主动（空亡≠不动）。
- **干神归支**=在家不动的静象；须继续辨支克干则居不住、脱墓则心力交瘁。
- **首尾相见**始终宜：旬首旬尾分临干支，无空亡则吉凶皆成。
- 附加：传将逆行=有退无进；河魁（戌）加临年命=动者静静者动；罗网（辰戌）逢空=解脱而去。

**书中的用法**：问史抚台能否赴任——马坐墓+干神归支双静象断其不动；占贼逃——戌加卯命+驿马行年双动断必逃。

**什么时候会失效**：马星坐墓落空则"纵动无终始"——动而不成，与旺火空动构成对照组，不可只断"动"不断"成不成"。

→ 深入: [`youlu-lilun`](./youlu-lilun/SKILL.md)

### 新增体系五：课体界定与毕法结构

**它解决什么问题**：第一本只说"课体是九宗门+毕法两层"，本书把 21 个课体逐一定界并展开毕法结构层。

**核心逻辑**：不备/知一/度厄/涉害/曲直/回环周遍/蒿矢/元首/重审/炎上/斩关/顾祖/无禄无路/八专/绝嗣/铸印乘轩/连茹/九丑/润下/玄胎逐课界定（含涉害课取用之争：陈公献孟仲季 vs 古法克多）。**病玄胎**：玄胎平时主新意萌动，占病则"别处投胎"成死忌。**墓发用分事类**：同一象按事类定向，非一律凶。毕法结构层补强：彼此全伤、明生暗克、三传递克、干支互乘败气、干支坐墓甘招晦、首尾相见。

**书中的用法**：问答录九占无禄无路课大凶——《曾门》全词佐证；涉害课两课讨论取用法之争。

**什么时候会失效**：课体名界定只是起点，须落到干支乘神与天将结构才能断。

→ 深入: [`keti-qishi`](./keti-qishi/SKILL.md)

### 新增体系六：空亡勘误（日寄宫空更甚）

**它解决什么问题**：第一本说"旺不为空、得助不为空"，本书进一步勘误一个流行谬说。

**核心逻辑**：**日寄宫之空更甚于别宫之空**——《指南》数例为证，"日寄宫空不为空"是无稽之谈。占考试幕贵坐空→断不由科甲，不可按"空不为空"放行。中末空亡先利后不利（初传吉≠全事吉）；中末空占病=新病好久病死；发用落空=事不成或成而不久。另勘误神煞起例：血支正月起丑顺行（原书误作血忌）。

**什么时候会失效**：空亡两端的例外仍在——旺火逢空仍动、罗网逢空即脱。

→ 深入: [`kongwang-bianzhi`](./kongwang-bianzhi/SKILL.md)

### 新增体系七：兵占 / 贼占 / 逃亡（贼符 / 玄武四步）

**它解决什么问题**：第一本完全没覆盖的古典战事 / 失窃 / 逃亡域。

**核心逻辑**：
- **兵占**：贼符（子卯巳申）加干支=内外皆有兵警的快速信号（"冬月必有兵警"）；游都/鲁都断兵贼有无与来向；**干为攻、支为守**——干之阳神=攻方大将、阴神=攻方部属，支上两课=守方大将与部属，课传中看谁的力大。
- **贼占玄武四步**：方向看玄武所临地盘、里数看盗神（玄武阴神）上下相乘、亲属看三合支辰、捕获看勾陈或官鬼克玄武；申作孤辰=祠庙僧象（藏身寺庙）。

**书中的用法**：续二占子逃——玄武临未断西南、盗神卯6×未8=四十八里、玄武居三合断投亲戚之家、勾陈克玄武断丙丁日必获——四步全部应验。

**什么时候会失效**：现代语境下"兵占"须类比为商战/竞争升级，"贼占"可类比失物/走失，但"里数相乘"等口诀属古典经验，不能按字面套用。

→ 深入: [`zhinan-zhanbing`](./zhinan-zhanbing/SKILL.md)

### 新增体系八：孕产判断（生男女多法 / 占产定位）

**它解决什么问题**：占生产 / 胎儿性别的多法并观判读程序。

**核心逻辑**：生男女**多法共振再下结论**——课体法（元首生男/重审生女/纯阴反阳生男/阳不备生女）+ 干上神比和法（比则男、卯震男酉兑女）+ 金口诀法（太乙加本命顺至占时，看上神阴阳，阳男阴女）。占产定位：**支为产母、干为胎儿**；支加干上=已见孩面（顺利），干支互临生合=难产；不备课=气数弱、不足月早产。

**书中的用法**：问答录四占六甲——课体法+干上神法+金口诀法三法合断生男，又断生必顺利（支加干上）。

**什么时候会失效**：多法互斥时以何者为准，书中未给仲裁规则——须标注置信度。

### 新增体系九：来意占（正时断来意）

**它解决什么问题**：来意不明之课，先还原对方所问。

**核心逻辑**：**正时断来意**——正时象义 × 天将 × 类神三点定位（如太岁+青龙断功名、胎神断六甲、章奏占看朱雀）；干支定位：干上主思、支上主行。泛泛而占可断紧事：课体定类→干支乘神定象→逐层收窄到当前最紧急之事。

**什么时候会失效**：多象共振方向不明时，来意仍是猜测，须明言。

→ 深入: [`sanbu-duanke`](./sanbu-duanke/SKILL.md)

### 元方法论：断课三看与主次取舍

**它解决什么问题**：第二本书横贯各占的方法论主线，直接补强第一本的三步断课法。

**核心逻辑**：
- **断课三看**：课体 + 类神 + **一定要看阴神**——阴神不可省略是采集纪律（朱雀阴神断吉旨、玄武阴神即盗神断里数）。
- **主次取舍**：课体大势 > 类神细节；先明课象定方向，再找类神充实细节；特殊课体（如顾祖课）可覆盖类神吉象。
- **救解局部性**：有救解≠改总凶，只决定降几级、不改方向。
- **一德解百祸**：日德可减祸，但只减轻灾祸、不改变课凶总趋势。
- 非占现类勿言之的例外：课象明显可跨占类断（如占病课中见玄武可断贼）。

**什么时候会失效**：主次取舍依赖断者经验，"课体可也、类神可也"的多解自由度仍在。

→ 深入: [`sanbu-duanke`](./sanbu-duanke/SKILL.md) / [`jixiong-tiaozhi`](./jixiong-tiaozhi/SKILL.md)

### 学习路径（第二本书的阅读观）

壬归→指南→断案是正道；站在《指南》高度看壬归、以断案思路看《指南》，才能跳出《指南》；**注书是逼自己进步**；心浮气躁无法深入。第一本给现代实战骨架，本书给古典断法深度——两本合读，才是一个完整的北海体系。

### 批判性提示（读这本扩展要打的折扣）

1. **全部"果应"无统计**：130 占例与逐问注释全是"果应"叙事，无失败样本、无对照、无盲测——古典注疏提供的是"解释力"而非"预测力"，以严格标准检验，命中率未必高于随机。
2. **事后附会温床**：任何断语几乎都能事后找到解释路径（干支/天将/神煞/阴神/年命/地盘任取其一），同一课换一套法则常能推出别的结论。
3. **古典断法对现代语境需类比**：科举 vs 高考、总督 vs 高管、巡抚 vs 省级干部——映射风险书中未讨论，使用者须自行转换并标注置信度。

## 如果只带走三句话（两书合订版）

1. **断课三步走：明占类 → 定侧重 → 看显象**——先问"要的结果是哪一类"，再从类神/课体两条主线选一条，最后做真假校验；第二本书补强为**断课三看**：课体 + 类神 + 一定要看阴神，主次取舍上**课体大势 > 类神**。
2. **凶煞优先 + 空亡变质校验**：先扫凶煞找否定的充分理由，再对吉象类神查空亡与变质；占病用**四维框架 + 必死四忌**，空亡须记得第二本书的勘误——**日寄宫空更甚**、旺火逢空仍动。
3. **应期先定迟速再定日期，两线定一点**（古典应期可辅以岁日月时发用、前三辰、地盘临处）；且永远记住——这套方法的前提（干支五行映射人事）未经论证，两本书的案例都存在幸存者偏差，使用时需标注置信度与多解风险。
