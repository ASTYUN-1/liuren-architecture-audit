# 三重验证结果 — 《北海的六壬特训班讲义》

> 阶段 1.5 产出。对 5 个提取器的候选池（19 framework + 38 principle + 37 case + 15 counter-example + 20 term）执行 V1 跨域 / V2 预测力 / V3 独特性。
> 验证原则：案例与反例、术语作为佐证与素材，不独立成 skill；framework 与 principle 单元逐条验证后按"skill 单元"归组。
> 通过率：57 个方法论单元中通过 55（≈96%）——本书是密集实操讲义，提取器已预筛过，通过率高符合预期。

## 最终 skill 单元（15 个，按用户要求"核心方法论优先、AI 分析工具定位"排序）

### S01 三步断课法（明占类→定侧重→看显象）
- **组成单元**: f01 三步断课法 / f02 占类三分法 / f04 入课传为重 / p18 看课重点（干上支上三传+纠结处）/ g01 占类 / g02 侧重点
- **V1 跨域**: ✓ 第一讲定义方法论 → 第二~十一讲全部课例践行（c01-c06 等 30+ 课例均"先明占类再定侧重"）；"首先明占类/其次定侧重"句式贯穿全书
- **V2 预测力**: 新问题"问一个从未占过的事项（如设备故障能否修好）如何入断" → 可推导：先归占类→选侧重→取类神/课体→过空亡变质闸
- **V3 独特性**: 壬学独有操作流，非常识；"以简驭繁、主线只有两条"反直觉
- **反例约束**: ce13（同一课多解）、ce14（可证伪性）、ce12（幸存者偏差）

### S02 类神 / 课体双侧重选择

- **V2 预测力**: 新问题"占能否买到二手房" → 建立房产类象清单→扫课传→查空亡旺衰与得助，输出信心度
- **V3 独特性**: "九大类象系统（除课体八类）取象""位定吉凶"是壬学特有体系

### S03 空亡与变质辨析

### S04 类象之动·"有路"理论
