# 孕产判断（六甲 / 生男生女 / 产期）

## R — 原文 (Reading)

> 时为日之胎神，必为六甲占也。余曰：然，男乎？抑女也？曰：干上卯属震，长男之象。又是幕贵，三传四课纯阴极阳，生贵儿必矣。且支加干，仰首见子，生必顺利。但四课不备，未能足月。生于何时？曰：六月生。果一一如所断。
>
> — 陈公献 断, 北海闲人 讲理, 问答录四《占生产六甲》（癸卯日戊午时）

---

## I — 方法论骨架 (Interpretation)

面对的问题是"是否为胎产占、生男生女、顺产难产、足月早产、产期何时"。五步逻辑按序执行：

1. **来意断六甲——多象共振（p21/p23/f37）**: 占时为日干胎神（《毕法》"胎财生气妻怀孕"）+ 干上见子孙爻 + 支上见巳火太乙（胎产类神）+ 干支皆乘子孙。四象中多象共振方可断"六甲/胎产占"，勿凭单象；干支定位"干上主所思、支上主所行"辅助还原所问（z03 先由戴羲断来意、陈公献续断）。
2. **生男生女——多法并观（f38/p24/p25/f39/p26）**: 三套独立判据互证，合一乃断：
   - 课体法：元首男 / 重审女 / 纯阳反阴女 / 纯阴反阳男 / 阳不备女 / 阴不备男；
   - 干上神比和法：干上神与日干比则男、不比则女；干上卯属震=长男、干上酉属兑=少女；
   - 金口诀法（《大六壬金口诀》"欲占孕育课中求，太乙常加本命头。阳将为男阴是女，更看生克定因由"）：巳火加女方本命属相宫，顺布至占时，上神阳=男、阴=女，作者称此法极验。
   - 判读纪律：多法同向方可定断；陈公献重课体与干上神二法，金口诀法独立成第二套判据。
3. **占产支干定位（f40/p27）**: 支=产母、干=胎儿；干支互临而生合=母子相恋主难产；支加干上=产妇低头见子=已生下来之象，主生产顺利。
4. **不备主气数弱（p28）**: 不备课统一含义为气数不足——占产则不足月早产（占病则体虚力弱）。同一课体按事类展开象义。
5. **应期——产期（f19/p29/f20/p31，细化转 yingqi-panduan）**: 太岁发用应一年内、月建一月内、日辰当日、时发用当时；前三辰法则——发用之神在岁/月/日/时之前三辰范围内，应在发用神当令之时（z03 未土发用、在月建巳前二辰，断六月生）。

产出：占类确认（六甲）+ 生男/生女 + 顺/难产 + 足月/不足月 + 产期（量级→月份→日时）。

## A1 — 书中的应用 (Past Application)

### 案例: 戴羲占六甲——生男、生必顺利但不足月、六月生（z03, 问答录四）
- **问题**: 徽州戴羲访陈公献占课（戴羲先断来意，陈公献续断）：问生产、生男生女、产期、是否足月。甲子四月癸卯日戊午时，蒿矢、不备；三传未（朱雀）→酉（勾）→亥（空）；干上卯，支上巳（太乙）；四课不备；未土发用、在月建巳前二辰。
- **陈公献/戴羲断（双层第一层）**: 断来意——时午为日干癸之胎神（午是胎财但非生气），干上见子孙爻、支上巳太乙为胎产类神又为支之子孙，干支皆乘子孙，各面结合断为六甲占。断男女——课体纯阴反阳生男 + 干上卯与日干癸比 + 卯属震为长子，三法合断生男；又曰"贵儿"（干上卯为震长子又为幕贵、阴神见财德贵马）。断难易——支加干上=产妇低头见子=已生下之象，生必顺利。断足月——四课不备，未能足月。断产期——未土发用在月建巳前二辰（前三辰范围内），六月生。
- **北海闲人讲理（双层第二层）**: ①孕占与产占是两种占法，此课先断孕否、再断产之详情；②生男生女多法并观，陈公献重课体与干上神二法，金口诀法另记一法互参；③"不备"一象随事类转义（占病主虚、占产主早产）；④应期用前三辰法则与岁/月/日/时发用框架，不必另寻地盘。
- **结论**: 生男、贵儿；生必顺利但不足月；六月生。
- **结果**: 果一一如所断；细看子冲胎神、子上见寅，故子日寅时生（反馈进一步落到日时）。
- **附会批判**: "生贵儿必矣"而阴神财德贵马空亡——北海闲人评此断"有点圆滑"，贵也不久。示范读古断须核对课盘、警惕定性附会辞（与 p46 勘误纪律同型）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **断来意（若未明言所问）**
   - 查占时是否为日干胎神；查干上是否见子孙爻；查支上是否见巳火太乙（胎产类神）；查干支是否皆乘子孙。
   - 完成标准: 输出四象命中情况；≥3 象命中则定"六甲/胎产占"，否则转 sanbu-duanke 断来意通用法。
   - 注意: 若占时只是胎财而非生气，仍可断孕（z03 午为胎财但非生气），勿以单象否决。

2. **多法并观定生男生女**
   - 课体法（元首男/重审女/纯阳反阴女/纯阴反阳男/阳不备女/阴不备男）；干上神比和法（与干比则男、不比则女；卯震男/酉兑女）；金口诀法（巳加女方本命顺至占时看上神阴阳，需女方属相）。
   - 完成标准: ≥2 法指向同一结论方可定断；若互斥，输出"存疑"并列出各法依据与强弱（课体法、干上神法权重更高）。

3. **定产之难易与足月**
   - 支=产母、干=胎儿；干支互临而生合=难产；支加干上=已见孩面=顺利；不备课=气数弱=不足月早产。
   - 完成标准: 输出顺/难产判定与足月/不足月判定，各带课盘依据（干支临处 + 课体是否不备）。

4. **定产期**
   - 岁/月/日/时发用框架定量级（太岁→年、月建→月、日辰→日、时→时）；前三辰法则定具体月份（发用在岁/月/日/时前三辰→应在发用神当令之时）；如需细化到日时转 yingqi-panduan。
   - 完成标准: 输出产期量级与具体月份；标注所需女方本命/行年数据是否齐备（缺失时如实声明，勿补造）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯恋爱关系成否/婚期/第三者——归 lianai-panduan；纯终身运势/姻缘格局——归 zhongshen-nianyun。
- 缺乏女方本命/行年数据时：金口诀法（巳加本命）无法起算；产期细化与行年较量类判断不可强行给出。
- 把古典孕产断法当作现代医学依据使用——生男生女、产期、难易诸断无医学基础，仅供文化参考，产检为准。

### 作者在书中警告的失败模式

- **"生贵儿"附会（z03/北海闲人自评）**: 干上卯为幕贵、阴神又见财德贵马故曰贵儿，然财德贵马空亡，贵也不久——北海闲人评此断"有点圆滑"。定性附会辞（贵儿/贵格）须核对课盘支撑，空亡在象则断语打折。
- **多法互斥**: 生男生女三法（课体/干上神/金口诀）互证是纪律；若互斥不可强合，宁可存疑。
- **"不备"误读**: 不备占产=不足月早产，但若课中得支加干上，顺与不足月并存（z03 生必顺利且未足月）——两断分属不同维度，不可互相抵消。

### 作者的盲点 / 时代局限

- **无统计背书（ce12 同型）**: 金口诀法作者称"极验"，z03 结果"果一一如所断"，均为叙事性反馈，无统计、无盲测、无失败样本，真实命中率未知。
- **事后附会风险（BOOK_OVERVIEW 最强反对意见）**: 任何断语几乎都能事后找齐干支/天将/神煞/阴神任取其一作解释路径；读古断须按 p46 纪律回盘核对。
- **时代局限**: 古典产占以"六甲""足月早产"为语汇，无现代产检概念；性别、产期判断在现代语境仅作文化参考。

### 容易混淆的邻近方法论

- 与 **lianai-panduan（婚恋生育）**: lianai 管"恋爱关系/婚期/有无别人"，本 skill 管"已孕之后的生男女/产期/难易"；问"能不能在一起"用 lianai，问"胎占详情"用本 skill。
- 与 **zhongshen-nianyun（终身运势）**: 终身/年运中的生育维度是整体运势的一部分，单问孕产详情用本 skill。
- 与 **sanbu-duanke（三步断课法）**: 来意正时法是通用框架，本 skill 只用其"胎神断六甲"实例，勿混为全部来意占。
- 与 **yingqi-panduan（应期判断）**: 产期=孕产专用实例（岁/月/日/时发用 + 前三辰），一般应期另有病死/征召等事类，勿串用。
