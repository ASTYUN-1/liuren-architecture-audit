# 类神 / 课体双侧重选择

## R — 原文 (Reading)

> 判断的侧重点则只有两个：1、类神。2、课体。能找的类神的看类神，找不到类神的就看课体大势，这是进行壬课判断的不二法门。……类神现于课传而不空陷，不变质，则其事必成。……壬占最重"位"。同一类象在四课上和三传上，并不是一回事。课上的白虎，只是显象，而不主吉凶。然白虎又发用，则又主吉凶。
>
> — 北海闲人，《北海的六壬特训班讲义》第一讲、第四讲
>
> **《大六壬指南》问答录（扩展）**
>
> "在这一课的分析中，课体大势的作用是远远大于类神的作用的，这一点值得我们思考。"
> "占仕途如何，一看课体，二看类神。课体反映了人当前的状况，尤其是四课。"
>
> — 北海闲人, 问答录八 / 问答录十

## I — 方法论骨架 (Interpretation)

- **面对的问题**：占类已明（"能否出现/能否成"类），该用哪条主线判断？
- **怎么判断**：
  1. **先尝试取类神**：从九大类象系统（除课体外的八类）为该事物找"干支神将组合"之象。示例：房产=亥楼/午厅堂/卯房宿/丑勾田产；孕=胎神；证件=戌印绶乘六合（舟车盖章）；病=白虎官鬼；职位=禄/父母/长生。**类神现课传+不空陷+不变质 ⇒ 事必成。**
  2. **取不到就走课体**：占者没给具体对象（如"会去哪里"）、或所占是方向/大势类问题时，无类神可取——读课体大势（九宗门→毕法→干支关系）。
  3. **辨"位"再论吉凶**：同一类象在四课（干支、上神）上只是显象、不主吉凶；发用/入三传才真正主事。先标"位"，再谈吉凶。
- **产出**：一条明确的"主线选择 + 判据清单"，附置信度；类神与课体两线互证时置信度最高。

### 课体大势优先（《大六壬指南》问答录扩展）

- **课体大势 > 类神**：当课体（顾祖、干支皆败、龙化为蛇、勾陈投朱雀）与类神吉象冲突时，以课体大势为主、类神让位——"课体大势的作用远远大于类神的作用"。特殊课体可覆盖类神吉象：顾祖例中龙神作官星加干发用且得末传生助，看似很利于官，但遇特殊课体这个象就要舍弃（问答录八）。
- **占仕途/科举/占病同构**：一看课体、二看类神；课体反映当前状况、尤重四课——占仕途（问答录十）、科举（问答录二）、占病（问答录五）三域同构，一律课体先行、类神跟进。
- **先明课象定方向，再找类神附会**：先定"成/败"大方向，再按此目标找类神附着的事物——方向已定时类神只用于充实细节，不是方向来源（问答录七）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占单位分房（c02）
- **问题**: 占分房能否分到。
- **方法论的使用**: 取房屋类象为类神——干上亥为楼阁，类神现于干上=有获得之象；但亥旬空→"不确定"，须结合它象；再辨空亡：亥在酉月旺相，申生亥且申入中传、申与太岁子相合=有势力领导生扶→旺不为空、得生得助不为空。
- **结论**: 楼必得，但返吟反复、暗箱操作、绝上加绝不甚满意。
- **结果**: 亥月末事果应。

### 案例 2: 急占妻是否已孕（c03）
- **问题**: 占是否已孕。
- **方法论的使用**: 取胎神为类神（干上子为丙日之胎神）；虽空亡但为月建→旺不为空必有孕；再查位与变质：胎神之阴神未为月破、穿害胎爻，子又为日鬼乘蛇→胎必有变、破胎即小产。
- **结论**: 有孕，但胎难保（小产）。
- **结果**: 两周后确有孕，占课次日流掉。

### 案例 3: 驾驶证何时发下来（c06）
- **问题**: 占证照是否有、何时下发。
- **方法论的使用**: 证件是具体之物→取类神：干上戌为印绶乘六合=关于舟车的盖章=驾驶证，类神现课传=证已在；兼看课体"下发"象（干支互传、铸印）；戌合入末传=证在别人手中，巳常在中传=递送之人，戌在巳上=有人驮证前来，太常到辰为佩印→辰日到。
- **结论**: 证必有、应辰日到。
- **结果**: 断辰日到（文中未给进一步明言反馈）。

### 案例 4: 占入相+罢官归乡·课体大势优先（问答录八，z07）
- **问题**: 代占少宗伯马康庄能否入相。
- **方法论的使用**: 占官以龙神为用——此课龙神作官星加干发用且得到末传寅生助，似乎很利于官；但遇上特殊的课体（顾祖课主归乡不满仕、干支皆败势倾颓、龙化为蛇由大变小、龙神克下=皇帝不喜欢），这个象就要舍弃。课体大势的作用远远大于类神的作用。
- **结论**: 不但不能入相，且不日归乡。
- **结果**: 果枚卜不就，次年察处归里，后弃世为道。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问"能否得到某物 / 有没有 / 何时到手"类问题，需要先为该物定义类象再扫描课传。
2. 用户问的对象含糊（"去哪家单位""会往哪个方向"）导致取不到类神，需要切换到课体大势。
3. AI 作为分析框架：为具体事物（房产、孕、证照、职位、病愈、物件下落）建立类象清单并走"现课传→不空→不变质"三道检查。
4. 用户问的同一课，出现"类神/课体哪条更准"的疑问时——用本 skill 的两线互证法。

### 语言信号 (用户的话里出现这些就应激活)

- "这套房/这个证/这份工作能不能到手？" "能否得到/能不能成/会不会有/有没有/can I get/will it arrive"
- "占/预测/测测/divination/chart"
- "有没有怀上/证什么时候下来/病能好吗" "怀孕/证件/病愈/会来吗/will it come"
- "这课该看类神还是看课体？" "看什么/从哪断/classify/leishen/keti"

### 与相邻 skill 的区分

- 其余 14 个 skill：`sanbu-duanke`(三步断课法总入口，本 skill 是其"定侧重"环节的下钻)、`kongwang-bianzhi`(空亡与变质辨析，类神确立后的真假闸)、`youlu-lilun`(有路理论，类象引动)、`xiongsha-suduan`(凶煞速断)、`keti-qishi`(课体气势阅读法，本 skill 课体分支的细读)、`shiyun-zonghe`(时运课综合断法)、`cailu-panduan`(财禄判断)、`renji-guanxi`(人际关系判断)、`yingpin-gongzuo`(应聘与工作判断，职位类神=禄父母长生的细读)、`shengzhi-jiaxin`(升职加薪判断)、`lianai-panduan`(恋爱判断)、`yingqi-panduan`(应期判断)、`zhongshen-nianyun`(终身与年运课法)、`jixiong-tiaozhi`(吉凶调制与缩放)。
- 与本 skill 的区分：本 skill 只解决"**选哪条主线 + 类神怎么取**"；`keti-qishi` 解决课体选定后"怎么读大势"；`kongwang-bianzhi` 解决类神取到后"是真是假"。三者的调用顺序是：本 skill →（类神线）`kongwang-bianzhi` /（课体线）`keti-qishi`。

### 课体大势优先 触发场景（《大六壬指南》问答录扩展）

1. **类神吉而课体凶**（顾祖/干支皆败/龙化蛇/勾陈投朱雀）——课体优先、类神让位，不断吉象而按课体大势断。
2. **占仕途/科举/占病**——同构三看：一看课体（尤其四课反映现状）、二看类神，先方向后细节。
3. **占新领域/新占类**——一律课体先行定方向，再找类神附会充实细节。
4. **泛占断紧事**——课体定类（度厄=外来灾、三传递克=众人欺）→干支乘神定象→落点成事（素材绑定，详见 sanbu）。

### 课体大势优先 语言信号

- "这个类神看起来很好/得生助，但课体好像不对"
- "顾祖/干支皆败/龙化为蛇/课体大势/是不是该先看课体"
- "占仕途/科举/占病 应该先看什么"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **取类神**：为该事物建立类象清单（干支/天将/组合），扫描课传命中与否。
   - 完成标准: 输出类象清单 + 每条是否入课传的命中表。
   - 判停条件: 若对象含糊到无法定义类象（如"去哪"），跳步骤 2 走课体线。

2. **读课体大势**：按九宗门→毕法格局→干支关系读整体气势，输出课体走向（留北去南、进退、大势）。
   - 完成标准: 输出 1-3 条课体判据及方向性结论。
   - **扩展子步骤（问答录课体优先判定）**: 先做"特殊课体扫描"——顾祖（归乡/不满仕）、干支皆败（势倾颓）、龙化为蛇（由大变小）、勾陈投朱雀（非细之讼）任一命中则**课体优先**、类神吉象让位（如龙神发用得助仍断不利）；再按"一看课体二看类神"顺序读仕途/科举/占病。
   - 判停条件: 若用户明确给了具体对象且类神命中，可跳过本步骤（类神线优先）。

3. **位次校验并出结论**：对关键象标"位"（四课显象 vs 三传/发用主事），只让主事位的象计入结论；类神与课体两线结论一致时置信度最高。
   - 完成标准: 输出"主线选择 + 判据 + 结论 + 置信度"。
   - 判停条件: 两线结论冲突时，标注"多解"，输出两条线各自结论并说明分歧点，不强行合一。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题属方向/大势类（"经济走向""职业发展方向"）且对象不可取类神——直接走课体线（`keti-qishi`）。
- 类神已确立、只需辨真假（空亡/变质）时——那是 `kongwang-bianzhi` 的工作。
- 用户要精确应期——转到 `yingqi-panduan`。

### 作者在书中警告的失败模式

- ce01（只盯课经忽略毕法）：课体线不只九宗门，《毕法》干支上神结构（解离格/彼此全伤/交车相合）也是课体，漏读即断错。
- ce02（空亡陷阱）：类神现课传≠事必成——空亡使结果变成"不确定"；但空亡≠必不成，要辨旺衰与得助；天空之空不论旺衰一律凶。
- ce03（变质）：类神乘凶将/作闭口/作破碎煞/阴神见鬼则吉转凶——"现课传"只是必要条件。
- ce11（凶课体）：类神吉而课体凶时不可只见类神——天网课难逃、解离格可逃脱（吉凶随占类而变）、干支乘墓主"止"、轩盖课遇空亡变"乘轩落马"。

### 《大六壬指南》问答录扩展失败模式（B 段追加）

- **ce18 顾祖强进定遭不足**：见龙神发用、官星得生助等类神吉象就断官运亨通，忽略顾祖课体"主归乡、不满仕"的大势；或见"龙神克下"仍强行求进——特殊课体下类神吉象要让位，强进必遭不足（问答录八：果枚卜不就，次年察处归里）。
- **ce13 只见一象、忽视多象互证**：只凭单一类神象（虎马发用速成、单个神煞）定论，不引课体大势与多象印证——"物以类聚方以群分"多象共观（问答录十二）。

### 勘误备忘（问答录扩展）

- **课体大势>类神是作者明确主张（问答录八）**：顾祖例作者点明"在这一课的分析中，课体大势的作用是远远大于类神的作用的"——不可因类神吉象而忽略课体大势，这是断课取舍的最高原则（配套 p51/p48）。

### 作者的盲点 / 时代局限

- 类神象意（六合=添人口、天后=女子、勾=田产）被当作普适常量、不随文化/个体变动——这是未论证的信仰前提（ce15）。
- 作者明确承认多课"类神课体皆可"，解释自由度大（ce13）——使用者应自行对多解保持警惕。
- 全书房产/孕/证件等类神案例全部"果应"，存在幸存者偏差（ce12），不能据此估计命中率。

### 容易混淆的邻近方法论

- 与 `kongwang-bianzhi`：本 skill 管"取类神 + 现课传"；后者管"类神真假校验"。先取后验，勿跳过。
- 与 `keti-qishi`：本 skill 的课体分支只做"选主线"，`keti-qishi` 才是课体阅读法本体。
- 与 `yingpin-gongzuo`：应聘的职位类神（禄/父母/长生）细节规则已归 `yingpin-gongzuo`，本 skill 只给通用取类神框架。
