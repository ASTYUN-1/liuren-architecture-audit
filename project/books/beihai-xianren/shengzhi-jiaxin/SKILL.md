# 升职与加薪判断（进达象 / 增益象）

## R — 原文 (Reading)

> 升要有进达之象，加要有增益之象。何谓进达之象？旺气、吉神占据课传之要位。旺气者，月建、进气；吉神者，龙常贵合、仪神、月将、长生、德禄等；要位者，干上、支上、三传、年命上。……何谓增益之象？生气，即父母爻现于课传，必有生计宽裕、收入增加之象。……这些类象旺相不空，则加薪是必然的。
>
> — 北海闲人, 第九讲《升职与加薪》

> 一个人要当官，有这么几个方面必须具备：1），是贵人，主上头有人支持；2），是龙神，这是官类神；
> 3），是禄神，主薪水，也就代表工作；4），是财神，这是官之源；5），是马星，当官的要坐车，
> 没马是不行的。……又财官禄马俱入墓绝之乡，急流勇退为佳，否则必有意外之虞。
>
> — 北海闲人, 问答录九《章奏》（官五要素审计）

> 三传午辰寅，这是顾祖课，主回家；天将初龙末蛇，是龙化为蛇，由大变小；龙是皇帝，克下是
> 皇帝不喜欢。这一切都说明官运不利。凡在朝为官占得顾祖，多不满仕。
>
> — 北海闲人, 问答录八《占入相》（仕途课格）

> 传将逆行，凡事有退无进，占官当退位，占行人当归来，占出行不可出，强进则多阴滞凶险。
>
> — 北海闲人, 问答录续一《田大冢宰占》（仕途课格）

> 此课幕贵申临干但落空，因此就说非科甲中人……末为归结，代表最后的地位，龙为文官之位，
> 月建为诸侯之象，官位由小至大，最后能统治一方。
>
> — 北海闲人, 问答录十五《断何官所占》（出身判定）

## I — 方法论骨架 (Interpretation)

面对的问题是"已任职者，职位是否上升、收入是否增加"。第一步先分目标——**升与加是两种不同的象，判据不可混用**：

1. **升职 = 进达之象**: 旺气（月建、进气）× 吉神（龙常贵合、仪神、月将、长生、德禄）× 要位（干上、支上、三传、年命上）三维交集。三维命中 ⇒ 升迁倾向；缺位 ⇒ 难升。龙常并见、德入天门、龙德、时泰等课体对普通人同用。
2. **加薪 = 增益之象**: 生气（父母爻现于课传，主生计宽裕、收入增加）+ 金钱类象（申、酉、虎、阴属金；贵人、太常、青龙为钱财；天后≈福利分红；六合本有增益）旺相不空 ⇒ 加薪必然。注意财爻克父母爻，现课传一般不作吉论。
3. **快速否定（p32）**: 发用空亡 + 处时令衰气 ⇒ 断不果——"空亡+衰气"双杀，任何吉象难以成事。
4. **墓象（p17）**: 干支上皆乘墓神、鬼墓发用 ⇒ 既不能升也不能迁、工作繁剧（墓主阻滞），并入课体阅读法。

产出：升/不升、加/不加的分层结论 + 时间线索 + 风险修正（小人/勾陈/凶将并存时的质感，可调 s15 四象限）。

### 官五要素审计（问答录九/续一，阶段2合并）

当官者必具五要素，逐一查其旺衰空墓绝：
- **贵**＝上头有人支持；**龙**＝官类神（官本身）；**禄**＝薪水即职位（有位才有禄、无位则无禄）；**财**＝官之源；**马**＝当官的行动/仪仗。
- 任一入墓、绝、空则该方面不保：禄空墓＝丢位；马入墓＝不能行动、无法行使权力；太阳入山（加夜方）＝光辉不再、失势。
- 财官禄马俱入墓绝之乡＝急流勇退为佳，恋栈强求必有意外之虞（z08 张维枢、z15 田大冢宰）。
- 与进达/增益象承接：进达象答"升不升"，官五要素审计答"位子稳不稳、还值不值得守、何时当退"。

### 仕途课格（问答录八/十/十二/续一，阶段2合并）

仕途课以课体大势优先（课体＞类神），遇下列课格直接定势：
- **铸印乘轩定迁转**：旺气发用断升迁（z11）。
- **顾祖课归乡不满仕**：三传回归本位主回家，在朝官多不满仕（z07）。
- **龙化为蛇由大变小**：初传龙末传蛇，龙神克下＝上不喜（z07）。
- **干支坐墓甘招晦**：身宅坐墓必受人欺绐、终难解脱（z15）。
- **干支乘墓皆昏迷**：干支上神皆墓，同僚不睦、有人攻击（z09）。
- **干支皆败势倾颓**：四课干支上皆败气，已走下坡路（z07）。
- **传将逆行有退无进**：天将+三传双逆，占官当退位、行人当归、出行不可出，强进多阴滞凶险（z15）。
- **三传递克主参劾**：无论递克方向、不必克到日干，在朝官均主被参劾（z15）。
- **勾陈投朱雀非细之讼**：辰加午必被查办（z07）。
- **贵履天罗**：官星贵人加辰受克坐墓＝贵人有罪、丢官入狱（z15）。

### 出身判定（问答录十五，阶段2合并）

断官阶来源与终局轨迹：
- **幕贵坐空＝非科甲中人**（幕贵是科甲专属类神；坐空即不由科甲，但不妨恩荫/纳粟入仕）。
- **发用长生父母爻＋末传皇恩＝恩荫之官**（沾父祖之光，区别于科甲、纳粟）。
- **卯太冲主林木舟车**：三传木局、日禄又为卯木＝林木舟车之官（行业/职能类神取象，z14）。
- **末传为归结**：末传龙神乘月建（作月建不作墓论）＝由小至大、最终统治一方（z14）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占单位里近况（医院，升职+加薪双象齐断）（c28）
- **问题**: 占单位里近况如何（实际问升迁与待遇前景）。
- **方法论的使用**: 进达象+增益象双查：中传月建太常=荣升有望；生气、龙禄并见=不但升职而且待遇优厚——升、加双命中。蒿矢逢鬼提示有小人女子作祟，但干上蛇墓=甘居低位反而避开派系纷争（低调避祸的缓冲）。
- **结论**: 翻身的日子不远——升职且待遇优厚。
- **结果**: 月余单位内贪污事发、多人被双规；此人因清白反得新院长赏识，升科室主任，油水颇多。

### 案例 2: 占能否在公司中升职（c29）
- **问题**: 占能否在公司中升职。
- **方法论的使用**: 进达之象的否定式校验。午神发用空亡、又处时令之衰气——命中"空亡+衰气"双重否定规则，任何吉象难以成事。
- **结论**: 断不果。
- **结果**: 后果未升成。

### 案例 3: 林子成占平生养息（生气日禄例，古课）（c30）
- **问题**: 普通百姓占平生福泽（含财运、运势顺遂），重点理解"生气""日禄"的增益作用。
- **方法论的使用**: 干上勾陈作日鬼=官司缠身（当前状态）；申为传送空亡克日=不可为鹅/医/碓/道士，弃碓磨；支上卯在长生上=驴骡、竹木、术士皆前程；乙日木局全旺在卯、生于亥=取全盛之地营之；三传初墓（蛰于父荫）→中传长生→末传旺禄，出申之绝、未之墓、走向亥之生、卯之旺禄=先凶后吉。一课双时层：三传=一辈子，干上=当前。
- **结论**: 弃碓磨改养孳畜、竹木，再兴贩，先折磨后兴隆。
- **结果**: 七年生五驴、竹木大盛，又从之兴贩数年大发。

### 案例 4: 占入相 + 顾祖不满仕（z07，问答录八）
- **问题**: 代占少宗伯马康庄能否入相（枚卜）。
- **方法论的使用**: 官星青龙发用且得末传生助，看似利官——但顾祖课主归乡、四课干支皆败势倾颓、天将初龙末蛇=龙化为蛇由大变小、龙神克下=上不喜、辰加午勾陈投朱雀主非细之讼——课体大势远大于类神，此吉象须舍弃。初传官星空亡、末传助鬼有人陷害，多亏鬼空不致被抓。
- **结论**: 不但不能入相，且不日归乡。
- **结果**: 果枚卜不就，次年察处归里，后弃人间事从赤松子游。

### 案例 5: 占章奏上书 + 官五要素逐查（z08，问答录九）
- **问题**: 张少司空维枢索占（未明所问，正时断章奏占），问吉凶与上书旨意。
- **方法论的使用**: 官五要素逐一查——贵人乘旬空、龙神乘未临子克下且落空、禄神午火加亥临绝地、财星亥水加墓入墓、马星巳火加戌入墓——财官禄马俱入墓绝之乡，断急流勇退为佳。朱雀乘天喜、阴神见驿马旬丁生日=有救解，但救解是局部的，只断"好旨归里"（免处分退职），不改总凶。
- **结论**: 主降罚削权之凶；上书得好旨归里。
- **结果**: 后唯冠带闲住，回家未久仙游。

### 案例 6: 占显宦 + 太阳入山（z09，问答录十）
- **问题**: 迟王两父师偕陈公献入觐索占，断占者身份与仕途长短。
- **方法论的使用**: 发用官贵日德、贵人居岁君日禄旺位=显宦；但干支乘墓皆昏迷（阴神太常刑克干支）、禄神午火落空、马星落空、太阳加戌上最怕加夜方=光辉不再——断不能久任。应期以来年太岁乘朱雀冲龙神根基断三月因言请归；一德解百祸只能减祸（回家寿也不久）。
- **结论**: 所占必是显宦；不能久任；次年三月因言请归。
- **结果**: 果次年三月因言请归，后知为大冢宰王射斗。

### 案例 7: 占功名 + 铸印速迁速败（z11，问答录十二）
- **问题**: 吏科给事中宋太斗占功名，断升迁与久暂。
- **方法论的使用**: 铸印乘轩定应迁转、月建虎马发用其力更雄——断月内定转长垣；但贵人空亡且临害地=贵气不久、末传玄武作鬼=平地起风波、发用落空=事或不成或成而不久——断居官难以久任。速度（速迁）与久暂（不长久）两维分断。
- **结论**: 月内定转长垣；居官难以久任。
- **结果**: 果随转吏长垣，后因提武场事降大行。

### 案例 8: 占官 + 贵履天罗参劾（z15，问答录续一）
- **问题**: 代占在朝官田大冢宰，断仕途凶险、参劾、子祸。
- **方法论的使用**: 三传递克（无论方向、不必克到干）=主被参劾；官星贵人亥加辰受克+坐墓=贵履天罗、贵人有罪；日禄巳加戌既墓且空=职位不保；马入墓=无法行使权力；干支坐墓甘招晦=必受人欺绐；传将逆行=有退无进，当请告而退，否则必挂弹章。幸末传寅作太岁长生，只丢官而无大咎。
- **结论**: 主台省参劾，应请告而退；丢官入狱之征。
- **结果**: 果被劾，伊子仍被逮下狱。

### 与相邻 skill 的区分

- 与 `s01 三步断课法` 的区别: 本 skill 是三步法在"升职加薪"占类的实例化，先明占类（升 or 加）再定判据。
- 与 `s02 类神/课体双侧重选择` 的区别: 本 skill 以课体（进达/增益两象）为主、类神（官星/父母爻）为辅。
- 与 `s03 空亡与变质辨析` 的区别: p32 的"发用空亡+衰气断不果"是 s03 判据在升迁课上的专项应用。
- 与 `s04 类象之动·有路理论` 的区别: 升迁行动之象看发用、行动原因看阴神（官星太常=升迁、勾陈=受役），本 skill 借阴神链判断动因。
- 与 `s05 凶煞速断` 的区别: 勾陈克干/克行年=升迁受阻、麻烦缠身；蒿矢逢鬼=小人女子作祟（c28 的干扰项）。
- 与 `s06 课体气势阅读法` 的区别: 干支乘墓/鬼墓发用=不能升迁（p17 墓象）；轩盖课遇空亡=乘轩落马丢官罢职（ce11），课体凶格在此拦断。
- 与 `s07 时运课综合断法` 的区别: 时运课官运维（贵龙常作父母长生=升迁）与 s11 共用判据；问一年综合运势用 s07，专项问升加用本 skill。
- 与 `s08 财禄判断` 的区别: 加薪涉及收入，但 s08 管"收入/纯财"的总量质量，s11 管"加不加"的变化判断。
- 与 `s09 人际关系判断` 的区别: 单位派系、上司态度是升迁背景（c28 涉派系纷争），但落点是"升不升"仍归本 skill。
- 与 `s10 应聘与工作判断` 的区别: 未入职前用 s10（职位能否到手）；已入职后的升加用本 skill。
- 与 `s12 恋爱判断` 的区别: 无涉。
- 与 `s13 应期判断` 的区别: 升迁粗略应期（如中传月建提示月内）在本 skill，精确定日调用 s13。
- 与 `s14 终身与年运课法` 的区别: c30 兼为终身课素材；问"平生福泽"走 s14，问"生气日禄的增益作用"回看本 skill。
- 与 `s15 吉凶调制与缩放` 的区别: 进达/增益象与凶将并见时用四象限调制成败质感（升了但得罪人、加薪但加量受气）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分判目标：升 or 加**
   - 确认问题是问"升"（职位/地位上升）、"加"（收入增加）还是双问。
   - 完成标准: 明确输出目标分类（升/加/双），据此选择进达象或增益象判据，绝不混用。

2. **专项扫描**
   - 升 → 扫旺气（月建/进气）× 吉神（龙常贵合/月将/长生/德禄）× 要位（干上/支上/三传/年命上）三维交集；加 → 扫生气（父母爻现课传）+ 金钱类象（申酉虎阴、贵常龙、天后、六合）旺相不空，注意财爻克父母爻不作吉论。
   - 完成标准: 输出各判据命中清单，每个命中注明位置与旺衰；扫凶煞（勾陈克干克行年、蒿矢逢鬼、朱雀乘丁）作修正项。
   - 判停条件: 若发用空亡+处时令衰气 ⇒ 直接输出"断不果"，跳到步骤 3；若干支乘墓/鬼墓发用 ⇒ 输出"不升不迁、工作繁剧"，跳到步骤 3。
   - 官五要素审计＋仕途课格扫描（阶段2扩展）: 在进达/增益象之后追加——①官五要素（贵/龙/禄/财/马）逐一查旺衰空墓绝：禄空墓=丢位、马入墓=无权行使、太阳加夜方=失势、财官禄马俱入墓绝=急流勇退；②仕途课格扫描：铸印乘轩=迁转、顾祖=归乡不满仕、龙化为蛇=由大变小、干支坐墓=受欺、干支乘墓=同僚不睦、干支皆败=势倾颓、传将逆行=有退无进、三传递克=被参劾、勾陈投朱雀=非细之讼、贵履天罗=贵人有罪；③出身判定：幕贵坐空=非科甲、长生父母+末传皇恩=恩荫、卯太冲=林木舟车、末传龙乘月建=由小至大。
   - 完成标准（阶段2）: 输出官五要素风险清单 + 仕途课格命中清单，并入结论；任一凶格命中须修正"升/加"乐观结论。

3. **输出结论与质感**
   - 分层输出：升/不升、加/不加、时间线索（月将/太岁/中传提示）、渠道风险（小人/勾陈/取巧）。
   - 用 s15 四象限给"吉凶质感"（吉爻×凶将=吉中有忧，如升职但被嫉恨；凶爻×吉将=灾缓，如加薪慢但终究有）。
   - 完成标准: 结论含目标分类、判据命中清单、结论、时间线索、风险修正五项；标注置信度与存疑点（ce12–ce15）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 未入职的求职问题——归 `yingpin-gongzuo`。
- 问收入总量/财运（薪水之外的钱、投资、外快）——归财禄判断（s08）。
- 综合运势中顺带问升迁——归时运课综合断法（s07）；专项问"升不升/加不加"才用本 skill。

### 作者在书中警告的失败模式

- **ce11 凶课体速断陷阱（乘轩落马）**: 占升迁得轩盖课（三传午卯子）本是高盖乘轩、爵禄显赫的吉课；若卯或午空亡则为乘轩落马、变三交课，且三神临死地，主因酒色、阴私、贪污之事被告发、丢官罢职——吉课体遇空亡变质转凶。
- **ce02 空亡陷阱**: 进达/增益类神空亡是"不确定"而非必凶，需辨旺衰与是否得住；但天空之空不论旺衰一律以凶论。
- **ce03 变质**: 吉象类神乘凶将/作闭口/破碎/阴神见鬼则吉转凶——如日禄乘玄武作闭口则禄难到手（占工作）、日德作鬼被勾陈夹带则德变"没德"。
- **ce12–ce15 公共方法学边界**: 全部案例"果应"无失败样本（ce12）；同一课可多解、结论对侧重选择敏感（ce13）；象意组合可事后自圆其说、可证伪性未解决（ce14）；干支五行→人事映射是未论证前提（ce15）。

### 问答录扩展反例（《大六壬指南》问答录 阶段2合并）

- **ce08 中末空先利后不利**: 初传吉≠全事吉——中末空亡则先利后不利、有始无终，升官亦不长久（z01 省试先利后不利；z11 发用落空成而不久）。
- **ce10 救解局部**: 有救解（天喜/阴神驿马生日）只降级不改总凶——z08 断"好旨归里"非极刑，但无禄课与财官禄马入墓绝的总凶不变，不可见救解即改吉断。
- **ce14 干支坐墓受欺**: 干支（含寄宫）坐地盘墓库，误以为只是"晦滞慢一点"而忽略"必受人欺绐"的被动受害结局（z15 丢官入狱之征）。
- **ce15 传将逆行强进**: 天将+三传双逆=有退无进，占官当退位；强进则多阴滞凶险（z15 田大冢宰请告而退）。
- **ce18 顾祖强进**: 在朝官占得顾祖多不满仕——龙神发用得助的吉象要让位于课体大势，强进必遭不足（z07 枚卜不就）。
- **ce19 虎马暴败**: 虎马发用速成但暴成暴败；发用落空则事或不成或成而不久——速度与久暂两维须分断（z11 速迁速败）。
- **ce20 无禄无路**: 四上克下无禄即无路、大凶（《曾门》"室空无人，臣子受殃"）；财官禄马俱入墓绝之乡应急流勇退，恋栈强求必有意外之虞（z08/z13）。
- **ce21 八专专横**: 八专课主专横、不分青红皂白——占上书/论理/对上争讼不能指望公理辩解（z08"拿他开刀"）。
- **ce22 太阳夜方**: 太阳最怕加夜方（酉戌亥子丑）——光辉不再则贵气全失必丢官（z09 太阳入山）。
- **ce24 涉害取用之争**: 涉害课陈公献以孟仲季上神取用（不论涉害深浅），古法以克多者为用——读《指南》课例须先辨取用法，否则课盘对不上（z02）。

### 勘误备忘（问答录 阶段2合并）

- **天马→驿马（z08）**: 原书"天马"实为驿马；且此课从戌为地盘论巳火则不入墓——神煞之名与所临地盘须核对，不可照录原书。
- **日寄宫空更甚于别宫之空（z13/z14）**: "日寄宫空不为空"纯属无稽——日上之神（幕贵/官星/禄马）落空即对应之事无着落，日空必须当空处理（幕贵坐空断非科甲）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: 升职加薪案例（c28/c29/c30）全部应验或应验于叙事，无对照样本。
- **解释自由度（ce13）**: 升职课"以类神为侧重也可、以课体为侧重也可"，进达象缺位时补救解释空间大。
- **可证伪性（ce14）**: "生气日禄"的增益效果（c30）是断后立论、断后应验的叙事，缺乏预注册检验。
- **时代局限**: 案例多为事业单位/传统单位语境（双规、派系、任命制），现代市场职场（裁员、猎头、远程办公）语境需转化。

### 容易混淆的邻近方法论

- 与 **财禄判断（s08）**: s08 判"收入多少/好不好"，s11 判"加不加/升不升"——总量 vs 变化。
- 与 **应聘与工作（s10）**: 以入职为分界。
- 与 **时运综合（s07）**: 综合运势五维 vs 单问升加专项。
