- id: f01
  title: 三步断课法
  type: framework
  source_chapter: 第一讲
  source_quote: |
    "最简捷的断课方法，应该是'三步走'：明占类，定侧重，看显象。"
  summary: |
    全书判断的总入口流程，共三步：①明占类——先明确所占之事追求的结果类型（见 f02）；
    ②定侧重——依据占类与课传特征，从"类神 / 课体"两条主线中选一条作为断课主线；
    ③看显象——对选定主线的象做真假辨析（空陷、变质、乘凶将等），排除假象后下最终结论。
    对 AI：这是可复用的决策流水线骨架——先做结果导向分类，再选分析主线，最后做真假校验，
    每步都有明确的产出物与进入下一步的条件，任何一类占问都先套此框架再细化。
  tags: [divination, decision-flow, core]

- id: f02
  title: 占类三分法（结果导向分类）
  type: framework
  source_chapter: 第一讲
  source_quote: |
    "大六壬课占断追求的结果，无外乎如下三种：1、某事能否成，如：能否升职，会否受伤。
    2、某人事物能否出现。3、某人事物会向哪个方向发展。"
  summary: |
    三步法第一步"明占类"的判定结构：任何占问都先归入三类结果之一——
    ①某事能否成（成败二元，如升职、伤病）；②某人事物能否出现（存现问题，如买房、得贵人）；
    ③某人事物向何方发展（方向/趋势问题，如终生运势、经济走向）。
    结果类型直接决定后续侧重：能成/能否出现类适合以类神为主线看"存现"，
    向何方发展类适合以课体为主线看阴阳盈虚、升降晦明。
    对 AI：这是一个 if-then 路由表——先对用户问题做结果分类，分类输出作为选择后续分析主线的前置条件，
    避免不问结果类型就直接套用类神取法。
  tags: [divination, decision-flow, core]

- id: f03
  title: 类神 / 课体双侧重选择法
  type: framework
  source_chapter: 第一讲
  source_quote: |
    "判断的侧重点则只有两个：1、类神……2、课体……能找的类神的看类神，找不到类神的就看课体大势，
    这是进行壬课判断的不二法门。"
  summary: |
    全书唯一的断课主线选择规则：侧重点只有两类。①类神主线——能取到代表某人某物某象的干支神将时，
    以它为准，类神现于课传又得吉气旺气则事可成；②课体主线——取不到类神（或所占是方向/大势类问题）时，
    以课传整体结构为准，某课体格局出现即代表事成。同一个课常可双侧重并行互证（如肇事车逃逸一案，
    类神与课体都能断）。对 AI：这是主线选择的分叉判断——先尝试提取类神，成功则走类神分支并做存现校验，
    失败则切到课体分支读整体气势；两分支结果一致时置信度最高。
  tags: [divination, decision-flow, core]

- id: f04
  title: 入课传为重、不入课传为轻（信息权重法则）
  type: framework
  source_chapter: 第一讲
  source_quote: |
    "一般地，占课以入课传为重，而不入课传为轻。若课传上类神的象明晰，则依类神断；
    课体的象明晰，则依课体断。"
  summary: |
    多信号冲突时的取舍原则：出现在课传中的象重于未入课传的象，这是判断信息加权的基础规则。
    依序判定——课传上类神象明晰则依类神断，课体象明晰则依课体断，两者都明晰再综合，都不明晰则取课体大势。
    对 AI：这是特征加权与消解优先级规则——输入的多条信号先按"是否入课传"分层，
    课传内信号优先采信；同层冲突时按"类神明晰 > 课体明晰"的优先级裁决。
  tags: [divination, reasoning, core]

- id: f05
  title: 空亡辨法（旺衰 + 得助两重鉴别）
  type: framework
  source_chapter: 第一讲
  source_quote: |
    "空亡的辨别，一个方面，要看其旺衰；另一方面，又看是否得住。旺不为空，得生得助不为空，
    这是看空亡的基本原则。"
  summary: |
    类神现于课传却不空陷是事成的前提，因此空亡是看显象的第一道闸门。辨空亡有两重检查：
    ①看旺衰——旺相（如乘月建、在旺地）则"旺不为空"；②看得住——得生、得助、有路可通则"得生得助不为空"。
    真正空亡的类神不代表凶，而是"不确定"，必须结合其它象综合判断。
    对 AI：这是真假校验流程的第一步——命中空亡时把结论从"成"降级为"待定/需旁证"，
    再检查旺衰与得助两个修正因子决定是否解除降级，形成一个明确的二段校验函数。
  tags: [divination, reasoning, false-check, core]

    对 AI：这是第二步反查校验——列出类神后逐项检查乘将、空亡、破碎煞、闭口、丁神、落墓、阴神六亲，
    任一命中即否定或降级吉断，输出"变质报告"作为结论依据。

- id: f07
  title: "有路"理论（类象之动）
  type: framework
  source_chapter: 第三讲
  source_quote: |
    "何为有路？有路就是被引动了，由于变成了'动爻'，它的力量就强，其显象就明确。……
    凡合（三合、六合、遁干五合）、刑、冲、破、害都为有路，而类象与其天盘、落宫之间，也为有路。"
  summary: |
    静态类象不被引动时意义模糊；一旦"有路"被引动，就成为突出的判断标志，力量强、显象明确。
    有路共六种引动方式：三合、六合、遁干五合、刑、冲、破、害，另加类象与其天盘、落宫之间的关系。
    看类象分直观看法（有啥象意断啥）与曲折看法（经有路引发的复合发动象），曲折看法是壬占入高段的必由之路。
    对 AI：这是动象检测引擎——对候选类神扫描六种引动关系，被引动者权重提升并优先采信，
    未被引动的象标注为"静态/弱信号"，作为判断深入与排序的依据。

- id: f08
  title: 凶煞优先断法（快速否定式过滤）
  type: framework
  source_chapter: 第四讲
  source_quote: |
    "在断课之时，我们可以先找到一个'凶'的充分理由，则可确定人有灾病，而事不成功。
    这虽然是一种'偷懒'的法子，却是一种极有效的法子，盖非吉即凶，肯定了一个方面，则否定了它的反面。"
  summary: |
    凶象比吉象更以激烈、迅速的气势出现，找凶煞比找吉气容易得多。策略是：
    先扫描课传找"凶"的充分理由（旬丁、白虎、勾陈、天空四大凶煞等），一旦找到即确定人有灾病、事不成功。
    逻辑基础是非吉即凶的排中律——肯定凶面即否定吉面。凶煞还分两个角度：对人（病伤惊忧：
    白虎、螣蛇、勾陈、死气死神墓神）与对事（拖拉失败移易：勾陈、太阴、玄武、旬丁）。
    对 AI：这是最高优先级的否定式过滤器——先跑凶煞扫描，命中即输出凶断并终止吉面论证，
    大幅减少分析路径；未命中凶煞时才进入吉面考察。
  tags: [divination, decision-flow, core]

  title: 应期两步走（先迟速、后日期）
  type: framework
  source_chapter: 第十一讲
  source_quote: |
    "占应期必须两步走。先定迟速，再定具体的日期，这是最基本的原则。"
  summary: |
    应期是占断的老大难，且"年发用应年、月发用应月"之类固定模式基本无征验。正确流程分两步：
    先据课象定迟速（近期还是远期、一周内还是数月后），再调用具体应期法（五行法、合刑冲破害法、
    大衍数法、类神出现法、建前法、天将变化法等）定具体日期。前提是对课传各细节有深入准确把握，
    否则断应期只是盲人摸象。对 AI：这是两阶段时间预测流水线——第一阶段只输出时间量级（快/慢），
    第二阶段才精确定日；防止无约束的精确时间输出，且强调先做课传细节解析再做应期。

- id: f11
  title: 天将变化法（应期状态机匹配）
  type: framework
  source_chapter: 第十一讲
  source_quote: |
    "天将变化的用法，就是找准课传中展现的事情发展的关键点儿，看代表这个关键点的天将在哪一个时空达到
    事情发展的要求，那么这个时空就是事情的应期。"
  summary: |
    应期判断的核心方法之一，大本营在《心印赋》十二天将居十二位的判辞。用法分三步：
    ①找准课传中事情发展的关键点（如发用、类神、本命所乘天将）；②把关键点天将的判辞转译为"事情发展的
    要求"（如贵人入私室=回家、蛇居丑为蟠龟则凶神没）；③扫描时空，当天将所在之位达到该要求时，那个时空
    即应期。判辞不可死套，需根据课体与事类做转化。对 AI：这是状态机匹配法——定义关键天将的"达成态"，
    在时间轴上逐位扫描判辞，找到首次达成要求的时空点即输出应期，可逐年、逐月、逐日推进。
  tags: [divination, timing, core]

- id: f12
  title: 两线定一点（多方法交叉验证应期）
  type: framework
  source_chapter: 第十一讲
  source_quote: |
    "两线定一点，五行应法和天将应法都以酉为期，丁酉日必归也。"
  summary: |
    单一应期方法易生歧义（如只凭五行断只能定"火灭之时"，不精确到日），因此用两条独立应期线分别推算：
    五行应法（如火旺于巳午、死于酉戌）+ 天将应法（如贵人酉日入私室），两条线交于同一点时即为应期。
    书中"两线定一点"最终锁定丁酉日。对 AI：这是交叉验证范式——对同一目标用两条相互独立的推理链
    （五行旺死链、天将判辞链）分别推算，交集输出为高置信结果；仅一条线命中时标注"待验证/需补充方法"，
    体现"应期方法越多越准"的原则。
  tags: [divination, timing, core]

- id: f16

  type: framework
  source_chapter: 第二讲
  source_quote: |

    '初传旺相末传否，前去行藏叹不偶。初传囚死末传旺，彼处机缘真个有。'"
  summary: |
    空间/去向类问题的推理框架：三传各司其位——发用=我方/出发点，中传=道路/过程，末传=他乡/目的地。
    比较初末旺衰可断去留方向：初传旺相末传休囚则不宜远行（"前去行藏叹不偶"），
    初传囚死末传旺相则彼处有机缘。结合发用/末传所乘天将与支神，可推"去不成"与"去哪里"两问。
    对 AI：这是路线推理算子——把"去哪/留这"类问题映射到三传空间坐标，
    用初末旺衰比较输出方向倾向，用中传/末传类象补全具体地点与路径信息。
