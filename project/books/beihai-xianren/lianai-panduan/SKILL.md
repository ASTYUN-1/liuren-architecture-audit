# 恋爱判断（常法 / 变法 / 琐象）

## R — 原文 (Reading)

> 恋爱之占，有常法、变法两种。……所谓常法，主要是干支上神之间的关系。以干支分类男女，看其上神之关系。干为男，支为女；干支上神生合则终成眷属，干支上神冲克刑害则各奔东西。……三、琐象。四课不备，只有三课，三角关系，这个准验度很高。
>
> — 北海闲人, 第十讲《恋爱》

---

## I — 方法论骨架 (Interpretation)

面对的问题是"两人恋爱能否成、关系如何发展、有无第三者、何时成"。三套逻辑按序执行，结果可叠加：

1. **常法（基础判据）**: 干=男、支=女，看干支上神关系——生合则成，冲克刑害则散；交车相合=暂时融洽终究分手。课体断语：解离格（干支互克上神）=先好后坏；干支乘墓=墓为止最终分手；人宅皆死=死心；干支皆败=灰心丧气。
2. **变法（纠偏判据）**: ① 年命倒置——支辰为男方本命/行年、或干寄宫为女方本命/行年时，干支角色互换而看；年命迭现以命为先、互为行年以行年为先。② 第三者象——天后/妻财/太阴临干 + 青龙/官星/贵人临支=另有对象、不成之象；但课传成合之象甚明反为速成。③ 男占：天后妻财临干与干上生合且支上不见官龙贵=成；女占反之。④ 铸印课不空陷=姻缘可成（形成整体）。⑤ 婚喜之象并聚（龙后旺相、太常天喜旺相生合、戌/父母乘六合=结婚证）则婚成。
3. **琐象（高准验快查清单）**: 四课不备三课=三角关系、两课=放荡同居；男占鬼临三四或人宅受脱=防被骗；课中勾陈作鬼=为情痛苦拖拉；太阴现课传=女子缠绕；财克干上长生=女方非礼义；玄阴后合太多=淫乱；子作六合=荡妇；未作天后=妇女奸淫；小吉单逢六合=婚姻聘礼。
4. **强信号（p37）**: 男女本命相加临课传、或行年相加临课传 ⇒ 婚必成，虽空无事；太常发用=婚礼之象佐证。

产出：成/散/先好后坏 + 风险标签（第三者/被骗/三角/无心）+ 婚期线索。

## A1 — 书中的应用 (Past Application)

### 案例 1: 男因女友有孕问今年能否结婚（c31）
- **问题**: 男因女友有孕，问今年能否结得成婚。
- **方法论的使用**: 常法+琐象。干支上酉丑相合看似吉，但酉为旬空、丑乘天空=双方无心之意（合神空亡变质）；琐象：阴后临于支二课又作鬼=女必有奸私事，而丑作天空男尚不自知；子为胎神临丑乘虎受克=此胎不成。
- **结论**: 婚不成，胎亦不成。
- **结果**: 后侦知此女联系多个男人，此胎不知是何人之果，乃放弃之。

### 案例 2: 问与女友关系发展（c32）
- **问题**: 问与女友关系发展如何。
- **方法论的使用**: 常法+有路。伏吟、亥旬空，秋占为孤辰=孤独之象；支上天后（妻星）被末传青龙冲去=有路（冲）引动克灭妻星，婚姻无从谈起。
- **结论**: 交冬令必散。
- **结果**: 后果亥月散掉。

### 案例 3: 问恋爱成否（男七六、女七七）（c33）
- **问题**: 问恋爱成否。
- **方法论的使用**: 年命相加强信号。男本命辰、女本命巳，本命相加临；男行年巳、女行年午，行年相加临=年命相加婚必成，虽空无事；又太常发用=婚礼之象；申年子作长生=成婚应期线索。
- **结论**: 必成婚。
- **结果**: 虽屡屡起落，终于在次年成婚，但二人矛盾不断。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户直接问占恋爱：恋爱成否、关系发展、能不能结婚、对方心意、暗恋对象。
2. 用户提供两人年命/出生信息问婚姻适配、婚期。
3. 感情课中疑似第三者/三角关系场景（常以"对方是不是还有别人"出现）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **常法先断**
   - 取干支上神关系矩阵（生克合冲刑害），对照课体断语（解离格/干支乘墓/人宅皆死/干支皆败/交车相合）。
   - 完成标准: 输出干支上神关系矩阵与基础结论（成/散/先好后坏）。

2. **变法纠偏 + 年命强信号**
   - 检查年命倒置条件（支辰=男方本命/行年，或干寄宫=女方本命/行年）；查第三者象（天后/妻财/太阴临干 + 官龙贵临支）；查男女本命/行年相加临课传（命中=婚必成）；查铸印课、婚喜并聚。
   - 完成标准: 输出角色是否倒置、有无第三者象、是否命中"年命相加"强信号。
   - 判停条件: 若命中"年命相加婚必成"且无琐象否决 ⇒ 直接输出"必成"，跳到步骤 3；若第三者象成立且无成合大势 ⇒ 输出"不成/另有对象"，跳到步骤 3。

3. **琐象扫描 + 输出结论**
   - 逐条核对琐象清单（四课不备三课=三角、两课=同居、鬼临三四=被骗、勾陈鬼=为情痛苦、太阴=女子缠绕、玄阴后合=淫乱、子作六合=荡妇、未作天后=奸淫）。
   - 合并常法+变法+琐象得出成/散结论、过程特征与婚期线索，附每个风险标签的依据。
   - 完成标准: 结论含三法各自依据、风险标签列表、成/散判定与时间线索；标注置信度与存疑点（ce09、ce12–ce15）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 夫妻已成的相处关系（关系质量/争吵/离婚）——归人际关系判断（s09 夫妻框架）。
- 问"一生姻缘格局/性格决定姻缘"——归终身与年运课法（s14）。
- 把琐象口诀（"子作六合为荡妇"等）当作统计保证使用——作者标"准验度很高"仍是经验断言，未经盲测（ce14）。

### 作者在书中警告的失败模式

- **ce09 恋爱琐象凶例（全条）**: 四课不备只有三课=三角关系（准验度很高）、只有两课=放荡同居；男占鬼临三四或人宅受脱=防被骗；课中勾陈作鬼=为感情痛苦、拖拉好长时间；太阴现课传=女子缠绕；财克干上长生=女方非礼义之辈；玄阴后合太多=必淫乱之人；干支上神虽合但合神空亡或乘天空=双方无心（c31 酉丑相合而酉空丑天空，女有奸私事）。
- **ce02 空亡陷阱**: 恋爱课"干支上神生合"须查合神是否空亡/乘天空——空合=虚合=无心；天空之空不论旺衰皆凶。
- **ce03 变质**: 妻星/夫星类神乘凶将（如末传申蛇空亡=妻非贤妻、财作蛇=小人琐碎）则吉转凶。
- **ce12–ce15 公共方法学边界**: 全部恋爱案例"果应"无失败样本（ce12）；常法与变法结论冲突时选择权大（ce13）；琐象口诀可证伪性未解决（ce14）；"天后=妻、六合=媒"等象意映射是未论证前提（ce15）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: c31–c34 全部按作者断语应验于叙事，无断错样本，无法估计真实命中率。
- **解释自由度（ce13）**: "干支上神相合但空亡"可断"无心"，"空亡但得生"又可断"虽空无事（c33）"——同一空亡两种用法，结论弹性大。
- **可证伪性（ce14）**: 琐象口诀组合（干支×天将×位）几乎总能事后自圆其说。
- **时代与文化局限**: "女方非礼义之辈""荡妇/奸淫"等断语带明显旧伦理色彩，现代多元亲密关系语境需慎用（ce15 象意非普适常量）。

### 容易混淆的邻近方法论

- 与 **人际关系（s09）**: s09 断"关系质量/他人态度"，s12 断"成否/婚期"。
- 与 **终身与年运（s14）**: 问恋爱成败用 s12；问个人整体姻缘格局（性格决定姻缘）用 s14。
