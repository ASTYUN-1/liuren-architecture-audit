# 凶煞速断（否定式过滤）

## R — 原文 (Reading)

> 凶的东西，总比吉的东西，更能以一种激烈的、迅速的气势出现，因此，断课的时候，找凶煞，往往比找吉气更容易，因此，在断课之时，我们可以先找到一个"凶"的充分理由，则可确定人有灾病，而事不成功。这虽然是一种"偷懒"的法子，却是一种极有效的法子，盖非吉即凶，肯定了一个方面，则否定了它的反面，自然之理也。
>
> — 北海闲人, 第四讲

> 占病，有这么几个方面：病因、症候、医药、生死。陈公献在这里主要断了病因、症候、生死。
>
> — 北海闲人,《大六壬指南》问答录二

> 占病有这么几个大忌：一是马星，主魂游千里；二是玄胎课，主别处投胎；三是三传传空，主没有活路；四是日鬼太旺，主病重难医；还要兼看禄神，古人常有"不禄"代表死亡。
>
> — 北海闲人,《大六壬指南》问答录五

## I — 方法论骨架 (Interpretation)

面对的问题是：课传吉凶混杂、信号两面摇摆，不知从何定夺。这套方法的思路是**反过来找凶**——凶比吉更醒目、更易识别，只要找到一个"凶"的充分理由，就等于否定了吉的一面（非吉即凶）。

四大凶煞各管一段：
1. **旬丁**（对事，主移易动摇）——占待定结果（考试/应聘等公布前）遇朱雀乘丁，结果会被篡改；求稳之事（工作/生计/姻缘）遇丁则风雨飘摇；丁并劫煞大凶。
2. **白虎**（对人，主死丧病伤，也主事的转折中断）——必须看"位"：作阴神只是显象不主吉凶，**发用才主吉凶**；白虎受制（被地盘所克）则病可愈。
3. **勾陈**（对人=斗讼争官，对事=迟滞）——最常见的误用是只看官司打斗，忽略其"迟滞"义：运势极度低迷、如被捆住手脚。
4. **天空**（主空亡+平地风波）——它是唯一"不论旺衰、例以凶论"的空亡例外，见天空即凶煞。

产出：先跑完凶煞扫描，命中→输出"凶"的定性结论（性质、对人/对事、程度分级）；未命中→通过否定关，把吉凶判断让给其他 skill。

### 占病四维体系（《大六壬指南》问答录扩展）

占病/病势/生死问题不直接找单一凶神，而按"病因—症候—医药—生死—应期"五面拆解，各面各有主断类神与判定程序（问答录二/五/十一三次以同一枚举顺序出现）：

1. **病因三选一**（白虎受克神/日鬼/脱气）——先列三类候选病源，再以两条判据选一：①是否上卦传；②力量强弱（是否发用、是否太岁、离干近远）。白虎未上卦传或落空则弃之，脱气力弱让位（问答录五"白虎落空，占病不以白虎断"；问答录二"脱气力量比日鬼小得多，以日鬼为断"）。病因是占病第一决策，选错则症候、医药全盘皆错。
2. **症候以课体象人体**——不备课主气势不足、象人体虚力弱；火受克为血病；食神主食欲、财主饮食，财食落空则饮食难进（问答录二/五）。
3. **医药治本不治标**——以官鬼/白虎之五行辨受症之本脏（木官鬼→肝、火白虎→心），据五行生克看表象之腑，治法取本脏不治标（问答录十一"理肝清心，勿治脾肺"）。
4. **生死判**：
   - **必死四忌**（禁忌清单累计）：马星主魂游千里；玄胎课主别处投胎；三传传空主没有活路；日鬼太旺主病重难医。见其一即大凶，多条叠加断必死；兼看禄神，"不禄"代表死亡（问答录五）。
   - **收魂杀**＝日墓发用乘玄武，断必死（问答录十一）。
   - **墓发用分事类**：墓发用问失事物在、行人归、诉讼判刑、病症必死——同一象按事类定向，占病最凶。
   - **病体难担荷格**：干支皆为上神所脱＋三传合局为财＋支上亦财，身弱不胜财耗，断缠绵难愈（问答录十一）。
   - 快速信号：太岁克干＋长生入墓＝生气全无（问答录二）；病符坐空、阴神又制之则无病之忧（问答录十四）。
5. **应期**——病死应期常规断长生/墓/绝之时，亦可断鬼旺之时（病气最盛）；占病大凶课必须问行年本命较量（问答录五/十一）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 徐盟鹿占远行被劫（旬丁+劫煞，古课）
- **问题**: 徐盟鹿携妻子远行，问吉凶（八专、绝嗣）。
- **方法论的使用**: 先扫凶煞——中传巳为旬丁又为劫煞，"飞祸横来，全家遭难"；再叠加：男干女支行入空墓之地、末传日死加巳"合为死字"、壬戌加卯发用"河井相加"主车船破坏。巳本为长生、太常为父母（生命之源），作丁神劫煞则"见生不生，不如无生"。
- **结论**: 全课凶象并集，断全家远行遭难。
- **结果**: 近江西百余里，男女五人被盗而死。

### 案例 2: 何子重占平生（白虎活用，古课）
- **问题**: 何子重四十八岁占平生福泽。
- **方法论的使用**: 白虎活用看"位"——干上长生作太阴（福佑），申为金银为僧、白虎为死丧，亥阴带申虎来＝"死丧之财"；课上的白虎作阴神只是显象，而虎之阴神见勾陈＝刑罚之象。
- **结论**: 先得死丧之财（僧人溺亡、拾银四锭）而宽余，宽余之后横祸即来，犯刑发配。
- **结果**: 次年拾银四锭作生意宽余十一年；第十二年伤人受刑，后被陈姓人告发配池州。

### 案例 3: 辛酉命占运势（勾陈大限）
- **问题**: 占整体运势（辛酉命）。
- **方法论的使用**: 勾陈双义——中传丑鬼作勾陈发用（第二大限主题），"本来就主麻烦多多"；又被地盘午害，"更是雪上加霜"。断 22 岁以后麻烦不断，主迟滞低迷而非单一官司。
- **结论**: 第二大限麻烦不断、工作做不长、身体长期不佳。
- **结果**: 反馈逐条应验：00 年大病高考失利、06 年后转做幼儿教师、07 年生病、抑郁 8 年需吃药。

### 案例 4: 占女病——占病四维逐面拆解（z01，问答录二）
- **问题**: 占女病（古课）。
- **方法论的使用**: 占病四维——病因三选一：日鬼发用乘凶将、离干近且为太岁，白虎未上课传、脱气力弱，故取日鬼为断；症候：不备课主气虚体弱、火受克为血病；中末空亡主新病好、久病无路；太岁克干＋长生入墓断生气全无，冬水旺断冬月死。
- **结论**: 病势凶险——新病可愈、久病难保，死期在冬月。
- **结果**: （古课注疏，按"病因—症候—生死—应期"四维逐项演示断法）

### 案例 5: 妇病断死——必死四忌叠加（z04，问答录五）
- **问题**: 阴人（妇人）占病。
- **方法论的使用**: 必死四忌逐忌扫描——发用马星主魂游、病玄胎课主别处投胎、中末空亡主无活路、日鬼发用主病重，四忌占三；兼看禄神"不禄"；未（坤）乘天后＋蛇为妇女类神断占问对象为妇人；应期断鬼旺之时。
- **结论**: 多忌叠加、凶象总量已定，断病者必死。
- **结果**: （注疏按语：据前几个条件已断定病者离开这个世界）

### 案例 6: 收魂杀断死——墓发用×玄武（z10，问答录十一）
- **问题**: 占病（刘一纯占病）。
- **方法论的使用**: 墓发用分事类——占病必死；且墓乘玄武谓"收魂杀"大凶；病体难担荷格（干支皆脱＋三传合财）主缠绵难愈；医药治本断"理肝清心、勿健脾补肺"；应期与本命行年较量（甲戌流年不保）。
- **结论**: 病必死，应期在甲戌流年。
- **结果**: （注疏警示：占病大凶课必须问行年本命，缺此则应期只能断粗框架）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **占事吉凶不明**：用户问"这事能成吗？会不会有麻烦/灾祸？"——先跑否定式过滤，确认无凶煞命中再论吉。
2. **结果会不会生变**：考试/应聘等待公布结果、工作生计姻缘等求稳之事——旬丁"移易"信号。
3. **怎么老没进展/低迷拖沓**：事情长时间无进展、运势停滞——勾陈"迟滞"信号。
4. **会不会落空/没来由的麻烦**：担心白忙一场、莫名风波——天空信号（不论旺衰一律凶）。
5. **AI 作为分析框架**：任何占断任务先执行凶煞扫描作为第一道闸门，命中即产出否定性结论，再交 `jixiong-tiaozhi` 定程度。
6. **占病/病势/生死**：用户问"这病能治好吗？病势如何？何时会死/会不会死？"——跑占病四维检查（病因三选一→症候→医药→生死四忌/收魂杀→应期），命中必死忌/收魂杀即最高凶级。

### 语言信号 (用户的话里出现这些就应激活)

- "占/预测/divination/chart 吉凶/good or bad"
- "灾/病/祸/血光/disaster/illness/misfortune/injury"
- "麻烦/纠缠/拖沓/trouble/delay/stuck"
- "变动/被改/不安稳/change/unstable"
- "落空/白费/没来由/in vain"

- "占病/病势/能不能治好/何时死生/illness/prognosis/recover/何时死/life-death"

### 与相邻 skill 的区分

- 与 `jixiong-tiaozhi` 的区别: 凶煞命中给"凶"的**定性**（是否凶）；程度（凶到什么程度、吉中是否有忧）由四象限调制**定量**。本 skill 是调制的一个输入象限。
- 与 `kongwang-bianzhi` 的区别: 天空"不论旺衰一律凶"是空亡规则的**例外**；普通空亡仍须辨旺衰（旺不为空、得生得助不为空）。
- 与 `keti-qishi` 的区别: 天网课等凶课体是**课体层**否定，凶煞是**神将层**否定；同一课两者可叠加，先各自扫过再合并。
- 与 `yingqi-panduan` 的区别: 凶神"没则吉事来"（蛇居丑为蟠龟）是应期信号，但本 skill 只管吉凶定性，不管"何时"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **扫描凶煞命中表**
   - 完成标准: 对旬丁/白虎/勾陈/天空四煞逐一检查：是否发用、临干、临支、乘类神、作日鬼；输出命中表，每条注明位置与所克对象（如"中传巳＝旬丁+劫煞，克支"）。

2. **分级与辨位**
   - 完成标准: 对命中的凶煞分"对人（病伤惊忧）/对事（拖拉失败移易）"两途；白虎查"位"（阴神只显象 vs 发用主吉凶）与受制（被地盘所克则病可愈）；日鬼克干查所带神将分级（金鬼带勾虎蛇＝大凶有伤身害命之危；带玄武天空＝怕被欺骗；带太阴天后＝暗害说坏话）。
   - 判停条件: 若四煞**全部未命中**，跳过步骤 3 的凶结论，将判断转交 `jixiong-tiaozhi` 或对应领域 skill 论吉。

3. **输出否定结论**
   - 完成标准: 明确给出"凶/未凶"结论 + 凶的性质（动变/死丧/迟滞/落空）、涉及人还是事、程度分级；并附一句书中盲点提醒（见 B 段）。

4. **占病四维检查**（凡占病/病势/生死必跑，在凶煞扫描之后执行）
   - 病因三选一：列白虎受克神/日鬼/脱气三类候选→筛上卦传者→取力强者（发用/太岁/离干近），弃落空或未上卦传者；
   - 症候：课体象人体（不备=气虚、火受克=血病、财食空=饮食难进）；
   - 医药：官鬼五行定本脏→治本不治标；
   - 生死：必死四忌逐忌扫描（马星魂游/玄胎别投胎/传空无活路/鬼旺病重难医）＋收魂杀（日墓发用乘玄武）＋墓发用分事类＋病体难担荷格；多忌叠加断必死；
   - 应期：长生墓绝或鬼旺择一，须问行年本命较量。
   - 完成标准: 输出"病因/症候/医药/生死/应期"五维结论；生死维度注明命中的忌数（0/1/多条），忌数≥2 即断必死。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问**应期/何时**，不涉吉凶——交 `yingqi-panduan`。
- 纯**课体大势**走向问题（经济走势、方向）——交 `keti-qishi`。
- 课传**吉象并聚**（生合吉旺、龙常贵合并聚）已成局时，不可因单一凶煞就全盘否定——吉象并聚可替代类神不现（c27 应验），须交 `jixiong-tiaozhi` 综合裁定。
- 本方法是"速断"不是终审——命中凶煞后仍要复查课传是否另有救应（如 c15 中卯月将生起巳常，"破而不破"）。

### 作者在书中警告的失败模式

- **ce04 旬丁**：占待定结果（考试/应聘公布前）只看类神吉象，忽略旬丁"移易"——朱雀乘丁则录取结果被篡改；占求稳之事遇丁则风雨飘摇甚至倒台；丁并劫煞大凶（徐盟鹿例全家死于盗匪）。
- **ce05 白虎**：见虎一律断死丧病伤，忽略"位"——作阴神仅显象不主吉凶，发用才主吉凶；白虎受制/其阴神克日则病必可愈。
- **ce06 勾陈**：只断官司斗讼，忽略"迟滞"义——运势极度低迷、如时间停止、被捆住手脚。
- **ce10 财煞**：求财见财就断得财，忽略脱气（乘玄武/天空成脱耗格、脱空格，主钱财耗尽）、财怕空、财乘破碎煞、三传全财大凶、三传财局生鬼因财致祸。
- **ce16 占病四忌**（问答录五）：占病只看日鬼、白虎等单一凶将，漏掉四条必死大忌的快速筛查（马星魂游/玄胎投胎/传空无活路/鬼旺病重难医），把"必死课"断成可治。
- **ce17 多重凶叠加不可心存侥幸**（问答录五）：病玄胎＋中末空亡＋日鬼发用，各凶象单看都有"辩解余地"（马被合、禄神不明显），但凶象叠加的总势已断必死——单象可解、总凶难救。
- **ce28 病因三选一须辨力量**（问答录二/五）：占病病因只认白虎（或只认日鬼），不辨三者在课传上的力量与空陷——白虎未上卦传或落空则弃之、脱气力弱让位，选错病源则症候医药全盘皆错。
- **ce09 中末空亡占病分新旧**（问答录二）：不辨新病久病一律断吉或一律断凶——新病气血未衰空亡反主虚惊速解而愈，久病无本钱中末空则无路续命故死。
