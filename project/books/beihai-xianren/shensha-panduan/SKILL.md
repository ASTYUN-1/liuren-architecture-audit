# 神煞判读（一纲两源 · 分级取用）

## R — 原文 (Reading)

> 吉凶由神，克应由煞。……将（天将）无神不灵，神无煞不应。神煞较之天官、月将更为重要。
>
> — 《神煞全解》开篇（盲派神煞）

> "三传吉凶有狐疑，全凭神煞解心迷。"
>
> — 《神煞全解》重点煞清单（L135）

> 对神煞的思考是从季节煞开始，因为其最贴合十二长生气的理法，四季各有五行执掌权柄，以推测旺相休囚死。……在社会的范畴里，人的共识就是社会秩序，用季节的流变表示社会秩序再合适不过。……从共识的角度出发，来推演六壬的所有季节煞。季煞推演遵循两个基本原则：一.五气旺衰 二.十二长生气。
>
> — 《六壬思辨-神煞》（友人实战经验）

> 神煞略有 200 余，纷繁复杂，其象杂乱十分，到底能不能使用神煞作为吉凶论证，这是六壬学者一致认为的难题。
>
> — 《六壬思辨-神煞》（友人实战经验）

## I — 方法论骨架 (Interpretation)

面对的问题：课传中神煞数十上百，如何**取用**（选重点）、**断状态**（力大力微）、**判叠加**（组合意义），而不被神煞淹没、也不误用神煞推翻课体大势。

核心是**一纲两源**：

1. **一纲**（定位）："吉凶由神，克应由煞"——课体+类神定吉凶大方向，神煞在框架内做**精细化调整**；神煞**不可推翻课体大势**（课体吉+神煞凶→过程波折；课体凶+神煞吉→仍按课体凶论）。
2. **两源**：
   - **清单源**《神煞全解》六壬区：岁煞 8 / 季煞 8 / 月煞 19 / 旬煞 5 / 干煞 3 / 支煞 10 共 53 煞，每条含起法+核心义+断法要点。
   - **推演源**《六壬思辨-神煞》：不靠死记，用**五气旺衰 + 十二长生气**推演季煞（以春木局为坐标示例）——理解"煞从何来"，遇到未收录之煞可自行推演。

### 神煞判读三原则（《神煞全解》总纲）

- **叠加原则**：同一位置叠加神煞越多，该象越确凿——单煞可存疑，三煞并见则无疑。
- **状态原则**：神煞本身有状态——空亡则虚、旺相则力大、休囚则力微、坐墓则被压、被克则受制不能为祸/福。
- **不推翻原则**：神煞只做精细化调整，不推翻课体大势（与主 skill 裁决阶梯一致）。

### 季煞推演法（《六壬思辨-神煞》方法论，友人独有）

以春木局为例的推演坐标（理解法，非死记）：

| 地支 | 季煞 | 推演逻辑（五气旺衰 × 十二长生气） |
|:---:|------|------|
| 亥/子 | 返魂煞 | 木之长生沐浴，冬形死而气生，返魂 |
| 寅 | 皇书、吏神 | 木之临官，旺气未掌权，得书任职、小吏传书 |
| 卯 | 转煞、贼神 | 帝旺生变是转折；旺则争斗为羊刃故亦为贼神 |
| 辰 | 天目、浴盆 | 衰为退气、预见之象（目主出去）；浴盆产煞占产吉、占病凶 |
| 巳 | 孤辰 | 酉金亲戚被囚后成社会边缘人 |
| 午 | 火鬼 | 火旺克木之象 |
| 未 | 狱神 | 囚气之象 |
| 申 | 绝神、战雌 | 木局绝地；寅强申弱故申为战雌 |
| 酉 | 丧车煞 | 囚气克旺气，酉必遭囚之凶 |
| 戌 | 天耳、天喜 | 木之养，进气权柄回归，预见之象（耳主进来） |
| 丑 | 寡宿 | 酉金亲戚被囚成边缘人 |

**要点**：①辰戌都主预见，但一耳一目——辰主出去（浴盆）、戌主进来（天耳），合人体耳目进出之象；②季节煞必然有事主，事主者发十二气五气的坐标系；③年煞中病符=去年太岁（权柄丧失）亦主旧事疾病，同"退气"逻辑。

## A1 — 书中的应用 (Past Application)

### 案例 1: 太岁断流年与成败（《神煞全解》L19）
- **问题**: 占流年吉凶、竞选成败、病者生死。
- **方法论的使用**: 太岁为天子元首之象，主一岁吉凶"应在一年之内"；占流年以太岁为主要类神观三传；竞选看太岁加临日干年命之上主胜出；寅卯辰作太岁乘龙神=真龙天子象；**占病太岁作阎王祖宗之象大忌见之**。
- **结论**: 太岁是岁煞之首，全占类年度性判读核心。

### 案例 2: 驿马状态全集（《神煞全解》L115）
- **问题**: 占出行/调动/变动是否真动。
- **方法论的使用**: 驿马卦卦要推课课要看，最喜与禄神并（禄马同乡）；**若驿马空亡、落空、疾病、恋生、入墓、被合，皆主虽有出门动身之象实不行也**；临干身动、临支宅动、临年命身动；年马月马命马与日马相并主速动远动大动。
- **结论**: 驿马非见即动，须查六种"实不行"状态。

### 案例 3: 月厌四组合断（《神煞全解》L67）
- **问题**: 占嫁娶、盗贼、怪梦、病死、忧禁。
- **方法论的使用**: 月厌妨嫁娶；**加玄武→盗贼，加蛇→怪梦，加虎克日→病死，加朱勾→忧禁**；逃者忌向此方。
- **结论**: 同一煞随所乘天将不同而转义——神煞×天将组合断法。

### 案例 4: 丁马避险与妖神（《神煞全解》L99）
- **问题**: 占变动、忧惊、避难。
- **方法论的使用**: 丁马主摇动不安，亦为妖神专主不祥怪异忧惊；**本命逢丁马心惊不安，坐地盘长生之上可作避难逃生论**；长生禄神乘丁皆主生意、但禄神不安恐难持久；壬癸日逢丁多主财动婚动，庚辛逢丁多主凶动；六庚六辛丁临宅人宅俱动俱灾。
- **结论**: 丁马兼具动象与妖象，须按日干六亲分断吉凶方向。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **取课中神煞**
   - 从排盘引擎 keyShensha / 课传中列出实际出现的神煞（**以引擎输出为准，不自算起法**；起法核对用 refs/daliuren-shensha.md）。
   - 完成标准: 输出"课中神煞清单（含所在位置）"。

2. **分级取用**（按优先级逐级检查）
   - ⭐⭐⭐ 一级（课传必查）：旬空、禄神、驿马、丁马——直接定吉凶/应期。
   - ⭐⭐ 二级（按占类必查）：贵人、闭口、破碎煞、德神（天/月/日德）、八煞（劫杀/灾煞/岁煞/亡神/死气等）、九宝（生气/天喜/天德等）、胎神、玄武。
   - ⭐ 三级（占类专属）：皇恩/天赦（刑狱）、游都/鲁都/贼符（兵贼）、风伯/雷公（天时）、天医/地医（健康）、桃花/华盖/咸池（感情）、月厌/血支/血忌/丧魄（嫁娶血光）。
   - **重点 19 煞检查**（《神煞全解》L135）：日德、驿马、丁神、劫煞、成神、天马、生气、死气、死神、月厌、破碎煞、天鬼、天赦、太岁、岁破、小耗、病符、天喜、丧吊。
   - 完成标准: 输出"命中分级 + 重点煞检查结果"。

3. **断神煞状态**
   - 逐煞查状态：空亡→虚、旺相→力大、休囚→力微、坐墓→被压、被克→受制。
   - 完成标准: 输出"各关键煞的状态判定"。

4. **查叠加组合**
   - 命中《神煞全解》叠加组合（月厌×天将四断、破碎+败神=破败神、桃花=悬绳煞、华盖覆日、丧吊并见占病必死、丁马避险法等）或速查表叠加速查表。
   - 完成标准: 输出"叠加组合断法命中项"。

5. **推演理解（可选深化）**
   - 遇未收录/不明之煞，用季煞推演法（五气旺衰 × 十二长生气）推其义。
   - 完成标准: 输出"推演得出的煞义 + 依据"。

6. **输出神煞判读结论**
   - 汇总：分级命中 + 状态 + 叠加 + 重点煞 → 给出神煞层面对吉凶/应期/过程的影响判断。
   - **纪律**：神煞只做精细化调整，不推翻课体大势；与课体结论冲突时按主 skill【⚖️ 冲突裁决阶梯】处理。
   - 完成标准: 输出"神煞判读结论（标注影响方向与力度）"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯凶煞否定式速断（课传吉象并聚时的单一凶煞否决）→ 转 `xiongsha-suduan` 或 `jixiong-tiaozhi` 综合。
- 空亡/变质的类神真假校验 → 转 `kongwang-bianzhi`。
- 纯课体大势阅读 → 转 `keti-qishi`。
- 只需要神煞起法/口诀 → 用 `refs\daliuren-shensha.md` 速查表（本 skill 不管起法公式）。
- 八字命理神煞（以年柱/命宫起法）→ **不混入六壬体系**（《神煞全解》L151-1010 八字区，起法基柱不同）。

### 作者/来源警告的失败模式

- **神煞推翻课体（总纲禁止）**：课体吉+神煞凶→过程波折而非翻转；课体凶+神煞吉→仍按课体凶论。神煞是调整项不是主线。
- **起法冲突未裁决**：天医起法两派并存（正月戌《神煞全解》vs 正月辰《指南》系）——引用时注明流派差异，勿当唯一标准；浴盆天目"科丑"系"冬丑"之误，以"春辰夏未秋戌冬丑"为准。
- **八字区混入**：八字神煞（驿马以年支、桃花年支等）起法与六壬（以日支/日干）不同，混用则全盘错位——只允许禄马象意作"人物/性格注解"并标注"八字义"。
- **空表格/民俗煞**：《神煞全解》L1044-1057 三张空表与道教十二神煞，弃用不引。
- **单源经验（友人思辨）**：季煞推演法为单源未验证的推演方法论——用于理解"煞从何来"、增强判读，不替代权威起法。

### 作者的盲点 / 时代局限

- 《神煞全解》为网络文（2016），署名【神宵玉清，秋玄道人】，非古籍——六壬区（L9-137）与《指南》体系兼容，但八字区为转载，权威性弱于六壬正典。
- 《六壬思辨-神煞》为友人个人思辨，季节煞推演仅以春木局为示例，未覆盖四季全推演（"片面"即此）——蒸馏时以方法论收录，不以清单完备度要求。
- 神煞判读"果应"案例缺乏统计支撑（ce12 幸存者偏差通用）；"三传吉凶有狐疑全凭神煞解心迷"为经验断言（ce14 可证伪性通用）。

### 容易混淆的邻近方法论

- 与 `xiongsha-suduan` 的凶煞清单重叠（白虎/丁马/天空等）：凶煞 skill 管"凶的否定力量"，本 skill 管"煞的整体取用"——同一煞两个视角。
- 与 refs 速查表的分工：速查表=起法/分级静态数据；本 skill=判读流程/推演法/组合断。
