# 应聘与工作状况判断

## R — 原文 (Reading)

> 薪水的代表是禄神，而生活来源的代表是父母爻，而长生爻也代表安身立命。所以，禄、父母、长生都是职位类神。职位类神现于课传，而吉旺，不空陷，则职位必得，应聘必成。……课传中生合吉旺、龙常贵合等吉象并聚，虽类神不现，亦可以成就论之。
>
> — 北海闲人, 第八讲《应聘与工作状况》

> 中传见小吉乘太常，太常为"禀"，末传见长生学堂，是有"禀"（皇粮）之象，故院试可取。……
> 科举省试，一重课体，二重类神。这一课，三传递生是有人为他说话，现在是三传递克，
> 是有人扯后腿，压制他。
>
> — 北海闲人, 问答录二《占考试》（考试/科举类神）

> 1），是河魁作旬首临干发用，是必然考取且居榜首之意；2），是三传递生，主有贵人推荐；
> 3），是三传都在四课上，是回环格，吉凶都会成；4），是月将贵人未土加在亥命上，是贵登天门。
>
> — 北海闲人, 问答录七《会试》（考试吉象四要素）

## I — 方法论骨架 (Interpretation)

面对的问题是"能否得到某个职位/工作"（应聘、投考、跳槽、等待录用）。判断分四条线，按序执行：

1. **取职位类神**：禄神=薪水，父母爻=生活来源，长生爻=安身立命，三者都代表"职位"。先扫课传（干上、支上、三传、年命上）找三者。
2. **判必得**：类神现于课传 + 旺相（月建/进气）+ 不空陷 + 不变质 ⇒ 职位必得、应聘必成。
3. **补救路线**：类神不现不等于失败——查课传是否"吉象并聚"（生合吉旺、龙常贵合、三传进茹官局、发用引动支上贵人、龙神与幕贵生合），并聚则以成就论。
4. **快速细则**：禄神发用 + 合干上 + 所占之爻进气 ⇒ 虽乘玄武（取巧/走关系）亦必成且速；课名返吟则反复进退、数次方成。空亡非死刑：旺不为空、得生得助不为空（如长生落空但作月将/太岁仍得）。

产出：必得 / 可成（带速度与渠道特征）/ 不成 / 不确定（需结合他象）四级结论 + 依据链。

### 考试/科举类神（问答录二/七/十五，阶段2合并）

若问考试/科考/投考，在职位类神之外追加考试专用判据：
- **先定课体大势、再查类神**：科举占一重课体二重类神——课体（回环/炎上/三传格局）定成败方向，类神充实人事细节（与求职占同构，都是课体先行）。
- **传递方向＝人缘助力**：三传递生=有人为他说话/贵人推荐；三传递克=有人扯后腿、压制他（z01 省试无望 vs z06 递生中甲）。
- **考试吉象四要素**（问答录七 z06，多吉则中甲无疑）：①河魁作旬首临干发用=必然考取且居榜首；②三传递生=贵人推荐；③三传都在四课上=回环格，吉凶皆成；④月将贵人加亥命=贵登天门。
- **太常=禀（皇粮）**：中传太常＋末传长生学堂=院试可取（z01）。
- **幕贵坐空=不由科甲**：幕贵是科考专属类神，坐空断非科甲（z14）；反查长生父母爻+末传皇恩=恩荫门路。
- **读古断须回盘核对**：原文断语（如"朱雀遁乙奇乘长生旺气贴试官"）须核对课面条件（空亡/乘将）是否成立，不可照抄（z06 勘误）。

产出：必得 / 可成（带速度与渠道特征）/ 不成 / 不确定（需结合他象）四级结论 + 依据链。

## A1 — 书中的应用 (Past Application)

### 案例 1: 欲另谋公司高就能否进入（c25）
- **问题**: 某因厂里待遇差，欲另谋一公司高就，问能否进入。
- **方法论的使用**: 取禄神为职位类神。禄神发用（卯）又与干上相合，寅月占卯乃进气——命中"禄发用+合干上+进气"三重信号；禄乘玄武提示"取巧"；课名返吟提示反复进退。
- **结论**: 必成且速，但过程反复、走非常规渠道。
- **结果**: 成功且成得别具一格——其嫂之情人为公司老总，犹豫再三，至卯月接受其入公司上班。

### 案例 2: 占投考一公司（c26）
- **问题**: 占投考一公司能否入。
- **方法论的使用**: 禄神不现于课传（类神未现，本应存疑）；末传申作长生虽落空，但作月将又是太岁——"旺不为空、得生得助不为空"，申月必得。发用寅龙作马=能力超群、善于行动；支为辰，支上丑、丑辰相加为房室即公司之象，丑作空亡=虚位以待，寅引丑（有路引动）=获得此位。
- **结论**: 申月必得。
- **结果**: 后参加考试，拖到申月，得到通知而上班。

### 案例 3: 占应聘（c27）
- **问题**: 占应聘结果。
- **方法论的使用**: 虽无禄神、长生现于课传（类神全缺），但三传进茹官局，生起干上印绶青龙，发用引动支上贵人，龙神又与幕贵生合——走"吉象并聚"补救路线（类神不现亦可成）。
- **结论**: 虽有波折，最终可成。
- **结果**: 后果于本月成功上班。

### 案例 4: 占考试院试/省试（z01，问答录二）
- **问题**: 一课四问之一——陆庠友占考试（院试/省试）。
- **方法论的使用**: 占考试分两段：院试——中传小吉乘太常为"禀"、末传长生学堂，有皇粮之象，故院试必取；省试——一重课体二重类神，三传递克是有人扯后腿压制（非递生有人说话），蛇鬼临干发用主恶事缠绕，中末空亡亦先利后不利——断省试未遂。
- **结论**: 院试必取，科举省试未能遂志。
- **结果**: 后四事皆验（院试中、省试不遂）。

### 案例 5: 占会试中甲（z06，问答录七）
- **问题**: 占长兄公明进京会试，断是否考中、名次。
- **方法论的使用**: 考试吉象四要素齐备——河魁作旬首临干发用（必取居榜首）、三传递生（贵人推荐）、三传都在四课上（回环格吉凶皆成）、月将贵人未土加亥命（贵登天门）——断中甲无疑。反面因素（三传合局泄干气、贵人为日干之墓）力量小可忽略，但不可说全无作用（主次取舍）。
- **结论**: 必联捷而去，中甲无疑。
- **结果**: 放榜时果中三十九名（一甲），后封治安伯。

### 案例 6: 断何官所占 + 幕贵坐空（z03 续接 z14，问答录四/十五）
- **问题**: 干上卯为幕贵、阴神见财德贵马——断所生为贵儿（科甲/贵气类神取象）；反例：幕贵申临干但落空，断非科甲中人。
- **方法论的使用**: 幕贵是科甲/贵气的重要类神：干上卯乘幕贵+阴神见财德贵马=贵儿之象（但财德贵马空亡，贵也不久）；若幕贵坐空则断不由科甲，改查发用长生父母爻+末传皇恩断恩荫之官（z14 非科甲却作科甲之官、恩荫入仕）。
- **结论**: 幕贵旺相空不空决定"贵气是否落实"——坐空即不由科甲。
- **结果**: z03 果生贵儿；z14 此官非科甲、恩荫入仕，后果升镇江太守。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户直接问占求职类：应聘、投考、面试、等 offer/录取通知、跳槽另谋高就、"工作好找吗"。
2. 用户已起课（或给出盘面/时间/年命），要求 AI 作为分析框架判读"能否获得职位、何时成、走什么渠道"。
3. AI 在综合运势课（时运/年运）中识别到求职子问题，需按职位类神判据单独拆出判断。
4. 用户直接问占考试/科考：考编、考公、会试、院试、投考、"中不中""上不上榜""名次""考官对我印象如何"。
5. 用户已起课（或给出盘面），要求按考试类神判据判读成败与人缘助力（递生/递克）。

### 与相邻 skill 的区分

- 与 `s01 三步断课法` 的区别: 本 skill 是三步法在"求职"占类的实例化；三步法管全局流程，本 skill 管职位类神取用与判据。
- 与 `s02 类神/课体双侧重选择` 的区别: 本 skill 固定以类神为主（禄/父母/长生）、课体为辅；s02 教何时选哪条主线。
- 与 `s03 空亡与变质辨析` 的区别: 本 skill 调用其判据（旺不为空、变质）但不展开内部机制。
- 与 `s04 类象之动·有路理论` 的区别: c26 的"寅引丑"用到引动机制，本 skill 只借其结果判断到位。
- 与 `s05 凶煞速断` 的区别: 求职等待期必查朱雀乘丁（结果被篡改，ce04），凶煞扫描是求职课的否定式前置过滤。
- 与 `s06 课体气势阅读法` 的区别: 取不到类神且无吉象并聚时，看课体大势（如火局逆合留北不南）定去向。
- 与 `s07 时运课综合断法` 的区别: 时运课含"官运/工作"维；问一年综合运势用 s07，单问求职成败用本 skill。
- 与 `s08 财禄判断` 的区别: 禄神兼管收入，但本 skill 判"职位能否到手"，s08 判"收入/钱多少"。
- 与 `s09 人际关系判断` 的区别: 职场人际（同事/上司态度）用 s09；"能否进单位"用本 skill。
- 与 `s11 升职加薪判断` 的区别: 已入职后的晋升加薪用 s11；本 skill 只管入局/换工作。
- 与 `s12 恋爱判断` 的区别: 无涉。
- 与 `s13 应期判断` 的区别: 本 skill 可给粗略时间线索（如申月必得、本月成），精细断日调用 s13。
- 与 `s14 终身与年运课法` 的区别: 年运课中"换工作"事件可借本 skill 的职位判据；问终身格局用 s14。
- 与 `s15 吉凶调制与缩放` 的区别: 吉象并聚之成可用四象限调制质感（如"取巧之成"vs"正常之成"）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定占类并取职位类神**
   - 确认问题是"能否获得职位"（能成/能出现类），非升职/收入/去向类。
   - 完成标准: 在课传（干上、支上、三传、年命上）扫描禄神、父母爻、长生爻，列出三类职位类神各自是否现课传、位于何处、乘何天将。
   - 判停条件: 若类神现于课传且旺相、不空陷、不变质 ⇒ 直接输出"必得"，跳到步骤 3 补过程特征；否则进入步骤 2。

2. **空亡/变质校验与补救路线**
   - 对已现类神做空亡校验（旺不为空、得生得助不为空；天空之空不论旺衰皆凶）与变质校验（乘玄武/闭口/破碎/阴神见鬼=变质）；类神不现则查吉象并聚（生合吉旺、龙常贵合、三传进茹官局、发用引动支上贵人）。
   - 扫凶煞：等待期朱雀乘丁=结果被篡改；返吟=反复进退。
   - 考试类神检查（阶段2扩展，若占考试/科考/投考）: 先定课体大势（回环/炎上/三传格局），再查——①传递方向：三传递生=有人说话举荐、三传递克=有人扯后腿压制；②考试吉象四要素：河魁作旬首临干发用（必取居榜首）/三传递生（贵人推荐）/回环格（吉凶皆成）/贵登天门（月将贵人加亥命）——多吉则中；③太常=禀：中传太常+末传长生学堂=院试可取；④幕贵坐空=不由科甲；⑤读古断核对课面条件（如朱雀遁乙奇须验乘将/空亡）。
   - 完成标准（阶段2）: 输出考试吉象命中数与结论；四要素全中→中甲无疑，递克/幕贵空→降档或非科甲。
   - 完成标准: 输出"必得/可成/不成/不确定"四级结论，并附依据链（类神位+旺衰+空亡变质+吉象并聚）。
   - 判停条件: 若命中"发用空亡+时令衰气"或类神空陷且无生扶 ⇒ 输出"不成/难成"，跳到步骤 3。

3. **输出结论 + 过程特征 + 时间线索**
   - 给出成/不成结论，标注速度（进气息旺则速、返吟则反复数次）、渠道性质（乘玄武=取巧/走关系）、粗略应期（月将/太岁/申月等提示）。
   - 完成标准: 结论含四要素（成否、过程、渠道、时间线索），并明确标注置信度与存疑点（依 ce12–ce15 方法学边界）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问的不是"能否获得职位"，而是收入多少、晋升加薪、同事关系——分别归财禄 / shengzhi-jiaxin / 人际 skill。
- 用户把书中的"果应"案例当命中率统计证据时——应先提示幸存者偏差（ce12）。
- 无课传盘面（只有起课时间/年份而无盘）时本 skill 无法执行——需先起课。

### 作者在书中警告的失败模式

- **ce04 旬丁篡改结果**: 占考试/应聘，在考完等待公布结果的日子里，若占得朱雀乘丁神，则录取结果会被篡改；想求安稳之事（工作、生计）遇丁则风雨飘摇、意外倒台。
- **ce02 空亡陷阱**: 类神空亡不等于失败——旺不为空、得生得助不为空；但天空所主之空不论旺衰一律以凶论，又主平地风波。
- **ce12 幸存者偏差 / ce13 同一课可多解 / ce14 可证伪性 / ce15 映射前提未论证**（公共方法学边界，见下）。

### 问答录扩展反例（《大六壬指南》问答录 阶段2合并）

- **ce01 日寄宫空误放行**: "日寄宫空不为空"纯属无稽——日寄宫之空更甚于别宫之空；日空则日上之神（幕贵/官星/禄马）落空。幕贵坐空仍断"科甲可中"是典型误断（z14 断非科甲、z13 进京不得意而归，皆日寄宫空为证）。
- **ce08 中末空先利后不利**: 初传吉≠全事吉——中末空亡则先利后不利、有始无终（z01 省试：院试虽取、省试因中末空亡不遂）。

### 勘误备忘（问答录 阶段2合并）

- **朱雀遁乙奇贴试官（z06）**: 原文"朱雀遁乙奇乘长生旺气、文字甚贴试官之意"——照课朱雀乘酉而旬空，应无遁干、亦不生幕贵，课中遁乙在亥但不乘朱雀，故该断语在本课并无实据。读古断必须回盘核对原文与课面条件（空亡/乘将），不可照抄断语（呼应 ce31）。

### 作者的盲点 / 时代局限

- **幸存者偏差（ce12）**: 全书求职案例全部"果应"，无失败样本、无对照、无盲测，真实命中率不可知。
- **解释自由度（ce13）**: 类神不现时"吉象并聚"补救线几乎总能成立，结论对侧重选择高度敏感，同一课可多解。
- **可证伪性（ce14）**: 象意组合自由度极大（干支×天将×位×阴神×年命），断"后应验"可能是事后合理化。
