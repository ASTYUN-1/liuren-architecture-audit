## 1. 结构 (Structural)

### 类型
古典课例问答注疏。对陈公献《大六壬指南》占验中的代表性课例作逐问解析。非入门书，假设读者已掌握起课、九宗门、十二天将，且对《指南》原文有基本了解。与前作《特训班讲义》（现代实战方法论）相比，本书是"古典断法细读"——把《指南》里高度浓缩的铁口直断逐条拆开讲理。

### 一句话主旨
以《大六壬指南》经典课例为教材，把陈公献的每一句断语还原成可操作的壬学法则（占病四维、官星禄马、攻守定位、应期法则、动象三查、主次取舍），示范"**课体大势 > 类神细节 > 主次取舍**"的古典断课思路。

### 骨架 (主要论点及其关系)

1. **《指南》导读**（问答录一）：成书明末清初（1607–1651），陈公献主撰、程翔云/庄公远/何伴鹤/彭南溟合著；五卷结构（注释心印赋+指掌赋=总纲、会纂=分类断诀、占验=130 占例、神煞=起例）；读书法：背诵→结合理论析课例→遇高手点拨+多实践。
2. **占病四维框架**（问答录二/五/十一）：病因（虎鬼受克神 / 日鬼 / 脱气 → 看上卦传者、以力强者为断）、症候（课体象人体：不备=气虚、火受克=血病；日鬼乘蛇=气不顺、食神空=不进饮食）、医药（以官鬼星五行辨受症脏腑 → 治本脏不治标）、生死（占病大忌四：马星魂游 / 玄胎别投胎 / 传空无活路 / 鬼旺病重；墓发用乘玄武=收魂杀必死）、应期（长生/墓/绝、鬼旺之时、与占者本命行年较量）。
3. **占官仕途法**（问答录三/八/九/十/十二/十五/续一）：官五要素=贵（上人支持）/龙（官类神）/禄（薪水=职位）/财（官之源）/马（行动），任一入墓绝空=该方面受损；科举看课体+类神（三传递生=人说好话、递克=人扯后腿）；幕贵定科甲；铸印乘轩=迁转、虎马发用=速迁速败；顾祖=归乡、龙化为蛇=由大变小；财官禄马入墓绝=急流勇退；干支坐墓甘招晦；传将逆行=有退无进；三传递克=被参劾。
4. **动象三查**（问答录二/四/六/十/续一）：驿马三怕（坐长生/坐墓/被地盘合）；干神归支=静象（须辨支克干则居不住、脱墓则心力交瘁）；首尾相见=吉凶皆成；传将逆行=有退无进。
5. **应期法则**（问答录三/四/五/十/十一）：太岁发用应一年内、月建一月内、日辰当日、时发用当时；发用加地盘岁日月时同上；前三辰法则（发用在岁日月时之前三神 → 断发用当令之时）；"六壬定应期很重视地盘，多以类神临处为断"；病死期看长生/墓/绝或鬼旺。
6. **兵占/贼占/逃亡**（问答录二/十一/续二）：兵占框架=贼符（子卯巳申）/游都/鲁都/天乙贵人/日鬼，课传中看谁的力大；干为攻支为守，干之阳神攻方大将、阴神攻方部属、支上两课守方大将部属；贼占=玄武类神，玄武所临地盘断方向、盗神（玄武阴神）上下相乘断里数、三合支辰断亲戚、勾陈或官鬼克玄武=贼可获。
7. **学习观**（末尾）：壬归→指南→断案是正道；站在指南高度看壬归、以断案思路看指南，才能跳出指南；注书是逼自己进步；心浮气躁无法深入。

**论点之间的关系**: 1 是背景导读（并列前置）；2–6 是按事类的古典断法细节（并列），其中 4 与"主次取舍"是横贯各占的方法论主线；7 是学习路径收尾。

### 作者要解决的核心问题
"《指南》每一句断语到底是怎么断出来的？"——把古典课例里高度浓缩的铁口直断，还原成可理解、可复用的法则链。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 贼符 | 子卯巳申四个地支；占兵时"贼符加干支，冬月必有兵警" | ≠ 普通神煞清单；是"内外皆有兵战之象"的快速信号 |
| 游都/鲁都 | 占兵贼有无与来向的类神（辛日寅为游都） | 仅用于兵占，与玄武（贼占）分工 |
| 收魂杀 | 日墓发用且乘玄武，占病必死 | 墓乘凶将的极端形态，生死判的直接依据 |
| 病玄胎 | 三传合局构成病症之象（玄胎课主"别处投胎"） | 玄胎课平常只主新意萌动；占病则成死忌 |
| 墓发用 | 占失事=物在、行人=人归、诉讼=判刑、病症=必死 | ≠ 一律凶；分事类解读，占病最凶 |
| 幕贵 | 科举考试的关键类神；幕贵坐空=不由科甲 | 科甲占专属类神，与普通贵人分工 |
| 官五要素 | 当官者必须具备：贵人/龙神/禄/财/马 | 综合判断官运的清单，任一坏则对应方面不保 |
| 干神归支 | 干上神加支上=在家不动的静象 | 须继续辨支神与干神关系：克=居不住、脱墓=心力交瘁 |
| 驿马三怕 | 怕坐长生、怕坐墓、怕被地盘合（缚足恋厩） | 判断"马动不动"的三条快速检查 |
| 首尾相见 | 旬首旬尾分临干支，《毕法》"首尾相见始终宜" | 无空亡则吉凶事皆成（吉凶同论） |
| 传将逆行 | 天将逆行+三传逆=凡事有退无进 | 占官当退、占行人当归、出行不可出 |
| 罗网 | 天罗地网（辰戌）；日上罗网逢空=解脱而去 | 网空即脱，动势的例外判定 |
| 盗神 | 玄武之阴神（玄武上神） | 断贼里数=盗神上下相乘；断贼去向=玄武所临地盘 |
| 病体难担荷 | 干支皆脱/三传合局为财而日干衰=病体难担 | 占病"身弱不胜财耗"的课格 |
| 前三辰法则 | 发用之神在岁/月/日/时之前三辰范围内 | 应期定月/定日的古典法则 |
| 一德解百祸 | 日德（如亥水发用遁辛）可解祸 | 只减轻灾祸、不改变课凶总趋势 |
| 元首生男/重审生女 | 课体断生男生女：元首生男、重审生女、纯阴反阳生男、阳不备生女 | 占生产的多法并观，须结合干上神、比和 |

### 核心命题 (用自己的话)

1. 断课先抓主线：**课体大势优先于类神细节**，主次因素的取舍决定断课成败。
2. 占病四维：病因/症候/医药/生死各有所主类神；病因取"上卦传且力量最强"者（虎鬼、日鬼、脱气三选一）。
3. 占病必死四忌：马星（魂游千里）、玄胎（别处投胎）、三传传空（没有活路）、日鬼太旺（病重难医）；墓乘玄武=收魂杀必死。
4. 当官者贵龙禄财马五要素俱全方为吉，任一入墓绝空则该方面不保。
5. 应期最重地盘与类神临处：太岁/月建/日辰/时发用定大框架，前三辰法与长生/墓/绝/鬼旺定具体时点。
6. 动象三查：驿马三怕、干神归支、首尾相见——判断"动不动、能不能动"。
7. 救解是局部：有救解≠改总凶；**断课不能只看课体，还要看类神，一定要看阴神**。
8. 兵占攻守定位：干为攻、支为守；干支各自上下两课分主攻守双方的大将与部属。
9. 贼占玄武法：方向看玄武所临地盘、里数看盗神上下相乘、亲属看三合、捕获看勾陈/官鬼克玄武。
10. 干支坐墓甘招晦：身宅坐墓必受人欺绐，终难解脱（《毕法》）。
11. 三传递克主参劾：无论递克方向（初克中、中克末或反向），在朝官占得均主被参。
12. 一德解百祸：日德可减祸但难改总趋势；"空亡墓绝"类大凶看能否得德解。
13. 壬学根于天文而成其体系，又独立于天文而存在——古传口诀（星宿、图书之府等）依然有效。
14. 日寄宫空不为空是"无稽之谈"：**日寄宫之空更甚于别宫之空**（《指南》数例可证）。
15. 旺火逢空仍可燎天：占逃亡/动象，干支上时令旺火虽空亦主速动（丁火旺相）。

### 论证链
每课先录《指南》原文断语，再以问答形式逐句追问"为什么这么断"。北海闲人以课盘数据（干支上神/三传/天将/神煞/年命/驿马）还原推导路径，引用《毕法赋》《指掌赋》《心印赋》《会纂指南》《玉成歌》《曾门》等古籍佐证，多数课例补充事后验证（"后四事皆验""果陈忠也"），部分给出修正（"原书说是血忌，实际上是血支"）。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 依托明末清初制度（科举、巡抚/总督、卫所、给事中、枚卜），大量篇幅考据官职制度；对现代占事（公司职位、高考）需类比转换，映射风险未讨论。
- 占例反馈仍是"果应"叙事，无统计、无盲测、无失败样本。
- 神煞/星宿考据（如"未中有井鬼二宿"）占篇幅，与断法应用关系弱。

### 作者的立场盲点
- 以注释经典为务，默认《指南》断语全对，除个别"此点待议"外几乎不质疑陈公献——缺少对古典断法本身的批判性检验。
- 北海闲人自己的断课实例很少（本书以解释古人为主），"灵验时刻"全部来自陈公献。
- 把古典断法当作"可直接复制"的，未讨论古今社会结构差异（科举 vs 高考、总督 vs 高管）对类神映射的影响。

### 未被证明的假设
- 陈公献每一句断语都内在地有完整可还原的法则链（可能部分是直觉/经验，事后才附会出道理）。
- 神煞象意的古传口诀在当代依然"独立于天文而有效"。
- 占病/占官/占兵等古典定式在现代社会结构下依然成立。

### 最强反对意见
本书把《指南》断语逐句"合理化"——任何断语几乎都能事后找到解释路径（干支、天将、神煞、阴神、年命、地盘任取其一），这恰是"事后附会"的温床；同一课换一套法则常能推出别的结论。古典注疏提供的是"解释力"而非"预测力"，若以严格标准检验，命中率未必高于随机。
