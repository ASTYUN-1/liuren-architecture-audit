- id: z01
  title: 占考试（院试/省试）+ 升迁/女病/兵占四问同课（丙戌日己丑时）
  type: case
  source_chapter: 问答录二
  source_quote: |
    "断曰；院试必取，科举省试未能遂志。问曰：史抚台已升凤督去否？余曰：必不能去。
    盖因驿马坐墓，干神归支，静象也。又问女病，余曰：胎鬼发用，血忌加支，又四课不备，
    病主脉息虚弱，心胸不利，以致失血，必因胎产所致，冬月不保。又问：宿迁边合战，安堵否？
    余曰：贼符加干支，冬月必有兵警……后四事皆验。"
  问题: |
    一课四问：陆庠友占考试；史抚台升凤督能否赴任；女病吉凶；宿迁边合战安堵否。
  课盘关键信息: |
    壬午五月丙戌日己丑时。不备、知一、度厄。三传子（蛇鬼）→未（常）→寅（六）。
    四课中有两课相同（丙寄巳宫，第一课丙上子、第四课巳上子），为辰阴不备；
    三上克下取子为用（知一/比用课，子与日干俱阳相比）；三上克下谓之幼度厄。
    驿马申坐丑上入墓；干神归支（丙寄巳宫加支上）。
  断法使用: |
    ①占考试分两段：院试——中传小吉乘太常为"禀"、末传长生学堂，有"禀"（皇粮）之象，
    故院试可取；省试——一重课体二重类神，三传递克是有人扯后腿压制（非三传递生有人说话），
    蛇鬼临干发用主恶事缠绕，子为岁破即省试主考官今作蛇鬼，明明无望；中末空亡亦先利后不利。
    ②占升迁：驿马坐墓 + 干神归支（支为家）= 在家不动静象；干神归支又须辨支神与干神关系
    （支克干则居不住、被支脱墓则心力交瘁）；禄为薪水、日禄归支则禄属他人、有人代替他去；
    问动象看驿马，驿马三怕（怕坐长生/坐墓/被地盘合），缚足恋厩有等于无。
    ③占病：占病四维=病因/症候/医药/生死。病因看虎鬼（白虎乘神所克五行、日鬼五行、日支
    脱耗之气）——日鬼离干最近且发用、又是太岁气势汹汹，白虎不上课传、脱气仅见中传，
    故以日鬼为断；日鬼子为丙之胎神、蛇为胎产类神、支为病体、血支临支（原书说血忌实为血支），
    故断胎产所致。症候：课体象人体，不备主气虚力弱；火受克为血病；中末空亡新病好、久病死。
    生死：太岁当头克干、长生入墓、生气全无，冬水旺故断冬月死。
    ④兵占：看贼符（子卯巳申）、游都鲁都、天乙贵人、日鬼，课传中谁的力大；干为攻、支为守，
    干阳神=攻方大将、干阴神=攻方部属、支上两课=守方大将部属；以发用为敌方、末传为守方，
    发用生末传 + 中传制初传 → 敌攻不破城；干上乘蛇=敌惊恐自逃。
  结论: |
    院试必取、省试不遂；史抚台不能赴升（在家不动）；女病因胎产所致、冬月不保；
    冬月有兵警但来兵败退、城无破患。
  事后反馈: 后四事皆验。
  教学点: |
    ①一课可多占，主次类神分占各断；②干神归支是静象但须进一步看支克干（居不住）、
    支脱墓（心力交瘁）之别；③驿马三怕是查"动象"的快速清单；④占病病因取
    "上卦传且力量最强"者（虎鬼/日鬼/脱气三选一），此课日鬼最强故舍白虎；⑤兵占攻守
    定位法：干支上下两课分主攻守双方大将与部属，以传中谁力大为断。
  bound_to:
    - "占病四维（病因/症候/生死）"
    - "动象三查：驿马三怕 / 干神归支"
    - "兵占攻守定位 / 贼符"
  outcome: 后四事皆验。

- id: z02
  title: 占功名 + 钦召应期（己亥日辛未时）
  type: case
  source_chapter: 问答录三
  source_quote: |
    "断曰：龙神发用，传课结成官局，来意必占今年功名事。六月即有钦召之应。
    盖春得进旺之木，遇夏则枝叶茂密，将来事业远大。问：六月之说何也？
    缘岁建皇恩发用，中传天诏，是以六月定有佳音。"
  问题: 两客进坐索占，未知来意；断来意 + 官运 + 应期。
  课盘关键信息: |
    癸未正月己亥日辛未时。涉害、曲直、回环。三传未（青龙）→亥（蛇）→卯（玄），
    传课结成木局（曲直）；三传都在四课为回环课。太岁未作青龙发用，未又为占时；
    中传天诏亥；天诏亥加于未上，未为皇恩又是太岁。
  断法使用: |
    ①断来意：太岁作龙神发用，太岁为天子、青龙为官职、未又为占时——
    "先贤时察来情，端倪无不显露"；传将结成木局，旺则吉衰则凶；是官非鬼，故知必占功名事。
    ②断应期：六壬定应期很重视地盘，多以类神临处为断——天诏亥加于未上主六月有圣旨前来；
    未为皇恩又是太岁，显象明了，不必再寻地盘卯。③断前程：春得进旺之木，遇夏则枝叶茂密，
    将来事业远大。
  结论: 来意必占今年功名事；六月即有钦召之应；将来事业远大。
  事后反馈: 来占者即赵忻城昆弟，果于是月奉诏进京授京营提督，甲申又升京营戎政。
  教学点: |
    ①涉害课古法以克多者为用，但陈公献以孟仲季上神取用、不论涉害深浅（此为陈氏独特取用法）；
    ②回环课=三传都在四课；③应期以"类神临地盘"为断，皇恩/太岁等显象叠加更确。
  bound_to:
    - "来意占（太岁龙神）"
    - "应期法则：类神临地盘"
    - "课体界定：涉害 / 曲直 / 回环"
  outcome: 果于是月奉诏进京授京营提督，甲申又升京营戎政。
  tags: [case, divination, career, timing]

- id: z03
  title: 占生产六甲：生男生女 + 产期 + 是否足月（癸卯日戊午时）
  type: case
  source_chapter: 问答录四
  source_quote: |
    "曰：时为日之胎神，必为六甲占也。余曰：然，男乎？抑女也？曰：干上卯属震，长男之象。
    又是幕贵，三传四课纯阴极阳，生贵儿必矣。且支加干，仰首见子，生必顺利。
    但四课不备，未能足月。生于何时？曰：六月生。果一一如所断。"
  问题: 访徽州戴羲占课（戴义先断来意，陈公献续断）；问生产、生男生女、产期、是否足月。
  课盘关键信息: |
    甲子四月癸卯日戊午时。蒿矢、不备。三传未（朱雀）→酉（勾）→亥（空）。
    干上卯（属震长男之象，又为幕贵）；支为家，上见巳火太乙（胎产类神、又是支之子孙）；
    干支皆乘子孙；时午为日干癸之胎财。四课不备。未土发用，在月建巳前二辰。
  断法使用: |
    ①断来意：时午为日之胎神，《毕法》"胎财生气妻怀孕"，午是胎财但不是生气；干上子孙爻
    示想问子孙事；支上巳太乙为胎产类神又是支之子孙，干支皆乘子孙，各面结合断为胎产占。
    ②断男女：三法并观——课体（纯阴反阳生男）、干上神与干比（卯与癸比）、干上卯属震为长子；
    另有课体通则：元首生男、重审生女、纯阳反阴生女、阳不备生女、阴不备生男，干上酉兑为少女主生女；
    《金口诀》"欲占孕育课中求，太乙常加本命头，阳将为男阴是女，更看生克定因由"亦极验。
    ③断顺产/足月：支为产妇、干为胎儿，干支互临而生合主母子相恋主难产；但支加干上=产妇
    低头看到孩子=已生下来之象，主生产顺利；不备主气数弱，占产主不足月而早产。
    ④断产期：应期法则——太岁发用应一年内、月建一月内、日辰当日、时发用当时；
    发用在岁月日时之前三神则应在发用之神当令之时；未土发用，在月建巳前二辰，
    仍在"前三辰"范围内，故断六月生。
    ⑤断贵儿：干上卯为震长子、为幕贵，阴神又见财德贵马，故曰贵儿；但财德贵马空亡，
    贵也不久（北海闲人评此断"有点圆滑"）。
  结论: 来意为六甲（生产）占；生男、贵儿；生产顺利但不足月；六月生。
  事后反馈: 果一一如所断；细看子冲胎神、子上见寅，子日寅时生。
  教学点: |
    ①孕占与产占是两种占法；②生男生女多法并观（课体+干上神+胎神），陈公献重课体与干上神；
    ③"不备"一象随事类转义（占病主虚、占产主早产）；④应期"前三辰法则"与
    太岁/月建/日辰/时发用的框架法；⑤"贵儿"之类定性附会辞须谨慎（北海闲人示范批判性阅读）。
  bound_to:
    - "占生产六甲 / 生男生女课体法"
    - "应期法则：发用加岁月日时 / 前三辰法则"
    - "来意占：时作胎神"
  outcome: 果生（六月，子日寅时），一一如所断。
  tags: [case, divination, childbirth, gender, timing]

- id: z04
  title: 占妇人病：胸膈饮食 + 必死应期（辛亥日甲午时）
  type: case
  source_chapter: 问答录五
  source_quote: |
    "断曰：公为阴人占病。主胸膈不宽，饮食少进。曰：果妇病，若何？传得病玄胎，
    又四课德鬼发用，巳作闭口，食神乘空，依知病在胸膈，不能饮食。且禄临绝地，何以养生？
    目今子支制鬼无妨，恐来年初夏太岁生鬼可虑；况夫占妻岂宜财空，主半路断弦续娶也。"
  问题: 王养吾索占；断是否妇女病、病位与饮食、生死、应期、以及夫占妻之财空象。
  课盘关键信息: |
    乙丑十月辛亥日甲午时。元首、玄胎。三传巳（蛇鬼）→寅（勾）→亥（白虎），为病玄胎。
    四课德鬼发用（巳作闭口）；食神乘空；禄神酉临绝地；巳为驿马但临地盘申被合；
    干上天后遁丁鬼克辛金；末传白虎克蛇。中末空亡。
  断法使用: |
    ①断"为阴人占病"：三传病玄胎主病症；日鬼发用乘蛇主惊恐不安；干上天后遁丁鬼
    （《毕法》"金日逢丁凶祸动，要详丁神之六亲天将分而言之"），未为坤、本身代表中年以上妇女，
    乘天后更有妇人之象，天后乘丁来克辛金→正为女人事烦恼；支上太阴其阴神巳火克合太阴且
    发用乘蛇，末传白虎又克蛇，蛇亦妇女类神→断定是妇女问题；巳为驿马但被地盘申合，
    不能断逃跑（动象三查）。
    ②断胸膈不宽饮食少进：占病症类神=白虎/日鬼/脱气看谁最鲜明——日鬼发用乘凶将最明显，
    白虎落空故不以白虎断；巳主气乘蛇主气不顺；食神主食欲、财主饮食，今亥落空、寅卯空亡，
    故断饮食难进。
    ③断必死：占病四大忌——马星（魂游千里）、玄胎课（别处投胎）、三传传空（无活路）、
    日鬼太旺（病重难医）；兼看禄神（"不禄"代表死亡）。此课发用即马星（虽被地盘申合总是不吉）、
    干上旬丁主动、三传病玄胎且中末空亡、日鬼发用病势沉重→病者必死。
    ④断应期：占病死一般断在长生/墓/绝，但陈公献此课用"鬼旺之时"（来年初夏太岁生鬼），
    说明应期断法灵活。
  结论: 为妇女占病；胸膈不宽、饮食难进；必死；来年初夏为险关；夫占妻财空主半路断弦续娶；
    辛日不宜占病（辛作亡神）。
  事后反馈: 原文未记反馈，但断"必死"应期详明（来年初夏）。
  教学点: |
    ①占病四维（病因/症候/生死/应期）+ 病症类神"谁最鲜明"取舍法；②占病必死四忌
    （马星/玄胎/传空/鬼旺）是生死判的快速清单；③应期既可看长生墓绝也可看鬼旺之时——
    方法随课灵活；④"不禄"是古占死亡之代语；⑤金日逢丁主凶祸动，须详丁神六亲天将。
  bound_to:
    - "占病四维 / 必死四忌 / 病玄胎"
    - "应期法则：鬼旺之时"

- id: z05
  title: 僧占泛泛：阴人缠扰 + 攻讦 + 去而复来（丙寅日庚寅时）
  type: case
  source_chapter: 问答录六
  source_quote: |
    "神后蛇鬼临干发用，必有阴人往来缠扰。僧默然久之，曰：凶吉若何？曰：干支首尾相见，
    一时不能拆离；且河魁加卯命，驿马临行年，必有相携而逃之意。然而传将互克，
    提防有人攻讦事。"
  问题: 僧人丽天未言所占何事，泛泛而占断其"最紧急的事"。
  课盘关键信息: |
    丙寅四月丙寅日庚寅时。涉害、周遍。三传子（蛇鬼）→未（常）→寅（六）。
    三下克下为度厄（此课三传上干下俱受克，干支皆受克，干上明鬼、支上遁癸暗鬼）。
    丙寅属甲子旬，子为旬首、酉为旬尾——干上旬首、支上旬尾（首尾相见）；
    和尚卯年生，本命河魁戌；驿马加行年丑上。
  断法使用: |
    ①泛泛而占断来意：先从课体看——三下克下是度厄，主有外来灾难（《毕法补谭》
    "彼此全伤防两损""明生暗克最支离"，此课干支都受克，干上明鬼、支上遁癸暗鬼），
    当前运气很差；三传"三传递克众人欺"很凶。干上子水鬼乘蛇克身——子为神后为妇人、
    蛇为轻薄绕舌女人、又为缠绕之神；宅上酉为少女/婢女/妓女，干支互乘败气→因不正当男女
    关系被对方缠上；和尚居所本应纯阳、应多见天空空亡之类，今见从魁（酉）大不合理。
    ②断"一时不能拆离"：干支首尾相见（《毕法》"首尾相见始终宜"），无空亡则吉凶事皆成就。
    ③断逃跑之意：河魁动神，凡魁罡加临日干年命，动者静而静者动；和尚卯年本命河魁，
    戌收万物入地狱主处困境想逃跑；河魁天涯海角、魁居卯是动身居门上；驿马加行年丑上，
    年命上皆动神→必有相携而逃之意。
    ④断攻讦：三传递克主丽天为人不谨慎或多行坏事、众口指责；子为丙之胎神、酉为寅之胎神
    又是日财又是月内死气——"胎气死气损胎推"，可能女方有孕、丑名远扬。
    ⑤断去而复来：一旬周遍格，《毕法》"交加用事，去而复来"；此课自干上发用、末传是支神，
    虽非回环格但回归到支（宅），还要回来一次；末传又作六合，是又在一起。
  结论: 有阴人往来缠扰；长时间拆不开；和尚有相携而逃之意；有人攻讦。
