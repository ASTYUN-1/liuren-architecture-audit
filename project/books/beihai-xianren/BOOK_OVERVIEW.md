## 1. 结构 (Structural)

### 类型
实操手册 / 传统术数（大六壬）实战判断方法论。非入门书，假设读者已掌握起课、九宗门、十二天将等基础知识，本书专讲"怎么断"。

### 一句话主旨
教学习者用"**明占类 → 定侧重 → 看显象**"三步走，以**类神**或**课体**为判断主线，通过辨析课传中的**象、动、凶煞**，完成对人事的准确占断。

### 骨架 (主要论点及其关系)

1. **三步断课法**（第一讲）：明占类（结果分三类：能否成 / 能否出现 / 向何方向发展）→ 定侧重 → 看显象（辨析真假）。
2. **判断侧重点只有两个**（第一、二讲）：**类神**（代表某人某物某类象的干支神将）或**课体**（课传整体结构）。类神现于课传又得吉气则事成；找不到类神就看课体大势。
3. **象的动态化——"有路"理论**（第三讲）：类象被引动才显象明确。凡合（三合/六合/遁干五合）、刑、冲、破、害皆为"有路"；研究课传中的"动"是判断深入的关键。
4. **凶煞优先断法**（第四讲）：凶比吉更易识别，先找到一个"凶"的充分理由，非吉即凶。四大凶煞：**旬丁**（动变）、**白虎**（死丧病伤）、**勾陈**（迟滞官司）、**天空**（空亡风波）。
5. **分类占断六大门类**（第五~十讲）：时运、收入财运、人际关系、应聘与工作、升职加薪、恋爱——每类给出取类神原则与忌讳。
6. **应期断法**（第十一讲）：先定迟速、再定日期；天将变化法（《心印赋》十二天将居位判辞）+ 五行法，两线定一点。

**论点之间的关系**: 递进 + 应用并列。1→2→3 是核心方法论递进（主线确立→象的解读→动的深化），4 是辅助速断工具，5 是方法论在六大领域的平行应用，6 是收尾（时间维度）。

### 作者要解决的核心问题
"一个课拿到手里，该从什么角度入断？"—— 困扰大六壬学习者最大的问题，即把浩瀚的壬学知识收敛成一条可操作、可复用的判断主线。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 占类 | 所占之事追求的结果类型：①某事能否成 ②某人事物能否出现 ③某人事物向何方发展 | 非"占卜分类学"，是"结果导向"的分类 |
| 侧重点 | 断课主线，全书只有两类：类神 / 课体 | 以简驭繁的核心，反对逐项硬套课经 |
| 类神 | 代表某类人事物象的干支神将组合（如亥午卯丑勾=房产田产） | 有具体取象来源系统（九大类象系统） |
| 课体 | 课传整体结构特征（九宗门起课名 + 毕法赋格局，如登天课、凝阴课、天网课、解离格） | 作者强调《毕法赋》的课传结构也是课体重要内容，不能只盯《课经》 |
| 有路 | 类象被引动的方式：合（三合/六合/遁干五合）、刑、冲、破、害，以及类象与其天盘、落宫之间 | 陈公献只说"合处为来之路"，作者扩展为六种 |
| 空亡 | 类神空陷则事不确定；旺不为空、得生得助不为空 | 空亡不是一律凶，要辨旺衰与是否得住 |
| 变质 | 类神乘凶将（如日禄乘玄武作闭口则禄难到手；财乘破碎煞则耗钱） | 类神"变形"，吉象转凶 |
| 凶煞 | 旬丁（动摇）、白虎（死丧）、勾陈（迟滞/斗讼争官）、天空（空亡/平地风波） | 从"对人"（病伤惊忧）与"对事"（拖拉失败移易）两角度讲 |
| 年命 | 本命 + 行年；年命入课传看本身，不入课传看年命之上神 | 终身课/年运课的关键抓手 |
| 三限 | 三传（初/中/末）代表人生初中末三限，天将代表该限运势特征 | 终身课结构法 |
| 天将变化法 | 用《心印赋》十二天将居十二位判辞断应期：找关键点天将在何时空达到事情发展的要求 | 判辞不仅是判断依据，更是应期法则 |

### 核心命题 (用自己的话)

1. 断课不需要背烂所有课经，三步走 + 两侧重即可覆盖绝大多数情况。
2. 能取类神的看类神，取不到类神的看课体大势——这是壬课判断的不二法门。
3. 占课以入课传为重，不入课传为轻；课上传上的象明晰则据此断。
4. 类神现于课传 + 不空陷 + 不变质 ⇒ 事必成；空陷或变质 ⇒ 事向反面。
5. 空亡的辨别：旺不为空，得生得助不为空。
6. 象动则显象明确；"有路"方式共六种，被引动的类象力量强、判断准。
7. 凶煞优先：先找到一个凶的充分理由，就否定了吉的一面，是"偷懒却极有效"的法子。
8. 时运课 = 综合课：安全看吉凶二象，收入看父/禄，婚姻看六合太常天后青龙，官运看贵龙常作父母长生，家运看支上。
9. 收入看禄与父母爻（旺相不空陷不乘蛇虎玄空不作闭口不乘丁神不落墓地为全吉）；纯财看财爻或龙/虎/阴；三传全财大凶。
10. 人际关系以日干为自己：生、合、德为对我有利；刑、克、穿、鬼为对我不利；看某人态度看其类神对日干/干上神/年命上神的损益。
11. 应聘看禄、父母、长生（职位类神）现于课传且吉旺不空陷则必得；课传生合吉旺、龙常贵合并聚亦可成。
12. 升职要有"进达之象"（旺气吉神据要位），加薪要有"增益之象"（生气/金钱类象旺相）。
13. 恋爱常法看干支上神生合则成、冲克刑害则散；变法看类象组合与年命倒置；琐象（四课不备三角关系、课中勾陈鬼等）准验度高。
14. 应期没有固定模式，方法越多越准；**必须先定迟速，再定具体日期**。
15. 一课之中，既显示整体的、长久的信息，又显示当前的、主要的近事（干上神代表当前状态）。

### 论证链
作者用**大量实战案例逐一演示**：每股/每房/每事先"明占类"，再选侧重点，再拆解干支上神、三传、阴神、年命、天将的叠加，落到具体结论并附事后反馈（"果应""果于X月X日"）。理论主张都由课例支撑，形成"法则→课例→反馈"的循环。核心的"有路""空亡辨""凶煞优先"等都是通过案例中的灵验时刻反推提炼。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 案例集中于 2004–2009 年（股市、房价、人民币升值、2008 金融危机），经济事件语境已过时；但方法论本身不依赖时代。
- 依赖具体历法操作（月将加时起课），对不了解干支历法体系的现代读者门槛高。
- 反馈多是占者自述，时间跨度短（多为数月），缺乏长周期检验。

### 作者的立场盲点
- **占者视角只呈现"验"的案例**：全书 30+ 例全部"果应"，未呈现一例断错或存疑的课——存在严重幸存者偏差，读者无法估计真实命中率。
- **同一课可多解**：书中多次"以课体为侧重也可，以类神为侧重也可"，判断存在较大解释自由度，却未讨论这种自由度本身的风险。
- **隐含信仰前提**：天干地支、五行生克、神将象意与人事之间存在客观映射——这被当作不言自明，从未论证。

### 未被证明的假设
- "课传显示什么，就是所遇之事"的对应关系稳定且唯一。
- 神将象意（如六合=添人口、天后=女子）是普适常量，不随文化/个体变动。
- 事后"应验"（果应）= 判断正确（存在记忆偏差与事后合理化）。

### 最强反对意见
大六壬的象意系统高度模糊且组合自由度极大（干支×天将×位×阴神×年命…），同一课几乎总能事后自圆其说；而书中全部案例都是"断前立论、断后应验"的叙事，无对照、无盲测、无统计。若严格检验（预注册占断 + 大量样本统计），命中率未必显著高于随机——这套方法要成立，必须先回应可证伪性问题。
