# 三步断课法（明占类→定侧重→看显象）

## R — 原文 (Reading)

> 最简捷的断课方法，应该是"三步走"：明占类，定侧重，看显象。……无外乎如下三种：1、某事能否成；2、某人事物能否出现；3、某人事物会向哪个方向发展。……判断的侧重点则只有两个：1、类神。2、课体。……确定了侧重点之后，要仔细辨析类神和课体的真假，这就是"看显象"。类神现于课传而不空陷，不变质，则其事必成。
>
> — 北海闲人，《北海的六壬特训班讲义》第一讲
>
> **《大六壬指南》问答录（扩展）**
>
> "看课要抓主线，上述因素是有的，比起上述几个因素来，力量相对来说小些，可以忽略不计。反过来说，他们确实也起了作用……但主次因素的取舍一定要分清。"
> "断课的时候不能只看课体，还应该看一看类神，而且一定要看阴神。""但这个救解是局部，并不能改变课凶的总体趋势。"
>
> — 北海闲人, 问答录七 / 问答录九
>
> "陈公献只好用泛泛而占的方法来推断一下他当前'最紧急的事'，这就要从课体上来看了。"
> "壬占灵活，不可拘泥。这一课盗象比较明显，因为人宅受脱俱招盗。"
>
> — 北海闲人, 问答录六 / 问答录十一

## I — 方法论骨架 (Interpretation)

- **面对的问题**：一卦（一课）拿到手，该从什么角度入断——这是全书要解决的核心问题。
- **怎么判断**：
  1. **明占类**：先把用户的问话转成"结果导向"分类——①某事能否成（成败二元）；②某人事物能否出现（存现问题）；③某人事物向何方发展（方向/趋势）。先归好类，后面的主线才选得对。
  2. **定侧重**：从仅有的两条主线里选一条——**类神**（能取到代表该事物的干支神将组合）或**课体**（整体结构）。以"入课传为重、不入课传为轻"加权；课上传上象明晰则依它断。
  3. **看显象**：对所选主线的象做真假校验——空亡辨旺衰与得助、类神辨是否变质（乘凶将/闭口/破碎/阴神见鬼），排除假象后定最终结论。
- **产出**：一条"占类标签 → 主线选择 → 真假校验"的完整结论链，每步有依据可查，置信度可标注。

### 断课三看与主次取舍（《大六壬指南》问答录扩展）

- **看课抓主线、主次取舍**：一课吉凶混杂时，先定课体大势（方向与正误），主因素定结论、次因素只微调——"力量相对来说小些，可以忽略不计，但主次因素的取舍一定要分清"（问答录七会试例：三传合局泄干气、贵人坐墓不影响中甲）。
- **课体大势 > 类神细节**：顾祖例中龙神发用得生助看似利官，遇特殊课体（顾祖/干支皆败/龙化蛇）此象舍弃——"课体大势的作用远远大于类神的作用"（问答录八）。
- **断课三看**：①课体定大势 ②类神定人事 ③**一定要看阴神**——朱雀乘戌不生不克，唯阴神巳火为驿马旬丁且生日，故断"好旨归里"而非下狱（问答录九）。阴神是第三层不可省略。
- **救解局部性**：有救解（如阴神生日、天将吉）≠改总凶——救解只减轻局部、决定"降几级"（降罚而不极刑），不改变课凶总趋势（问答录九）。

### 来意占（《大六壬指南》问答录扩展）

- **正时断来意**：以正时/占时及其所临类神定所问——时逢日之胎神断六甲、太岁作青龙发用断功名、正时之象（文书/禄）合天将（天空=章奏）断章奏（问答录三/四/九）。
- **断六甲多象共振**：占时胎神＋干支皆乘子孙＋太乙胎产类神，多象结合勿凭单象（问答录四）。
- **干上主思、支上主行**：干上神=所思所关注、支上神=所见所作为，断来意先分干支（问答录四）。
- **泛占断紧事**：来意不明时从课体看当前最紧急的事——课体定类（度厄=外来灾）→干支乘神定象（干上子水鬼乘蛇=阴人缠绕、宅上酉=不正当男女关系）→落点成事（问答录六僧占）。
- **非占现类勿言之例外**：默认"非占现类勿言之"，但课象明显（人宅受脱俱招盗、玄武发用传归支上、衰土难担旺财）时可越占断之——"壬占灵活，不可拘泥"，此为有据的灵活而非随意发挥（问答录十一）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占鹏博士股票次日走势（c01）
- **问题**: 占个股次日走势，属"某人事物会向哪个方向发展"。
- **方法论的使用**: 明占类为方向类→定侧重为课体气势+五行特质；看显象：四课不备+六阴相继尽昏迷=徘徊低迷；干支各被上神克=《毕法》"彼此全伤防两损"；三传木局逢白虎=谣言四起、动摇不定，支亥被克价必落。
- **结论**: 股必降。
- **结果**: 次日降 7%，日最高降幅 8.78%。

### 案例 2: 占单位分房（c02）
- **问题**: 占分房能否分到，属"某人事物能否出现"。
- **方法论的使用**: 定侧重为房屋类象（亥为楼阁、午厅堂、卯房宿、丑/勾田产）；看显象：亥现于干上=到手之象，但亥为旬空→"不确定"，须结合它象（旺衰/得助）；返吟主反复、玄六重逢主暗箱操作、绝上加绝主不很满意。
- **结论**: 房必得，但过程反复、结果不甚满意。
- **结果**: 亥月末事果应（分到房）。

### 案例 3: 占人民币升值前景（c05）
- **问题**: 占宏观货币政策走向，属"某人事物会向哪个方向发展"。
- **方法论的使用**: 定侧重为课体大势+类象组合；看显象：初传蛇末传龙=蛇化为龙由小变大、初空末实→升值必然；干上白虎=政策有变、支上午蛇=民众摇惑；太岁酉作太阴+酉加亥=太岁登天门本年必行权。
- **结论**: 升值必然。
- **结果**: 2005 年 7 月 21 日央行公告美元兑人民币调整为 1:8.11。

### 案例 4: 占会试中甲·主次取舍（问答录七，z06）
- **问题**: 占长兄公明进京会试能否考中。
- **方法论的使用**: 主次取舍——河魁作旬首临干发用=必取居榜首、三传递生=贵人推荐、三传都在四课=回环格吉凶皆成、贵登天门四大吉象为主；三传合局泄干气、贵人为日干之墓为次，力量小可忽略不计——"但主次因素的取舍一定要分清"。
- **结论**: 联捷而去，中甲无疑。
- **结果**: 放榜时果中三十九名（一甲）。

### 案例 5: 占章奏上书·断课三看（问答录九，z08）
- **问题**: 占上书吉凶、旨意。
- **方法论的使用**: 断课三看——课体无禄无路大凶；类神朱雀乘戌与日干不生不克；**阴神巳火为驿马、又是旬丁、而且生日**→断"好旨归里"而非下狱。有救解（阴神生日）但救解是局部的，不改变无禄课总凶（"不是极凶的课，因为还有救解。但这个救解是局部，并不能改变课凶的总体趋势"）。
- **结论**: 章奏占；主降罚削权、宜急流勇退；上书得好旨归里。
- **结果**: 后唯冠带闲住，回家未久仙游（死）。

### 案例 6: 僧占泛泛·泛占断紧事（问答录六，z05）
- **问题**: 僧人未言所占何事，泛泛而占断其"最紧急的事"。
- **方法论的使用**: 泛占断紧事——课体定类：三下克下度厄主外来灾、三传递克众人欺；干支乘神定象：干上子水鬼乘蛇=阴人缠绕（神后妇人+蛇缠绕）、宅上酉=少女/不正当男女关系、干支互乘败气=败坏之事；落点成事：因不正关系被缠上。
- **结论**: 有阴人往来缠扰、一时不能拆离；有相携而逃之意；有人攻讦。
- **结果**: 众施主送僧渡江，后复来扬携妇而去。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户对任何具体事项直接问占并要一个"成不成 / 有没有 / 往哪走"的结论（工作、财运、感情、健康、买房、考试、出行……）。
2. 用户给出一卦/一课/一个干支盘面，要求"看看怎么断"或"从哪入手"——需要先建判断框架。
3. AI 侧作为分析框架：在调用任何分类 skill（财禄、恋爱、应聘等）之前，先用本 skill 定占类、定主线、过真假闸。
4. 用户问"同一件事换种问法结论变不变"——三类结果导向分类能暴露问法对结论的影响。

### 语言信号 (用户的话里出现这些就应激活)

- "这件事能不能成？会不会成？" "能否/会不会/能不能成/能不能出现/will it work/will it happen"
- "我这段时间运势/运气怎么样？" "运势/运气/luck/fortune"

- 其余 14 个 skill：`leishen-keti`(类神/课体双侧重选择，本 skill 第 2 步的下钻)、`kongwang-bianzhi`(空亡与变质辨析，本 skill 第 3 步的真假闸)、`youlu-lilun`(类象之动·有路理论，静态盘面的动态深化)、`xiongsha-suduan`(凶煞速断，否定式过滤前置)、`keti-qishi`(课体气势阅读法，课体主线的细节读法)、`shiyun-zonghe`(时运课综合断法，五维清单)、`cailu-panduan`(财禄判断，收入 vs 纯财)、`renji-guanxi`(人际关系判断，损益矩阵)、`yingpin-gongzuo`(应聘与工作判断，职位类神)、`shengzhi-jiaxin`(升职加薪判断，进达/增益象)、`lianai-panduan`(恋爱判断，常法/变法/琐象)、`yingqi-panduan`(应期判断，先迟速后日期)、`zhongshen-nianyun`(终身与年运课法，年命三限)、`jixiong-tiaozhi`(吉凶调制与缩放，四象限+大背景)。
- 与本 skill 的区分：本 skill 是**总入口流程**（三段式骨架），只做"归类与主线决策"，不做任何分类的细节判据；其余 skill 是某一环节或某类事项的**下钻实现**。若用户已明确是财运/恋爱/应聘等具体门类，可直接调用对应分类 skill；若问题泛化或跨门类，先走本 skill。

### 断课三看 / 来意占 触发场景（《大六壬指南》问答录扩展）

1. **一课吉凶混杂、因素多**——需要抓主线、分主次（先课体大势后类神细节），见"合局泄气/贵人坐墓"等小因素不推翻主结论。
2. **占者未明言所问**（"泛泛而占"/来意不明）——正时断来意（正时象义×天将×类神）或泛占断紧事（课体定类→干支乘神定象→落点成事）。
3. **盘面有救解但课体偏凶**——按"救解局部性"降级不改方向，不因一两个吉象改口吉断。
4. **断课需要精确到细节/方向**——三看（课体+类神+阴神）逐层采集，阴神补关键转折（如朱雀阴神驿马生日→好旨归里）。
5. **占病课却见明显盗象**（玄武发用、人宅受脱俱招盗）——判断可否越占断事（"非占现类勿言之"的例外触发）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明占类**：把用户问题转译为三类结果之一（能否成 / 能否出现 / 向何方发展），并写出占类标签。
   - 完成标准: 输出明确占类标签 + 一句"该问题要追求的结果是 X"。

2. **定侧重**：尝试为该事物取类神（见 `leishen-keti`）；取不到或属方向/大势类则选课体主线；按"入课传为重"加权主要信号。
   - 完成标准: 输出"主线=类神/课体"选择及 1-3 条入课传的关键信号。
   - **扩展子步骤（问答录三看与主次）**: 主线选定后做"断课三看"——①课体定大势 ②类神定人事 ③**一定要看阴神**补细节与方向；吉凶混杂时主因素定结论、次因素只微调（"主次因素的取舍一定要分清"）；有救解只降级、不改方向（救解局部性）。
   - 判停条件: 若盘面数据缺失（无干支/三传/天将）或占类含糊到无法归类，则跳到步骤 3 输出"需澄清"而不是硬断。

3. **看显象并出结论**：对主线象过空亡/变质校验（见 `kongwang-bianzhi`），排除假象后输出"成 / 不成 / 不确定+依据链"。
   - 完成标准: 结论含校验依据、置信度（高/中/低）与"若存疑则列明待证点"。
   - 判停条件: 校验命中"空陷或变质"时输出"向反面/待定"，不武断下"必成"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问干支历法、起课操作等纯技术问题（无判断目标）。
- 用户要的是精确到某月某日的应期——那属于 `yingqi-panduan`。
- 盘面关键信息缺失，连占类都无法归类时，先向用户澄清而不是硬断。

### 作者在书中警告的失败模式

- ce01（只盯课经忽略毕法）：选了课体主线却只翻《课经》九宗门课名，漏掉《毕法》干支上神结构（解离格、彼此全伤、交车相合等）→课体断错。**课体=九宗门大势+毕法格局两层。**
- ce13（同一课可多解）：书中多次"以类神为侧重也可、以课体为侧重也可"，同一课两条主线结论可以不同甚至相反——输出单一结论时必须声明"多解风险"。
- ce14（可证伪性）：象意系统组合自由度极大（干支×天将×位×阴神×年命），任何结果几乎总能事后自圆其说——把解释视为"假设"而非"验证"。
- ce12（幸存者偏差）：全书 30+ 例全部"果应"，无失败样本——案例个数≠命中率，不可把本书案例当统计证据。

### 《大六壬指南》问答录扩展失败模式（B 段追加）

- **ce10 救解局部性误判**：见课中有救解（日德、天喜、生合、天马）就把整体改为吉断，忽视课体凶局未变——"有救解为何还凶"是初学最典型误断；救解只能减轻灾祸、保住体面（好旨归里、只丢官无大咎），不能改变无禄无路/干支坐墓的总凶之势（问答录九）。
- **ce11 断课只看课体/只看类神，漏看阴神**：不查类神之阴神（上神），漏掉关键转折与应验方式——朱雀阴神巳火驿马生日→"好旨归里"；官德阴神子乘天空临齐之分野→至山东路阻（问答录九/十四）。
- **ce12 次因素喧宾夺主**：见一个凶点（合局泄气、贵人坐墓）就推翻多数吉象，或反之只见吉象忽略课体凶势——主次取舍不分明则断课方向反置（问答录七会试例）。
- **ce13 只见一象、不与多象互证**：只凭单一象义（虎马发用、一个神煞）就下结论——张官德"物以类聚方以群分"主张多象共观，单象须以多象印证（问答录十二）。
- **ce30 "非占现类勿言之"两极端**：拘泥"非占现类勿言之"漏断明显之象；或无视事类随意断他事（把"灵活"当随意）——只有外显之象有明确类神依据（玄武发用、人宅受脱、传归宅上）时才可越占（问答录十一）。
