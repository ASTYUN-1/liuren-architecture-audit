# 财禄判断（收入 vs 纯财）

> **组成单元** (verified.md S08): p19 收入全吉六条件 / p20 纯财类神 / p21 财局大忌 / p22 传递象 / p23 贵人差迭 / g17 脱气 / g18 闭口 / g19 破碎煞 / f19 大背景缩放

## R — 原文 (Reading)

> 占收入、利润，均以禄或父母类神，要禄或父母爻旺相不空陷，不乘蛇虎玄空，不作闭口，不乘丁神，不落墓地，方为全吉。……占纯"钱"，则以财爻或龙、虎、阴为类神……财怕空，有钱财消失之象；怕破碎煞……占财，最怕三传合财局生干支、年命上之鬼，主因财致祸。……脱气为求财最忌，占薪占利占钱，课传中俱为凶象。
>
> — 北海闲人，第六讲《收入和财运》

---

## I — 方法论骨架 (Interpretation)

用户说"财运"时，必须先拆成两类：**收入**（薪水/固定进账）与**纯财**（薪水之外的钱）。类神完全不同，混淆即误断。

1. 收入判据（六条件全过才全吉）：禄或父母爻旺相、不空陷、不乘蛇虎玄空、不作闭口、不乘丁神、不落墓地。任一不过=该维度缺陷（如禄作闭口=看得见拿不着，见 g18）。
2. 纯财判据：财爻或龙、虎、阴为类神（龙=财喜，虎/阴属金=金银金融）。
3. 纯财三忌：财怕空（消失之象）、怕乘破碎煞（拆分用光）、三传全财（大凶——克伤生气，身体与收入双困）。
4. 因财致祸：三传合财局而生干支、年命上之鬼→得财但致伤病祸事；玄武乘财=财耗、乘鬼=既有灾又损财。
5. 脱气最忌（g17）：占薪/利/钱凡见脱气俱凶；脱气乘玄/乘空=脱耗格/脱空格→钱财耗尽。
6. 不见财爻也可断钱（p22 传递象）：干支互传、干支相加=传递之象（欲得者得、欲出者出）；申为传送、卯为帐目，申卯相加或申作六合=帐目划拨之象，空亦不忌（帐目非现金、空来空去）。
7. 大背景缩放（f19/p23）：贵人差迭、二贵受克时"若有凶象则凶大、若有吉象则吉小"——先定大背景，再对单象打折（案例 c21）。
8. 产出：收入结论 + 纯财结论 + 风险清单（每条标注判据缺陷）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占最近有无额外收入 (c18)
- **问题**: 某占最近有无额外收入——薪水之外，属纯财。
- **方法论的使用**: 取财爻为类神；未、戌二财皆空（财怕空的变通情形），但课传结构从干课传到支上=自外而内之传递象（申传送、卯帐目，申卯相加=帐目划拨，空亦不忌，因帐目非现金、空来空去）→不以凶论。
- **结论**: 有额外收入，取象为帐目划拨式外快。
- **结果**: 后乙丑日果有外快若干（数目未透露）。

### 案例 2: 职员问 08 年经济状况 (c19)
- **问题**: 职员问一年经济——既看薪水（收入），又看外快（纯财）。
- **方法论的使用**: 收入维：禄临长生→不至丢工作、收入尚称稳定；纯财维：三传木局为日鬼=作鬼枷锢格，如兽在笼中只能守当前→外快无；干加支被支克=自取乱首，亥财作蛇=收入不稳之象。
- **结论**: 一年仅靠薪水，外快无，收入稳定但难以多论。
- **结果**: 果然 08 年仅靠薪水，因单位效益变化薪水上下波动；想的求财门路都因迟疑未做。

### 案例 3: 农村打零工问 08 年财运 (c20)
- **问题**: 打零工者问纯财运（薪水之外的钱）。
- **方法论的使用**: 安全前置：太岁作蛇鬼落辰地=鬼临鬼地事放怀→小麻烦一堆（妻弱智、新生子）；干上父母爻作勾陈→生活磕绊，幸卯带亥贵收入尚有；天空发用作巳=铸印（打工），落空=干一阵歇一阵；天空之阴神朱雀脱气=无意识无计划、花钱大手大脚（脱气最忌的实证）；末传财作太阴=钱财隐而不见。
- **结论**: 身无余钱、过得郁闷，但无大灾。
- **结果**: 年底来报果然身无余钱，过年还借了几百元。

> 附 c21（问几年财运）演示大背景缩放：昼贵子临戌夜地、夜贵申临昼地午=贵人差迭，申受午克、子受戌克=二贵受克→计划多不能成；此大背景下"吉象则吉小、凶象则凶大"，坏运势一直到 08 年。三年中屡屡借钱投资、收入平平、08 年负债压力很大。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分类目标**
   - 完成标准: 已把问题映射到"收入"（薪水/固定进账→禄/父母爻）或"纯财"（薪水之外→财爻/龙虎阴），或两者都要；并确定时间尺度（短期/一年/数年）。
   - 判停条件: 若问题是泛"综合时运"，停止本 skill，返回 `shiyun-zonghe` 走五维，不要在此硬断。

2. **收入六条件 + 纯财三忌双线校验**
   - 完成标准: 收入线——禄/父母爻逐条过六条件（旺相不空陷、不乘蛇虎玄空、不作闭口、不乘丁神、不落墓地），列出缺陷项；纯财线——查财爻空亡、破碎煞、三传全财、财局生鬼、玄武乘财乘鬼、脱气（尤忌乘玄/乘空）。输出两条各自判据清单，每项标 ✓/✗ 及课传依据。
   - 判停条件: 若见脱气乘玄/乘空（脱耗格/脱空格）或三传全财，直接定"钱难守/收入困"，停止继续找吉象，转 B 段核对是否误断（防 ce10）。

3. **传递象与大背景收尾**
   - 完成标准: 检查干支互传/干支相加/申卯相加（帐目划拨）等传递象补位；再用大背景（贵人差迭/二贵受克）对全课吉凶打折（吉小凶大）。输出"收入结论 + 纯财结论 + 风险清单"，每条结论有判据链。
   - 判停条件: 若盘面无课传，止步于生成收入/纯财两类问题的澄清清单，不作断言。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问综合运势（五维中含收入维即可，不必细走六条件）→ `shiyun-zonghe`。
- 问"能否升职/加薪名额/职位"→ 职位仕途判定（`shengzhi-jiaxin`），本 skill 只管钱。
- 无课传盘面、只有笼统"我想发财"→ 无法取类神，只能澄清+建议具体问题。

### 作者在书中警告的失败模式

- ce10（财运忌讳，全条）：见财爻现课传就断得财，忽略①脱气（尤忌乘玄/乘空=脱耗格/脱空格，主钱财耗尽）②财怕空（消失之象）③财怕破碎煞（拆分用光）④三传全财大凶（克伤生气，身体与收入双困）⑤三传财局生干支年命之鬼=因财致祸⑥玄武乘财=财耗、乘鬼=既有灾又损财⑦父母爻作白虎/螣蛇/勾陈=见生不生不如无生⑧贵人差迭/二贵受克大背景下"吉小凶大"。
- 收入/纯财类神混用：把禄/父母爻拿去断纯财、把财爻拿去断薪水，得出错误结论。
- ce12-ce15（公共边界）：全书案例全部"果应"=幸存者偏差（且 c20"年底来报"等均为占者自述）；同一课可多解；象意系统模糊、无预注册检验；干支五行映射人事是未论证的信仰前提。

### 作者的盲点 / 时代局限

- 全书"财运"案例集中于 2008 金融危机前后，收益语境过时；但"薪水≠财运"的分类、脱气/破碎/三传全财大忌不依赖时代。
- 帐目划拨（申卯相加）是 2000 年代末的新象，作者自称"当今帐目划拨已非常普遍"——此映射是否普适常量未论证（ce15）。
- 负债、亏损等负面结果的呈报是否完整不可知，无法估计真实命中率（ce12）。

### 容易混淆的邻近方法论

- 与 `shengzhi-jiaxin` 的"增益之象"：加薪=收入域，升职加薪 skill 的判据是"金钱类象旺相不空"；本 skill 六条件是更细的"收入"判据，可组合使用。
- 与 `kongwang-bianzhi`：财空/闭口/破碎是变质的具体形态，通用空亡规则（旺不为空、得生得助不为空、天空例外）见该 skill。
- 与 `shiyun-zonghe` 收入维：时运收入维只看父/禄虚实一句；本 skill 是全量判据（六条件+纯财+传递象+大背景）。
