# 大六壬断课主 Skill（三步断课法）

> **角色声明**：本 skill 是 daliuren 体系的主断课入口。三步断课法主干（明占类→定侧重→看显象）与十一条执行链、冲突裁决阶梯内嵌自包含；但五个关键环节**必做**加载并执行对应北海子 skill（`kongwang-bianzhi` 显象 / `youlu-lilun` 有路 / `keti-qishi` 课体 / `jixiong-tiaozhi` 调制 / `yingqi-panduan` 应期，均已部署于 `.opencode\skills\`），以完整运用北海理论；分类占子 skill（恋爱/财禄/应聘/升职/时运/终身/人际）为**可选参考**，在占类判定后按需调用。冲突时一律以本 skill 的【⚖️ 冲突裁决阶梯】为准。

## R — 原文 (Reading)

> 最简捷的断课方法，应该是"三步走"：明占类，定侧重，看显象。……无外乎如下三种：1、某事能否成；2、某人事物能否出现；3、某人事物会向哪个方向发展。……判断的侧重点则只有两个：1、类神。2、课体。……确定了侧重点之后，要仔细辨析类神和课体的真假，这就是"看显象"。类神现于课传而不空陷，不变质，则其事必成。
>
> — 北海闲人，《北海的六壬特训班讲义》第一讲

> 空亡的辨别，一个方面，要看其旺衰；另一方面，又看是否得住。旺不为空，得生得助不为空，这是看空亡的基本原则。……比如占工作，见日禄本是吉象。但如果日禄乘玄武、作闭口，则禄难到手。
>
> — 北海闲人，第一讲、第六讲

> 何为有路？有路就是被引动了，由于变成了"动爻"，它的力量就强，其显象就明确。……凡合（三合、六合、遁干五合）、刑、冲、破、害都为有路，而类象与其天盘、落宫之间，也为有路。……看行动的原因，就看其阴神是什么。……但行年的介入，就便这个虎动了起来，由惊危变成了破坏。
>
> — 北海闲人，第三讲

> 凶的东西总比吉的东西更以激烈、迅速的气势出现，因此找凶煞往往比找吉气更容易。先找到一个"凶"的充分理由，则可确定人有灾病、事不成功——非吉即凶，肯定一面即否定其反面。
>
> — 北海闲人，第四讲（否定式过滤）

## I — 方法论骨架 (Interpretation)

- **面对的问题**：一课拿到手，该从什么角度入断——这是全书要解决的核心问题。本 skill 将其工程化为一条可重复执行的推理脊柱。
- **三步断课法主干**（北海闲人第一讲）：
  1. **明占类**：把用户问话转成"结果导向"三分类——①某事能否成（成败二元）；②某人事物能否出现（存现问题）；③某人事物向何方发展（方向/趋势）。先归好类，后面的主线才选得对。
  2. **定侧重**：从两条主线里选一条——**类神**（能取到代表该事物的干支神将组合）或**课体**（整体结构）。以"入课传为重、不入课传为轻"加权；课传上象明晰则依它断。**课体大势 > 类神细节**（问答录八）。
  3. **看显象**：对所选主线的象做真假校验——空亡辨旺衰与得助、类神辨是否变质（乘凶将/闭口/破碎/阴神见鬼/落墓/乘丁），排除假象后定最终结论。
- **产出**：一条"占类标签 → 主线选择 → 真假校验 → 调制 → 应期"的完整结论链，每步有依据可查，置信度可标注。

### 断课三看与主次取舍（问答录扩展）

- **看课抓主线、主次取舍**：一课吉凶混杂时，先定课体大势（方向与正误），主因素定结论、次因素只微调——"主次因素的取舍一定要分清"（问答录七：三传合局泄干气、贵人坐墓不影响中甲）。
- **断课三看**：①课体定大势 ②类神定人事 ③**一定要看阴神**——朱雀乘戌不生不克，唯阴神巳火为驿马、又是旬丁、而且生日，故断"好旨归里"而非下狱（问答录九）。阴神是第三层不可省略。
- **救解局部性**：有救解（阴神生日、天将吉）≠ 改总凶——救解只减轻局部、决定"降几级"（降罚而不极刑），不改变课凶总趋势（问答录九）。
- **非占现类勿言之例外**：默认不越占，但课象明显（人宅受脱俱招盗、玄武发用传归支上）时可越占断之——此为有据的灵活而非随意发挥（问答录十一）。

### 来意占（问答录扩展）

- **正时断来意**：以正时/占时及其所临类神定所问——时逢日之胎神断六甲、太岁作青龙发用断功名、正时之象合天将（天空=章奏）断章奏（问答录三/四/九）。
- **泛占断紧事**：来意不明时从课体看当前最紧急的事——课体定类（度厄=外来灾）→ 干支乘神定象（干上子水鬼乘蛇=阴人缠绕、宅上酉=不正当男女关系）→ 落点成事（问答录六僧占）。
- **干上主思、支上主行**：干上神=所思所关注、支上神=所见所作为，断来意先分干支（问答录四）。

### 看显象——空亡与变质（第一/四/六讲 + 问答录十四）

- **空亡二重鉴别**：①查旺衰——旺相（月建/旺地）则**旺不为空**；②查得助——得生得助、有路可通则**得生得助不为空**。真正空亡 = "不确定"而非必凶，须结合它象。
- **空亡两个例外**：①**天空所主之空不论旺衰一律以凶论**（不可用"旺不为空"豁免）；②**日寄宫之空更甚于别宫之空**（问答录十四："日寄宫空不为空纯属无稽"）。
- **变质六查**：乘凶将 / 作闭口 / 作破碎煞 / 阴神见鬼（遁干为鬼）/ 落墓 / 乘丁。命中任一项，吉断降级或翻转。

### 凶煞否定式过滤（第四讲）

- 四大凶煞：**丁马（旬丁/遁丁）**（动变移易）、**白虎**（死丧病伤）、**勾陈**（迟滞官司）、**天空**（空亡风波）。
- **位限定**：白虎须发用才主吉凶，课上显象不主吉凶；凶可被吉象并聚或受制化解（白虎被地盘克→病可愈）。

### 有路动态深化（第三讲）

- 有路扫描：三合/六合/遁干五合/刑/冲/破/害 + 类象与天盘落宫间有路；被引动者=动爻、显象明确、优先采信。
- 阴神推演：看行动原因看阴神（官星太常=升迁、勾陈=受役、玄武=暗昧消失）；吉象阴神见凶=暗含损耗。
- 年命引动：行年介入使静态类象由"惊危"变"破坏"；行年上神=占者自身思想动向，区分主动/被动。
- 丁马（旬丁/遁丁）动移：身不由己之动，求稳之事逢丁=风雨飘摇。

### 课体细读三层（第一/三讲 + 问答录）

- **九宗门为大势** → **《毕法》课传结构定关键**（干支上神结构、彼此全伤、干支互传、干支乘墓、解离格、四课不备等，不能只盯《课经》）→ **位次定力度**（同象在四课 vs 三传、干上 vs 支上、发用 vs 末传力度不同，"壬占最重位"）。

### 吉凶调制（第六/十一讲）

- **四象限**：爻吉凶 × 乘将吉凶 → 吉吉=吉上加吉 / 吉凶=吉中有忧 / 凶吉=温柔一刀 / 凶凶=人间地狱。
- **大背景缩放**：课体大局定性后，"若有凶象则凶大，若有吉象则吉小"（背景凶）或反之（背景吉）。
- **救解局部性**：有救解只降级、不改方向。

### 应期两步走（第十一讲）

- 先定迟速，再定具体日期；两线定一点交叉验证（天将变化法《心印赋》+ 五行旺死法）；岁日月时发用量级（太岁发用应年内/月建一月内/日辰当日/时发用当时）。**纪律：应期必须在吉凶已定之后断。**

### 一课双时层（第九讲）

- 三传 = 长久/全局（终身课即从小到老）；日干上神 = 当前状态/近事。分开命名空间输出，避免把当下细节当全局走势。

### ⚖️ 信息源冲突裁决阶梯（顶层仲裁，优先级高于一切步骤）

> 当古籍、案例、理气（五行生克）、排盘断语产生矛盾时，必须先执行本裁决，再继续推理。

| 优先级 | 信息源 | 采信规则 |
| :---: | :--- | :--- |
| **1（最高）** | **已验证的实战反馈** | 仅当 `经验日志\` 中存在同一课体（或同发用组合）且标记为 **"反馈：验"** 的记录时，直接采信该结论，其他信息源仅作背景说明。**未验证的记录降为第 3 级。** |
| **2（次高）** | **类神状态（课式本身）** | 无已验证实战日志时执行"**类神定结局，课体定环境**"：课体说吉但核心类神空亡坐墓→以类神凶为判决；课体凶但类神旺相且临吉将→以类神吉为判决。 |
| **3（中位）** | **天将主宰权（将高于神）** | 当地支五行（生克）与天将（吉凶）矛盾时，以天将的"吉凶属性"为主（青龙永吉，只是力量受阻），地支仅描述受阻方式。未验证的实战反馈也在此级。 |
| **4（末位）** | **古籍理论通论** | 仅在前三层无法做出明确判断时，才引用古籍蒸馏经验作为兜底。 |

> *"⚠️ 仲裁触发：虽然 [被否决的信息源] 指向 X，但根据 [采信的信息源及具体依据]，本次最终裁决为 Y。"*

### 工程纪律（防漏防编机制）

- **强制读断语**：排盘输出自带的课义/断曰/课经/毕法标注是权威浓缩信号，必须逐条读取并引用后再进入推理。**断语在眼前而不读 = 任务失败。**（历史翻车：课经断曰"用神与支作六害，又生鬼克日"就在页面上却未读取，导致卯辰六害漏判。）
- **反推纪律**：① 反推必须有依据——任何事后归因或修正技法必须引用现存资料佐证（古籍原文/经验库条目/已验证案例）；② 禁止无依据瞎编——禁止为了"吻合答案"临时发明技法；③ 从疑可入库，必须带"未验证从疑"标签（单案例反推/未经独立验证/不得作为断语依据），严禁混入已验证规则；④ 从疑转正机制——只有经后续独立案例验证通过后才可摘除标签。
- **网络搜索**：仅作次要可选证据，不覆盖课象核心判断。
- **案例检索（必做）**：断课推理完成后、组织断语前，必须调 liuren-cases 检索案例库 + 检索经验日志（"反馈：验"同课记录），并经【⚖️ 冲突裁决阶梯】核对后方可定案（见步骤 10）。不检索即输出 = 任务失败。
- **🔒 必调铁律（防跳步防偷懒）**：凡标注 **🔗 必做调用** 的子 skill（步骤 4/5/6/7/8/9：`kongwang-bianzhi`/`shensha-panduan`/`youlu-lilun`/`keti-qishi`/`jixiong-tiaozhi`/`yingqi-panduan`）与子智能体（步骤 10：`liuren-cases`），**必须实际调用**——子 skill 用 skill 工具加载并执行其完整流程，子智能体用 task 工具调起。**禁止**以本页内置摘要代替调用、禁止凭记忆自行推断后直接作答。**未调用即输出 = 任务失败，须回补调用后重新组织断语。** 输出前必须过步骤 11 的调用核对表。

## A1 — 书中的应用 (Past Application)

### 案例 1: 占鹏博士股票次日走势（c01）
- **问题**: 占个股次日走势，属"某人事物会向哪个方向发展"（方向类）。
- **方法论的使用**: 明占类=方向类 → 定侧重=课体线（取不到具体类神）+五行特质 → 看显象：四课不备+六阴相继尽昏迷=徘徊低迷；干支各被上神克=《毕法》"彼此全伤防两损"；三传木局逢白虎=谣言四起、动摇不定，支亥被克价必落。
- **结论**: 股必降。**结果**: 次日降 7%，日最高降幅 8.78%。

### 案例 2: 占单位分房（c02）
- **问题**: 占分房能否分到，属"某人事物能否出现"（存现类）。
- **方法论的使用**: 定侧重=类神线（亥为楼阁、午厅堂、卯房宿、丑/勾田产）；看显象：亥现于干上=到手之象，但亥为旬空→**空亡二重鉴别**：亥在酉月属旺相（旺不为空）+ 申入中传生亥、与太岁子相合=得生得助不为空→空亡解除；返吟主反复、玄六重逢主暗箱操作、绝上加绝主不很满意。
- **结论**: 房必得，但过程反复、结果不甚满意。**结果**: 亥月末事果应（分到房）。

### 案例 3: 占章奏上书·断课三看（问答录九，z08）
- **问题**: 占上书吉凶、旨意。
- **方法论的使用**: **断课三看**——①课体定大势：无禄无路课大凶、财官禄马俱入墓绝；②类神定人事：朱雀乘戌与日干不生不克；③**看阴神**：阴神巳火为驿马、又是旬丁、而且生日→断"好旨归里"而非下狱。**救解局部性**：阴神生日是救解，但救解是局部的，不改变无禄课总凶（"不是极凶的课，因为还有救解。但这个救解是局部，并不能改变课凶的总体趋势"）。
- **结论**: 章奏占；主降罚削权、宜急流勇退；上书得好旨归里。**结果**: 后唯冠带闲住，回家未久仙游（死）。

### 案例 4: 僧占泛泛·来意占（问答录六，z05）
- **问题**: 僧人未言所占何事，泛泛而占断其"最紧急的事"。
- **方法论的使用**: **来意占·泛占断紧事**——课体定类：三下克下度厄主外来灾、三传递克众人欺；干支乘神定象：干上子水鬼乘蛇=阴人缠绕（神后妇人+蛇缠绕）、宅上酉=少女/不正当男女关系、干支互乘败气=败坏之事；落点成事：因不正关系被缠上。再配**有路动态**：干支首尾相见无空亡=纠缠之事一时不能拆离、河魁加卯命+驿马临行年=必起相携而逃之意、一旬周遍格"去而复来"。
- **结论**: 有阴人往来缠扰、一时不能拆离；有相携而逃之意；有人攻讦。**结果**: 众施主送僧渡江，后复来扬携妇而去。

### 案例 5: 男占 08 年年运·年命引动（c08）
- **问题**: 占 08 年运势，课中日禄乘白虎又作闭口，工作如鸡肋——结局会怎样。
- **方法论的使用**: **有路+年命引动**：日禄乘白虎本是"惊危"之象；行年（子年生人行年在丑）上神卯乘蛇冲日禄白虎→**行年介入使虎由惊危变成破坏**；行年上蛇=自己起异心（主动），故断辞职而非被炒；弹射+源消根断叠加大背景缩放=投资亏损。
- **结论**: 会主动辞掉工作，炒股大亏。**结果**: 08 年辞掉工作、下半年炒股大亏。

### 案例 6: 张四知去留·空亡例外（问答录十三，z12）
- **问题**: 因高镇兵马屯北城外，占是留是走。

### 步骤 3 · 定侧重

1. **两条主线二选一**：
   - **类神线**：能取到代表该事物的干支神将组合（按上表占类取类神）→ 取类神。
   - **课体线**：取不到类神（没给具体对象）或问大势/方向类问题 → 走课体。
   - 选择原则：**入课传者为重，不入课传者为轻**；哪个象更明晰就以哪个为主；**课体大势 > 类神细节**（顾祖例：龙神发用得生助看似利官，遇特殊课体此象舍弃）。
2. **断课三看**（主线选定后强制执行）：①**课体定大势** ②**类神定人事** ③**一定要看阴神**（行动原因/后续转折/隐藏内容）。
3. **主次取舍**：吉凶混杂时主因素定结论、次因素只微调（问答录七：合局泄气、贵人坐墓不推翻中甲主结论）。
   - 完成标准: 输出"主线=类神/课体"选择 + 1-3 条入课传的关键信号 + 阴神快查结果。
   - 判停条件: 盘面数据缺失（无干支/三传/天将）或占类含糊到无法归类 → 跳到步骤 11 输出"需澄清"而不是硬断（去向：终止链路，不进入步骤 4-10）。

### 步骤 4 · 看显象（空亡与变质校验）★判停闸门

> 🔗 **必做调用（不可跳步）**：进入本步骤时，**必须先实际调用并执行 `kongwang-bianzhi` 子 skill**（空亡二重鉴别 + 变质六查 + 空亡勘误，`.opencode\skills\kongwang-bianzhi`）。下方内置摘要仅作导航提示，**绝不等于已调用该子 skill**——跳过实际调用、直接凭摘要输出 = 任务失败。调用该子 skill 后，其结论写回本步"完成标准"；细则与边界以子 skill 为准，冲突走【⚖️ 冲突裁决阶梯】。

**类神的"真假"校验——这是"三步断课法"的第三步。**

1. **空亡二重鉴别**（空亡 ≠ 一律断凶，而是"不确定"）：

   | 鉴别维度 | 检查 | 结论 |
   |---------|------|------|
   | ① 旺衰 | 类神是否旺相（乘月建/处旺地）？ | **旺不为空** → 空亡可解除，事仍可成 |
   | ② 得助 | 类神是否得生、得助、有路可通？ | **得生得助不为空** → 空亡可解除 |
   | 两者皆否 | 空亡且休囚死绝、无生扶 | 真空 → "不确定/向反面"，须结合它象 |

   - **例外 1（强制）**：**天空所主之空不论旺衰一律以凶论**——不可用"旺不为空"豁免。
   - **例外 2（强制）**：**日寄宫之空更甚于别宫之空**——日上之神落空不可按"空不为空"放行吉断（幕贵坐空断非科甲、出行日空断不得意而归）。
   - 空亡类神遇动（冲/合）被填实 → 空亡可解；旺火逢空仍动、罗网逢空即脱为动象侧例外（见步骤 6）。

2. **变质六查**（对每个核心类神逐项查）：①乘凶将（日禄乘玄武作闭口→禄难到手）；②作空亡（财空→反为损耗）；③作破碎煞（财作破碎→花费/拆分）；④阴神见鬼/遁干为鬼（得财因财致祸）；⑤作闭口（贵人闭口=在场但不说话）；⑥落墓/乘丁。
   - 类神状态四层追问（防单层误读）：位置（干上/支上/初传/中传/末传/不入课传）→ 叠加神煞（闭口/空亡/破碎/丁马/驿马）→ 所乘天将 → 六亲属性。**任何一层出现空亡/闭口/破碎/坐墓 → 该类神吉象打折甚至反转。**
   - 完成标准: 输出"空亡状态 + 两查结论 + 变质项清单（可为零项）"。
   - 判停条件: 命中空陷或变质 → 输出"向反面/待定"，不武断下"必成"；空亡且无救且无课体变通依据时，同样输出"向反面/待定"（去向：可继续步骤 5-9 佐证，但不再下"必成"结论）。

### 步骤 5 · 凶煞否定式过滤（可并行于步骤 4）

> 🔗 **必做调用（不可跳步）**：进入本步骤时，**必须先实际调用并执行 `shensha-panduan` 子 skill**（神煞分级取用 + 状态判断 + 叠加组合断，`.opencode\skills\shensha-panduan`）作整体神煞判读，再以本步骤的否定式过滤确立凶断倾向。跳过实际调用、直接凭摘要输出 = 任务失败。神煞起法核对用 `refs/daliuren-shensha.md` 速查表。

**反向过滤，防"只数吉象、不看凶象"的系统性乐观偏误。**

1. **四大凶煞扫描（每课必扫）**：

   | 凶煞 | 属性 | 判断要点 |
   |------|:----:|----------|
   | **丁马（旬丁/遁丁）** | 动变 | 占考试/应聘逢朱雀乘丁→结果被篡改；求稳之事（工作/生计/姻缘）逢丁→风雨飘摇；丁并劫煞→大凶 |
   | **白虎** | 死丧病伤 | 须看"位"：课上显象不主吉凶，**发用才主吉凶**；白虎被其地盘克→病可愈；长生带白虎→先吉后祸 |
   | **勾陈** | 迟滞官司 | 拆读四义"斗/讼/争/官"；**迟滞义最易被忽略**——勾陈临干或主大运→麻烦不断、如被捆住手脚 |
   | **天空** | 空亡风波 | **天空之空不论旺衰一律以凶论**（区别于普通空亡）；天空临干/临父→父母不同意、事情落空 |

2. **凶煞优先判断逻辑**：

   ```
   扫描课传（干支上神 + 三传 + 阴神）：
   ```

- **dl-01 排盘零 AI 参与**：禁止 LLM 自行推算天地盘/四课/三传，必须本地排盘引擎；自行推算必然出错。
- **dl-02 强制读断语**：课义/断曰/课经/毕法标注必读必引用。**历史翻车：**课经断曰"用神与支作六害，又生鬼克日"就在排盘页面上却未读，导致卯辰六害漏判——断语在眼前而不读=任务失败。
- **dl-03 蒸馏经验不回查原文**：经验库无相关条目时直接跳过，不回查古籍原文拖慢主流程。

**读象层（防单层/漏层读象）：**

- **dl-04 强制六亲序列**：干上/支上/三传六亲序列必列。**历史翻车：**三传卯(财)→寅(财)→丑(父) 财财父序列=传财太旺破印（资格被破），考试占误断"能过"。
- **dl-05 发用与日支关系必查**：用神害支/冲支/刑支必查。**历史翻车：**初传卯与日支辰作六害，课经断曰已明确警告却漏判。
- **dl-06 类神四层追问**：位置/叠加神煞/天将/六亲四层必查。**历史翻车：**干上贵人未临申（申为闭口），只见"贵人生干"就断"有贵人相助"，漏掉"贵人闭口=评委不认可"——最典型的单层读象错误。
- **dl-07 神煞分级必查**：一级神煞（旬空/禄神/驿马/丁马）每课必查；闭口属二级，考试/求人/谈判/面试占升级为一级。
- **dl-08 日禄三查**：**历史翻车：**日禄逢空被当"小瑕疵"放过，实际是考试/事业占的根基性凶兆——禄空=自身能力/待遇根基已失。
- **dl-09 末传天将序列**：**历史翻车核心：**"末传生日干但乘天空"=看似有利实则虚（终局落空）；末传乘玄武=终局暗昧有诈。
- **dl-10 干支上神对比**：干上神 vs 支上神相克相害=我与事/环境正面冲突，必查。

**认知偏误层（防系统性乐观/悲观偏误）：**

- **dl-11 凶煞优先扫描**：读断语后、正式推理前必扫四大凶煞，确立凶断倾向。**历史翻车：**多次案例（入党答辩/肺结节/电瓶车）因"只数吉象、不看凶象"系统性误断偏乐观。
- **dl-12 反向三凶核查**：断课前强制列出最不利三个信号，确认未被吉象掩盖。
- **dl-13 空亡二重鉴别**：不一律断凶（旺不为空、得生得助不为空），也不一律放行（天空之空不论旺衰一律凶、日寄宫之空更甚）。
- **dl-14 有路检测**：合刑冲破害及天盘落宫六种引动必扫，被引动类象权重提升。
- **dl-15 阴神推演**：关键象阴神必推（行动原因/后续发展/隐藏内容）。
- **dl-16 年命引动检查**：年命/行年冲合刑破静态类象必查，区分主动/被动。
- **dl-17 一课双时层**：三传看长久全局、干上神看当前状态，分开命名空间输出，防把当下细节当全局走势。
- **dl-18 大背景缩放**：课体大局定性后，局部吉凶按大局缩放，防孤立判读单象。

**调制层（防程度误判）：**

- **dl-19 吉凶调制四象限**：爻吉凶×乘将吉凶四象限调制，输出程度与质感，禁止用程度词回避明确结论。

**流程纪律层（防方法失范）：**

- **dl-22 先定占类后取类神**：不同占类不同取法，先归好类再取类神。
- **dl-23 课体也是一种类象**：课体是相对固定的类象组合，不与类神对立。

### 公共认识论批判（内置，勿跳过）

- **幸存者偏差（ce12）**：书中/库中案例几乎全部"果应"，无失败样本——**案例个数 ≠ 命中率，不可把案例当统计证据**。占者自述反馈、时间跨度短（数月）均削弱证据力。
- **同一课多解（ce13）**："以类神为侧重也可、以课体为侧重也可"，同一课两条主线结论可以不同甚至相反——输出单一结论时必须声明"多解风险"。
- **可证伪性（ce14）**：象意系统组合自由度极大（干支×天将×位×阴神×年命），任何结果几乎总能事后自圆其说——把解释视为"假设"而非"验证"；禁止事后强解。
- **干支映射信仰前提（ce15）**：天干地支、五行生克、神将象意与人事之间存在客观映射——这是全体系的不言自明前提，从未被论证。判断建立在此前提下，用户应知悉其非实证性质。

### 纠错记录（本 skill 历史勘误）
